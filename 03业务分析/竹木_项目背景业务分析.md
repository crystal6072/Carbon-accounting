## 1 项目背景

| 背景维度 | 分析结论 | 判断类型 |
| :--- | :--- | :--- |
| 政策背景 | 国家正在建立产品碳足迹管理体系，包含核算规则标准、背景数据库、碳标识认证、应用场景和国际互认。 | 【资料明确】 |
| 行业背景 | 木竹产品已进入产品碳足迹标准和认证试点语境，木竹专项标准、竹木专项团体标准已出现，木制品中的人造板和木质地板进入首批碳足迹标识认证试点目录。 | 【资料明确】 |
| 企业背景 | 木竹产品涉及采伐、加工、运输、使用、废弃与循环等阶段，生产过程存在能耗、辅料、运输、工序分摊、碳固存等复杂核算事项。 | 【资料明确】 |
| 市场背景 | 绿色采购、客户审查、碳标签、绿色产品评价、国际客户 ESG/Scope 3 披露可能推动企业提供产品碳足迹数据。 | 【合理推断】 |
| 项目触发 | 现有资料明确提到运输环节数据缺口、多工序共线共设备导致核算精度不足、碳数据分散存储、口径不统一、数据碎片化等痛点。 | 【资料明确】 |
| 行业特殊性 | 木竹材料具有生物碳、长期碳固存、含水率/绝干质量、采伐损耗、废弃处置碳释放等特殊问题，不能完全套用一般工业品核算模型。 | 【资料明确】 |

## 4 用户痛点

### 4.1 当前碳核算方式

| 当前方式 | 现状判断 | 判断类型 |
| :--- | :--- | :--- |
| 人工台账和分散表格 | 企业碳数据分散在生产、能耗、物流、供应商、凭证和报告文件中，存在碎片化和复用困难。 | 【资料明确】 |
| 按组织或总量核算 | 企业可能掌握总能耗、总排放或企业层面盘查数据，但难以拆解到单个产品、批次、工序和生命周期阶段。 | 【合理推断】 |
| 依赖人工选择因子和标准 | 排放因子来源多、版本多、适用条件复杂，人工选择容易导致口径不一致。 | 【资料明确】 |
| 运输、使用、废弃阶段数据不足 | 资料明确提出运输环节核算数据缺口，并强调使用阶段、废弃与循环阶段补齐。 | 【资料明确】 |
| 核算结果难以被第三方复核 | 若缺少原始数据、因子来源、计算过程、版本记录和上报历史，结果难以满足核查和认证。 | 【合理推断】 |

### 4.2 主要痛点

| 痛点 | 业务影响 | 判断类型 |
| :--- | :--- | :--- |
| 数据分散、口径不统一 | 同一产品不同批次、不同人员、不同企业的核算结果不可比，难以复用和审核。 | 【资料明确】 |
| 生命周期覆盖不完整 | 只算生产能耗会遗漏原料采伐、运输、使用维护、废弃处置和循环利用影响。 | 【资料明确】 |
| 工序级分摊困难 | 多工序共线、共设备、共能耗导致产品或工序排放归属不清，影响精度。 | 【资料明确】 |
| 木竹碳固存口径复杂 | 生物碳、长期碳储存、碳流失、生物源 CO₂ 是否计入或抵扣总排放，需要按标准明确。 | 【资料明确】 |
| 因子和标准溯源压力高 | 不同标准、因子版本、区域差异和供应商数据会影响结果可信度和认证解释。 | 【资料明确】 |
| 上报和核查材料准备成本高 | 企业需要在上报前完成完整性、逻辑一致性、合理性、合规性校验，并保留证据链。 | 【资料明确】 |
| 供应链数据质量不可控 | 上游原料、胶黏剂、涂料、包装和物流数据可能缺失或可信度不足。 | 【合理推断】 |
| 对外披露风险 | 若低碳宣传、碳标签或碳固存表述不符合标准，可能引发认证不通过或绿色声明争议。 | 【合理推断】 |

## 5 典型场景

| 场景 | 业务过程 | 系统需支撑的问题 | 判断类型 |
| :--- | :--- | :--- | :--- |
| 产品全生命周期碳足迹核算 | 选择产品、批次、生命周期边界，录入活动数据，匹配因子并计算总碳足迹。 | 支撑摇篮到坟墓、摇篮到大门、大门到大门等边界配置和结果解释。 | 【资料明确】 |
| 采伐与原料阶段核算 | 记录林地信息、采伐量、出材率、集材距离、设备油耗、采伐损耗。 | 支撑原料来源和生物质流失的核算与追溯。 | 【资料明确】 |
| 加工工序级核算 | 记录干燥、热压、胶合、砂光、涂装等工序能耗、辅料和损耗。 | 解决共线、共设备、共能耗分摊和工序级排放归属。 | 【资料明确】 |
| 运输与仓储核算 | 记录原料运输、半成品调拨、成品配送、装卸和仓储排放。 | 补齐运输环节数据缺口，支持运输方式、距离、载重、装载率等参数。 | 【资料明确】 |
| 使用阶段和长期碳固存核算 | 配置产品设计寿命、维护周期、翻新次数、长期碳固存参数。 | 单独列示碳固存和使用阶段排放，按标准确定是否纳入最终汇总。 | 【资料明确】 |
| 废弃与循环利用核算 | 配置回收、再生、焚烧、填埋、堆肥、能源回收等处置路径。 | 支撑废弃排放、循环利用减排和生物源 CO₂ 单独列示。 | 【资料明确】 |
| 碳标签和报告生成 | 根据核算结果生成报告、标签、二维码和披露材料。 | 支撑模板、版本、快照、脱敏、水印和对外展示控制。 | 【资料明确】 |
| 企业数据上报 | 将核算完成的数据上报给监管部门、行业主管部门、集团或第三方平台。 | 支撑上报校验、上报包、回执留存、历史记录和审计视图。 | 【资料明确】 |
| 第三方核查 | 核查人员查看原始数据、因子来源、计算过程、日志和报告附件。 | 支撑只读审计、证据链追溯和版本一致性。 | 【资料明确】 |
| 减排诊断与对标 | 查看产品排行、工序热力图、行业平均对比、情景模拟和优化建议。 | 识别高排放环节、低碳工艺空间和商业展示依据。 | 【合理推断】 |

| :--- | :--- | :--- |

| 提升客户响应能力 | 面向品牌商、采购方、出口客户、绿色供应链审查时，可快速提供产品碳足迹和证据材料。 | 【合理推断】 |

| 非范围 | 排除原因 | 判断类型 |
| :--- | :--- | :--- |
| 通用企业碳盘查平台 | 本项目核心是木竹产品碳足迹，不默认覆盖企业组织层面全范围碳盘查。 | 【资料明确】 |
| 认证机构发证 | 系统支撑报告、标签和核查材料，不直接代表认证机构出具认证结论。 | 【资料明确】 |
| 标准制定工作 | 系统维护和引用标准规范，不承担国家、行业或团体标准制定职责。 | 【资料明确】 |
| ERP/MES/TMS/WMS/SRM 替代建设 | 这些系统作为数据来源或对接对象，不在本项目内重建完整业务系统。 | 【资料明确】 |
| 硬件采购、布线施工、计量检定 | 计量设备接入和管理可纳入系统，但硬件工程范围需另行确认。 | 【资料明确】 |
| 供应商线下审厂和数据担保 | 系统记录供应商数据和依据文件，不替代合同约束、现场审计和第三方验证。 | 【资料明确】 |
| 工艺改造实施 | 系统提供诊断、模拟和建议，不直接承担设备改造、产线调试和投资建设。 | 【资料明确】 |
| 碳交易履约 | 不默认覆盖碳配额、CCER、交易撮合和履约管理。 | 【资料明确】 |
| 公共政策法规全量自动采集 | 系统可维护标准规范和指南文件，但不承诺外部政策全量自动同步。 | 【资料明确】 |
| 对所有行业产品开放 | 项目应聚焦木竹/竹木产品，不扩展为所有工业品通用产品碳足迹平台。 | 【合理推断】 |

## 9 成功指标

> 当前资料未提供正式验收指标，以下指标为结合业务目标形成的建议口径。

| 指标类别 | 建议指标 | 判断类型 |
| :--- | :--- | :--- |
| 覆盖能力 | 首批覆盖的产品品类、生命周期阶段、核算边界、标准/因子来源达到项目约定范围。 | 【合理推断】 |
| 数据完整性 | 关键活动数据、因子来源、标准依据、凭证附件、核算过程和版本记录完整率达到约定阈值。 | 【合理推断】 |
| 核算效率 | 单个产品或批次从数据准备到报告生成的周期明显低于人工方式。 | 【合理推断】 |
| 核算准确性 | 多工序共线、共设备、运输、废弃等复杂场景可按规则完成分摊和复核。 | 【合理推断】 |
| 可追溯性 | 任一产品碳足迹结果可追溯到活动数据、排放因子、核算规则、标准版本、操作记录和报告快照。 | 【合理推断】 |
| 上报可用性 | 上报包可通过完整性、逻辑一致性、合理性和合规性校验，并留存回执。 | 【合理推断】 |
| 核查支撑 | 第三方核查人员可通过审计视图查看必要证据链，减少线下补材料次数。 | 【合理推断】 |
| 用户采用 | 试点企业、活跃用户、已核算产品/批次数、生成报告数、上报次数达到项目目标。 | 【合理推断】 |
| 业务价值 | 企业可识别主要排放热点，形成减排方案、客户披露材料或绿色认证材料。 | 【合理推断】 |
| 数据治理 | 因子、标准、产品、工艺、供应商数据具备版本管理、适用条件、状态和审核记录。 | 【合理推断】 |
| 监管价值 | 监管/行业侧可获得按企业、产品、区域、阶段汇总的碳足迹数据和异常情况。 | 【合理推断】 |
| 验收指标 | 具体验收口径、阈值、测试方法、试点数量、性能指标和上线标准尚未提供。 | 【待确认】 |

## 10 业务风险

| 风险 | 影响 | 判断类型 |
| :--- | :--- | :--- |
| 标准口径不一致 | 不同标准对生命周期边界、GWP、碳固存、生物源 CO₂、循环利用减排的处理不同，可能导致结果不可比。 | 【资料明确】 |
| 碳固存表达不当 | 若将木竹产品简单宣传为“负碳”或直接抵扣全部排放，可能引发认证和披露风险。 | 【合理推断】 |
| 数据质量不足 | 企业历史台账、供应商数据、运输数据、废弃处置数据不完整，会影响核算可信度。 | 【资料明确】 |
| 因子来源不被采信 | 因子来源、版本、适用条件和不确定性不清，可能导致第三方核查或认证不认可。 | 【合理推断】 |
| 系统边界过大 | 若一期同时覆盖移动端、物联采集、ERP/MES 对接、行业数据集和高阶分析，实施风险较高。 | 【合理推断】 |
| 外部系统对接不确定 | ERP/MES/物联设备/上报平台接口、字段和同步频率未确认，会影响工期和数据闭环。 | 【待确认】 |
| 数据授权与保密 | 企业上报、行业数据集、供应商数据和二维码披露涉及商业敏感信息，需要权限、脱敏和授权规则。 | 【合理推断】 |
| 政策和认证规则变化 | 产品碳足迹标准、碳标识试点目录、国际法规和目标客户要求可能变化。 | 【合理推断】 |
| 项目定位不清 | 政府平台、企业内部系统、行业平台、第三方服务商平台或 SaaS 产品的运营模式不同，会影响权限、流程和商业模式。 | 【待确认】 |

| 待确认事项 | 为什么必须确认 | 判断类型 |
| :--- | :--- | :--- |
| 项目建设主体和运营主体是谁 | 决定系统定位、部署方式、权限模型、运维责任和数据归属。 | 【待确认】 |
| 首批目标客户和试点企业是谁 | 决定需求优先级、数据接入路径、角色设计和试点验收方式。 | 【待确认】 |
| 首批产品品类是什么 | 决定生命周期边界、PCR/标准适配、字段、报告模板和核算规则。 | 【待确认】 |
| 是否限定实施地区，例如南平及核心产区 | 决定区域基础库、地方因子、产业链数据和监管汇总维度。 | 【待确认】 |
| 采用标准和优先级是什么 | 决定 GB/T 24067、LY/T 3436、T/CBIAS 2108、ISO 14067、EPD 等口径如何适配。 | 【待确认】 |
| 碳固存是否抵扣最终碳足迹 | 决定核算结果、报告呈现、碳标签和对外声明风险。 | 【待确认】 |
| 生物源 CO₂、甲烷 GWP100、循环利用减排如何处理 | 决定废弃阶段、资源化利用和最终总量口径。 | 【待确认】 |
| 碳标签是内部模板还是正式认证标签 | 决定是否需要审批、发布、撤销、外部查询和认证机构流程。 | 【待确认】 |
| 是否真实对接 ERP/MES/WMS/TMS/SRM | 决定接口范围、字段映射、主数据归属、联调计划和数据责任。 | 【待确认】 |
| 是否真实接入物联设备和电碳表 | 决定硬件、协议、采样频率、时序数据、现场施工和设备检定边界。 | 【待确认】 |
| 供应商数据如何授权和审核 | 决定上游数据可信等级、依据文件、审核流程和责任边界。 | 【待确认】 |
| 行业数据集是否对外共享 | 决定企业数据脱敏、授权、贡献机制、审核责任和公共服务属性。 | 【待确认】 |
| 一期和二期建设范围如何拆分 | 决定 MVP、预算使用、页面清单、接口清单、验收计划和项目风险。 | 【待确认】 |
| 项目成功的正式验收指标是什么 | 决定系统上线、业务验收、核算成果验收和合同交付口径。 | 【待确认】 |
| 是否面向国际客户或出口合规 | 决定是否需要兼容 ISO、EPD、GHG Protocol、EN 15804、EUDR、ESPR 等国际语境。 | 【待确认】 |
