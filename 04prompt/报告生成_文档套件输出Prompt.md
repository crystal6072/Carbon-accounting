     报告（PcfReport） 1 ─── N 报告版本（PcfReportVersion）

## 产物二：业务 PRD（`报告生成业务PRD.md`）

**必须包含**：

- **§3 功能清单**：模块 | 功能点 | 描述 | 优先级（模板选择、生成 / 重新生成、封面信息补充、说明性内容编辑、预览、下载、确认完成、只读态）
- **§4 核心业务规则（R-052 起，承接碳足迹核算 R-051）**，至少覆盖：
  - **R-052 报告准入**：④→⑤ 需核算完成 + 准入校验通过（方案 §5.5），不通过不可生成
  - **R-053 报告生成**：按「项目配置 + 检测结果 + 核算结果 + 选定模板」生成初稿，按边界区分配置
  - **R-054 模板选择**：可选模板、按边界过滤、切换模板后需重新生成；模板版本随报告版本留存
  - **R-055 封面信息补充**：企业 / 产品信息字段的带出与手工补充规则；仅草稿阶段可编辑
  - **R-056 编辑边界**：仅可改说明性 / 展示性内容；活动数据、因子、分配比例、公式、核算结果不可改
  - **R-057 报告版本**：草稿 + 正式版全量留存；每次生成生成新版本
  - **R-058 确认完成**：由核算人员执行；二次确认 + 留痕（确认人 / 时间）；确认后项目状态 → **已完成（终态）**
  - **R-059 确认后不可修改**：终态锁定报告与步骤①~④数据，入口只读 / 隐藏；如需修订 → 新建修订版（本期后置）
  - **R-060 报告下载**：PDF / 系统规定格式，支持下载、打印
  - **R-061 概念不外露**
- **§5 状态与动作**：报告状态流转 Mermaid（报告生成中 → 报告编制中 → 已完成）+ 状态→项目状态映射表 + **动作能力矩阵**（生成 / 重生成 / 编辑 / 预览 / 下载 / 确认完成 × 各状态；确认后全列 ❌）
- **§6 报告章节结构**：按边界（gate/grave）列出报告章节与要素（对齐 ISO 14067 / GB/T 24067-2024）
- **§7 边界与异常处理**：准入不通过、生成失败、模板失效、并发确认、已完成再次进入、报告已确认后上游数据变更（应不可变）
- **§8 待确认事项**（与字段清单交叉引用，含 D1 修订登记）
- **§9 验收标准**（≥ 10 条，覆盖生成、模板、封面、编辑、下载、确认锁定、只读、准入、概念不外露）
