## 模块定性（不得偏离）
- 模块名称：**行业库**
- 业务归属：后台管理 → 基础库 → 行业库（方案 §2.3 A1-4、§4.2.5、§六 P06）
- 模块类型：**基础数据维护（轻量）**；不是业务单据、**无审核流、无版本化**
- 维护形态：列表 + 新增 / 编辑弹窗（或独立页，按结论）；**列表支持批量启用 / 禁用**
- 数据来源两档：**系统预置（`PUBLIC`，只读）** / **组织自建（`ORG`，可编辑）**（是否开放组织自建见分歧 4。方案 §3.3.3 已把行业库列在 `PUBLIC` 系统预置清单中）
- 状态术语：**启用 / 禁用**（与物料、能源、计量单位库、标准文件、工序一致；**不采**竞品的「上架 / 下架 / 下架」类术语）
- **设计基调（不得偏离）**：参考竞品（南平铝业工业碳管理平台「信息库 / 行业库」）——竞品只有「行业名称 + 描述 + 行业核算指南」，本模块是**轻量分类字典**，**字段总数控制在 8～10 项**，不做过度建模
- 适用模板：`07template/04-前端Demo PRD/标准型页面&模块的PRD文档集/字段清单模板.md`

### 分歧 1：行业库到底承载什么？「行业分类字典」还是「行业参数模板」（Q01，**本任务最关键**）

上游三处表述**互相矛盾**，必须给出结论：

| 出处 | 表述 | 隐含结构 |
| :--- | :--- | :--- |
| 方案 §2.3 A1-4 | 行业分类与**行业参数模板**，供行业化配置复用 | 行业库**承载参数** |
| 方案 §1.2 | 新行业通过「**行业库 + 阶段配置 + 因子集 + 规则模板参数**」组合接入 | 行业库**只是组合入口之一**，参数在别的模块 |
| 方案 §4.2.4 D2 | **行业基线由行业库承载**，与核算模型解耦 | 阶段基线与行业库挂钩 |
| 方案 §4.2.4 修订说明 | 「**基线**」**不是独立对象**，是「按行业 + 边界查出来的阶段集合」，**不另建阶段基线实体** | 行业库**不承载**阶段集合 |

| 口径 | 结构 | 取舍 |
| :--- | :--- | :--- |
| **A（推荐）** | 行业库 = **行业分类字典 + 元数据**（编码 / 名称 / 上级行业 / 描述 / 行业核算指南 / 数据来源 / 使用状态）。**不承载任何参数**；「行业化配置」通过**其他模块的「适用行业」字段**（生命周期阶段、物料、能源、因子、模型）反向关联实现，行业库是**锚点** | 与 §4.2.4「不另建基线实体」「不两处维护」一致；字段最少，最接近竞品；不会因参数演进而反复改行业库 |
| B | 行业库 = **参数模板容器**：在行业上挂「默认阶段基线（引用阶段库多选）」「默认因子集（引用因子库）」「默认规则模板（引用模型）」等引用字段 | 与 §2.3 字面最贴，但**与 §4.2.4 修订说明冲突**（等于重建了"阶段基线实体"）；且引入对**未交付模块（因子库 A2-6、模型 A2-3）**的强依赖，行业库会被阻塞 |

**请给出结论或标【待确认】并写明推荐口径。** 若采纳 B，必须同时列出：新增哪些引用字段、依赖哪些模块、这些模块未交付时如何降级。
