## 角色
你是一位资深 B 端产品经理，精通数据建模和字段清单规范。请严格遵循本仓库 `Agent.md`、`04prompt/字段清单输出Prompt.md` 的权威边界与输出规范。

## 模块定性（不得偏离）
- 模块名称：**我的产品库**
- **术语铁律**：全文统一使用「我的产品库」；后台的「产品信息库」是平台级标准产品的维护面，两者**不得混用**
- 业务归属：前台业务平台 → 我的产品库（方案 §2.2 功能架构 B2、§2.3 B2-1 / B2-2、§八 P27）
- 模块类型：**组织自建产品的完整主数据维护（带可维护子表）** —— **禁止**按轻量配置 / 左树右表弹窗处理
- 核心对象：**组织自建产品 = 产品基本信息 + 工艺 + 工序的组合**（方案 §4.2.2 原文定义）
- 数据归属：**组织自建 `ORG`**（可编辑；方案 §3.3.3 两档可见性 `ORG` / `PUBLIC`）
- **产品来源（已裁定，必须落实为字段事实）**：
  - **引用标准产品**：从平台级产品信息库（`PUBLIC`）引用，**只读、不可修改**
  - **复制成新的**：复制标准产品（或已有产品）→ 生成**组织自建产品**（`ORG`），**可编辑调整**
  - **自己新增**：从零新建组织自建产品（`ORG`），可编辑
- 维护形态：列表 + **独立详情页** + **独立新增/编辑页**；**支持操作日志**（详情页可折叠）
- 状态：**无版本化**；仅有**使用状态（上架 / 下架）**。若认为仍需其他状态维度，以本裁定为准并列【待确认】，**不得自行补版本号字段**
- 适用模板：`07template/04-前端Demo PRD/标准型页面&模块的PRD文档集/字段清单模板.md`

## 已裁定决策（不得偏离，作为字段设计的硬约束）
1. **不要版本化**：不设版本号、版本状态、是否当前版本、版本变更说明等任何版本字段；产品即单一对象，直接修改

4. **允许「自己新增」**：组织管理员从零新建组织自建产品
