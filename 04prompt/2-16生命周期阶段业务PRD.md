## 文档结构（必须包含以下章节）

### 0. 文档基础信息
- 文档属性表（版本 V0.1、状态：草稿）、变更记录

- 文档分工表（字段清单 / 业务 PRD / Demo PRD 各管什么）

### 1. 需求概述
- 需求背景：生命周期阶段是**组织填报、检测、汇总与报告的骨架**；方案 §1.4 术语明确「支持一级/二级，可自定义」。阶段配置错误会**直接导致报告准入失败**（方案 §5.5）或触发 E10 / E11
- 需求目标（3～5 条可验证目标）
- In Scope / Out of Scope（明确：无审核流、无版本化；**导入 / 导出 / 删除 / 组织自定义是否支持必须写清**）
- 涉及角色（平台运营管理员维护系统预置基线；组织管理员维护组织自建阶段；核算人员在项目内启用 / 排除 —— 对齐方案 §7.1 / §7.2）
- 影响范围（下游：核算项目 P19 产品与边界配置、**P20 生命周期模型配置**、数据填报 P22、检测 E10 / E11、报告 P26）

### 2. 用户与使用场景
每条含：触发条件、操作流程、预期结果
- S01 查看系统预置阶段基线（通用基线）
- S02 查看行业基线（木竹基线）与通用基线的差异
- S03 新增 / 调整阶段（组织自定义）
- S04 启用 / 禁用阶段
- S05 调整一级 / 二级阶段的顺序
- S06 项目内启用 / 排除阶段（**含排除必须填原因**，对齐 E11）
- S07 阶段被项目引用后的编辑 / 禁用 / 删除限制
- S08 阶段变更对已建项目的影响（对齐 §4.9 快照与 E13）

### 3. 功能清单
| 模块 | 功能点 | 功能描述 | 优先级 |

覆盖：列表与查询、新增 / 编辑 / 查看阶段、层级与顺序维护、按边界的纳入规则维护、启用 / 禁用、导出；导入按结论。

### 4. 阶段结构与基线规则（**核心章节之一**）
- **一级 / 二级结构**：层级上限、二级阶段的上级归属、一级与二级的排序是否独立
- **默认阶段基线**（按方案 §4.2.4 的表）：
  | 一级阶段 | 二级阶段示例 | 摇篮到大门 | 摇篮到坟墓 |
  | 原材料获取 | 原材料获取、原材料运输 | 必须纳入 | 必须纳入 |
  | 生产 | 生产过程、生产过程废弃物处理 | 必须纳入 | 必须纳入 |
  | 运输/交付 | 运输 | 不纳入 | 必须纳入 |
  | 使用 | 仓储、产品使用 | 不纳入 | 按场景纳入 |
  | 生命周期末期 | 回收与最终处置 | 不纳入 | 必须纳入 |
- **决策 D2 的落地**：基线**按行业预置多套**（通用/制造业基线 + **木竹基线** + 后续行业基线）；每套含「一级 + 二级 + 按边界的纳入规则」；**项目创建时按「行业 + 边界」自动加载对应基线**；行业基线由**行业库承载，与核算模型解耦**
- **木竹基线的差异**：结合方案 §4.2.4 的脚注（如增加「种植 / 培育」阶段）与 §6.5 生物碳（固碳与末期释放对称，E16），列出木竹基线相对通用基线需要新增或调整的阶段
- 阶段与**边界**的关系（摇篮到大门 / 摇篮到坟墓各自一套纳入规则）

### 5. 纳入规则与排除规则（**核心章节之二**）
- 「按边界的纳入规则」的表达（三态 / 两态，按字段清单结论）
- **阶段加载机制**：项目创建时如何按「行业 + 边界」加载基线（引用方案 §5.1 第 3 / 4 步）
- **排除机制**：项目内排除阶段**必须填写原因**（方案 §5.1 第 4 步）；不适用必须填理由（**E11**，可计算但标风险、阻断报告）
- **覆盖性校验**：必须纳入的阶段缺失数据 → **E10**（阻断）
- 排除原因与本模块的关系（**推荐：排除是项目级行为，不回写阶段主数据**）
- 生物碳相关的末期阶段要求（方案 §6.5：开启固碳开关后，摇篮到坟墓必须对称处理，否则 **E16**）

### 6. 业务规则（R-001 起）
每条含：触发条件、处理逻辑、例外策略。至少覆盖：
- 阶段编码 / 名称的唯一性（同级内唯一？）
- 二级阶段的上级必须是一级阶段，且不允许跨级
- 阶段顺序的取值范围与同级唯一性
- 「适用行业」为空 = 全行业通用
- 系统预置阶段只读、组织自建可编辑（按字段清单结论）
- 阶段被引用后的锁定范围（编码只读？能否改纳入规则？）
- 禁用规则：禁用后不可被新项目加载，历史引用保留
- 删除规则：被引用的阶段不可删除；系统预置阶段不可删除
- **阶段变更的连锁处理**：改名 / 调顺序 / 改纳入规则后，已建项目与已核算结果如何处理（对齐 **§4.9 快照** 与 **E13**）
- 基线加载的确定性：同一「行业 + 边界」在同一时点必得到同一阶段集合（可复现）

### 7. 状态与操作矩阵
数据来源（系统预置 / 组织自建）× 使用状态（启用 / 禁用）× 引用状态，表格列出可用操作
