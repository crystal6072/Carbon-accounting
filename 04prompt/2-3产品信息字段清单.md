# 任务：生成「产品信息库」字段清单

## 角色
你是一位资深 B 端产品经理，精通数据建模和字段清单规范。请严格遵循本仓库 `Agent.md`、`04prompt/字段清单输出Prompt.md` 的权威边界与输出规范。

## 模块定性（不得偏离）
- 模块名称：**产品信息库**
- 业务归属：后台管理 → 基础库 → 产品库 → 产品信息库（方案 §2.3 A1-6、§4.2.2、§八 P08）
- **注意**：「产品库」是父级菜单（含产品分类 + 产品信息库），本模块只指「产品信息库」，不要与菜单名混用
- 模块类型：**完整主数据维护（带可维护子表）** —— **禁止**按轻量配置 / 左树右表弹窗处理
- 核心对象：**产品 = 产品基本信息 + 工艺 + 工序的组合**（方案 §4.2.2 原文定义）
- 维护形态：列表 + **独立详情页** + **独立新增 / 编辑页**；**支持操作日志**（详情页可折叠）
- 状态：**版本化**（V1.0 → V1.1 → V2.0）+ 上架 / 下架；版本策略必须在清单中写清
- 适用模板：`07template/04-前端Demo PRD/标准型页面&模块的PRD文档集/字段清单模板.md`
