## 文档结构（必须包含以下章节）

### 1. 需求概述
- 需求背景：能源是工序能源投入与排放计算的挂载点；能源的实物量与能量单位之间的折算（热值）是碳排放计算的关键环节
- 需求目标（3～5 条可验证目标）
- In Scope / Out of Scope（明确：无审核流、无版本化；**导入 / 导出 / 删除 / 批量启停是否支持必须写清**；**电网因子的区域 + 年度不在本模块**）

### 4. 能源类型分层与热值规则（**核心章节之一**）
- **能源类型（粗粒度）+ 能源名称（具体品名）** 的分层口径，按字段清单结论撰写
- 各类型下的典型能源（燃料 → 柴油 / 天然气 / 汽油；电力 → 外购电力 / 自发电；热力 → 蒸汽 / 热水）
- **热值 / 折算系数**：
  - 热值口径（LHV / HHV）按字段清单结论（推荐只留低位热值 LHV）
  - 折算方向：实物量 → 能量；**「热值」与「热值单位」成对填写**（如 `44.8` + `MJ/kg`）
  - 是否必填；活动数据填报时能否覆盖该默认值
  - **与「排放因子库」的边界**：热值只负责「实物量 → 能量」，**「能量 → 排放量」由排放因子库负责**，两层不得混算（方案 §4.4）
  - 需回答 **Q12：热值字段是否必需** —— 取决于排放因子库的因子表达口径（按物理量给出则热值冗余，可移除「热值 + 热值单位」）
- **单位归属（已确认，不得推翻）**：能源**不设「默认单位」**，单位由**工序的投入项 / 产出项**逐行选择；能源的「热值单位」只是热值的分母，不是填报单位。E04 与质量平衡的校验以**工序行的单位**为准
- **不得引入**「默认单位」「数据获取方式」「引用资源」「可见性」等字段（已于 2026-09-20 确认移除）
- 与生物碳 / 固碳的关系（方案 §6.5）：生物质能源是否需要标记，负排放因子在因子库侧处理

### 5. 单位与区域口径（**核心章节之二**）
- **默认单位**：必须引用计量单位库；能源实物量的默认单位（L / m³ / kg / 吨 / kWh / MJ / 吨蒸汽）
- **区域与年度归属**：电网类因子按「区域 + 年度」管理属**排放因子库**（方案 §4.4）；本模块**不含**区域 / 年度字段（按字段清单结论）
- 单位不可换算时的连锁影响：触发 **E04**（方案 §5.4）
- 能量平衡（**E15**）：投入能源与单位产品能耗的合理性校验，本模块提供哪些基础数据、由谁校验

### 6. 业务规则（R-001 起）
每条含：触发条件、处理逻辑、例外策略。至少覆盖：
- 能源编码 / 名称的唯一性
- 默认单位必填且引用计量单位库
- 热值 / 折算系数的必填性与取值约束（正数、范围）
- 系统预置能源只读、组织自建可编辑
- 能源被引用后的锁定范围（编码只读？热值能否改？）
- 禁用规则：禁用后不可被新工序选用，历史引用保留；已复制到产品版本的副本不受影响
- 删除规则：被引用的能源不可删除；系统预置能源不可删除
- **热值 / 默认单位变更的连锁处理**：是否触发 **E13**（重新检测 → 重新核算）
- 批量启停的约束
- 与排放因子库的职责边界（本模块不存因子、不存区域年度）
