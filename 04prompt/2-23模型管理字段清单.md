## 模块定性（不得偏离）
- 模块名称：**模型管理**（对象名：**核算模型**）
- 业务归属：后台管理 → 核算模型 → **模型管理**（方案 §2.3 **A2-3 模型配置 / A2-4 检测规则配置 / A2-5 版本化·发布**、§4.3.1、§4.3.2、§八 **P14（P0）**；原型 `/model/list`、`/model/list/:id`）
- 模块类型：**核算模型域对象（配置类）**——**既不是**基础数据维护（轻量）模块，**也不是**业务单据。关键差异：
  - **不做版本化**（**P3，业务决策**）：不设「模型版本 / 版本状态」，统一用**使用状态（启用 / 停用）**控制可用性 —— ⚠️ 方案 §4.9 原将模型列入**口径 1（版本化 + 发布 + 不可变）**，本模块改按**口径 2（模板 + 引用即复制）**，**须登记偏离**
  - **无审核流**、不参与单据下推、无外部系统同步
- 核心定位：核算模型是**「怎么算、要什么数据、怎么校验、怎么出报告」与「标准差异」的承载对象**（方案 §4.3.1 原话）；**标准差异（ISO 14067 / PAS 2050 / GB/T 24067 / PEF）= 不同标准依据绑定 + 不同配置组合 = 不同模型**（**P3 无版本化，故表现为一组独立模型**），不引入独立「规则包」对象（方案 v1.2 修订 1 / §4.3.1）
- 运行方式（方案 §4.3.2）：`后台配置模型 → 发布（发布后不可变，只能出新版本） → 前台引用模型 → 项目级实例化 → 项目核算模型快照`
- 本期口径：**温室气体仅 CO₂（CO₂e ≡ CO₂）**（方案 §1.1 / §6.1.1）
- 设计基调：**不凭空扩字段**；每多一个字段都必须在「备注」列写明理由（引用方案条款或下游引用方）
