## 模块定性（不得偏离）
- 模块名称：我的产品库
- **术语铁律**：统一使用「我的产品库」；「产品信息库」是后台平台级标准产品维护面，两者**不得混用**
- 业务归属：前台业务平台 → 我的产品库（方案 §2.2 B2、§2.3 B2-1 / B2-2、§八 P27）
- 模块类型：**组织自建产品的完整主数据**（非轻量配置、非左树右表弹窗）
- 数据归属：**组织自建 `ORG`**（可编辑；方案 §3.3.3）
- **产品来源（已裁定，业务规则必须落实）**：
  - **引用标准产品**：从平台级产品信息库（`PUBLIC`）引用，**只读、不可修改**
  - **复制成新的**：复制标准产品（或已有产品）→ 生成**组织自建产品**（`ORG`），**可编辑调整**
  - **自己新增**：从零新建组织自建产品（`ORG`），可编辑
- 维护形态：列表 + **独立详情页** + **独立新增/编辑页**；支持操作日志（详情页可折叠）
- 状态：**无版本化**；仅有**使用状态（上架 / 下架）**；**无审核流**
- 不适用：审核流、版本化、外部系统推送、单据下推、回写
- **本期后置口径**：角色可见范围 v1.0 §4 将 P27 列为后置（P1），但本文按**完整版**产出，仅在「优先级」列标注后置项，**不得删减功能范围**

## 文档结构（必须包含以下章节）

### 0. 文档基础信息
- 文档属性表（版本 V0.1、状态：草稿）、变更记录
- 关联链接：字段清单（我的产品库 + 产品信息库 + 产品分类）、整体设计方案 v1.2、角色可见范围 v1.0
- 文档分工表（字段清单 / 业务 PRD / Demo PRD 各管什么）

### 1. 需求概述
- 需求背景：我的产品库是**组织自建产品**的维护面 + 核算人员的引用面；与后台「产品信息库」（平台级 `PUBLIC`）按数据归属 `ORG` / `PUBLIC` 分离；**产品无版本化**，调整走「复制成新的」或「自己新增」
- 需求目标（3～5 条可验证目标）
- In Scope / Out of Scope（明确：无审核流、**无版本化**；引用标准产品只读、复制成新的、自己新增三种来源；导入 / 导出 / 删除是否支持必须写清）
- 涉及角色（组织管理员维护组织自建、核算人员引用、审核员只读 —— 对齐角色可见范围 v1.0 §2.3）
- 影响范围（下游：核算项目 P19 / P20、报告）

### 2. 用户与使用场景
每条含：触发条件、操作流程、预期结果
- S01 引用标准产品（从平台级产品信息库引用 → 只读展示，不可修改）
- S02 自己新增产品（基本信息 + 组合工艺与工序）
- S03 复制成新的（复制标准产品 / 已有产品 → 生成可编辑的组织自建产品）
- S04 编辑产品（仅组织自建产品可编辑；引用标准产品无编辑入口）
- S05 上架 / 下架
- S06 被核算项目引用后的表现
- S07 查看产品详情与操作日志

### 3. 功能清单
| 模块 | 功能点 | 功能描述 | 优先级 |

覆盖：列表、查询、新增（引用 / 复制 / 自建）、编辑（仅自建）、查看、上架 / 下架、导入 / 导出（按结论）。**后置项（角色可见范围 v1.0 §4）在优先级列标注，不删除**。

### 4. 产品来源与组合规则（**本文核心章节，已裁定，必须落实**）
- **三种产品来源的语义与规则**：
  - 引用标准产品：只读引用，不可修改；上架 / 下架由后台产品信息库控制，本模块只读展示
  - 复制成新的：复制标准产品（或已有产品）生成组织自建产品，副本可编辑；是否保留「来源产品」追溯标识必须写清
  - 自己新增：从零新建组织自建产品
- 与后台「产品信息库」的**数据归属边界**：组织自建产品（`ORG`）是否同时出现在两处，还是按归属严格分离
- 产品 = 基本信息 + 工艺 + 工序的组合层级与数量约束（对齐产品信息库 §4，但**以字段清单 §1.2 结论为准**）
- 组合校验：至少 1 个工艺、至少 1 个工序？末道工序产出必须为成品？
- 组合变更对已引用产品的影响（项目侧快照，产品侧无需版本化）

### 5. 上架 / 下架规则（R-001 起）
每条含：触发条件、处理逻辑、例外策略。至少覆盖：
- 上架 / 下架直接作用于产品（无版本维度）；引用标准产品的上下架由后台控制（只读）
- 下架后对下游的影响（不可被新项目选择，历史引用保留）
- 被核算项目引用后，产品侧修改是否影响已建项目（对齐方案 §4.9：项目侧快照，产品侧无需锁定，仅提示引用数）
- 删除规则（仅下架未引用可删？）
- 产品被项目引用时的快照原则：项目引用的是「产品 + 引用时点快照」，禁止实时变更污染已建项目

### 6. 状态与操作矩阵
产品来源 × 使用状态 × 可用操作（编辑 / 复制成新的 / 上架 / 下架 / 删除 / 被引用）；**无版本维度，矩阵闭环无死状态**

### 7. 上下游与引用关系
| 方向 | 关联模块 | 引用字段 | 联动规则 |
至少含：平台级产品信息库（引用标准产品的上游来源）、产品分类（上游引用）、计量单位库（单位）、行业库（所属行业）、工艺流程库、工序管理、核算项目 P19 / P20（下游引用快照）、报告

### 8. 待确认事项
Q01 起编号，与字段清单待确认项**交叉引用**，**不得偷换为已确认事实**。至少覆盖：与后台产品信息库的边界、数据归属、上架 / 下架口径、本期后置范围。
