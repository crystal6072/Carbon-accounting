## 模块定性（不得偏离）
- 模块名称：我的工艺库
- **术语铁律**：统一使用「我的工艺库」；「工艺库」（工序管理 A1-8 + 工艺流程 A1-7）是后台平台级标准维护面，两者**不得混用**
- 业务归属：前台业务平台 → 我的工艺库（方案 §2.2 B3、§2.3 B3-1~B3-4、§八 P28）
- 模块类型：**组织自建工艺与工序的完整主数据**（非轻量配置、非左树右表弹窗）
- 核心对象：**两个并列主对象** —— **工艺流程**（= 有序工序集合）+ **工序**（= 工序定义 + 投入产出流）
- 数据归属：**组织自建 `ORG`**（可编辑；方案 §3.3.3）
- **来源（已裁定，业务规则必须落实）**：
  - **引用标准工艺/工序**：从平台级工艺库（`PUBLIC`）引用，**只读、不可修改**
  - **复制成新的**：复制平台级（或已有）工艺/工序 → 生成**组织自建**（`ORG`），**可编辑调整**
  - **自己新增**：从零新建组织自建（`ORG`），可编辑
- 维护形态：列表 + **独立详情页** + **独立新增/编辑页**；支持操作日志（详情页可折叠）
- 状态：**无版本化**；仅有**使用状态**；**无审核流**
- 不适用：审核流、版本化、外部系统推送、单据下推、回写
- **本期后置口径**：角色可见范围 v1.0 §4 将 P28 列为后置（P1），但本文按**完整版**产出，仅在「优先级」列标注后置项，**不得删减功能范围**

### 4. 工艺 / 工序来源与组合规则（**本文核心章节，已裁定，必须落实**）
