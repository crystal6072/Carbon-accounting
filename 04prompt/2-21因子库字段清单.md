### 分歧 1：因子的**表达口径**——「按物理量」还是「按能量」（Q01，**本任务最关键，跨模块阻塞项**）

方案 §4.4 未明确因子的分母口径，而该口径**直接决定能源库是否需要「热值 + 热值单位」**（方案附录二 · 后续动作 5；`04prompt/2-13能源字段清单.md` 已把该项登记为待办，**当前按「不落」处理**）。

```text
口径 A（按物理量）：因子的分母是"实物量" → 如 kgCO₂e/kg（木材）、kgCO₂e/m³（天然气）、kgCO₂e/L（柴油）
                    能源库【不需要】热值；填报时直接用实物量 × 因子
口径 B（按能量）  ：因子的分母是"能量"   → 如 kgCO₂e/MJ（燃料）、kgCO₂e/kWh（电力）
                    能源库【需要】热值 + 热值单位：先 实物量 × 热值 → 能量，再 × 因子
口径 C（并存）    ：同一能源在不同库里两种口径因子都存在，靠"因子单位"区分，引擎按单位自动判路径
```

| 口径 | 结构 | 取舍 |
| :--- | :--- | :--- |
| **A（推荐）** | 因子分母 = 实物量单位（`kg` / `m³` / `L` / `kWh` / `t·km` / `件`…），**分子恒为质量类 CO₂e**。**能源库不落热值** | 与「单位库基准中转」链路最简（1 次换算）；与**省级电网因子**（`kgCO₂e/kWh`，本身即能量口径但电力实物量即 kWh）兼容；**与能源库现状一致**（能源只 6 项、不落热值）；与竞品（南平铝业）实物量填报习惯一致 |
| B | 因子分母 = 能量单位（`MJ` / `kWh`），能源**必须**先热值折算 | 需在能源库补「热值 + 热值单位」，且**同一能源不同批次热值不同**时须在活动数据侧覆盖热值（新增链路与字段）；汽柴油、天然气、生物质燃料均受影响 |
| C | 两套口径并存 | 灵活但**单位一致性判定（E04）与自动匹配复杂度翻倍**；同一能源可能出现两条不同口径因子并列，人工确认负担上升 |

**请给出结论或标【待确认】并写明推荐口径。** 若采纳 B 或 C，必须同时列出：
- 能源库需新增哪些字段（热值 / 热值单位 / 是否允许活动数据覆盖）
- 引擎侧新增的换算步骤（方案 §6.1.1 的 `活动数据 × 排放因子` 公式需否改写）
- 此举对**方案 §4.2.1 / 附录二第二节第 5 项**的回改影响（须在本清单 §9 交叉登记）
