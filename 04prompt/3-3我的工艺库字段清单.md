## 模块定性（不得偏离）
- 模块名称：**我的工艺库**
- **术语铁律**：全文统一使用「我的工艺库」；后台的「工艺库」（=「工序管理」A1-8 + 「工艺流程」A1-7 两个平台级子模块）是**平台级标准维护面**，两者**不得混用**
- 业务归属：前台业务平台 → 我的工艺库（方案 §2.2 功能架构 B3、§2.3 B3-1~B3-4、§八 P28）
- 模块类型：**组织自建工艺与工序的完整主数据维护（带可维护子表）** —— **禁止**按轻量配置 / 左树右表弹窗处理
- 核心对象：**两个并列主对象**（对齐后台工艺库结构，方案 §2.3 B3 原文）：
  - **工艺流程**（组织自建）= 有序的工序集合（B3-1 引用工艺 / B3-2 自定义工艺）
  - **工序**（组织自建）= 工序定义 + 投入产出流（投入项 / 产出项）（B3-3 引用工序 / B3-4 自定义工序）
- 数据归属：**组织自建 `ORG`**（可编辑；方案 §3.3.3 两档可见性 `ORG` / `PUBLIC`）
- **来源（建议对齐「我的产品库」三态，须落实为字段事实）**：
  - **引用标准工艺/工序**：从平台级工艺库（`PUBLIC`）引用，**只读、不可修改**
  - **复制成新的**：复制平台级（或已有）工艺/工序 → 生成**组织自建**（`ORG`），**可编辑调整**（注：B3 原文只写「引用 / 自定义」，本态是否需要由业务裁定，见「必须回答的问题」Q2）
  - **自己新增**：从零新建组织自建（`ORG`），可编辑
- 维护形态：列表 + **独立详情页** + **独立新增/编辑页**；**支持操作日志**（详情页可折叠）
- 状态：**无版本化**（对齐后台「工序不做版本化」「工艺流程去版本化」已确认结论）；仅有**使用状态**。使用状态口径（上架/下架 还是 启用/禁用）**须裁定**，见 Q5
- 适用模板：`07template/04-前端Demo PRD/标准型页面&模块的PRD文档集/字段清单模板.md`

## 已裁定决策（不得偏离，作为字段设计的硬约束）
1. **不要版本化**：工艺流程、工序均**不设**版本号、版本状态、是否当前版本、版本变更说明、生效日期等任何版本字段；对象即单一记录，直接修改
2. **引用标准工艺/工序不可修改**：从平台级工艺库引用的工艺/工序，在「我的工艺库」中**只读**，不提供编辑入口
3. **允许「复制成新的」调整**（若 Q2 裁定保留）：复制平台级（或已有）工艺/工序生成新的**组织自建**对象，副本可编辑调整
4. **允许「自己新增」**：组织管理员从零新建组织自建工艺/工序
5. **投入产出流（工序核心）沿用后台 7 类流口径**：投入项 = 原辅料 / 能源 / 自然资源输入；产出项 = 中间品 / 产品 / 副产品 / 排放物（排放物须标注排放物类别 ∈ 废气 / 废水 / 废渣）；**工序只维护数据项清单 + 单位，不填数量**（数量 = 工序单耗，在核算填报阶段填写）
6. **「模板 + 引用即复制」沿用**：被「我的产品库」引用时**复制**（复制点在产品版本层），副本保留来源模板标识；本模块不因「被引用」而锁定
