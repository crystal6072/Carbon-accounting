## ⚠️ 已确认的字段取舍（不得推翻）

**「数据来源」相关字段已于 2026-09-20 确认精简，本清单必须遵守：**

| 结论 | 说明 |
| :--- | :--- |
| **保留**「数据来源」单一字段 | 取值只有「系统预置 / 组织自建」，**仅用于权限与可见性判定**；可见性由它推导，不单独设字段 |
| **不设**「数据获取方式」 | 实测 / 统计 / 估算 / 供应商 / 数据库 是**活动数据**的属性（方案 §4.6 把它列在「活动数据」章节），**不在物料主数据上预设默认值**。由数据填报（P22）按记录填写 |
| **不采**「引用资源」 | 竞品的资源文件选择器**不采纳**：不参与计算，且会引入对标准文件库（P05，P1）的依赖，与物料库「保持轻量」的定位不符 |
| **不设**「可见性」 | 由「数据来源」推导（与计量单位库口径一致） |
| **不设「默认单位」** | 物料只回答「是什么」，**不绑定单位**。单位在**工序的投入项 / 产出项**中逐行选择（那里本来就有单位字段）。方案 §4.2.1 原列有「默认单位」，**此处为有意偏离，需同步修订方案**。理由：同一物料在不同工序可能用不同单位，在物料上预设默认值反而制造口径不一致 |

> 物料字段目标：**7 项**（物料编码 / 物料名称 / 物料分类 / 适用行业 / 描述 / 数据来源 / 使用状态）。不得再往主对象上加数据来源类字段或单位字段。

- 竞品底部按钮为「**下架**」
- 方案：产品用「上架 / 下架」（A1-6）；分类类模块我们用「启用 / 禁用」

请统一本模块的术语口径。
