## 文档结构（必须包含以下章节）

### 1. 需求概述

- In Scope / Out of Scope（明确：无审核流；**导入 / 导出 / 删除 / 版本管理是否支持必须写清**）

### 4. 投入产出流规则（**本文核心章节**）
- **两张子表的结构与边界（已确认）**：「投入项」承载原料投入 / 能源投入，「产出项」承载中间品 / 成品 / 副产品；两表字段大体一致，但投入侧要选物料或能源、产出侧只选物料，须写清两表的行级约束差异
- 5 类流的定义与使用边界（原料投入 / 能源投入 / 中间品 / 成品 / 副产品）
- 「中间品」的上下游衔接：既是上游工序的产出、又是下游工序的投入，本模块如何表达
- 投入 / 产出两侧的必填约束（如：至少 1 条产出？是否必须有成品或中间品）
- 物料与能源的引用来源（物料库 / 能源库），以及是否允许自定义
- 数量与单位口径：基准数量、单位换算、是否允许 0 / 负数
- **与质量平衡的关系**：本模块记录哪些数据用于 E09 质量平衡校验，换算与含水率如何处理
- 副产品与分配的关系（方案 §4.5 副产品分摊 / 替代法），本模块记录到哪一步为止

### 5. 业务规则（R-001 起）
每条含：触发条件、处理逻辑、例外策略。至少覆盖：
- 工序编码 / 名称唯一性
- 投入产出流的行级约束（行数、重复物料、流类型必填）
- 工序复用规则（一个工序可被多个工艺流程 / 产品引用）
- **引用方式 = 复制（已确认核心口径）**：工序是**模板**，被引用时**复制**一份定义到目标侧；**模板可自由编辑、不受「被引用」约束**，基础库后续调整**不回写**已建副本，因此工序调整不影响已建模型
- **副本的冻结与来源标识**：副本归目标所有、可在目标侧修改，且必须保留「来源模板标识（工序编码 + 复制时点）」以支持追溯（字段清单 D12）
- **复制点已定在产品版本层**（已确认 Q20）：本模块只做模板，复制动作发生在产品信息库引用时；**不做自动同步**（已确认 Q21），副本上仅展示「来源模板已更新」标记
- 禁用规则：禁用后不可被新的工艺流程 / 产品选用，历史引用保留
- 删除规则：被引用的工序不可删除
- 投入产出流修改对下游的影响（已引用工序的工艺/产品是否需要重新校验）
