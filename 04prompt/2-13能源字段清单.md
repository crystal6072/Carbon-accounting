## ⚠️ 必须先给出结论的设计分歧（不得回避）

### 分歧 1：「能源类型」的枚举分层（Q01）

竞品与方案的写法**不一致**，且方案自身的写法有问题：

| 出处 | 内容 |
| :--- | :--- |
| 方案 §2.3 A1-2 | 能源类型（**电、柴油、天然气、蒸汽、热力**等） |
| 竞品界面（能源库） | 能源类型 = **燃料** / **电力** / **热力**，具体品名（柴油、天然气）放在「能源名称」里 |

方案把「类型」和「具体品名」混在了一个枚举里（柴油、天然气都是「燃料」；蒸汽属于「热力」）。**推荐按竞品分层**：

```text
能源类型（枚举，粗粒度）  →  能源名称（具体品名，用户填写）
├── 燃料    →  柴油、天然气、汽油、煤炭
├── 电力    →  外购电力、自发电
└── 热力    →  蒸汽、热水、外购热力
```

请给出结论或标【待确认】并写明推荐口径。

### 分歧 2：「热值 / 折算系数」的建模（Q02）

方案 §4.2.1 明确能源含「**热值或折算系数**」。请回答：

| # | 问题 |
| :--- | :--- |
| 1 | 热值的口径：**低位热值（LHV）还是高位热值（HHV）**？还是同时保留两个字段？ |
| 2 | 折算系数是「能源实物量 → 能量（MJ / kWh）」的系数，还是「能源实物量 → 排放量」的系数？**若为后者，则与排放因子库职责重叠**（方案 §4.4 明确因子归因子库），需划清边界 |
| 3 | 热值是否必填？不同批次热值不同时如何处理（是否允许在活动数据填报时覆盖）？ |
| 4 | 热值是否随区域 / 年度变化（如电网排放因子按区域 + 年度）？ |

### 分歧 3：与物料模块保持一致（**已确认，不得推翻**）

以下内容已于 2026-09-20 确认，**能源必须与物料完全一致**（见 `物料字段清单`）：

| 结论 | 说明 |
| :--- | :--- |
| **保留**「数据来源」单一字段 | 只有「系统预置 / 组织自建」，仅用于权限与可见性判定 |
| **不设**「数据获取方式」 | 实测 / 统计 / 估算 / 供应商 / 数据库 属**活动数据**（方案 §4.6），在 P22 填报时记录 |
| **不采**「引用资源」 | 竞品的资源文件选择器不采纳 |
| **不设**「可见性」 | 由「数据来源」推导 |
| 状态术语 | 用「启用 / 禁用」，与物料、计量单位库、工序一致 |
| **不设「默认单位」** | 能源与物料一致，**不绑定填报单位**；单位由**工序的投入项 / 产出项**逐行选择。方案 §4.2.1 原列有「默认单位」，此处为有意偏离，需同步修订方案 |
| **保留「热值单位」** | 热值是一个**比值**（`44.8 MJ/kg`），没有单位则数值无意义。**「热值单位」≠「默认单位」**：前者是热值的分母（定义域信息），后者是填报语义，二者职责不同，不可互相替代 |

> 能源字段目标：**9 项**（能源编码 / 能源名称 / 能源类型 / 适用行业 / 热值 / 热值单位 / 描述 / 数据来源 / 使用状态）。不得再往主对象上加默认单位或数据来源类字段。

### 分歧 4：与排放因子库的边界（Q04，必答）

方案 §4.4 规定电网类因子「按**区域 + 年度**管理」。请明确：
- 能源库是否需要「适用区域」字段？还是区域与年度**完全归属排放因子库**，能源库只管能源本身的属性？
- **推荐**：能源库不含区域 / 年度；电网因子的区域 + 年度在排放因子库（A2-6）管理，避免两处维护
