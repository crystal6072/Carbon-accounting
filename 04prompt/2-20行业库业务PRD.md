## 模块定性（不得偏离）
- 模块名称：行业库
- 模块类型：**基础数据维护（轻量）**，非业务单据、**无审核流、无版本化**
- 维护形态：列表 + 新增 / 编辑（弹窗或独立页，按字段清单结论）；**列表支持批量启用 / 禁用**
- **核心定位**：行业库是「**通用 → 行业**」的**唯一扩展点**（方案 §4.2.5）。行业本身只作为**配置结果的锚点**存在——木竹 / 钢铁 / 纺织 / 食品均通过「行业库 + 阶段配置 + 因子集 + 规则模板」组合接入，**引擎与数据模型不感知具体行业**（方案 §1.2）
- **设计基调**：对齐竞品（南平铝业「信息库 / 行业库」：仅行业名称 + 描述 + 行业核算指南）的轻量形态，**业务规则总数控制在 8～10 条以内**
- 优先级：方案标 **P2**；但物料 / 能源 / 产品 / 工艺流程 / 工序**均已使用「适用行业」引用本模块**（方案附录二 · 待确认偏离 1 已登记该冲突），**P2 与实际依赖强度不匹配**——本文必须给出该冲突的处理结论
- 不适用：审核流、单据下推、外部系统同步、版本化、快照、核算引擎逻辑
