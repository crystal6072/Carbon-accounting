# 6-1 系统原型骨架（Vite + React + TS）

产品碳足迹核算系统的前端原型骨架。提供可运行的路由、Layout、设计 token、通用组件与 Mock 数据层，供后续按各模块 PRD 逐步填充页面。

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 产物输出 dist/
npm run typecheck  # TypeScript 类型检查
```

## 技术栈

Vite 5 · React 18 · TypeScript · React Router 6 · 原生 CSS + CSS 变量（自研轻量组件，无 UI 框架依赖）。

## 目录结构

```text
src/
├── main.tsx                 # 入口（BrowserRouter + ToastProvider + 全局样式）
├── App.tsx                  # 路由表
├── layouts/                 # BasicLayout / AppHeader / AppSidebar
├── router/menu.ts           # 菜单 + 面包屑唯一数据源
├── pages/                   # 业务页面（dashboard / category / product / PlaceholderPage …）
├── shared/
│   ├── components/          # Button/Input/Select/Table/Modal/Tag/Tree/Pagination/Toast 等
│   ├── styles/              # design-tokens.css + global.css
│   └── utils/tree.ts        # 分类树构建与层级工具
├── mock/                    # data.ts（种子）+ index.ts（async 服务）
└── types/                   # 业务类型定义
```
