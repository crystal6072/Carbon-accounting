# 熊宝科技重竹地板：产品碳足迹核算验证数据包

这是一套用于验证产品碳足迹系统的**真实业务案例复现数据**。案例来自项目内已有的熊宝科技重竹地板核算附件及其业务推演，已做脱敏、单位产品化和字段结构化处理。它适合做录入、单位匹配、生命周期模块、负数流、生物碳、末端处置、分摊留痕和结果复算验证。

数据不构成熊宝科技或必维公司出具的第三方核查声明，也不应直接用于对外发布。因子值保留原案例快照，系统正式上线时应替换为已授权、可追溯的数据库因子，并保存数据库版本、地区、电力属性和有效期。

## 文件

| 文件 | 用途 |
|---|---|
| `product.json` | 产品、功能单位、质量、面积、边界和方法学元数据 |
| `factors.csv` | 排放因子快照；因子单位必须参与单位校验 |
| `activity_data.csv` | 28 条生命周期活动数据和逐行预期结果 |
| `expected_results.csv` | 阶段汇总、边界汇总和归一化结果断言 |
| `verify_case.py` | 不依赖第三方库的复算脚本 |

## 核算口径

- 产品：1860 × 140 × 20 mm 重竹地板。
- 功能单位：1 块；净重 5.53 kg；面积 0.2604 m²。
- 数据期间：2025-01-01 至 2025-12-31。
- 生命周期：A1、A2、A3、A4、A5、B1-B7、C1、C2、C3、C4。
- 结果保留：内部至少 10 位小数，展示 4 位小数。
- 化石/非生物碳行级公式：`activity_amount × fossil_factor`。
- 生物碳净值行级公式：`fossil_emission + activity_amount × biogenic_factor`。
- 运输活动量已经换算为 `t·km`，不得再次除以 1000。
- A1-C4 结果包含 0 值阶段；系统应保留这些阶段并显示为 0，而不是删除。

## 应触发的系统校验

1. 将 `kWh` 活动量绑定 `kgCO₂e/kg` 因子，应阻断并定位到行级单位错误。
2. 因子缺失时，结果不得发布；应显示待匹配因子。
3. 竹粉、边角料和误差调整包含负数，系统应要求流向、原因和凭证，而不是简单拒绝或静默扣减。
4. `误差调整` 属于校准项，必须有 `adjustment_reason`、`evidence_id` 和审批记录。
5. `C4 木材处置`同时存在化石因子和生物碳因子，系统应能分开核算并做生物碳对称性检查。
6. 删除 A2 或 C4 阶段后，系统应提示边界覆盖不完整。
7. 将同一行重复导入，系统应提示重复明细，不能无提示地重复累计。
8. 将活动量单位从 `kg` 改为 `g`，结果应按单位换算更新，而不是把数值当作同一单位。
