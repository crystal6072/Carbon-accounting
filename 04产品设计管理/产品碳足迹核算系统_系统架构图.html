能力支撑层
核算计算引擎
  • 行级 → 阶段汇总 → 全局三层受控公式
  • 公式即算法，未配置时回退默认口径
  • 结果可下钻至「数据·因子·公式·分配」
单位换算引擎
  • 基准中转：值_B = 值_A × 系数_A ÷ 系数_B
  • 数量类不可换算，跨类型不支持
  • 引擎自动计算行级单位换算系数
因子匹配引擎
  • 按「活动类型 + 阶段 + 区域 + 年度」推荐
  • 优先级：组织自建 > 平台预置
  • 匹配结果人工确认并留痕，可替换
分配引擎
  • ISO 14044 层级：避免分配 → 物理 → 经济
  • 共用能源 / 多产品共线 / 副产品替代法
  • 比例合计 = 100%，层级合规校验
数据检测引擎
  • 阻断级 / 提示级两级问题清单
  • E01–E16：因子缺失·单位·质量平衡·周期覆盖
  • 准入校验：报告生成前必须关闭阻断项
版本与快照服务
  • 不可变对象：发布 / 引用后冻结，改动出新版本
  • 模板 + 引用即复制（工序 / 工艺流程）
  • 历史项目永远还原当时的标准
报告生成引擎
  • 章节对齐 GB/T 24067-2024 / ISO 14067
  • 按边界区分模板，草稿与正式版本全量留存
  • 正式版本只读，说明性内容仅草稿可编辑
权限与审计服务
  • 数据域五档：SELF / CURRENT / SUB_TREE / SPECIFIED / ALL
  • 组织过滤在前、创建人过滤在后，行级隔离
  • 操作日志全留痕，租户数据完全隔离
导入导出与任务服务
  • Excel 模板批量导入（≤2000 条）与校验
  • 核算任务异步执行 · 状态查看 · 失败重试
  • 结果明细导出，作为报告数据来源
附件与凭证服务
  • 活动数据凭证上传与关联
  • 附件访问鉴权，租户级存储隔离
  • 数据可追溯：来源 · 凭证 · 核验人 · 核验时间
