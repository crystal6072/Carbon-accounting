## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 产品碳足迹核算（前台业务平台主链） |
| 业务归属 | 前台业务平台 → 产品碳足迹核算 |
| 模块类型 | 业务对象 + 结果载体（非纯主数据、非纯配置） |
| 核心对象 | **核算项目** |
| 核心职责 | 承载一次 PCF 核算：绑定 1 个产品 + 1 种边界 + 1 套核算模型快照，向下产出核算结果与报告 |

### 1.2 对象结构

| 结构 | 对象 | 与主对象关系 | 主键/唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主对象 | 核算项目 | 主对象 | 项目编号（`PCF-YYYYMMDD-NNN`） | 本清单定义范围 |
| 子对象 · 阶段配置 | 项目生命周期阶段 | 1:N | 项目编号 + 阶段编码 | 批次 3 定义（阶段随工艺流程带出，项目内只确认纳入范围） |
| 子对象 · 核算工序 | 项目核算工序 | 1:N | 项目编号 + 工序 id | 批次 3 定义（**引用即复制**，阶段随工艺带出） |
| 子对象 · 活动数据 | 活动数据（投入 / 产出填报 + 分配比例） | 1:N | 项目编号 + 数据行 id | 批次 3 定义（**V0.6 由原批次 4 并入**；**分配比例取代原独立「分配场景」对象**） |
| 子对象 · 检测结果 | 检测任务 / 问题项 | 1:N | 项目编号 + 检测批次 | 批次 5 定义 |
| 子对象 · 核算结果 | 结果版本 / 明细 | 1:N | 项目编号 + 结果版本 | 批次 5 定义 |
| 子对象 · 报告 | 报告版本 | 1:N | 项目编号 + 报告版本 | 批次 6 定义 |
| 关联对象（后置） | 关联项目 / 共享数据集 | N:N | — | P30，本期后置 |

> **关系全景**：核算项目 : 产品版本 = **N:1**（一个产品版本可被多个项目引用）；核算项目 : 核算模型 = **N:1**（项目引用模型并生成快照）；核算项目 : 报告 = **1:N**（全版本留存）。

### 1.3 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | 用户填写 + 系统带出（产品/模型/阶段/核算主体）+ 系统生成（编号/快照/状态） |
| 外部系统数据源 | 否（本期无 ERP 对接） |
| 新增编辑 | 新建支持；编辑按状态与步骤开闭（见《业务 PRD》状态矩阵） |
| 子表 | 按步骤逐步产生（阶段/分配/数据/结果/报告） |
| 导入导出 | 活动数据支持 Excel 导入（批次 4）；核算结果支持导出（批次 5） |
| 状态与执行 | 项目状态机（§5.2 方案）+ 步骤条进度（骨架 §5.2） |
| 关键唯一键 | 项目编号；同一「产品版本 + 边界 + 核算年度 + 核算主体」建议唯一（【待确认】Q04） |
| 历史兼容 | 无历史数据 |

### 1.4 关键数据约束

| 约束ID | 约束 | 影响对象 |
| :--- | :--- | :--- |
| D01 | 项目编号系统生成、全局唯一、**不可修改** | 主对象 |
| D02 | **一项目一边界**：绑定 1 个产品 + 1 种边界；多边界需新建关联项目（后置） | 主对象 |
| D03 | 引用核算模型仅「**启用**」态可选；引用后生成**项目快照**，模型后续变更不影响本项目 | 主对象 |
| D04 | 核算主体组织**由当前登录用户所属组织自动带出**（不由用户填写），项目内数据归属该组织（方案 §3.3.4 规则 1） | 主对象 + 全部子对象 |
| D05 | **进入「检测中」后，①②步骤字段冻结**（需回退才可改） | 主对象 |
| D06 | 项目处于可编辑状态时同一时间仅一个**编辑锁**持有人 | 主对象 |
| D07 | **不设「作废」状态**：取消项目统一走物理删除，记录消失 | 主对象 |

### 6.4 项目活动数据（投入 / 产出填报 + 分配比例）

> **V1.1 口径（Q1 / Q2 / Q3）**：每个数据项**绑定模型公式**（工序公式配置阶段完成，前台只读）；填报字段 = 公式 `activity` 因素（**动态**，如运输 = 运输重量 + 运输距离）；因子 = 公式 `parameter` 因素（**单因子**，手动匹配）；公式 `constant` 因素前台不出现。
>
> **V0.6 新增（P15 / P16 / P17）**：原「分配场景配置」与「数据填报」并入本步骤，活动数据与核算工序在同屏维护。
>
> **以原型为准（2026-09-24）**：① **绑定公式可修改**（下拉改选启用态公式，改选后按新公式重建活动量变量、重置默认因子，原填报值清空）；② **排放来源默认带出公式绑定因子**（如运输因子 → 公路货运 F-301），允许修改；③ 活动量**动态成列**（每个 `activity` 变量一列，列名 = 变量名，而非单一「活动量」列内堆叠）；④ 步骤② 支持**新增工艺流程 / 新增工序（可选所属工艺或所属阶段）/ 删除工序**。
