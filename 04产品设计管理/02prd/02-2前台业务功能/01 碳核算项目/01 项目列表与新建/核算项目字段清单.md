## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 产品碳足迹核算（前台业务平台主链） |
| 业务归属 | 前台业务平台 → 产品碳足迹核算 |
| 模块类型 | 业务对象 + 结果载体（非纯主数据、非纯配置） |
| 核心对象 | **核算项目** |
| 核心职责 | 承载一次 PCF 核算：绑定 1 个产品 + 1 种边界，向下产出核算结果（报告环节已移出，归「报告管理」） |

### 1.2 对象结构

| 结构 | 对象 | 与主对象关系 | 主键/唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主对象 | 核算项目 | 主对象 | 项目编号（`PCF-YYYYMMDD-NNN`） | 本清单定义范围 |
| 子对象 · 阶段配置 | 项目生命周期阶段 | 1:N | 项目编号 + 阶段 id | 步骤①勾选（5 个通用一级 + 二级，按适用边界带出） |
| 子对象 · 阶段数据项 | 项目数据项（产品建模） | 1:N | 项目编号 + 数据行 id | 步骤②维护（V1.2 起取代原「项目核算工序 + 活动数据」） |
| 子对象 · 过程节点 | 上游过程节点（继续追溯） | 1:N | 项目编号 + 节点 id | 步骤②「继续追溯」生成，可递归 |

| 关联对象（后置） | 关联项目 / 共享数据集 | N:N | — | P30，本期后置 |

### 1.3 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | 用户填写 + 系统带出（产品/阶段/核算主体/来源模型）+ 系统生成（编号/状态） |
| 外部系统数据源 | 否（本期无 ERP 对接） |

### 1.4 关键数据约束

| 约束ID | 约束 | 影响对象 |
| :--- | :--- | :--- |
| D01 | 项目编号系统生成、全局唯一、**不可修改** | 主对象 |
| D02 | **一项目一边界**：绑定 1 个产品 + 1 种边界（步骤①可修改，修改后按新边界重新带出阶段）；多边界分别新建项目（关联项目后置） | 主对象 |
| D03 | 核算模型仅**新建时**作为可选来源（平台模型库 / 我的模型库，仅已发布态）；选用后**引用即复制**，模型后续变更不影响本项目 | 主对象 |
| D04 | 核算主体组织**由当前登录用户所属组织自动带出**（表单不展示），项目内数据归属该组织（方案 §3.3.4 规则 1） | 主对象 + 全部子对象 |
| D05 | **「已核算」之前均可编辑**（含检测中 / 待核算 / 核算失败）；「已核算」修改 → 回退「进行中」重走检测 → 核算（E13），或在步骤④「重新计算」生成新版本；**「已完成」同样可编辑**（V1.1 确认完成后不锁定，可编辑 / 重检 / 重核算 / 重算，保存即回退重走）；**回退保留结论**——修改数据保存回退后检测结论与核算结果保留，步骤③默认展示原检测数据，不强制重新检测 | 主对象 |
| D06 | 项目处于可编辑状态时同一时间仅一个**编辑锁**持有人 | 主对象 |
| D07 | **不设「作废」「已归档」状态**：删除**不受状态限制**（二次确认、记录消失） | 主对象 |

## 3. 枚举值（当前批次涉及）

### 3.1 系统边界（核算边界）

> **V1.2 起（以原型为准）**：边界取值来源由固定枚举改为「**平台支撑 · 数据字典 · 系统边界**」字典项编码（仅启用项展示，卡片式单选）。字典预置项如下，后台可扩展（如「大门到大门」）：

| 枚举值（字典编码） | 含义 | 是否默认 | 适用条件 | 备注 |
| :--- | :--- | :---: | :--- | :--- |
| `gate` 摇篮到大门 | 原材料获取 + 生产 | 是 | 全部 | 本期主推 |
| `grave` 摇篮到坟墓 | 增加运输/交付、使用、生命周期末期 | 否 | 全部 | 本期支持但双边界协作为 P30 后置 |
| `gate_to_gate` 大门到大门 | 仅生产阶段 | 否 | 字典预置 | 阶段库按「适用边界」过滤带出 |

### 3.2 产品取得方式

| 枚举值 | 含义 | 是否默认 | 适用条件 | 备注 |
| :--- | :--- | :---: | :--- | :--- |

### 3.3 项目状态

| 枚举值 | 含义 | 是否终态 | 备注 |
| :--- | :--- | :---: | :--- |
| 新建 | 已创建未保存基础信息 | 否 | 骨架「草稿」 |
| 进行中 | 配置与填报阶段 | 否 | 覆盖方案「目标与范围编辑中 / 产品模型创建中」 |
| 检测中 | 检测执行中 | 否 | 含系统异常 |
| 待核算 | 检测通过待核算 | 否 | — |
| 核算中 | 核算执行中 | 否 | — |
| 核算失败 | 核算异常 | 否 | 可重试 |
| 已核算 | 核算完成 | 否 | 结果可查看导出、可重新计算（新版本）；步骤④可「确认完成」 |
