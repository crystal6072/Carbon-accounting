## 二、新建核算项目页（P18）

### 2.1 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 新建核算项目 |
| 页面目标 | 填写项目基础信息，生成项目并进入工作台步骤① |
| 页面路径 | `/pcf/project/new` |
| 骨架结构 | 页头（标题 + 取消/保存并进入）→ 单卡片（**顶部步骤条** + 基本信息表单） |

### 2.2 页头操作区

| 元素 | 规格 |
| :--- | :--- |
| 按钮顺序 | `取消`（Default）→ `保存并进入`（Primary） |
| 取消 | 返回列表 `/pcf/project` |
| 保存并进入 | 校验通过 → 创建项目 → Toast「保存成功」→ 跳转 `/pcf/project/{id}`（工作台步骤①） |

### 2.3 顶部步骤条

| 项目 | 规格 |
| :--- | :--- |
| 位置 | 卡片内顶部（在「基本信息」表单**上方**） |
| 展示 | **6 步**全量展示；当前落在**第①步「目标与范围」**并高亮 |
| 可达性 | 仅第①步可达，②–⑥ 灰显 `disabled` |
| 未交付标注 | 批次 > 1 的步骤尾缀 `待交付` |
| 交互 | **不可点击**（新建页不提供步骤切换） |

### 2.4 表单字段（基本信息）

| 字段 | 控件类型 | 规格 |
| :--- | :--- | :--- |
| 项目名称 | `Input` | 必填；placeholder「如：全竹碳化筷子 240mm·摇篮到大门」；hint「建议包含产品与边界，便于识别」 |
| 核算主体组织 | `ReadonlyText`（`.form-static`） | **只读自动带出**：取当前登录用户所属组织；hint「默认取当前登录用户所属组织，作为数据归属与权限范围」；**不提供选择器** |
| 统计时间 | 两个 `DateInput` | 必填；默认当年自然年；起始 ≤ 结束；hint「原「核算年度 + 核算周期」合并」 |
| 核算边界 | `Select` | 必填；选项「摇篮到大门 / 摇篮到坟墓」；hint「一项目一边界；创建后仍可在步骤① 修改，修改后需重新配置模型与数据」 |
| 引用核算模型 | `Select` | 必填；**默认带出启用中的首个模型**；选项格式 `{模型名称}（{编码} · {边界}）`；仅返回启用态模型；hint「默认已选启用中的模型；引用后生成项目快照，模型后续变更不影响本项目」 |
| 备注 | `Textarea` | 选填；`rows=3`；`maxLength=200`；placeholder「选填，最长 200 字符」 |

**字段联动**

- 核算边界变更 → 若当前模型与该边界不匹配，自动切换到同边界的首个启用模型。
- 进入页面 → 自动带出核算主体组织（只读）。

### 2.5 保存校验

| 动作 | 校验范围 | 失败反馈 |
| :--- | :--- | :--- |
| 保存并进入 | 项目名称 / 核算年度 / 引用核算模型 必填；备注长度 | 控件红框 + 字段下方文案，Toast「请先完善必填项」；服务端错误（如模型不可用、无可用模型）走 Toast |

### 2.6 页面提示

> 卡片底部提示区（`.pcf-form-tip`）：保存后进入「项目工作台」，按**上方步骤**依次完成：目标与范围 → 模型与数据（阶段 / 工序 / 投入产出 / 分配比例）→ 数据检测 → 碳足迹核算 → 核算结果 → 报告。

## 三、项目工作台（承载 P19–P26）

### 3.1 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 项目工作台 |
| 页面路径 | `/pcf/project/{id}`（默认落当前步骤）/ `/pcf/project/{id}/{step}` |
| 骨架结构 | 页头 → 单卡片（项目摘要条 + **顶部步骤条** + 内容区 + 底部状态条） |

### 3.2 项目摘要条

| 区域 | 内容 |
| :--- | :--- |
| 左侧标题行 | 项目编号（等宽）、核算边界 `Tag`、项目状态 `Tag` |
| 左侧元信息 | 产品、核算主体、统计时间、核算模型 |
| 右侧动作 | 步骤① / ② 可编辑时展示 `保存`（Primary）；页头固定展示 `返回列表` |

### 3.3 顶部步骤条

| 项目 | 规格 |
| :--- | :--- |
| 位置 | 摘要条下方、内容区上方，横向铺满 |
| 步骤 | **6 步**（目标与范围 / **模型与数据** / 数据检测 / 碳足迹核算 / 核算结果 / 报告） |
| 完成态 | `seq < 当前查看步骤` → `✓`（绿底圆点）；`= 当前查看步骤` → 高亮（浅绿底 + 蓝字 + 蓝底圆点）；`> 项目进度` → 灰显且 `disabled` |
| 未交付标注 | 批次 > 1 的步骤尾缀 `待交付` |
| 点击行为 | 已到达步骤可切换（切到 `/pcf/project/{id}/{seq}`）；未到达步骤 `disabled`（不渲染可点击态） |

### 3.4 内容区

| 步骤 | 渲染 |
| :--- | :--- |
| ① 目标与范围 | **可编辑**（状态 ∈ 可编辑集合）：项目名称 / 统计时间 / 核算边界 / 核算模型 / 核算方法 / 单位与净重（可编辑）+ 引用产品带出字段（只读）+ 备注；只读态用 `detail-list` 展示全部字段 |
| ② 模型与数据 | **已交付（V0.3 合并批次）**：① 顶部「生命周期阶段」折叠面板（默认收起，三态勾选 + 可选纳入排除原因）；② **左树右表**——左侧「生命周期阶段 → 工艺流程 → 核算工序」树（已填工序带「已填」标记、树头显示 `已填 x/y（待填 n）`），右侧所选工序的**投入项 / 产出项两张表**（数据项名称 · 类别 · **活动量 *（按绑定公式动态：如运输 = 运输重量 + 运输距离，未填标红）** · **排放来源（手动匹配：公式含因子时投入项必选、产出项选填，未匹配标红）**；**多产出工序额外显示「分配比例（%）」列与合计提示**）；支持数据项名称搜索；**活动量未填全或投入项未匹配排放来源时保存被阻断**并提示条数 |
| ③–⑥ | 占位卡片：`该步骤将在批次 N 交付。`（不渲染假入口） |
| ⑥ 报告 | 确认动作为「确认已完成」，**操作人 = 核算人员**（批次 6 交付） |

### 3.5 底部状态条

| 位置 | 内容 |

## 四、通用交互规范

| 项 | 规范 |
| :--- | :--- |
| 必填标识 | 必填字段标签前红色星号 |
| 空值展示 | 统一 `-`，禁止 `null`/`undefined`/空串 |
| 加载态 | 表格 `加载中…`；工作台无数据时展示「加载中…」或「项目不存在或已被删除」 |
| 错误反馈 | 字段下方红字；操作失败 Toast（error） |
| 成功反馈 | Toast 成功提示；关键操作后刷新列表 |
| 危险操作 | 二次确认，确认按钮语义化（**确认删除**），禁止用「确定」 |
| 只读字段 | 使用 `.form-static`（行高与控件一致），不可伪装成可编辑控件 |
| 样式约束 | 一律引用 `design-tokens` 变量，禁止行内色值与近似间距 |
| 数据访问 | 页面只调用 `@/mock` 服务，不直接改动种子数组 |
