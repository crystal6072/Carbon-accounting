## 1. 拟添加的批注清单

### 1.1 整体流程

#### F01-01 核算主链路整体流程
**拟标注位置**：功能标题「产品碳足迹核算」附近（全局说明）｜**标记**：已确认

- **适用场景**：核算人员从零开始完成一次产品碳足迹核算，或查找 / 继续此前的核算记录。
- **流程**：进入核算记录列表 →（首次）点「新增产品模型」选入口创建草稿 → 步骤①填写保存后落库 → 工作台按 4 步推进（①目标与范围 → ②产品建模 → ③数据检测 → ④碳足迹核算与结果）→ ④「确认完成」后项目锁定。
- **分支**：新建有三条入口（自定义核算 / 从平台模型库选择 / 从我的模型库选择）；列表行点击产品名称或「编辑 / 查看」均进入工作台。
- **衔接**：草稿保存后跳转正式项目工作台；步骤条未到达的步骤锁定不可点。
- **结束**：步骤④「确认完成」后项目流转「已完成」并锁定（结果仍可查看与下载清册）；或任意状态删除记录。

### 1.2 全局规则说明

#### F01-02 全局规则
**拟标注位置**：功能标题「产品碳足迹核算」附近（与整体流程同一全局说明入口）｜**标记**：已确认

1. **扁平一层列表**：一行 = 一条核算记录；同一产品可按不同核算边界 / 统计时间建多条记录，不再按产品分组。
2. **草稿不落库**：新建走草稿路由（仅内存），步骤①点「保存」才创建核算项目（生成编号 `PCF-YYYYMMDD-NNN`）并跳转正式项目；未保存返回列表等同取消，不产生记录。
3. **删除不受状态限制**：任意状态（含检测中 / 已核算 / 已完成）均可删除，二次确认、不可恢复；本项目不设「作废 / 归档」。
4. **编辑约束**：「已核算」之前（含检测中 / 待核算 / 核算失败）步骤①②均可编辑，保存即回退重走检测 → 核算；**「已完成」同样可编辑**（V1.1 确认完成后不锁定，保存即回退重算）；仅「核算中」只读。
5. **不跳步**：步骤条中超过项目当前进度的节点锁定不可点，仅允许回到已到达步骤。
6. **概念不外露**：列表与工作台不展示公式、绑定、异常编号、快照术语。
7. **状态文案**：新建 / 进行中 / 检测中 / 待核算 / 核算中 / 核算失败 / 已核算 / 已完成。

### 1.3 业务状态说明

#### F01-03 项目状态（完成状态列 / 摘要条状态 Tag）
**拟标注位置**：列表「完成状态」列、工作台摘要条状态 Tag｜**标记**：已确认

- **含义与流转**：新建（草稿）→ 进行中（步骤①保存落库）→ 检测中（提交检测）→ 待核算（检测通过）/ 回进行中（检测不通过）→ 核算中（开始核算）→ 已核算（核算完成）/ 核算失败（异常，可重新核算）→ 已完成（步骤④「确认完成」）。
- **可进行的操作**：任意状态可「进入工作台」「删除」；「已核算」前可编辑步骤①②；「已核算」可重新计算、可确认完成；**「已完成」结果不锁定（V1.1）**：仍可编辑 / 重新检测 / 重新核算 / 重新计算。
- **状态变化**：「已核算 / 已完成」修改步骤①②数据 → 回退「进行中」重走检测 → 核算（**检测界面默认展示原检测数据，不强制重新检测**）。

### 1.4 操作功能及对应业务规则

#### F01-04 核算记录列表
**拟标注位置**：列表表格区域与工具条｜**标记**：已确认

- **展示内容**：产品名称（链接，展示「名称｜规格」）、核算编号、系统边界、时间边界（起 ~ 止）、完成状态（Tag）、更新时间、操作。
- **展示规则**：每页 20 条；默认按更新时间倒序；工具条左侧「共 N 条核算记录」+ 提示「默认按更新时间倒序」。
- **操作列**：「编辑」（可编辑状态）或「查看」（只读状态）+「删除」。
- **空状态**：「暂无核算记录，点击右上角『新增产品模型』开始」。

#### F01-05 查询与重置
**拟标注位置**：列表上方查询区｜**标记**：已确认

- **查询项**：① 产品名称 —— 模糊匹配（同时匹配产品名称与产品编码）；② 更新时间 —— 起止日期区间（按日期比较）。
- **规则**：输入条件后点「查询」才生效；「重置」清空全部条件并恢复完整清单；条件变化后回到第 1 页。

#### F01-06 新增产品模型（下拉菜单）
**拟标注位置**：列表右上「新增产品模型」按钮及下拉浮层｜**标记**：已确认

- **操作目的**：创建新的核算草稿。
- **入口**：列表页头右侧主按钮「新增产品模型」下拉，三项——**自定义核算**（从零开始，自行录入目标与范围与产品建模）/ **从平台模型库选择**（引用平台已发布模型，快速带入阶段与数据项）/ **从我的模型库选择**（引用本组织「我的模型」，带入后可继续编辑）。
- **操作过程**：自定义核算 → 直接进入空白草稿工作台（步骤①）；选模型库 → 打开选模型弹窗（F01-07）。
- **结果**：进入草稿工作台（仅步骤①可编辑），保存后落库。

#### F01-07 选模型弹窗（平台模型库 / 我的模型库）
**拟标注位置**：选模型大弹窗｜**标记**：已确认（Tab 默认值来源为原型已表现·待核对）

- **操作目的**：从模型库选用一个模型，按「引用即复制」带入目标与范围与产品建模内容。
- **弹窗结构**：顶部 Tab「平台模型库 / 我的模型库」+ 搜索条件（模型名称 / 核算标准 / 产品分类 / 适用行业，支持「搜索 / 重置」与展开收起）+ 3 列卡片网格。
- **卡片操作**：「预览」（跳模型详情页）与「选用」；未选模型点「确认」→ toast「请先选择一个模型」。
- **结果**：确认后关闭弹窗并进入草稿工作台（路由 `/pcf/project/new/model/:modelId`），模型的目标与范围带入步骤①；产品建模内容在步骤①保存落库后复制进项目。
- **原型表现（待核对）**：Tab 初始值由下拉菜单项决定（从平台进入默认「平台模型库」）；模型卡片过滤条件的具体匹配口径以模型库页面为准。

#### F01-08 删除核算记录
**拟标注位置**：列表操作列「删除」、确认弹窗｜**标记**：已确认

- **显示条件**：任意状态均显示（删除不受状态限制）。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认删除」，正文「删除后不可恢复（核算记录消失）；已完成的记录同样可删除，且删除后不可找回。确认删除『{产品名称｜规格}』？」；底栏「取消」与「确认删除」。
- **结果**：确认后记录消失，toast「删除成功」，列表刷新；删除不可恢复。

#### F01-09 项目工作台（壳）
**拟标注位置**：工作台页面（摘要条 + 步骤条 + 内容区 + 底部状态条）｜**标记**：已确认

- **页头**：面包屑（前台业务平台 / 产品碳足迹 / 产品碳足迹核算 / 末级 = 正式项目编号或草稿产品名）+ 标题（产品「名称｜规格」，草稿为空时显示占位）+「返回」按钮（统一回核算列表；草稿未保存返回等同取消）。
- **摘要条**：编号（草稿显示「保存后生成编号」）+ 系统边界 Tag + 项目状态 Tag + 产品 + 统计时间 +（选用模型时）引用模型；右侧「保存」按钮**仅在步骤①②可编辑时展示**。
- **步骤条**：顶部横向 4 步（①目标与范围 / ②产品建模 / ③数据检测 / ④碳足迹核算与结果）；已完成显示 ✓、当前步高亮、超过项目进度的步骤锁定不可点。
- **底部状态条**：左侧「数据变更后需重新检测并核算，系统将保留历史结果版本」+ 右侧「最后更新：X」。
- **草稿态**：固定停留在步骤①，步骤条不可切换；保存后跳转正式项目（`replace`）。

#### F01-10 保存（摘要条）
**拟标注位置**：工作台摘要条右侧「保存」｜**标记**：已确认

- **显示条件**：项目可编辑（草稿态或状态 ∈ new / ongoing / checking / toCalc / calcFailed / calculated / **done**）且当前在步骤①或②。
- **操作过程**：点击后执行当前步骤的保存（步骤① = 校验并落库 / 步骤② = 校验并保存数据项）。
- **结果**：草稿态保存 → 创建项目（生成编号）、toast「保存成功，核算项目已创建」并跳转正式项目；正式项目保存 → toast「保存成功」；回改数据保存 → 项目回退「进行中」并需重走检测 → 核算（**检测界面默认展示原检测数据，不强制重新检测**）。

### 1.5 字段说明

#### F01-11 列表与摘要字段
**拟标注位置**：列表各列、工作台摘要条｜**标记**：已确认

- **产品名称**：被核算产品名称，列表展示「名称｜规格」；查询按名称 / 编码模糊匹配。
- **核算编号**：系统生成 `PCF-YYYYMMDD-NNN`，全局唯一、不可修改；草稿态未生成（显示「保存后生成编号」）。
- **系统边界 / 时间边界**：分别展示边界名称与统计时间起止。
- **完成状态**：项目当前状态 Tag（F01-03）。
- **更新时间**：最近一次变更时间；列表默认排序依据与查询条件。
- **引用模型**：选用模型新建时展示来源模型名称（追溯用，自定义新建为空）。
