## 1. 对象说明

报告环节涉及四个对象，均为**项目内派生对象**（报告与封面信息由系统生成后人工补充，模板为引用，章节为报告正文结构）：

```text
报告（PcfReport） 1 ─── 1 报告封面信息（ReportCover）
报告（PcfReport） N ─── 1 报告模板（ReportTemplate，引用）
报告（PcfReport） 1 ─── N 报告章节（ReportSection）
```

- **报告（PcfReport）**：步骤⑤ 产出物，归属项目、按边界生成，**单一当前版本**（重新生成覆盖）。
- **报告封面信息（ReportCover）**：报告的封面 / 基本信息，含企业信息 + 产品信息，区分「系统带出（只读）」与「手工补充（可编辑）」。
- **报告模板（ReportTemplate）**：报告版式与章节结构的来源，**引用对象**；本期系统预置 1 个，后台配置后置。
- **报告章节（ReportSection）**：报告正文结构，每章标注「系统生成（只读）」或「说明性内容（可编辑）」。

> **概念不外露（骨架 D06 / S-007）**：报告页只呈现人话内容与结论，不展示公式 DSL、因子绑定、计算引擎、快照、异常编号。

## 4. 报告模板引用（ReportTemplate）

> 本期报告模板**由系统预置**（后台报告模板配置功能未交付）；前台为**引用**，不维护模板内容。

| 字段 | 类型 | 来源 | 必填 | 说明 |
| :--- | :--- | :--- | :---: | :--- |
| `templateId` | string | 后台 | 是 | 模板唯一标识 |
| `templateName` | string | 后台 | 是 | 模板名称 |
| `applicableBoundary` | enum `ReportType \| all` | 后台 | 是 | 适用边界（摇篮到大门 / 摇篮到坟墓 / 通用） |
| `templateVersion` | string | 后台 | 是 | 模板版本 |
| `isPreset` | boolean | 后台 | 是 | 是否系统预置（本期为 `true`） |
| `status` | enum `启用 \| 停用` | 后台 | 是 | 模板启用状态；停用模板不出现在选择中 |

> **本期口径 ③**：仅系统预置 **1 个**模板（`applicableBoundary = all`），前台默认带出、无多模板选择场景；结构上保留模板选择控件，支持后续后台配置多模板后按边界过滤。

## 5. 报告章节（ReportSection）

> 报告正文结构，按边界（gate / grave）由模板决定章节集合；每章标注类型：`system`（系统生成，只读）或 `editable`（说明性内容，草稿阶段可编辑）。

| 字段 | 类型 | 来源 | 必填 | 说明 |
| :--- | :--- | :--- | :---: | :--- |
| `id` | string | 系统 | 是 | 章节唯一标识 |
| `reportId` | string | 系统 | 是 | 所属报告 id |
| `sectionCode` | string | 系统 | 是 | 章节编码（如 `S01`） |
| `sectionTitle` | string | 系统 / 模板 | 是 | 章节标题 |
| `sectionType` | enum `SectionType` | 系统 / 模板 | 是 | 章节类型（见 §6.3） |
| `content` | string（富文本） | 系统 / 人工 | 条件 | 章节内容；`system` 由系统填充（只读），`editable` 由用户编辑 |
| `order` | number | 系统 | 是 | 章节排序 |

**章节清单（对齐《报告模板定义（系统预置V1）》，GB/T 24067 口径）**

| # | 章节 | 子节 | 类型（默认） | 数据来源 |
| :-: | :--- | :--- | :--- | :--- |
| 0 | 封面 | — | editable（字段见 §3.1） | 项目 / 产品带出 + 手工补充 |
| 一 | 概况 | 1.生产者信息 / 2.产品信息 / 3.量化方法 | editable + system | 手工补充（§3.2 / §3.3）+ 项目（依据标准 GB/T 24067） |
| 二 | 量化目的 | — | editable | 手工补充（默认文案可改） |
| 三 | 量化范围 | 1.功能单位或声明单位 / 2.系统边界 / 3.取舍准则 / 4.时间范围 | system + editable | 项目「单位」「核算边界」「统计时间」+ 固定文案 |
| 四 | 清单分析 | 1.数据来源说明 / 2.分配原则与程序 / 3.清单结果及计算（表 1）/ 4.数据质量评价 | system + editable | 核算结果明细 + 多产出分配比例 + 手工补充 |
| 五 | 影响评价 | 1.影响类型和特征化因子选择 / 2.产品碳足迹结果计算（**含生物碳 / 不含生物碳双口径**） | system | IPCC AR6 GWP100 + 核算结果（`unitEmission` / `fossilEmission`） |
| 六 | 结果解释 | 1.结果说明（表 2 + 图 2，**双口径**） | system + editable | 核算结果（阶段汇总 / 占比，含双口径） |

> 章节集合由**系统预置模板固定**（本期仅 1 个模板，`applicableBoundary = all`）；`system` 章节内容随核算结果生成、**不可编辑**；`editable` 章节仅**报告编制中**可编辑，确认完成后全部只读。表 1 / 表 2 / 图 2 的列定义与数据映射见《报告模板定义（系统预置V1）》§5。
>
> **口径披露（V0.3 · 多口径）**：核算结果已支持「多口径」（含生物碳 / 不含生物碳）。报告**按结果实际口径披露**——五、影响评价与六、结果解释（表 1 / 表 2）**同时给出双口径**；仅含生物碳的项目展示双口径与生物碳净额，不含生物碳的项目两口径相等、按单一口径呈现（字段见《碳足迹核算字段清单》§1.2 / §3）。

## 6. 枚举

### 6.1 报告状态（ReportStatus）

| 值 | 界面文案 | 说明 | 是否终态 |
| :--- | :--- | :--- | :---: |
| `reportGenerating` | 报告生成中 | 报告生成执行中（含生成失败） | 否 |
| `reportEditing` | 报告编制中 | 报告已生成，草稿编辑中 | 否 |
| `done` | 已完成 | 报告确认完成 | **是** |

> **不设「已归档」**（本版口径 ⑥）：报告终态为「已完成」，不提供归档动作与「已归档」状态；项目状态同步由 11 个收敛为 **10 个**（删除 `archived`）。

### 6.2 报告类型（ReportType）

| 值 | 界面文案 | 说明 |
| :--- | :--- | :--- |
| `gate` | 摇篮到大门 | 取项目「核算边界」 |
| `grave` | 摇篮到坟墓 | 取项目「核算边界」 |

### 6.3 章节类型（SectionType）

| 值 | 界面文案 | 说明 |
| :--- | :--- | :--- |
| `system` | 系统生成 | 由核算结果 / 项目信息填充，只读 |
| `editable` | 说明性内容 | 用户可编辑（仅报告编制中） |

### 6.4 封面字段来源（CoverFieldSource）

| 值 | 含义 | 界面表现 |
| :--- | :--- | :--- |
| `system` | 项目 / 产品带出 | 只读展示，无编辑入口 |
| `manual` | 手工补充 | 可编辑输入 |
