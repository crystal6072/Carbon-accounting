## 二、区域与控件规格

### 2.1 报告生成区

| 项目 | 规格 |
| :--- | :--- |
| 位置 | 内容区顶部 |
| 控件 | 模板下拉 `Select`（默认选中系统预置模板）+ 生成按钮 |
| 模板选项 | 本期仅 1 项「产品碳足迹报告（通用模板）」（`applicableBoundary = all`）；停用模板不展示；报告已生成后下拉锁定 |
| 生成按钮 | 未生成时文案「生成报告」（Primary）；报告已生成后该按钮不渲染，改由「报告文件卡」的「重新生成」承担 |
| 状态表达 | 生成中：按钮禁用 + 文案「报告生成中…」+ 提示「正在按模板装配报告…」；只读态（已完成）：生成区整体不渲染 |

> **红线**：不可用动作直接不渲染（不展示 disabled 假入口）；「重新生成」一律二次确认（覆盖当前报告内容，R-059）。

### 2.2 报告提示条

| 项目 | 规格 |
| :--- | :--- |
| 位置 | 生成区下方（浅色提示条） |
| 内容 | 报告按模板自动填入核算结果，正文以文件形式承载、在 Word 预览控件中查看；企业信息 / 产品信息与说明性章节可在此补充、编辑后保存；报告确认完成后不可修改 |
| 样式 | 复用 `.pcf-form-tip` |

### 2.3 封面与概况信息区

| 项目 | 规格 |
| :--- | :--- |
| 容器 | 面板（复用 `.pcf-panel`），分组：封面 / 生产者信息 / 产品信息 |
| 只读字段 | 产品名称、产品规格、生产者名称、报告编号（带出 / 生成，只读展示） |
| 可编辑字段 | 报告日期（DatePicker，必填）、出具报告机构（输入框，选填） |
| 生产者信息 | 地址 / 法定代表人 / 授权人（联系人）/ 联系电话（输入框）、企业概况（多行 `Textarea`） |
| 产品信息 | 产品功能 / 产品介绍（输入框 / 多行）、产品图片（选择文件，本期**不做上传**，字段保留） |
| 编辑边界 | 仅「报告编制中」可编辑；「已完成」全部只读（无输入框） |

### 2.4 报告文件卡（正文承载）

| 项目 | 规格 |
| :--- | :--- |
| 位置 | 提示条下方（报告已生成时渲染） |
| 元素 | 文件图标 + 文件名（`{产品名称}_产品碳足迹报告_{YYYYMMDD}.doc`）+ 元信息（报告编号 / 模板与版本 / 生成时间 / 状态）+ 动作（查看报告 / 下载报告 / 重新生成） |
| 状态表达 | 报告编制中（Warning）/ 报告生成中（Info）/ 已完成（Success） |
| 查看报告 | Primary；先落库再打开 Word 预览控件（2.7） |
| 重新生成 | 仅「报告编制中」渲染；二次确认后覆盖（R-059） |
| 正文位置 | 报告正文（六章 + 表 1 / 表 2 / 图 2 占位）**不在页面上平铺**，只在 Word 预览控件内按 A4 分页呈现 |

> **红线**：页面主体不渲染报告正文，避免「编辑表单 + 长文档」双份内容重复；正文口径统一由预览控件承载。
> **系统章节归属**：量化方法 / 功能单位 / 系统边界 / 时间范围 / 分配原则 / 表 1 / 表 2 / 图 2 / 结果值等 `system` 内容随核算结果自动填充，页面与控件内均**不可编辑**。

### 2.5 说明性章节内容区（表单式编辑）

| 章节 | 控件 | 默认文案 |
| :--- | :--- | :--- |
| 二、量化目的 | 多行 `Textarea` | 绩效追踪 / 供应链披露 / 优化潜力识别 |
| 三、量化范围 3. 取舍准则 | 多行 `Textarea` | 1% / 5% / 80% 三条规则（见模板定义 §3.4.1） |
| 四、清单分析 1. 数据来源说明 | 多行 `Textarea` | 初级数据 / 次级数据说明 |
| 四、清单分析 4. 数据质量评价 | 多行 `Textarea` | 来源 / 完整性 / 代表性 / 准确性 |
| 六、结果解释 1. 结果说明（补充部分） | 多行 `Textarea` | 空（句式部分自动生成、只读） |

> - 仅「报告编制中」渲染本区；「已完成」全只读、不再提供编辑入口（内容在预览控件中查看）。
> - 说明性章节默认带出模板文案（视为非空）；用户未编辑也可直接确认完成（R-063 / Q7）。
> - 编辑区为**表单式**（章节标题 + 文本域），不复刻文档版式；文档版式只在预览控件中呈现。

### 2.6 动作区

| 元素 | 规格 |
| :--- | :--- |
| 查看报告 | Primary；先保存再打开 Word 预览控件（2.7）；报告未生成时不渲染 |
| 下载报告 | Secondary；点击导出 doc；报告未生成时不渲染 |
| 保存 | Secondary；仅「报告编制中」渲染；提交封面 / 概况信息与说明性章节 |
| 确认完成 | Secondary；仅「报告编制中」且操作人为**核算人员**时渲染；点击二次确认（Confirm 弹窗） |

### 2.7 Word 预览控件（查看报告）

| 项目 | 规格 |
| :--- | :--- |
| 形态 | 全屏遮罩 + 最大化弹窗（宽 1120 / 高 88vh），内部灰底 + 多张 A4 纸张纵向滚动 |
| 工具条 | 文件图标 + 文件名 +「Word 预览（原型模拟）」标；页码「第 x / N 页」；缩放（− / 百分比 / ＋，60% ~ 160%）；适应宽度；在 Word 中打开；下载；关闭 |
| 分页 | 第 1 页 封面 + 一、概况；第 2 页 二、量化目的 + 三、量化范围；第 3 页 四、清单分析（表 1）；第 4 页 五、影响评价 + 六、结果解释（表 2 + 图 2 占位）；每页页脚「第 x 页 / 共 N 页」 |

### 2.8 状态与只读表达

| 报告状态 | 页面表现 |
| :--- | :--- |
| 未生成（已核算） | 生成区可操作（模板 + 「生成报告」）；报告区空态占位「尚未生成报告…」；动作区不渲染 |
| 报告生成中 | 生成区展示「报告生成中…」+ 装配提示；报告区 loading 占位；动作区不渲染 |

| 已完成 | 生成区不渲染；报告文件卡与封面概况全只读（状态 Success）；说明性章节区不渲染；动作区仅查看 / 下载 |

## 三、交互流程

```text
已核算 → 进入步骤⑤
  ① 默认带出模板（本期 1 个）→ 点击「生成报告」
  ② 项目置「报告生成中」→ 报告区 loading（约 1.2s）
  ③ 生成成功 → 「报告编制中」：生成报告文件（编号 PCF-R-YYYYMMDDNNN），封面 / 概况带出、正文六章装配
  ④ 用户补充封面 / 概况信息 + 编辑说明性章节 → 点「保存」
  ⑤ 查看报告（Word 预览控件 · 分页只读）/ 下载（doc）
  ⑥ 确认完成（核算人员）→ 二次确认 → 校验通过 → 「已完成」+ 报告锁定
```

| 交互 | 行为 |
| :--- | :--- |
| 切换模板 | 报告已生成后模板下拉锁定（本期仅 1 个模板）；切换模板需「重新生成」并二次确认后覆盖 |
| 重新生成 | 报告文件卡内按钮 → 二次确认 → 覆盖报告；保留的项目 / 产品带出字段不变 |
| 编辑概况 / 说明性章节 | 本地暂存，点「保存」落库；查看 / 下载 / 确认前自动保存 |
| 查看报告 | 自动保存 → 打开 Word 预览控件（分 4 页，可缩放、翻页页码联动） |
| 确认完成 | 校验封面必填（报告日期）+ 说明性章节非空 → 通过后置「已完成」 |

## 四、校验与错误展示

| 检查 | 触发时机 | 失败反馈 |
| :--- | :--- | :--- |
| 报告日期未填 | 保存 / 查看 / 下载 / 确认完成 | 阻断 + 定位到封面「报告日期」，Toast：「请填写报告日期」 |
| 说明性章节为空 | 确认完成 | 阻断 + 定位到对应章节，Toast：「请完善<章节名>内容」 |
| 未核算即生成 | 生成报告 | Toast：「请先完成核算」 |
| 存在未处置阻断项 | 生成报告 | 允许生成但标注「待处置」，确认完成不可用，Toast：「存在未处置问题，暂不可确认完成」 |
| 无可用模板 | 生成报告 | Toast：「暂无可用报告模板」 |
| 生成失败 | 生成报告 | 提示「报告生成失败」+「重新生成」入口 |
| 项目不存在 | 加载报告 | Toast：「项目不存在或已被删除」 |

> 校验策略：**报告装配由服务端（mock）执行**，前端仅渲染返回的报告结构；状态不允许时 mock 抛错，前端 Toast 兜底。
