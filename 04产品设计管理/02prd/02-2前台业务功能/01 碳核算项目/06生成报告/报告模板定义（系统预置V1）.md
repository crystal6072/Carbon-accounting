# 产品碳足迹报告模板定义（系统预置 V1）

> **文档定位**：定义工作台步骤⑤「报告」本期**唯一系统预置模板**的章节结构、变量占位符、数据来源与图表规则；是《报告生成业务PRD》报告生成规则、《报告生成_Demo》报告编辑区与 `ProjectStepFive.tsx` 的**模板依据**。
> **来源**：依据业务提供的《碳足迹核算报告模板.docx》（**GB/T 24067《温室气体 产品碳足迹 量化要求和指南》** 口径）转换并变量化。
> **口径**：本期仅 1 个模板（`applicableBoundary = all`）；后台报告模板配置功能本期未交付，后续以此结构字段化（见 §7）。

> **类型**：`system` = 系统生成（只读）；`editable` = 说明性内容（报告编制中可编辑）。
> **内容来源**：`项目` / `产品` / `核算结果` / `手工补充` / `固定文案`。

| 元素 | 类型 | 内容来源 | 占位符 |
| :--- | :--- | :--- | :--- |

| 章节 | 类型 | 内容来源 | 占位符 |

**§3.4.1 取舍准则默认文案**

- 依据 GB/T 24067 中 6.3.5.3；
- 舍弃对产品碳足迹影响 **< 1%** 的单个环节；
- 所有舍弃环节的总影响 **≤ 产品碳足迹总量的 5%**；
- 对碳排放贡献显著（**贡献度 ≥ 80%**）的单元过程均纳入核算范围，未进行舍弃。

> 原文条款编号有笔误（出现两个「3、」），此处已按语义规范化。

## 5. 表格与图表规则

### 5.1 表 1 —— 生命周期碳排放清单

| 列 | 数据来源 | 说明 |
| :--- | :--- | :--- |
| 工序 | 核算结果明细 `opName` | 如 P01 / P02 |
| 阶段 | 核算结果明细 `stage` | 生命周期阶段 |
| 投入 / 产出 | 核算结果明细 `direction` | 投入 / 产出 |
| 名称 | 核算结果明细 `flowName` | 数据项名称 |
| 数量 | 活动量 | 合计行留空 |
| 单位 | 活动量单位 | |
| 排放因子 | 因子名称 / 值 | 产出无因子时显「—」 |
| 排放量 kgCO₂e | 明细排放量 | 中间产品行显「不重复计算」；合计行汇总 |

### 5.2 表 2 —— 生命周期各阶段碳排放情况

| 列 | 数据来源 |
| :--- | :--- |
| 生命周期阶段 | 核算结果阶段汇总 `stage` |
| 碳足迹 /（声明单位） | 阶段汇总 `emission` |
| 百分比 /% | 阶段汇总 `ratio` |
| 总计行 | 总排放 + 100% |

> **单位口径（已确认）**：表 2 与结果值的展示单位**取项目实际计算单位**（项目「单位」），**不做强制 t↔kg 换算**；原模板示例中的 `tCO₂e` 仅示例，实际按项目单位表达。

### 5.3 图 2 —— 各阶段碳排放分布图

- 图形：饼图或柱形图（模板说明「一般以饼状图或柱形图表示」）；
- 数据：阶段汇总占比；
- 原型实现：**本期先占位**（渲染占位区并标注「图 2 各阶段碳排放分布图」），真实图表后置（已确认）。
