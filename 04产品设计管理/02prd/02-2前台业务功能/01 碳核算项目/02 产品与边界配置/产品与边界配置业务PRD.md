## 1. 需求概述

### 1.1 需求背景

步骤①「目标与范围」是核算项目从「建了个空壳」到「知道算谁、算到什么口径」的转折点：

```text
列表「新增产品模型」（自定义核算 / 从平台模型库选择 / 从我的模型库选择）
        ↓ 草稿（不落库，仅步骤①可编辑）
步骤① 目标与范围（统计时间 / 核算标准 / 产品 / 声明单位 / 产品图片 + 系统边界 / 生命周期阶段）   ← 本文
        ↓ 「保存」（草稿态即落库：生成编号、创建项目）
步骤② 产品建模（阶段数据项 + 引用因子 / 继续追溯）—— 需要阶段与边界才能挂数据项
```

**没有产品与声明单位，后续所有数据都无处挂载**：阶段数据项按「生命周期阶段」组织，核算结果按「声明单位」表达。

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :-: | :--- | :--- |
| G1 | **产品可引用可录入** | 支持从「我的产品库」引用（仅上架），也支持步骤①直接录入产品名称（不写回产品库） |
| G2 | **引用即快照** | 引用产品后，产品库后续变更不影响本项目已带出的名称/规格/分类/行业/单位/图片 |
| G3 | **声明单位口径唯一** | 声明单位 = 数值 + 单位；单位默认取产品「单位」，允许项目级覆盖（数值 + 单位），覆盖**不写回产品库**；结果表达只用声明单位 |
| G4 | ~~净重必填实测~~ | **已作废（V1.2）**：净重 / 净重单位字段已删除（无下游计算） |
| G5 | **边界可修改** | 系统边界卡片单选（数据字典取值），可随时切换；切换后按新边界重新带出生命周期阶段（一项目一边界不变） |
| G6 | **周期可覆盖核算** | 统计时间必填（起 ≤ 止）；活动数据期间须覆盖统计时间（E14，步骤③检测执行校验） |

### 1.3 范围（In Scope / Out of Scope）

**In Scope**

| # | 范围 |
| :-: | :--- |

| 6 | 编辑态与只读态切换（受项目状态约束） |

**Out of Scope**

| 不做项 | 归属 / 原因 |

## 2. 用户与使用场景

| 场景ID | 场景 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| S01 | 草稿填写并保存落库 | **主流程** | 从「新增产品模型」进入草稿（仅步骤①可编辑）→ 填写两面板 → 摘要条「保存」→ 创建项目（生成编号）并跳转正式项目工作台 |

| S06 | 重新选择引用产品 | 辅助 | 已引用产品后在弹窗改选另一产品 → 二次确认「重新选择产品将覆盖已有带出信息…」→ 覆盖带出 |

| S08 | 步骤①只读查看 | 辅助 | 项目处于「核算中 / 已完成」（及历史报告态）时步骤①整体只读（分组面板 + 纯文本） |

## 4. 核心业务规则

> 编号承接批次 1《核算项目业务 PRD》§7（R-001 ~ R-019），本模块从 **R-020** 起（原 R-014 ~ R-024 已按原型现行口径改写并重新编号，旧编号映射见 §9.2）。

| 规则ID | 规则 | 依据 |
| :--- | :--- | :--- |
| R-020 | **[产品取得方式]** 产品名称可**自行录入**（不写回任何产品库），或点「引用产品」从「**我的产品库**」弹窗选择（自己新增 / 引用平台产品，**仅返回「上架」产品**）；已引用的产品被下架 → 项目内标记「已下架」但快照继续可用 | 以原型为准（2026-10-14） |
| R-021 | **[引用即快照]** 选定引用产品后，带出的名称 / 规格 / 分类 / 所属行业 / 单位 / 产品图片在项目内**冻结为快照**；产品库后续编辑或下架**不影响本项目**；如需采用新产品数据，走「重新选择产品」（R-023）并重走检测 → 核算（E13） | 方案 §4.9 |
| R-022 | **[声明单位口径]** 声明/功能单位 = **数值（文本框录入）+ 单位（级联，取值来自计量单位库）**，均必填；单位默认取产品「单位」；**允许项目级覆盖**；**覆盖不写回产品库**；结果表达用声明单位（如 `kgCO₂e / 双`） | 以原型为准（2026-10-14） |
| R-023 | **[重新选择产品]** 已引用产品后在弹窗改选其他产品 → 二次确认「**重新选择产品将覆盖已有带出信息，且已配置的核算工序可能失效，确认？**」→ 确认后覆盖带出字段组，并按当前边界重新带出生命周期阶段 | 以原型为准（原型二次确认弹窗） |
| R-024 | **[核算边界可修改]** 系统边界在步骤①以**卡片单选**切换（取值来自「数据字典 · 系统边界」**启用项**，卡片展示名称 + 备注）；修改边界后按新边界**重新带出生命周期阶段**（默认全部纳入）；仍遵守「一项目一边界」 | 以原型为准 / 骨架 D17 |
| R-025 | **[阶段带出规则]** 生命周期阶段按当前系统边界从阶段库带出：**启用态**且（适用边界为空 = 全边界通用，或包含当前边界）；按阶段顺序排序；**默认全部纳入**（`included = true`），项目内可取消 | 以原型为准（原型 `deriveStages`） |
| R-026 | **[阶段勾选联动]** 「生命周期阶段配置」弹窗内**一级 / 二级阶段均可勾选**；勾选 / 取消**一级阶段联动其下全部二级阶段**；支持「全选 / 全不选」；汇总展示「已纳入 X / Y 个阶段」 | 以原型为准（原型 `LifecycleStageConfigModal`） |
| R-027 | **[核算标准可选]** 核算标准**由用户在步骤①选择**，选项来自**标准文件库**（仅「现行」标准，展示 `{标准号} {名称}`）；**必填**；标准文件库未交付前用假数据支撑 | V0.4 业务反馈 |
| R-028 | **[统计时间]** 统计时间（起止区间）必填，默认当年自然年，起 ≤ 止；活动数据的数据期间**必须覆盖统计时间**，不足触发阻断（E14，步骤③检测执行） | 方案 §4.6 / §5.4 E14 |
| R-029 | **[产品图片必填]** 产品图片必填（上传或引用产品时自动带出）；未上传阻断保存 | 以原型为准（2026-10-13） |

## 5. 状态与动作

步骤①**无独立状态机**，其可编辑性完全由**项目状态**决定（承接《核算项目业务 PRD》§5.4）：

| 项目状态 | 步骤①表现 | 可执行动作 |
| :--- | :--- | :--- |
| 新建（草稿，未落库） | 可编辑 | 保存（落库并跳转正式项目） |
| 进行中 | 可编辑 | 保存 |
| 检测中 / 待核算 / 核算失败 | 可编辑（改动即回退「进行中」） | 保存 |
| 核算中 | 只读 | — |
| 已核算 | 可编辑（改动即回退并重算） | 保存 |
| **已完成** | **可编辑（V1.1 不锁定；改动即回退并重算）** | 保存 |
| 报告生成中 / 报告编制中（历史态） | 只读 | — |

## 6. 边界与异常处理

| 场景 | 系统行为 |
| :--- | :--- |
| 必填项缺失 | 字段下方红字提示（统计时间「请选择统计时间」/ 起始晚于结束「统计时间起始不能晚于结束」；核算标准「请选择核算标准」；产品名称「请输入产品名称」；产品图片「请上传产品图片」；单位「请选择单位」；声明单位数值「请输入声明单位数值」），并 toast「请先完善必填项」 |
| 我的产品库为空或全部下架 | 产品选择弹窗空态「暂无可选产品，请先在『我的产品库』新增或引用产品」 |
| 引用产品已被下架（快照已存在） | 允许继续使用快照；产品名称旁「已下架」Tag，不阻断 |
| 重新选择引用产品 | 二次确认「重新选择产品将覆盖已有带出信息，且已配置的核算工序可能失效，确认？」 |
| 声明单位被清空 | 阻断保存（声明单位数值与单位均必填） |
| 统计时间起 > 止 | 阻断保存，提示「统计时间起始不能晚于结束」 |
| 无可用核算标准（标准文件库无现行标准） | 核算标准下拉为空，阻断保存（标准文件库未交付前用假数据支撑） |
| 切换系统边界 | 按新边界重新带出生命周期阶段（默认全部纳入），不阻断 |
| 当前边界下无任何适用阶段 | 系统边界卡片区提示「暂无启用的系统边界字典项」（字典为空时）；阶段配置弹窗空态「当前系统边界下暂无可选生命周期阶段」；「生命周期阶段配置」按钮在无阶段时禁用 |
| 当前用户无归属组织 | 阻断保存并提示「当前账号未配置所属组织，请联系管理员」 |
