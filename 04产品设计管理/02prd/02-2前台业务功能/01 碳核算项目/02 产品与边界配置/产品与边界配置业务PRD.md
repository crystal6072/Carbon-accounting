## 1. 需求概述

### 1.1 需求背景

步骤②是核算项目从「建了个空壳」到「知道算谁、算到什么口径」的转折点：

```text
步骤① 目标与范围（名称 / 年度 / 边界 / 模型）
        ↓
步骤② 产品与边界配置（算哪个产品、功能单位是什么、净重多少、周期多长）   ← 本文
        ↓
步骤③ 生命周期模型（阶段、工艺、核算工序）—— 需要产品才能挂工序
```

**没有产品与功能单位，后续所有数据都无处挂载**：活动数据按「阶段 + 核算工序」组织，而核算工序来自产品工艺；结果按「功能单位」表达。

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :-: | :--- | :--- |
| G1 | **产品可引用可自建** | 支持从产品信息库引用（仅上架产品），也支持项目内自定义（不写回产品库） |
| G2 | **引用即快照** | 引用产品后，产品库后续变更不影响本项目已带出的名称/规格/单位/行业 |
| G3 | **功能单位口径唯一** | 默认取产品「单位」，允许项目级覆盖，覆盖**不写回产品库**；结果表达只用功能单位 |
| G4 | **净重必填实测** | 净重必填且 > 0；缺失阻断提交检测（E01）；净重单位必须是重量类单位 |
| G5 | **边界不可改** | 核算边界创建时确定，步骤②只读，无修改入口（一项目一边界） |
| G6 | **周期可覆盖核算** | 核算周期必填；活动数据期间须覆盖核算周期（E14，批次 5 执行校验） |

### 1.3 范围（In Scope / Out of Scope）

**In Scope**

| # | 范围 |
| :-: | :--- |
| 1 | 产品来源选择（引用产品库 / 自定义）与产品信息带出 / 填写 |
| 2 | 功能单位（默认取产品单位，可覆盖）与产品净重 + 净重单位 |
| 3 | 核算范围：核算边界（只读）、核算方法（只读带出）、核算周期、核算地点 |
| 4 | 步骤②的完成判定（驱动步骤条前进到③） |
| 5 | 编辑态与只读态切换（受项目状态约束） |

**Out of Scope**

| 不做项 | 归属 / 原因 |
| :--- | :--- |
| 产品的新建 / 编辑 / 上下架 | 后台 · 产品信息库（P08） |
| 产品工艺与核算工序配置 | 批次 3（P20） |
| 活动数据填报、按批次覆盖净重 | 批次 4（P22） |
| 关联项目 / 共享数据集（方案 §5.1 步骤3） | P30 后置，本期步骤②不含 |
| 产品版本选择（历史版本） | 【待确认 Q07】，本期固定引用当前生效版本 |
| 材质 / 密度 / 含水率 | 【待确认】，本期不落字段 |

### 1.4 与上下游的边界

| 归属 | 模块 | 本文的角色 |
| :--- | :--- | :--- |
| 产品主数据（编码 / 名称 / 规格 / 单位 / 行业 / 上下架） | 产品信息库（P08） | 只引用，不维护 |

## 4. 核心业务规则

> 编号承接批次 1《核算项目业务 PRD》§7（R-001 ~ R-013），本批次从 **R-014** 起。

| 规则ID | 规则 | 依据 |
| :--- | :--- | :--- |
| R-014 | **[产品来源约束]** 引用产品库时，选择器**仅返回「上架」产品**；已下架产品不出现在候选。来源 = 引用时，「引用产品」必填 | 产品库 D03 类比 / 骨架 D09 |
| R-015 | **[引用即快照]** 选定引用产品后，带出的编码 / 名称 / 型号 / 规格 / 所属行业 / 单位在项目内**冻结为快照**；产品库后续编辑或下架**不影响本项目**；如需采用新产品数据，走「重新选择产品」并重走检测 → 核算（E13） | 方案 §4.9 / 核算模型 PRD G3 同口径 |
| R-016 | **[功能单位口径]** 功能单位默认取产品「单位」；**允许项目级覆盖**（覆盖值引用计量单位库）；**覆盖不写回产品库**；功能单位用于结果表达（如 `kgCO₂e / 双`）。**产品信息库已将原「功能单位」合并进「单位」**，本项目侧保留覆盖能力以支持按重量基准出结果 | 产品库 D04 / 方案 §4.2.3 / 【待确认 Q08】 |
| R-017 | **[产品净重]** 产品净重**必填且 > 0**，按批次**实测**录入；净重单位必须为**重量类**计量单位；净重缺失或 ≤ 0 时**阻断提交检测**（E01 人话化：「产品净重还没填，请补实测净重」）；不允许用默认值静默替代 | 方案 §5.4 E01 / 附录二第14项 |
| R-018 | **[核算边界可修改]** 核算边界在创建项目时确定，**步骤①可修改**（V0.5 放开）；修改边界后需**重新配置生命周期模型**（批次 3）；仍遵守「一项目一边界」 | V0.5 业务反馈（原只读）；骨架 D17 |
| R-019 | **[核算方法可选]** 核算方法**由用户在步骤①选择**，选项来自**标准文件库**（仅「现行」标准）；默认带出引用模型「绑定的标准依据」，允许改选；**必填** | V0.4 业务反馈（原只读；Q09 关闭） |
| R-020 | **[统计时间]** 统计时间（起止区间）必填，默认当年自然年；**V0.4 由原「核算年度 + 核算周期」合并**；活动数据的数据期间**必须覆盖核算周期**，不足触发阻断（E14，批次 5 执行） | 方案 §4.6 / §5.4 E14 |
| R-021 | **[步骤②完成条件]** 满足以下全部条件时，步骤②视为完成，步骤条允许前进到③：① 产品来源已选；② 引用产品已选（或自定义产品名称 / 行业 / 单位已填）；③ 功能单位已确认；④ 产品净重 > 0 且净重单位已选；⑤ 核算周期完整（起止日期）且起 ≤ 止 | 骨架 S-001 |
| R-022 | **[编辑约束]** 项目状态 ∈ {新建, 进行中} 时步骤②可编辑；「检测中」及之后**整体只读**；「已核算」及之后修改步骤②数据 → 项目回退「进行中」，需重走检测 → 核算（E13） | 批次1 R-006 / 骨架 S-003 |
| R-023 | **[自定义产品最小集]** 自定义产品仅需名称、所属行业、单位、分类（其余选填）；**自定义产品不写入产品信息库**，不占用产品编码 | 骨架 D09 / 【待确认 Q11】 |
| R-024 | **[概念不外露]** 步骤②不展示异常编号、公式、快照术语；净重缺失提示为人话「产品净重还没填，请补实测净重」 | 《角色可见范围 v1.0》§3.1 |

## 5. 状态与动作

步骤②**无独立状态机**，其可编辑性完全由**项目状态**决定（承接批次 1 §5.4）。

| 项目状态 | 步骤②表现 | 可执行动作 |
| :--- | :--- | :--- |
| 新建 | 可编辑 | 保存 / 保存并进入③ |
| 进行中 | 可编辑 | 保存 / 保存并进入③ |
| 检测中 | 只读 | — |
| 待核算 | 可编辑（改动即回退「进行中」） | 保存 |
| 核算中 / 核算失败 | 只读 | — |
| 已核算 | 可编辑（改动即回退并重算） | 保存 |
| 报告生成中 / 报告编制中 | 只读 | — |
| 已完成 / 已归档 | 只读 | — |

## 6. 边界与异常处理

| 场景 | 系统行为 |
| :--- | :--- |
| 产品库为空或全部下架 | 产品选择弹窗展示空状态「暂无可选产品，可在产品信息库新增或上架」；提供「改为自定义产品」引导 |
| 引用产品已被下架（快照已存在） | 允许继续使用快照；产品名称旁提示「该产品已下架」，不阻断 |
| 切换产品来源（引用 ↔ 自定义） | 清空对侧字段并二次确认「切换后将清空已填写的产品信息，确认切换？」 |
| 重新选择引用产品 | 二次确认「重新选择产品将覆盖已有带出信息，且已配置的核算工序可能失效，确认？」（工序失效处理见批次 3） |
| 净重为 0 或空 | 阻断保存 / 进入③，净重字段下方提示「产品净重还没填，请补实测净重」 |
| 净重单位选了非重量类 | 单位下拉**只提供重量类单位**，从源头避免 |
| 核算周期起 > 止 | 阻断保存，提示「核算周期起始日期不能晚于结束日期」 |
| 功能单位被清空 | 保存时回退为产品「单位」（留空即取产品单位） |
| 无可用核算方法（模型未绑标准依据） | 核算方法展示 `-`，不阻断（标准依据在模型侧维护） |
