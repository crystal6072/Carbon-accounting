## 一、页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 产品与边界配置（工作台步骤②内容区） |
| 页面目标 | 确定「算哪个产品、按什么功能单位、净重多少、周期多长」，为步骤③挂工艺工序提供前提 |
| 承载容器 | 项目工作台内容区（顶部步骤条高亮第②步） |
| 骨架结构 | 页头动作（保存 / 保存并进入步骤③）→ 三个分组卡片 |

**分组顺序（与字段清单 §5 一致）**

```text
① 产品信息      （产品来源 / 引用产品 / 产品字段）
② 功能单位与净重（功能单位 / 产品净重 / 净重单位）
③ 核算范围      （核算边界 / 核算方法 / 核算周期 / 核算地点）
```

## 二、区域与控件规格

### 2.1 页头动作（工作台摘要条右侧）

| 元素 | 规格 |
| :--- | :--- |
| 保存 | Default；仅步骤②处于可编辑态时展示 |
| 保存并进入步骤③ | Primary；校验通过后保存并 `navigate` 到 `/pcf/project/{id}/3` |
| 只读态 | 两个按钮均不渲染（项目状态为检测中及之后） |

### 2.2 分组①：产品信息

| 字段 | 控件类型 | 规格 |
| :--- | :--- | :--- |
| 产品来源 | `Select` | 选项「引用产品库 / 自定义」；默认 `引用产品库`；**切换时二次确认并清空对侧字段**（C06） |
| 引用产品 | 只读输入框 + `选择产品` 按钮 | 来源=引用时展示；点击打开**产品选择弹窗**（§三）；已选后展示 `{编码} {名称}`；已下架时右侧显示 `Tag`「已下架」 |
| 产品编码 | `ReadonlyText` | 引用时带出，只读；自定义时展示 `-` |
| 产品名称 | `Input`（引用时 `ReadonlyText`） | 必填 |
| 产品分类 | `Input` / `Select`（自定义时 `Select` 引用产品分类，仅启用项） | 自定义时必填 |
| 型号 | `Input`（引用时只读） | 选填 |
| 规格 | `Input`（引用时只读） | 选填 |
| 所属行业 | `Input` / `Select`（自定义时选择） | 必填 |
| 产品版本 | `ReadonlyText` | 引用时带出「当前生效版本」；自定义时 `-` |

### 2.3 分组②：功能单位与净重

| 字段 | 控件类型 | 规格 |
| :--- | :--- | :--- |
| 功能单位 | `Select`（可搜索） | **默认取产品「单位」**；可覆盖（引用计量单位库）；hint「结果表达基准，如 `kgCO₂e / 双`；覆盖不写回产品库」 |
| 产品净重 | `NumberInput`（用 `Input type="number"`） | 必填；> 0；最多 6 位小数；placeholder「请输入实测净重」；hint「按批次实测，缺失将阻断提交检测」 |
| 净重单位 | `Select` | 必填；**仅重量类单位**（g / kg / t）；默认 `kg` |

### 2.4 分组③：核算范围

| 字段 | 控件类型 | 规格 |
| :--- | :--- | :--- |
| 核算边界 | `ReadonlyText` | 只读；来自创建项目时确定，hint「一项目一边界，不可修改」 |
| 核算方法 | `ReadonlyText` | 只读；取引用模型的「绑定的标准依据」；为空展示 `-` |
| 核算周期 | 两个 `DateInput`（起始 / 结束） | 必填；默认 `{核算年度}-01-01 ~ {核算年度}-12-31`；起始 ≤ 结束 |
| 核算地点 | `Input` | 选填；placeholder「如：福建·南平」 |

### 2.5 字段联动

| 触发 | 表现 |
| :--- | :--- |
| 选择引用产品 | 带出编码 / 名称 / 型号 / 规格 / 所属行业 / 产品版本；**功能单位自动设为产品「单位」**（用户已覆盖过则不覆盖） |
| 切换产品来源 | 二次确认 → 清空对侧字段（引用侧清空引用产品与带出值；自定义侧清空填写值） |
| 重新选择引用产品 | 二次确认「重新选择产品将覆盖已有带出信息，且已配置的核算工序可能失效，确认？」 |
| 改核算年度 | 若核算周期仍为默认值，则同步更新为新年度的自然年 |
| 进入步骤② | 只读带出核算边界、核算方法；核算周期按默认规则填充 |

## 三、产品选择弹窗

| 项目 | 内容 |
| :--- | :--- |
| 容器类型 | `Modal`（size = lg） |
| 标题 | 选择产品 |
| 查询区 | 产品编码 / 名称（`Input`，模糊）、所属行业（`Select`） |
| 表格列 | 单选列、产品编码、产品名称、型号、规格、所属行业、单位、使用状态 |

| 底栏 | `取消`（Default）+ `确认选择`（Primary，未选中时不可用） |
| 交互 | 点击行或单选按钮选中；双击行直接确认 |

## 四、校验与错误展示

| 动作 | 校验范围 | 失败反馈 |
| :--- | :--- | :--- |
| 保存 | 已填字段的格式与范围（净重 > 0、周期起 ≤ 止） | 字段下方红字，定位首错 |
| 保存并进入步骤③ | 完整必填校验（R-021） | 阻断前进并 Toast「请先完善必填项」；净重缺失时字段下方提示「产品净重还没填，请补实测净重」 |

**必填项（R-021）**：产品来源、引用产品（或自定义名称 / 行业 / 单位）、功能单位、产品净重（> 0）、净重单位、核算周期。

### 4.1 二次确认弹窗文案

| 触发 | 标题 | 内容 | 确认按钮 |
| :--- | :--- | :--- | :--- |
| 切换产品来源 | 确认切换产品来源 | 切换后将清空已填写的产品信息，确认切换？ | **确认切换** |
| 重新选择产品 | 确认重新选择产品 | 重新选择产品将覆盖已有带出信息，且已配置的核算工序可能失效，确认？ | **确认重新选择** |

> 拒绝时：保持当前选择，不做任何清空。

## 六、Mock 数据规格

| 要求 | 说明 |
| :--- | :--- |
| 产品选项 | ≥ 5 条，含 **1 条已下架**（验证 R-014 过滤） |

| 数据要求 | 全部虚构演示数据，不使用真实企业名 |
