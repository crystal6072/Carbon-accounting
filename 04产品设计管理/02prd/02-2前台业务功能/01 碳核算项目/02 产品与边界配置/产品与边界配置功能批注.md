## 1. 拟添加的批注清单

### 1.1 整体流程

#### F02-01 步骤①填写与保存整体流程
**拟标注位置**：步骤①内容区标题附近（全局说明）｜**标记**：已确认

- **适用场景**：新建核算（草稿态）或编辑已有项目的目标与范围。
- **流程**：进入步骤① → 填写「基本信息与产品」（统计时间 / 核算标准 / 产品名称[可引用产品] / 规格 / 分类 / 行业 / 声明单位 / 产品图片）→ 在「生命周期阶段」面板选系统边界、按需配置纳入阶段 → 摘要条点「保存」。
- **分支**：产品可自行录入或「引用产品」从我的产品库带出；系统边界切换会按新边界重新带出阶段。
- **衔接**：草稿保存 = 创建项目并跳转正式工作台；正式项目保存 = 更新并可能触发回退重算。
- **结束**：保存成功（toast 提示）；必填未填全则阻断并标红。

### 1.2 全局规则说明

#### F02-02 全局规则
**拟标注位置**：步骤①内容区标题附近（与整体流程同一全局说明入口）｜**标记**：已确认

1. **两面板结构**：「基本信息与产品」+「生命周期阶段」；表单不展示项目名称（按产品名称自动生成、内部留存）、核算主体组织（自动取当前登录用户所属组织）、备注、型号、产品编码 / 版本、核算公式、单位转换系数、净重。
2. **产品双通道**：产品名称可自行录入（不写回任何产品库），或「引用产品」从「我的产品库」选择（仅上架；自己新增 / 引用平台产品）。
3. **引用即快照**：引用产品带出的字段组冻结为项目快照，产品库后续变更不影响本项目。
4. **一项目一边界**：边界卡片单选（数据字典启用项），可随时切换；切换后按新边界重新带出阶段（默认全部纳入）。
5. **阶段默认全纳**：按当前边界带出的阶段默认全部纳入，项目内可自由取消。
6. **必填最小集**：统计时间 / 核算标准 / 产品名称 / 产品图片 / 声明单位（数值 + 单位）六项。
7. **编辑约束**：「已核算」前均可编辑（保存即回退重算）；**「已完成」同样可编辑**（V1.1 确认完成后不锁定，保存即回退重算）；仅「核算中」只读。

### 1.3 业务状态说明

#### F02-03 步骤①可编辑性（由项目状态决定）
**拟标注位置**：步骤①内容区（编辑 / 只读态切换）｜**标记**：已确认

- **可编辑**：草稿（新建）/ 进行中 / 检测中 / 待核算 / 核算失败 / 已核算 / **已完成**（改动即回退「进行中」并重走检测 → 核算；检测界面默认展示原检测数据，不强制重新检测）。
- **只读**：核算中（及历史报告态）—— 分组面板 + 纯文本展示，无保存入口。

### 1.4 操作功能及对应业务规则

#### F02-04 填写基本信息与产品
**拟标注位置**：「基本信息与产品」面板各字段｜**标记**：已确认

- **统计时间**（必填）：起止两个日期输入，默认当年自然年；hint「活动数据期间须覆盖」；起始晚于结束 → 红字「统计时间起始不能晚于结束」。
- **核算标准**（必填）：下拉，选项来自标准文件库（仅「现行」，展示 `{标准号} {名称}`）；hint「引用标准文件库」。
- **产品名称**（必填）：文本框（placeholder「请输入产品名称，或点击右侧『引用产品』带出」）+「引用产品」按钮；已下架的已引用产品显示「已下架」Tag（「已引用」Tag 已下线，V1.1）。
- **规格 / 产品分类 / 所属行业**（选填）：规格为文本框；分类 / 行业为级联选择（可搜索）。
- **声明/功能单位**（必填）：数值文本框（placeholder「如 5」）+ 单位级联选择（取值来自计量单位库）；hint「核算结果的表达单位，如 5 Item(s)」。
- **产品图片**（必填）：上传（原型以 data URL 存储）；tip「必填；引用产品时自动带出，也可自行上传」。

#### F02-05 引用产品（选择产品弹窗）
**拟标注位置**：「引用产品」按钮、选择产品弹窗、重新选择确认弹窗｜**标记**：已确认（二次确认文案待核对，见 §3）

- **操作目的**：从「我的产品库」选用产品并带出字段组。
- **弹窗结构**：搜索（产品编码 / 名称模糊）+ 表格（单选列 / 产品编码 / 产品名称 / 规格 / 所属行业 / 单位 / 来源[自己新增｜引用平台产品]）+ 分页（每页 20）；空态「暂无可选产品，请先在『我的产品库』新增或引用产品」。
- **操作过程**：单选一行 → 「确认选择」→ 带出产品字段组（名称 / 规格 / 分类 / 行业 / 图片 / 单位），并按当前边界重新带出阶段。
- **重新选择**：已引用产品后改选其他产品 → 二次确认「重新选择产品将覆盖已有带出信息，且已配置的核算工序可能失效，确认？」→ 确认后覆盖。
- **结果**：带出字段可继续修改；单位默认取产品「单位」（项目级修改不写回产品库）。

#### F02-06 系统边界（卡片单选）
**拟标注位置**：「生命周期阶段」面板左侧「系统边界」｜**标记**：已确认

- **取值来源**：「平台支撑 · 数据字典 · 系统边界」启用项（卡片展示名称 + 备注；预置 摇篮到大门 / 摇篮到坟墓 / 大门到大门）。
- **操作过程**：点击卡片即切换；切换后按新边界重新带出生命周期阶段（默认全部纳入）。
- **空态**：无启用字典项时提示「暂无启用的系统边界字典项」。

#### F02-07 生命周期阶段配置（弹窗）
**拟标注位置**：「生命周期阶段配置」按钮与弹窗｜**标记**：已确认

- **入口**：系统边界卡片区下方「生命周期阶段配置」按钮（无阶段时禁用）。
- **弹窗结构**：工具条（「已纳入 X / Y 个阶段；默认全部纳入，可按项目实际情况自定义」+「全选 / 全不选」）+ 四列表格（一级阶段名称 / 一级阶段描述 / 二级阶段名称 / 二级阶段描述，一级行合并单元格）。
- **勾选规则**：一级 / 二级阶段均可勾选；勾选 / 取消一级阶段**联动其下全部二级阶段**。
- **底部注意**：「二级阶段为一级阶段的从属明细；取消勾选一级阶段将同步取消其下二级阶段。取消纳入的阶段可不填报活动数据。」
- **结果**：「确定」回写纳入状态，「取消」不保存；步骤①汇总「已纳入 X / Y 个阶段」与阶段树实时更新。
- **空态**：「当前系统边界下暂无可选生命周期阶段」。

#### F02-08 保存（草稿落库 / 编辑保存）
**拟标注位置**：工作台摘要条「保存」｜**标记**：已确认

- **校验**（任一不通过即阻断，字段下方红字 + toast「请先完善必填项」）：统计时间未选或起 > 止 / 核算标准未选 / 产品名称为空 / 产品图片未上传 / 单位未选 / 声明单位数值为空。
- **草稿保存**：创建核算项目（生成编号）→ 写入步骤①全量字段 →（选用模型新建时）复制模型产品建模内容 → 跳转正式项目；toast「保存成功，核算项目已创建」。
- **编辑保存**：更新项目；「待核算 / 核算中 / 核算失败 / 已核算 / 已完成」态保存 → 回退「进行中」并定位步骤②（需重走检测 → 核算；**检测界面默认展示原检测数据，不强制重新检测**）；toast「保存成功」。

#### F02-09 只读态查看
**拟标注位置**：只读态步骤①内容区｜**标记**：已确认

- **展示内容**：「基本信息与产品」面板纯文本网格（核算编号 / 统计时间 / 核算标准 / 产品 / 产品分类 / 所属行业 / 规格 / 声明功能单位[数值 + 单位]）+ 产品图片预览；「生命周期阶段」面板（系统边界只读 + 已纳入汇总 + 已纳入阶段树）。

### 1.5 字段说明

#### F02-10 字段口径
**拟标注位置**：步骤①各字段｜**标记**：已确认

- **统计时间**：起止日期区间，活动数据归集期间；活动数据期间须覆盖统计时间（检测层校验）。
- **核算标准**：核算依据的方法学 / 标准；仅「现行」标准可选；落 `methodId` / `method`。
- **产品名称**：被核算产品名称；可自行录入或引用带出；已下架的已引用产品展示「已下架」Tag（「已引用」Tag 已下线，V1.1）。
- **规格 / 产品分类 / 所属行业**：选填；引用产品时带出（可修改）；分类按分类名称落库。
- **声明/功能单位**：结果表达基准 = 数值 + 单位（如 `5 Item(s)`）；单位默认取产品单位，允许项目级覆盖（不写回产品库）。
- **产品图片**：产品外观图片；必填；引用产品时自动带出。
- **系统边界**：核算边界口径；卡片单选；修改后按新边界重新带出阶段。
- **生命周期阶段**：纳入核算的阶段集合（一级 / 二级）；默认全部纳入、可取消；作为步骤②左树来源。
