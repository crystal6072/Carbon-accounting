## 1. 拟添加的批注清单

### 1.1 整体流程

#### F05-01 核算与结果整体流程
**拟标注位置**：步骤④内容区标题附近（全局说明）｜**标记**：已确认

- **适用场景**：检测通过后执行核算、查看多维结果、导出清册并确认完成。
- **流程**：检测通过（项目「待核算」）→ 步骤④「开始核算」→「核算中…」（原型模拟异步）→ 核算完成（同页展开结果区）→ 按需切换口径 / 下钻明细 / 下载清册 / 重新计算 →「确认完成」→ 项目流转「已完成」。
- **分支**：核算异常 →「核算失败」+「重新核算」；「核算中」项目进入本步骤自动推进异步任务到完成；「已核算 / 已完成」修改步骤①② → 回退「进行中」重走检测 → 核算（或在结果区直接「重新计算」生成新版本）。
- **衔接**：步骤③「进入碳足迹核算」进入；结果区与执行区同页（不跨步骤）。
- **结束**：「确认完成」后项目流转「已完成」（**结果不锁定**：仍可再编辑 / 重检 / 重核算 / 重算）。

### 1.2 全局规则说明

#### F05-02 全局规则
**拟标注位置**：步骤④内容区标题附近（与整体流程同一全局说明入口）｜**标记**：已确认

1. **计算入口**：碳核算计算引擎**内置代码层级**，暂按默认口径求值（行级 `数量 × 单位换算系数 × 排放因子` → 阶段 `SUM` → 全局 `SUM`）；步骤①**不再引用核算公式**。
2. **计算范围**：步骤①纳入阶段下的全部数据项（含追溯节点内数据项）；无因子行因子值记 0。
3. **单位换算**：数据项单位 → 因子分母单位，引擎按计量单位库「基准中转」计算换算系数（无法换算时为 1；跨类型由检测 B4 事前阻断）。
4. **四口径**：因子带 GWP 分项时，结果按 `total` 总量（不含生物源CO₂）/ `biogenic` 生物源 / `luluc` 直接土地利用变化 / `fossil` 化石 四分量单独求值，界面卡片切换（顺序即 `PCF_CALIBERS`）；无分项时按单一口径呈现（不出现切换卡片）。
5. **实时汇总**：阶段 / 数据项 / 排放源 / 明细均按**当前口径**从结果明细实时汇总（口径切换仅影响展示与导出，不改变原始明细）。
6. **结果版本化**：每次核算 / 重新计算生成新版本（版本号递增），历史版本保留不可篡改；界面展示最近版本。
7. **概念不外露**：界面不展示公式 DSL、计算引擎、快照术语、异常编号。
8. **确认完成后不锁定（V1.1）**：「已完成」仍可再编辑 / 重检 / 重核算 / 重新计算；编辑保存后回退「进行中」重走检测 → 核算；「已完成」态不再展示「确认完成」入口。

### 1.3 业务状态说明

#### F05-03 核算状态（四态 + 项目状态映射）
**拟标注位置**：核算状态卡｜**标记**：已确认

- **待核算（idle）**：项目「待核算」；文案「尚未执行核算」+「检测已通过，可开始核算」；动作「开始核算」。
- **核算中（calculating）**：项目「核算中」；文案「核算中…」+「正在按工序公式计算活动数据与排放因子…」；按钮禁用。
- **核算完成（done）**：项目「已核算」；文案「核算完成」+「核算时间：X · 结果版本 Vn」；动作「重新计算」「确认完成」。
- **核算失败（failed）**：项目「核算失败」；文案「核算失败」+「核算异常，请检查数据后重新核算」；动作「重新核算」。
- **回看 / 已完成（V1.1 不锁定）**：项目「已完成」；文案「核算已完成，结果仅供查看」；动作「重新计算」「下载清册」「预览模型」；历史报告态仍只读、无执行入口。

### 1.4 操作功能及对应业务规则

#### F05-04 开始核算 / 重新核算
**拟标注位置**：核算状态卡动作按钮｜**标记**：已确认

- **准入**：项目状态 ∈ 「待核算 / 核算失败 / **已完成**」（V1.1 起已完成不锁定，可重新核算）；未检测或检测不通过不可进入（步骤③已阻断）。
- **操作过程**：点击后状态卡切「核算中…」（防重复提交）；「核算中」项目进入本步骤会自动推进异步任务到完成（toast「核算完成」）。
- **结果**：完成 → 项目「已核算」、生成结果版本（版本号递增）、结果区同页展开、toast「核算完成」；异常 → 项目「核算失败」、保留失败记录、可「重新核算」重试。

#### F05-05 重新计算（新结果版本）
**拟标注位置**：核算状态卡「重新计算」｜**标记**：已确认

- **显示条件**：项目「已核算」或「已完成」（V1.1 起已完成不锁定，同样可重新计算）。
- **操作过程**：按当前活动数据与排放因子重算，**按版本号递增生成新结果版本，历史版本保留不可篡改**（不回退「进行中」）。
- **结果**：toast「重新计算完成，已生成结果版本 Vn」。

#### F05-06 确认完成（结果不锁定）
**拟标注位置**：核算状态卡「确认完成」、二次确认弹窗｜**标记**：已确认

- **显示条件**：项目「已核算」（仅 `calculated` 可执行；`done` 态不再展示）。
- **操作过程**：点击后弹二次确认弹窗（标题「确认完成核算」），正文「确认完成后，该项目将变为『已完成』状态（结果不锁定：后续仍可继续编辑数据、重新检测、重新核算或重新计算；如修改数据并保存，项目将重走检测 → 核算）。确认完成『{项目名 / 编号}』？」；底栏「取消」「确认完成」。
- **结果**：确认后项目流转「已完成」，toast「已确认完成」。
- **边界**：非「已核算」态不展示入口；**「已完成」结果不锁定（V1.1）**——仍可再编辑 / 重新检测 / 重新核算 / 重新计算；编辑保存后回退「进行中」重走检测 → 核算。

#### F05-07 结果总览卡（单位产品碳足迹 + 四口径卡片）
**拟标注位置**：结果总览卡｜**标记**：已确认

- **主指标**：「单位产品碳足迹」= 当前口径合计（kgCO₂e / 项目单位）；非「核算完成」态时旁标「历史版本」Tag；下方展示核算时间。
- **下载清册**：总览卡右侧主按钮（title「按『{影响评价指标中文名}』下载核算清册（总表 + 每个最末级生命周期阶段各 1 张表）」）；toast「已下载清册（{口径}）」。
- **口径切换**：存在 GWP 分项时展示 4 张口径卡片（每张 = 影响评价指标 + 该口径合计值），点击切换；无分项时展示「口径：{总量}（本项目所选因子未提供 GWP 分项，按单一口径核算）」。
- **空态**：无结果时「暂无核算结果，请先完成碳足迹核算」/ 失败「核算失败，暂无可用结果」/ 只读无版本「核算已完成，结果只读（当前无结果版本）」。

#### F05-08 阶段汇总 / 数据项汇总
**拟标注位置**：两个汇总面板｜**标记**：已确认

- **阶段汇总**：生命周期阶段（按一级阶段上卷）/ 排放量（kgCO₂e）/ 占比（占比色条）；按排放量降序；标题带当前口径简称；tip「生命周期阶段按一级阶段上卷；随所选口径实时汇总」。
- **数据项汇总**：数据项 / 所属过程 / 所属阶段 / 最末级阶段 / 排放量 / 贡献率 / 操作；按排放量降序；「查看明细」点击后结果明细区按该数据项过滤并滚动定位，再点「收起明细」恢复。
- **汇总口径**：均按当前口径从明细实时汇总；占比 = 占该口径合计。
- **（V1.7 调整）**：结果页**不再输出「排放源归类」独立汇总维度**，仅保留阶段 / 数据项 / 明细三维；如需按来源拆分，可经明细的「数据项类型 / 背景数据来源」透视。

#### F05-09 结果明细（下钻）
**拟标注位置**：结果明细面板｜**标记**：已确认

- **列**：数据项名称 / 类别（Tag）/ 流向（投入 / 产出）/ 活动量 / 最末级阶段 / 排放因子 / 排放系数（按所选口径取值，含因子单位）/ 背景数据来源 / 所属过程 / 排放量 / 其中生物源 / 其中土地利用。
- **提示**：「数量 × 排放系数 = 排放量；系数按所选因子快照固化，同一行可切换『总量 / 化石 / 生物源 / 土地利用』查看」。
- **过滤**：数据项汇总点「查看明细」后仅展示该数据项明细（标题带数据项 Tag）。

#### F05-10 下载清册（Excel 多工作表）
**拟标注位置**：结果总览卡「下载清册」｜**标记**：已确认（结果明细 CSV 入口待确认，见 §3）

- **清册结构**：**总表**（产品名称 / 功能单位 / 系统边界 / 影响评价方法[IPCC 2021 GWP100] / 影响评价指标[按当前口径] / 结果 kgCO₂e / 计算方法[活动数据 × 排放因子] / 统计时间 / 结果版本 + 各阶段排放与占比）+ **每个最末级生命周期阶段各 1 张表**（生命周期过程 / 排放系数 / 背景数据来源 / 结果 kgCO₂e / 占比 %）。
- **口径**：按当前所选口径生成（一个口径 = 一套清册）。
- **数据来源**：最近一次核算结果明细（数据项 × 因子快照），不额外造数。

#### F05-11 预览模型（流程画布）
**拟标注位置**：核算状态卡「预览模型」按钮｜**标记**：原型已表现·待核对

- **操作目的**：以流程画布形式只读预览建模数据（输入 / 输出 + 追溯链路）。
- **原型表现（待核对）**：步骤④各状态恒显「预览模型」。

### 1.5 字段说明

#### F05-12 结果字段口径
**拟标注位置**：结果总览卡与各汇总表｜**标记**：已确认

- **单位产品碳足迹**：以项目「单位」为口径的单位产品碳排放量（kgCO₂e）= 当前口径清单合计（数据项用量即数量口径，无需再除产量）。
- **结果版本**：`V{n}`，递增；界面展示最近版本，历史版本保留。
- **四口径**：总量（不含生物源CO₂）/ 生物源（不含CO₂）/ 直接土地利用变化 / 化石；卡片顺序即界面与清册展示顺序。
- **排放系数**：因子值口径（按所选分量取值），含因子单位（如 `kgCO₂e/kg`）。
- **背景数据来源**：因子所在库 + 版本 + 因子名称（如「中国官方排放因子库 V1.0 数据库：电力排放因子」）。
- **最末级阶段**：「一级阶段-二级阶段」路径（直接挂一级时为一级名）；清册按此拆表。
