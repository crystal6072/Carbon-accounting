## 1. 对象说明

碳足迹核算环节涉及三个对象，均为**项目内派生对象**（由系统核算生成，不参与人工录入）：

```text
核算任务（PcfCalcTask） 1 ─── 1 核算结果（PcfCalcResult） 1 ─── N 结果明细（PcfResultDetail）
```

- **核算任务**：一次「开始核算」动作触发的异步计算任务，记录状态与起止时间。
- **核算结果**：一次核算的结论快照（总排放 + 阶段 / 工序 / 排放源汇总），版本化留存。
- **结果明细**：结果下钻到「工序 → 数据项 → 因子 → 公式」的明细行。

> **概念不外露（骨架 D06 / S-007）**：结果页只呈现人话排放构成（总量 / 阶段 / 数据项 / 排放源），**不展示公式 DSL 本体**（表达式、变量占位、运算符）与引擎、快照术语、异常编号。

### 1.1 核算口径（V0.6：引擎内置默认口径）

```text
行级：逐条阶段数据项 → 数量 × 单位换算系数 × 排放因子   → 行碳排
阶段：SUM 该阶段各行碳排
全局：SUM 各阶段碳排 → 核算结果（单位产品碳足迹）
```

| 项 | 口径 |
| :--- | :--- |
| 计算入口 | **引擎内置代码层级**（默认口径如上）；步骤①**不再引用「核算公式」**（V0.8 移除），原三层受控表达式口径作废 |
| 计算范围 | 步骤①纳入阶段下的全部阶段数据项（含「继续追溯」节点内数据项）；无因子行因子值记 0 |
| 单位换算 | `[当前行.单位换算系数]` 由引擎按计量单位库「**基准中转**」自动计算（数据项单位 → 因子分母单位）；无法换算时为 1 |
| 单位产品碳足迹 | = 全局 SUM 结果。**数据项用量即「单位产品用量」口径**，故结果 = 清单合计，系统不再执行「÷ 产出量」 |

> ~~公式的字段结构、变量库与配置规则见后台《**公式管理字段清单**》《**公式管理业务 PRD**》~~ —— 项目侧公式引用已移除，后台公式管理仅服务引擎后续建设。

### 1.2 四口径输出（V0.6：GWP 四分量）

因子库支持「多口径」——因子可选带 **GWP 分项口径**（`calibers`：`gwpFossil` 化石 / `gwpBiogenic` 生物碳 / `gwpLuluc` 土地利用，均为选填；见《排放因子库字段清单》）。核算结果因此输出**四口径**（原型 `PCF_CALIBERS`）：

| 口径 key | 界面文案 | 结果字段 | 逐行取值 |
| :--- | :--- | :--- | :--- |
| `total` | 总量（不含生物源CO₂） | `emission` / `totalEmission` / `caliberEmission.total` | 用**总量因子值**代入行级口径求值后汇总 |
| `biogenic` | 生物源（不含CO₂） | `biogenicEmission` / `emissionBreakdown.biogenic` / `caliberEmission.biogenic` | 有分项用 `gwpBiogenic` 单独算（吸收为负、释放为正）；只有总值时记 0 |
| `luluc` | 直接土地利用变化 | `lulucEmission` / `emissionBreakdown.luluc` / `caliberEmission.luluc` | 有分项用 `gwpLuluc` 单独算；只有总值时记 0 |
| `fossil` | 化石 | `fossilEmission` / `emissionBreakdown.fossil` / `caliberEmission.fossil` | 有分项用 `gwpFossil` 单独算；只有总值时 = 总量 |

> **顺序口径（V0.7）**：上表顺序 = 原型 `PCF_CALIBERS` 定义顺序（total / biogenic / luluc / fossil），即界面口径卡片与清册「影响评价指标」的展示顺序。

**逐行口径规则（混合口径兜底）**：

| 行的因子情况 | 总量 | 化石 | 生物源 | 土地利用 |
| :--- | :--- | :--- | :--- | :--- |
| **有分项口径** | 用**总量**算 | 用 `gwpFossil` 单独算 | 用 `gwpBiogenic` 单独算 | 用 `gwpLuluc` 单独算 |
| **只有总值**（无分项口径） | 用**总值**算 | = 总量 | 记 **0** | 记 **0** |

> **数据源**：行内 `factorCalibers` 快照（步骤②「引用因子」时写入，见《核算项目字段清单》§6.1），核算时**不回查因子库**；无口径信息的行按上表「只有总值」处理。
> **汇总维度**：总量 / 阶段 / 数据项 / 排放源 / 明细**均按当前口径实时汇总**；口径切换仅影响展示与导出，不改变原始明细；无 GWP 分项时结果区按单一口径呈现（不出现口径切换卡片）。

## 3. 核算结果（PcfCalcResult）

| 字段 | 类型 | 来源 | 必填 | 说明 |
| :--- | :--- | :--- | :---: | :--- |
| `projectId` | string | 系统 | 是 | 所属核算项目 id |
| `version` | number | 系统 | 是 | 结果版本号（递增） |
| `calculatedAt` | string | 系统 | 是 | 核算完成时间（`YYYY-MM-DD HH:mm`） |
| `totalEmission` | number | 系统 | 是 | 模型总碳排（kgCO₂e）= 各阶段碳排合计，用于占比与「总量」展示；= **含生物碳口径** |
| `fossilEmission` | number | 系统 | 是 | **不含生物碳口径**（化石源）总排放（kgCO₂e）；无生物碳信息时 = `totalEmission` |
| `biogenicEmission` | number | 系统 | 是 | **生物碳净额**（吸收为负、释放为正，kgCO₂e）；无生物碳信息时为 0 |
| `lulucEmission` | number | 系统 | 是 | **直接土地利用变化**总排放（kgCO₂e）；无口径信息时为 0（V0.7 补，原型实际产出） |
| `caliberEmission` | `PcfCaliberValues` | 系统 | 否 | **四分量口径的单位产品碳足迹值**（kgCO₂e / 声明单位，V0.7 补，原型实际产出）；口径切换与清册导出用 |
| `unit` | string | 系统 | 是 | 结果表达单位（取项目「单位」，如「双」「个」「包」） |
| `unitEmission` | number | 系统 | 是 | 单位产品碳足迹（kgCO₂e / 结果表达单位）= 全局 SUM 结果（= `totalEmission`，数据项用量即单位产品用量口径） |
| `unitEmissionBreakdown` | `PcfUnitEmission[]` | 系统 | 是 | 各口径单位产品碳足迹（**保留字段，界面不再展示**——步骤①已移除单位转换系数，无换算口径） |
| `formulaName` | string | 系统 | 是 | ~~本次核算所引用的**核算公式名称**~~（**保留字段**——V0.8 起步骤①不再引用公式；原型实际赋值为「默认口径（活动数据 × 排放因子）」，界面不展示） |
| `stageSummary` | `PcfStageSummary[]` | 系统 | 是 | 阶段汇总（各一级阶段排放 + 占比） |
| `operationSummary` | `PcfOperationSummary[]` | 系统 | 是 | **数据项汇总**（各数据项排放 + 贡献率；界面列：数据项 / 所属过程 / 所属阶段 / 最末级阶段 / 排放量 / 贡献率） |
| `sourceSummary` | `PcfSourceSummary[]` | 系统 | 是 | 排放源汇总（分类排放 + 占比） |
| `details` | `PcfResultDetail[]` | 系统 | 是 | 结果明细（工序 → 数据项 → 因子 → 公式） |

### 3.1 阶段汇总（PcfStageSummary）

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `stage` | string | 一级生命周期阶段名称（如「原材料获取」「生产」） |
| `emission` | number | 该阶段排放量（kgCO₂e，**当前口径**） |
| `fossilEmission` | number | 该阶段**化石源**排放（kgCO₂e；原型按明细实时汇总，汇总对象不落该字段） |
| `biogenicEmission` | number | 该阶段**生物源净额**（kgCO₂e；同上） |
| `ratio` | number | 该阶段占总排放比例（%，保留 1 位小数） |

### 3.2 数据项汇总（PcfOperationSummary）

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `operationId` | string | 数据项 id（对应填报行 id） |
| `processName` | string | 所属过程名称（追溯节点名；直接挂阶段下时为空） |
| `opName` | string | **数据项名称** |
| `stage` | string | 所属一级生命周期阶段 |
| `stagePath` | string | 最末级生命周期阶段路径（如「原材料获取-原材料运输」；无二级时为一级阶段名） |
| `emission` | number | 该数据项排放量（kgCO₂e，按当前口径） |
| `ratio` | number | 该数据项贡献率（%，保留 1 位小数） |

> 汇总对象仅 `emission` / `ratio`；四口径分项值由明细实时汇总（原型 `caliberValueOf`），不落汇总对象。

### 3.3 排放源汇总（PcfSourceSummary）

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `source` | enum `CalcSourceType` | 排放源归类（见 §5） |
| `emission` | number | 该分类排放量（kgCO₂e，**含生物碳口径**） |
| `fossilEmission` | number | 该分类**不含生物碳**排放（kgCO₂e） |
| `biogenicEmission` | number | 该分类**生物碳净额**（kgCO₂e） |
| `ratio` | number | 该分类占总排放比例（%，保留 1 位小数） |

### 3.4 单位产品碳足迹口径（PcfUnitEmission）

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `unit` | string | 口径单位（如 `双` / `kg`） |
| `value` | number | 该口径下的单位产品碳足迹（kgCO₂e / 单位） |

> 首项固定为项目「单位」口径（值 = 全局 SUM 结果）；**换算口径不再产生**（步骤①已移除「单位转换系数」，V1.2），本结构保留仅为兼容。

## 5. 排放源归类（CalcSourceType）

> **归类口径（V0.3）**：结果「排放源」按**排放源归类**（材料 / 能源 / 运输 / 废弃物 / 末期处理 / 生物碳）归类；无因子行按数据项流类型兜底归类。**`FactorCategory` 仅作为核算结果排放源归类的内部枚举**（原型 `PcfCalcSourceType = FactorCategory`），**不再属于因子字段**（因子不设分类 / 适用行业，见《排放因子库字段清单》V0.3）。
