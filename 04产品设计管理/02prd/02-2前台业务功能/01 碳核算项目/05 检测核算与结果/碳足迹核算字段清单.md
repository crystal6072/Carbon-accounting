## 1. 对象说明

碳足迹核算环节涉及三个对象，均为**项目内派生对象**（由系统核算生成，不参与人工录入）：

```text
核算任务（PcfCalcTask） 1 ─── 1 核算结果（PcfCalcResult） 1 ─── N 结果明细（PcfResultDetail）
```

- **核算任务**：一次「开始核算」动作触发的异步计算任务，记录状态与起止时间。
- **核算结果**：一次核算的结论快照（总排放 + 阶段 / 工序 / 排放源汇总），版本化留存。
- **结果明细**：结果下钻到「工序 → 数据项 → 因子 → 公式」的明细行。

> **概念不外露（骨架 D06 / S-007）**：结果页只呈现人话排放构成（总量 / 阶段 / 工序 / 排放源），不展示公式 DSL、计算引擎、快照、异常编号。

## 2. 核算任务（PcfCalcTask）

| 字段 | 类型 | 来源 | 必填 | 说明 |
| :--- | :--- | :--- | :---: | :--- |
| `projectId` | string | 系统 | 是 | 所属核算项目 id |
| `status` | enum `CalcStatus` | 系统 | 是 | 核算状态：`idle`（待核算）/ `calculating`（核算中）/ `done`（完成）/ `failed`（失败） |
| `startedAt` | string | 系统 | 否 | 核算开始时间（`YYYY-MM-DD HH:mm`）；未开始为空 |
| `finishedAt` | string | 系统 | 否 | 核算完成时间；未完成 / 失败为空 |
| `version` | number | 系统 | 否 | 结果版本号（递增，从 1 起）；未完成无版本 |
| `errorMessage` | string | 系统 | 否 | 失败原因（人话描述）；仅 `failed` 时有值 |

**`CalcStatus` 枚举**

| 值 | 界面文案 | 说明 |
| :--- | :--- | :--- |
| `idle` | 待核算 | 检测通过、尚未执行核算 |
| `calculating` | 核算中 | 核算执行中 |
| `done` | 核算完成 | 已生成结果版本 |
| `failed` | 核算失败 | 核算异常，可重试 |

## 3. 核算结果（PcfCalcResult）

| 字段 | 类型 | 来源 | 必填 | 说明 |
| :--- | :--- | :--- | :---: | :--- |
| `projectId` | string | 系统 | 是 | 所属核算项目 id |
| `version` | number | 系统 | 是 | 结果版本号（递增） |
| `calculatedAt` | string | 系统 | 是 | 核算完成时间（`YYYY-MM-DD HH:mm`） |
| `totalEmission` | number | 系统 | 是 | 总碳排放量（kgCO₂e） |
| `unit` | string | 系统 | 是 | 功能单位（取项目「单位」，如「双」「个」「包」） |
| `unitEmission` | number | 系统 | 是 | 单位产品碳足迹（kgCO₂e / 功能单位；本期 = `totalEmission`） |
| `stageSummary` | `PcfStageSummary[]` | 系统 | 是 | 阶段汇总（各一级阶段排放 + 占比） |
| `operationSummary` | `PcfOperationSummary[]` | 系统 | 是 | 工序汇总（各工序排放 + 贡献率） |
| `sourceSummary` | `PcfSourceSummary[]` | 系统 | 是 | 排放源汇总（分类排放 + 占比） |
| `details` | `PcfResultDetail[]` | 系统 | 是 | 结果明细（工序 → 数据项 → 因子 → 公式） |

### 3.1 阶段汇总（PcfStageSummary）

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `stage` | string | 一级生命周期阶段名称（如「原材料获取」「生产」） |
| `emission` | number | 该阶段排放量（kgCO₂e） |
| `ratio` | number | 该阶段占总排放比例（%，保留 1 位小数） |

### 3.2 工序汇总（PcfOperationSummary）

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `operationId` | string | 项目内核算工序 id |
| `processName` | string | 所属工艺流程名称 |
| `opName` | string | 工序名称 |
| `stage` | string | 所属一级生命周期阶段 |
| `emission` | number | 该工序排放量（kgCO₂e） |
| `ratio` | number | 该工序贡献率（%，保留 1 位小数） |

### 3.3 排放源汇总（PcfSourceSummary）

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `source` | enum `CalcSourceType` | 排放源分类（见 §5） |
| `emission` | number | 该分类排放量（kgCO₂e） |
| `ratio` | number | 该分类占总排放比例（%，保留 1 位小数） |

## 5. 排放源分类（CalcSourceType）

> 对齐因子分类（方案 §4.4），结果按**匹配因子的分类**归类；无因子行按数据项流类型兜底归类。

| 值 | 界面文案 | 说明 |
| :--- | :--- | :--- |
| `material` | 材料 | 原辅料 / 自然资源输入排放 |
| `energy` | 能源 | 电力 / 燃料 / 热力燃烧排放 |
| `transport` | 运输 | 原料与成品运输排放 |
| `waste` | 废弃物 | 废水 / 废渣 / 废弃物处理排放 |
| `eol` | 末期处理 | 生命周期末期处理排放 |
| `biocarbon` | 生物碳 | 生物碳吸收（负排放）/ 释放 |

## 6. 关键决策

| 编号 | 决策事项 | 结论 | 状态 |
| :--- | :--- | :--- | :---: |
| C01 | 结果版本化 | 每次核算生成新版本（版本号递增），旧版本保留；本期仅展示最近版本，历史切换后置 | 待业务确认 |
| C02 | 单位换算 | 原型层简化（检测 B4 已保证可换算），核算直接用因子值，不引入换算系数 | 待业务确认 |
| C03 | 分配比例 | 多产出工序分配比例在结果明细作参考展示，不做副产品替代法扣减（本期后置） | 待业务确认 |
| C04 | 排放源归类 | 以匹配因子分类（`FactorCategory`）归类；无因子行按流类型兜底 | 待业务确认 |
| C05 | 核算异步模拟 | 原型模拟异步核算（提交后短暂「核算中」，随后返回结果） | 待业务确认 |
