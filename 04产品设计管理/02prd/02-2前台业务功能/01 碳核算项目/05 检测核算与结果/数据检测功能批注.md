## 1. 拟添加的批注清单

### 1.1 整体流程

#### F04-01 数据检测整体流程
**拟标注位置**：步骤③内容区标题附近（全局说明）｜**标记**：已确认

- **适用场景**：进入核算前的最后一道质量闸门。
- **流程**：完成步骤② → 进入步骤③ → 点「提交检测」→「检测中…」（原型模拟异步，约 1 秒）→ 返回结论。
- **分支**：无阻断项 → 「检测通过」+「进入碳足迹核算」入口（项目转「待核算」、步骤推进到④）；有阻断项 → 「检测不通过」+ 问题清单（项目回「进行中」、停留③）。
- **衔接**：点问题「修改入口」跳步骤①/② 整改 → 回步骤③「重新检测」（覆盖最近一次结论）。
- **结束**：检测通过并进入步骤④；或项目「已完成」后只读回看。

### 1.2 全局规则说明

#### F04-02 全局规则
**拟标注位置**：步骤③内容区标题附近（与整体流程同一全局说明入口）｜**标记**：已确认

1. **检测对象**：步骤②的阶段数据项（不再有工序 / 分配比例）；仅**纳入的一级阶段下**的数据项参与检测（二级阶段数据项上卷到一级阶段判定）。
2. **实际检测项**：B1 用量缺失 / B2 投入项未匹配因子 / B4 因子单位不可换算 / B5 已纳入一级阶段无数据项（阻断级）+ W2 生物碳未在生命末期闭环（提示级）；**B3 分配比例与 W1 质量平衡当前不产生**。
3. **两级问题**：阻断级未清零不可进入核算；提示级仅作风险标注，不阻断。
4. **概念不外露**：问题清单只呈现「人话问题 + 修改入口」，不展示异常编号（E01–E16）、检测规则编号、公式、因子绑定术语。
5. **提交条件**：「提交检测」仅项目状态为「进行中 / 检测中 / **已完成**」时可用（V1.1 起已完成不锁定，可重新检测）。
6. **结果留存**：检测结果随项目留存（最近一次结论）；**回退保留结论（V1.1）**——已核算 / 已完成修改数据保存回退「进行中」后，步骤③**默认展示原检测数据**（问题清单可回看），**不强制重新检测**；用户主动重检后覆盖。

### 1.3 业务状态说明

#### F04-03 检测状态（四态结论卡）
**拟标注位置**：检测结论卡｜**标记**：已确认

- **待检测（pending）**：尚未提交过检测；文案「尚未提交检测」+「请点击下方按钮提交检测」；动作「提交检测」。
- **检测中（checking）**：检测执行中；文案「检测中…」+「正在校验活动数据、排放来源、阶段覆盖、因子单位与质量平衡…」；按钮禁用（「检测中…」）。
- **检测通过（passed）**：无阻断级问题；文案「检测通过，可进入碳足迹核算」+ 检测时间；项目转「待核算」时展示「进入碳足迹核算」，其余通过态展示「查看核算结果」。
- **检测不通过（failed）**：存在阻断级问题；文案「检测不通过」+「阻断 N 项 · 提示 M 项 · 检测时间：X」；动作「重新检测」。

### 1.4 操作功能及对应业务规则

#### F04-04 提交检测 / 重新检测
**拟标注位置**：检测结论卡动作按钮｜**标记**：已确认

- **显示条件**：「提交检测」= 待检测态且项目「进行中 / 检测中 / 已完成」（V1.1 起已完成不锁定，可重新检测）；「重新检测」= 不通过态且项目可检测。
- **操作过程**：点击后结论卡切「检测中…」（按钮禁用、防重复提交）→ 异步返回结论。
- **结果**：通过 → toast「检测通过」，项目「待核算」、当前步骤推进到④；不通过 → toast「检测不通过，存在 N 项阻断问题」，项目回「进行中」、停留③。
- **失败兜底**：检测异常 → toast「检测异常，请重新检测」并重读最近结论。
- **回退默认展示原检测数据（V1.1）**：已核算 / 已完成修改数据保存回退「进行中」后，步骤③仍展示最近一次检测结论（问题清单可回看），**不强制重新检测**；用户主动重检后覆盖。

#### F04-05 问题清单（阻断 / 提示两级）
**拟标注位置**：阻断问题面板、提示问题面板｜**标记**：已确认

- **分组**：「阻断问题（N）」与「提示问题（N）」两个面板；阻断组 tip「须整改后才能进入碳足迹核算」/ 空态「未发现阻断问题」；提示组 tip「提示问题不阻断核算，建议关注」/ 空态「未发现提示问题」。
- **单条结构**：级别 Tag（阻断=红 / 提示=黄）+ 检测类别 + 人话标题 + 详细描述 + 定位（「阶段：X / 数据项：Y」）+ 修改入口按钮（`{fixLabel} →`）。
- **展示条件**：待检测 / 检测中不展示问题清单。
- **修改入口口径**（原型实际）：B1「去填写」/ B2「去匹配因子」/ B4「去修改」/ B5「去补充」（均跳步骤②）；W2「去调整边界」（跳步骤①）。

#### F04-06 检测规则明细（问题文案口径）
**拟标注位置**：问题清单各条（按类别）｜**标记**：已确认

| 编号 | 触发条件 | 标题（原型实际） | 修改入口 |
| :--- | :--- | :--- | :--- |
| B1 | 数据项单位产品用量为空 | 「数据项『X』的数量未填写」 | 去填写 |
| B2 | 投入项（原辅料 / 自然资源 / 能源及能源介质）未匹配因子 | 「投入项『X』未匹配排放因子」 | 去匹配因子 |
| B4 | 数据项单位与因子分母单位跨类型不可换算（同类型量级不阻断，由引擎基准中转换算） | 「数据项『X』的数量单位与因子单位不可换算」 | 去修改 |
| B5 | 步骤①纳入的一级阶段下无任何数据项 | 「阶段『X』已纳入但未录入数据项」 | 去补充 |
| W2 | 存在因子口径含生物碳分量，但纳入的一级阶段中无生命末期 / 废弃 / 处置 / 回收阶段 | 「生物碳未在生命末期闭环」 | 去调整边界 |

> **类别界面文案**：数据完整性 / 因子单位 / 阶段覆盖 / 生物碳（分配比例、质量平衡枚举保留但不产生）。

#### F04-07 进入碳足迹核算 / 查看核算结果
**拟标注位置**：检测结论卡动作按钮｜**标记**：已确认

- **进入碳足迹核算**：检测通过且项目「待核算」时展示，点击跳步骤④。
- **查看核算结果**：检测通过但项目非「待核算 / 进行中」（如已核算、已完成回看）时展示，点击跳步骤④。

#### F04-08 预览模型（流程画布）
**拟标注位置**：检测结论卡「预览模型」按钮｜**标记**：原型已表现·待核对

- **操作目的**：以流程画布形式只读预览建模数据（输入 / 输出 + 追溯链路）。
- **原型表现（待核对）**：步骤③各状态恒显「预览模型」；画布数据取自已保存数据。

#### F04-09 只读态（核算中）
**拟标注位置**：只读态步骤③｜**标记**：已确认

- **展示内容**：检测说明 + 最近一次检测结论卡 + 问题清单（只读）。
- **限制**：无「提交检测 / 重新检测」入口。
- **V1.1 起「已完成」不再只读**（确认完成后结果不锁定）：可提交 / 重新检测，默认展示原检测数据。

### 1.5 字段说明

#### F04-10 检测结论字段
**拟标注位置**：检测结论卡统计区｜**标记**：已确认

- **检测时间**：最近一次检测完成时间（未检测 / 检测中为空）。
- **阻断 N 项 · 提示 M 项**：问题清单实际条数（N / M 与分组面板标题数字一致）。
- **定位**：问题所在阶段 / 数据项（如「阶段：原材料获取 / 数据项：电力」）。
