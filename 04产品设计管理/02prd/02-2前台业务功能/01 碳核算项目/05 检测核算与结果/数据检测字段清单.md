## 1. 对象说明

数据检测环节涉及两个对象，均为**项目内派生对象**（由系统检测生成，不参与人工录入）：

```text
检测结果（PcfCheckResult） 1 ─── N 检测问题（PcfCheckIssue）
```

- **检测结果**：一次「提交检测」动作的结论快照，记录检测时间、阻断/提示问题数、是否通过。
- **检测问题**：检测结果中的一条问题，含级别（阻断/提示）、类别、人话描述、定位与修改入口。

> **概念不外露（骨架 D06 / S-007）**：检测问题在界面**只呈现「人话问题 + 修改入口」**，不展示异常编号（E01–E16）、检测规则编号、公式、因子绑定等配置段术语（《角色可见范围分层 v1.0》§3 / §3.1）。

## 2. 检测结果（PcfCheckResult）

| 字段 | 类型 | 来源 | 必填 | 说明 |
| :--- | :--- | :--- | :---: | :--- |
| `projectId` | string | 系统 | 是 | 所属核算项目 id |
| `status` | enum `CheckStatus` | 系统 | 是 | 检测状态：`pending`（未检测）/ `checking`（检测中）/ `passed`（通过）/ `failed`（不通过） |
| `checkedAt` | string | 系统 | 是 | 检测完成时间（`YYYY-MM-DD HH:mm`）；未检测 / 检测中为空 |
| `blockingCount` | number | 系统 | 是 | 阻断级问题数 |
| `warningCount` | number | 系统 | 是 | 提示级问题数 |
| `issues` | `PcfCheckIssue[]` | 系统 | 是 | 问题清单（可为空数组） |

**`CheckStatus` 枚举**

| 值 | 界面文案 | 说明 |
| :--- | :--- | :--- |
| `pending` | 待检测 | 尚未提交过检测 |
| `checking` | 检测中 | 检测执行中 |
| `passed` | 检测通过 | 无阻断级问题，可进入核算 |
| `failed` | 检测不通过 | 存在阻断级问题，需整改后重检 |

## 3. 检测问题（PcfCheckIssue）

| 字段 | 类型 | 来源 | 必填 | 说明 |
| :--- | :--- | :--- | :---: | :--- |
| `id` | string | 系统 | 是 | 问题唯一标识（检测项编码 + 定位拼接） |
| `level` | enum `CheckIssueLevel` | 系统 | 是 | 问题级别：`blocking`（阻断）/ `warning`（提示） |
| `category` | enum `CheckCategory` | 系统 | 是 | 检测类别（见 §5） |
| `title` | string | 系统 | 是 | 人话标题（不展示异常编号） |
| `description` | string | 系统 | 是 | 详细描述（含整改建议） |
| `location` | string | 系统 | 否 | 定位信息（如「工序：断料 / 数据项：电力」），用于快速定位问题 |
| `fixStep` | enum `1 \| 2` | 系统 | 否 | 修改入口步骤：`1` = 步骤①目标与范围，`2` = 步骤②工序与数据 |
| `fixLabel` | string | 系统 | 否 | 修改入口按钮文案（如「去填写」「去修改」「去匹配因子」） |

**`CheckIssueLevel` 枚举**

| 值 | 界面文案 | 语义 | 是否阻断核算 |
| :--- | :--- | :--- | :---: |
| `blocking` | 阻断 | 必须整改后才能进入碳足迹核算 | 是 |
| `warning` | 提示 | 建议关注，可标风险继续核算 | 否 |

> 阻断级 / 提示级与方案 §5.4「阻断计算 / 阻断报告」列的对应关系：本环节的 `blocking` 对应「阻断计算 = 是」的异常；`warning` 对应「可计算但标风险 / 提示级」的异常。

## 4. 检测项清单

> 检测项是本环节的核心字段约束来源。编号 `B` = 阻断级（Blocking）、`W` = 提示级（Warning）。**界面不展示编号**，仅作为文档与 mock 实现的对齐锚点。

| 编号 | 检测项 | 级别 | 检测类别 | 触发条件（简化口径） | 定位 | 修改入口 |
| :--- | :--- | :---: | :--- | :--- | :--- | :--- |
| B1 | 活动数据缺失 | 阻断 | 完整性 | 某数据项的任一活动量未填（`value == null`） | 工序 / 数据项 | 步骤② 填活动量 |
| B2 | 排放来源缺失 | 阻断 | 完整性 | 需因子的投入项未匹配排放因子（`requiresFactor && direction=input && factorId==null`） | 工序 / 数据项 | 步骤② 匹配因子 |
| B3 | 分配比例不闭合 | 阻断 | 分配比例 | 多产出工序的产出项分配比例合计 ≠ 100% | 工序 | 步骤② 调比例 |
| B4 | 因子单位不匹配 | 阻断 | 因子单位 | 活动量单位与因子分母单位**不可换算** | 工序 / 数据项 | 步骤② 换因子或改单位 |
| B5 | 阶段无数据 | 阻断 | 阶段覆盖 | 步骤①勾选纳入的阶段未匹配到任何工序数据 | 生命周期阶段 | 步骤② 补充工序 |
| W1 | 质量平衡偏差 | 提示 | 质量平衡 | 工序投入（物料类）与产出（成品/副产品类）质量偏差超阈值 | 工序 | 步骤② 核对数据 |

## 5. 检测类别（CheckCategory）

| 值 | 界面文案 | 说明 |
| :--- | :--- | :--- |
| `completeness` | 数据完整性 | 活动量 / 排放来源缺失 |
| `factorUnit` | 因子单位 | 因子分母单位与活动量单位不匹配 |
| `allocation` | 分配比例 | 多产出分配比例不闭合 |
| `stageCoverage` | 阶段覆盖 | 已纳入阶段无数据 |
| `massBalance` | 质量平衡 | 投入产出质量偏差 |
