## 一、页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 数据检测（工作台步骤③ 内容区） |
| 页面目标 | 提交检测、查看检测结论与问题清单、整改后重检、通过后进入核算 |
| 承载容器 | 项目工作台内容区（顶部步骤条高亮第③步） |
| 骨架结构 | 检测说明 + 检测结论卡 + 问题清单（阻断级 / 提示级分组） |

```text

② 检测结论卡（待检测 / 检测中 / 通过 / 不通过）
③ 问题清单（阻断级分组 + 提示级分组）
```

## 二、区域与控件规格

### 2.1 检测说明

| 项目 | 规格 |
| :--- | :--- |
| 位置 | 内容区顶部（浅色提示条） |
| 内容 | 数据检测将在进入核算前，对活动数据、排放来源、分配比例、阶段覆盖、因子单位与质量平衡进行校验；检测通过后方可进入碳足迹核算 |
| 样式 | 复用 `.pcf-form-tip`（浅色说明条） |

### 2.2 检测结论卡

| 项目 | 规格 |
| :--- | :--- |
| 容器 | 卡片（`card` 内嵌，或复用 `.pcf-panel`） |
| 内容 | 结论状态图标 + 文案 + 统计（阻断 N / 提示 N）+ 动作按钮 |

**四态规格**

| 状态 | 图标 / 配色 | 文案 | 动作 |
| :--- | :--- | :--- | :--- |
| 待检测（pending） | 灰 | 尚未提交检测 | `提交检测`（Primary） |
| 检测中（checking） | 蓝（loading） | 检测中… | 无（按钮禁用 / 隐藏） |
| 通过（passed） | 绿（success） | 检测通过，可进入碳足迹核算 | `进入碳足迹核算`（Primary） |
| 不通过（failed） | 红（error） | 检测不通过，存在 N 项阻断问题 | `重新检测`（Primary） |

> 统计展示：`阻断 N 项 · 提示 M 项`（N / M 为问题清单实际条数）。

### 2.3 问题清单

| 项目 | 规格 |
| :--- | :--- |
| 容器 | 分组面板（复用 `.pcf-panel`），按级别分两组 |
| 分组顺序 | 先「阻断问题」后「提示问题」 |
| 分组标题 | `阻断问题（N）` / `提示问题（M）`；N=0 时组标题右侧显示「无」 |

**问题条目（行）结构**

| 元素 | 规格 |
| :--- | :--- |
| 级别 Tag | 阻断 = 红（error）· 提示 = 橙（warning） |
| 类别 | 灰色小字（数据完整性 / 因子单位 / 分配比例 / 阶段覆盖 / 质量平衡） |
| 标题 | 人话问题标题（加粗） |
| 描述 | 次要文字（含整改建议） |
| 定位 | 灰色小字（如「工序：断料 / 数据项：电力」；无则省略） |
| 修改入口 | 文字按钮（链接色），如「去填写」「去匹配因子」「去修改」「去补充」；点击跳转步骤①/② |

**空态（无问题）**

| 项目 | 规格 |
| :--- | :--- |
| 阻断问题 | 绿色提示「未发现阻断问题」 |
| 提示问题 | 灰色提示「未发现提示问题」 |

### 2.4 页头动作（工作台摘要条右侧）

| 元素 | 规格 |
| :--- | :--- |
| 可检测态 | `提交检测` / `重新检测`（Primary，由步骤③内部承载，工作台摘要条可不再重复渲染） |
| 只读态 | 不渲染检测按钮 |

> 步骤③的检测动作按钮**落在内容区结论卡**，工作台摘要条右侧保持「返回 / 保存」通用动作（本步骤无需「保存」，无步骤③专属页头按钮）。

## 三、校验与错误展示

| 检查 | 触发时机 | 失败反馈 |
| :--- | :--- | :--- |
| 项目无工序数据 | 提交检测 | 返回检测结果（含 B5 / B1），正常展示问题清单，不额外弹 Toast |
| 检测执行异常 | 提交检测 | Toast：「检测异常，请重新检测」（服务端兜底） |
| 状态不可检测 | 提交检测 | Toast：「当前状态不可检测」（服务端兜底） |

> 校验策略：**检测逻辑由服务端（mock）执行**，前端仅渲染返回的检测结果；状态不可检测时 mock 抛错，前端 Toast 兜底。

## 四、反馈文案

| 操作 | 反馈 | 文案 |
| :--- | :--- | :--- |
| 检测通过 | 结论卡 | 检测通过，可进入碳足迹核算 |
| 检测不通过 | 结论卡 | 检测不通过，存在 N 项阻断问题 |
| 重新检测 | 结论卡 | 重新检测中…（→ 返回新结论） |
| 加载失败 | Toast（error） | 项目不存在或已被删除 |

## 五、Mock 数据规格

| 要求 | 说明 |
| :--- | :--- |
| 检测结果来源 | mock 新增 `fetchPcfCheckResult(projectId)` / `submitPcfCheck(projectId)` |
| 检测逻辑 | `submitPcfCheck` 真实遍历项目活动数据（`pcfActivityStore`）+ 工序（`pcfOperationStore`）做简化检测（B1–B5 / W1） |
| 单位可换算 | 以计量单位库「单位类型」判定（同类型可换算），原型用简化实现 |
| 样本覆盖 | PJ03（`checking`，step3）预置「检测不通过」问题清单；PJ04（`toCalc`，step4）构造「检测通过」结果 |
| 质量平衡（W1） | 简化：对物料类投入 / 成品副产品类产出比较，偏差超 5% 标提示 |
| 数据要求 | 全部虚构演示数据 |
