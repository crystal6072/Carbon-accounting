## 1. 需求概述

### 1.1 需求背景

步骤②「产品建模」把「一个产品 + 一组边界与阶段」变成「**可核算的数据清单**」：

```text
步骤① 目标与范围（产品 / 声明单位 / 系统边界 / 纳入的生命周期阶段）
        ↓
步骤② 产品建模（左树选末级阶段 → 右侧维护阶段数据项）   ← 本文
        ├─ 投入项：引用排放因子 或 继续追溯上游过程（递归）
        └─ 数据凭证附件（选填）
        ↓ 名称 + 数量填全
步骤③ 数据检测（B1 / B2 / B4 / B5 / W2）
```

**没有阶段数据项，检测与核算都无输入**；投入项没有排放因子，核算无法求值。

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :-: | :--- | :--- |
| G1 | **按阶段组织数据** | 左树仅末级阶段可点击；右侧数据列表按「阶段 / 追溯节点」作用域展示，默认保留一行空白行 |
| G2 | **投入项可匹配因子** | 投入项（原辅料 / 自然资源 / 能源及能源介质）通过「引用因子」匹配排放来源；未匹配 → 检测 B2 阻断 |
| G3 | **上游过程可追溯** | 任意数据项可「继续追溯」生成上游过程节点（递归），在节点内录入其自身数据项 |
| G4 | **数据可批量导入** | CSV 模板导入（下载模板 → 上传 → 校验 → 按当前作用域追加） |
| G5 | **必填最小集** | 保存校验 = 名称 + 数量；空白行不落库 |
| G6 | **概念不外露** | 界面不展示工序、公式、绑定、异常编号等配置段术语 |

## 4. 核心业务规则

> 编号承接《产品与边界配置业务 PRD》（R-020 ~ R-034），本模块从 **R-035** 起（原 R-025 ~ R-033 已按原型现行口径改写并重新编号，旧编号映射见 §9.2）。

| 规则ID | 规则 | 依据 |
| :--- | :--- | :--- |
| R-035 | **[左树作用域]** 左侧树 = 步骤①纳入的生命周期阶段（**仅末级阶段可点击录入**：二级阶段恒为末级；一级阶段无下级阶段时才是末级）+ 「继续追溯」生成的过程链路；阶段 / 节点切换即切换右侧数据列表作用域 | 以原型为准（2026-10-14） |
| R-036 | **[数据项结构]** 阶段数据项 = 名称 / 数据项类型 / 排放物子类（类型 = 排放物时必填）/ 数量 / 单位；**方向由类型推导**（原辅料 / 自然资源 / 能源及能源介质 = 投入，其余 = 产出），不单独设字段 | 字段清单 §6.1 |
| R-037 | **[默认空白行]** 进入可编辑作用域时默认保留一行空白数据项；空白行（名称为空）**不落库** | 以原型为准 |
| R-038 | **[必填校验]** 保存时校验已填写数据项的**名称与数量必填**；存在未填用量项 → 阻断保存并 toast「还有 N 条数据项未填写数量」 | 以原型为准 |
| R-039 | **[排放来源二选一]** 数据项的「上游过程名称」列在**未追溯**时提供「引用因子 / 继续追溯」二选一；**已引用因子后不可追溯**（仅可更换因子或撤回）；已追溯数据项不再提供因子入口 | 以原型为准 |
| R-040 | **[引用因子]** 「引用因子」弹窗候选 = **背景数据库（已发布库）+ 我的因子库**（左侧库分组切换，右侧单选）；确认后写入因子快照（`factorId` / `factorName` / `factorValue` / `factorCalibers`，引用即复制）并回显「上游过程名称」列；**撤回**后恢复二选一 | 以原型为准 / 骨架 D22 |
| R-041 | **[投入项因子强制]** 投入项（原辅料 / 自然资源 / 能源及能源介质）未匹配因子 → 检测 **B2 阻断**；产出项不强制 | 骨架 D22 |
| R-042 | **[继续追溯]** 「继续追溯」以数据项名称为依据生成**上游过程节点**（需先填写数据项名称，否则 toast「请先填写数据项名称，再继续追溯」），节点挂在该数据项下、进入左树，可递归追溯；节点内数据项结构同阶段数据项 | 以原型为准 |
| R-043 | **[取消追溯]** 左树节点「取消追溯」→ 移除该节点**及其全部子节点与已录入数据**（不可恢复）；toast「节点已删除」 | 以原型为准 |
| R-044 | **[CSV 导入]** 导入 = 下载模板（列：名称 / 数据项类型 / 数量 / 单位 / 排放物类型）→ 上传 CSV → 校验 → **按当前作用域追加**；校验规则：名称非空、类型有效（七类中文枚举）、用量为数值（可为负）、排放物类型有效（类型 = 排放物时）；失败行展示「行号 / 名称 / 失败原因」；导入前移除当前作用域空白行 | 以原型为准 |
| R-045 | **[数据凭证]** 数据项可上传凭证附件（**选填、可多个**，原型以 data URL 本地存储）；操作列展示「数据凭证（N）」；凭证不参与计算 | 字段清单 §6.3 |
| R-046 | **[保存与回退]** 保存 = 整表提交阶段数据项 + 过程节点；「待核算 / 核算中 / 核算失败 / 已核算 / 已完成」态保存 → 项目回退「进行中」并定位步骤③，需重走检测 → 核算（E13；**检测结论与核算结果保留，步骤③默认展示原检测数据，不强制重新检测**） | 以原型为准（mock `savePcfStageData` / R-048） |
| R-047 | **[编辑约束]** 承接 R-033：「已核算」之前均可编辑；**「已完成」同样可编辑**（V1.1 确认完成后不锁定，保存即回退重走检测 → 核算）；仅「核算中」只读（无添加 / 导入 / 删除 / 追溯入口） | 批次1 R-006 / V1.4 |

## 5. 状态与动作

步骤②**无独立状态机**，其可编辑性由**项目状态**决定（承接《核算项目业务 PRD》§5.4）：

| 项目状态 | 步骤②表现 | 可执行动作 |
| :--- | :--- | :--- |
| 进行中 | 可编辑 | 添加 / 编辑 / 删除 / 引用因子 / 追溯 / 导入 / 凭证 / 保存 |
| 检测中 / 待核算 / 核算失败 | 可编辑（改动即回退「进行中」） | 同上 + 保存 |
| 核算中 | 只读 | — |
| 已核算 | 可编辑（改动即回退并重算） | 同上 + 保存 |
| **已完成** | **可编辑（V1.1 不锁定；改动即回退并重算）** | 同上 + 保存 |
| 报告生成中 / 报告编制中（历史态） | 只读 | — |

## 6. 边界与异常处理

| 场景 | 系统行为 |
| :--- | :--- |
| 步骤①未勾选任何阶段 | 左树空态「步骤①未勾选生命周期阶段，请先在『目标与范围』配置后再返回建模」；右侧提示「请先在左侧选择一个生命周期阶段」 |
| 当前作用域无数据项 | 表格空态「暂无数据项，点击右上角『添加数据』录入或『导入』批量导入」 |
| 未填名称即点「继续追溯」 | toast「请先填写数据项名称，再继续追溯」 |
| 保存时存在未填用量项 | 阻断保存，toast「还有 N 条数据项未填写数量」 |
| 导入文件为空 / 无数据行 | toast「文件为空或缺少数据行」 |
| 导入行类型 / 用量 / 排放物类型无效 | 该行进入失败列表（行号 + 名称 + 失败原因），不影响可导入行 |
| 因子库为空 | 因子弹窗库列表空态「暂无因子库」；所选库无因子 → 表格空态「该库暂无因子」 |
| 已引用因子的数据项 | 不再展示「继续追溯」入口（仅更换 / 撤回） |
| 取消追溯 | 移除节点及其子节点与数据（不可恢复），toast「节点已删除」 |
| 草稿态（未落库） | 步骤②不可达（草稿固定步骤①，保存落库后才进入步骤②） |

## 8. 验收标准

| # | 验收项 | 输入条件 | 预期结果 |
| :-: | :--- | :--- | :--- |
| V01 | **仅末级阶段可点** | 打开步骤②，左树含一级 + 二级阶段 | 一级阶段为分组态（不可点），二级阶段可点击录入 |
| V02 | **数据项必填阻断** | 留任意一条数据项的名称或数量为空后点「保存」 | 阻断保存并提示「还有 N 条数据项未填写数量」；空白行不落库 |
| V03 | **排放来源二选一** | 查看未追溯数据项的「上游过程名称」列 | 展示「引用因子 / 继续追溯」两个入口 |
| V04 | **引用因子回显** | 对某投入项点「引用因子」并确认 | 回显因子名称；可点击更换、可撤回；撤回后恢复二选一 |
| V05 | **已引用因子不可追溯** | 对已引用因子的数据项查看入口 | 无「继续追溯」入口 |
| V06 | **继续追溯** | 对某数据项点「继续追溯」 | 生成上游过程节点并进入左树（挂该数据项下），可在节点内录入其数据项 |
| V07 | **取消追溯** | 对已追溯节点点「取消追溯」 | 节点及其子节点与数据被移除，toast「节点已删除」 |
| V08 | **CSV 导入** | 下载模板 → 填写上传 → 校验 → 确认导入 | 按当前作用域追加数据项，toast「已导入 N 条数据项」；失败行展示原因 |
| V09 | **数据凭证** | 对某数据项上传凭证附件 | 操作列显示「数据凭证（N）」；凭证选填、可多个 |
| V10 | **编辑即回退** | 「已核算」态修改步骤②并保存 | 项目回退「进行中」并定位步骤③，需重走检测 → 核算（检测界面默认展示原检测数据，不强制重新检测） |
| V11 | **只读态** | 项目「核算中」打开步骤② | 输入框只读，无添加 / 导入 / 删除 / 追溯入口（「已完成」不锁定，仍可编辑，V1.1） |
| V12 | **无工序口径** | 走查步骤②界面 | 不出现工序 / 工艺流程 / 绑定公式 / 分配比例相关列与入口 |
