# 生命周期模型配置业务 PRD（步骤②）

> **【本文档已废弃 · 2026-09-24】**：随「核算模型」废弃，本项目**不再有独立的「生命周期模型配置」步骤**，原步骤②「生命周期模型配置」已并入并重命名为「**工序与数据**」。
>
> **废弃原因**：原步骤②的「生命周期阶段勾选 / 排除」依赖核算模型的阶段结构；去模型后，阶段降级为「工序/工艺的『所属生命周期阶段』标签」，**不再需要项目内手工配置阶段**。
>
> **替代方案（已在前端原型落地，2026-09-24 最终口径）**：
> - 工序由所选产品**引用即复制**带入（含工序投入产出项的**公式**）；
> - **生命周期阶段勾选已恢复到步骤①「目标与范围」**（阶段库仅 5 个通用一级阶段，按核算边界带出、默认全勾选可取消）；步骤② **按勾选阶段对齐展示工序**（左树 = 生命周期阶段 → 工艺流程 → 工序），未匹配阶段显示空分组；
> - 步骤②支持**新增工艺流程 / 新增工序（可选所属工艺或所属阶段）/ 删除工序**；
> - 本步骤保留**活动数据填报（动态变量列）+ 排放来源（默认带出公式绑定因子、可改）+ 多产出分配比例**（步骤名改为「工序与数据」）；
> - 相关字段口径并入《核算项目字段清单》§6。
>
> 本文档以下内容仅作历史留档，不再维护。

> **⚠️ V0.6 口径变更（2026-09-23，优先于本文正文）**：按业务反馈（见骨架 V0.6 / D18–D21），本模块与「分配场景配置」「数据填报」**合并为第②步「模型与数据」**。正文如有冲突，以下列口径为准：
>
> ① **工序的所属生命周期阶段不再由用户手工指定**——一个工艺流程对应一个生命周期阶段，阶段随「产品 → 工艺流程」带出，**项目内只读**；若工艺所属阶段被排除 → 阻断保存（R-014）。
> ② **本步骤新增投入 / 产出数据填报**（数量默认留空，工艺基准值仅作提示）与**多产出的分配比例**（同工序合计 100%），见《核算项目字段清单》§6.4。
> ③ 步骤条已由 8 步收敛为 **6 步**（②模型与数据 / ③数据检测 / ④碳足迹核算 / ⑤核算结果 / ⑥报告）；本文「步骤②」含义不变。

## 1. 需求概述

### 1.1 需求背景

步骤②把「一个产品」变成「可核算的生命周期模型」—— 回答两个问题：

```text
① 算哪些生命周期阶段？（按行业 + 边界从阶段库加载 → 项目内确认/排除）
② 有哪些核算工序、各自落在哪个阶段？（引用即复制自产品 → 指定阶段）
        ↓
后续：数据填报按「阶段 + 核算工序」组织，核算结果按阶段汇总
```

**没有阶段与工序的绑定，活动数据无处挂载**。

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :-: | :--- | :--- |
| G1 | **阶段按行业 + 边界自动加载** | 进入步骤② 即带出适用阶段，无需手工逐条新增 |
| G2 | **必须纳入阶段不可排除** | 「必须纳入」阶段的勾选框禁用；「可选纳入」可排除但必填原因 |
| G3 | **排除原因留痕且不回写主数据** | 排除原因保存在项目内；查看阶段库无变化 |
| G4 | **工序引用即复制** | 工序与投入产出流复制到项目；产品库后续变更不影响本项目 |
| G5 | **每道工序必须归入一个已启用阶段** | 未指定阶段时阻断保存；阶段候选只列已启用的二级阶段 |
| G6 | **投入产出流本步骤只读** | 数量 / 单位在批次 4（数据填报）录入 |

### 1.3 范围（In Scope / Out of Scope）

## 4. 核心业务规则

> 编号承接批次 2（R-014 ~ R-024），本批次从 **R-025** 起。

| 规则ID | 规则 | 依据 |
| :--- | :--- | :--- |
| R-025 | **[阶段加载]** 首次进入步骤② 时，按「**产品所属行业 + 项目核算边界**」从生命周期阶段库加载阶段；纳入规则**三态**取该边界对应的值；**「不纳入」的阶段默认不启用**（可手工启用）。加载结果在项目内**冻结为快照**，阶段库后续变更不影响已建项目（重算走 E13） | 方案 §4.2.4 / §4.3.1 |
| R-026 | **[必须纳入阶段不可排除]** 「必须纳入」阶段的勾选框**禁用**（固定启用）；缺少其活动数据时触发 **E10** 阻断（批次 5 校验） | 方案 §5.4 E10 |
| R-027 | **[可选纳入阶段排除须填原因]** 「可选纳入」阶段可取消勾选，但**必须填写排除原因**；未填阻断保存。**排除动作与原因保存在项目内，不回写阶段主数据** | 方案 §5.4 E11 / §4.2.4 修订说明 |
| R-028 | **[工序引用即复制]** 首次进入步骤② 时，从所选产品的工艺 / 工序副本**复制**一份到项目（含工艺流程、工序顺序、投入产出流）；副本归项目所有，**产品库后续变更不回写**；保留「来源产品 + 复制时点」供追溯 | 方案 §4.9 **口径 2** |
| R-029 | **[重选产品重新复制]** 步骤① 重选产品后进入步骤②，工序**重新复制**且**清空已有阶段分配**；需二次确认「重新选择产品将清空已配置的工序阶段归属，确认？」 | 骨架 S-001 / D11 |
| R-030 | **[工序必须归入已启用阶段]** 每道核算工序必须指定所属**二级阶段**；候选**只列出已启用**的二级阶段；存在未指定工序时阻断保存 | 方案 §5.1 步骤4–5 |
| R-031 | **[投入产出流只读]** 本步骤只展示投入 / 产出（名称、类型、数量、单位），**不可编辑**；数量与凭证在批次 4（P22）数据填报时确认 | 批次拆分 |
| R-032 | **[编辑约束]** 承接 R-006（骨架 D13）：**核算完成前均可编辑**；「已核算」修改 → 回退「进行中」并重走检测 → 核算（E13） | 骨架 D13 |
| R-033 | **[步骤②完成条件]** 满足以下全部条件时步骤② 视为完成，可前进到③：① 至少启用 1 个二级阶段；② 所有被排除的「可选纳入」阶段均已填原因；③ **每道核算工序均已指定所属阶段** | 骨架 S-001 |

## 5. 状态与动作

步骤②**无独立状态机**，其可编辑性由**项目状态**决定（承接批次 1 §5.4 / 骨架 D13）：

| 项目状态 | 步骤②表现 | 可执行动作 |
| :--- | :--- | :--- |
| 新建 / 进行中 | 可编辑 | 保存 / 前进到③ |
| 检测中 / 待核算 / 核算失败 | 可编辑 | 保存 |
| 核算中 | 只读 | — |
| 已核算 | 可编辑（改动即回退重算） | 保存 |
| 报告生成中 / 报告编制中 / 已完成 / 已归档 | 只读 | — |

## 6. 边界与异常处理

| 场景 | 系统行为 |
| :--- | :--- |
| 产品所属行业与边界下无任何适用阶段 | 阶段区展示空状态「当前行业与边界下暂无适用阶段」；阻断前进到③ |
| 所选产品无工艺 / 工序 | 工序区展示空状态并引导「请到产品信息库完善产品或重新选择产品」；阻断前进到③ |
| 启用的二级阶段为 0 | 阻断保存并提示「请至少启用一个生命周期阶段」 |
| 取消一级阶段后其下有工序 | 保存时校验：工序所属阶段若已不可用 → 提示重新指定 |
| 重选产品 | 二次确认后重新复制工序、清空阶段分配 |
| 产品库中的工序被删除 | 不影响本项目（副本已复制，R-028） |
| 阶段库中阶段被禁用 | 不影响已建项目（阶段已快照，R-025） |

## 8. 验收标准

| # | 验收项 | 输入条件 | 预期结果 |
| :-: | :--- | :--- | :--- |
| V01 | **阶段自动加载** | 项目边界 = 摇篮到大门，产品行业 = 竹制品制造 | 阶段列表带出该行业 + 该边界的适用阶段 |

| V04 | **可选纳入排除填原因** | 取消「可选纳入」阶段勾选后直接保存 | 阻断，提示填写排除原因 |
| V05 | **排除原因不回写** | 项目内排除某阶段并填原因后，查看后台阶段库 | 阶段库无变化 |
| V06 | **工序引用即复制** | 项目保存后，后台修改该产品的工序名称 | 项目内工序名称不变 |
| V07 | **重选产品重新复制** | 步骤① 换成另一个产品并保存，回到步骤② | 二次确认后工序列表更新、阶段分配清空 |

| V09 | **阶段候选只列已启用二级阶段** | 排除某二级阶段后打开工序阶段下拉 | 该阶段不在候选中 |
| V10 | **投入产出流只读** | 查看工序的投入 / 产出 | 只读展示，无编辑入口 |
| V11 | **只读态** | 项目处于「核算中」，打开步骤② | 全部只读，无保存入口 |
| V12 | **步骤前进** | 全部校验通过后点击保存 | 保存成功且进度推进到③ |

| 项目生命周期阶段 | 从阶段库加载到项目内的阶段集合，含三态规则与项目内启用状态 |
