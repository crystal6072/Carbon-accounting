## 1. 拟添加的批注清单

### 1.1 整体流程

#### F03-01 产品建模整体流程
**拟标注位置**：步骤②内容区标题附近（全局说明）｜**标记**：已确认

- **适用场景**：把「产品 + 边界 + 阶段」落成「可核算的数据清单」。
- **流程**：左树选末级生命周期阶段 → 右侧「添加数据」维护数据项（名称 / 类型 / 用量 / 单位）→ 投入项「引用因子」匹配排放来源（或「继续追溯」生成上游过程递归录入）→ 按需上传数据凭证 / CSV 批量导入 → 摘要条「保存」→ 步骤③提交检测。
- **分支**：每个数据项的排放来源「引用因子 / 继续追溯」二选一；追溯可多级递归。
- **衔接**：步骤①未勾选阶段时左树为空并引导回步骤①；保存后步骤③检测。
- **结束**：保存成功（名称 + 数量填全）；「已核算」前可反复修改（保存即回退重算）。

### 1.2 全局规则说明

#### F03-02 全局规则
**拟标注位置**：步骤②内容区标题附近（与整体流程同一全局说明入口）｜**标记**：已确认

1. **左树仅末级可点**：二级阶段恒为末级；一级阶段无下级阶段时才是末级；非末级为分组态。
2. **统一数据列表**：输入 / 输出合并在同一张表；方向由数据项类型推导（原辅料 / 自然资源 / 能源及能源介质 = 投入，产品 / 中间产品 / 副产品 / 排放物 = 产出）。
3. **默认空白行**：进入可编辑作用域默认保留一行空白数据项；空白行（名称为空）不落库。
4. **必填最小集**：保存校验 = 数据项名称 + 数量；数量可为负（负 = 扣减 / 流出）。
5. **排放来源二选一**：未追溯时可「引用因子」或「继续追溯」；已引用因子后**不可追溯**（仅可更换 / 撤回）；已追溯数据项不再提供因子入口。
6. **投入项因子强制**：投入项未匹配因子 → 检测 B2 阻断（保存不阻断，检测阻断）。
7. **无工序口径**：界面不出现工序 / 工艺流程 / 绑定公式 / 分配比例相关列与入口。
8. **编辑约束**：「已核算」前均可编辑；**「已完成」同样可编辑**（V1.1 确认完成后不锁定，保存即回退重算）；仅「核算中」只读。

### 1.3 业务状态说明

#### F03-03 步骤②可编辑性（由项目状态决定）
**拟标注位置**：步骤②内容区（编辑 / 只读态切换）｜**标记**：已确认

- **可编辑**：进行中 / 检测中 / 待核算 / 核算失败 / 已核算 / **已完成**（保存即回退「进行中」并定位步骤③，需重走检测 → 核算；检测界面默认展示原检测数据，不强制重新检测）。
- **只读**：核算中（及历史报告态）—— 输入框只读、无添加 / 导入 / 删除 / 追溯入口。

### 1.4 操作功能及对应业务规则

#### F03-04 左树（生命周期阶段 / 追溯链路）
**拟标注位置**：步骤②左侧树｜**标记**：已确认

- **结构**：头部「生命周期阶段 / 追溯链路」+「共 N 个阶段」；阶段节点（一级分组态 / 二级可点，叶节点带「N 项」计数）+ 已追溯数据项节点（带「已追溯」Tag，可递归下级）。
- **点击规则**：仅末级阶段可点击（切换右侧作用域）；点击追溯节点进入该上游过程。
- **追溯链路展示**：仅**已追溯**的数据项进左树（未追溯数据项不进入，保持树简洁）；节点挂在其触发数据项下。
- **空态**：「步骤①未勾选生命周期阶段，请先在『目标与范围』配置后再返回建模」。

#### F03-05 数据列表（新增 / 编辑 / 删除）
**拟标注位置**：步骤②右侧「数据列表」表格｜**标记**：已确认

- **工具条**：「数据列表」标题 + 当前作用域提示（「{阶段} · 全部」或「{阶段} / {节点}」）+「导入」「添加数据」「预览模型」按钮。
- **列**：名称（文本框）/ 数据项类型（下拉七类 + 排放物时子类下拉 废水 / 废渣 / 废气）/ 数量（可为负，数值输入）/ 单位（级联选择，取自计量单位库）/ 上游过程名称 / 操作。
- **操作列**：「数据凭证（N）」+「删除」（可编辑态展示）。
- **空态**：「暂无数据项，点击右上角『添加数据』录入或『导入』批量导入」；未选阶段时提示「请先在左侧选择一个生命周期阶段」。
- **删除**：直接移除该行（无二次确认）。

#### F03-06 排放来源：引用因子（弹窗）
**拟标注位置**：「上游过程名称」列「引用因子」、选择排放因子弹窗、因子详情弹窗｜**标记**：已确认

- **操作目的**：为数据项匹配排放因子（投入项必配，产出项选配）。
- **弹窗结构**：左侧库分组（「背景数据库」= 已发布库 /「我的因子库」）+ 右侧因子表（单选列 / 因子名称 / 因子值 / 因子单位[分子/分母] / 操作[查看]）+ 搜索（因子名称 / 编码）。
- **操作过程**：选库 → 单选因子（可点「查看」打开因子详情弹窗）→「确认选择」→ 回显「上游过程名称」列；toast「排放因子已匹配」。
- **更换 / 撤回**：已引用因子显示因子名（点击 = 更换）+ 撤回图标（toast「已撤回因子选择」，恢复「引用因子 / 继续追溯」二选一）。
- **空态**：无库「暂无因子库」；所选库无因子「该库暂无因子」。
- **快照口径**：因子名称 / 因子值 / 因子单位 / 因子口径（GWP 分项）随选择写入项目（引用即复制），因子库后续变更不影响本项目。

#### F03-07 排放来源：继续追溯（上游过程节点）
**拟标注位置**：「上游过程名称」列「继续追溯」、左树节点「取消追溯」｜**标记**：已确认

- **操作过程**：点「继续追溯」→ 以数据项名称为依据生成上游过程节点（需先填写数据项名称，否则 toast「请先填写数据项名称，再继续追溯」）→ 节点进入左树并自动选中，toast「已生成子节点『X』，请录入其数据」→ 在节点作用域内录入其自身数据项（可继续递归追溯）。
- **节点入口**：已追溯数据项的「上游过程名称」列显示节点名 ↗（点击进入该节点）。
- **取消追溯**：左树节点「取消追溯」→ 移除该节点及其全部子节点与已录入数据（不可恢复），toast「节点已删除」。
- **互斥**：已引用因子的数据项不再展示「继续追溯」。

#### F03-08 CSV 导入（弹窗）
**拟标注位置**：「导入」按钮、导入数据弹窗｜**标记**：已确认

- **三步式**：第 1 步「下载模板并填写」（列：名称 / 数据项类型 / 数量 / 单位 / 排放物类型；类型为「排放物」时须填 废水 / 废渣 / 废气）→ 第 2 步「上传文件」（选 CSV）→ 第 3 步「校验结果」（可导入 N 条 · 失败 N 条；失败行列出行号 / 名称 / 失败原因）。
- **校验规则**：名称非空；数据项类型为七类中文枚举之一；数量为数值（可为负）；排放物类型有效。
- **导入范围**：按当前作用域（阶段 / 节点）追加；导入前移除当前作用域下的空白行。
- **结果**：「确认导入（N）」→ 关闭弹窗并追加数据项，toast「已导入 N 条数据项」；文件为空 toast「文件为空或缺少数据行」。

#### F03-09 数据凭证（弹窗）
**拟标注位置**：操作列「数据凭证（N）」｜**标记**：已确认

- **操作目的**：为数据项上传活动数据支撑材料。
- **规则**：**选填、可多个**；操作列展示「数据凭证（N）」；原型以 data URL 本地存储；凭证不参与计算；只读态仅可查看。

#### F03-10 预览模型（流程画布）
**拟标注位置**：「预览模型」按钮、流程画布弹窗｜**标记**：原型已表现·待核对

- **操作目的**：以流程画布形式只读预览已保存的建模数据（输入 / 输出 + 追溯链路）。
- **画布结构**：根卡片 = 纳入的末级生命周期阶段；子卡片 = 「继续追溯」生成的上游过程节点（按父子关系挂靠）；卡片内数据项按类型分输入 / 输出；连线 = 追溯关系（标签 = 触发追溯的数据项名称）。
- **原型表现（待核对）**：「预览模型」在步骤②仅**可编辑态**展示（步骤③④各状态恒显）；画布数据取自已保存数据（未保存的本地编辑不反映）。

#### F03-11 保存（摘要条）
**拟标注位置**：工作台摘要条「保存」｜**标记**：已确认

- **校验**：已填写数据项（名称非空）的**数量必填**；存在未填 → 阻断并 toast「还有 N 条数据项未填写数量」。
- **保存范围**：整表提交阶段数据项 + 过程节点（新增 / 删除在本地完成后一次性提交）。
- **回退**：「待核算 / 核算中 / 核算失败 / 已核算 / 已完成」态保存 → 项目回退「进行中」并定位步骤③（需重走检测 → 核算；**检测界面默认展示原检测数据，不强制重新检测**）；toast「保存成功」。

### 1.5 字段说明

#### F03-12 数据项字段口径
**拟标注位置**：数据列表各列｜**标记**：已确认

- **名称**：数据项标识；必填；空白行不落库。
- **数据项类型**：七类（原辅料 / 自然资源 / 能源及能源介质 / 产品 / 中间产品 / 副产品 / 排放物）；决定投入 / 产出方向与排放源归类；变更类型时排放物子类联动清空。
- **排放物子类**：类型 = 排放物时必填（废水 / 废渣 / 废气）。
- **数量**：每 1 个声明单位的消耗 / 产出量（如「0.062 kg / 双」）；必填；可为负。
- **单位**：用量的计量单位（级联，取自计量单位库）；选填；与因子分母单位的可换算性由检测 B4 负责。
- **上游过程名称**：排放来源列——未追溯时「引用因子 / 继续追溯」二选一；已引用因子显示因子名（可更换 / 撤回）；已追溯显示节点名 ↗。
- **所属阶段 / 节点**：由左树当前作用域决定，落库时写入。
