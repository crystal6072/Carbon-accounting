## 一、页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 生命周期模型配置（工作台步骤② 内容区） |
| 页面目标 | 确认纳入哪些生命周期阶段、把核算工序归入对应阶段，形成可核算的生命周期模型 |
| 承载容器 | 项目工作台内容区（顶部步骤条高亮第②步） |
| 骨架结构 | 页头动作（保存）→ 两个分组面板 + 底部说明 |

```text
① 生命周期阶段   （按行业 + 边界加载 · 启用 / 排除 + 排除原因）
② 核算工序       （引用即复制自产品 · 工艺分组 · 指定所属阶段 · 投入产出流只读）
```

## 二、区域与控件规格

### 2.1 生命周期阶段面板

| 项目 | 规格 |
| :--- | :--- |
| 面板标题 | 生命周期阶段 |
| 标题右侧提示 | 按「产品所属行业 + 核算边界」从阶段库加载 |
| 列表形态 | 紧凑行列表（带边框圆角容器）；**一级阶段缩进 0，二级阶段缩进一档** |
| 行内容 | 勾选框 + 阶段名称 + 三态 `Tag` +（被排除且可选纳入时）排除原因输入框 |
| 勾选框 | 「必须纳入」阶段**禁用且固定勾选**；「可选纳入 / 不纳入」可切换 |
| 三态 Tag | 必须纳入 = 蓝（info）· 可选纳入 = 灰（default）· 不纳入 = 灰（default） |
| 未启用行样式 | 阶段名称置灰 |
| 排除原因输入框 | 仅在「可选纳入 + 未勾选」时出现；宽度 220px；未填时红框提示 |
| 只读态 | 勾选框禁用、原因输入框 `readOnly` |
| 空状态 | 「当前行业与边界下暂无适用阶段」 |

### 2.2 核算工序面板

| 项目 | 规格 |
| :--- | :--- |
| 面板标题 | 核算工序 |
| 标题右侧提示 | 引用即复制自产品工艺；每道工序需指定所属生命周期阶段 |
| 分组 | 按**工艺流程**分组，组标题为 `工艺流程名称（编码）` |
| 表格列 | `#`（工序顺序）· 核算工序 · 所属生命周期阶段 · 投入 / 产出 |
| 「所属生命周期阶段」列 | `Select`；**候选 = 项目内已启用的二级阶段**；未指定时红框；只读态显示阶段名称文本 |
| 「投入 / 产出」列 | 只读两行小字：`投入：名称 数量单位、…` / `产出：…`；无数据显示 `-` |
| 空状态 | 「所选产品暂无工艺 / 工序，请到「产品信息库」完善产品或重新选择产品」 |
| 只读态 | 阶段列显示文本，无选择入口 |

### 2.3 底部说明

| 位置 | 内容 |
| :--- | :--- |
| 面板下方提示条 | 工序与投入产出流已按「引用即复制」从产品复制到本项目；产品库后续变更不影响本项目 |

### 2.4 页头动作（工作台摘要条右侧）

| 元素 | 规格 |
| :--- | :--- |
| 保存 | Primary；仅步骤② 可编辑时展示 |
| 只读态 | 不渲染保存按钮 |

## 三、校验与错误展示

| 检查 | 触发时机 | 失败反馈 |
| :--- | :--- | :--- |
| 必须纳入阶段被排除 | 保存 | Toast：「「{阶段名}」为必须纳入阶段，不可排除」 |
| 可选纳入阶段排除未填原因 | 保存 | Toast：「排除「{阶段名}」时请填写排除原因」；输入框红框 |
| 工序未指定阶段 | 保存 | Toast：「工序「{工序名}」未指定所属生命周期阶段」；该行下拉红框 |
| 至少 1 个二级阶段启用 | 保存 | Toast：「请至少启用一个生命周期阶段」（服务端兜底） |

> 校验策略：**前端先提示、服务端兜底**（`updatePcfProjectLifecycle` 二次校验同样口径）。

## 四、反馈文案

| 操作 | 反馈 | 文案 |
| :--- | :--- | :--- |
| 保存成功 | Toast | 保存成功 |

## 五、Mock 数据规格

| 要求 | 说明 |
| :--- | :--- |
| 阶段来源 | 复用生命周期阶段种子（`lifecycleSeed`）：含木竹基线（种植与培育 / 碳化处理 / 生物碳释放）+ 通用基线；覆盖三态 |
| 阶段筛选 | `applicableLibraryStages(行业, 边界)`：仅启用态、非「不纳入」、行业匹配或全行业 |
| 工序来源 | 从 `productSeed` 中对应产品的 `processes` 复制（含投入产出流） |
| 产品样本 | 至少 1 个产品含多道工序（240mm 全竹碳化筷：断料 / 碳化 / 打磨成型），覆盖投入产出流多种流类型 |
| 空样本 | 至少 1 个产品无工序（用于验证空状态） |
| 阶段分配 | 初始为空（需用户指定），验证 R-030 |
| 数据要求 | 全部虚构演示数据 |
