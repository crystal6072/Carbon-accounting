## 一、拟添加的批注清单

### 1.1 整体流程
- **B-SA-01 分析单生命周期**：列表「新增敏感性分析」→ 选已核算项目（仅「已核算」可创建）→ 详情（基准自动带出）→「+ 新增敏感性分析情景」→ 行内「编辑情景数据」→ 右侧抽屉改数量 →「核算碳足迹」回填结果与变化率 → 情景对比表。删除分析单联动删除全部情景。
- **B-SA-02 入口约束**：敏感性分析仅可基于「已核算」项目创建；无已核算项目时新增弹窗 `Select` 禁用并 `Alert` 提示，不得创建。

### 1.2 全局规则
- **B-SA-G01 状态机**：分析状态 = 未完成 / 待更新 / 已完成。（1）有任一已核算情景即「未完成」；（2）来源核算项目发生重新核算、基准版本变化时转「待更新」，结论可能失效；（3）来源已删除时分析单置灰并标记「来源已删除」，仅保留查看与删除。
- **B-SA-G02 口径切换联动**：详情「评价指标」下拉（四口径：总量 / 化石 / 生物源 / 土地利用；仅基准结果含 GWP 分项时渲染为下拉，否则只读单值）切换后，基准卡、情景表、对比表的数值与变化率全部按所选口径重新呈现，原变更集不变。
- **B-SA-G03 变化率口径**：变化率 = (情景碳足迹 − 基准碳足迹) / 基准碳足迹 × 100，保留 1 位小数；基准为 0 时置 `null` 展示 `-`；强度条按 `|Δ| ÷ 本组最大 |Δ|` 归一化到 0~100。

### 1.3 操作功能及业务规则
- **B-SA-03 列表查询与表格**：筛选含核算项目 / 产品名称 / 分析状态；表格列 = 序号 / 核算项目（进详情）/ 产品名称 / 基准碳足迹结果 / 分析结果更新时间 / 分析状态（Tag）/ 操作（查看 / 删除）；默认按更新时间倒序；整行点进详情。
- **B-SA-04 新增分析弹窗**：`Dialog` 选「已核算」项目，选中后 `Descriptions` 预览产品名称 / 系统边界 / 声明单位 / 统计时间 / 基准结果（含版本）/ 核算时间；确定后跳转详情，基准清单自动复制并锁定基准版本。
- **B-SA-05 删除分析单**：`Popconfirm`「删除分析单将同时删除全部情景，不影响来源核算项目，删除后不可恢复。确认删除？」，二次确认 `Dialog`「确认删除」(`theme=danger`)。
- **B-SA-06 基准情景卡**：情景描述为 `Textarea`（500 字，失焦自动保存，保存后重新拉取详情以刷新分析状态）；碳足迹结果为 `Statistic`（大数字 + `kgCO₂e`）；结果元信息 = 结果版本 `V{n}` · 核算时间 · 结果单位。
- **B-SA-07 变更情景卡**：「变更情景」卡右上角 `Button variant="dashed"`「+ 新增敏感性分析情景」追加一行（描述空、结果 `-`、状态「未核算」），分析状态转「未完成」；情景表列 = 情景 / 情景描述（行内 `Textarea` 失焦保存）/ 变更项数 / 碳足迹结果 / 变化率（文字 + `Progress` 强度条）/ 核算状态（Tag）/ 关键敏感项（`★ 关键敏感项` `Tag theme=danger` + `Tooltip`）/ 操作（编辑情景数据 / 删除 `Popconfirm`）；待更新态下不渲染新增按钮与各行操作，动作区改人话提示「来源数据已更新，请先更新基准」。
- **B-SA-08 情景对比卡**：存在 ≥1 已核算情景时渲染，按 `|变化率|` 降序；关键敏感项（`keySensitive=true`）以 `Tag theme=danger`「★ 关键敏感项」标注；基准不计入排序。
- **B-SA-09 填写情景数据抽屉**：`Drawer`（960px），一级阶段 `Tabs` + 二级阶段 `RadioGroup`（多个二级时渲染）+ 左 `Tree`（搜索同源过滤，全部 → 一级 → 二级 → 过程 → 数据项）+ 右 `Table`（流名称 / 基准情景数量（只读）/ 情景数量（`InputNumber`，`decimalPlaces=4`，placeholder「继承基准」）/ 差值 / 单位 / 上游过程名称）；底部固定「取消」+「核算碳足迹」（约 900ms loading，回填结果与变化率）；情景数量 ≠ 基准时该行加粗并展示差值；清空 = 继承基准、不进入变更集。
- **B-SA-10 导出对比**：详情页头「导出对比」（`theme=outline`，无已核算情景时禁用）以 **CSV** 落地（Excel 后置）；导出当前基准 + 全部情景的对比结果。
- **B-SA-11 待更新与更新基准**：待更新态通栏 `Alert theme=warning`「来源核算数据已更新（基准版本 V{n} → V{m}），当前结论可能失效。」+「更新基准」(`theme=primary size=small`)；二次确认 `Dialog`「更新基准将同步最新核算结果并清空全部情景结果，需重新核算。确认更新？」；确认后基准刷新、全部情景结果清空、状态回「未完成」、`MessagePlugin.success('基准已更新，请重新核算各情景')`；来源已删除时按钮禁用 + `Tooltip`「来源核算项目已删除，无法更新基准」。

### 1.4 字段说明
- **B-SA-F01 分析编号**：`PCF-SA-YYYYMMDDNNN`，创建时由系统生成。
- **B-SA-F02 核算项目**：来自来源已核算项目；来源已删除时置灰 + 后缀 `Tag`「来源已删除」。
- **B-SA-F03 关键敏感项**：`refreshKeySensitive` 规则——`|Δ|` 最大的已核算情景置 `keySensitive=true`；用于标记对结果影响最大的单一情景。
- **B-SA-F04 变化率**：见全局规则 **B-SA-G03**；未核算与基准为 0 时展示 `-`。
- **B-SA-F05 情景描述**：`maxlength=500`，失焦保存；为空时阻断核算（`MessagePlugin.error('请填写情景描述')`）。
