# 敏感性分析字段清单

> **文档定位**：敏感性分析模块的**字段真相源**（SST）。定义敏感性分析、基准情景、基准清单快照、变更情景、情景变更集、情景结果六类对象的字段结构、枚举与字段级约束。业务规则（状态机、动作矩阵、重算口径）见《敏感性分析业务PRD》，页面呈现见《敏感性分析_Demo》（待产出）。

> **【口径对齐声明 · 2026-10-14】**
> - **引擎口径**：情景重算与核算主链**同一引擎**（行级 `数量 × 单位换算系数 × 排放因子` → 阶段 `SUM` → 全局 `SUM`），口径见《碳足迹核算字段清单》（V0.6）§1.1；本清单**不重复定义**引擎变量。
> - **四口径**：沿用 `total` 总量（不含生物源CO₂）/ `fossil` 化石 / `biogenic` 生物源 / `luluc` 直接土地利用变化（`PCF_CALIBERS`），见《碳足迹核算字段清单》§1.2。
> - **数据源字段**：基准清单快照**复制**核算项目步骤②「阶段数据项」（《核算项目字段清单》§6.1，含因子快照 `factorValue` / `factorCalibers`），引用即复制、与主链解耦。
> - **无「核算模型」维度**：列表首列口径为「核算项目」（核算模型已废弃，见骨架 V1.2）。

> **文档定位补充**：字段名保持英文原文（`camelCase`），中文为业务名称；业务 PRD 与 Demo PRD 只引用字段名称，不重复维护枚举与必填性。

## 1. 对象结构

### 1.1 关系全景

```text
敏感性分析（SensitivityAnalysis） 1
   ├── 1  基准情景（BaselineScenario）
   │        └── N 基准清单快照（BaselineScenarioItem）   ← 创建时复制核算项目数据项
   └── N  变更情景（Scenario）
            ├── N 情景变更集（ScenarioItem）              ← 数据项级：基准数量 / 情景数量
            └── 1 情景结果（ScenarioResult）               ← 1:1 内嵌：碳足迹四口径 + 变化率
```

| 结构 | 对象 | 与主对象关系 | 唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主对象 | 敏感性分析 | 主对象 | 分析编号（`PCF-SA-YYYYMMDDNNN`） | 本清单定义范围 |
| 子对象 · 基准情景 | 基准情景 | 1:1 | 分析编号 | 创建分析时生成，只读（描述可编辑） |
| 子对象 · 基准清单快照 | 基准数据项 | 1:N | 分析编号 + 数据项 id | 复制核算项目步骤②阶段数据项 |
| 子对象 · 变更情景 | 变更情景 | 1:N | 分析编号 + 情景 id | 用户新增 / 删除 |
| 子对象 · 情景变更集 | 情景变更行 | 1:N | 情景 id + 数据项 id | 只存「有变更」的数据项 |
| 子对象 · 情景结果 | 情景结果 | 1:1（内嵌情景） | 情景 id | 重算产出，可被覆盖 |
| 关联对象（只读） | 核算项目 | N:1 | 项目编号 | 来源，只读引用、不写回 |

> **关系说明**：敏感性分析 : 核算项目 = **N:1**（一个已核算项目可建多个分析单，如按不同假设各建一个）；分析单 : 变更情景 = **1:N**；变更情景 : 基准数据项 = **N:1**（每个情景都是对同一份基准清单的局部变量）。

### 1.2 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | 用户填写（描述 / 情景数量）+ 系统生成（编号 / 状态 / 结果 / 变化率）+ 系统带出（基准清单 / 基准结果，来自核算项目） |
| 外部系统数据源 | 否 |
| 新增编辑 | 新增 = 选择已核算项目创建；编辑 = 描述与情景数量（基准结果、基准清单、情景结果均不可直接编辑） |
| 子表 | 基准清单（创建时一次性复制）、变更情景（增删）、情景变更集（改数时维护）、情景结果（重算时覆盖） |
| 导入导出 | 本期**不做导入**；导出「情景对比」（Excel，P1） |
| 状态与执行 | 分析状态机（未完成 / 待更新 / 已完成）+ 情景核算（点「核算碳足迹」触发重算） |
| 关键唯一键 | 分析编号（全局唯一） |
| 历史兼容 | 无历史数据 |

### 1.3 关键数据约束

| 约束ID | 约束 | 影响对象 |
| :--- | :--- | :--- |
| D01 | 分析编号系统生成、全局唯一、**不可修改** | 主对象 |
| D02 | **一分析一基准**：每个分析单有且仅有 1 个基准情景，不可新增 / 删除 | 基准情景 |
| D03 | 基准情景**只读**（仅 `description` 可编辑）；创建后**不随主链自动改写**，主链新版本只触发状态置「待更新」（R-078） | 基准情景 |
| D04 | 基准清单**引用即复制**：创建时从核算项目复制数据项与因子快照；因子库 / 项目后续变化**不影响**已创建分析 | 基准清单快照 |
| D05 | 情景变更**仅限数据项数量**：不可新增 / 删除数据项、不可更换因子、不可增删阶段；未变更数据项继承基准数量 | 情景变更集 |
| D06 | 情景数量为数值、**可为负**；留空 = 继承基准 | 情景变更集 |
| D07 | 情景结果由系统重算产出、**不可手工编辑**；重复核算以当前变更集**覆盖**（R-075） | 情景结果 |
| D08 | 删除分析单**不影响**来源核算项目与报告；来源项目被删不影响本分析（基准为快照） | 主对象 |

| 字段名称 | 英文名 | 类型 | 来源 | 必填 | 字段说明 | 备注 |
| :--- | :--- | :--- | :--- | :---: | :--- | :--- |
| 所属情景 | `scenarioId` | string | 系统 | 是 | 所属情景 id | — |
| 数据项 id | `dataItemId` | string | 用户选择（行） | 是 | 指向基准清单行 | 外键 = §4 `dataItemId` |
| 基准数量 | `baselineQty` | number | 系统（快照） | 是 | 基准情景数量 | 只读快照，便于对比展示 |
| 情景数量 | `scenarioQty` | number | 用户填写 | 是 | 该情景下的单位产品用量，可为负 | 留空 = 视为继承基准、该行不落库 |
| 数量变化量 | `qtyDelta` | number | 系统 | 否 | `scenarioQty − baselineQty` | 派生（P1 提示用） |
| 数量变化率 | `qtyDeltaRate` | number | 系统 | 否 | `(scenarioQty − baselineQty) / baselineQty × 100%` | 派生（P1）；基准为 0 时为空 |

> 变更集与基准清单的差异即「情景假设」。若某数据项 `scenarioQty = baselineQty`，视为未变更、不落库。

## 7. 情景结果（ScenarioResult）

> 情景重算产出，1:1 内嵌于变更情景；**不可手工编辑**，重复核算覆盖（D07）。

| 字段名称 | 英文名 | 类型 | 来源 | 必填 | 字段说明 | 备注 |
| :--- | :--- | :--- | :--- | :---: | :--- | :--- |
| 所属情景 | `scenarioId` | string | 系统 | 是 | 所属情景 id | — |
| 结果单位 | `unit` | string | 系统 | 是 | 结果表达单位 | 取核算项目「单位」 |
| 碳足迹结果 | `emission` | number | 系统 | 是 | 情景碳足迹值（kgCO₂e / 声明单位） | 全局 SUM 结果 |
| 口径结果 | `emissionBreakdown` | `CaliberValues` | 系统 | 是 | 四口径情景值 | 见 §3.2 |
| 变化率 | `deltaRate` | number | 系统 | 是 | `(情景结果 − 基准结果) ÷ 基准结果 × 100%` | 保留 1 位小数；基准为 0 时为空（显示「—」） |
| 变化率展示 | `deltaRateText` | string | 系统 | 是 | 带符号文本，如「+10.2%」 | 基准为 0 时 = 「—」 |
| 核算时间 | `calculatedAt` | string | 系统 | 是 | 本次重算完成时间 | `YYYY-MM-DD HH:mm` |

> **口径结果结构（`CaliberValues`）**：`{ total, fossil, biogenic, luluc }`，与《碳足迹核算字段清单》§1.2 完全一致；无 GWP 分项时按核算 PRD §6.3「只有总值」兜底（化石 = 总量、生物源与土地利用 = 0）。

## 9. 计算、联动与回写口径

| 规则ID | 触发 | 输入字段/来源 | 计算或联动规则 | 影响字段 | 重算/覆盖方式 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| C01 | 新增分析（选已核算项目） | 核算项目最近核算结果 + 阶段数据项 | 生成分析编号；带出头部元信息；锁定 `baselineVersion` / `baselineEmission`；复制基准清单快照；生成 1 个基准情景（描述空） | 主对象 + 基准情景 + 基准清单 | 初始化 |
| C02 | 填写基准情景描述 | `description` | 保存；描述非空视为基准就绪 | 基准情景 | 保存 |
| C03 | 新增情景 | — | 生成变更情景，`seq` 递增、`calcStatus = notCalc`、结果为空；分析状态置「未完成」 | 变更情景 + 分析状态 | 新增 |
| C04 | 修改情景数量 | 数据项 `scenarioQty` | 与 `baselineQty` 不同的行写入变更集（`scenarioQty` / `qtyDelta` / `qtyDeltaRate`）；该情景 `calcStatus` 置 `notCalc`；分析状态置「未完成」 | 情景变更集 + 状态 | 覆盖 |
| C05 | 点「核算碳足迹」 | 基准清单 + 变更集 | 按引擎口径重算：变更项取 `scenarioQty`、其余取 `baselineQty` → 行级 → 阶段 SUM → 全局 SUM；输出四口径；计算 `deltaRate` = `(情景结果 − 基准结果) / 基准结果 × 100%` | 情景结果 + `resultUpdatedAt` | 覆盖（R-075 幂等） |
| C06 | 情景全部核算完成 | 各情景 `calcStatus` | 全部 = `calculated` → 分析状态置「已完成」；存在斜杠未核算 → 保持「未完成」 | 分析状态 | 派生 |
| C07 | 情景数量清空 | `scenarioQty` | 该行从变更集移除（视为继承基准） | 情景变更集 | 移除 |
| C08 | 删除情景 | — | 移除情景 + 变更集 + 结果；`seq` 重排；分析状态按 C06 重算 | 变更情景 + 分析状态 | 删除 |
| C09 | 来源项目产生新核算版本 | 核算项目 `version` / `calculatedAt` | 若新版本 ≠ `baselineVersion` → 分析状态置「待更新」；收起情景编辑入口 | 分析状态 | 状态置位 |
| C10 | 更新基准 | 核算项目新结果 + 阶段数据项 | 同步 `baselineVersion` / `baselineEmission` / 基准清单；**清空全部情景变更集与结果**（`calcStatus = notCalc`）；分析状态回「未完成」；基准情景 `description` 保留 | 基准情景 + 基准清单 + 变更情景 | 覆盖 |

### 12.2 术语表

| 术语 | 含义 |
| :--- | :--- |
| 基准情景 | 创建分析时锁定的核算结果版本与其数据清单，只读 |
| 基准清单快照 | 创建时复制的核算项目阶段数据项集合，作为情景编辑与重算的输入 |
| 情景变更集 | 情景中「有变更」的数据项集合（仅存变更行） |

| 待更新 | 来源核算项目产生新核算版本后，分析结论可能失效的状态 |
