## 一、拟添加的批注清单

### 1.1 整体流程
- **B-DQ-01 评价单生命周期**：列表「新增数据质量评价」→ 选已核算项目 → 详情（步骤① 定性 9 项自动初稿，编辑模式）→「下一步」确认定性 → 步骤② 定量（勾选 + 批量评估 / 行内评价，评分弹窗四项打分）→「下一步」生成结果 → 步骤③ 结果（定性 + 定量摘要与明细 + 导出）；列表「查看」→ 只读模式自由浏览。删除评价单联动移除全部评分。
- **B-DQ-02 入口约束**：数据质量评价仅可基于「已核算」项目创建；无已核算项目时新增弹窗 `Select` 禁用并 `Alert` 提示。

### 1.2 全局规则
- **B-DQ-G01 状态机**：评价状态 = 未完成 / 待更新 / 已完成。（1）步骤② 存在未评分项时为「未完成」；（2）来源核算项目重新核算、基准版本变化时转「待更新」，结论可能失效；（3）进入步骤③ 后整体 DQR 按 C08 派生为「已完成」。
- **B-DQ-G02 口径切换联动**：详情「评价指标」下拉（四口径；仅基准结果含 GWP 分项时渲染为下拉，否则只读单值）切换后，数据项排放量与贡献率按新口径重算，步骤③ 摘要与明细随之刷新（`switchCaliber`）；**评分与 DQR 分值不随口径变化**（DQR 基于数据项评分）。
- **B-DQ-G03 DQR 计算口径**：单项 DQR = (TiR + TeR + GeR + C) / 4，保留 1 位小数，按业务 PRD §6.2 映射等级（优 / 良 / 中 / 差）；单项不确定度 = `sqrt(Σ u_dim(s)²)`（系数 3% / 8% / 15% / 30% / 60%）；整体 DQR = `Σ(w_i × dqr)`（`w_i` = 贡献率小数，`Σw_i=0` 时退化为算术平均）；整体不确定度 = `sqrt(Σ(w_i × uncertainty)²)`。

### 1.3 操作功能及业务规则
- **B-DQ-03 列表查询与表格**：筛选含核算项目 / 产品名称 / 评价状态；表格列 = 序号 / 核算项目（进详情，默认编辑模式）/ 产品名称 / 评价结果更新时间 / 评价状态（Tag）/ 操作（查看 `?mode=view` / 编辑 / 删除 `Popconfirm`）；默认按更新时间倒序；整行点进详情。
- **B-DQ-04 新增评价弹窗**：`Dialog` 选「已核算」项目，选中后 `Descriptions` 预览产品名称 / 系统边界 / 声明单位 / 统计时间 / 基准碳足迹结果（含版本）；确定后跳转详情，自动复制数据清单并生成定性初稿。
- **B-DQ-05 删除评价单**：`Popconfirm`「删除数据质量评价将同时移除全部评分，不影响来源核算项目，删除后不可恢复。确认删除？」，确认按钮「确认删除」(`theme=danger`)；只读角色不渲染该操作。
- **B-DQ-06 三步向导与口径条**：步骤条 = ① 定性 / ② 定量 / ③ 结果；口径条含「影响评价方法」(只读带出) 与「评价指标」(四口径切换，联动步骤③)；编辑模式仅允许回看已完成步骤，查看模式可点任意步骤。
- **B-DQ-07 步骤① 定性 9 项**：`Card` 内 9 项 `Textarea`（时间 / 地理 / 技术覆盖范围、完整性、代表性、一致性、再现性、数据来源、信息的不确定性）；前 3 项由统计时间 + 因子库 + 因子 `region` 去重拼接生成初稿，后 6 项默认文案；全部可编辑，查看 / 待更新态 `disabled`；「下一步」无前置（三项选填），点击写入 `confirmed=true`。
- **B-DQ-08 步骤② 定量与评分弹窗**：顶部「跳过定量评价」`Checkbox`（勾选后 `Alert`，「下一步」放行直达步骤③）；批量工具栏（已选 N / 共 M + 清除选择 + 批量评估）；数据项表格带多选勾选列（行内 `Link`「评价 / 重新评价」打开评分弹窗）；评分弹窗（`Dialog` width=860）：指标列（TiR / TeR / GeR / C 四项，分档色 1 绿 / 2 青 / 3 蓝 / 4 橙 / 5 红，点击整格选中）+ 评分依据 `Descriptions`（生命周期阶段 / 统计数据来源 / 数据凭证 / 排放因子来源）+ 实时预览（当前 DQR / 等级 / 不确定度）+「确定」批量保存；批量 = 勾选后弹窗逐项打分（**不自动打分**）。
- **B-DQ-09 步骤③ 结果**：只读呈现（定性 9 项斑马纹列表 + 定量摘要条 + 明细表 + 分页）；未评分时顶部 `Alert theme=warning`「尚未进行任何定量数据质量评价，以下结果仅基于定性覆盖范围说明，未计算 DQR 与不确定度。」；明细表列 = 序号 / 生命周期二级阶段 / 数据名称 / 排放量(kgCO₂e) / 贡献率 / 数据质量 DQR（`{分值} · {等级 Tag}`，未评价显示「未评价」）；底部「导出结果」以 **CSV** 落地（P1）。
- **B-DQ-10 待更新与更新基准**：待更新态通栏 `Alert theme=warning`「来源核算数据已更新（基准版本 V{n} → V{m}），当前评价结论可能失效。」+「更新基准」(`theme=primary size=small`)；二次确认 `Dialog`「更新基准将同步最新核算结果并清空全部评分，需重新评估。确认更新？」；确认后清单刷新、全部评分清空、状态回「未完成」、`MessagePlugin.success('基准已更新')`；动作限制下不渲染步骤② 批量工具栏 / 跳过勾选 / 单项评价入口与步骤①「下一步」，仅保留「更新基准」与查看 / 导出。
- **B-DQ-11 查看 / 编辑双模式**：列表「查看」→ `/report/quality/:id?mode=view` 只读（页头「仅查看」Tag，编辑入口收起，步骤自由浏览，评分弹窗控件禁用无「确定」）；「编辑」/ 新建后进入全功能编辑模式；页面模式不影响评价状态与数据。

### 1.4 字段说明
- **B-DQ-F01 评价编号**：`PCF-DQ-YYYYMMDDNNN`，创建时由系统生成。
- **B-DQ-F02 核算项目**：来自来源已核算项目；来源已删除时更新基准按钮禁用 + `Tooltip`「来源核算项目已删除，无法更新基准」。
- **B-DQ-F03 四项评分（TiR/TeR/GeR/C）**：1–5 分判定标准矩阵（常驻全文，选中格分档色实底白字加粗）；取值由 `RadioGroup` 天然限制为 1–5，无自由输入。
- **B-DQ-F04 数据质量 DQR**：单项 / 整体均展示 `{分值} · {等级 Tag}`，未评价显示「未评价」；见全局规则 **B-DQ-G03**。
- **B-DQ-F05 定量前提**：进入步骤③ 前置为「全部数据项已评分」；否则阻断并 `MessagePlugin.warning('还有 {N} 项数据未评估')`；勾选「跳过定量评价」时放行（仅留定性说明）。
