# 数据质量评价字段清单

> **文档定位**：数据质量评价模块的**字段真相源**（SST）。定义数据质量评价、定性覆盖范围、评价数据项、谱系评分、评价结果五类对象的字段结构、枚举与字段级约束。业务规则（状态机、动作矩阵、DQR 计算口径）见《数据质量评价业务PRD》，页面呈现见《数据质量评价_Demo》（待产出）。

> **【口径对齐声明 · 2026-10-14】**
> - **评价范围**：复制核算项目步骤②「阶段数据项」（《核算项目字段清单》§6.1，含因子快照 `factorValue` / `factorCalibers` / `factorUnit` / 背景数据来源 / 数据凭证），**引用即复制**、与主链解耦。
> - **四口径**：沿用 `total` 总量（不含生物源CO₂）/ `fossil` 化石 / `biogenic` 生物源 / `luluc` 直接土地利用变化（`PCF_CALIBERS`），见《碳足迹核算字段清单》§1.2；用于**头部指标切换**，切换时按口径重算数据项排放与贡献率并刷新结果页（业务 PRD R-102）。
> - **无「核算模型」维度**：列表首列口径为「核算项目」（核算模型已废弃，见骨架 V1.2）。
> - **因子级 DQR 不回归**：因子字段清单 V0.4 已移除因子级 DQR；本模块 DQR 承载点为**数据项级**（谱系评分，含因子背景质量），不写回因子主数据（业务 PRD §1.3 / §9 Q6）。
>
> **【评分口径修订声明 · 2026-10-19】**
> - **谱系评分由五维收紧为竞品四项**：`temporal` 时间代表性 TiR / `technological` 技术代表性 TeR / `geographical` 地理代表性 GeR / `completeness` 完整性 C（各 1–5 分，判定标准见业务 PRD §6.1）。
> - **定性覆盖范围由 3 项扩为 9 项**：新增 完整性 / 代表性 / 一致性 / 再现性 / 数据来源 / 信息的不确定性（各 ≤500 字长文本）。
> - **评分方式**：弹窗评分会话（单项 / 勾选批量），不再有默认口径自动打分；批量评分经「确定」逐项提交。
> - **公式修正**：整体 DQR 与整体不确定度的加权权重一律为贡献率**小数**（`Σ w_i = 1`），禁止使用百分点。
> - **页面模式**：列表「查看」= 只读模式（`?mode=view`），「编辑」= 完整模式；本清单为字段口径，页面模式规则见业务 PRD R-101。

> **文档定位补充**：字段名保持英文原文（`camelCase`），中文为业务名称；业务 PRD 与 Demo PRD 只引用字段名称，不重复维护枚举与必填性。

## 1. 对象结构

### 1.1 关系全景

```text
数据质量评价（DataQualityAssessment） 1
   ├── 1  定性覆盖范围（QualitativeAssessment）      ← 9 项定性描述 + 确认
   ├── N  评价数据项（AssessmentItem）                ← 创建时复制核算项目阶段数据项
   │        ├── 1 谱系评分（PedigreeScore）           ← 四项分数（1–5）+ 评分来源
   │        └── 1 数据项结果（ItemResult）            ← DQR 分值 / 等级 / 不确定度（派生，内嵌）
   └── 1  评价结果（AssessmentResult）                ← 整体 DQR / 等级 / 不确定度 / 分布 / 结论
```

| 结构 | 对象 | 与主对象关系 | 唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主对象 | 数据质量评价 | 主对象 | 评价编号（`PCF-DQ-YYYYMMDDNNN`） | 本清单定义范围 |
| 子对象 · 定性 | 定性覆盖范围 | 1:1 | 评价编号 | 创建时生成，9 项描述可编辑、可确认 |
| 子对象 · 数据项 | 评价数据项 | 1:N | 评价编号 + 数据项 id | 复制核算项目步骤②阶段数据项 |
| 子对象 · 评分 | 谱系评分 | 1:1（内嵌数据项） | 数据项 id | 四项分数（1–5） |
| 子对象 · 结果 | 评价结果 | 1:1（内嵌主对象） | 评价编号 | 综合结果，派生生成 |
| 关联对象（只读） | 核算项目 | N:1 | 项目编号 | 来源，只读引用、不写回 |

> **关系说明**：数据质量评价 : 核算项目 = **N:1**（一个已核算项目可建多个评价单，如按不同评分口径各建一个）；评价单 : 评价数据项 = **1:N**；评价数据项 : 谱系评分 = **1:1**。

### 1.2 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | 用户填写（定性描述 / 四项评分 / 结论文案）+ 系统生成（编号 / 状态 / DQR / 不确定度 / 分布）+ 系统带出（数据清单、头部口径，来自核算项目） |
| 外部系统数据源 | 否 |
| 新增编辑 | 新增 = 选择已核算项目创建（进入编辑模式）；编辑 = 定性描述 9 项、四项评分、结论文案（DQR 结果均不可直接编辑）；查看模式（`?mode=view`）为只读 |
| 子表 | 评价数据项（创建时一次性复制）、谱系评分（评分时维护）、评价结果（评分变化时重算） |
| 导入导出 | 本期**不做导入**；导出「数据质量评价结果」（Excel，P1） |
| 状态与执行 | 评价状态机（未完成 / 待更新 / 已完成）+ 三步向导（定性 → 定量 → 结果） |
| 关键唯一键 | 评价编号（全局唯一） |
| 历史兼容 | 无历史数据 |

### 1.3 关键数据约束

| 约束ID | 约束 | 影响对象 |
| :--- | :--- | :--- |
| D01 | 评价编号系统生成、全局唯一、**不可修改** | 主对象 |
| D02 | **一评价一定性**：每个评价单有且仅有 1 个定性覆盖范围对象，不可新增 / 删除 | 定性覆盖范围 |
| D03 | 定性覆盖范围描述**可编辑**；创建时由系统按数据清单生成初稿；确认后记录确认人 / 时间 | 定性覆盖范围 |
| D04 | 评价清单**引用即复制**：创建时从核算项目复制数据项与因子快照；主链后续变化**不影响**已创建评价（仅按 D09 转「待更新」） | 评价数据项 |
| D05 | 评价范围 = 参与核算结果的**全部数据项**（含追溯节点内数据项）；**不可增删数据项**（范围由来源项目决定） | 评价数据项 |
| D06 | 谱系评分四项取值**均为 1–5 整数**，无缺省（未评分时该数据项不计入整体结果） | 谱系评分 |
| D07 | DQR 分值 / 等级 / 不确定度由评分**派生**、**不可手工编辑**；评分变更后结果自动刷新 | 谱系评分 / 评价结果 |
| D08 | 删除评价单**不影响**来源核算项目与报告；来源项目被删不影响本评价（清单为快照） | 主对象 |
| D09 | 来源核算项目产生**新核算结果版本** → 评价状态置「待更新」；「更新基准」后**清空全部评分** | 主对象 / 评价数据项 |
| D10 | 结论文案可编辑、**选填**；未编辑时保留系统默认结论文案 | 评价结果 |
| D11 | 评价结果同时记录**各数据项贡献率**（来自核算结果明细），整体 DQR 与不确定度按贡献率加权；总排放为 0 时退化算术平均 | 评价结果 |

## 3. 定性覆盖范围（QualitativeAssessment）

> 创建评价时生成，1:1 于主对象；9 项描述均可编辑、可确认（D02 / D03）；前 3 项系统生成初稿，后 6 项为默认文案，用户可改写；每项 ≤500 字。

| 字段名称 | 英文名 | 类型 | 来源 | 必填 | 字段说明 | 备注 |
| :--- | :--- | :--- | :--- | :---: | :--- | :--- |
| 所属评价 | `assessmentId` | string | 系统 | 是 | 所属评价单 id | — |
| 时间覆盖范围 | `temporalCoverage` | string（长文本） | 系统初稿 / 用户编辑 | 否 | 数据的时间代表性说明 | 初稿由统计时间 + 因子时间边界生成；≤500 字 |
| 地理覆盖范围 | `geographicalCoverage` | string（长文本） | 系统初稿 / 用户编辑 | 否 | 数据的地理代表性说明 | 初稿由活动数据地域 + 因子 `region` 生成；≤500 字 |
| 技术覆盖范围 | `technologicalCoverage` | string（长文本） | 系统初稿 / 用户编辑 | 否 | 数据的技术代表性说明 | 初稿默认为「采集数据均代表当前技术水平」；≤500 字 |
| 完整性 | `completeness` | string（长文本） | 系统默认 / 用户编辑 | 否 | 生命周期范围内单元过程覆盖情况说明 | 默认「生命周期范围内所有单元过程均已涵盖，排除的数据低于5%。」 |
| 代表性 | `representativeness` | string（长文本） | 系统默认 / 用户编辑 | 否 | 数据集对实际关注对象的代表程度说明 | 默认「参见上述时间、地理及技术覆盖范围。」 |
| 一致性 | `consistency` | string（长文本） | 系统默认 / 用户编辑 | 否 | 研究方法学统一应用说明 | 默认「研究方法在分析的各个部分均统一应用。」 |
| 再现性 | `reproducibility` | string（长文本） | 系统默认 / 用户编辑 | 否 | 相同方法复现结果的说明 | 默认「基于相同方法可复现研究结果。」 |
| 数据来源 | `dataSource` | string（长文本） | 系统默认 / 用户编辑 | 否 | 数据的来源与获取方式说明 | 默认「原材料消耗、运输及能源数据均来自特定数据。」 |
| 信息的不确定性 | `informationUncertainty` | string（长文本） | 系统默认 / 用户编辑 | 否 | 信息本身不确定性程度的说明 | 默认「所有数据及假设均通过提供的证据进行确认。」 |
| 是否已确认 | `confirmed` | boolean | 系统 / 用户 | 是 | 步骤① 是否已确认 | 默认 `false`；确认后置 `true` |
| 确认人 / 确认时间 | `confirmedBy` / `confirmedAt` | string | 系统 | 否 | 定性确认留痕 | 确认后写入 |

> **初稿生成示例（前 3 项自动生成）**：
> - 时间覆盖范围：「初级数据来自 {企业 / 主体} {统计时间起} 至 {统计时间止} 的生产数据。次级数据采用 {因子库 + 版本} 数据库。」
> - 地理覆盖范围：「特定数据采集自 {地域}。次级数据的地理位置包括 {去重后的因子适用区域列表}。」

## 9. DQR 计算、联动与回写口径

> `Q` 系列为 DQR 计算口径（与业务 PRD §6 一致）；`C` 系列为状态联动。

| :--- | :--- | :--- | :--- | :--- | :--- |

| C02 | 编辑定性描述 | `temporalCoverage` / `geographicalCoverage` / `technologicalCoverage` / `completeness` / `representativeness` / `consistency` / `reproducibility` / `dataSource` / `informationUncertainty` | 保存 9 项描述 | 定性覆盖范围 | 覆盖 |

### 12.2 术语表

| 术语 | 含义 |
| :--- | :--- |
| 评价数据项 | 从核算项目复制的阶段数据项，作为评分与分布的基本单元 |
| 谱系评分 | 评价数据项的五个质量维度评分（1–5） |
| 数据项 DQR | 五维算术平均得到的数据项级质量分值 |
| 整体 DQR | 各数据项 DQR 按排放贡献率加权得到的评价级质量分值 |
| 相对不确定度 | 由谱系分数换算并传播得到的相对百分比（%） |
| 待更新 | 来源核算项目产生新核算版本后，评价结论可能失效的状态 |
