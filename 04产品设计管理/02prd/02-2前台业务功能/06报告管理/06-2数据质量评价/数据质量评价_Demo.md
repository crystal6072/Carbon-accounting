# 数据质量评价_Demo（报告管理）

> **文档定位**：数据质量评价前端原型的输入文档，聚焦页面结构、控件类型、交互行为与 Mock 规格。
> **字段定义**：枚举、必填性、字段级约束见《数据质量评价字段清单》，本文件只写页面呈现规则，**不重复定义**。
> **业务规则**：状态机、动作矩阵、DQR 计算口径见《数据质量评价业务PRD》§4（R-083 ~ R-104）、§6。
> **UI 框架**：**tdesign-react**（腾讯 TDesign React 版），见 §一「技术接入方案」（与《敏感性分析_Demo》V0.2 同框架）。
> **版本**：V0.2 | 2026-10-19
> **落地位置**：原型 `/report/quality`（列表）、`/report/quality/:id`（详情 · 三步向导，已落地 `src/pages/report/QualityListPage.tsx` / `QualityDetailPage.tsx`）；替换 `App.tsx` `PLACEHOLDERS` 中的 `report/quality` 占位配置。

> **【V0.2 落地变更声明 · 2026-10-19】**：按 6-1 原型实际实现修订——① 定性扩为 9 项；② 定量评分改为**竞品四项**（TiR/TeR/GeR/C，1–5 分判定标准矩阵，选中格分档色实底）并在**弹窗**中完成（头部 `‹ 数据名 ›` 切换 + 完成进度 + 底部「确定」）；③ 表格多选勾选 + 批量工具栏，批量 = 弹窗逐项打分（**不自动打分**）；④ 列表去掉「整体 DQR」列，操作改「查看（只读）/ 编辑 / 删除」，详情页头新增「← 返回列表」；⑤ 步骤② 增加「跳过定量评价」；⑥ 步骤③ 只保留**定性 9 项 + 定量（摘要条 + 数据项明细 + 分页）**两段，结果随「评价指标」切换联动。

> **【布局口径声明 · 2026-10-14】**：本模块**保留竞品的「① 定性 → ② 定量 → ③ 结果」三步向导形态**（业务 PRD 明确要求对齐竞品），但**控件全部 tdesign 化**（`t-steps` / `t-table` / `t-textarea` / `t-radio-group` 等），不复用 `pcf-*` 私有样式类。与《敏感性分析_Demo》V0.2 的差异：敏感性分析脱离竞品布局改标准列表页，本模块因业务要求保留向导布局。

## 一、技术接入方案（tdesign-react）

### 1.1 依赖引入

原型当前**未引入任何 UI 组件库**（`package.json` 仅 react / react-dom / react-router-dom）。若《敏感性分析_Demo》为 tdesign 首个落地模块，本模块**复用同一依赖**，无需重复接入：

```bash
npm i tdesign-react@^1.18.3 tdesign-icons-react
```

| 项 | 内容 |
| :--- | :--- |
| `tdesign-react` | React 组件库（Stable 1.18.x，**兼容 React 18**，与项目 `react@^18.3.1` 匹配） |
| `tdesign-icons-react` | 官方图标库 |
| 样式引入 | `import 'tdesign-react/es/style/index.css'`（在 `main.tsx` 一次性引入） |
| 全局 reset | `import 'tdesign-react/dist/reset.css'`（按需引入，避免影响既有页面盒模型） |

### 1.2 主题与既有设计令牌的关系

| 项 | 方案 |
| :--- | :--- |
| 主色 | `ConfigProvider` 注入主题令牌，与现有 `design-tokens` 主色对齐（竞品截图主色为青绿 `#00b4a0` 系） |
| 既有 `pcf-*` 私有类 | **本模块不复用**；容器统一由 tdesign `Card` / `Descriptions` / `Table` 承载 |
| 混用约束 | 新旧模块样式隔离（tdesign `t-` 前缀命名空间，不与 `pcf-` 冲突） |
| 暗色 / 响应式 | 本期不做（跟随现有约定） |

### 1.3 本模块使用的 tdesign 组件清单

| 用途 | 组件 |
| :--- | :--- |
| 容器 | `Card`、`Descriptions` / `DescriptionsItem`、`Divider`、`Space` |
| 步骤 | `Steps` / `Step`（三步向导，`theme="dot"` 或默认） |
| 表单 | `Form`、`FormItem`、`Input`、`Textarea`、`Select`、`RadioGroup` / `Radio`（评分矩阵单元格）、`Checkbox`（跳过定量） |
| 数据 | `Table`（含 `type: 'multiple'` 勾选列）、`Pagination`、`Tag`、`Empty` |
| 导航 / 弹层 | `Dialog`（评分弹窗 / 新增 / 更新基准）、`Alert`、`Popconfirm` |
| 操作 | `Button`、`Link` |
| 反馈 | `MessagePlugin`（`success` / `error` / `warning`） |
| 图标 | `tdesign-icons-react`（`ChevronLeftIcon` / `ChevronRightIcon` / `EditIcon` / `DeleteIcon` / `DownloadIcon` 等） |

## 二、页面概述

| 页面 | 路由 / 容器 | 页面目标 | 页面模式 |
| :--- | :--- | :--- | :--- |
| 数据质量评价列表 | `/report/quality` | 定位评价单、查看状态、新增 / 删除评价 | 标准列表页（筛选表单 + 表格 + 分页） |

| 新增数据质量评价 | 列表页内弹窗 | 选择「已核算」项目创建评价 | `Dialog` |

**主流程**

```text
列表页 ──「新增数据质量评价」──▶ 选择已核算项目 ──▶ 详情页（步骤① 定性 9 项，自动初稿，编辑模式）
                                                        │
    列表「查看」──▶ 只读模式（仅查看标识，编辑入口收起，步骤自由浏览）                │
                    编辑 / 复核 9 项定性 ──「下一步」──▶ 步骤② 定量
                                                        │
      （可勾选「跳过定量评价」直达步骤③）                                            │
      勾选 N 项 →「批量评估」→ 评分弹窗逐项打分 → 确定                               │
      行内「评价 / 重新评价」→ 评分弹窗打分 → 确定                                   │
                    ──「下一步」──▶ 步骤③ 结果（定性 9 项 + 定量摘要与明细）
                                                        │
                          「评价指标」切换联动结果 / 「导出结果」/「上一步」改分重算
```

> `Space` 通栏，置于步骤条下方、内容区上方；随当前口径变化。

| 元素 | 控件 / 规格 |
| :--- | :--- |

**数据质量评估弹窗**（`Dialog`，`width=860`，版式对齐竞品）

| 区块 | 控件 / 规格 |
| :--- | :--- |
| 头部 | 左：标题「数据质量评估」；中：`‹ {数据项名} ›`（`icon button` 圆钮，上一项 / 下一项；批量会话有效，单项时置灰）；右：「完成进度：已评 X / 共 N 项」 |

| 主体 · 评分依据 | `Descriptions column={2}`：生命周期阶段 / 统计数据来源 / 数据凭证 / 排放因子来源 |
| 主体 · 实时预览 | 「当前评分 DQR {分值}（{等级}） | 不确定度 {±x%}」随草稿实时刷新 |
| 底部 | 左：提示文案「点击指标对应分值完成打分，确定后批量保存」；右：`确定`（`theme="primary"`，无可保存项置灰） |

## 五、校验与错误展示

| 检查 | 触发时机 | 失败反馈 |
| :--- | :--- | :--- |
| 未选核算项目创建 | 弹窗确定 | 「确定」保持不可点 + 表单级提示「请选择核算项目」 |
| 无已核算项目 | 打开新增弹窗 | `Select` 禁用 + `Alert` 提示 |
| 步骤② 存在未评分项 | 点「下一步」 | 阻断 + `MessagePlugin.warning('还有 {N} 项数据未评估')`，定位首个未评行；勾选「跳过定量评价」时放行 |
| 批量评估未勾选 | 点「批量评估」 | `MessagePlugin.warning('请先勾选需要批量评估的数据项')`，不打开弹窗 |
| 批量会话未打分 | 弹窗「确定」 | 按钮置灰 + 提示「点击指标对应分值完成打分，确定后批量保存」 |
| 评分取值 | `RadioGroup` 单选 1–5 | 组件天然限制，无自由输入 |
| 总排放为 0 | 步骤③ 生成结果 | 整体 DQR 按算术平均（导出汇总标注） |
| 评价指标切换 | 口径切换 | 数据项排放 / 贡献率与摘要按新口径重算；结果分页回首页；失败 `MessagePlugin.error('切换指标失败')` |
| 评价不存在 | 加载详情 | `MessagePlugin.error('数据质量评价不存在或已被删除')` → 返回列表 |
| 并发编辑冲突 | 保存评分 | `MessagePlugin.error('评价单已被他人更新，请刷新后重试')` |
| 来源已删除 | 更新基准 | 按钮禁用 + `Tooltip`「来源核算项目已删除，无法更新基准」 |
| 查看模式误操作 | 只读模式进入 | 编辑入口不渲染；评分弹窗控件禁用且无「确定」 |

> 校验策略：**DQR 计算由服务端（mock）执行**，前端负责字段级校验与渲染；状态不允许的操作由 mock 抛错、前端 `MessagePlugin.error` 兜底。

### 6.2 计算逻辑（mock）

| 项 | 规格 |
| :--- | :--- |
| 输入 | 评价数据项（含四项评分）+ 各数据项贡献率（切换口径后按该口径重算） |
| 单项 DQR | `(temporal + technological + geographical + completeness) / 4`，保留 1 位小数 → 按业务 PRD §6.2 映射等级 |
| 单项不确定度 | `sqrt(Σ u_dim(s)²)`（四项，系数 3% / 8% / 15% / 30% / 60%） |
| 整体 DQR | `Σ(w_i × dqr)`，`w_i` = 贡献率**小数**；`Σw_i = 0` 时退化为算术平均 |
| 整体不确定度 | `sqrt(Σ(w_i × uncertainty)²)`（权重用小数，禁止百分点） |
| 分布 | `levelDistribution` / `stageDistribution`（贡献率加权）/ `itemDistribution`（DQR 降序）/ `categoryDistribution` / `keySources`（页面不展示，导出可用） |
| 定性初稿 | 前 3 项由统计时间 + 因子库 + 因子 `region` 去重拼接生成；后 6 项按默认文案 |
| 口径拆分 | `switchCaliber`：排放 × 比例（化石 0.7 / 生物源 0.22 / LULUC 0.08）→ 贡献率归一化（演示口径，工程上应取核算结果分口径明细） |
| 版本失效 | mock 内为某项目提供「重新核算」触发点，用于演示状态转「待更新」 |
