## 1. 拟添加的批注清单

### 1.1 整体流程

#### B-R01-01 企业信息维护整体流程
**拟标注位置**：功能标题「企业信息维护」附近（全局说明）
**标记**：已确认

**批注内容**

- **适用场景**：平台 / 组织管理员在报告管理模块统一维护「报告主体（企业）」信息，作为报告编制时自动带入封面、基本信息表与表 1 的企业字段来源。
- **流程**：进入企业信息维护 → 在列表查看已维护的企业 → 按需查询定位 → 维护企业信息（新增 / 编辑）→ 不再需要时删除（受引用限制）。
- **分支**：新增只有一条入口 —— 页头「新增企业」，打开新增抽屉。编辑、删除都在列表行操作内完成。
- **衔接**：列表选中（通过查询 / 翻页）即查看当前企业信息；「新增 / 编辑」以抽屉完成，**不离开本页**；编辑抽屉带出该记录现有内容。
- **结束**：保存后立即生效，列表刷新。企业信息维护**没有提交、审核、驳回**，也没有操作日志入口；删除为物理删除、不可恢复（被报告引用的记录禁止删除）。

### 1.2 全局规则说明

#### B-R01-02 全局规则
**拟标注位置**：功能标题「企业信息维护」附近（与整体流程同一全局说明入口）
**标记**：已确认（权限、数据可见范围为待确认，见 §4）

**批注内容**

1. **适用范围**：本页维护的是「报告主体（企业）」信息库，用于统一企业归口口径；报告编制（报告管理 · 报告编制）在封面、基本信息表、表 1 引用本库记录（PRD R-104）。企业信息本身不参与碳排计算。
2. **引用关系（R-104 例外）**：报告正文本期「零人工编辑」，唯一例外是企业信息——报告编制时读取本库并允许编辑，无记录 / 字段缺失时允许现场补录；企业信息**不作为报告生成的准入阻断项**。
3. **更新级联（R-114）**：本库记录更新后，**引用该记录的报告转「待更新」**（提示「企业信息已更新，引用该企业的报告将标记为待更新」）。重新生成报告可同步。
4. **删除限制**：被报告引用的企业**禁止删除**（删除提示文案已说明「被报告引用的企业不可删除」）；未被引用的企业可正常删除。
5. **同名限制**：企业名称在全库**不可重复**——新增与编辑保存时都校验，重名即阻断保存（见 B-R01-04、B-R01-05、B-R01-13）。
6. **字段必填口径**：除「备注」外，企业名称、统一社会信用代码、法定代表人、企业地址、联系方式、联系人、所属行业**均为必填**；表单不做实时校验，保存时统一校验并提示「请填写 X」。
7. **无流程节点**：没有提交、审核、驳回，也没有操作日志入口；编辑为直接覆盖，不改变已生成报告的快照内容（报告以生成时刻快照为准）。
8. **无查看入口**：本页不提供独立的「查看」弹窗——列表直接展示核心字段，其余字段（企业地址 / 所属行业 / 备注等）需在「编辑」抽屉中查看；编辑兼具查看作用。
9. **权限**：谁可维护、谁只能查看，原型未做任何限制 → **待确认**（见 §4）。

### 1.3 引用关系与影响（与报告编制）

> 企业信息维护没有「启用 / 禁用」这类业务状态；它与报告编制之间是**引用关系**，因此单列本节说明引用与影响，替代通常的「业务状态说明」。

#### B-R01-03 引用关系与影响
**拟标注位置**：页面顶部 Alert 提示区（「统一维护报告主体…」提示旁）
**标记**：已确认（列表是否展示引用状态 / 引用次数见 §4）

**批注内容**

- **引用来源**：报告编制的封面、基本信息表、表 1 均引用本库记录（PRD R-104）；编制页步骤①支持「从企业信息库引用」，选中后自动带入企业字段（PRD R-131）。
- **引用后仍可改**：引用后，报告内字段仍可按需修改，**仅影响该报告**，不回写本库。
- **本库更新 → 报告待更新（R-114）**：本库记录编辑保存后，引用该记录的报告状态转为「待更新」，提示用户重新生成同步；不影响报告已生成的快照正文。
- **删除限制（引用拦截）**：记录被报告引用（`reportCount > 0`）时禁止删除；删除确认弹窗已提示「被报告引用的企业不可删除」。
- **引用计数（派生，只读）**：每条记录维护「被报告引用次数」（`reportCount`），由报告生成 / 删除自动增减；该值为系统派生，**用户不可改**。
- **缺记录 / 缺字段**：报告编制时若未引用本库或字段缺失，对应位置显「未引用企业信息库 / 待补录」，可现场补录（R-104 例外）。

### 1.4 操作功能及对应业务规则

#### B-R01-04 新增企业
**拟标注位置**：页头「新增企业」按钮旁
**标记**：已确认（重名校验为保存时拦截，表单不做实时校验）

**批注内容**

- **操作目的**：新建一条报告主体（企业）记录。
- **入口**：页头「新增企业」按钮（常驻显示）；**恒可操作，不限制已有企业数量**。
- **操作过程**：打开抽屉，标题为「新增企业」；填写各字段（企业名称、统一社会信用代码、法定代表人、企业地址、联系方式、联系人、所属行业、备注）。
- **结果**：保存成功后抽屉关闭，提示「企业已新增」，新记录出现在列表顶部（按更新时间倒序），引用次数为 0。
- **保存校验**：必填项为空时提示「请填写 X」并阻断保存；企业名称与已有记录重名时提示「已存在同名企业，请检查后重试或直接编辑原记录」并阻断保存。
- **取消或失败**：点「取消」或关闭抽屉不保存任何内容；校验不通过时抽屉保持打开、内容保留。

#### B-R01-05 编辑企业
**拟标注位置**：列表操作列「编辑」按钮旁、编辑抽屉底栏「保存」
**标记**：已确认（被引用记录是否锁定关键字段见 §4）

**批注内容**

- **操作目的**：修改企业信息；任何状态（是否被引用）的企业均可编辑。
- **入口**：列表操作列「编辑」。
- **操作过程**：打开抽屉，标题为「编辑企业 · 企业名称」，带出该记录现有内容；可修改全部字段。
- **结果**：保存成功后提示「企业信息已更新，引用该企业的报告将标记为待更新」，列表刷新；**引用该企业的报告转「待更新」**（R-114）。
- **保存校验**：同新增——必填项为空提示「请填写 X」；企业名称与其它记录重名时提示「已存在同名企业，请检查后重试」并阻断保存（允许与自身同名，即不改名）。
- **取消**：点「取消」或关闭抽屉不保存任何内容。

#### B-R01-06 删除企业
**拟标注位置**：列表操作列「删除」按钮旁、删除二次确认弹窗
**标记**：已确认（列表未展示引用状态，删除依赖引用但不直观，见 §4）

**批注内容**

- **操作目的**：移除一条不再需要的企业记录。
- **可操作条件**：恒显示删除入口；**但被报告引用的企业实际禁止删除**（保存拦截在后端 / mock 层）。
- **操作过程**：点击「删除」弹出二次确认，文案为「删除后不可恢复；被报告引用的企业不可删除。确认删除？」；底栏为「取消」与「确认删除」。
- **结果（未被引用）**：确认后记录被物理删除，提示「已删除」，列表刷新。
- **结果（被引用）**：确认后系统拦截，提示「该企业已被 N 份报告引用，不能删除」，不删除。
- **取消**：点「取消」或关闭弹窗，状态不变。

#### B-R01-07 查询与重置
**拟标注位置**：清单上方查询区
**标记**：已确认

**批注内容**

- **操作目的**：在全部企业中按名称 / 信用代码快速定位。
- **查询项**：单一输入框「企业名称」，placeholder 为「企业名称 / 信用代码」；按**包含关系模糊匹配、忽略大小写**，同时命中企业名称或统一社会信用代码。
- **规则**：输入条件后点「查询」执行筛选，结果回到第 1 页；「重置」清空关键词并恢复完整列表（回到第 1 页）。
- **统计**：查询区下方「共 N 条」统计**当前全部记录数**，不受分页与查询条件影响（注：当前「共 N 条」统计的是全量，而非当前筛选结果；行为是否应随筛选变化见 §4）。
- **不提供**：本页不提供按法定代表人、所属行业、联系方式等其它字段的查询，也不提供导出。

#### B-R01-16 被报告引用次数（派生，只读）
**拟标注位置**：（当前原型列表未展示该值；拟作为全局 / 文档级说明）
**标记**：待确认（是否需要在列表展示引用状态 / 次数）

**批注内容**

- **业务含义**：该企业在报告编制中被引用的份数（`reportCount`），由报告生成 / 删除自动增减。

- **当前表现**：原型列表**未展示**该值，用户无法直观判断哪些企业被引用、能否删除 → 是否补充展示「被引用 / 引用次数」列见 §4。

#### B-R01-17 制单信息（创建人 / 创建时间 / 更新人 / 更新时间）
**拟标注位置**：（当前原型列表仅展示「更新时间」；其余为系统记录）
**标记**：已确认（原型中为演示数据）

**批注内容**

- **创建人 / 创建时间 / 更新人**：由系统记录，不可维护；当前原型列表中**不展示**创建人与创建时间。
- **数据性质**：列表中展示的制单信息为**演示数据**（原型内置演示值），正式实现需由系统按真实操作记录生成。
