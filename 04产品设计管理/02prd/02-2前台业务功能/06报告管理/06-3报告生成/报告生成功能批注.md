## 一、拟添加的批注清单

### 1.1 整体流程
- **B-RP-01 报告单生命周期**：列表「新增报告」→ 选已核算项目（仅「已核算」可创建）→ 详情编辑态（① 企业信息补充：从企业信息库引用并补全必填项 → ② 预览与生成报告：A4 预览 +「生成正式报告」）→ 查看态（企业信息只读 + 查看报告 / 下载报告 / 重新生成）。删除报告单不影响来源核算项目与企业信息库。
- **B-RP-02 入口约束**：报告仅可基于「已核算」项目创建；无已核算项目时新增弹窗 `Select` 禁用并 `Alert` 提示。

### 1.2 全局规则
- **B-RP-G01 状态机**：报告状态 = 生成中 / 编制中 / 已生成 / 待更新。（1）进入详情编辑态即「编制中」；（2）「生成正式报告」成功转「已生成」；（3）来源核算项目重新核算、基准版本变化时转「待更新」，报告可能失效；（4）「生成中」为系统生成占位态，原型以「编制中」呈现。
- **B-RP-G02 零人工编辑原则**：报告正文内容 100% 由核算结果 + 企业信息库 + 报告模板自动拼装，**原型不允许在报告正文中人工改写文字**（模板占位符除外）；任何数据修正必须回溯至「产品碳足迹核算」或「企业信息库」后重新生成。
- **B-RP-G03 企业信息引用关系**：报告中的企业信息（生产者名称、地址、联系方式等）**从「企业信息库」（报告管理 / 企业信息维护）引用**，不允许报告内独立新建；企业信息库为空时详情① 引导前往维护，引用关系随库更新（来源已删除时标记并阻断生成）。
- **B-RP-G04 报告编号规则**：报告编号 `PCF-RP-YYYYMMDDNNN` 创建时生成；封面「报告编号」取自该字段，且为报告唯一标识（区别于核算单编号 `PCF-XXX` 与评价单编号 `PCF-DQ-XXX`）。

### 1.3 操作功能及业务规则
- **B-RP-03 列表查询与表格**：筛选含产品名称 / 报告状态 / 生成时间；表格列 = 序号 / 产品名称 / 核算项目 / 报告状态（Tag）/ 报告生成时间 / 操作（查看 / 删除）；默认按生成时间倒序；整行点进详情。
- **B-RP-04 新增报告弹窗**：`Dialog` 选「已核算」项目，选中后 `Descriptions` 预览产品名称 / 系统边界 / 声明单位 / 基准碳足迹结果（含版本）+ `Alert theme="warning"`「报告正文由核算结果 + 企业信息库 + 模板自动生成，生成后不可人工编辑」。
- **B-RP-05 删除报告单**：`Popconfirm`「删除报告将同时移除已生成的报告文件，不影响来源核算项目与企业信息库，删除后不可恢复。确认删除？」，二次确认 `Dialog`「确认删除」(`theme=danger`)。
- **B-RP-06 企业信息补充（步骤①）**：`Card`「企业信息」从企业信息库引用并呈现企业字段（生产者名称 / 统一社会信用代码 / 地址 / 联系人 / 联系方式等）；引用来源缺失时 `Alert` 引导维护；必填项缺失时阻断「预览与生成报告」并标记 `sa-required`；可「重新引用」刷新最新企业信息库数据。
- **B-RP-07 预览与生成报告（步骤②）**：`ReportPreview` 组件按报告模板（GB/T 24067—2024 附录 G）分 5 张 A4 页渲染（封面 + 各章节 + 图表占位）；工具栏含文件名 / 报告预览 Tag / 页码 / 缩放 / 适应宽度 / 下载；底部「生成正式报告」(`theme=primary`) 触发状态转「已生成」；生成前需步骤① 必填校验通过。
- **B-RP-08 查看态（报告查看）**：查看态企业信息只读、报告以只读 A4 预览呈现；操作含「查看报告」（同预览）/「下载报告」(`CSV`/`PDF` 后置)/「重新生成」（待更新态或数据变更后）；待更新态顶部 `Alert` +「重新生成」。
- **B-RP-09 待更新与重新生成**：待更新态通栏 `Alert theme=warning`「来源核算数据已更新（基准版本 V{n} → V{m}），当前报告可能失效。」+「重新生成」(`theme=primary size=small`)；点击后重新拼装报告并刷新，状态回「已生成」；来源已删除时阻断生成 + `Tooltip`「来源核算项目已删除，无法重新生成」。
- **B-RP-10 导出 / 下载**：查看态「下载报告」以 **PDF** 落地（原型可先以当前预览近似；CSV 仅用于内部明细导出）；封面字段（产品名称 / 规格型号 / 生产者 / 报告编号 / 出具机构 / 日期）来自企业信息库与报告头，空值以占位空格呈现（`blankFlag`）。

### 1.4 字段说明
- **B-RP-F01 报告编号**：`PCF-RP-YYYYMMDDNNN`，创建时生成，报告唯一标识。
- **B-RP-F02 核算项目**：来自来源已核算项目；来源已删除时标记并阻断生成 / 重新生成。
- **B-RP-F03 企业信息字段**：全部引用自企业信息库；必填缺失阻断生成（见 **B-RP-06**）。
- **B-RP-F04 报告状态**：见全局规则 **B-RP-G01**；Tag 配色对齐列表页。
- **B-RP-F05 封面字段**：产品名称 / 规格型号 / 生产者名称 / 报告编号 / 出具机构（若有）/ 日期，来自企业信息库与报告头；空值占位（见 **B-RP-10**）。
