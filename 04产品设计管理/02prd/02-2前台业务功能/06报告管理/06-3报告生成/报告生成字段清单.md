# 报告生成字段清单

> **文档定位**：报告生成（报告管理 · 报告编制）模块的**字段真相源**（RPT）。定义报告、报告封面与基本信息、报告正文章节、报告表格、报告图、装配快照六类对象的字段结构、枚举与字段级约束。业务规则见《报告生成业务 PRD》，章节 / 表格 / 映射见《报告模板定义（ZB13002 整竹砧板 V1）》，页面呈现见《报告生成_Demo》（V0.2）。
>
> **【口径对齐声明 · 2026-10-19 更新】**
> - **零人工编辑（企业信息例外）**：报告正文**不提供任何编辑入口**；内容 = 上游数据装配 + 模板固定文案。**唯一例外 = 企业信息**（封面报告主体 / 基本信息表·表 1）：读取『企业信息维护』并**允许编辑**，无记录 / 字段缺失时**允许现场录入**（R-104）。
> - **编制页仅展示并可编辑企业信息（V0.4 裁定）**：封面与概况字段（产品名称 / 规格 / 报告生成 / 核算周期 / 系统边界 / 生命周期边界 / 报告单位 / 标准依据 / 结论 / 产品图片等）由系统自动取值，**不在编制页提供手动录入、不展示输入框**；编制页仅保留「企业信息」卡片（5 个字段可编辑）。
> - **报告信息不展示（V0.4 裁定 · R-127）**：报告管理字段（报告编号 / 模板 / 来源项目 / 状态 / 下载文件名等）**不在编制页平铺**；仅面包屑与副标题保留「报告编号」作为系统内部标识（不打印，K03 / R-106）。
> - **报告日期自动（V0.4 裁定 · R-129）**：报告日期由系统在「生成正式报告」时**自动取生成当日**（`YYYY-MM-DD`），不手动填写。
> - **单一版本 / 重新生成覆盖**：报告不设多版本；「重新生成」直接覆盖并回到「编制中」（R-105）。
> - **模板固定**：本期仅 1 个系统预置模板（`RPT-PCF-ZB13002-001`），章节集合由模板固定（R-107）。
>
> **文档定位补充**：字段名保持英文原文（`camelCase`），中文为业务名称；业务 PRD 与 Demo 只引用字段名称，不重复维护枚举与必填性。

## 1. 对象结构

### 1.1 关系全景

```text
报告（PcfFootprintReport） 1
   ├── 1  封面与基本信息（ReportCover）          ← 企业信息（可编辑）+ 系统自动取值（封面概况）
   ├── N  正文章节（ReportSection）              ← 封面 / 基本信息表 / 目录 / 一~七章 / 附录
   │        ├── N 报告表格（ReportTable）         ← 表 1~表 12
   │        └── N 报告图（ReportFigure）          ← 图 1 产品图片 / 图 2 分布图
   └── 1  装配快照（ReportSnapshot）              ← 生成时锁定的上游只读副本
```

| 结构 | 对象 | 与主对象关系 | 唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主对象 | 报告 | 主对象 | 报告编号（`PCF-R-YYYYMMDDNNN`） | 本清单定义范围 |
| 子对象 · 封面与基本信息 | 封面信息 | 1:1 | 报告编号 | 生成时装配；**仅企业信息可编辑/可见** |
| 子对象 · 正文章节 | 章节 | 1:N | 报告编号 + `sectionCode` | 由模板固定 |
| 子对象 · 报告表格 | 表格 | 1:N（挂章节） | 报告编号 + `tableNo` | 表 1~表 12 |
| 子对象 · 报告图 | 图 | 1:N（挂章节） | 报告编号 + `figureNo` | 图 1 / 图 2 |
| 子对象 · 装配快照 | 快照 | 1:1 | 报告编号 | 生成时锁定，只读 |
| 关联对象（只读） | 核算项目 / 敏感性分析 / 数据质量评价 / 企业信息 | N:1 | 各自编号 | 来源，只读引用、不写回 |

> **关系说明**：报告 : 核算项目 = **N:1**（同项目保留**单一当前报告**）；报告 : 章节 = **1:N**；章节 : 表格 / 图 = **1:N**。

### 1.2 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | 系统生成（编号 / 状态 / 快照 / 装配正文）+ 系统带出（项目 / 产品 / 核算结果 / 敏感性 / 数据质量）+ **企业信息（唯一可编辑）** |
| 外部系统数据源 | 否 |
| 新增编辑 | 新增 = 选「已核算」项目创建「编制中」草稿（R-125）；编辑 = **仅企业信息**可在编制中步骤①编辑 / 补录，其余全部只读 |
| **编制页字段可见性** | **报告信息（编号/模板/来源项目/状态/文件名）不展示（R-127）；封面与概况字段系统自动取值、不提供录入（R-128）；编制页仅展示并可编辑「企业信息」5 字段** |
| 子表 | 章节（固定集合）、表格（按阶段渲染）、图（占位） |
| 导入导出 | 本期**不做导入**；导出 `docx`（P0） |
| 状态与执行 | 报告状态机（编制中 / 已生成 / 待更新）+ 生成 / 重新生成 |
| 关键唯一键 | 报告编号（全局唯一，不正文打印） |
| 历史兼容 | 无历史数据；旧《06生成报告》结构已作废 |

### 1.3 关键数据约束

| 约束ID | 约束 | 影响对象 |
| :--- | :--- | :--- |
| D01 | 报告编号系统生成、全局唯一、**不可修改**、**不正文打印**（仅面包屑/副标题展示） | 主对象 |
| D02 | **零人工编辑**：除 **企业信息**（封面报告主体 / 基本信息表·表 1）外，报告内容**不可编辑** | 封面 / 章节 |

| D08 | 生成 / 重新生成 / 删除报告**不写回**核算项目与其它报告管理子项 | 主对象 |
| **D09** | **编制页字段可见性（V0.4）**：报告信息不展示（R-127）；封面与概况系统自动取值、不提供手动录入（R-128）；编制页仅「企业信息」可编辑 / 可见 | 封面 / 编制页 |
| **D10** | **报告日期自动（V0.4）**：报告日期由系统于「生成正式报告」时取生成当日，不手动填写（R-129） | 封面 |

| 报告日期 | 系统（生成时刻） | 「生成正式报告」时自动取 `YYYY-MM-DD`（D10 / R-129） |
