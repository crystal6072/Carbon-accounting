# 报告生成_Demo（报告管理）

> **文档定位**：报告生成（报告管理 · 报告编制）前端原型的输入文档，聚焦页面结构、控件类型、交互行为与 Mock 规格。
> **字段定义**：对象、枚举、必填性、字段级约束见《报告生成字段清单》（V0.2），本文件只写页面呈现规则，**不重复定义**。
> **业务规则**：状态机、动作矩阵、生成准入见《报告生成业务 PRD》§4（R-101 ~ R-131）、§5、§6；章节 / 表格 / 图见《报告模板定义（ZB13002 整竹砧板 V1）》。
> **UI 框架**：**tdesign-react**。
> **版本**：V0.2 | 2026-10-19
> **落地位置**：原型 `/report/prepare`（列表）、`/report/prepare/:id`（详情）、详情内预览控件。
>
> **【零人工编辑声明 · 全文优先】**：报告正文**不在页面上平铺、不提供编辑入口**，统一由「查看报告」预览控件承载（只读 A4 分页）；编制中仅保留**两步向导**（① 企业信息补充 ② 预览与生成报告）；除外**企业信息**外，所有字段均为核算数据自动装配、只读（PRD R-104）。
>
> **【编制页交互声明 · 2026-10-19，全文优先】**：① **报告信息不展示**（仅面包屑/副标题保留报告编号，R-127）；② **封面与概况系统自动取值，不在编制页手动填写**（R-128）；③ **编制页仅保留「企业信息」可编辑**（R-104）；④ **报告日期自动取生成当日**（R-129）；⑤ **底部冻结操作栏**（R-130）。

## 二、页面概述

| 页面 | 路由 / 容器 | 页面目标 | 页面模式 |
| :--- | :--- | :--- | :--- |
| 报告列表 | `/report/prepare` | 定位报告、查看状态、新增 / 删除报告 | 标准列表页（筛选表单 + 表格 + 分页） |
| 报告详情（编制中） | `/report/prepare/:id` | 两步走：① 企业信息补充 ② 预览与生成报告 | 单页（步骤条 + 企业信息卡 / 内联预览 + 底部冻结操作栏） |

**主流程**

```text
列表页 ──「新增报告」──▶ 选已核算项目 ──▶「生成报告」──▶ 详情页（报告「编制中」）
                                                             │
                          ┌──────────────────────────────────┘
                          │ 步骤① 企业信息补充
                          │   从企业信息库引用 / 现场编辑（生产者名称必填）
                          │   「下一步：预览与生成」
                          ▼
                          步骤② 预览与生成报告
                              内联只读预览 ──▶「生成正式报告」
                                                 │
                                                 ▼
                                          报告「已生成」→「查看报告」Drawer / 「下载」/「重新生成」
```

## 六、校验与错误展示

| 检查 | 触发时机 | 失败反馈 |
| :--- | :--- | :--- |
| 未选核算项目生成 | 弹窗「生成报告」 | 「生成报告」`disabled` + 必填星号 |
| 无已核算项目 | 打开新增弹窗 | `Select` 禁用 + `Alert`「暂无可生成报告的核算项目，请先完成核算」 |
| 企业信息必填校验 | 步骤①「下一步」 | 生产者名称为空时阻断，`MessagePlugin.error('请完善企业信息：生产者名称')` |
| 报告不存在 | 加载详情 | `MessagePlugin.error('报告不存在或已被删除')` + 页面提示 |
| 来源已删除 | 重新生成 | 按钮禁用 + 提示「来源核算项目已删除，无法重新生成」 |
| 生成中重复操作 | 生成 / 重新生成 | 按钮转 `loading` 禁用，不重复提交 |
| 生成失败 | 装配异常 | 提示「报告生成失败，请稍后重试」，不产出半成品 |

> 校验策略：**报告装配由服务端（mock）执行**，前端负责字段级校验与渲染；状态不允许的操作由 mock 抛错、前端 `MessagePlugin.error` 兜底。

### 7.2 装配逻辑

| 项 | 规格 |
| :--- | :--- |

### 7.3 企业信息编辑口径（R-104 例外 / R-131 引用）

| 项 | 规格 |
| :--- | :--- |
| 数据源 | 优先取「企业信息维护」快照（或步骤①「从企业信息库引用」）；无则字段留空显「待补录」 |
| 编辑 | 编制中步骤① `Input` 直接录入 / 修改，保存写入**本报告快照**（`enterpriseSnapshot`） |

| 回写 | **不回写**核算主链；是否回写「企业信息维护」见字段清单 Q04（本期建议仅覆盖本报告） |
| 状态影响 | 报告内编辑企业信息**不置**「待更新」；「企业信息维护」模块自身变更 → 报告置「待更新」 |
