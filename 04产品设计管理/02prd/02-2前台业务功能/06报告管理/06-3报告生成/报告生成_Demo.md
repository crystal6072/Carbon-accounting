## 一、技术接入方案（tdesign-react）

### 1.1 依赖状态

`tdesign-react` 已由敏感性分析模块接入（实际安装 `tdesign-react@1.18.4` + `tdesign-icons-react`），本模块**直接复用**，无需重复安装：

| 项 | 内容 |
| :--- | :--- |
| `tdesign-react` | React 组件库（Stable 1.18.x，兼容 React 18） |
| `tdesign-icons-react` | 图标库（`FileIcon`、`DownloadIcon`、`RefreshIcon` 等） |
| 样式引入 | `main.tsx` 已引入 `tdesign-react/es/style/index.css` |
| 主题 | 沿用 tdesign 默认令牌；如需与 `design-tokens` 主色对齐，后续用 `ConfigProvider` 注入 |

### 1.2 本模块使用的 tdesign 组件清单

| 用途 | 组件 |
| :--- | :--- |
| 容器 | `Card`、`Descriptions` / `Descriptions.DescriptionsItem`、`Divider`、`Space` |
| 表单 | `Form` / `Form.FormItem`、`Input`、`Textarea`、`Select`、`DateRangePicker` |
| 数据 | `Table`、`Pagination`、`Tag`、`Empty`、`Tooltip` |
| 导航 / 弹层 | `Dialog`、`Drawer`（预览控件）、`Popconfirm`、`Alert` |
| 操作 | `Button`、`Link`（原型用原生 `<a className="rp-link">`） |
| 反馈 | `MessagePlugin`（`success` / `error` / `info`） |
| 图标 | `FileIcon`（报告文件卡）、`FileDownloadIcon`、`RefreshIcon` |

> **复用踩坑记录**（见敏感性 Demo §一）：`Tabs.TabPanel`、`Form.FormItem`、`Descriptions.DescriptionsItem` 为**静态属性**；`Form.FormItem` **无 `required`**（必填星号自行渲染）；`Table` 空状态用 `empty`（TNode）。

## 二、页面概述

| 页面 | 路由 / 容器 | 页面目标 | 页面模式 |
| :--- | :--- | :--- | :--- |
| 报告列表 | `/report/prepare` | 定位报告、查看状态、新增 / 删除报告 | 标准列表页（筛选表单 + 表格 + 分页） |
| 报告详情 | `/report/prepare/:id` | 查看报告信息、补录企业信息、预览 / 下载 / 重新生成 | 单页（信息卡 + 封面与概况 + 动作区） |
| 新增报告 | 列表页内弹窗 | 选「已核算」项目一键生成 | `Dialog` |
| 报告预览 | 详情页内控件 | A4 分页只读浏览报告全篇 | `Drawer`（宽 1120px） |

**主流程**

```text
列表页 ──「新增报告」──▶ 选已核算项目 ──▶「生成报告」──▶ 详情页（报告「生成中」→「已生成」）
                                                             │
                          （企业信息缺失时）补录企业信息 ──▶「保存」
                                                             │
                          「查看报告」──▶ 预览控件（A4 分页只读）
                          「下载报告」──▶ 导出 docx
                          「重新生成」（上游变更后）──▶ 覆盖
```

## 六、校验与错误展示

| 检查 | 触发时机 | 失败反馈 |
| :--- | :--- | :--- |
| 未选核算项目生成 | 弹窗「生成报告」 | 「生成报告」`disabled` + `Form.FormItem` 必填星号 |
| 无已核算项目 | 打开新增弹窗 | `Select` 禁用 + `Alert`「暂无可生成报告的核算项目，请先完成核算」 |
| 存在未处置阻断项 | 生成报告 | `MessagePlugin.error('核算存在未处置问题，暂不可生成报告')`（mock 抛错兜底） |
| 企业信息缺失 | 生成 | **不阻断**；封面与概况信息区对应字段显「待补录」 |
| 企业信息必填校验 | 保存 | 报告主体为空时阻断，`MessagePlugin.error('请填写报告主体')` |
| 报告不存在 | 加载详情 | `MessagePlugin.error('报告不存在或已被删除')` + 页面提示 |
| 来源已删除 | 重新生成 | 按钮禁用 + `Tooltip`「来源核算项目已删除，无法重新生成」 |
| 生成中重复操作 | 生成 / 重新生成 | 按钮转 `loading` 禁用，不重复提交 |
| 生成失败 | 装配异常 | 状态回「未生成」+ `MessagePlugin.error('报告生成失败，请稍后重试')` |

> 校验策略：**报告装配由服务端（mock）执行**，前端负责字段级校验与渲染；状态不允许的操作由 mock 抛错、前端 `MessagePlugin.error` 兜底。

### 7.2 装配逻辑

| 项 | 规格 |
| :--- | :--- |
| 输入 | 最近核算结果（`unitEmission` + 四口径 + `stageSummary` + `details`）+ 项目 / 产品 + 最近敏感性分析 + 最近数据质量评价 + 企业信息 |
| 编号 | `PCF-R-YYYYMMDDNNN`（生成日 + 当日 3 位顺序号）；**不进入正文** |
| 章节装配 | 按模板固定集合生成 `S00`（封面）/ `SB`（基本信息表，含结论句式）/ `ST`（目录）/ `S1`~`S7` / `SA`（附录） |
| 表格装配 | 表 2~表 8 = `details` 按 `stagePath` 拆表；表 9 = 三项（`total` / `biogenic` / `luluc`）；表 10 = 阶段汇总（一级 + 二级）；表 11 = 敏感性；附表 12 = 固定文案 |
| 图装配 | 图 1 = 项目 `productImageUrl`（缺失占位）；图 2 = 占位 |
| 结论句式 | 模板 §5.1（**不含碳储量**） |
| 缺失兜底 | 无敏感性 / 数据质量 → 对应章节 `blankFlag = true`、`content`「本项目未开展…」；报告仍「已生成」 |
| 单位口径 | 取项目「声明 / 功能单位」，不换算（R-109） |
| 快照 | 生成时对上游取 `ReportSnapshot`，后续上游变化 → 状态置「待更新」 |

### 7.3 企业信息编辑口径（R-104 例外）

| 项 | 规格 |
| :--- | :--- |
| 数据源 | 优先取「企业信息维护」快照；无则字段留空显「待补录」 |
| 编辑 | 报告内 `Input` 直接录入 / 修改，保存写入**本报告快照**（`enterpriseSnapshot`） |
| 回写 | **不回写**核算主链；是否回写「企业信息维护」见字段清单 Q04（本期建议仅覆盖本报告） |
| 状态影响 | 报告内编辑企业信息**不置**「待更新」；「企业信息维护」模块自身变更 → 报告置「待更新」 |
