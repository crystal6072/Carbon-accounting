# 行业数据集业务 PRD（前台业务平台）

> **【定位调整声明 · 2026-11-04】**：本模块定位由「本企业核算结果台账」修正为「**平台已发布版本行业数据集的只读浏览**」：
> - **数据来源**：后台「数据集管理 · 公共数据库」的**当前已发布版本**；仅当前版本，审核入库但未发版的数据不进入本模块；企业侧不感知版本管理，页面不展示版本号、不提供历史版本切换；
> - **页面结构**：**「数据 / 统计分析」两个 Tab 切换**（同一份数据的列表视图与分析视图）；支持按产品类别 / 行业 / 区域 / 工艺 / 阶段检索、导出、详情（只读）；
> - **不再承载**：手工补录、作废 / 恢复、行内「一键上报」；「一键上报（已核算碳数据上报）」的唯一入口为「数据管理 · 企业数据上报」（`/dataset/report`）；
> - 下文 §1 的「台账归集」口径与 §1.3 的手工补录 / 作废等能力视为**已被本声明替代**，待 PRD 下一版整体重写。

> **【模块归属声明 · 2026-11-03】**：行业数据集归属「**前台业务平台 · 产品碳足迹**」，菜单路由 `/dataset/records`。本模块**面向企业核算与管理人员**（非平台运维功能），**不改变核算主链**——只读消费平台已发布的数据集版本，不写回任何上游对象。
>
> **【口径声明 · 台账化方案】**：本模块**不建「数据集」实体**，把「数据集」理解为「**本企业碳足迹核算结果的结构化台账**」：
> - **归集** = 核算完成自动入账（+ 手工补录历史/外部记录）；
> - **检索** = 台账列表按产品类别 / 阶段 / 区域 / 工艺筛选；
> - **统计分析** = 对当前筛选命中的记录集计算均值 / 中位数 / 离散度 / 分布特征。
>
> **【验收入口】**：直接对应《项目需求边界》§2.9「行业数据集管理：数据集归集、检索、统计分析」三项能力，验收项见 §10。

> **文档定位**：本模块的**业务规则真相源**，定义对象边界、归集与入账逻辑、检索规则、统计口径、权限与验收标准。字段结构见《行业数据集字段清单》，页面控件见《行业数据集_Demo》（待产出）。

## 1. 需求概述

### 1.1 需求背景

企业每完成一次产品碳足迹核算，结果只停留在「单个项目详情」里：**能看一个产品，看不了「我们厂所有产品 / 所有品类的碳足迹分布」**。要做减排优先级判断、要给客户或审核方解释「我们的水平处在什么位置」，都需要把结果**横向排开看**。

现状三个断点：

| 断点 | 表现 |
| :--- | :--- |
| 结果不可横向看 | 核算结果只能在项目内逐条打开；没有跨项目、跨品类的台账视图 |
| 结果不可按维度切 | 无法回答「福建厂区和浙江厂区差多少」「热压工艺和冷压工艺差多少」 |
| 结果不可统计 | 「我们的平均水平是多少、离散程度多大、有没有异常值」全靠人工导表算 |

本模块把已核算结果**沉淀成台账**：

```text
核算项目（状态 = 已核算）
        │ 自动入账（快照，不回溯）
        ▼
行业数据集（台账）  一行 = 一次核算结果
        ├── 标签维度：产品类别 · 阶段 · 区域 · 工艺 · 边界 · 年度
        ├── 检索：多维度组合筛选 → 命中记录集
        └── 统计分析：均值 / 中位数 / 离散度 / 分布特征（对命中记录集实时计算）
```

> **为什么是台账而不是「数据集对象」**：验收要的是「把各行业碳足迹核算结果排开展示 + 能查 + 能算」。数据在核算完成时就已经齐了，再建一层「数据集容器 + 样本入库」只增加操作成本，不增加信息量。

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :-: | :--- | :--- |
| G1 | **归集零操作** | 核算项目「已核算」后自动进入台账，用户无需新建数据集、无需手动入库 |
| G2 | **历史可补录** | 上线前的存量结果、外部公开数据可手工补录（一条一录，来源必填） |
| G3 | **四维快速检索** | 产品类别 / 阶段 / 区域 / 工艺 四个维度可任意组合筛选，结果 ≤1 秒刷新（1 万条内） |
| G4 | **统计即算即显** | 命中记录集实时输出 n / 均值 / 中位数 / 离散度 / 分布图，无需导出到 Excel |
| G5 | **口径可比** | 边界、口径、GWP、声明单位不一致的记录自动排除并提示，不混算 |
| G6 | **不污染主链** | 全程只读消费核算结果；台账作废 / 删除不影响核算项目与报告 |
| G7 | **结果可出口** | 台账列表与统计结果可导出（Excel/CSV），供汇报与上报使用 |

## 4. 归集逻辑（核心）

### 4.1 自动入账

| # | 规则 |
| :-- | :--- |
| A1 | 触发点：核算项目状态变为「已核算」并产出结果版本时触发；检测未通过 / 核算中不入账（D16） |
| A2 | 幂等：以 `sourceProjectId + resultVersion` 判重，重复触发不新增行（D02） |
| A3 | 快照：写入时冻结全部数值与标签，之后上游任何变化不回溯（D06） |
| A4 | 替代：同项目存在更高 `resultVersion` 时，旧记录置「已替代」，默认不参与统计（D03） |
| A5 | 标签补全：区域取核算项目「区域」（Q01），缺失置「未填」；类别 / 行业 / 工艺缺失置「标签不全」并禁止进入统计（D04 / D05） |

### 4.2 手工补录

| # | 规则 |
| :-- | :--- |
| M1 | 必填：产品名称、产品类别、区域、工艺（≥1）、边界、统计期间、声明单位、总碳足迹 |
| M2 | 阶段值选填：可只填总值（标「阶段缺失」）；填写时按阶段库选择，一级阶段建议全填 |
| M3 | 必须填「来源说明」，建议附依据文件（报告 / 文献 / 统计年鉴）（D11） |
| M4 | 手工记录同样**入库即快照**，不可改数值；填错只可作废后重录（Q06） |
| M5 | 手工记录与自动记录在列表「来源」列区分，统计时**默认同时纳入**，可按来源筛选 |

### 4.3 去重与纠偏

| 情况 | 处理 |
| :--- | :--- |
| 同一产品多个项目（不同边界） | 各为一条记录，统计时按边界筛选，不合并 |
| 同一项目多次重算 | 只保留最新版本为「有效」，其余「已替代」 |
| 手工补录与自动记录重复 | 不做自动识别；由用户在列表识别后作废手工记录（避免误删） |
| 阶段值与总值不一致 | 标「阶段不闭合」提示，不修正原值（D08） |

| R-004 | 入库即快照 | 记录写入 | 数值与标签冻结，上游变化不回溯（D06） | — |
| R-005 | 类别父含子 | 检索 / 分组 | 选择父类时命中全部子类；分组按所选层级聚合（C05） | — |
| R-006 | 统计样本阈值 | 打开统计视图 | `n < 5` 只出 n / 均值 / 中位数，离散度与分布显示「样本不足」（S05） | `n = 0` 全区域空态 |
| R-007 | 可比性排除 | 统计计算 | 边界 / 口径 / GWP / 声明单位不一致的记录排除，并提示排除条数（S09 / D12） | 用户可切换筛选条件后重算 |
| R-008 | 离群不剔除 | 统计计算 | 1.5×IQR 标出离群，不自动剔除；如需剔除由用户加筛选条件（S06） | 列表可「仅看离群」 |
| R-009 | 软删除 | 作废 | 不物理删除，填原因后退出统计，可恢复（D10） | 恢复后重新参与统计 |
| R-010 | 不写回上游 | 全流程 | 台账与统计结果不回写核算项目、结果、报告（D15） | — |

## 6. 统计口径与呈现

> 口径细节见《行业数据集字段清单》§6.2（S01–S10），本节只定义**呈现方式与业务含义**。

### 6.1 统计对象

**当前筛选命中的「有效」记录集**（S01）。筛选条件变化即重算，不做预绑定。统计抽屉顶部固定显示一行「统计口径说明」：

```text
样本 n = 12 ｜ 已排除 2 条（声明单位不一致）｜ 区域：福建、浙江 ｜ 期间：2024-01 ~ 2024-12
```

### 6.2 指标呈现

| 区域 | 内容 | 业务含义 |
| :--- | :--- | :--- |
| 指标卡（第一排） | 样本数 n、均值、**中位数** | 中位数标注为「代表性水平」，避免被个别大值带偏 |
| 指标卡（第二排） | 标准差、变异系数 CV、极差、P90 | 反映离散程度与「较好水平」参考 |
| 参考线 | 行业基线值 / 先进值（箱线图虚线 + 指标卡角标） | 只读引用后台「产品碳基线库」；匹配口径见 §6.4 |
| 箱线图 | 最小值 / Q1 / 中位数 / Q3 / 最大值 + 离群点 | 一眼看出分布偏斜与异常记录 |
| 直方图 | 分箱数 `ceil(√n)`（≥5 箱） | 看是否单峰、是否有断层 |
| 分组表 | 按区域 / 工艺 / 年度分组：n、均值、中位数 | 定位差异来源 |
| 阶段结构（P1） | 各阶段均值 + 占比条形图 | 看主要排放环节 |

### 6.3 异常与边界处理

| 情况 | 呈现 |
| :--- | :--- |
| `n = 0` | 空态：「当前条件下无记录，请调整筛选条件」 |
| `1 ≤ n < 5` | 显示 n / 均值 / 中位数；离散度与图表位置显示「样本不足（n<5），暂不提供分布分析」 |
| 全部记录阶段缺失 | 统计页隐藏「阶段结构」，提示「当前记录未提供阶段数据」 |
| 存在单位不一致 | 顶部黄条提示「已排除 N 条单位/口径不一致记录」 |

### 6.4 行业基线参考线（Q02 已确认）

**来源**：后台「产品碳基线库 → 行业基线录入」中**已发布**的基线记录（只读引用）。本模块**不建公共统计值、不复制基线数据、不修改基线**。

**匹配顺序**（命中即用，不叠加）：

| 优先级 | 匹配键 |
| :-: | :--- |
| 1 | 行业 + 产品类别 + 系统边界 + 基准年（基准年 = 统计期间的结束年） |
| 2 | 行业 + 系统边界 + 基准年（基线「适用产品分类」为空 = 全品类） |
| 3 | 上级行业逐级回退（小类 → 中类 → 大类 → 门类）+ 边界 + 基准年 |
| — | 均未命中 → **不展示参考线，不报错** |

**展示规则**

| 位置 | 呈现 |
| :--- | :--- |
| 箱线图 | 基线值画水平虚线，标签「行业基线 {值}」；`advancedValue` 有值时再画一条「行业先进值」 |
| 指标卡 | 中位数卡右上角标「行业基线 {值}」；差额与偏差率 P1 |
| 口径不一致 | 基线边界 / 口径 / GWP 与统计集不一致 → **不展示**（避免误导） |

**限制**

- 参考线仅作参照，**不参与**任何指标计算（S01–S10 不变）
- 基线被编辑 / 归档后，参考线随之变化或消失（**非快照**，与台账记录的快照口径不同）
- 仅展示数值，不展示基线编号、发布机构、依据文件（如需追溯，跳转后台基线详情，P1）

## 7. 状态与操作矩阵

### 7.1 状态维度

| 状态 | 取值 | 进入统计 | 来源 |
| :--- | :--- | :---: | :--- |
| 记录状态 | 有效 / 已替代 / 作废 | 仅「有效」 | D03 / D10 |

> 本模块**无审核维度、无版本维度、无生效日期维度**；「已替代」由系统产生，「作废」由用户产生。

### 7.2 操作矩阵

| 记录状态 | 查看 | 补填区域 / 工艺 | 改备注 | 作废 | 恢复 | 进入统计 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| 有效 | 是 | 是 | 是 | 是 | — | 是 |
| 已替代 | 是 | 否 | 否 | 否 | 否 | 否 |
| 作废 | 是 | 否 | 否 | — | 是 | 否 |

**闭环校验**：有效 →（重算）已替代；有效 →（作废）作废 →（恢复）有效；无死状态。

### 10.1 验收点 ① 数据集归集

| 编号 | 验收项 | 操作 | 预期结果 |
| :--- | :--- | :--- | :--- |
| V01 | 自动入账 | 完成一个核算项目 | 台账列表新增 1 条记录，产品 / 类别 / 行业 / 边界 / 单位 / 总值与结果一致 |

| 编号 | 验收项 | 操作 | 预期结果 |
| :--- | :--- | :--- | :--- |

### 10.3 验收点 ③ 统计分析

| 编号 | 验收项 | 操作 | 预期结果 |
| :--- | :--- | :--- | :--- |
| V14 | 指标齐全 | 对 n ≥ 10 的记录集打开统计 | 展示 n / 均值 / 中位数 / 标准差 / CV / 极差 / P90，数值与导出核算一致 |
