## 一、技术接入方案（沿用现有约定）

### 1.1 组件与依赖

| 项 | 方案 |
| :--- | :--- |
| UI 组件 | **沿用自研组件库** `src/shared/components`（`Table` / `Modal` / `Drawer` 等价物 / `Select` / `MultiSelect` / `CascaderSelect` / `TreeSelect` / `Pagination` / `Tag` / `PageHeader` / `Toast`），与全站页面保持一致 |
| 样式令牌 | 引用全局 CSS 变量（`design-tokens`），不新增私有主题 |
| **图表实现** | `package.json` **无图表库**（仅 mermaid / tdesign / xlsx）。箱线图与直方图用 **原生 SVG 手绘**（静态分布图无需交互缩放），不新增依赖；如评审要求交互式图表，再评估引入 `echarts`（需登记依赖变更） |
| 统计计算 | 纯函数实现在 `datasetMeta.ts`（均值 / 中位数 / 百分位线性插值 / 样本标准差 / 直方图分箱 / 1.5×IQR），口径对齐字段清单 S01–S10 |
| Mock 层 | `src/mock/dataset.ts` 提供 `listRecords / getRecord / addManualRecord / voidRecord / fillRegion / getStats`；接真实接口仅替换内部实现 |

**主流程**

```text

   ├── 筛选（类别/阶段/区域/工艺 + 更多筛选）──▶ 表格与计数刷新
   │        └──「统计分析」──▶ 统计抽屉（对当前筛选集实时计算）

   └── 行「补填区域」──▶ 区域选择浮层 ──▶ 保存后参与区域检索与分组
```

### 4.2 布局（自上而下）

```text
┌──────────────────────────────────────────────────────┐

├──────────────────────────────────────────────────────┤
│ ② 指标卡 第一排（3 卡）                                  │
│    [ 样本数 n ]  [ 均值 ]  [ 中位数 ★代表性水平 ]          │
│    第二排（4 卡，n≥5 才显示）                             │
│    [ 标准差 ] [ 变异系数 CV ] [ 极差 ] [ P90 ]            │
├──────────────────────────────────────────────────────┤
│ ③ 箱线图（SVG，高 200）                                  │
│    ── 行业基线 12.34（虚线，有匹配才画）                    │
│    ── 行业先进值 9.80（虚线）                             │
├──────────────────────────────────────────────────────┤
│ ④ 直方图（SVG，高 200，分箱 ceil(√n) ≥ 5）                │
├──────────────────────────────────────────────────────┤
│ ⑤ 分组对比表   Tab：按区域 ｜ 按工艺 ｜ 按年度             │
│    列：分组项 ｜ n ｜ 均值 ｜ 中位数 ｜ (n≥5 时) 标准差/CV   │
├──────────────────────────────────────────────────────┤
│ ⑥ 底部操作栏  [保存统计快照(P1·灰)]  [导出统计(P1·灰)]      │
└──────────────────────────────────────────────────────┘
```

### 4.3 指标卡规格

| 卡片 | 数值 | 副行说明 |
| :--- | :--- | :--- |
| 样本数 n | 整数 | 「已排除 X 条不可比记录」 |
| 均值 | 2 位小数 + 单位 | 「算术平均」 |
| 中位数 | 2 位小数 + 单位 | 主视觉（加大字号）；右上角标 `★ 代表性水平`；有基线时角标「行业基线 {值}」 |
| 标准差 | 2 位小数 | 「样本标准差 (n-1)」 |
| 变异系数 CV | 百分比 1 位 | 「std/mean」 |
| 极差 | 2 位小数 | 「max − min」 |
| P90 | 2 位小数 | 「90% 分位（线性插值）」 |

### 4.4 SVG 图表规格

**箱线图**

| 项 | 规格 |
| :--- | :--- |
| 坐标 | 单一水平轴（值域 = [min−10% padding, max+10% padding]） |
| 箱体 | Q1–Q3 矩形（主题色 20% 填充），中位数实线加粗 |
| 须线 | 1.5×IQR 内的 min / max |
| 离群点 | 单点圆标记；hover 显示 `CR-2025-0007：8.9120`；提供「仅看离群」文字链（R-008） |
| 参考线 | 行业基线 / 行业先进值各一条虚线（颜色区分），左端标签；无匹配则整块不渲染（V20） |

**直方图**

| 项 | 规格 |
| :--- | :--- |
| 分箱 | `ceil(√n)`，最少 5 箱；等宽 |
| 柱体 | 主题色 60% 填充；hover 显示 `区间 [a, b)：k 条` |
| 轴 | x = 值区间，y = 频数（整数刻度） |
| 均值/中位数线 | 两条竖直虚线（图例区分） |

### 4.5 状态与降级

| 情况 | 呈现 |
| :--- | :--- |
| `n = 0` | 空态「当前筛选条件下无记录，请调整筛选条件后重试」+ `返回调整筛选` 按钮 |
| `1 ≤ n < 5` | 指标卡只渲染第一排；第二排与两图位置显示灰块说明「样本不足（n < 5），暂不提供离散度与分布分析」（R-006）；分组表仅显示 n 与均值（S07） |
| 全部记录阶段缺失 | 不渲染「阶段结构」区（P1 功能，本期默认不渲染该区） |
| 单位/口径排除 | 口径条显示排除条数；hover 列出被排除记录编号 |
| 基线匹配失败 | 参考线区域无渲染，指标卡无角标，**不显示任何报错** |
