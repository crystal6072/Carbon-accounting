# 行业数据集字段清单

> **文档定位**：行业数据集管理模块的**字段真相源**（SST）。定义「碳足迹核算记录台账行（`CarbonRecord`）」「阶段数值（`RecordStageValue`）」「统计快照（`RecordStatSnapshot`，P1）」三类对象的字段结构、枚举、字段级约束与统计口径。业务规则见《行业数据集业务 PRD》，页面控件见《行业数据集_Demo》（待产出）。
>
> **【口径声明 · 2026-11-03 · 台账化方案】**
> - 本模块**不建「数据集」实体**：台账即数据集，一行 = 一次核算结果；「归集」= 核算完成自动入账 + 手工补录，**不设容器对象、不设样本归属关系**。
> - **不设版本号、不设审核流、不设数据集状态机**：入库即快照，重算产生新行并替代旧行（D03）。
> - **统计对象 = 当前筛选结果集**，不预先绑定固定样本集合；如需留痕，另存「统计快照」（P1，D13）。
> - 与《整体设计方案 v1.2》§5.3「**共享数据集**」（关联项目间复用的活动数据集合）**不是同一对象**，术语见 §0.2。
>
> **【字段口径对齐声明】**
> - 结果数值（总值 / 阶段值 / 功能单位 / 四口径）沿用《碳足迹核算字段清单》，本清单**不重复定义计算规则**。
> - 行业 / 产品类别 / 工艺流程 / 区域 / 阶段 均为**引用字段**，候选来自对应基础库（行业库、产品品类、工艺流程库、数据字典、生命周期阶段库），本模块不维护主数据。
> - 字段名保持英文原文（`camelCase`），中文为业务名称；业务 PRD 与 Demo 只引用字段名称。

## 1. 对象结构

### 1.1 关系全景

```text
碳足迹核算记录（CarbonRecord） N          ← 一行 = 一次核算结果（台账行，入库即快照）
   ├── N  阶段数值（RecordStageValue）     ← 内嵌子表，一级阶段必填、二级选填
   └── 0/1 来源核算项目（只读引用，不写回）

统计快照（RecordStatSnapshot） 1（P1）     ← 保存「某一组筛选条件 + 统计结果」
   └── N  分组统计（SnapshotGroupStat）    ← 按区域 / 工艺 / 年度 分组结果
```

| 结构 | 对象 | 与主对象关系 | 唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主对象 | 碳足迹核算记录 | 主对象 | 记录编号 `recordNo` | 本清单定义范围；一行 = 一条核算结果 |
| 子对象 | 阶段数值 | 1:N（内嵌） | 记录编号 + 阶段编码 | 一级必填、二级选填；允许整体缺失（标「阶段缺失」） |
| 关联（只读） | 核算项目 | N:1 | 项目编号 + 核算结果版本 | 来源，只读引用；不写回 |
| 分析对象（P1） | 统计快照 | 独立对象 | 快照编号 `statNo` | 冻结筛选条件 + 统计指标 + 分布数据 |
| 分析对象（P1） | 分组统计 | 1:N（内嵌快照） | 快照编号 + 分组键 | 按区域 / 工艺 / 年度分组 |

> **关系说明**：一个核算项目可产生多条核算记录（每次重算 = 一条新记录），但**同一项目同一结果版本只允许入账一条**（D02）；重算后旧记录置「已替代」，默认不进入统计（D03）。

### 1.2 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | **系统写入**（核算项目「已核算」后自动入账）+ **用户补录**（手工新增历史 / 外部数据） |
| 外部系统数据源 | 否（一期不接外部接口，通过手工补录或 CSV 导入，CSV 导入为 P1） |
| 新增 | 自动入账（无界面）；手工补录（弹窗） |
| 编辑 | **台账数值不可编辑**（快照）；仅可改「备注」与「作废」 |
| 子表 | 阶段数值（随记录写入，不单独维护）；统计快照（P1，可保存 / 删除） |
| 导入导出 | 导入：P1（CSV 模板）；导出：P0（台账列表导出 Excel/CSV，验收演示用） |
| 状态 | 有效 / 已替代 / 作废（D03 / D10） |
| 关键唯一键 | `recordNo` 唯一；业务唯一键 `sourceProjectId + resultVersion`（自动来源） |
| 历史兼容 | 无历史数据迁移；上线前的存量项目按「补录」处理 |

### 1.3 关键数据约束

| 约束ID | 约束 | 影响对象 | 违反处理 |
| :--- | :--- | :--- | :--- |
| D01 | 记录编号系统生成、租户内唯一、**不可修改**；格式 `CR-{年度}-{4位流水}` | 主表 | 系统行为 |
| D02 | **同一「核算项目 + 核算结果版本」仅允许入账一条**（幂等）；重复触发只更新入账时间，不新增行 | 主表 | 阻断新增 |
| D03 | 同一项目的旧版本记录置「**已替代**」；默认列表与统计**只取「有效」记录**，避免重复计数 | 主表 | 系统行为 |
| D04 | **区域必填**（引用数据字典「区域」）；自动入账时取核算项目「区域」字段，缺失则置「未填」并在列表标黄，允许后续补填 | 主表 | 补填（不阻断入账） |
| D05 | **产品类别 / 行业 / 工艺**必填；任一项缺失则记录不可进入统计（标「标签不全」） | 主表 | 统计时排除 |
| D06 | **入库即快照**：核算项目后续重算 / 改名 / 删除，均**不回溯**已入库记录的数值与标签 | 主表 | 系统行为 |
| D07 | 阶段数值**允许整体为空**（外部补录数据常只有总值）：为空时标「阶段缺失」，仅参与总值统计，不参与阶段统计 | 子表 | 提示，不阻断 |
| D08 | 阶段值与总值一致性：**Σ 一级阶段 = 总值（容差 ±0.5%）**；超差标「阶段不闭合」（提示，不阻断，不修正原值） | 子表 / 主表 | 提示 |
| D09 | 数值精度：总值 / 阶段值 **4 位小数**存储、2 位展示；`≥ 0` | 主表 / 子表 | 阻断入库 |
| D10 | **不物理删除**：作废后保留可查、可导出，但不进入统计；作废须填原因（≤200 字符） | 主表 | 系统行为 |
| D11 | 手工补录必填：来源说明（≤200 字符）+ 引用依据（附件或外链，可空但需提示） | 主表 | 阻断保存 |
| D12 | 单位一致性：同一统计集内**功能单位必须一致**；不一致的记录自动排除并提示 | 统计 | 统计时排除 |
| D13 | 统计快照**保存即冻结**：筛选条件、记录集、指标值均不可改，只能删除重建（P1） | 统计快照 | 系统行为 |
| D14 | 权限：仅可见**本组织**记录；跨组织不可见（`orgId` 数据域）；行业基线参考值为**只读引用**，不可在本模块编辑 | 全对象 | 阻断访问 |
| D15 | 台账**不写回**核算项目、核算结果、报告；本模块为只读消费方 | 全对象 | 架构约束 |
| D16 | 自动入账以**核算结果「已完成 / 已核算」状态**为前置；检测未通过、核算中的项目不入账 | 主表 | 不入账 |

## 3. 子对象：阶段数值（`RecordStageValue`）

| 字段名称 | 英文名 | 类型 | 来源 | 必填 | 说明 |
| :--- | :--- | :--- | :--- | :---: | :--- |
| 阶段编码 | `stageCode` | string | 生命周期阶段库 | 是 | 引用阶段库；同记录内不重复 |
| 阶段名称 | `stageName` | string | 阶段库快照 | 是 | **引用即复制**，阶段改名不回写 |
| 阶段层级 | `stageLevel` | 1 \| 2 | 阶段库 | 是 | 1 一级 / 2 二级 |
| 上级阶段编码 | `parentStageCode` | string | 阶段库 | 条件 | 二级必填 |
| 阶段排放值 | `stageEmission` | decimal | 核算结果 | 是 | kgCO₂e / 声明单位；4 位小数、`≥ 0` |
| 阶段占比 | `stageShare` | decimal | 派生 | 是 | `stageEmission / totalEmission × 100%`，1 位小数；总值为 0 显示「—」 |
| 数据状态 | `dataStatus` | enum | 派生 | 是 | 正常 / 二期缺失 / 不适用 |

**阶段规则**

| # | 规则 |
| :-- | :--- |
| ST1 | 一级阶段：核算结果有值则全量写入；二级阶段有值则写入，无值不占位 |
| ST2 | 二级阶段**不进入总值汇总**（仅展示与结构分析），避免重复计入 |
| ST3 | 阶段值全部缺失时，`stageComplete = 缺失`，该记录只参与总值统计（D07） |
| ST4 | 检索「按阶段」= 命中**含该阶段数值**的记录；阶段筛选不改变总值统计口径 |

## 6. 字段级联动与统计口径

### 6.1 入账联动

```text
核算项目状态 = 已核算
        ↓
读取：产品名称/编码、产品类别、所属行业、系统边界、统计时间、声明单位、
      工艺流程、区域（项目字段）、总值、阶段值、结果版本
        ↓
标签完整性校验（D04 / D05）→ 缺「区域」置「未填」并标黄；缺类别/行业/工艺 → 标「标签不全」
        ↓
写入记录（快照）→ 同项目旧版本置「已替代」（D03）
```

| # | 联动 |
| :-- | :--- |
| C01 | 核算项目重算 → 新记录入账 + 旧记录「已替代」；台账不回溯旧值（D06） |
| C02 | 手工补录选择「引用已有项目」→ 自动带出标签与数值，仅允许改区域 / 工艺 / 来源说明 |
| C03 | 修改区域 / 工艺 → 仅影响筛选与分组，不重算任何数值 |
| C04 | 作废记录 → 从统计集移除，列表默认隐藏（可切「显示作废」） |
| C05 | 产品类别选择父类 → 检索时含全部子类；统计分组按所选层级聚合（R-005） |

### 6.2 统计口径（S 规则 · 与业务 PRD §6 同源）

| 编号 | 规则 |
| :--- | :--- |
| **S01** | 统计对象 = **当前筛选命中的有效记录集**；不预绑定样本池，不跨筛选条件合并 |
| **S02** | 均值 = 算术平均；加权均值本期不做 |
| **S03** | 中位数：n 为奇数取中间值；偶数取中间两值平均；**作为「代表性水平」首选指标**（抗离群） |
| **S04** | 百分位采用**线性插值**（`numpy.percentile` 默认口径）；P25 / P75 / P90 必备 |
| **S05** | 离散度：样本标准差（分母 n-1）、极差（max-min）、CV = 标准差 / 均值；`n < 5` 不出（R-006） |
| **S06** | 分布：直方图分箱数 = `ceil(√n)`（最少 5 箱）；箱线图须线 = 1.5×IQR；离群值**标记不剔除** |
| **S07** | 分组对比：按区域 / 工艺 / 年度分组，组内 `n < 5` 仅显示 n 与均值，不显示离散度与分布 |
| **S08** | 精度：数值 4 位小数存储、2 位展示；CV 以百分比展示保留 1 位；占比 1 位小数 |
| **S09** | 可比性：**边界、口径、GWP 版本、声明单位**任一不一致的记录不进入同一统计集，界面提示排除条数（D12） |
| **S10** | 总值统计与阶段统计分别计算样本量（阶段缺失记录只进总值统计，D07 / ST3） |
