> **【以原型为准修订声明 · 2026-10-13（V0.2），全文优先，废止 V0.1 中与原型冲突的条款】**：本文与前端原型（`06prototypes/6-1系统原型骨架/src/pages/myProduct/`）冲突之处，**一律以原型为准**：
> - **产品来源为「二态」**（业务裁定 2026-09-28）：`referenced` 引用标准产品（平台级 `PUBLIC`，只读指向，不可编辑 / 删除，上下架随后台）+ `custom` 自己新增（组织自建 `ORG`，可编辑）。**「复制成新的」已取消**（S03 / C5 / C6 / §4.1 第三行 / §6.2 复制列 / R-004 相关表述作废）。
> - **新增 = 弹窗二选一**：「引用产品库」（打开批量引用弹窗，从平台产品信息库勾选引用，支持跳过已存在项）/「自定义产品」（进入新增 / 编辑表单）。
> - **表单字段（以 `MyProductFormPage.tsx` 为准）**：产品编码（必填，唯一，含平台库查重）/ 产品名称（必填）/ 产品分类（必填，三级级联）/ 规格（选填）/ **产品批次号（选填）** / **生产地点（选填）** / **生产功能（选填）** / 单位（必填，计量单位库）/ 所属行业（必填，行业四级级联）/ 产品来源（只读带出「自己新增」）/ 归属组织（只读带出）/ **产品图片（必填）** / 产品描述（选填）。**型号不再维护**（表单无型号录入项，产品库不再维护型号）；**产品场景应用为选填**（场景说明 + 多张场景图片）。
> - **工艺流程为选填**（可不关联工艺）；已关联时组合校验（阻断级）：每个工艺流程至少 1 道工序、同工艺内工序顺序不重复、**同一生命周期阶段只能绑定一个工艺流程**、**末道工序的产出必须为「成品」**。
> - **保存后为「下架」状态**，通过组合校验后可上架供核算项目选择；工艺与工序组合支持**画布 / 列表**两种展示模式（全屏画布）。
> - **删除**：仅「自己新增 且 未被核算项目引用」可删（列表与详情页均 disabled 并提示）；**导出**为原型模拟（Toast「导出任务已创建」），无真实文件。

## 1. 需求概述

### 1.1 需求背景

我的产品库是前台业务平台的**组织自建产品维护面 + 核算人员的引用面**（方案 §2.2 分层：前台是「核算人员的日常作业面」）。与后台「产品信息库」（平台级标准产品 `PUBLIC`）按数据归属 `ORG` / `PUBLIC` 分离（方案 §3.3.3）。

组织管理员需要在前台维护**本组织自建的产品**，核算人员需要从这里**引用产品**开展核算。产品 = 基本信息 + 工艺 + 工序的组合（方案 §4.2.2）。

**业务裁定（2026-09-24）**：
1. **不要版本化** —— 产品即单一对象，直接修改，不设版本号 / 版本状态
2. **引用标准产品不可修改** —— 从平台级产品信息库引用，只读
3. **允许「复制成新的」调整** —— 复制标准/已有产品生成可编辑的组织自建产品
4. **允许「自己新增」** —— 组织管理员从零新建

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :--- | :--- | :--- |
| G1 | 支持两种产品来源 | 引用标准产品（只读）、自己新增 均可落地 |
| G2 | 引用标准产品只读 | 引用项无编辑 / 上下架 / 删除入口，点击不可修改 |
| G3 | 自建产品可完整编辑 | 自己新增的产品可修改基本信息、产品场景与工艺工序组合 |
| G4 | 产品可被核算项目稳定引用 | P19 引用产品时生成项目侧快照，产品后续修改不影响已建项目（方案 §4.9） |
| G5 | 下架控制可用范围 | 下架产品不可被新项目选择，历史引用保留 |

## 2. 用户与使用场景

### S01 引用标准产品

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要把平台级标准产品纳入本组织可引用范围 |
| 操作流程 | 列表「引用标准产品」→ 从平台级产品信息库选择 → 确认 |
| 预期结果 | 列表新增一条「引用标准产品」记录，**全字段只读**，无编辑入口；上下架状态随后台 |

### S02 自己新增产品

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 有一个新的组织自建产品需要建档 |
| 操作流程 | 列表「新增」→ 填写基本信息（名称、分类、型号、规格、单位、行业等）→ 添加工艺流程 → 带出工序并调整顺序 → 保存 |
| 预期结果 | 产品创建成功（产品来源 = 自己新增）；组合校验通过；可被项目引用（需先上架） |

### S03 复制成新的

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要在标准产品（或已有产品）基础上调整形成本组织产品 |
| 操作流程 | 列表对某产品（引用标准产品 / 已有产品）点「复制成新的」→ 系统带出基本信息 + 工艺 + 工序组合 → 修改 → 保存 |
| 预期结果 | 生成新的组织自建产品（产品来源 = 复制成新的，来源产品 = 源产品编码）；可自由编辑调整 |

### S04 编辑产品

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 组织自建产品信息需要修正 |
| 操作流程 | 列表点「编辑」→ 修改字段 → 保存 |
| 预期结果 | 仅「复制成新的 / 自己新增」产品可编辑；「引用标准产品」无编辑入口 |

### S05 上架 / 下架

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 产品需要投入或停止使用 |
| 操作流程 | 列表/详情页点「上架」或「下架」→ 二次确认 → 确认 |
| 预期结果 | 上架：可被新核算项目选择；下架：新项目不可选，历史项目引用与核算结果不受影响 |

### S06 被核算项目引用后的表现

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 某产品已被核算项目引用 |
| 操作流程 | 编辑 / 删除该产品 |
| 预期结果 | 项目侧已生成快照，产品后续修改**不影响已建项目**（方案 §4.9）；详情页展示「引用核算项目数」提示；删除受 R-009 约束 |

### S07 查看产品详情与操作日志

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要查看产品完整定义或历史变更 |
| 操作流程 | 列表点编码/名称进入详情页 → 查看基本信息、工艺工序 → 展开操作日志 |
| 预期结果 | 展示完整字段（含子表）与制单信息；操作日志可折叠并分页 |

## 4. 产品来源与组合规则

> 本章为模块核心。**「产品来源」三态已由业务裁定（2026-09-24），不得偏离。**

### 4.1 产品来源二态（V0.2 修订）

| 来源 | 可编辑 | 落库 | 上下架控制 | 说明 |
| :--- | :---: | :---: | :--- | :--- |
| 引用标准产品（`referenced`） | 否（只读） | 否（只读指向平台级产品） | 随后台产品信息库 | 从平台级产品信息库（`PUBLIC`）批量引用；平台产品须先引用后方可进入核算候选 |
| 自己新增（`custom`） | 是 | 是（`ORG`） | 本模块控制 | 从零新建组织自建产品 |

> **「复制成新的」已取消**（业务裁定 2026-09-28）：需要基于标准产品调整时，请在后台申请变更后重新引用，或自行新增产品。

### 4.2 引用标准产品规则

| # | 规则 |
| :--- | :--- |
| C1 | 引用标准产品**全字段只读**，不提供编辑入口（不渲染 disabled 假入口，直接不展示编辑按钮） |
| C2 | 引用标准产品的上下架状态**随后台产品信息库**（后台下架后，本模块引用项同步不可选【待确认 Q07】） |
| C3 | 引用标准产品**不可删除**（只读项） |
| C4 | 引用标准产品的详情页可查看，但不展示操作日志编辑痕迹（只读展示） |

### 4.3 复制成新的 / 自己新增规则

| # | 规则 |
| :--- | :--- |
| C5 | 复制成新的：系统带出源产品的**基本信息 + 工艺 + 工序组合**（【待确认 Q04】），用户修改后保存为新组织自建产品 |
| C6 | 复制成新的：生成**全新产品编码**（【待确认 Q03】），保留「来源产品」追溯 |
| C7 | 自己新增：从零填写基本信息 + 组合工艺工序 |
| C8 | 归属组织**取当前登录用户所属组织**，自动带出、不可改（字段清单 D03） |

### 4.4 产品与工艺、工序的组合规则

| # | 规则 |
| :--- | :--- |
| C9 | **工艺流程为选填**（产品可不关联工艺，V0.2 修订）；已关联时**每个工艺流程至少包含 1 道工序**（阻断级） |
| C10 | 工艺流程从「工艺流程库」引用，仅可选择**启用**状态的工艺流程 |
| C11 | 工序从「工序管理」引用，随所选工艺流程带出并**复制为产品副本**（对齐工序字段清单「模板 + 引用即复制」口径）；副本保留「来源模板标识」 |
| C12 | 同一工艺流程下的工序顺序连续且不重复（阻断级） |
| C13 | **同一生命周期阶段只能绑定一个工艺流程**（阻断级，2026-09-29 新增；阶段随工艺带出） |
| C14 | **末道工序的产出须为「产品」（成品）**（**阻断级**，V0.2 修订——原型 `assertComposition` 硬校验） |
| C15 | 投入产出流在本模块**只读展示**，维护归属为「工序管理」（A1-8），本模块不提供编辑入口 |

### 4.5 组合变更的影响

| 场景 | 处理 |
| :--- | :--- |
| 组织自建产品（复制成新的/自己新增）内调整工艺/工序 | 允许，保存后重新校验 C9～C14 |
| 引用标准产品调整工艺/工序 | 不可调整（只读） |
| 上游工艺流程/工序模板变更 | 已复制到产品的副本**不回写**（对齐工序字段清单 D13）；产品如需采用新工艺，可「复制成新的」重新生成 |
| 产品已被核算项目引用后修改 | 项目侧已生成快照，**不影响已建项目**（方案 §4.9） |

## 5. 上架 / 下架规则

| 规则编号 | 规则名称 | 触发条件 | 处理逻辑 | 例外策略 |
| :--- | :--- | :--- | :--- | :--- |
| R-001 | 产品编码唯一 | 新增保存时 | 编码在本模块 + 平台产品信息库范围内唯一（原型 `createMyProduct` 跨库查重） | 重复时阻断保存并提示「产品编码已存在（含平台级产品信息库）」 |
| R-002 | 产品分类引用约束 | 选择产品分类时 | 只能选择「启用」状态的分类；分类被禁用后不可新选 | 命中时提示分类已禁用 |
| R-003 | 组合完整性校验 | 保存产品时 | 校验 C9 / C12 / C13 / C14（均为阻断级）：每工艺 ≥1 工序、工序顺序不重复、同一阶段仅一个工艺、末道产出为成品 | 未关联工艺时跳过组合校验 |
| R-004 | 引用标准产品只读 | 对引用标准产品操作时 | 无编辑 / 上下架 / 删除入口 | 只能重新引用或自行新增 |
| R-005 | 自建产品可编辑 | 对自己新增产品操作时 | 可编辑基本信息、产品场景与工艺工序组合 | 被项目引用后仍可编辑（项目侧快照保护） |
| R-006 | 上架 / 下架作用对象 | 上架 / 下架操作时 | 直接作用于产品（无版本维度）；下架后不可被新项目选择；**新增保存后为「下架」态** | 引用标准产品上下架随后台，本模块只读 |
| R-007 | 下架后的下游影响 | 产品下架后 | 新项目不可选择该产品；已引用该产品的项目、核算结果不受影响 | 无例外 |
| R-008 | 快照引用 | 核算项目引用产品时 | 项目记录「产品 + 引用时点快照」，**禁止实时引用**（对齐方案 §4.9） | 无例外 |
| R-009 | 删除规则 | 删除产品时 | 仅「自己新增 且 未被项目引用」的产品可删除；引用标准产品不可删除 | 命中时阻断并说明原因（列表 / 详情页删除按钮 disabled + tip） |
| R-010 | 归属组织自动带出 | 新增时 | 归属组织取当前登录用户所属组织，不可改（D03） | 无例外 |

## 6. 状态与操作矩阵

### 6.1 状态维度说明

| 状态维度 | 取值 | 来源 |

### 6.2 操作矩阵

| 产品来源 | 使用状态 | 编辑 | 上架 | 下架 | 删除 | 被新项目选择 |
