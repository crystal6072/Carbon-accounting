# 我的产品库字段清单

> **文档定位**：我的产品库字段定义的唯一真相源（SST）。业务 PRD 和 Demo PRD 只引用字段名称，不重复维护枚举、必填性和字段口径。
> **适用类型**：组织自建产品的完整主数据维护模块（带可维护子表），**无版本化**
> **核心对象**：**产品 = 产品基本信息 + 工艺 + 工序的组合**（方案 §4.2.2）；**无版本化**（业务裁定 2026-09-24）
> **维护形态**：列表 + 独立详情页 + 独立新增/编辑页；**支持操作日志**（详情页可折叠）
> **成熟度**：粗纲
> **版本**：V0.1
> **更新时间**：2026-09-24

## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 我的产品库 |
| 业务归属 | 前台业务平台 → 我的产品库（方案 §2.2 功能架构 B2、§2.3 B2-1 / B2-2、§八 P27） |
| 模块类型 | 组织自建产品的完整主数据（带可维护子表），**无版本化** |
| 核心对象 | 产品（无版本维度） |
| 核心职责 | 作为**组织自建产品**的维护面 + 核算人员的引用面；支持「引用标准产品（只读）/ 复制成新的 / 自己新增」三种来源，向核算项目提供可引用的产品 |

### 1.2 对象结构

| 结构 | 对象 | 与主对象关系 | 主键/唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 产品 | 主对象 | 产品编码 | **无版本化**（业务裁定 2026-09-24）；产品来源三态（引用标准产品 / 复制成新的 / 自己新增） |
| 子表 | 产品工艺 | 1:N | 产品 + 工艺流程 | 引用「工艺流程库」的工艺流程（A1-7） |
| 子表（孙表） | 产品工序 | 1:N（挂在产品工艺下） | 产品 + 工艺 + 工序顺序 | 引用「工序管理」的工序（A1-8），随工艺流程带出并**复制为产品副本** |
| 只读明细 | 投入产出流 | 1:N（挂在产品工序下，只读） | 工序 | **维护归属为「工序管理」，本模块只读展示** |

**对象结构说明（业务裁定 2026-09-24）**

```text
产品（无版本维度）
├── 基本信息：编码、名称、产品来源、来源产品、分类、型号、规格、单位、行业、图片、描述、归属组织、使用状态
├── 产品工艺（1:N）：引用工艺流程库
│   └── 产品工序（1:N）：随工艺流程带出，复制为产品副本
│       └── 投入项 / 产出项（只读展示，维护归属工序管理）

产品来源三态：
├── 引用标准产品（只读）：从平台级产品信息库（PUBLIC）引用，不可修改
├── 复制成新的（可编辑）：复制标准/已有产品 → 生成组织自建产品（ORG）
└── 自己新增（可编辑）：从零新建组织自建产品（ORG）
```

> **与后台「产品信息库」的差异**：后台产品信息库为平台级标准产品（`PUBLIC`）+ 版本化；本模块为组织自建产品（`ORG`）+ **无版本化**。结构（产品 → 工艺 → 工序）对齐，但**取消版本维度**，且引入「产品来源」三态。

### 1.3 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | **引用标准产品**（平台级产品信息库，只读） + **组织自建**（复制成新的 / 自己新增，可编辑） |
| ERP是否数据源 | 否 |
| 新增编辑 | 仅「复制成新的 / 自己新增」可编辑；「引用标准产品」只读（不提供编辑入口） |
| 子表 | 可维护（产品工艺、产品工序）；投入产出流为只读展示 |
| 导入导出 | 导出：支持（【待确认】范围）；导入：V0.1 不支持（【待确认】） |
| 状态与执行 | 使用状态（上架 / 下架）；**无版本化、无审核流、无外部系统推送、无单据下推** |
| 关键唯一键 | 产品编码（唯一） |
| 历史兼容 | 产品被核算项目引用时，项目侧按快照冻结（方案 §4.9）；产品侧无需版本化 |

### 1.4 关键数据约束

| 约束ID | 约束 | 影响对象 |
| :--- | :--- | :--- |
| D01 | 产品编码唯一（【待确认】唯一范围） | 主表 |
| D02 | **产品来源 ∈ {引用标准产品 / 复制成新的 / 自己新增}**；引用标准产品 → 全字段只读、无编辑入口 | 主表 |
| D03 | 「复制成新的 / 自己新增」须归属当前登录用户所属组织（`ORG`），归属组织自动带出、不可改 | 主表 |
| D04 | 产品分类只能引用「启用」状态的分类 | 主表 |
| D05 | 「单位」引用计量单位库 | 主表 |
| D06 | 「所属行业」引用行业库，用于匹配行业阶段基线与核算模型 | 主表 |
| D07 | 组合完整性：至少 1 个工艺流程、至少 1 个工序 | 子表 |
| D08 | 工序顺序在同一工艺流程内不得重复且必须连续 | 子表 |
| D09 | 末道工序的产出须为「产品」（成品）【待确认 校验级别】 | 子表 |
| D10 | 投入产出流在本模块只读展示，维护归属为「工序管理」（A1-8） | 子表 |
| D11 | 使用状态 = 下架时，不可被新的核算项目选择；历史引用保留（项目侧快照） | 主表 |

> **已裁定决策（2026-09-24）**
> - **不要版本化**：不设版本号、版本状态、是否当前版本、版本变更说明等任何版本字段；产品即单一对象，直接修改。
> - **引用标准产品不可修改**：从平台级产品信息库引用的标准产品，在本模块**只读**，不提供编辑入口。
> - **允许「复制成新的」调整**：复制标准产品（或已有产品）生成新的**组织自建产品**，副本可编辑调整。
> - **允许「自己新增」**：组织管理员从零新建组织自建产品。
