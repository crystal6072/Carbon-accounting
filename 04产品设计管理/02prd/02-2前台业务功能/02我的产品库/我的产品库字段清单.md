# 我的产品库字段清单

> **【以原型为准修订声明 · 2026-10-13（V0.2），全文优先，废止 V0.1 中与原型冲突的条款】**：本清单字段与前端原型（`06prototypes/6-1系统原型骨架/src/pages/myProduct/`）冲突之处，**一律以原型为准**：
> - **产品来源为「二态」**（业务裁定 2026-09-28）：`referenced` 引用标准产品（只读）/ `custom` 自己新增；**「复制成新的」已取消**（来源产品仅引用标准产品时展示）。
> - **字段调整**：**移除「型号」**（产品库不再维护型号，表单无录入项）；**新增「产品批次号」「生产地点」「生产功能」**（均选填）；**「产品图片」改为必填**；新增子表「**产品场景应用**」（选填：场景说明 + 多张场景图片）。
> - **工艺流程为选填**（产品可不关联工艺）；已关联时组合校验为阻断级：每工艺 ≥1 工序、工序顺序不重复、同一生命周期阶段仅一个工艺、末道工序产出必须为「成品」。
> - **使用状态**：新增保存后为「下架」，上架后方可被核算项目选择；引用标准产品的上下架随后台产品信息库（只读展示）。
> - **删除边界**：仅「自己新增 且 未被核算项目引用」可删。

> **文档定位**：我的产品库字段定义的唯一真相源（SST）。业务 PRD 和 Demo PRD 只引用字段名称，不重复维护枚举、必填性和字段口径。
> **适用类型**：组织自建产品的完整主数据维护模块（带可维护子表），**无版本化**
> **核心对象**：**产品 = 产品基本信息 + 工艺 + 工序的组合**（方案 §4.2.2）；**无版本化**（业务裁定 2026-09-24）
> **维护形态**：列表 + 独立详情页 + 独立新增/编辑页；**支持操作日志**（详情页可折叠）
> **成熟度**：粗纲
> **版本**：V0.1
> **更新时间**：2026-09-24

## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 我的产品库 |
| 业务归属 | 前台业务平台 → 我的产品库（方案 §2.2 功能架构 B2、§2.3 B2-1 / B2-2、§八 P27） |
| 模块类型 | 组织自建产品的完整主数据（带可维护子表），**无版本化** |
| 核心对象 | 产品（无版本维度） |
| 核心职责 | 作为**组织自建产品**的维护面 + 核算人员的引用面；支持「引用标准产品（只读）/ 复制成新的 / 自己新增」三种来源，向核算项目提供可引用的产品 |

### 1.2 对象结构

| 结构 | 对象 | 与主对象关系 | 主键/唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 产品 | 主对象 | 产品编码 | **无版本化**（业务裁定 2026-09-24）；产品来源**二态**（引用标准产品 / 自己新增，2026-09-28 裁定取消「复制成新的」） |
| 子表 | 产品工艺 | 1:N | 产品 + 工艺流程 | 引用「工艺流程库」的工艺流程（A1-7）；**选填**（产品可不关联工艺） |
| 子表（孙表） | 产品工序 | 1:N（挂在产品工艺下） | 产品 + 工艺 + 工序顺序 | 引用「工序管理」的工序（A1-8），随工艺流程带出并**复制为产品副本** |
| 子表 | 产品场景应用 | 1:N | 产品 + 场景序号 | 选填：场景说明 + 多张场景图片（V0.2 新增） |
| 只读明细 | 投入产出流 | 1:N（挂在产品工序下，只读） | 工序 | **维护归属为「工序管理」，本模块只读展示** |

**对象结构说明（业务裁定 2026-09-24；V0.2 修订）**

```text
产品（无版本维度）
├── 基本信息：编码、名称、产品来源、来源产品、分类、规格、批次号、生产地点、生产功能、单位、行业、图片（必填）、描述、归属组织、使用状态
├── 产品工艺（1:N，选填）：引用工艺流程库
│   └── 产品工序（1:N）：随工艺流程带出，复制为产品副本
│       └── 投入项 / 产出项（只读展示，维护归属工序管理）
└── 产品场景应用（1:N，选填）：场景说明 + 多张场景图片

产品来源二态：
├── 引用标准产品（只读）：从平台级产品信息库（PUBLIC）批量引用，不可修改 / 删除，上下架随后台
└── 自己新增（可编辑）：从零新建组织自建产品（ORG），保存后为下架态
```

> **与后台「产品信息库」的差异**：后台产品信息库为平台级标准产品（`PUBLIC`）+ 版本化；本模块为组织自建产品（`ORG`）+ **无版本化**。结构（产品 → 工艺 → 工序）对齐，但**取消版本维度**，产品来源为二态。

### 1.3 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | **引用标准产品**（平台级产品信息库，只读） + **组织自建**（复制成新的 / 自己新增，可编辑） |
| ERP是否数据源 | 否 |
| 新增编辑 | 仅「复制成新的 / 自己新增」可编辑；「引用标准产品」只读（不提供编辑入口） |
| 子表 | 可维护（产品工艺、产品工序）；投入产出流为只读展示 |
| 导入导出 | 导出：支持（【待确认】范围）；导入：V0.1 不支持（【待确认】） |
| 状态与执行 | 使用状态（上架 / 下架）；**无版本化、无审核流、无外部系统推送、无单据下推** |
| 关键唯一键 | 产品编码（唯一） |
| 历史兼容 | 产品被核算项目引用时，项目侧按快照冻结（方案 §4.9）；产品侧无需版本化 |
