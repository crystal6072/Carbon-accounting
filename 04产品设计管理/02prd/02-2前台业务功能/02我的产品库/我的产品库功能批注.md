## 1. 拟添加的批注清单

### 1.1 整体流程

#### P03-01 产品维护与引用整体流程
**拟标注位置**：功能标题「我的产品库」附近（全局说明）
**标记**：已确认

**批注内容**

- **适用场景**：组织管理员在前台维护本组织产品（自建或从平台级产品库引用复制），核算人员核对产品组合，供核算项目选用。
- **流程**：进入「我的产品库」→ 列表展示本组织全部产品（自建与引用复制统一混排）→ 按需查询、进入详情页核对 → 需要新产品时点「新增」二选一 → 引用 / 保存完成 → 产品保存后为「下架」，上架后方可被核算项目选择。
- **分支一「引用产品库」**：打开「引用标准产品」弹窗，从平台级产品信息库（仅已上架）勾选，引用即把该产品**复制一份**到本组织（可编辑副本），列表新增该副本行。
- **分支二「自定义产品」**：进入新增表单页，填写基本信息、产品场景应用、工艺与工序组合，保存后跳转详情页。
- **衔接**：列表点产品编码或「查看」进详情页；详情页可进入编辑；表单保存后回到详情页。
- **边界**：引用复制副本与自建产品均可编辑 / 上下架 / 删除（仅被核算项目引用时不可删除）；两者差异仅在于「产品来源」与「来源产品」的溯源标识。
- **结束**：没有提交、审核、驳回，也没有版本分支，保存即生效；删除为终态且不可恢复。产品被核算项目引用后，项目侧生成快照，本模块后续修改不影响已建项目。

### 1.2 全局规则说明

#### P03-02 全局规则
**拟标注位置**：功能标题「我的产品库」附近（与整体流程同一全局说明入口）
**标记**：已确认（权限见 §3）

**批注内容**

1. **适用范围**：本模块是前台「组织产品的维护面 + 核算人员的引用复制面」；整个系统共用同一棵产品分类树（由后台「产品分类」维护），本模块只选用、不维护分类。
2. **产品来源二态（均可编辑）**：「引用标准产品」= 从平台级产品信息库**复制一份**到本组织，成为可编辑副本；「自己新增」= 组织从零自建，可编辑。两者在本模块内可编辑程度一致，差异仅为溯源标识（产品来源 / 来源产品）。「复制成新的」已取消，引用即复制。
3. **不版本化**：产品即单一对象，编辑保存后直接覆盖，不设版本号、版本状态、新建版本、版本对比。
4. **无流程节点**：没有提交、审核、驳回。
5. **编码唯一**：产品编码在「我的产品库 + 平台级产品信息库」范围内唯一，新增与编辑保存时都校验，重复即阻断保存。
6. **名称可重复**：产品名称允许重复，靠编码区分（C-02 已确认）。
7. **新增后为下架**：产品（含引用复制副本）保存后默认为「下架」，上架后才可被新的核算项目选择。
8. **引用副本可编辑、源头不回写**：引用复制的产品是独立副本，与自建产品同等可编辑 / 上下架 / 删除；平台级源头产品的后续更新**不回写**本副本。
9. **删除边界**：仅「未被核算项目引用」的产品可删除（自建与引用副本同等），删除后不可恢复。
10. **快照引用**：核算项目引用产品时在项目侧生成快照，产品后续修改不影响已建项目与核算结果。
11. **基础库引用口径**：产品分类（仅可选启用中）、单位（引用计量单位库）、所属行业（引用行业库）、工艺流程与工序（引用后台工艺库 / 工序库）均只引用、不维护；投入产出流只读展示，维护归属「工序管理」。
12. **权限（待确认）**：原型未做角色与权限限制，谁可维护、谁只能查看无法从原型判断 → 见 §3。

### 1.3 业务状态说明

#### P03-03 使用状态（上架 / 下架）
**拟标注位置**：列表「使用状态」列旁、详情页「使用状态」旁、上架 / 下架确认弹窗
**标记**：已确认

**批注内容**

- **含义**：上架 = 可被新的核算项目选择；下架 = 不可被新项目选择，历史引用与核算结果保留。
- **进入条件**：产品保存后为「下架」；「上架」由下架态经行操作进入；「下架」由上架态经行操作进入。引用副本的上下架由本模块控制（不影响平台源头）。
- **可进行的操作**：下架态可「上架」「编辑」「删除」「查看」；上架态可「下架」「编辑」「删除」「查看」。
- **状态变化**：上架 ↔ 下架双向可达、可反复切换；变更只刷新使用状态与更新时间，不改动产品其他内容。
- **对下游的影响**：下架后新核算项目不可选择该产品；已引用该产品的项目、核算结果与报告不受影响。
- **交互表现说明**：页面加载、保存过程中按钮暂不可点等属于交互表现，不视为业务状态。

#### P03-04 产品来源（引用标准产品 / 自己新增）
**拟标注位置**：表单 / 详情「产品来源」旁、新增产品方式弹窗
**标记**：已确认

**批注内容**

- **含义**：标识产品进入本模块的方式（溯源属性），仅用于区分来源，**不决定可编辑性**——两种来源在本模块内均可编辑。
- **进入条件**：由新增入口决定 ——「新增 → 引用产品库」产生的为「引用标准产品」（复制副本）；「新增 → 自定义产品」创建的为「自己新增」。创建后不可变更来源。
- **可进行的操作**：两种来源均可「查看」「编辑」「上架 / 下架」「删除（未被引用时）」。
- **说明**：来源是属性而非流转状态，不随上下架变化；「复制成新的」已取消，引用即复制。

### 1.4 操作功能及对应业务规则

#### P03-05 产品列表
**拟标注位置**：清单表格区域与清单上方工具条
**标记**：已确认

**批注内容**

- **操作目的**：查看并维护本组织全部产品（自建与引用副本混排）。
- **展示列**：产品编码、产品名称、产品分类、单位、使用状态、更新时间、操作（「产品来源」列已按裁决移除）。
- **行入口**：产品编码为链接，点编码或「查看」均进入详情页。
- **分类展示**：产品分类只展示分类名称；该分类被后台禁用时，附「已禁用」标识。
- **使用状态展示**：以标签展示。
- **排序**：全部产品（自建与引用副本）**统一按更新时间倒序，最新排在前面**（C-01 已确认）。
- **分页**：每页 20 条。
- **操作列**：「查看」对全部产品展示；「编辑」「上架 / 下架」「删除」对全部产品展示（引用副本与自建同等）；删除在被引用时置灰。
- **上下架互斥**：操作列按当前状态只显示「上架」或「下架」之一。
- **工具条**：显示「共 N 条」与提示「引用标准产品为可编辑副本、自己新增可维护；列表仅展示核心字段，其余请进入详情页查看」；「共 N 条」统计当前查询结果总条数，不受分页影响。
- **无内容时**：列表为空时不显示任何数据行。

#### P03-06 查询与重置
**拟标注位置**：清单上方查询区
**标记**：已确认（「搜索」按钮行为为原型已表现·待核对）

**批注内容**

- **操作目的**：按条件快速定位产品。
- **查询项**：① 产品编码 —— 按包含关系模糊匹配，忽略大小写；② 产品名称 —— 按包含关系模糊匹配；③ 产品分类 —— 级联下拉（可按分类名称 / 编码搜索），选中任一层级节点时，命中该节点及其全部下级分类下的产品；④ 使用状态 —— 下拉选择「上架 / 下架」，不选即为全部。（「产品来源」查询项已按裁决移除。）
- **规则**：四个条件同时生效（叠加过滤）；任一条件变化后清单回到第 1 页。
- **「搜索」按钮**：点「搜索」执行一次当前条件的筛选；因输入即即时收敛，按钮属于显式触发入口，两种方式结果一致。原型中点「搜索」只出现一次「查询完成」提示、不产生额外动作（待核对）。
- **「重置」**：清空全部条件并恢复完整清单，同时回到第 1 页。

#### P03-08 新增产品（方式二选一）
**拟标注位置**：页头「新增」按钮旁、新增产品弹窗
**标记**：已确认

**批注内容**

- **操作目的**：确定新产品的建立方式。
- **入口**：列表页头「新增」。
- **操作过程**：弹出「新增产品」小弹窗，二选一：
  1. **「引用产品库」** —— 从平台级产品信息库复制标准产品（弹窗内描述：复制一份到本组织，成为可编辑产品）；点后关闭本弹窗并打开「引用标准产品」弹窗。
  2. **「自定义产品」** —— 从零新建组织自建产品（弹窗内描述：可编辑、可上下架、可删除）；点后关闭本弹窗并进入新增表单页。
- **取消**：弹窗底栏仅有「取消」；点「取消」或关闭弹窗不产生任何变更。

#### P03-09 引用标准产品（批量复制弹窗）
**拟标注位置**：「新增 → 引用产品库」打开的引用弹窗
**标记**：已确认（弹窗内「产品分类」列恒空为原型缺陷，见 §3）

**批注内容**

- **操作目的**：把平台级标准产品复制为本组织可编辑产品。
- **数据范围**：仅展示平台级产品信息库中「已上架」的标准产品；下架的平台产品不在本列表展示，不能引用。
- **查询**：按产品编码（包含匹配、忽略大小写）、产品名称（包含匹配）过滤；「重置」清空条件并回到第 1 页；每页 6 条。
- **列表列**：勾选框、产品编码、产品名称、产品分类、单位、引用状态。
- **引用状态**：已复制（本组织已有该平台产品的副本）显示「已引用」并置灰，不可重复复制；未复制的显示「未引用」。
- **批量能力**：① 勾选行后点「引用所选产品（N）」（未勾选时不可点）；② 点「全部引用」一次性复制当前筛选结果中全部未复制项（无可复制项时不可点）。
- **引用口径**：引用 = **复制一份**到本组织（落库为可编辑副本）；复制成功后弹窗关闭、列表新增该副本行，结果提示「引用成功：共 N 条」；若存在跳过项（如重复复制），提示「引用完成：成功 N 条，跳过 M 条」。
- **复制后表现**：新行产品来源 = 引用标准产品（复制副本），与自建产品同等可编辑 / 上下架 / 删除；平台源头产品更新不回写本副本。
- **取消**：点「取消」或关闭弹窗，不产生任何复制。

#### P03-10 自定义产品（新增表单页）
**拟标注位置**：「新增 → 自定义产品」进入的新增产品页
**标记**：已确认

**批注内容**

- **操作目的**：从零建立组织自建产品。
- **入口**：仅「新增 → 自定义产品」；页面标题「新增产品」，页面描述「产品来源 = 自己新增（组织自建）；保存后为下架状态，通过组合校验后可上架」。
- **可操作条件**：恒可操作，不限产品数量。
- **操作过程**：填写「基本信息」（必填项见字段说明）→ 按需维护「产品场景应用」（选填）→ 按需关联「工艺与工序组合」（选填）→ 保存。
- **系统带出**：产品来源固定为「自己新增」（系统带出，不可改）；归属组织自动带出当前登录用户所属组织，不可改。
- **结果**：保存成功后提示「保存成功」并跳转该产品详情页；使用状态为「下架」。
- **取消**：点页头或底栏「取消」返回上一页，不保存任何内容。

#### P03-11 编辑产品
**拟标注位置**：列表操作列「编辑」、详情页页头「编辑」、编辑产品页
**标记**：已确认

**批注内容**

- **操作目的**：修正产品（自建或引用副本）的基本信息、场景应用与工艺工序组合。
- **可操作条件**：全部产品均可编辑（含引用副本）；被核算项目引用后仍可编辑（项目侧快照保护，已建项目不受影响）。
- **操作过程**：打开编辑页，带出现有内容；修改后保存。
- **页面口径**：标题「编辑产品」；页面描述「产品不版本化，保存后直接覆盖；组合校验通过后可上架供核算项目选择」。引用副本编辑时，页面描述增加提示「本产品为引用复制副本，编辑不影响平台级源头产品」。
- **结果**：保存成功后提示「保存成功」并跳转详情页；保存即覆盖原内容，不产生新版本。
- **取消**：点「取消」返回上一页，已修改内容不保存。

#### P03-12 工艺与工序组合维护（画布 / 列表）
**拟标注位置**：新增 / 编辑页「工艺与工序组合」卡片及画布工具栏
**标记**：已确认

**批注内容**

- **操作目的**：为产品关联工艺流程，并随工艺带出工序形成产品副本。
- **选填口径**：工艺流程为选填，产品可不关联工艺；未关联时保存跳过组合校验。
- **添加工艺流程**：点「+ 添加工艺流程」新增一个工艺块（工艺顺序按添加先后编号）；在工艺块内下拉选择工艺流程（来源为后台工艺流程库，仅可选启用状态）。选中后：
  - 「所属生命周期阶段」随工艺流程带出（一个工艺流程对应一个阶段）；
  - 该工艺的工序随模板带出并复制为产品内工序副本；
  - 若所选工艺的生命周期阶段已绑定其他工艺流程，即时提示「生命周期阶段『X』已绑定工艺流程『Y』，同一阶段不能重复选择工艺」且该选择不生效。
- **工序维护**：① 可「+ 添加工序」追加（原型默认取工序库列表第一条，模拟行为）；② 画布节点或列表行内可改选工序（改选后按新工序模板重新带出投入 / 产出）；③ 可删除工序（画布节点「×」或列表行「删除」），删除后同工艺内工序顺序自动连续重排；④ 工序顺序在同工艺内连续且不重复。
- **副本口径**：工序副本保留来源模板标识（工序编码 + 复制时点）；副本的投入 / 产出项随工序复制而来，本模块只读展示，维护归属「工序管理」；上游工序模板变更不回写已复制到产品的副本。
- **展示模式**：工艺与工序组合支持「画布」「列表」两种模式（页内切换，全屏时复用）：
  - **画布**：按工艺流程分块横向展示工序节点（序号、名称、投入 / 产出行）；点选中节点后「查看工序」可查看详情，双击节点同样打开工序详情；「全屏」进入全屏画布，「退出全屏」返回。
  - **列表**：按工艺分块以表格展示工序（工序、工序类型、投入项、产出项、计算公式）；无工序时显示引导文案。
- **删除工艺**：每个工艺块提供「删除工艺」，删除后后续工艺顺序自动重排。

#### P03-13 保存与组合校验
**拟标注位置**：表单页底栏「保存」「取消」
**标记**：已确认

**批注内容**

- **保存**：点「保存」先校验填写内容，通过后保存并跳转详情页，提示「保存成功」；保存过程中按钮显示「保存中…」并暂不可点击，避免重复提交。
- **必填校验（任一不通过即阻断保存，页面给出对应提示）**：
  1. 产品编码未填写 → 提示「请输入产品编码」；
  2. 产品名称未填写 → 提示「请输入产品名称」；
  3. 产品分类未选择 → 提示「请选择产品分类」；
  4. 单位未选择 → 提示「请选择单位」；
  5. 所属行业未选择 → 提示「请选择所属行业」；
  6. 产品图片未上传 → 提示「请上传产品图片」。
- **组合校验（保存时执行；未关联工艺流程时跳过，均为阻断级）**：
  1. 每个工艺流程至少 1 道工序；
  2. 同一工艺流程内工序顺序不重复；
  3. 同一生命周期阶段只能绑定一个工艺流程；
  4. 末道工序的产出必须为「成品」。
- **编码查重（阻断）**：产品编码与本模块已有产品、平台级产品信息库产品重复时，提示「产品编码已存在（含平台级产品信息库），请修改后重试」。
- **取消**：点「取消」或返回上一页，不保存任何内容。

#### P03-14 上架 / 下架
**拟标注位置**：列表操作列「上架 / 下架」、详情页页头「上架 / 下架」及二次确认弹窗
**标记**：已确认

**批注内容**

- **操作目的**：控制产品能否被新的核算项目选用。
- **可操作条件**：全部产品（自建与引用副本）均提供入口。
- **操作过程**：点「上架」或「下架」→ 二次确认弹窗（标题「确认上架 / 确认下架」，正文「确认将产品『产品名称』（产品编码）上架 / 下架？」）→ 确认。
- **提示口径**：上架弹窗补充「上架后该产品可被新的核算项目选择」；下架弹窗补充「下架后新项目不可选择该产品；已引用该产品的项目、核算结果与报告不受影响」。
- **结果**：确认后提示「上架成功 / 下架成功」，列表与详情页状态刷新。
- **取消**：点「取消」或关闭弹窗，状态不变。

#### P03-15 删除产品
**拟标注位置**：列表操作列「删除」、详情页页头「删除」及删除确认弹窗
**标记**：已确认

**批注内容**

- **操作目的**：删除不再使用的产品（自建或引用副本）。
- **可操作条件**：仅「未被核算项目引用」的产品可删除（自建与引用副本同等）；被引用时删除按钮置灰并提示原因。
- **禁用表现**：产品已被核算项目引用时，删除按钮置灰不可点；列表与详情页均悬停 / 旁位提示「该产品已被核算项目引用，不可删除」。
- **操作过程**：点「删除」→ 二次确认弹窗（标题「确认删除」，正文「确认删除产品『产品名称』（产品编码）？」，并提示「删除后不可恢复；仅『未被核算项目引用』的产品可删除」）→ 点「确认删除」。
- **结果**：删除成功后提示「删除成功」；从列表页删除后列表刷新，从详情页删除后返回列表页。
- **取消**：点「取消」或关闭弹窗，不删除。
