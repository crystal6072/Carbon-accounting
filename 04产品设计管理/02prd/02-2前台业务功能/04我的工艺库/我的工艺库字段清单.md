## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 我的工艺库 |
| 业务归属 | 前台业务平台 → 我的工艺库（方案 §2.2 B3、§2.3 B3 / B3-1、§八 P09 类） |
| 模块类型 | 组织自建工艺流程的完整主数据（带可维护子表：工序明细），**无版本化**、**无使用状态** |
| 核心对象 | 工艺流程（含工序明细） |
| 核心职责 | 把工序按顺序装配为可复用的生产路径，作为组织内产品工艺组合的复用来源；支持「引用后台工艺（只读）/ 自己新增」二态 |

### 1.2 对象结构

| 结构 | 对象 | 与主对象关系 | 主键/唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 工艺流程 | 主对象 | 工艺流程编码 | **无版本化**、**无使用状态**；工艺来源**二态**（引用后台工艺 / 自己新增） |
| 子表 | 工序明细 | 1:N | 工艺流程 + 工序顺序 | 引用「工序管理」的工序，构成有序工序链；同一工序**允许重复出现**，以序号区分 |
| 只读明细 | 引用/复制情况 | — | — | 「已复制产品数」**本模块不展示**（保持精简，详见 §0 备注） |

### 1.3 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | **引用后台工艺**（平台级工艺流程库，只读、不落库）+ **组织自建**（自己新增，可编辑） |
| ERP是否数据源 | 否 |
| 新增编辑 | 仅「自己新增」可编辑；「引用后台工艺」只读（不提供编辑入口） |
| 子表 | 可维护（工序明细，仅自己新增） |
| 导入导出 | 导出：支持（原型模拟 Toast）；导入：V0.1 不支持（【待确认 Q07】） |
| 状态与执行 | **无使用状态**（已确认移除）、**无版本化**；无审核流、无外部系统推送、无单据下推 |
| 关键唯一键 | 工艺流程编码（跨「我的工艺库 + 后台工艺流程库」唯一） |
| 历史兼容 | 被产品工艺组合引用时，产品侧按复制冻结；工艺侧无需版本化 |
