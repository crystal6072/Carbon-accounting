## 1. 需求概述

### 1.1 需求背景

我的工艺库是前台业务平台的**组织自建工艺流程维护面**（方案 §2.2 分层：前台是「核算人员的日常作业面」）。与后台「工艺流程库」（平台级标准 `PUBLIC`）按数据归属 `ORG` / `PUBLIC` 分离（方案 §3.3.3）。

组织管理员在前台维护本组织的工艺流程，支持两种方式沉淀为可复用生产路径：**引用后台工艺**（只读指向平台级标准工艺）与**自己新增**（从零自建）。工艺流程 = 工序按序装配的工序链，处于「工序 → 工艺流程 → 产品」链条的中间层，是产品工艺组合的复用来源。

**业务确认（2026-10-16）**：

1. **不要使用状态（启用 / 禁用）** —— 可编辑 / 可删除完全由「工艺来源」决定，无独立状态维度。
2. **引用后台工艺不可修改** —— 只读指向，不落库。
3. **允许「自己新增」** —— 组织管理员从零新建组织自建工艺。
4. **「复制成新的」已取消** —— 与我的产品库口径一致，原型无此入口。

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :--- | :--- | :--- |
| G1 | 支持两种工艺来源 | 引用后台工艺（只读）、自己新增（可编辑）均可落地 |
| G2 | 引用后台工艺只读 | 引用项无编辑 / 删除入口，点击仅可查看 |
| G3 | 自建工艺可完整编辑 | 自己新增的工艺可修改基本信息与工序明细 |
| G4 | 工序链可装配与校验 | 工序明细增删改序、同工序可重复；首道投入 / 末道产出 / 中间衔接三条校验均为**提示级、不阻断** |
| G5 | 自建工艺可被组织内复用 | 自己新增的工艺可在组织内被产品工艺组合引用 |

## 2. 用户与使用场景

### S01 引用后台工艺

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要把平台级标准工艺纳入本组织可复用范围 |
| 操作流程 | 列表「新增」→ 选「引用后台工艺」→ 从平台级工艺流程库勾选（仅启用中项、已引用置灰）→ 确认 |
| 预期结果 | 列表新增一条「引用后台工艺」记录，**全字段只读**，仅可查看；不落库（只读指向平台级工艺） |

### S02 自己新增工艺

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 有一条新的生产路径需要沉淀为组织自建模板 |

| 预期结果 | 工艺创建成功（工艺来源 = 自己新增）；工序链校验结果在节点上可见（三条均提示级、不阻断） |

### S03 编辑工艺

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 自己新增的工艺内容需要修正 |
| 操作流程 | 列表点「编辑」→ 修改（含工序明细）→ 保存 |

| 项 | 内容 |

| 项 | 内容 |

## 4. 工艺来源与装配规则

> 本章为模块核心。**「工艺来源」二态已确认（2026-10-16），不得偏离。**

### 4.1 工艺来源二态

| 来源 | 可编辑 | 落库 | 说明 |
| :--- | :---: | :---: | :--- |
| 引用后台工艺（`referenced`） | 否（只读） | 否（只读指向平台级工艺） | 从平台级工艺流程库（`PUBLIC`）批量引用；不落库；平台工艺须先引用后方可进入组织复用 |
| 自己新增（`custom`） | 是 | 是（`ORG`） | 从零新建组织自建工艺 |

> **「复制成新的」已取消**（与我的产品库口径一致）：需要基于标准工艺调整时，请在后台申请变更后重新引用，或自行新增工艺。

### 4.2 引用后台工艺规则

| # | 规则 |
| :--- | :--- |
| C1 | 引用后台工艺**全字段只读**，不提供编辑入口（不渲染 disabled 假入口，直接不展示编辑 / 删除按钮） |
| C2 | 引用后台工艺的可用性**随后台工艺流程库**（后台启用方可被本组织引用；只读展示，本模块不维护状态） |
| C3 | 引用后台工艺**不可删除**（只读项） |
| C4 | 引用后台工艺的详情页可查看，但操作日志为只读展示（无本组织编辑痕迹） |

### 4.3 自己新增规则

| # | 规则 |
| :--- | :--- |
| C5 | 自己新增：从零填写基本信息 + 装配工序明细 |
| C6 | 工艺流程编码在「我的工艺库 + 后台工艺流程库」范围内唯一（跨库查重，原型 `createMyProcess` 已实现） |
| C7 | 自己新增默认对组织内产品工艺组合可用，**无需使用状态门控**（删除「使用状态」后，可用性由来源决定） |

### 4.4 工序明细装配规则

| # | 规则 |
| :--- | :--- |
| A1 | 工序明细**只能引用「启用」状态的工序**；已禁用的工序不可新选 |
| A2 | 工序明细**至少 1 行** |
| A3 | 工序明细**不允许在本模块新增工序定义**；本模块只做引用与排序 |
| A4 | 工序的投入项 / 产出项在本模块**只读展示**，维护归属为「工序管理」（A1-8） |
| A5 | 工序顺序**连续且不重复**：由**流程画布节点自左向右的顺序自动生成**（新增 / 删除 / 插入 / 拖拽后自动重排），不允许手工跳号 |
| A6 | **同一工序允许重复出现**（以节点序号区分）；画布结构 = 序号 + 工序名 + ×删除 + 工序下拉 + 投入 / 产出投影；支持末尾「+ 添加工序」、节点间「+」插入、节点 × 删除、**鼠标拖拽节点调整顺序**；画布 / 列表视图切换 + 画布全屏；**取消「撤销」** |
| A6c | **查看工序详情**：选中节点或点击明细中工序名称查看该引用工序的**只读详情**——工序编码、工序名称、工序类型、工序描述 + 投入项、产出项（**不含「计算公式」列**，保持精简）；该弹窗只读 |

### 4.5 工序链校验规则（**提示级，不阻断保存**）

> **归属（唯一执行方）**：校验在本模块执行（工序模块单工序不含上下游、产品侧仅做组合完整性兜底，与《工艺流程业务 PRD》§4.3 一致）。

**校验对象**：工序明细按「工序顺序」排序后**相邻两行逐对校验**。

| # | 校验规则 | 判定依据 | 级别 |
| :--- | :--- | :--- | :--- |
| A7 | **末道产出为成品** | 末道工序的产出项中应存在「流类型 = 成品」的项；若末道产出仅为中间品则命中 | **提示**（不阻断保存） |
| A8 | **首道投入合规** | 首道工序的投入项应为原辅料 / 能源 / 自然资源输入（不应全部为「中间品」）；命中异常时提示 | **提示**（不阻断保存） |
| A9 | **上下游衔接** | 取上游工序产出中流类型 ∈ {中间品, 产品} 的集合，与本工序全部投入项集合求**交集**：交集非空即衔接通过；为空即「衔接断点」 | **提示**（不阻断保存） |
| A10 | **判定口径** | 按**物料对象一致**（引用对象编码一致）判定，不按名称文本判定；副产品、排放物**不参与**衔接判定 | — |
| A11 | **校验时机与呈现** | 明细变更时**实时提示** + 保存时校验；合规项标注「已衔接」，首道行标注「首道」，异常行标注「衔接断点」并展示断点原因 | — |
| A12 | **校验范围** | 校验只读引用工序的投入产出流，不在本模块修改；工序模板变更后本模块重新计算校验结果 | — |

> **阻断级校验仅剩**：工序明细至少 1 行（R-004）、只能引用启用中工序（R-003）、工序顺序连续不重复（R-005）、编码唯一（R-001）。

## 5. 状态与业务规则

> 本模块**无使用状态维度**（已确认移除），**无版本化**。规则编号自 R-001 起重排。

| 规则编号 | 规则名称 | 触发条件 | 处理逻辑 | 例外策略 |
| :--- | :--- | :--- | :--- | :--- |
| R-001 | 编码唯一 | 新增保存时 | 工艺流程编码在「我的工艺库 + 后台工艺流程库」范围内唯一 | 重复时阻断保存并提示「工艺流程编码已存在（含后台工艺流程库）」 |
| R-002 | 产品分类引用约束 | 选择适用产品分类时 | 只能选择「启用」状态的分类 | 命中时提示分类已禁用 |
| R-003 | 工序引用约束 | 选择工序时 | 仅可选启用中的工序 | 已禁用的工序不在候选列表出现 |
| R-004 | 工序明细至少一行 | 保存时 | 明细为空则阻断 | 无例外 |
| R-005 | 顺序连续性 | 保存时 | 顺序不重复且连续（自动生成） | 命中时定位到行 |
| R-006 | 首道投入规则 | 保存时 / 明细变更时 | 首道投入宜含原辅料 / 能源 / 自然资源输入（A8） | **提示级**，不阻断保存 |
| R-007 | 末道产出为成品 | 保存时 / 明细变更时 | 末道工序产出应含成品（A7） | **提示级**，不阻断保存 |
| R-008 | 上下游衔接校验 | 保存时 / 明细变更时 | 按物料对象逐对校验衔接（A9 / A10） | **提示级**，不阻断保存 |
| R-009 | 引用后台工艺只读 | 对引用后台工艺操作时 | 无编辑 / 删除入口，仅可查看 | 只能重新引用或自行新增 |
| R-010 | 自己新增可编辑 | 对自己新增工艺操作时 | 可编辑基本信息与工序明细 | 被产品引用后仍可编辑（模板 + 引用即复制口径） |
| R-011 | 删除规则 | 删除工艺时 | **仅「自己新增」可删除**；引用后台工艺不可删除 | 二次确认；删除后不可恢复 |
