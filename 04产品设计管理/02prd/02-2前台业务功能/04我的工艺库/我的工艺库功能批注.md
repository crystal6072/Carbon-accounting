## 1. 拟添加的批注清单

### 1.1 整体流程

#### P09-01 组织工艺维护与引用整体流程
**拟标注位置**：功能标题「我的工艺库」附近（全局说明抽屉）
**标记**：已确认

**批注内容**

- **适用场景**：组织管理员在前台维护本组织可复用的工艺流程（自建或从平台级工艺库引用），核算人员在产品工艺组合中引用。
- **流程**：进入「我的工艺库」→ 列表展示本组织全部工艺（引用后台工艺只读 + 自己新增可维护，统一混排）→ 按需查询、进入详情页核对 → 点「新增」二选一 → 保存后（自己新增）进入列表 → 在「产品工艺组合」中被引用。
- **分支一「引用后台工艺」**：打开「新增」二选一弹窗，选「引用后台工艺」→ 从平台级工艺流程库（`PUBLIC`、仅启用中）勾选 → 引用即**只读指向**平台级工艺（不落库），列表新增该只读记录。
- **分支二「新增工艺流程」**：选「新增工艺流程」→ 进入表单页，填写基本信息 + 在流程画布装配工序明细 → 保存后生成组织自建工艺。
- **衔接**：列表点工艺流程编码或「查看」进详情页；详情页可进入编辑（仅自己新增）；表单保存后回到详情页。
- **边界**：**无使用状态维度**（已确认移除）：可编辑 / 可删除完全由「工艺来源」决定，没有启用 / 禁用、没有提交 / 审核 / 驳回、不做版本化。删除为终态且不可恢复（仅自己新增）。被产品工艺组合引用后，产品侧按引用时点复制副本，本模块后续修改不影响已建产品。

### 1.2 全局规则说明

#### P09-02 全局规则
**拟标注位置**：功能标题「我的工艺库」附近（与整体流程同一全局说明入口）
**标记**：已确认（权限见 §3）

**批注内容**

1. **适用范围**：本模块是前台「组织自建工艺流程的维护面 + 核算人员的引用面」；整个系统共用同一棵产品分类树（后台维护），本模块只选用、不维护分类。
2. **工艺来源二态（决定可编辑性）**：「引用后台工艺」= 从平台级（`PUBLIC`）**只读指向**（不落库，可用性随后台工艺流程库）；「自己新增」= 组织从零自建（`ORG`，可编辑）。两者差异仅在于来源，是否可编辑 / 删除**完全由来源决定**，与任何状态无关。
3. **「复制成新的」已取消**：与我的产品库口径一致，原型无此入口；需要调整标准工艺时，请重新引用或自行新增。
4. **无使用状态维度**：不设启用 / 禁用，故列表无「使用状态」列、无启用 / 禁用操作、详情无「使用状态」标签（已确认移除）。
5. **不版本化**：工艺即单一对象，编辑保存后直接覆盖，不设版本号 / 版本状态 / 新建版本 / 版本对比。
6. **编码唯一**：工艺流程编码在「我的工艺库 + 后台工艺流程库」范围内唯一，新增与编辑保存时都校验，重复即阻断保存。
7. **名称可重复**：工艺流程名称允许重复，靠编码区分。
8. **新增后为「自己新增」**：自己新增保存后来源即「自己新增」，默认可编辑；引用后台工艺只读、不可编辑 / 删除。
9. **删除边界**：仅「自己新增」可删除（二次确认），删除后不可恢复；引用后台工艺只读、无删除入口。
10. **快照引用**：被产品工艺组合引用时，产品侧按引用时点复制并冻结副本；本模块后续编辑不影响已建产品与核算结果。
11. **基础库引用口径**：产品分类（仅可选启用中）、行业（引用行业库）、生命周期阶段（引用生命周期库）、工序（引用工序管理，仅启用中）均只引用、不维护；投入 / 产出流只读展示，维护归属「工序管理」。
12. **权限（待确认）**：原型未做角色与权限限制，谁可维护、谁只能查看无法从原型判断 → 见 §3。

### 1.3 业务状态说明

#### P09-03 工艺来源（引用后台工艺 / 自己新增）
**拟标注位置**：列表「工艺来源」展示位置、详情「工艺来源」行、新增工艺二选一弹窗
**标记**：已确认

**批注内容**

- **含义**：标识工艺进入本模块的方式（溯源属性），**决定可编辑性与可删除性**——引用后台工艺只读，自己新增可编辑 / 可删除。
- **进入条件**：由新增入口决定 ——「新增 → 引用后台工艺」产生的为「引用后台工艺」（只读指向）；「新增 → 新增工艺流程」创建的为「自己新增」。创建后不可变更来源。
- **可进行的操作**：
  - 引用后台工艺：仅可「查看」；无编辑 / 删除入口（不渲染 disabled 假入口，直接不展示按钮）。
  - 自己新增：可「查看 / 编辑 / 删除」。
- **说明**：来源是属性而非流转状态，不随任何操作变化；本模块无独立状态维度（无启用 / 禁用）。

### 1.4 操作功能及对应业务规则

#### P09-04 工艺列表
**拟标注位置**：清单表格区域与清单上方工具条
**标记**：已确认（原型含「使用状态」列，见 §3 待对齐）

**批注内容**

- **操作目的**：查看并维护本组织全部工艺（引用后台工艺只读 + 自己新增可维护）。
- **展示列**：工艺流程编码、工艺流程名称、适用产品分类、所属生命周期阶段、工序数量、更新时间、操作。
  - 「工艺来源」**不单列**于列表（已确认），来源靠操作入口区分（引用项仅查看、自己新增有编辑 / 删除）。
  - 「使用状态」列**已确认移除**，原型当前仍展示，需回改（见 §3 待对齐 D 类）。
  - 适用产品分类被后台禁用时，附「已禁用」标识（原型的分类列展示分类名称）。
- **行入口**：工艺流程编码为链接，点编码或「查看」均进入详情页。
- **排序**：按更新时间倒序展示（最新在前）；每页 20 条。
- **操作列**：「查看」对全部工艺展示；「编辑」「删除」**仅「自己新增」展示**（引用后台工艺不展示，不渲染假入口）。
- **工具条**：显示「共 N 条」与提示「引用后台工艺只读、自己新增可维护；列表仅展示核心字段，其余请进入详情页查看」；提供「导出」（原型模拟 Toast「导出任务已创建」）。
- **无内容时**：列表为空时不显示任何数据行。

#### P09-05 查询与重置
**拟标注位置**：清单上方查询区
**标记**：已确认（「工艺来源」筛选项见 §3 待确认 Q01）

**批注内容**

- **操作目的**：按条件快速定位工艺。
- **查询项**：① 工艺流程编码 —— 按包含关系模糊匹配、忽略大小写；② 工艺流程名称 —— 按包含关系模糊匹配；③ 适用产品分类 —— 级联下拉（可按分类名称 / 编码搜索），选中任一层级节点时，命中该节点及其全部下级分类下的工艺。
- **规则**：三个条件同时生效（叠加过滤）；任一条件变化后清单回到第 1 页。
- **「搜索」按钮**：点「搜索」执行一次当前条件的筛选；因输入即即时收敛，按钮属于显式触发入口，两种方式结果一致。原型中点「搜索」只出现一次「查询完成」提示、不产生额外动作（待核对）。
- **「重置」**：清空全部条件并恢复完整清单，同时回到第 1 页。
- **「工艺来源」筛选项**：原型当前**无**该筛选项；是否补充下拉（引用后台工艺 / 自己新增）待确认（见 §3 Q01），与我的产品库口径一致。

#### P09-06 新增工艺（方式二选一）
**拟标注位置**：页头「新增」按钮旁、新增工艺弹窗
**标记**：已确认

**批注内容**

- **操作目的**：确定新工艺的建立方式。
- **入口**：列表页头「新增」。
- **操作过程**：弹出「新增工艺」小弹窗，二选一：
  1. **「引用后台工艺」** —— 从平台级工艺流程库（`PUBLIC`、仅启用中）批量引用（弹窗内描述：只读指向平台级工艺，不可编辑 / 删除，可用性随后台工艺流程库）；点后关闭本弹窗并打开「引用后台工艺」弹窗。
  2. **「新增工艺流程」** —— 从零新建组织自建工艺（弹窗内描述：操作与后台「新增工艺流程」一致，基本信息 + 工序链装配）；点后关闭本弹窗并进入新增表单页。
- **取消**：弹窗底栏仅有「取消」；点「取消」或关闭弹窗不产生任何变更。

#### P09-07 引用后台工艺（批量引用弹窗）
**拟标注位置**：「新增 → 引用后台工艺」打开的引用弹窗
**标记**：已确认

**批注内容**

- **操作目的**：把平台级标准工艺以**只读指向**方式纳入本组织（不落库）。
- **数据范围**：仅展示平台级工艺流程库中「启用」中的工艺；禁用 / 下架的后台工艺不在本列表展示，不能引用。
- **查询**：按工艺流程编码（包含匹配、忽略大小写）、工艺流程名称（包含匹配）、适用产品分类（级联，命中父级及其全部子级）过滤；「重置」清空条件并回到第 1 页；每页 6 条。
- **列表列**：勾选框、工艺流程编码、工艺流程名称、适用产品分类、所属生命周期阶段、工序数、引用状态。
- **引用状态**：已引用的显示「已引用」并置灰，不可重复引用；未引用的显示「未引用」。
- **批量能力**：① 勾选行后点「引用所选工艺（N）」（未勾选时不可点）；② 点「全部引用」一次性引用当前筛选结果中全部未引用项（无可引用项时不可点）。
- **引用口径**：引用 = **只读指向**平台级工艺（不落库）；引用成功后列表新增该只读记录、提示「引用成功：共 N 条」；若存在跳过项（如重复引用），提示「引用完成：成功 N 条，跳过 M 条」。
- **复制后表现**：引用项在本模块全字段只读，仅可查看，无编辑 / 删除入口；其可用性随后台工艺流程库（后台启用方可被引用、被产品使用）。
- **取消**：点「取消」或关闭弹窗，不产生任何引用。

#### P09-08 新增工艺流程（表单页）
**拟标注位置**：「新增 → 新增工艺流程」进入的表单页
**标记**：已确认（复用后台「工艺流程」表单，`scope="frontend"`）

**批注内容**

- **操作目的**：从零建立组织自建工艺。
- **入口**：仅「新增 → 新增工艺流程」；页面标题「新增工艺流程」。
- **可操作条件**：恒可操作，不限工艺数量。
- **操作过程**：填写「基本信息」（必填项见字段说明）→ 在「工序明细」画布 / 列表装配工序（见 P09-10）→ 保存。
- **系统带出**：工艺来源固定为「自己新增」（系统带出，不可改）。
- **结果**：保存成功后提示「保存成功」并跳转该工艺详情页；来源为「自己新增」，默认可编辑。
- **取消**：点页头或底栏「取消」返回列表，不保存任何内容。

#### P09-09 编辑工艺
**拟标注位置**：列表操作列「编辑」、详情页页头「编辑」、编辑工艺页
**标记**：已确认

**批注内容**

- **操作目的**：修正自己新增工艺的基本信息与工序明细。
- **可操作条件**：**仅「自己新增」可编辑**；引用后台工艺无入口（不渲染假入口）。
- **操作过程**：打开编辑页（复用新增表单），带出现有内容；修改后保存。
- **结果**：保存成功后提示「保存成功」并跳转详情页；保存即覆盖原内容，不产生新版本。被产品工艺组合引用后，产品侧已复制副本不受影响（模板 + 引用即复制口径）。
- **取消**：点「取消」返回上一页，已修改内容不保存。

#### P09-10 工序明细维护（画布 / 列表）
**拟标注位置**：新增 / 编辑页「工序明细」卡片及画布工具栏、详情页「工序明细」卡片
**标记**：已确认

**批注内容**

- **操作目的**：为工艺装配有序的工序链（工序按序串联）。
- **选填口径**：工艺流程必含工序（至少 1 道）；工序明细**只引用、不新增**工序定义，本模块仅做装配与排序。
- **添加工序**：点「+ 添加工序」新增节点（或在节点间「+」插入）；下拉选择「工序」（来源为后台工序管理，**仅可选启用中**）。
- **工序维护**：① 可删除工序（画布节点「×」或列表行「删除」），删除后同工艺内工序顺序自动连续重排；② 工序顺序按画布节点顺序自动生成（1..n），不手工填写；③ **同一工序允许重复出现**（以节点序号区分）。
- **副本口径**：工序的投入 / 产出项随工序带出，本模块**只读展示**，维护归属「工序管理」；上游工序模板变更后本模块展示最新并重算校验。
- **展示模式**：工序明细支持「画布」「列表」两种模式（页内切换，全屏时复用）：
  - **画布**：按节点横向展示工序（序号、名称、投入 / 产出行）；点选中节点后「查看工序」可查看详情，双击节点同样打开工序详情；「全屏」进入全屏画布。
  - **列表**：以表格展示工序（工序、工序类型、投入项、产出项）；无工序时显示引导文案。
- **节点交互**：支持鼠标拖拽节点左上角手柄调整顺序；节点间「+」插入；取消「撤销」。
- **查看工序详情**：选中节点或点击明细中工序名称查看该引用工序的只读详情（见 P09-14）。

#### P09-11 保存与工序链校验
**拟标注位置**：表单页底栏「保存」「取消」、表单 / 详情「工序链校验」提示区
**标记**：已确认（三条校验为提示级、不阻断）

**批注内容**

- **保存**：点「保存」先校验填写内容，通过后保存并跳转详情页，提示「保存成功」；保存过程中按钮显示「保存中…」并暂不可点击，避免重复提交。
- **必填校验（任一不通过即阻断保存，页面给出对应提示）**：
  1. 工艺流程编码未填写 → 「请输入工艺流程编码」（或「工艺流程编码已存在（含后台工艺流程库），请修改后重试」）；
  2. 工艺流程名称未填写 → 「请输入工艺流程名称」；
  3. 适用产品分类未选择 → 「请选择适用产品分类」；
  4. 所属行业未选择 → 「请选择所属行业」；
  5. 所属生命周期阶段未选择 → 「请选择所属生命周期阶段」；
  6. 工序明细为空或存在未选工序的节点 → 阻断并高亮。
- **工序链校验（保存时执行；均为提示级、不阻断保存）**：
  1. **首道投入合规**（A8）：首道工序投入宜含原辅料 / 能源 / 自然资源输入，命中异常仅提示；
  2. **末道产出为成品**（A7）：末道工序产出应含「成品」，否则提示；
  3. **上下游衔接**（A9）：相邻工序按物料对象（引用编码）逐对校验衔接，为空即「衔接断点」并展示断点原因。
