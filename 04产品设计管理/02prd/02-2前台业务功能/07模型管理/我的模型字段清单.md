## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 产品碳足迹核算 → 模型管理 → 我的模型 |
| 业务归属 | 前台业务平台 → 产品碳足迹核算 → 模型管理 |
| 模块类型 | 组织级业务对象（有新建/编辑/删除，有来源二态） |
| 核心对象 | **我的模型（MyModel）** |
| 核心职责 | 沉淀本组织可复用的核算模型模板，供新建核算项目引用 |

### 1.2 对象结构

| 结构 | 对象 | 与主对象关系 | 主键/唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主对象 | 我的模型 | 主对象 | 模型编码（`MYM-NNN`） | 本清单主定义范围 |
| 子对象 · 生命周期阶段 | 模型生命周期阶段 | 1:N | 模型 id + 阶段 id | 步骤①配置，含勾选态 |
| 子对象 · 数据项 | 模型数据项（ModelDataItem） | 1:N | 模型 id + 数据项 id | 步骤②配置 |
| 子对象 · 过程节点 | 模型过程节点（ModelProcessNode） | 1:N | 模型 id + 节点 id | 步骤②「继续追溯」生成，可递归 |
| 关联对象 | 平台模型（CarbonModel） | 0/1:1 | `sourceModelId` | 收藏副本追溯用，内容已复制 |

### 1.3 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | 用户填写 + 系统带出（产品分类/核算标准/行业标签）+ 系统生成（编码/来源） |
| 外部系统数据源 | 否 |
| 新增编辑 | 支持新建与编辑；收藏副本只读 |
| 子表 | 按两步向导逐步产生（生命周期阶段 / 数据项 / 过程节点） |
| 导入导出 | 本期不做 |
| 状态与执行 | 无独立状态机；来源二态（`manual` / `collected`）决定编辑/删除权限 |
| 关键唯一键 | 模型编码（全局唯一） |

### 1.4 关键数据约束

| 约束ID | 约束 | 影响对象 |
| :--- | :--- | :--- |
| D01 | 模型编码系统生成、全局唯一、**不可修改** | 主对象 |
| D02 | **一模型一边界**：一个模型只对应 1 种系统边界 | 主对象 |
| D03 | 收藏副本为**复制式快照**，不与源模型联动 | 主对象 + 全部子对象 |
| D04 | 仅 `origin = manual` 可编辑/删除；`collected` 只读 | 主对象 |
| D05 | 模型被核算项目引用时按「引用即复制」写入项目，后续模型变更不影响已建项目 | 主对象 |

## 3. 枚举值

### 3.1 模型来源（内部枚举）

> 列表页不展示、不筛选；仅用于详情页 Tag 与操作权限。

| 枚举值 | 含义 | 可编辑 | 可删除 | 备注 |
| :--- | :--- | :---: | :---: | :--- |
| `manual` | 自己新增 | 是 | 是 | 默认 |
| `collected` | 收藏副本 | 否 | 否 | 从平台模型库复制生成 |

### 3.2 系统边界

> 取值来源：平台支撑 · 数据字典 · 系统边界（仅启用项）。

| 枚举值（字典编码） | 含义 | 是否默认 | 备注 |
| :--- | :--- | :---: | :--- |
| `gate` | 摇篮到大门 | 是 | 原材料获取 + 生产 |
| `grave` | 摇篮到坟墓 | 否 | 增加运输/交付、使用、生命周期末期 |
| `gate_to_gate` | 大门到大门 | 否 | 仅生产阶段 |

## 4. 计算、联动与回写口径

| 规则ID | 触发 | 输入字段/来源 | 计算或联动规则 | 影响字段 | 重算/覆盖方式 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| C01 | 新建保存 | 系统 | 模型编码按 `MYM-NNN` 生成 | 模型编码 | 系统生成 |
| C02 | 选择核算标准 | 标准文件库选项 | 带出 `standardId` 与 `standardName` | 核算标准 | 覆盖 |
| C03 | 选择产品分类 | 产品分类树 | 带出分类 id 与名称 | 产品分类 | 覆盖 |
| C04 | 切换系统边界 | 系统边界字典 | 按适用边界重新带出生命周期阶段，默认全部纳入 | 生命周期阶段 | 覆盖 |
| C05 | 收藏平台模型 | 平台模型 | 复制全部内容，`origin = collected`，`sourceModelId` / `sourceModelName` 记录来源 | 来源字段组 | 复制生成 |
| C06 | 保存步骤② | 数据项 | 空白行不落库；名称必填 | 数据项 | 覆盖保存 |
