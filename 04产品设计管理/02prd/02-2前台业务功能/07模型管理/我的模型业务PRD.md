## 1. 需求概述

### 1.1 需求背景

「我的模型」是组织级的核算模型模板库。用户可自定义新建模型，也可从平台模型库收藏已发布模型形成本组织私有副本，供后续新建核算项目时快速引用。

```text
平台模型库（已发布）
        ↓ 「加入我的模型」复制式快照
    我的模型（组织级）
        ↓ 新建核算项目时引用
    核算项目（引用即复制）
```

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :-: | :--- | :--- |
| G1 | **信息密度优先** | 列表采用表格版式，一屏可见模型名称、产品分类、核算标准、行业标签、更新时间、操作 |
| G2 | **收藏副本只读** | 从平台模型库收藏的副本在列表中不单独展示来源列，但在详情页与操作区按只读处理 |
| G3 | **引用即复制** | 收藏平台模型后生成独立副本，后续平台模型变更不影响本组织副本 |
| G4 | **新建/编辑同构** | 新建与编辑均走「目标与范围 → 产品建模」两步向导 |

### 1.3 范围

**In Scope**

| # | 范围 |
| :-: | :--- |
| 1 | 我的模型列表：条件查询 + 表格列表 + 分页 |
| 2 | 我的模型详情：查看、编辑（自己新增）、删除、收藏副本只读提示 |
| 3 | 新建模型：两步向导（目标与范围 / 产品建模） |
| 4 | 编辑模型：同新建，回填已有模型内容 |
| 5 | 删除模型：自己新增模型可删除，二次确认 |

**Out of Scope**

| 不做项 | 说明 |
| :--- | :--- |
| 模型版本化 | 我的模型不版本化，每次编辑直接覆盖 |
| 收藏来源联动 | 收藏副本不与源模型联动，仅保留来源快照用于追溯 |
| 批量操作 | 本期不做 |

## 4. 单据定位与实体关系

### 4.1 基本定位

| 项目 | 内容 |
| :--- | :--- |
| 对象层级 | 组织级业务对象 |
| 核心职责 | 沉淀本组织可复用的核算模型模板 |
| 来源 | 用户手动新建 / 从平台模型库收藏 |
| 下游产出 | 新建核算项目时作为可选来源被引用（引用即复制） |

### 4.2 实体关系

| 关系 | 说明 |
| :--- | :--- |
| 我的模型 : 平台模型 | **N:1 或 0:1**；收藏时记录 `sourceModelId` / `sourceModelName` 追溯，但内容已复制 |
| 我的模型 : 核算项目 | **1:N**；一个我的模型可被多个项目引用，引用时复制内容 |
| 我的模型 : 产品分类/核算标准/行业 | 引用基础库字段作为筛选与展示维度 |

## 6. 核心业务规则

| 规则ID | 规则 | 依据 |
| :--- | :--- | :--- |
| R-001 | **[编码生成]** 我的模型编码由系统按 `MYM-NNN` 生成，全局唯一、不可修改 | 原型 `nextMyModelCode` |
| R-002 | **[收藏即复制]** 收藏平台模型时，将平台模型内容完整复制生成新的我的模型；副本不与源模型联动 | 原型 `collectModelToMy` |
| R-003 | **[收藏命名]** 收藏副本名称默认带「（收藏）」后缀，如「{源模型名}（收藏）」 | 原型 `collectModelToMy` |
| R-004 | **[编辑约束]** 仅 `origin = manual` 的模型可编辑；`collected` 仅只读预览 | 原型操作列 |
| R-005 | **[删除约束]** 仅 `origin = manual` 的模型可删除；删除后不可恢复 | 原型操作列 |
| R-006 | **[列表排序]** 默认按更新时间倒序，不做表头排序 | 原型 `fetchMyModels` |
| R-007 | **[列表筛选]** 产品分类按级联树父级命中子级；行业标签任一命中；核算标准精确匹配；关键词模糊匹配名称/编码 | 原型 `matchesModelFilter` |
| R-008 | **[分页大小]** 每页 9 条 | 原型 `MODEL_PAGE_SIZE` |

## 7. 边界与异常处理

| 场景 | 处理方式 |
| :--- | :--- |
| 列表为空 | 空态文案「暂无模型：点击右上角「新建模型」创建，或到「模型库」收藏平台模型」 |
| 收藏来源模型已被停用/删除 | 已收藏副本不受影响，仍可在我的模型中查看；来源追溯字段可能显示为 `-` |
| 编辑过程中源模型变更 | 不影响当前编辑内容（副本不联动） |
| 删除失败 | Toast 提示失败原因 |
