## 1. 需求概述

### 1.1 需求背景

「我的模型」是组织级的核算模型模板库。用户可自定义新建模型，也可从平台模型库收藏已发布模型形成本组织私有副本，供后续新建核算项目时快速引用。

```text
平台模型库（已发布）
        ↓ 「加入我的模型」复制式快照
    我的模型（组织级）
        ↓ 新建核算项目时引用
    核算项目（引用即复制）
```

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :-: | :--- | :--- |
| G1 | **信息密度优先** | 列表采用表格版式，一屏可见模型名称、产品分类、核算标准、行业标签、模型版本、创建时间、更新时间、操作 |
| G2 | **加入副本同权** | 从平台模型库加入的副本 = 复制一份到我的模型库，与自建模型一样可查看 / 编辑 / 删除；详情页展示来源与版本提示 |
| G3 | **引用即复制** | 加入平台模型后按当前版本生成独立副本，后续平台模型变更不影响本组织副本 |
| G4 | **新建/编辑同构** | 新建与编辑均走「目标与范围 → 产品建模」两步向导 |
| G5 | **可重复加入** | 同一平台模型可多次加入，每次在列表新增一条独立副本（编码 / 创建时间不同） |

### 1.3 范围

**In Scope**

| # | 范围 |
| :-: | :--- |
| 1 | 我的模型列表：条件查询 + 表格列表 + 分页 |
| 2 | 我的模型详情：查看、编辑、删除、加入副本来源与版本提示 |
| 3 | 新建模型：两步向导（目标与范围 / 产品建模） |
| 4 | 编辑模型：同新建，回填已有模型内容（含加入副本） |
| 5 | 删除模型：所有模型可删除（删除副本不影响平台源模型），二次确认 |

**Out of Scope**

| 不做项 | 说明 |
| :--- | :--- |
| 我的模型自身版本化 | 我的模型编辑直接覆盖；`version` 仅记录加入时的平台版本快照（自建为 V1.0） |
| 加入来源联动 | 副本不与源模型联动，仅保留来源快照用于追溯 |
| 批量操作 | 本期不做 |

## 4. 单据定位与实体关系

### 4.1 基本定位

| 项目 | 内容 |
| :--- | :--- |
| 对象层级 | 组织级业务对象 |
| 核心职责 | 沉淀本组织可复用的核算模型模板 |

| 下游产出 | 新建核算项目时作为可选来源被引用（引用即复制） |

### 4.2 实体关系

| 关系 | 说明 |
| :--- | :--- |
| 我的模型 : 平台模型 | **N:1 或 0:1**；加入时记录 `sourceModelId` / `sourceModelName` 与版本快照 `version` 用于追溯，但内容已复制；同一平台模型可被同一组织多次加入（多条 N:1 记录） |
| 我的模型 : 核算项目 | **1:N**；一个我的模型可被多个项目引用，引用时复制内容 |
| 我的模型 : 产品分类/核算标准/行业 | 引用基础库字段作为筛选与展示维度 |

## 6. 核心业务规则

| 规则ID | 规则 | 依据 |
| :--- | :--- | :--- |
| R-001 | **[编码生成]** 我的模型编码由系统按 `MYM-NNN` 生成，全局唯一、不可修改 | 原型 `nextMyModelCode` |
| R-002 | **[加入即复制]** 加入平台模型时，按**当前版本**将平台模型内容完整复制生成新的我的模型；副本不与源模型联动 | 原型 `collectModelToMy` |
| R-003 | **[加入命名]** 加入副本名称默认带版本后缀，如「{源模型名}（V1.2）」 | 原型 `collectModelToMy` |
| R-004 | **[编辑同权]** 所有模型均可编辑（含 `collected` 加入副本；副本为复制式快照，编辑不影响源模型） | 原型操作列 |
| R-005 | **[删除同权]** 所有模型均可删除（含 `collected` 加入副本）；删除后不可恢复；删除副本不影响平台源模型，可在模型库重新加入 | 原型操作列 |
| R-006 | **[列表排序]** 默认按更新时间倒序，不做表头排序 | 原型 `fetchMyModels` |
| R-007 | **[列表筛选]** 产品分类按级联树父级命中子级；行业标签任一命中；核算标准精确匹配；关键词模糊匹配名称/编码 | 原型 `matchesModelFilter` |
| R-008 | **[分页大小]** 每页 9 条 | 原型 `MODEL_PAGE_SIZE` |
| R-009 | **[可重复加入]** 同一平台模型可多次加入，每次新增一条独立副本；副本 `version` = 加入时的平台当前版本，`createdAt` = 加入时刻 | 原型 `collectModelToMy` |
| R-010 | **[列表列]** 列表展示模型版本与创建时间；创建时间取模型新建 / 加入时刻，排序仍按更新时间 | 原型 `MyModelListPage` |

## 7. 边界与异常处理

| 场景 | 处理方式 |
| :--- | :--- |
| 列表为空 | 空态文案「暂无模型：点击右上角「新建模型」创建，或到「模型库」加入平台模型」 |
| 加入来源模型已被停用/删除 | 已加入副本不受影响，仍可在我的模型中查看、编辑、删除；来源追溯字段可能显示为 `-` |
| 编辑过程中源模型变更 | 不影响当前编辑内容（副本不联动） |
| 重复加入同一模型 | 允许；每次新增一条独立副本，名称相同也可通过编码 / 创建时间区分 |
| 删除失败 | Toast 提示失败原因 |
