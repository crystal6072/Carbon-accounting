## 1. 需求概述

### 1.1 需求背景

「模型库」是平台已发布核算模型的展示与引用入口。前台用户可浏览平台模型，将需要的模型「加入我的模型」，形成本组织私有副本，供后续新建核算项目时引用。

```text
后台模型管理（已发布）
        ↓ 前台可见
    模型库（只读卡片网格）
        ↓ 加入我的模型
    我的模型（组织私有副本）
        ↓ 新建核算项目引用
    核算项目（引用即复制）
```

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :-: | :--- | :--- |
| G1 | **浏览效率优先** | 卡片网格展示封面、角标、标签、标准说明、统计指标，一屏可见多个模型 |
| G2 | **快速定位** | 支持产品分类、核算标准、行业标签、名称/编码筛选 |
| G3 | **加入即复制** | 点击「加入我的模型」后按平台**当前版本**生成独立副本，原平台模型后续变更不影响副本 |
| G4 | **只读预览** | 详情页仅支持预览，不可编辑；可一键加入我的模型 |
| G5 | **版本可见** | 卡片与详情均展示平台模型当前版本号（`V{主}.{次}`），企业按当前版本复制 |
| G6 | **可重复加入** | 同一模型可多次加入，每次在「我的模型」新增一条独立副本 |

### 1.3 范围

**In Scope**

| # | 范围 |
| :-: | :--- |
| 1 | 模型库卡片网格列表：条件查询 + 分页 |
| 2 | 模型卡片信息：封面角标、标准代号角标、名称、标签行、标准说明、编码 + 版本号、阶段/数据项数、更新时间、操作 |
| 3 | 模型详情预览：只读展示目标与范围 + 产品建模内容，并展示模型版本 |
| 4 | 加入我的模型：按当前版本复制生成组织私有副本，二次提示（Toast）；可重复加入 |

**Out of Scope**

| 不做项 | 说明 |
| :--- | :--- |
| 模型编辑/删除 | 归后台「模型管理」 |
| 模型发布/停用 | 归后台「模型管理」 |
| 批量加入 | 本期不做 |

## 4. 单据定位与实体关系

### 4.1 基本定位

| 项目 | 内容 |
| :--- | :--- |
| 对象层级 | 平台级只读库 |
| 核心职责 | 展示平台已发布核算模型（含当前版本），供前台用户加入引用 |
| 来源 | 后台「模型管理」发布后的平台模型 |
| 下游产出 | 加入后按当前版本生成「我的模型」副本 |

### 4.2 实体关系

| 关系 | 说明 |
| :--- | :--- |
| 平台模型 : 我的模型 | **1:N**；一个平台模型可被多个组织、同一组织多次加入，每次生成独立副本 |
| 平台模型 : 核算项目 | 不直接关联；通过「我的模型」副本间接引用 |

## 5. 卡片信息结构

| 区域 | 内容 | 说明 |
| :--- | :--- | :--- |
| 封面左上角 | 「平台」角标 | 固定展示，不再有「已加入」态 |
| 封面右上角 | 标准代号角标 | 取标准号首段，如 `GB/T`、`ISO`、`DB35/T` |
| 名称 | 模型名称 | 可点击预览 |
| 标签行 | 行业标签 · 标准层级 · 系统边界 | 行业标签为空时显示「全行业」 |
| 标准说明 | `标准号：标准名称` | 卡片副文案，最多两行 |
| 编码 + 版本号 | 模型编码 + 当前版本号 | 元信息行，版本号以描边小徽标展示 |
| 指标行 | 系统边界 · N 阶段 · N 数据项 | 取自模型内容 |
| 底部 | 更新时间 + 操作区 | 操作区为文字链接（预览 / 加入我的模型） |

## 6. 核心业务规则

| 规则ID | 规则 | 依据 |
| :--- | :--- | :--- |
| R-001 | **[仅展示已发布]** 模型库只展示后台状态为 `published` 的平台模型 | 原型 `fetchPublishedModels` |
| R-002 | **[版本展示]** 卡片与详情展示平台模型**当前版本号**；版本由后台发布升版控制（编辑后重新发布次版本 +1），前台不可改 | 原型 `CarbonModel.version` |
| R-003 | **[加入即复制]** 加入平台模型后，按**当前版本**复制生成新的我的模型副本，`origin = collected`，副本 `version` = 平台当前版本，名称带版本后缀「（V1.x）」 | 原型 `collectModelToMy` |
| R-004 | **[可重复加入]** 同一平台模型可多次加入，每次新增一条独立副本（编码 / 创建时间各自独立）；不设「已加入」互斥态，入口始终展示 | 原型卡片操作区 |
| R-005 | **[列表筛选]** 产品分类按级联树父级命中子级；行业标签任一命中；核算标准精确匹配；关键词模糊匹配名称/编码 | 原型 `matchesModelFilter` |
| R-006 | **[分页大小]** 每页 9 张卡片 | 原型 `MODEL_PAGE_SIZE` |
| R-007 | **[默认排序]** 按平台模型更新时间倒序 | 原型 `fetchPublishedModels` |
| R-008 | **[空态]** 无符合条件模型时显示「暂无符合条件的模型」 | 原型空态 |

## 7. 边界与异常处理

| 场景 | 处理方式 |
| :--- | :--- |
| 平台无已发布模型 | 空态「暂无符合条件的模型」 |
| 加入失败 | Toast 提示失败原因 |
| 重复加入 | 每次点击都新增一条副本，Toast 提示「已加入我的模型：{模型名称}（{版本} 副本）」 |
| 源模型被后台停用 | 已生成的我的模型副本不受影响；模型库不再展示该模型 |

## 8. 验收标准

| # | 验收项 | 输入条件 | 预期结果 |
| :-: | :--- | :--- | :--- |
| V01 | 卡片网格展示 | 进入模型库 | 展示已发布平台模型卡片，每页最多 9 张 |
| V02 | 条件筛选 | 选择产品分类 / 核算标准 / 行业标签 / 输入关键词 | 卡片按条件过滤，重置后恢复 |
| V03 | 版本号展示 | 查看任意卡片与详情 | 卡片元信息行与详情基本信息区展示当前版本号（如 `V1.2`） |
| V04 | 加入我的模型 | 点击卡片的「加入我的模型」 | Toast 提示已加入（含版本），「我的模型」新增一条副本，卡片仍保留加入入口 |
| V05 | 重复加入 | 对同一模型再次点击「加入我的模型」 | 「我的模型」再新增一条独立副本，两条副本互不影响 |
| V06 | 预览详情 | 点击卡片名称/封面/预览 | 进入详情页，内容只读，右上角显示「加入我的模型」 |
| V07 | 标准代号角标 | 模型标准号为 `GB/T 24067-2024` | 封面右上角显示 `GB/T` |
| V08 | 标签行展示 | 模型含行业标签、标准层级、系统边界 | 标签行依次展示行业标签 · 标准层级 · 系统边界 |
| V09 | 前往我的模型 | 点击「前往我的模型」 | 跳转「我的模型」列表 |
| V10 | 空态 | 平台无已发布模型 | 显示「暂无符合条件的模型」 |

## 9. 附录

### 9.1 术语表

| 术语 | 含义 |
| :--- | :--- |
| 模型库 | 平台已发布核算模型的前台只读展示库 |
| 模型版本 | 平台模型当前发布版本号（`V{主}.{次}`）；首次发布 `V1.0`，编辑后重新发布次版本 +1 |
| 加入副本 | 平台模型按当前版本复制到本组织的模型快照，与自建模型同权 |
| 复制式快照 | 加入时不建立引用关系，而是完整复制模型内容 |
| 标准层级 | 国际标准 / 国家 / 行业 / 地方 / 团体 / 其他，由标准号前缀推导 |

### 9.2 下游影响

| 下游 | 影响 |
| :--- | :--- |
| 我的模型 | 加入动作按当前版本生成我的模型副本（可多次加入，每次一条） |
| 核算项目新建 |  indirectly 通过我的模型被引用 |
