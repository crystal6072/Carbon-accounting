## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 产品碳足迹核算 → 模型管理 → 模型库 |
| 业务归属 | 前台业务平台 → 产品碳足迹核算 → 模型管理 |
| 模块类型 | 平台级只读库 + 收藏入口 |
| 核心对象 | **平台模型（CarbonModel）前台投影** |
| 核心职责 | 展示平台已发布核算模型，供前台用户收藏引用 |

### 1.2 对象结构

| 结构 | 对象 | 与主对象关系 | 主键/唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主对象 | 平台模型（CarbonModel） | 主对象 | 模型编码（`MDL-NNN`） | 本清单主定义范围 |
| 子对象 · 生命周期阶段 | 模型生命周期阶段 | 1:N | 模型 id + 阶段 id | 含勾选态 |
| 子对象 · 数据项 | 模型数据项（ModelDataItem） | 1:N | 模型 id + 数据项 id | 产品建模内容 |
| 子对象 · 过程节点 | 模型过程节点（ModelProcessNode） | 1:N | 模型 id + 节点 id | 追溯节点 |
| 关联对象 | 我的模型收藏副本 | 1:N | `sourceModelId` = 平台模型 id | 收藏后生成，各组织独立 |

### 1.3 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | 后台「模型管理」发布后的平台模型 |
| 外部系统数据源 | 否 |
| 新增编辑 | 前台只读；编辑/发布/停用归后台 |
| 子表 | 与后台模型一致 |
| 导入导出 | 本期不做 |
| 状态与执行 | 仅展示 `status = published` 的模型 |
| 关键唯一键 | 模型编码（全局唯一） |

### 1.4 关键数据约束

| 约束ID | 约束 | 影响对象 |
| :--- | :--- | :--- |
| D01 | 仅展示 `status = published` 的平台模型 | 主对象 |
| D02 | 前台只读，不直接落库 | 主对象 |
| D03 | 收藏时完整复制内容，生成我的模型副本 | 关联对象 |
| D04 | 同一组织内同一平台模型只能收藏一次 | 关联对象 |

## 3. 枚举值

### 3.1 平台模型状态（后台枚举）

> 模型库仅展示 `published`。

| 枚举值 | 含义 | 模型库是否可见 | 备注 |
| :--- | :--- | :---: | :--- |
| `draft` | 草稿 | 否 | 仅后台可见 |
| `published` | 已发布 | 是 | 前台模型库可见 |
| `disabled` | 已停用 | 否 | 前台模型库不可见 |

### 3.2 标准层级（卡片标签行展示）

> 由标准号前缀推导。

| 判定规则 | 展示文案 |
| :--- | :--- |
| ISO / IEC / EN / BS / DIN / ASTM / PAS 开头 | 国际 |
| GB 开头 | 国家 |
| HB / JB / QB / SB / SN / YS 开头 | 行业 |
| DB 开头 | 地方 |
| T/ 开头 | 团体 |
| 其他 | 其他 |

### 3.3 系统边界

> 取值来源：平台支撑 · 数据字典 · 系统边界。

| 枚举值（字典编码） | 展示文案 |
| :--- | :--- |
| `gate` | 摇篮到大门 |
| `grave` | 摇篮到坟墓 |
| `gate_to_gate` | 大门到大门 |

## 4. 计算、联动与回写口径

| 规则ID | 触发 | 输入字段/来源 | 计算或联动规则 | 影响字段 | 重算/覆盖方式 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| C01 | 列表加载 | 后台模型数据 | 过滤 `status = published` 并按更新时间倒序 | 列表数据 | 实时读取 |
| C02 | 收藏状态判定 | 我的模型副本 | 若存在 `origin = collected` 且 `sourceModelId = 当前平台模型 id` 的副本，则标记已加入 | 是否已加入 | 实时反查 |
| C03 | 卡片渲染 | 标准号 | 取标准号首段作为右上角标准代号角标 | 标准代号角标 | 实时计算 |
| C04 | 卡片渲染 | 标准号 | 按前缀匹配规则推导标准层级文案 | 标准层级标签 | 实时计算 |
| C05 | 卡片渲染 | 行业标签数组 | 为空展示「全行业」；多个取首个 +「等 N 个行业」 | 行业标签文案 | 实时计算 |
| C06 | 加入我的模型 | 平台模型 | 完整复制内容生成我的模型副本 | 我的模型副本 | 新增 |
