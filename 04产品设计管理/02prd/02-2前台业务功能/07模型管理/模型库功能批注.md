## 1. 拟添加的批注清单

### 1.1 整体流程

#### LIB-01 模型库整体流程
**拟标注位置**：功能标题「模型库」附近（全局说明）
**标记**：已确认

**批注内容**

- **适用场景**：平台已发布核算模型的展示与引用入口。用户浏览平台模型，将需要的模型「加入我的模型」，形成本组织私有副本，供后续新建核算项目时引用。
- **主流程**：进入本页 → 按条件筛选定位模型 → 点击卡片进入详情预览，或直接在卡片点「加入我的模型」→ 「我的模型」按平台当前版本新增一条独立副本（可重复加入）。
- **衔接与结束**：本功能**只读**，不提供编辑/删除/发布；修改与发布统一在后台「模型管理」完成，编辑后重新发布会升版（V1.0 → V1.1）。

### 1.2 全局规则说明

#### LIB-02 全局规则
**拟标注位置**：功能标题「模型库」附近
**标记**：已确认

**批注内容**

1. **仅展示已发布**：模型库只展示后台状态为「已发布」的平台模型；草稿/停用模型不可见。
2. **只读库**：本页所有模型均为平台所有，用户**不能编辑、不能删除、不能发布**，仅可预览与加入我的模型。
3. **加入即复制**：「加入我的模型」时按平台**当前版本**完整复制模型内容，生成独立副本；源模型后续变更不影响该副本（不联动）。
4. **可重复加入**：同一平台模型在同一组织中**可多次加入**，每次新增一条独立副本（编码 / 创建时间各自独立）；不设「已加入」互斥态，入口始终展示。
5. **版本口径**：平台模型新建为 `V1.0`，编辑后重新发布次版本号 +1（`V1.0` → `V1.1`）；本页展示当前发布版本，副本记录加入时的版本快照。
6. **与我的模型相互独立**：本页是平台视图，加入后才进入「我的模型」；两处数据各自维护。

### 1.3 业务状态说明

#### LIB-03 模型版本号
**拟标注位置**：卡片元信息行（编码右侧）/ 详情页基本信息区
**标记**：已确认

**批注内容**

- **含义**：平台模型当前发布版本号，格式 `V{主}.{次}`。
- **展示位置**：卡片元信息行以描边小徽标展示（如 `V1.2`）；详情页顶部描述与「基本信息」区展示「模型版本」。
- **版本口径**：首次发布 `V1.0`；编辑后重新发布次版本 +1；未编辑直接重新启用不升版。
- **对下游影响**：加入我的模型时按当前版本复制，副本版本号 = 加入时的平台版本，后续平台升版不回溯已有副本。

### 1.4 操作功能及对应业务规则

#### LIB-04 筛选与搜索
**拟标注位置**：工具栏筛选区
**标记**：已确认（「搜索」按钮行为为原型已表现·待核对）

**批注内容**

- **筛选项**：
  - 产品分类：级联选择（按分类树父级命中其全部子级）。
  - 核算标准：单选下拉（仅现行标准）。
  - 行业标签：多选（命中任一即返回）。
  - 模型名称 / 编码：关键词模糊匹配名称与编码。
- **过滤规则**：四个条件同时生效（叠加过滤）；任一条件变化后回到第 1 页；「重置」清空全部条件。
- **「搜索」按钮**：点「搜索」执行一次当前条件的筛选；因输入条件后卡片网格即时收敛，按钮属于显式触发入口，两种方式结果一致。原型中点「搜索」不产生额外动作（待核对）。

#### LIB-05 重复加入与版本复制
**拟标注位置**：卡片 / 详情页「加入我的模型」
**标记**：已确认

**批注内容**

- **重复加入**：同一平台模型可多次加入，每次新增一条独立副本，不覆盖、不复用。
- **复制口径**：每次加入都复制平台模型**当前版本**的完整内容，副本版本号 = 加入时的平台版本。
- **命名**：副本名称默认带版本后缀（如「…（V1.2）」），便于区分同一模型的多次加入。
- **不联动**：平台后续升版不回溯已加入的副本。

#### LIB-06 前往我的模型
**拟标注位置**：工具栏「前往我的模型」按钮
**标记**：已确认

**批注内容**

- **入口**：工具栏右侧按钮。
- **作用**：跳转到「我的模型」列表页，查看本组织已加入的副本与自主新建的模型（含模型版本、创建时间）。
- **工具栏统计**：工具栏左侧展示「共 N 个模型 · 平台已发布」，N 为当前筛选结果下的平台已发布模型数；不再统计「已加入」数量。

#### LIB-07 卡片信息结构
**拟标注位置**：模型卡片
**标记**：已确认

**批注内容**

- **封面左上角角标**：固定「平台」。
- **封面右上角角标**：标准代号角标（取标准号首段，如 GB/T、ISO）。
- **名称**：模型名称，点击进入详情。
- **标签行**：行业标签 · 标准层级 · 系统边界（行业标签为空显示「全行业」）。
- **标准说明**：标准号：标准名称（最多两行）。
- **元信息行**：模型编码 + 当前版本号（描边小徽标，如 `V1.2`）。
- **指标行**：系统边界 · N 阶段 · N 数据项。
- **底部**：更新时间 + 操作区（预览 / 加入我的模型）。

#### LIB-08 预览模型
**拟标注位置**：卡片「预览」/ 卡片名称
**标记**：已确认

**批注内容**

- **入口**：卡片上的「预览」，或点击封面 / 模型名称。
- **展示内容**：进入详情页，复用只读视图展示「目标与范围」与「产品建模」全部内容；详情页基本信息区展示模型编码、模型版本、维护人、创建时间、更新时间。
- **只读提示**：详情页顶部展示提示「模型库为平台已发布模型，仅支持只读预览；「加入我的模型」将按当前版本复制一份到本组织（复制式快照，不与平台模型联动；同一模型可重复加入，每次新增一条副本）。」
- **只读**：详情页不可编辑，仅可「加入我的模型」或返回。

#### LIB-09 加入我的模型
**拟标注位置**：卡片「加入我的模型」/ 详情页「加入我的模型」
**标记**：已确认

**批注内容**

- **显示条件**：**所有已发布模型始终显示「加入我的模型」入口**（卡片与详情页），不因已加入而隐藏。
- **操作方式**：点击后按平台模型**当前版本**复制一份，生成「我的模型」副本（名称默认带版本后缀，如「（V1.2）」）。
- **操作结果**：提示「已加入我的模型：{模型名称}（{版本} 副本）」；「我的模型」列表同步新增该条副本（记录创建时间与版本）。
- **重复加入**：同一模型可重复加入，每次点击都新增一条独立副本，互不影响。

#### LIB-10 分页
**拟标注位置**：卡片网格底部
**标记**：已确认

**批注内容**

- 每页展示固定数量卡片（每页 9 条，与「我的模型」列表分页一致）；切换页码正常刷新。
- 空态：无符合条件模型时展示「暂无符合条件的模型」。

### 1.5 字段说明

#### LIB-11 字段：模型名称 / 模型编码
**拟标注位置**：卡片名称区 / 编码区
**标记**：已确认

**批注内容**

- **模型名称**：平台模型名称，点击进入详情。
- **模型编码**：系统生成、平台唯一，作为副标识；列表与详情展示。

#### LIB-12 字段：标准代号角标 / 标准层级 / 系统边界
**拟标注位置**：卡片角标与标签行
**标记**：已确认

**批注内容**

- **标准代号角标**：取标准号首段（如 GB/T、ISO），展示于封面右上角。
- **标准层级**：由标准号前缀推导（国际 / 国家 / 行业 / 地方 / 团体 / 其他），展示于标签行。
- **系统边界**：模型核算边界（摇篮到大门 / 摇篮到坟墓 / 大门到大门），展示于标签行与指标行。

#### LIB-13 字段：行业标签 / 数据项与阶段数
**拟标注位置**：卡片标签行与指标行
**标记**：已确认

**批注内容**

- **行业标签**：模型适用行业，可多选；为空显示「全行业」。
- **数据项与阶段数**：模型内数据项总数与纳入阶段数，展示于指标行，用于快速判断模型体量。
