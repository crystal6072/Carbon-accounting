# 我的因子库字段清单

> **【以原型为准修订声明 · 2026-10-16（V0.4），全文优先，废止 V0.3 及以前版本中与原型冲突的条款】**：本清单字段与前端原型（`06prototypes/6-1系统原型骨架/src/pages/factor/`：`types/index.ts` 的 `FactorItem` / `MyFactor` / `MyFactorLibrary` / `FactorExt` / `FactorExchange`，`factorMeta.ts`，`FactorFormPage.tsx` / `FactorDetailPage.tsx` / `MyFactorLibraryListPage.tsx` / `MyFactorLibraryDetailPage.tsx` / `FactorCollectModal.tsx` / `FrontendLibraryListPage.tsx` / `FrontendLibraryDetailPage.tsx`）冲突之处，**一律以原型为准**（与后台《排放因子库字段清单》V0.4 同源）：
> - **因子字段集（16 项 + 来源）**：因子编码 / 因子名称 / 因子别名 / 英文名称 / 适用场景（必填）/ 录入方式（总指标 / 指标）/ GWP 分项口径（化石 / 生物碳 / 土地利用）/ 因子数值 / 因子分子单位 / 因子分母单位 / 单位类别 / 地域 / 描述 / ext / exchanges / 归属我的因子库 + `origin`。
> - **录入方式 `entryMode`**：`total` 总指标（单一 `value`）/ `split` 分指标（`calibers` 三项分别录入，合计 `gwpTotal` **自动计算只读**）；`value` = 分项之和。
> - **因子单位为复合单位**：`numeratorUnit`（碳排放量类，分子）+ `denominatorUnit`（活动数据单位，分母），表单用 CascaderSelect 直接选「分子/分母」，如 `kgCO₂e/kg`。
> - **因子编码规则定稿**：手工新增与收藏副本均由系统生成 **`MF-{序号}`**（3 位补齐、组织内自增唯一），**不沿用源编码**；源编码记入 `sourceFactorCode`。
> - **来源元数据 / 更新标记 / 来源状态**：`sourceLibraryId/Name` / `sourceVersionId/No` / `sourceFactorId/Code`（仅 `collected`）；`updateAvailable`（源库新版本 + **因子值**不同）；`sourceStatus`（`ok` / `offline` 源库已下架 / `removed` 源因子已移除或源库不存在 / 无已发布版本）。
> - **列表列**（原型 `MyFactorLibraryDetailPage`）：因子名称 / 英文名称 / 别名 / 来源（`origin` Tag + 源库·版本 + 状态角标）/ 因子值·单位（含口径摘要）/ 操作（查看 / 编辑 / 一键更新 / 删除）；**我的因子库列表与库内因子列表均无查询区、无搜索**。
> - **因子详情 = 三页签**（因子信息 / 数据基本信息 / 输入输出信息）+ 收藏来源（仅副本）+ 制单信息；表单同三页签，**无「来源信息」页签**。

> **文档定位**：我的因子库字段定义的唯一真相源（SST）。业务 PRD 和 Demo PRD 只引用字段名称，不重复维护枚举、必填性和字段口径。
> **适用类型**：前台**组织私有因子库**（收藏夹 + 自建区），**不发布、不参与共享、不版本化**、无审核流
> **核心对象**：**我的因子库（MyFactorLibrary）→ 我的因子（MyFactor）**；**因子字段与后台库内因子同源**（统一字段集）
> **维护形态**：背景数据库只读预览 + 五角星收藏；我的因子库列表 + 库详情（因子表带「来源」列 + 更新提醒 + 一键更新）；支持手工新增因子
> **模块归属**：前台业务平台 → 因子管理（背景数据库 / 我的因子库）（方案 §2.3 B4、§八 P29；原型 `/pcf/factor-libraries`、`/pcf/my-factor`）
> **字段同源来源**：`02prd/02-1后台管理/09因子库/排放因子库字段清单.md`（统一因子字段集）
> **成熟度**：粗纲
> **版本**：V0.4
> **更新时间**：2026-10-16

**对象结构说明**

```text
我的因子库（MyFactorLibrary，私有、不发布、不版本化）
├── 库标识 / 名称 / 描述 / 因子数 / 制单信息
└── 我的因子（MyFactor，1:N）—— 统一字段集
    ├── 因子编码（MF-{序号}，系统生成）/ 名称 / 别名 / 英文名称
    ├── 适用场景（必填）/ 录入方式（total 总指标 / split 分指标）
    ├── 因子数值 + 分子单位（碳排放量类）+ 分母单位（活动数据单位）【复合单位】
    ├── 单位类别 / 地域 / 描述
    ├── GWP 分项口径 calibers（化石 / 生物碳 / 土地利用 + 合计 gwpTotal）
    ├── ext（数据基本信息）/ exchanges（输入输出）
    ├── origin：manual 手工新增 ｜ collected 收藏副本
    ├── 来源元数据（仅 collected）：sourceLibraryId / sourceVersionId / sourceFactorId ...
    ├── updateAvailable（仅 collected）：源库新版本 + 因子值变化 → true
    └── sourceStatus（仅 collected）：ok ｜ offline 源库已下架 ｜ removed 源因子已移除

收藏 = 复制式快照：
  复制因子值形成独立副本（新编码 MF-xxx）→ 源库后续更新【不自动影响】副本
  仅当源库发布新版本且该因子值变化 → updateAvailable = true → 手动【一键更新】按覆盖字段刷新
  取消收藏（源因子详情页五角星）→ 删除副本
```

| D01 | 我的因子编码为系统生成 **`MF-{序号}`**（3 位补齐、组织内自增），**收藏副本与手工新增均新生成、不沿用源编码**；编码在组织内唯一 | MyFactor |
| D02 | **`origin` ∈ {`manual` 手工新增 / `collected` 收藏副本}**；系统带出、不可改 | MyFactor |
| D03 | **录入方式 `entryMode` ∈ {`total` 总指标 / `split` 分指标}**，必填；`split` 时 `calibers` 三项选填、合计 `gwpTotal` 自动计算只读 | MyFactor |
| D04 | **口径闭合校验**：填写分项时 `gwpTotal` 应 ≈ 化石 + 生物碳 + 土地利用（容差 1%）；全部为空视为「单一口径」 | MyFactor |
| D05 | **因子值必填且不能为 0**（分指标合计不能为 0）；生物碳吸收为负由「生物碳」分项表达 | MyFactor |
| D06 | 因子单位为**复合单位**：`numeratorUnit`（碳排放量类）+ `denominatorUnit`（活动数据单位），均必填；分母须与活动单位**同类型可换算**，否则 **E04** | MyFactor |
| D07 | 单位类别 / 地域为**选填**；表单不直接录入（**收藏时随源复制**）；手工新增的地域口径经「数据基本信息 → 地理信息 → 地域（`ext.geoName`）」维护，详情页「因子信息 → 地域」取 `region` | MyFactor |
| D08 | 「描述」最长 **500 字符** | MyFactor |
| D09 | `ext` / `exchanges` 收藏外部库因子时**一并复制**；手工新增可在表单「数据基本信息 / 输入输出信息」页签维护 | MyFactor |
| D10 | 「归属我的因子库」**只读**，由上下文带出（手工新增取当前库；收藏取弹窗所选目标库） | MyFactor |
| D11 | 收藏副本必填来源元数据（源库 / 源版本 / 源因子）；手工新增来源元数据为空、`updateAvailable` 不适用 | MyFactor |
| D12 | `updateAvailable` 判定（仅 `collected`）：源库存在且有已发布版本、未整库下架、**当前发布版本 ≠ `sourceVersionId`**、且当前版本中同 `sourceFactorCode` 因子的 **`value` 与副本不同** → true；一键更新后复位 | MyFactor |
| D13 | **`sourceStatus`**（仅 `collected`）：源库**整库下架** → `offline`；源库当前发布版本中该因子**已被移除**、或源库不存在 / 已无已发布版本 → `removed`；否则 `ok`。`offline` / `removed` 时**不提供一键更新**，副本值保持快照不变 | MyFactor |
| D14 | **一键更新覆盖字段**：`value` / `numeratorUnit` / `denominatorUnit` / `name` / `alias` / `ext` / `exchanges` + `sourceVersionId` / `sourceVersionNo`；`scenario` / `calibers` / `unitCategory` / `region` / `description` / `englishName` / `code` 保持副本现值 | MyFactor |
| D15 | **收藏判重**：同一 `sourceFactorId` 在**同一「我的因子库」内不可重复收藏**（失败提示「该因子已收藏，请勿重复收藏」）；收藏到不同库允许 | MyFactor |

## 5. 枚举值

### 5.1 来源方式（origin，**本模块特有**）

| 枚举值 | 展示 | 含义 | 来源元数据 | updateAvailable | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `manual` | 手工新增 | 从零新增的自用因子 | 空 | 不适用 | 可编辑 / 可删除 |
| `collected` | 收藏副本 | 从后台已发布库收藏的复制副本 | 必填 | 适用 | **不随源库自动变化**；可取消收藏（删除副本） |

### 5.2 录入方式（entryMode）

| 枚举值 | 展示 | 因子值录入 | 指标明细展示 |
| :--- | :--- | :--- | :--- |
| `total` | 总指标录入 | 直接填一个总体值（`value`） | 仅「温室气体（总体 / 总指标）」一行（口径说明「单一口径总指标值」） |
| `split` | 分指标录入 | 分别填化石 / 生物碳 / 土地利用，合计自动计算 | 化石 / 生物碳 / 土地利用 / 合计四行 |

### 5.3 GWP 分项口径（calibers，选填）

| 键 | 展示 | 口径说明 | 备注 |
| :--- | :--- | :--- | :--- |
| `gwpFossil` | 温室气体（化石） | 不含生物碳口径 | 对应「不含生物碳」核算口径 |
| `gwpBiogenic` | 温室气体（生物碳） | 吸收为负、释放为正 | 双口径之差 |
| `gwpLuluc` | 温室气体（土地利用） | 土地利用变化 | |
| `gwpTotal` | 温室气体（总体 / 总指标） | = 化石 + 生物碳 + 土地利用 | **自动计算只读**；缺省回退 `value` |

### 5.4 单位类别（unitCategory）

| 枚举值 | 含义 | 备注 |
| :--- | :--- | :--- |
| 质量 | 分母为质量类单位（`kg` / `t`） | 选填；收藏随源复制 |
| 能量 | 分母为能量类单位（`kWh` / `MJ`） | 选填；收藏随源复制 |
| 体积 | 分母为体积类单位（`m³` / `L`） | 选填；收藏随源复制 |

### 5.5 来源状态（sourceStatus，仅收藏副本）

| 枚举值 | 展示 | 含义 | 一键更新 |
| :--- | :--- | :--- | :---: |
| `ok` | 正常 | 源库在线且当前版本中存在该因子 | 按 `updateAvailable` |
| `offline` | 来源库已下架 | 源库整库下架，副本停留快照值 | **否** |
| `removed` | 来源因子已移除 | 源库当前版本中该因子已被移除 / 源库不存在 / 无已发布版本 | **否** |

### 5.6 碳类型（exchanges.carbonType，选填）

| 枚举值 | 展示 | 备注 |
| :--- | :--- | :--- |
| `fossil` | 化石 | 用于从交换数据归集 GWP 分项 |
| `biogenic` | 生物碳 | 吸收记负 |
| `luluc` | 土地利用 | |
| `null` | 未标注 | 默认 |

### 5.7 系统模型（ext.systemModel，选填）

| 枚举值 | 展示 | 备注 |
| :--- | :--- | :--- |
| `cutoff` | Cutoff（截断） | 外部数据库的截断口径 |
| `apos` | APOS（分配） | |
| `consequential` | Consequential（边际） | |

### 5.8 排放源归类（**非因子字段**）

> 原「因子分类（系统内置 6 类）」**不属于因子字段**；MyFactor **不设 `category` / `industries`**。该 6 类枚举仅为**核算结果的「排放源归类」**展示口径（`PcfCalcSourceType`），不进入因子表单 / 详情 / 匹配。

| 归类 | 含义 |
| :--- | :--- |
| 材料 | 原材料获取产生的排放 |
| 能源 | 能源使用产生的排放 |
| 运输 | 运输周转量产生的排放 |
| 废弃物处理 | 生产废弃物处理产生的排放 |
| 末期处理 | 生命周期末期回收 / 处置产生的排放 |
| 生物碳（负排放） | 生物碳吸收 / 释放（负排放） |

### 5.9 已移除字段清单（V0.3 起，以原型为准）

| 已移除字段 | 原用途 | 现状 |
| :--- | :--- | :--- |
| 因子分类 / 适用行业 | 匹配 / 分类 | 删除；归类降级为核算结果展示口径（§5.8） |
| 来源信息（来源类别 / 发布年份 / 发布日期 / 发布国家·组织 / 发布机构 / 数据来源文件） | 来源说明 | 删除；详情无「来源信息」区块、表单无该页签 |
| 适用对象 / 适用阶段 / 适用年度 | 匹配维度 | 删除；改用「适用场景 + 复合单位 + 单位类别 + 地域」 |
| 气体种类 | 气体构成 | 删除；由 GWP 分项口径承载 |
| 生物碳类型 | 正负值控制 | 删除；由「生物碳」分项表达（吸收为负） |
| 数据质量等级（DQR） | 质量评价 | 删除；如需保留后续在活动数据侧 / 引擎层实现 |
| 使用状态（启用 / 禁用） | 启停 | 删除；私有因子均可被匹配选用 |

## 6. 更新标记与来源状态计算口径

| 规则ID | 触发 | 输入 | 计算规则 | 影响 |
| :--- | :--- | :--- | :--- | :--- |
| U-01 | 列表 / 详情加载 | 副本 + 源库当前发布版本 | 源库存在且有已发布版本、未下架、当前版本 ≠ `sourceVersionId`、同 `sourceFactorCode` 因子 `value` 不同 → `updateAvailable = true` | 更新提醒角标 |
| U-02 | 列表 / 详情加载 | 副本 + 源库 | 源库下架 → `offline`；源因子已移除 / 源库不存在 / 无已发布版本 → `removed`；否则 `ok` | 来源状态标记 |
| U-03 | 一键更新（单条 / 批量） | 用户确认 | 按 D14 覆盖字段刷新副本；`sourceVersionId` / `sourceVersionNo` 更新为最新；`updateAvailable` 复位 | 副本值 / 来源版本号 |
| U-04 | 更新作用范围 | 一键更新 | **仅影响该副本**，不影响同一源的其它副本 | 副本独立性 |
| U-05 | 变更不追溯 | 副本被项目引用后更新 / 删除 | 项目侧快照冻结，**不影响已建项目**（方案 §4.9）；重算走 **E13** | 项目快照 |
| U-06 | 取消收藏 | 源因子详情页五角星 | 二次确认后删除副本；源库因子不受影响 | 副本删除 |
| U-07 | 删库 | 删除「我的因子库」 | 二次确认后**级联删除**库内全部因子 | 库 + 因子 |
