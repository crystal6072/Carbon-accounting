# 我的因子库业务 PRD

> **【以原型为准修订声明 · 2026-10-16（V0.5），全文优先，废止 V0.4 及以前版本中与原型冲突的条款】**：本文与前端原型（`06prototypes/6-1系统原型骨架/src/pages/factor/`）冲突之处，**一律以原型为准**。V0.5 相对 V0.4 的关键修订：
> - **「取消收藏」落地**：背景数据库因子详情页五角星为**开关态** —— 未收藏「☆ 收藏」打开收藏弹窗；已收藏「★ 已收藏」再次点击 → 二次确认 → **删除「我的因子库」中的副本**（新增 S02b / R-012 / §6.2）。
> - **收藏判重定稿（Q03 关闭）**：同一源因子在**同一「我的因子库」内不可重复收藏**（提示「该因子已收藏，请勿重复收藏」）；收藏到**不同库**允许。
> - **因子编码规则定稿（Q02 关闭）**：收藏副本与手工新增**均由系统生成 `MF-{序号}`**（3 位补齐、组织内自增唯一），**不沿用源编码**；源编码记入 `sourceFactorCode` 供回源比对。
> - **更新提醒判定口径收窄（Q08 关闭）**：仅当「源库当前发布版本 ≠ 副本 `sourceVersionId`」**且源库当前版本中同源编码因子的 `value` 与副本不同**时 `updateAvailable = true`；单位 / 名称等其它字段变化**不触发**。
> - **一键更新覆盖范围定稿（Q04 / Q05 关闭）**：刷新 `value` / `numeratorUnit` / `denominatorUnit` / `name` / `alias` / `ext` / `exchanges` 与 `sourceVersionId` / `sourceVersionNo`；`scenario` / `calibers` / `unitCategory` / `region` / `description` / `englishName` / `code` **保持副本现值**；副本**手工编辑后仍可一键更新**（以源值覆盖），来源元数据保留。
> - **来源状态判定定稿**：源库不存在或已无已发布版本 → `removed`；源库**整库下架** → `offline`；源库当前发布版本中无同源编码因子 → `removed`；`offline` / `removed` 时**不提供一键更新**，副本保持快照值。
> - **我的因子库列表 / 库内因子列表均无查询区、无搜索**（卡片网格与因子表直接展示；库内因子表仅列表列 + 操作列）。
> - **删除边界对齐原型**：我的因子删除**不做引用阻断**（二次确认后直接删除）；已建项目侧快照冻结不受影响（方案 §4.9）。
> - **导出 / Excel 导入均未在原型实现**（暂缓；Q10 更新为「原型未实现」）。
> - **因子详情 = 三页签**（因子信息 / 数据基本信息 / 输入输出信息）+ 收藏来源（仅收藏副本）+ 制单信息；**无「来源信息」页签**。

## 1. 需求概述

### 1.1 需求背景

因子管理是前台业务平台「产品碳足迹」分组下的二级菜单，含两个页面（原型 `router/menu.ts`：`group-factor`）：

| 菜单项 | 路由 | 定位 |
| :--- | :--- | :--- |
| **背景数据库** | `/pcf/factor-libraries` | 只读预览后台**已发布**的因子库（商业数据库 / 自建库），五角星收藏到我的因子库 |
| **我的因子库** | `/pcf/my-factor` | 组织私有因子库：手工新增 + 收藏副本 |

我的因子库承担两个职责：

1. **收藏夹**：把后台**已发布库**中最新的因子**收藏（复制副本）**到我的因子库，供本人 / 本组织核算时使用；
2. **自建区**：手工新增本人 / 本组织的自用因子。

**关键定位（业务口径 2026-10-08，原型实现一致）**：

| 定位 | 口径 |
| :--- | :--- |
| **组织私有** | 仅本人 / 本组织可见，**不发布、不参与平台共享** |
| **不版本化** | 我的因子库与库内因子**不设版本号、版本状态**，直接修改 |
| **收藏 = 复制式快照** | 收藏动作**复制因子值形成独立副本**；源库后续更新**不自动影响**副本 |
| **更新提醒 + 一键更新** | 当源库发布新版本且该因子值发生变化时，副本显示「有新版本可更新」角标，支持**手动一键更新**（单条 / 批量） |
| **可取消收藏** | 在背景数据库因子详情页再次点击五角星，二次确认后**删除副本** |

> **与后台「排放因子库」的关系**：后台是**多库 + 库级版本化 + 发布**的维护面（见《排放因子库业务 PRD》）；前台我的因子库是**私有库**，二者**字段同源、对象分离** —— 我的因子与后台库内因子共用统一字段集，但我的因子额外记录**来源元数据**（源库 / 源版本 / 源因子）与**更新标记**。

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :--- | :--- | :--- |
| G1 | 支持多个我的因子库 | 本人 / 本组织可维护多个「我的因子库」（名称、描述、因子数） |
| G2 | 已发布库可按规则预览 | 只能预览后台**已发布版本**的因子；草稿版本 / 未发布 / 已整库下架的库不可见 |
| G3 | 收藏 = 复制式快照且不自动变化 | 收藏生成独立副本（新编码 `MF-{序号}`）；源库发布新版本后，**副本值不自动变化** |
| G4 | 更新提醒可用 | 源库发布新版本**且因子值发生变化**时，副本标记「有新版本可更新」 |
| G5 | 一键更新可用 | 一键更新把副本值刷新为**源库最新已发布版本**的值，并更新来源版本号（单条 / 批量） |
| G6 | 手工新增可用 | 支持从零手工新增因子（`origin = manual`） |
| G7 | 私有边界明确 | 我的因子库 / 我的因子**不发布、不参与平台共享、不版本化** |
| G8 | 可被核算项目引用 | 核算匹配时我的因子（组织自建）**优先于**平台级 / 商业数据库因子 |
| G9 | 来源失效可感知 | 源库整库下架 → 副本标记「来源库已下架」；源因子被移除 → 标记「来源因子已移除」；均不可一键更新 |
| G10 | 可取消收藏 | 背景数据库因子详情页五角星可取消收藏（删除副本） |

### 1.3 In Scope / Out of Scope

**In Scope**

| 能力 | 说明 |
| :--- | :--- |
| 背景数据库列表 | 已发布库卡片网格 + 查询区（库名称 / 编码、库来源筛选）；展示来源标签、库编码、维护方、因子数、当前版本 |
| 背景数据库详情（只读） | 商业数据库左侧 **ISIC 门类 A~S → 类**两级分类树 + 右侧因子表；自建库无分类树（单节点「全部因子」）；版本切换（生效中 / 历史版本）；关键词搜索 |
| 因子详情（只读预览） | 三页签（因子信息 / 数据基本信息 / 输入输出信息）+ 制单信息；我的因子副本另展示「收藏来源」区块 |
| **收藏（复制副本）** | 在因子详情页用五角星收藏：选目标「我的因子库」（或即时新建）→ 复制因子值生成独立副本 |
| **取消收藏** | 已收藏因子再次点击五角星 → 二次确认 → 删除副本 |
| 我的因子库列表 | 卡片网格（库名称 / 描述 / 因子数 / 更新时间）；**无搜索** |
| 我的因子库 CRUD | 新建 / 重命名 / 删除（删除时库内因子**级联删除**） |
| 我的因子列表 | 因子表列：因子名称 / 英文名称 / 别名 / 来源（含角标）/ 因子值·单位 / 操作 |
| **手工新增因子** | 从零新增（`origin = manual`），字段同统一字段集 |
| 编辑 / 删除我的因子 | 手工新增与收藏副本均可编辑 / 删除（删除无引用阻断，二次确认直删） |
| **一键更新** | 单条（行内）+ 批量（库详情顶部「一键更新（N）」） |

**Out of Scope**

| 不做项 | 说明 |
| :--- | :--- |
| **发布 / 版本化** | 我的因子库**不发布、不版本化**（无版本号、版本状态、新建版本） |
| **平台共享 / 跨组织共享** | 私有库仅本人 / 本组织可见 |
| **库级版本管理** | 属后台「排放因子库」，本模块不做 |
| **商业数据库整库导入** | 属后台；本模块仅可**收藏**其已发布因子 |
| **自动同步源库** | 收藏副本**不自动变化**；仅通过「更新提醒 + 一键更新」手动刷新 |
| **列表收藏 / 批量收藏** | 原型明确「不在列表做收藏」——收藏只在因子详情页五角星 |
| **导出 / Excel 导入** | 原型均未实现（暂缓） |
| 审核流 / 单据下推 / 外部系统同步 | 均不涉及 |
| 匹配规则配置 | 归核算模型（D4），本模块只遵循 |

## 2. 用户与使用场景

### S01 浏览已发布库并预览因子（背景数据库）

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要从后台已发布库中查找可用因子 |
| 操作流程 | 「背景数据库」→ 库列表（查询区：库名称 / 编码 + 库来源筛选；卡片展示来源标签 / 库编码 / 维护方 / 因子数 / 版本）→「预览」→ 库详情（**只读**：商业数据库左侧 ISIC 两级分类树 + 右侧因子表；自建库无分类树）→ 版本下拉可切换**历史版本**（只读追溯）→ 关键词搜索（过程名称 / 英文 / 编码）→ 点「过程 / 因子名称」进入因子详情 |
| 预期结果 | 仅**已发布版本**的因子可见（草稿版本、未发布库、已整库下架的库不可见）；预览只读，无编辑入口 |

### S02 收藏因子（复制副本）

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要在本人 / 本组织核算中使用某已发布库因子 |
| 操作流程 | 因子详情页点**五角星「☆ 收藏」** → 收藏弹窗（选目标「我的因子库」或即时新建）→「收藏所选因子（N）」→ 系统**复制因子值**生成独立副本 |
| 预期结果 | 我的因子库新增一条 `origin = collected` 的副本（新编码 `MF-{序号}`）；记录来源元数据（源库 / 源版本 / 源因子）；**副本独立于源库，源库后续更新不自动影响副本** |

### S02b 取消收藏（删除副本）

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 不再需要某已收藏因子，或收藏错了 |
| 操作流程 | 背景数据库因子详情页点**五角星「★ 已收藏」** → 二次确认「确认取消收藏「X」？将删除『我的因子库』中的副本」→ 确认 |
| 预期结果 | 该源因子在「我的因子库」中的副本被**删除**；五角星复位为「☆ 收藏」；源库因子本身不受影响 |

### S03 查看更新提醒

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 副本的来源库发布了新版本，且该因子值发生变化 |
| 操作流程 | 打开我的因子库详情 → 因子表「来源」列查看角标 |
| 预期结果 | 该副本显示「**有新版本可更新**」角标（`updateAvailable = true`）；副本详情页「收藏来源」区块同步展示角标 |

### S04 一键更新副本

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 副本有更新提醒，用户希望采用源库最新值 |
| 操作流程 | **单条**：因子表行内「一键更新」→ 直接刷新；**批量**：库详情顶部「一键更新（N）」→ 二次确认 → 刷新库内全部可更新副本 |
| 预期结果 | 副本值刷新为**源库最新已发布版本**的值，来源版本号更新为最新；`updateAvailable` 复位为 false；**仅更新该副本，不影响其他副本**；批量更新汇总「成功 N 条，失败 M 条」 |

### S05 手工新增因子

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 本组织有实测 / 自用因子，后台库中无对应条目 |
| 操作流程 | 我的因子库详情「手工新增因子」→ 表单三页签（**因子信息**：名称 / 英文名称 / 别名 / 适用场景 / 录入方式 / 因子值 / 复合单位 / 描述；**数据基本信息**：产品名称 / CAS 号 / 所有者 / 过程描述 / 系统模型 / 特征化方法 / GWP 版本 / 时间 / 地理 / 工艺技术 / 完整性；**输入输出信息**：输入 / 输出流）→ 保存 |
| 预期结果 | 新增 `origin = manual` 的因子（编码 `MF-{序号}`）；归属于当前我的因子库；可编辑 / 删除；可被核算引用 |

### S06 编辑 / 删除我的因子

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 因子需修正，或不再需要 |
| 操作流程 | 因子表行操作「编辑」/「删除」→ 删除时二次确认「确认删除因子「X」？」 |
| 预期结果 | 手工新增因子与收藏副本均可编辑（编辑**保留来源元数据**，仍可一键更新）/ 删除；删除**无引用阻断**，已建项目侧快照冻结不受影响（方案 §4.9） |

### S07 我的因子库 CRUD

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要新建 / 重命名 / 删除一个私有因子库 |
| 操作流程 | 我的因子库列表「新建我的因子库」→ 填名称（必填）、描述 → 保存；或对已有库「重命名」/「删除」 |
| 预期结果 | 私有库创建 / 更新 / 删除成功；**不发布、不版本化**；删除前二次确认「确认删除「X」？库内因子副本将一并删除」，确认后**级联删除**库内全部因子 |

### S08 被核算项目引用后的表现

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 我的因子被核算项目匹配引用 |
| 操作流程 | 匹配时系统推荐组织自建因子（优先于平台级 / 商业数据库）；用户确认 / 替换 |
| 预期结果 | 项目侧记录所用因子；我的因子后续修改**不影响已建项目**（项目快照冻结，方案 §4.9） |

## 4. 核心规则（**本章为核心**）

### 4.1 我的因子库定位

| 维度 | 口径 |
| :--- | :--- |
| 可见范围 | 仅本人 / 本组织（`ORG`） |
| 发布 / 共享 | **不发布、不参与平台共享** |
| 版本化 | **不版本化**（无版本号 / 版本状态 / 新建版本） |
| 角色 | **收藏夹 + 自建区** |
| 字段 | 与后台库内因子**同源**（统一字段集）+ `origin` + 来源元数据 + `updateAvailable` + `sourceStatus` |
| 删除 | 私有库可删除（**级联删除**库内因子）；库内因子可删除（无引用阻断） |

### 4.2 已发布库预览规则（背景数据库）

| # | 规则 |
| :--- | :--- |
| P1 | 前台**只能预览后台「已发布版本」**的因子；**草稿版本不可见**；库**未发布**（无已发布版本）或**已整库下架**时不可预览（原型 `fetchPublishedLibraries` / `fetchPublishedLibraryDetail`） |
| P2 | 已发布库列表包含 `external` 商业数据库与 `builtin` 自建库；库卡片展示来源标签、库编码、维护方、因子数、当前版本号 |
| P3 | 库详情**只读**：版本下拉可切换**历史版本**（`history`，只读追溯，标注「当前为历史版本，仅供追溯」）；默认展示**最新已发布版本** |
| P4 | 分类树：**商业数据库**按 **ISIC 门类 A~S → 类**两级组织（因子经 `ext.isicCode` / `ext.isicDivisionCode` 归集，节点右侧显示因子数）；**自建库无分类树**（单节点「全部因子」，因子表占满整行） |
| P5 | 库详情因子表列：过程 / 因子名称（进详情）/ 所属分类（仅商业数据库）/ 英文名称 / 因子别名 / 单位类别 / 地域 / 因子值·单位（含口径摘要）/ 操作（查看详情） |
| P6 | **列表不做收藏、不做批量收藏**：点击名称进入因子详情，在详情页用五角星收藏（原型页面注释明确） |

### 4.3 收藏复制规则（**核心**）

| # | 规则 |
| :--- | :--- |
| C1 | **收藏 = 复制式快照**：收藏动作**复制因子值**（数值、复合单位、名称、别名、适用场景、`calibers`、`unitCategory`、`region`、`ext` / `exchanges` 等）形成**独立副本** |
| C2 | 副本记录**来源元数据**：`sourceLibraryId` / `sourceLibraryName`、`sourceVersionId` / `sourceVersionNo`、`sourceFactorId` / `sourceFactorCode` |
| C3 | **源库后续更新不自动影响副本** —— 源库发布新版本后，副本**值保持不变**（不自动同步） |
| C4 | 副本 `origin = collected`；副本在我的因子库内**可编辑 / 可删除** |
| C5 | 收藏时副本归属我的因子库由用户选择（可选已有库，或在收藏弹窗内**即时新建**） |
| C6 | **收藏判重**：同一源因子（`sourceFactorId`）在**同一「我的因子库」内不可重复收藏**（失败提示「该因子已收藏，请勿重复收藏」）；收藏到**不同库**允许 |
| C7 | **因子编码**：副本由系统生成新编码 **`MF-{序号}`**（3 位补齐、组织内自增唯一），**不沿用源编码**；源编码记入 `sourceFactorCode` |
| C8 | **来源状态 `sourceStatus`**：源库**整库下架** → `offline`（标记「来源库已下架」）；源库当前发布版本中该因子**已被移除**、或源库不存在 / 已无已发布版本 → `removed`（标记「来源因子已移除」）；否则 `ok` |
| C9 | **取消收藏**：在背景数据库因子详情页再次点击五角星 → 二次确认 → **删除副本**；源库因子不受影响 |

> **声明（务必落地展示）**：**收藏副本是源的"快照"，不与源库联动**；源库更新**仅通过「更新提醒 + 一键更新」手动生效**。

### 4.4 更新提醒与一键更新规则

| # | 规则 |
| :--- | :--- |
| U1 | **触发条件（判定口径）**：副本的源库**发布了新版本**（`sourceVersionId` ≠ 源库当前发布版本）**且该因子值 `value` 发生变化**（与源库当前版本中同 `sourceFactorCode` 的因子比对）；单位 / 名称等其它字段变化**不触发** |
| U2 | 满足 U1 时，副本 `updateAvailable = true`，列表「来源」列显示「**有新版本可更新**」角标 |
| U3 | **一键更新（覆盖字段）**：把副本的 `value` / `numeratorUnit` / `denominatorUnit` / `name` / `alias` / `ext` / `exchanges` 刷新为**源库最新已发布版本**的值，并更新 `sourceVersionId` / `sourceVersionNo` 为最新版本；`scenario` / `calibers` / `unitCategory` / `region` / `description` / `englishName` / `code` **保持副本现值** |
| U4 | 一键更新**仅影响该副本**，不影响同一源的其它副本；更新后 `updateAvailable` 复位为 false |
| U5 | 源库新版本**未改变该因子值**时，`updateAvailable` 保持 false（不打扰用户） |
| U6 | 副本**手工编辑后仍可一键更新**（以源值按 U3 覆盖），来源元数据保留；编辑不脱离源版本追踪 |
| U7 | **`sourceStatus = offline` / `removed` 时不提供一键更新**（行内无「一键更新」按钮）；副本保持快照值不变 |
| U8 | **批量一键更新**：库详情顶部「一键更新（N）」对该库内全部 `updateAvailable = true` 的副本执行更新，汇总成功 / 失败条数 |
| U9 | 源库**整库下架**后，副本**保持快照值不变**、`updateAvailable` 置 false，并标记「来源库已下架」；源库重新上架后恢复正常比对 |

### 4.5 手工新增因子规则

| # | 规则 |
| :--- | :--- |
| M1 | 手工新增因子 `origin = manual`；来源元数据为空、`updateAvailable` 不适用 |
| M2 | 字段遵循**统一字段集**（与后台库内因子同源，见《排放因子库字段清单》V0.4 / 原型 `FactorItem`）：因子编码（系统生成 `MF-{序号}`）/ 因子名称 / 因子别名 / 英文名称 / **适用场景（必填）** / **录入方式（总指标 / 分指标）** / **GWP 分项口径（化石 / 生物碳 / 土地利用）** / 因子数值 + 分子单位 + 分母单位（复合单位）/ 单位类别 / 地域 / 描述 + 数据基本信息（`ext`）/ 输入输出（`exchanges`）；**不含** `libraryVersionId` 语义（改记归属我的因子库），**亦不含「适用对象 / 适用阶段 / 适用年度 / 气体种类 / 生物碳类型 / 数据质量等级 / 使用状态 / 因子分类 / 适用行业 / 来源信息」字段** |
| M3 | **录入方式**：`total` 总指标（直接填一个总体值）/ `split` 分指标（分别填「化石 / 生物碳 / 土地利用」，**合计自动计算**，只读） |
| M4 | **保存校验**：因子名称、适用场景、复合单位（分子 + 分母）必填；**因子值不能为空且不能为 0**；分指标合计不能为 0；**口径闭合校验**：`gwpTotal` 应 ≈ 化石 + 生物碳 + 土地利用（容差 1%）；描述最长 **500 字符** |
| M5 | 手工新增因子可编辑 / 删除；可被核算匹配引用（作为组织自建因子，匹配时**优先于**平台级 / 商业数据库因子） |

### 4.6 因子详情结构（原型三页签）

| 区块 | 内容 |
| :--- | :--- |
| 收藏来源（**仅收藏副本**） | 来源库 / 源版本 / 源因子编码 / 当前值 + 状态标签（有新版本可更新 / 已是最新） |
| 页签① 因子信息 | 因子编码 / 因子名称 / 英文名称 / 因子别名 / 适用场景 / 碳排放因子值 / 单位·活动数据单位（复合）/ 单位类别 / 地域 / 描述 + **指标明细**（分指标因子：化石 / 生物碳 / 土地利用 / 合计；总指标因子：仅合计，口径说明「单一口径总指标值」） |
| 页签② 数据基本信息 | 基本信息（产品名称 / CAS 号 / 所有者 / 所属分类（ISIC 路径）/ 过程描述）、时间信息（时间边界 / 时间描述）、地理信息（地域 / 地理信息描述）、工艺技术（工艺技术描述）、技术信息（完整性说明） |
| 页签③ 输入输出信息 | 输入数据（列含上游过程名称）/ 输出数据（列含下游过程名称）；名称 / 数量 / 单位 / 对端过程名称 |
| 制单信息 | 创建人 / 创建时间 / 更新人 / 更新时间（置底） |

> **无「来源信息」页签 / 区块**（来源类别 / 发布年份 / 发布日期 / 发布机构 / 数据来源文件等均不设）。

### 4.7 与后台库的关系

| 关系 | 说明 |
| :--- | :--- |
| 字段来源 | 与后台库内因子**同源**（统一字段集）；我的因子额外携带来源元数据、`updateAvailable`、`sourceStatus` |
| 生命周期 | 后台库级版本化 + 发布；我的因子库**不发布、不版本化** |
| 更新机制 | 后台发布新版本 → **不自动同步**到我的因子库 → 仅触发**更新提醒** |
| 匹配优先级 | 我的因子（组织自建）> 平台级 / 商业数据库因子（方案 §4.4） |

## 5. 业务规则

| 规则编号 | 规则名称 | 触发条件 | 处理逻辑 | 例外策略 |
| :--- | :--- | :--- | :--- | :--- |
| R-001 | 私有边界 | 我的因子库 / 我的因子任何操作时 | **不发布、不参与平台共享、不版本化**；仅本人 / 本组织可见 | 无例外 |
| R-002 | 已发布库预览约束 | 预览后台库时 | 仅**已发布版本**因子可见；草稿版本、未发布库、已整库下架库不可见（P1） | 无例外 |
| R-003 | 收藏复制 | 收藏因子时 | **复制因子值形成独立副本**（新编码 `MF-{序号}`）+ 记录来源元数据（C1 / C2 / C7） | 无例外 |
| R-004 | 收藏判重 | 收藏因子时 | 同库同源因子**不可重复收藏**，失败并提示（C6） | 收藏到不同库允许 |
| R-005 | **副本不自动同步** | 源库发布新版本时 | 副本值**保持不变**；仅按 U1 判定并标记 `updateAvailable`（U1 / U2） | 无例外 |
| R-006 | 一键更新 | 对 `updateAvailable = true` 的副本操作时 | 按 U3 覆盖字段刷新 + 更新来源版本号 + 复位标记（U3 / U4 / U8） | `offline` / `removed` 不提供更新（U7） |
| R-007 | 手工新增 | 从零新增因子时 | `origin = manual`；字段遵循统一字段集；编码 `MF-{序号}`（M1 / M2 / M5） | 无例外 |
| R-008 | 保存校验 | 手工新增 / 编辑保存时 | 名称 / 适用场景 / 复合单位 / 因子值必填；因子值 ≠ 0；口径闭合（容差 1%）；描述 ≤ 500 字符（M4） | 校验失败阻断保存 |
| R-009 | 单位一致性校验 | 匹配 / 核算前置校验时 | 我的因子分母单位 ↔ 活动单位须可换算；不可换算触发 **E04** | 补换算关系后放行 |
| R-010 | 因子缺失阻断 | 核算前置校验时 | 参与计算的活动数据无有效因子 → **E03** 阻断，禁止按 0 排放 | 无例外 |
| R-011 | 变更不追溯 | 我的因子被项目引用后修改 / 一键更新时 | 项目侧快照冻结，**不影响已建项目**（方案 §4.9）；重算走 **E13** | 删除因子同样不追溯（无引用阻断） |
| R-012 | **取消收藏** | 在背景数据库因子详情页取消收藏时 | 二次确认后**删除该源因子在「我的因子库」中的副本**；源库因子不受影响（C9） | 无例外 |
| R-013 | **来源状态与失效提示** | 源库下架 / 源因子被移除时 | 源库**整库下架** → 标记「来源库已下架」；源因子在最新版本**已移除** / 源库不存在 / 无已发布版本 → 标记「来源因子已移除」；副本值保持快照不变，不提供一键更新（C8 / U7 / U9） | 提示用户按需替换或删除副本 |
| R-014 | 删库级联 | 删除「我的因子库」时 | 二次确认（提示「库内因子副本将一并删除」）后**级联删除**库内全部因子 | 无例外 |

> 规则总数 **14 条**（V0.5 新增 R-012「取消收藏」、R-014「删库级联」，原 R-011 编号顺延调整并合并删库口径）。

## 6. 状态与操作矩阵

### 6.1 状态维度说明

| 状态维度 | 取值 | 来源 |
| :--- | :--- | :--- |
| 因子来源 | `manual` 手工新增 / `collected` 收藏副本 | 字段清单（系统带出，只读） |
| 更新状态 | `updateAvailable` = true / false | 系统自动（源库新版本 + **因子值变化**，仅 `collected`） |
| 来源状态 | `ok` 正常 / `offline` 源库已下架 / `removed` 源因子已移除 | 系统自动（仅 `collected`） |
| 指标口径 | `total` 总指标 / `split` 分指标（`calibers` 有分项值） | 系统按 `calibers` 推导展示 |

> 本模块**无版本维度、无发布状态、无启用 / 禁用状态**（不发布、不版本化；私有因子均可被匹配选用）。

### 6.2 操作矩阵

| 因子来源 | 更新状态 | 来源状态 | 编辑 | 删除 | 一键更新 | 取消收藏（源详情页） | 被匹配引用 |
| :--- | :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| 手工新增 `manual` | 不适用 | 不适用 | 是 | 是 | — | — | 是 |
| 收藏副本 `collected` | false | `ok` | 是 | 是 | —（无提醒） | 是 | 是 |
| 收藏副本 `collected` | true | `ok` | 是 | 是 | **是** | 是 | 是 |
| 收藏副本 `collected` | false | `offline` | 是 | 是 | 否（来源库已下架） | 是 | 是 |
| 收藏副本 `collected` | false | `removed` | 是 | 是 | 否（来源因子已移除） | 是 | 是 |

**闭环校验**

- 收藏副本与手工新增因子均可编辑 / 删除（**删除无引用阻断**；已建项目侧快照冻结，R-011）；
- 更新状态仅在「源库发布新版本 + 因子值变化」时置 true，一键更新后复位；
- `offline` / `removed` 状态下不提供一键更新，副本保持快照；
- 无版本分支、无发布分支、无审核分支、无死状态。
