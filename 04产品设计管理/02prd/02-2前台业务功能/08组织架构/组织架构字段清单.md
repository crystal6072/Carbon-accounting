## 0. 表定位

```text
租户（tenant，由租户管理字段清单维护，本清单只引用）1 ──── N 组织节点（org）
租户（tenant）1 ──── N 组织类型字典（org_type_dict）
组织类型字典（org_type_dict）1 ──── N 组织节点（org.org_type_id）
组织模板（org_template，平台级，不属于任何租户）1 ──── N 组织模板节点（org_template_node）
组织模板节点（org_template_node）自关联：parent_node_id
成员（member，由成员管理字段清单维护）N ──── 1 组织节点（member.dept_id 语义等于 org.id）
角色指定组织范围（role_function_dept，由角色管理字段清单维护）N ──── 1 组织节点
业务数据（核算项目 / 产品 / 工艺 / 工序 / 因子）N ──── 1 组织节点（owner_org_id）
```

推论：

| # | 推论 |
| :--- | :--- |
| 1 | 组织表是租户内唯一的组织实体表，不另建「部门表」；成员 `dept_id` 与角色 `dept_id` 均指向 `org.id` |
| 2 | 组织类型字典归租户，模板归平台；模板节点只存类型**名称**，套用时按名称匹配或自动建类型 |
| 3 | 组织不做软删：删除前由业务校验拦截，通过后物理删除；无「已删除」状态 |
| 4 | 组织变更不建历史表，靠审计日志 + 业务数据冗余 `owner_org_path` 追溯（业务 PRD D07） |
| 5 | 组织节点数不设硬上限，`org_path` 用 ID 路径而非名称路径，改名与移动不影响业务数据快照的可读性（移动时会同步重算业务数据快照的场景见 §6） |
| 6 | 代配置不落独立表，全部操作落审计日志并打「代配置」标记 |

| :--- | :--- | :--- | :--- |
| `member.dept_id` | 成员主组织，语义等于 `org.id` | 成员管理字段清单 | 可空；为空按「仅本人」；对应组织必须启用才可挂新成员；组织删除前须无挂靠成员 |
| `role_function_dept.dept_id` | 角色「指定组织」数据范围的节点 | 角色管理字段清单 | 组织删除时由本模块联动移除引用并提示（对齐角色管理 D10），不做数据库级联 |
| `pcf_project.owner_org_id` | 核算项目的核算主体组织 | 核算项目字段清单 | 不可空；组织删除前须无项目引用 |
| `pcf_project.owner_org_path` | 项目归属组织的路径快照 | 核算项目字段清单 | 创建时写入；组织移动后**不重算**，保留历史口径 |
| 产品 / 工艺 / 工序 / 因子 `owner_org_id` | 主数据归属组织 | 各模块字段清单 | 可空（平台预置为空）；组织删除前须无引用 |
| `role_function_dept` 范围枚举 | 2=本组织及下级 / 3=本组织 / 5=指定组织 | 角色管理字段清单 | 「本组织及下级」按 `org_path` 前缀匹配实时计算 |

**`owner_org_path` 快照规则**

| 场景 | 处理 |
| :--- | :--- |
| 新建业务数据 | 写入当时的 `org.org_path` |
| 组织改名 | 快照不变（路径存 ID，不含名称） |
| 组织移动 | 快照**不重算**，保留历史路径；同时记录审计，便于解释「为何路径与当前树不一致」 |
| 组织删除 | 因存在业务引用而禁止删除（§5.5），故不会出现悬空快照 |
| 按组织统计 | 以 `owner_org_id` 为主，`owner_org_path` 仅用于历史口径还原与报表说明 |

## 7. 待确认（字段级）

| # | 事项 | 说明 |
| :--- | :--- | :--- |
| T01 | `parent_id` 用 0 还是 NULL 表示根 | 本清单用 `0`，以保证 `(tenant_id, parent_id, org_name)` 唯一索引对根节点同样生效；若技术侧坚持 NULL，需改为函数索引或应用层判重 |
| T02 | `org_path` 存 ID 路径还是编码路径 | 本清单存 ID 路径（形如 `/12/45/`），改名与编码变更不影响；若需可读性可另加 `org_path_name` 冗余列，本期不建 |
| T03 | 业务数据是否保存 `owner_org_path` | 本清单建议保存（见 §6）；如不保存，组织移动后历史数据将无法按原路径解读，需改为组织时点表 |
| T04 | 成员 `dept_id` 是否更名 `org_id` | 本期只做语义映射，不改字段（业务 PRD D02、T06） |
| T05 | 组织负责人是否落账号ID | 本期存姓名与电话文本（`leader_name` / `leader_phone`）；若要联动权限，需改为 `leader_account_id` 并补角色规则 |
| T06 | 组织编码生成规则 | 本期系统生成 `ORG + 6 位租户内序号`；若客户有既有编码体系，允许手填覆盖，需保证导入时编码不与系统生成冲突 |
| T07 | 模板是否需要租户级私有模板 | 本期模板全平台共享（`org_template` 无 `tenant_id`）；若客户要求沉淀私有模板，需加 `tenant_id` 可空列并区分可见范围 |
