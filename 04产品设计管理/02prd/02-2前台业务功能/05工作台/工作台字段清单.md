## 3. 接口契约（数据来源）

> 工作台仅消费以下 5 个既有接口 / 工具函数，**不新增接口**。签名以原型 `src/mock/index.ts` 为准。

| # | 接口 / 函数 | 签名 | 返回 | 语义与排序 |
| :-: | :--- | :--- | :--- | :--- |
| I1 | `fetchPcfProjects` | `() => Promise<PcfProject[]>` | 核算项目全量列表 | **按 `updatedAt` 倒序**；供区块②③⑤取数与派生统计 |
| I2 | `fetchMyProducts` | `() => Promise<MyProductItem[]>` | 我的产品库列表 | 组织自建 + 引用平台产品；仅取 `length` 作「产品数量」（C04） |
| I3 | `fetchPcfCurrentUserOrg` | `() => Promise<PcfOrgOption>` | `{ id, name }` | 当前登录用户所属组织（原型 mock 固定返回 `pcfOrgOptionSeed[1]`）；供欢迎语与统计卡标题 |
| I4 | `fetchPcfCalcResult` | `(projectId: string) => Promise<PcfCalcResult \| null>` | 项目**最新版本**核算结果 | 按 `version` 倒序取第一条；无结果返回 `null`；供总览与概览卡片取 `unitEmission` / `stageSummary` / `calculatedAt` |
| I5 | `boundaryLabelOf` | `(code: string) => string` | 系统边界文案 | 查「数据字典 · 系统边界」启用项编码 → 标签；未命中回退编码本身；供待办元信息 |

**装载时序**：`Promise.all([I1, I2, I3])` 并行 → 再 `I1` 结果逐项目并行 `I4` → 渲染。

### 3.1 引用的上游字段（投影口径）

| 上游对象 | 字段 | 用途 |
| :--- | :--- | :--- |
| `PcfProject` | `id` / `name` / `productName` / `ownerOrg` / `productIndustry` / `createdBy` / `boundary` / `status` / `updatedAt` | 区块②③⑤ |
| `PcfCalcResult` | `unitEmission` / `calculatedAt` / `stageSummary[]` | 区块②⑤ |
| `PcfStageSummary` | `stage` / `emission` / `ratio` | 区块② 阶段构成 |
| `PcfOrgOption` | `name` | 区块①④ |
| `MyProductItem` | （仅计数） | 区块④ |
| 状态元数据 | `PCF_STATUS_TEXT` / `PCF_STATUS_TONE`（`pages/pcf/pcfMeta.ts`） | 区块③ 待办 Tag |

## 5. 统计口径与计算规则

| 规则ID | 统计量 | 输入 | 计算规则 | 输出 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| C01 | 待计算产品数 | 项目列表 | `count(status ∈ {new, ongoing, checking, toCalc, calculating, calcFailed})` | number | 待计算组（§6.1） |
| C02 | 已计算产品数 / 已计算数量 | 项目列表 | `count(status === 'calculated')` | number | 区块③④ 同源同值 |
| C03 | 报告数量 | 项目列表 | `count(status ∈ {reportGenerating, reportEditing, done})` | number | 历史保留态；兼容统计 |
| C04 | 产品数量 | 我的产品库列表 | `length` | number | 组织自建 + 引用平台产品 |
| C05 | 碳排放总览记录 | 项目列表 + 各项目最新结果 | 过滤 `status === 'calculated' 且 result ≠ null`，按 `calculatedAt` 降序取首条 | 记录 或 null | 空 → 总览空态 |
| C06 | 待办项目 | 项目列表（`updatedAt` 倒序） | 首个 `status ∈ 待计算组` 的项目 | 项目 或 null | 空 → 待办空态 |
| C07 | 概览卡片集合 | 项目列表（`updatedAt` 倒序） | `slice(0, 3)`（`FP_CARD_COUNT`） | 项目[] | 不足 3 张按实际展示 |
| C08 | 数值格式化 | `value: number \| null \| undefined` | 空 / 非有限值 → `-`；否则 `String(Number(value.toFixed(4)))` | string | 全页排放数值唯一格式 |

## 7. 展示格式规则

| 格式编号 | 规则 | 示例 |
| :--- | :--- | :--- |
| F1 | `formatEmission`：空 / 非有限值 → `-`；否则保留最多 4 位小数并去尾零 | `0.038` → `0.038`；`0.03898756` → `0.039`；`null` → `-` |
| F2 | 占比展示：`ratio.toFixed(1) + '%'`；条形宽度 = `emission > 0 ? Math.max(ratio, 2) : 0`（%） | `12.3%` |
| F3 | 碳足迹单位书写：总览主块 = `kgCO₂e`；概览卡片 = `kg CO2-Eq`（同一口径两种书写，以原型为准） | — |
| F4 | 欢迎行日期：`{YYYY} 年 {M} 月 {D} 日`（进入页面时计算一次） | `2026 年 10 月 14 日` |
| F5 | 文本占位：组织名为空 → `—`；卡片键值空 → `-`；加载中统计数值 → `-`；加载中文案区 → 「加载中…」 | — |
| F6 | 元信息拼接：`[productIndustry \|\| '未填行业', boundaryLabelOf(boundary), updatedAt].filter(Boolean).join(' · ')` | `竹制品制造 · 摇篮到大门 · 2026-09-18 16:30` |
