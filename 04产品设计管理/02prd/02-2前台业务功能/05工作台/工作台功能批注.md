## 1. 拟添加的批注清单

### 1.1 整体流程

#### P01-01 工作台使用流程
**拟标注位置**：欢迎行主标题「欢迎回来，{组织名}」附近（全局说明入口）
**标记**：已确认

**批注内容**

- **适用场景**：用户登录后进入系统，需要先看清「最近算得怎么样、还有什么没算、组织家底有多少」，再决定去哪个模块继续工作。
- **流程**：进入工作台（登录后默认落到本页）→ 页面自动汇总数据并渲染六个区块 → 阅读「碳排放总览」了解最近一个已完成核算的产品碳足迹 → 阅读「核算进度」了解待计算 / 已计算数量 → 从待办卡直接去完成最近的待核算项目 → 需要看单个项目时，从「碳足迹概览」卡片进入该项目。
- **分支**：① 没有任何已完成核算时，总览不显示数值，改为引导文案；② 没有待核算项目时，待办区不显示卡片，改为空态；③ 没有任何核算项目时，概览区改为引导文案。
- **衔接**：本页只做查看与跳转，不承载任何写操作；要新建核算必须去「碳足迹核算」列表，本页不提供入口。
- **结束**：本页没有提交、审核、保存动作，也没有"完成"终点；看完或点卡片进入其他页面即离开本页，本页的数据在下次进入时重新汇总。

### 1.2 全局规则说明

#### P01-02 全局规则
**拟标注位置**：欢迎行主标题附近（与整体流程同一全局说明入口）
**标记**：已确认（部分为原型已表现·待核对）

**批注内容**

1. **只读页面**：工作台**没有任何写操作**——不提供新增、编辑、删除、导入、导出入口，也没有可提交的表单；所有内容都是其他模块数据的汇总展示。
2. **无创建入口**：**不在本页提供「新增核算 / 新增产品模型」**；需要新建核算记录时，去「碳足迹核算」列表，概览区空态文案负责引导。
3. **数据来源**：全部为只读汇总，来源包括核算项目及其最近一次核算结果、我的产品库、当前登录用户所属组织；本页不单独产生数据。
4. **组织口径**：欢迎语与「组织统计」卡片标题取**当前登录用户所属组织**，不由用户手工选择；本期单组织，不提供组织切换。
5. **概念不外露**：本页不展示计算式、因子、异常编号、专业术语与内部字段名，只呈现用户可理解的业务名称与数值。
6. **数值口径统一**：本页所有排放数值按同一规则格式化（最多四位小数并去掉末尾无效的 0；无结果显示 `-`），避免同一数值在不同区块显示成不同位数。
7. **单位书写保留两种写法**：碳排放总览写 `kgCO₂e`，碳足迹概览卡片写 `kg CO2-Eq`——同一单位在两处的界面写法不同，**以原型为准，暂不统一**（是否统一见 §4）。
8. **统计口径与核算项目一致**：待计算 / 已计算 / 报告三组分群与「碳足迹核算」的项目状态定义一致（详见 P01-04）。
9. **原型已表现·待核对**：原型未对汇总接口失败做处理（无错误提示与重试）；且汇总取的是全部项目，未按所属组织过滤 —— 正式实现的数据范围口径见 §4。

### 1.3 进入与数据装载

#### P01-03 进入工作台与数据装载（含加载态）
**拟标注位置**：欢迎行主标题附近（全局说明入口）
**标记**：已确认（加载表现为原型已表现·待核对）

**批注内容**

- **触发**：从菜单进入工作台、或登录后自动落到本页；每次进入都重新汇总，不缓存上次结果。
- **装载顺序**：先并行取「核算项目列表 / 我的产品库 / 当前用户所属组织」，再据此逐项目取各自最近一次核算结果；全部到位后一次性渲染。
- **加载中表现**：所有统计数字先显示 `-`，总览区与待办区显示「加载中…」；不出现空白面板，也不出现未格式化的原始数值。
- **结果**：装载完成后，六个区块按最终数据渲染；没有数据时按各区块的空态文案展示（见 P01-07 / P01-09 / P01-12 / P01-15）。
- **刷新**：本页不提供刷新按钮，也不自动轮询；要看最新数据需重新进入本页。
- **待确认**：汇总接口失败时是否补错误提示与重试入口（原型未处理），见 §4。

### 1.4 业务状态说明

#### P01-04 核算项目状态与三组统计口径
**拟标注位置**：「核算进度」卡片标题旁；待办卡状态标签旁同步引用
**标记**：已确认（"是否含历史态"为待核对）

**批注内容**

- **说明对象**：本页自身没有业务状态；这里说明的是被汇总对象——**核算项目的状态**，它决定一个项目被计入哪一组统计、以及能否成为待办。
- **分群口径**：

| 分群 | 包含的项目状态 | 本页用于 |
| :--- | :--- | :--- |
| 待计算组 | 新建、待处理、待检测、检测中、待核算、核算中、核算失败 | 「待计算产品」计数、待办卡选取范围 |
| 已计算组 | 已完成、以及历史遗留的「已核算」 | 「已计算产品 / 已计算数量」计数、碳排放总览选取范围 |
| 报告组（历史保留） | 报告生成中、报告编制中 | 仅「报告数量」计数；核算流程不再产生这两种状态，通常为 0 |

- **状态来源与变化**：状态随核算流程推进而变化，由「碳足迹核算」内的操作驱动（保存、检测、核算等）；本页不改动任何项目状态。
- **界面表现**：待办卡上的状态标签文字与配色沿用「碳足迹核算」的统一口径，本页不自定义。
- **原型已表现·待核对**：原型把「已完成」与历史态「已核算」都计入「已计算产品」，与 PRD/字段清单把历史态单独归到报告组的写法不同，需裁决后统一口径（见 §4）。

### 1.5 区块说明、操作功能及对应业务规则

#### P01-05 碳排放总览（最近一个已完成核算）
**拟标注位置**：「碳排放总览」标题旁（含空态）
**标记**：已确认

**批注内容**

- **区块目的**：一屏讲清最近一次核算成果，回答「最近算得怎么样」。
- **取数规则**：只在**已完成核算**的项目中，取**核算时间最靠前（最近）的那一条**；不是累计值，也不是全部项目的合计。没有符合条件的项目时不显示数值。
- **展示内容**：产品名称、碳足迹大数（每声明单位的碳排放量）、核算时间，以及该产品各生命周期阶段的构成条形图。
- **展示限制**：本区块只展示这**一条**记录，不提供历史列表、切换框、时间范围筛选；要看历史记录去「碳足迹核算」列表。
- **无内容时**：显示引导文案「暂无已完成核算的产品，完成首次核算后展示碳足迹与阶段构成」；此时**不出现 0、不出现空数值**，也不出现任何占位数值。

#### P01-06 各阶段构成
**拟标注位置**：总览右栏「各阶段构成」区域
**标记**：已确认

**批注内容**

- **展示内容**：该产品生命周期各一级阶段逐行展示——阶段名称、条形（按占比填充）、该阶段排放量、占总排放的百分比。
- **形成规则**：条形长度按该阶段占比填充；**占比很小但排放量为正时，仍保证一小段可见**（按最小 2% 兜底），排放量为 0 或负值时条形为空。
- **解读口径**：各行占比之和为 100%；具体阶段名称与行数随该项目核算范围而定，本页不固定阶段数量与顺序。
- **数据来源**：取自该产品最近一次核算结果，不由用户在本页填写或修改。

#### P01-07 核算进度统计
**拟标注位置**：「核算进度」卡片标题旁
**标记**：已确认

**批注内容**

- **区块目的**：回答「还有什么没算」，并给出最快的继续入口。
- **展示内容**：① **待计算产品**——处于待计算组的项目数量；② **已计算产品**——处于已计算组的项目数量。
- **计数口径**：按**项目数量**统计（一个项目计一条），不是按产品去重、也不是按核算结果版本数统计；同一产品的多条核算记录分别计数。
- **口径提示**：两个数量互斥且同时使用同一份项目列表，**某个项目被改动状态后，下次进入本页两个数字会同步变化**。
- **加载中**：显示 `-`，不显示 0，避免误读为"没有待办"。
- **关联影响**：本区块的计数口径与 P01-04 的状态分群一致；状态口径调整时，两个数字同时调整。

#### P01-08 待办卡
**拟标注位置**：待办卡整体（项目名 + 状态标签 + 元信息）
**标记**：已确认（"只显示一条"为待核对）

**批注内容**

- **区块目的**：把"下一个该处理的项目"直接摆在进度卡里，减少查找成本。
- **选取规则**：在待计算组的项目中，取**最近更新过的那一个**；只取一条，不做清单、不分页、不排序。
- **展示内容**：项目名称、项目当前状态标签、元信息（所属行业 · 系统边界 · 最近更新时间）。
- **展示规则**：所属行业为空时显示"未填行业"；元信息各段为空时自动省略该段，段之间用「·」连接；项目名过长省略显示。
- **覆盖范围**：只覆盖本组织可见的核算项目；本项目状态变为已计算后，待办卡自动换成下一个待计算项目。
- **无内容时**：显示"暂无待核算项目"；加载过程中显示"加载中…"。
- **原型已表现·待核对**：只显示一条待办，是否需要待办清单或多条待办尚未裁决（见 §4）。

#### P01-09 待办卡状态标签与元信息
**拟标注位置**：待办卡状态标签旁
**标记**：已确认

**批注内容**

- **状态标签**：展示该项目当前所处的状态（如待处理、待检测、待核算、核算失败等），文字与配色沿用「碳足迹核算」的统一口径，本页不自定义文案。
- **标签含义**：标签只说明"该项目目前停在流程哪一步"，不表示工作台对它的处理能力；本页不会因标签不同而改变可进行的动作（一律只能查看与跳转）。
- **元信息**：所属行业取自项目所属行业字段；系统边界取自该项目设定的核算边界并转成界面文案；最近更新时间为该项目最后一次发生变更的时间。

#### P01-10 「去完成」跳转
**拟标注位置**：待办卡右侧「去完成」
**标记**：已确认

**批注内容**

- **操作目的**：直接继续处理该项目，不经过列表查找。
- **可操作条件**：存在至少一条待计算组的项目时显示该卡片；与项目具体状态无关（任何一个待计算状态都可继续）。
- **操作方式**：整张待办卡可点，右侧「去完成」为明确的动作提示，两者结果相同。
- **结果**：进入该核算项目的项目工作台，**落在该项目当前所处步骤**上，而不是固定回到第一步；本页不发生任何数据变更。
- **边界**：跳转后原页面的数据不再自动刷新；完成处理后返回工作台，需要重新进入或刷新页面才能看到更新后的统计与待办。

#### P01-11 组织统计卡
**拟标注位置**：组织统计卡标题（组织名）旁
**标记**：已确认（"报告数量"是否保留为待确认）

**批注内容**

- **区块目的**：一屏盘点组织家底，回答"组织已有多少资产与成果"。
- **卡片标题**：当前登录用户所属组织的名称；组织名为空时兜底显示"我的组织"。
- **展示内容**：① **已计算数量**——已完成核算的项目数，与左侧「已计算产品」同源同值；② **产品数量**——我的产品库中的产品条数（组织自建与引用平台产品合计）；③ **报告数量**——处于历史报告态的项目数。
- **计数口径**：产品数量按我的产品库现有条目计数，不区分上架 / 下架状态，也不去重引用同一平台产品的多条副本。
- **加载中**：三项均显示 `-`。
- **待确认**：核算流程调整后不再产生历史报告态，"报告数量"通常会一直为 0，是否保留该项或换成其他统计尚未裁决（见 §4）。

#### P01-12 碳足迹概览卡片
**拟标注位置**：概览卡片整体 + 「碳足迹概览」标题旁
**标记**：已确认

**批注内容**

- **区块目的**：给出最近几条核算记录的快捷入口，便于逐个查看。
- **取数规则**：取项目列表中**最近更新的前 3 条**（按更新时间倒序），不论项目状态；不足 3 条时按实际条数展示。
- **卡片内容**：产品名称、核算主体、所属行业、创建人、碳足迹数值（每声明单位排放量）。
- **数值口径**：取该项目**最近一次核算结果**的数值；**项目尚无核算结果时数值显示为 `-`**，而不是 0。
- **加载中**：数值显示 `-`。
- **无内容时**：整个概览区显示引导文案「暂无核算记录，去「产品碳足迹核算」新增」。
- **待确认**：概览卡片数量固定为 3 张且不可配置，是否需要开放配置尚未裁决（见 §4）。

#### P01-13 概览卡片跳转
**拟标注位置**：概览卡片整卡（含右箭头）
**标记**：已确认

**批注内容**

- **操作目的**：查看某个具体项目的核算情况。
- **可操作条件**：任何状态的卡片都可点击，不限制是否已有核算结果、也不限制项目状态。
- **操作方式**：整张卡片可点（含右侧箭头提示），鼠标悬停时卡片有高亮反馈。
- **结果**：进入该项目的项目工作台，**落在该项目当前所处步骤**上；本页不产生任何数据变更，也不改变卡片顺序。
- **边界**：进入后不会自动回到工作台；返回需自行导航。

#### P01-14 碳报告（占位）
**拟标注位置**：「碳报告」卡片标题旁
**标记**：已确认（后续是否接数据为待确认）

**批注内容**

- **区块目的**：为后续报告能力预留位置，本期只占位。
- **展示内容**：固定占位空态（文件图标 +「暂无数据」），**不接入任何数据源**。
- **适用阶段**：任何数据条件下都这样显示；即使已有核算结果或已生成过报告，本区块也不展示内容。
- **待确认**：「报告管理」功能上线后，本区块是否改为展示真实报告数据尚未裁决（见 §4）。

#### P01-15 欢迎行
**拟标注位置**：欢迎行副标题（产品碳足迹核算工作台 · 日期）
**标记**：已确认

**批注内容**

- **展示内容**：主标题「欢迎回来，{当前组织名}」；副标题「产品碳足迹核算工作台 · {当天日期}」。
- **取值口径**：组织名取当前登录用户所属组织；当天日期取进入页面时的系统日期（年 / 月 / 日），不是数据更新时间。
- **空值处理**：组织名为空时主标题显示 `—`，不做隐藏、不显示"未设置"等替代文案。

#### P01-16 产品名称
**拟标注位置**：碳排放总览产品名称、概览卡片头部产品名
**标记**：已确认

**批注内容**

#### P01-17 碳足迹数值、单位与核算时间
**拟标注位置**：碳排放总览大数单位区、核算时间行；概览卡片底部数值区同步引用
**标记**：已确认（单位书写差异为已确认的原型口径）

**批注内容**

- **碳足迹数值**：该项目**每声明单位**的产品碳足迹（不是总量），取最近一次核算结果。

- **核算时间**：该产品最近一次完成核算的时间；为空时显示 `—`。
- **数据来源**：全部来自最近一次核算结果，本页不重算、不四舍五入到不同位数、不做单位换算。

#### P01-18 待计算 / 已计算 / 产品 / 报告四项统计值
**拟标注位置**：核算进度两项数值旁；组织统计三项数值旁
**标记**：已确认（报告数量口径为待核对）

**批注内容**

- **待计算产品**：处于待计算组的项目条数（详见 P01-04）。
- **已计算产品 / 已计算数量**：处于已完成与历史「已核算」状态的项目条数；两处**同源同值**，出现不一致属于数据异常。
- **产品数量**：我的产品库现有产品条数（自建 + 引用），不包含未上架过滤。
- **报告数量**：处于历史报告态的项目条数；核算流程调整后通常恒为 0。
- **加载中统一表现**：四项数值在加载过程中均显示 `-`，不显示 0。
