# 文件库字段清单

> **文档定位**：企业文件库（租户端）字段定义的唯一真相源（SST）。业务 PRD 与 Demo PRD 只引用字段名称，不重复维护枚举、必填性与字段口径。
> **适用类型**：租户级文件资产台账 —— 无审核流，**文件可替换**（保留历次文件记录），**有引用关系**（业务引用文件，替换后同步生效）
> **核心用途**：租户内文件统一收纳与替换留痕，供业务模块通过统一选择器引用，替代各模块散存附件
> **维护形态**：列表（左侧分类导航）+ 详情抽屉 / 独立页（当前文件 + 文件记录 + 引用区）+ 上传弹窗 + 编辑弹窗
> **成熟度**：定稿
> **版本**：V0.3
> **更新时间**：2026-10-30

## 0. 对象结构

```text
文件分类（字典）
      │
文件（file_doc）  1 ─── N  文件记录（file_record）
      │
      └─ 1 ─── N  引用关系（file_reference） ──▶ 业务对象（台账 / 检测记录 / 报告 / 产品 / 模型）
```

| 结构 | 对象 | 与主对象关系 | 唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 文件 `file_doc` | 主对象 | 文件编码（租户内唯一） | 一条记录 = 一份文件资产；分类创建后可改（D02） |
| 子表 | 文件记录 `file_record` | 1:N | 记录 ID | **每次上传或替换新增一条**；最新一条为当前文件，其余为历史文件（只读） |
| 子表 | 引用关系 `file_reference` | 1:N | 引用 ID | 一条 = 某业务对象对某文件的一次使用；替换文件后自动指向新文件 |
| 字典 | 文件分类 `file_category` | — | 分类编码 | 系统内置 + 平台字典可扩展 |

**文件替换口径（核心）**

| 场景 | 是否新增文件记录 |
| :--- | :---: |
| 上传新文件（新建记录） | 是（首条记录即当前文件） |
| 编辑时只改元数据（名称 / 分类 / 说明） | 否 |
| 编辑时删除原文件再上传新的 | 是（新文件成为当前文件，旧文件转历史） |
| 编辑时直接上传新的替换 | 是（同上） |
| 停用 / 启用 | 否 |

> 一条记录始终只有一个当前文件；移除当前文件后必须上传新文件才能保存。
> 界面不出现「版本号」「升版」，用户看到的是「当前文件 + 历史文件记录」。
> 数据层仍以递增序号（原 `versionNo`）排序与定位引用，仅供系统内部使用。

> 分类由平台字典维护、租户不可新增；新增分类无需改代码。分类**固定单级**，不扩展子分类。

### 2.2 数据权限口径（不设「可见范围」字段）

| 项 | 口径 |
| :--- | :--- |
| 权限粒度 | **功能级**：持有「文件库 · 查看」功能点即可见本租户全部文件；持有对应操作功能点即可操作全部文件 |
| 行级隔离 | **不做**：不按部门、不按创建人、不按「指定部门 / 仅本人」隔离 |
| 归属部门 | 仅作展示与统计，不参与权限判定 |
| 租户边界 | 仍严格隔离：跨租户不可见、不可引用（D20） |
| 已移除字段 | 原「可见范围（全租户 / 指定部门 / 仅本人）」及配套「可见部门」选择 |

> 口径依据：企业用户端本期不做细粒度数据权限，成员只要被授予「文件管理」模块与相应功能点，即可见并可操作本租户内全部文件。

### 2.3 文件状态

| 取值 | 含义 | 可否被选择引用 | 已引用业务 |

## 3. 关键数据约束

| 约束ID | 约束 | 影响对象 |
| :--- | :--- | :--- |
| D01 | 「文件编码」在租户内唯一，系统生成（`EF-` + 6 位流水），创建后不可修改 | 主表 |
| D02 | 「文件分类」必填；**允许修改**（一次分类纠正不改文件记录，记操作日志）；取值须为启用中的字典项 | 主表 |
| D03 | 一条记录 = 一个当前文件；不支持「一条记录多附件」 | 文件记录 |
| D04 | 业务模块上传文件必须先入库再引用，**不允许绕过文件库直存** | 主表 / 引用 |
| D05 | 上传或替换均新增一条文件记录，序号自增；同一文件「是否当前文件」有且仅有一条；**界面不展示版本号** | 文件记录 |
| D06 | **数据权限为功能级**：持有「文件库 · 查看」即可见租户内全部文件；不设可见范围、不做部门 / 个人行级隔离（§2.2） | 主表 |
| D07 | 文件停用后不出现在选择器；已引用处仍可预览下载并标「已停用」；停用不减少引用次数 | 主表 |
| D08 | **被有效引用的文件不可删除**，只能停用；删除前须列出引用清单 | 主表 |
| D09 | 引用次数 = `引用状态 = 有效` 的引用条数，实时统计，不做冗余存储漂移 | 引用 |
| D10 | **替换即生效**：替换当前文件后，该文件的有效引用自动指向新文件；失效引用不跟随 | 引用 |
| D11 | 历史文件记录不可编辑、不可单独删除，仅可预览与下载 | 文件记录 |
| D12 | 删除文件 = 删除整条记录（含全部文件记录），二次确认，不可恢复；仅「引用次数 = 0」时可用 | 主表 |
| D13 | 上传按分类校验格式与大小（§2.7），并按 MIME / 魔数二次校验，防改后缀 | 文件记录 |
| D14 | 预览与下载须鉴权 + 写审计（人、时间、IP、文件与记录） | 文件记录 |
| D15 | 文件操作仅受**功能权限点**控制：持有「上传 / 编辑 / 停用启用 / 删除」即可操作全部文件，不因创建人或归属部门受限 | 主表 |
| D16 | 引用方业务记录删除时，对应引用置「失效」，文件本身保留在库中 | 引用 |
| D17 | 上传前静默校验租户容量配额，超限按 `overflow_policy` 阻断或告警，**不提供用量查看入口** | 文件记录 |
| D18 | 文件名称 ≤ 100、文件说明 ≤ 500 字符 | 主表 |
| D19 | 归属部门取创建人所属部门的**创建时快照**；成员调岗后归属部门不变；仅供展示与统计，**不参与权限判定** | 主表 |
| D20 | 数据域固定租户级，租户标识由服务端注入，不接收前端传值；跨租户不可见、不可引用 | 主表 |
| D21 | 原始文件名只读保留，重命名只改「文件名称」，不回写历史记录 | 文件记录 |
| D22 | 业务类型新增须在功能码与枚举两侧同步注册，未注册类型拒绝建立引用 | 引用 |

## 6. 不设字段的设计约定

| 不设项 | 理由 | 替代方式 |
| :--- | :--- | :--- |
| **可见范围 / 可见部门 / 仅本人** | 企业端本期只做功能级权限，持有该功能即全量可见可操作，不做行级隔离 | 功能权限点（§2.2 / D06） |
| 存储用量 / 容量字段 | 已确认不在前台展示用量 | 配额由后台静默校验（D17），超限仅上传报错 |
| **版本号展示 / 升版原因** | 用户心智是「换掉这份文件」，不是「升版」 | 编辑时替换文件；留痕放「文件记录」（§2.4 / D05） |
| 自定义文件夹 / 目录路径 | 一期以分类 + 搜索为主路径；文件量千人级内不需要逐层浏览 | 分类 + 关键字检索；文件夹树列入 P1 |
| 标签 | 一期分类已覆盖单据类型维度 | P1 |
| 密级 / 涉密标记 | 企业端本期不做密级管控，也不做行级隔离 | 如需，另行立项（P2） |
| 审核状态 / 审批流 | 文件为资产台账，不做审批 | 无 |
| 归档 / 冻结状态 | 一期用「停用」表达 | 停用 |
| 有效期 / 到期提醒 | 属业务语义（如报告有效期），放在引用方模块 | 引用方自管 |
| 下载次数 / 浏览量 | 非治理必需，审计日志可查 | 操作日志 |
| 数据来源（自建 / 引用平台） | 本库无平台来源文件 | 无 |
