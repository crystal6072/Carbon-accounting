## 1. 需求概述

### 1.1 需求背景

企业侧现有文件散落在各业务模块的附件字段里：台账有「数据凭证」子表、含碳量检测库有「报告文件」、产品库有场景图、报告编制有导出件。同一份检测报告在多个模块各上传一次，导致占用重复、同一份文件出现多个不一致的副本、核查时无法回答「这份文件现在用的是哪一份、被哪些业务引用过」。

「文件管理 → 文件库」在租户内建一层统一的文件资产层，业务模块不再各自散存附件，改为**从库中选择或上传即入库，并以引用关系关联文件**。

```text
后台「文件管理」（平台级）
  标准 + 平台单据，全租户只读                          ← 本模块不涉及
        │
企业「文件库」（租户级）★本期                            本期建设
  文件 + 文件记录 + 引用关系
        │ 引用（替换后同步生效）
业务模块：含碳量检测库 / 台账 / 报告 / 产品库 / 我的模型   ← 只存引用关系
```

三层边界不复用彼此职责：

| 维度 | 后台文件管理 | 企业文件库（本模块） | 业务内嵌附件（改造前） |
| :--- | :--- | :--- | :--- |
| 数据域 | 平台级 | 租户级，严格隔离 | 随业务记录 |
| 维护方 | 平台运营 | 租户成员按功能权限 | 记录创建人 |
| 换文件 | 每次上传新增一条记录 | 编辑里替换当前文件，留痕可查 | 直接覆盖，无留痕 |
| 本模块是否接入 | 不接入（只读参考） | — | 逐模块收敛为引用 |

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :-: | :--- | :--- |
| G1 | **一份文件只存一次** | 同一检测报告在含碳量检测库与台账同时引用，库内仅 1 条记录、引用次数 = 2 |
| G2 | **换文件足够直接** | 编辑里删掉原文件再传新的，或直接上传新的替换；界面不出现「升版 / V2」这类说法 |
| G3 | **换完立即生效** | 替换后，所有引用该文件的业务同步使用新文件，无需逐条更新 |
| G4 | **查看即可用** | 详情页「当前文件」卡片直接提供预览与下载，不必先下载才能确认内容 |
| G5 | **删除有护栏** | 被引用的文件无法删除，删除前可看到完整引用清单 |
| G6 | **上传入口统一** | 所有业务模块使用同一个文件选择器；业务页内直接上传的文件自动入库 |

### 1.3 范围

**In Scope**

| # | 范围 |
| :-: | :--- |
| 1 | 文件库列表：左侧分类导航 + 条件查询 + 表格列表 + 分页 |
| 2 | 文件详情：当前文件卡片（预览 / 下载）、基本信息、文件记录、引用关系、操作日志 |
| 3 | 上传文件：多选、拖拽、格式大小校验、分类设置 |
| 4 | **替换文件**：编辑时可删除当前文件后上传新的，或直接上传新的覆盖；旧文件转入文件记录 |
| 5 | 编辑元数据：名称、分类、说明（不影响当前文件） |
| 6 | 预览与下载：详情页与文件记录行内均可预览（PDF / 图片在线）与下载，均鉴权留审计 |
| 7 | 停用 / 启用文件 |
| 8 | 删除文件（仅未引用，二次确认，整条含全部文件记录） |
| 9 | 统一文件选择器组件（选已有 / 上传即入库 / 多选 / 分类筛选） |
| 10 | 引用关系建立与解除、引用次数统计；替换文件后同步生效 |
| 11 | P0 试点接入：含碳量检测库报告文件、加工能耗台账数据凭证 |

**Out of Scope**

| 不做项 | 说明 |
| :--- | :--- |
| 版本号 / 升版流程 | 已确认不做；换文件即「替换」，留痕放文件记录 |
| 存储用量页 / 容量条 | 已确认不做；配额仅作上传时的静默校验，不提供查看入口 |
| 可见范围 / 行级数据权限 | 企业端只做功能级权限 |
| 自定义文件夹树 | 一期用「分类 + 搜索」承载；文件夹树列入 P1 |
| 标签 | P1 |
| 在线协同编辑 / Office 在线编辑 | 不做，仅预览 |
| OCR / 内容全文检索 | 一期只检索元数据（名称 / 编码 / 原始文件名） |
| 审核流 / 归档状态 | 文件为资产台账，无审批；用停用替代归档 |
| 对外分享链接 | P2，需独立评估外链安全 |
| 跨租户共享 | 本期不允许，严格租户隔离 |
| 后台标准文件维护 | 属平台级「文件管理」，不在本模块 |
| 存量附件强制迁移 | 只提供归档入口，不自动批量迁移 |

## 2. 用户与使用场景

| 场景ID | 场景 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| S01 | 上传文件到库 | **主流程** | 进入文件库 → 「上传文件」→ 多选 / 拖拽 → 设分类 → 保存，单文件生成一条记录 |
| S02 | 列表检索 | **主流程** | 左侧分类导航 + 关键字 / 分类 / 格式 / 上传人 / 时间 / 引用状态筛选；默认更新时间倒序 |
| S03 | 查看与预览 | **主流程** | 点击文件名进详情 → 「当前文件」卡片直接预览 / 下载；文件记录里也可预览历史文件 |
| S04 | 替换文件 | **主流程** | 详情或列表点「编辑」→ 文件区「删除」当前文件 → 「上传文件」选新文件 → 保存，新文件成为当前文件 |
| S05 | 编辑元数据 | **主流程** | 改名 / 改分类 / 改说明，不换文件 |
| S06 | 业务模块引用文件 | **主流程** | 业务表单点「选择文件」→ 选择器弹窗 → 选已有文件（或就地上传）→ 建立引用 |
| S07 | 停用文件 | **辅助** | 过期或不再使用的文件停用，选择器不再出现，已引用处仍可读 |
| S08 | 删除文件 | **辅助** | 仅未引用文件可删，二次确认；有引用时提示引用清单并引导停用 |
| S09 | 查看引用去向 | **辅助** | 详情页引用区列出「哪个模块、哪张单、引用了哪份文件」 |
| S10 | 替换后核对影响 | **支线** | 编辑弹窗提示「该文件已被 N 处业务引用，替换后同步使用新文件」，保存后 toast 告知已同步数量 |

## 4. 单据定位与实体关系

### 4.1 基本定位

| 项目 | 内容 |
| :--- | :--- |
| 对象层级 | 租户级业务资产 |
| 核心职责 | 收纳租户内文件、支持替换并留痕、对外提供可选择与可引用的文件资产 |
| 来源 | 用户在文件库直接上传 / 在业务模块上传即入库 |
| 下游产出 | 被各业务模块引用（引用关系表），不直接产出业务结果 |

### 4.2 实体关系

| 关系 | 说明 |
| :--- | :--- |
| 文件 : 文件记录 | **1:N**；每次上传或替换追加一条，最新一条为当前文件，其余为历史文件（只读） |
| 文件 : 引用关系 | **1:N**；一条引用 = 一个业务对象对该文件的一次使用 |
| 文件 : 文件分类 | **N:1**；引用平台字典，租户不可新增分类 |
| 文件 : 组织架构 / 成员 | **N:1**；归属部门取创建时快照，上传人取实际用户 |
| 文件库 : 后台文件管理 | **无关系**；平台级标准文件不进入本库，本库不做标准维护 |

## 5. 状态与权限

### 5.1 文件状态

| 状态 | 含义 | 可否被选择引用 | 可否替换文件 | 可否编辑 | 可否删除 |
| :--- | :--- | :---: | :---: | :---: | :---: |
| 正常 | 可用资产 | 是 | 是 | 是 | 仅未引用时可删 |
| 停用 | 不再新增引用，保留历史 | 否 | 是 | 是 | 仅未引用时可删 |

> 状态单向可逆：正常 ↔ 停用，均走行操作 + 二次确认。

### 5.2 操作能力矩阵

企业端本期只做**功能级权限**：不按创建人、部门、文件归属做行级隔离。同一租户内，持有功能点的成员对全部文件一致可见、可操作。

| 动作 | 持有「文件库 · 查看」 | 持有对应操作功能点 | 未授予「文件管理」模块 |
| :--- | :---: | :---: | :---: |
| 查看 / 预览 / 下载 | 是（本租户全部文件） | 是 | 否（菜单不渲染） |
| 上传新文件 | 否 | 是（上传） | 否 |
| 替换文件 | 否 | 是（编辑） | 否 |
| 编辑元数据 | 否 | 是（编辑） | 否 |
| 停用 / 启用 | 否 | 是（停用启用） | 否 |
| 删除（仅未引用） | 否 | 是（删除） | 否 |
| 引用到业务 | 否 | 是（查看） | 否 |

### 5.3 功能权限点（供租户角色勾选）

| 功能点 | 说明 |
| :--- | :--- |
| 文件库 · 查看 | 进入列表与详情；可见本租户全部文件（无行级隔离） |
| 文件库 · 上传 | 上传新文件 |
| 文件库 · 编辑 | 改元数据、替换文件 |
| 文件库 · 停用启用 | 状态治理 |
| 文件库 · 删除 | 删除未引用文件 |
| 文件库 · 下载 | 下载与批量下载 |
| 文件库 · 查看引用关系 | 查看引用清单 |

> 「文件管理」须同步登记为**租户模块授权**中的一项（用户体系 §5.1.4），未授权租户整组菜单不渲染。
> 功能点只控制「能做什么」，**不含数据范围**：企业端不做行级数据权限，不设「全租户 / 指定部门 / 仅本人」。

## 6. 核心业务规则

| 规则ID | 规则 | 依据 |
| :--- | :--- | :--- |
| R-001 | **[编码生成]** 文件编码由系统生成，`EF-` + 6 位流水，租户内唯一，创建后不可改 | 字段清单 D01 |
| R-002 | **[一记录一文件]** 一条文件记录始终只有一个当前文件；多附件场景拆多条记录 | D03 |
| R-003 | **[上传即入库]** 业务模块不得直存附件；页内上传须先落库生成文件记录，再建立引用 | D04 |
| R-004 | **[替换即换文件]** 编辑时删除当前文件后上传新的、或直接上传新的，新文件成为当前文件；旧文件转入文件记录只读保留；界面不出现版本号 | D05 / D11 |
| R-005 | **[元数据不影响文件]** 改名、改分类、改说明不改变当前文件，仅记操作日志 | D05 |
| R-006 | **[替换即生效]** 替换当前文件后，该文件的有效引用自动指向新文件，业务侧无需逐条更新；失效引用不跟随 | D10 |
| R-007 | **[引用计数]** 引用次数只统计有效引用，实时计算，不做冗余计数漂移 | D09 |
| R-008 | **[删除保护]** 存在有效引用的文件不可删除，只能停用；删除入口对有引用文件隐藏并说明原因 | D08 / D12 |
| R-009 | **[删除范围]** 删除为整条记录删除（含全部文件记录），二次确认，不可恢复 | D12 |
| R-010 | **[停用语义]** 停用后不再出现在选择器；已引用处仍可预览下载并标「已停用」；不减少引用次数 | D07 |
| R-011 | **[操作看功能点]** 能否替换 / 编辑 / 停用 / 删除只取决于功能权限点，与是否为创建人、属哪个部门无关 | D15 |
| R-012 | **[引用失效]** 引用方业务记录删除时，引用置失效；文件保留在库中，引用次数相应减少 | D16 |
| R-013 | **[配额静默校验]** 上传前校验租户容量，超限按 `overflow_policy` 阻断或告警；不提供任何用量查看入口 | D17 |
| R-014 | **[功能级权限]** 被授予「文件管理」模块与「文件库 · 查看」即可见本租户全部文件；不设可见范围，不做部门 / 个人行级隔离 | D06 |
| R-015 | **[部门快照]** 归属部门取创建人创建时部门，成员调岗不回写；仅作展示与统计，不参与权限判定 | D19 |
| R-016 | **[租户隔离]** 租户标识服务端注入，前端不可传；跨租户不可见、不可引用 | D20 |
| R-017 | **[上传校验]** 按分类白名单校验格式与大小，MIME / 魔数二次判定，防改后缀 | D13 |
| R-018 | **[预览鉴权]** 预览与下载均鉴权并写审计（人、时间、IP、文件与记录） | D14 |
| R-019 | **[分类必填]** 上传时分类必填，无「待分类」暂存区；分类可事后修改 | D02 |
| R-020 | **[对接注册]** 新增业务类型须同步注册枚举与功能码，未注册类型拒绝建立引用 | D22 |

## 7. 跨模块对接机制（本模块核心）

### 7.1 两个入口，一个落点

| 入口 | 行为 | 结果 |
| :--- | :--- | :--- |
| 从库中选择 | 业务表单点「选择文件」→ 选择器弹窗 → 筛选 / 搜索 / 多选既有文件 | 建立引用关系，不复制文件 |
| 业务页内直接上传 | 在业务表单直接拖入文件 | 先入库生成文件记录（弹分类补全）→ 再建立引用 |

两个入口在业务侧的展示形态统一：`文件名 · [预览] [下载] [更换]`，「更换」= 解除旧引用 + 建新引用。业务侧同样提供预览与下载，不需要回到文件库。

### 7.2 引用与替换的关系

| 场景 | 业务侧表现 |
| :--- | :--- |
| 建立引用 | 业务详情展示该文件的文件名与预览 / 下载入口 |
| 文件库替换当前文件 | 业务侧自动变为新文件名与新内容，无「有新版本」提示、无需手工确认 |
| 文件库改文件名 / 分类 | 业务侧名称同步更新，文件内容不变 |
| 文件库停用 | 业务侧仍可预览下载，标「已停用」 |
| 文件库删除 | 被引用时不可删除 |

> 已确认**不做「锁版本 / 跟随最新」二选**：引用始终指向文件当前文件，避免出现「库里换了、业务里还是旧的」这种反直觉状态。

### 7.3 文件侧动作对业务侧的影响

| 文件侧动作 | 已引用业务的表现 | 是否阻断 |
| :--- | :--- | :---: |
| 替换当前文件 | 业务侧同步显示新文件名与新内容 | 否 |
| 编辑元数据（改名） | 引用方展示同步更新为新名称 | 否 |
| 停用 | 引用方仍可预览下载，标「已停用」 | 否 |
| 删除 | 不可执行（被引用） | 是 |
| 文件分类变更 | 引用方无感知 | 否 |

### 7.4 P0 试点改造点

| 模块 | 现状 | 改造后 |
| :--- | :--- | :--- |
| 含碳量检测库 · 报告文件 | 附件字段，必传、限 1 个、无留痕 | 改为引用关系；选择器选取或上传即入库；替换后同步生效；必传规则不变 |
| 加工能耗台账 · 数据凭证 | 独立附件子表，0–10 个，软删 | 改为引用关系；保留 0–10 上限与排序；删除台账记录时引用置失效，文件留在库 |

> 存量处理：原附件表结构与历史数据保留不动，提供「归档到文件库」入口，由租户自行触发，不做自动批量迁移（Q04）。

## 8. 边界与异常处理

| 场景 | 处理方式 |
| :--- | :--- |
| 列表为空 | 空态文案「暂无文件：点击「上传文件」上传，或在业务模块上传时自动入库」 |
| 上传时超出配额（`block`） | 阻断并提示「存储空间不足，请联系管理员」，不展示具体用量 |
| 上传时超出配额（`warn`） | 放行并提示告警，后台触发 `QUOTA_WARNING` 事件 |
| 上传格式或大小不符 | 单文件标红并给原因，其余文件不受影响 |
| 多文件中部分失败 | 逐条展示成败，失败可重试，不整批回滚 |
| 编辑时删除了当前文件但未上传新文件 | 阻断保存，提示「已移除当前文件，请上传新文件后再保存」 |
| 替换文件时该文件已被引用 | 弹窗内提示影响条数；保存后 toast 告知已同步 N 处引用 |
| 删除被引用文件 | 不提供删除入口并提示「该文件被 N 处业务引用，可先停用」；强制删除不提供 |
| 引用的文件被停用 | 业务侧仍可预览下载，展示「已停用」标记，不允许新业务再选它 |
| 引用的文件被判为需删除 | 先解除全部引用（业务侧更换或清空）后才可删除 |
| 预览不支持的格式 | 提示「该格式不支持在线预览，请下载查看」 |
| 演示数据无文件内容 | 预览 / 下载提示「演示数据未包含文件内容，可上传本地文件后预览」 |
| 成员被移出租户 | 其创建的文件保留，归属部门不变，上传人显示为已移出 |
| 分类字典项被停用 | 已引用文件只读回显原分类名，编辑时不可再选该项，须改选其他分类 |
| 业务记录被删除 | 引用自动置失效，文件保留，引用次数下降 |
