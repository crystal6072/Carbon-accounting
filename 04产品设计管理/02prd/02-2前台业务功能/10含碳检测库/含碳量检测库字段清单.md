> **文档定位**：含碳量检测库字段定义的唯一真相源（SST）。业务 PRD 与 Demo PRD 只引用字段名称，不重复维护枚举、必填性与字段口径。
> **适用类型**：基础数据维护（轻量）—— 无审核流、无版本化、无操作日志
> **维护形态**：列表 + 查看 / 新增 / 编辑弹窗；**上架 / 下架走行操作，不进表单**
> **成熟度**：定稿（V2.8）
> **版本**：V2.8
> **更新时间**：2026-11-06

## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 含碳量检测库 |
| 业务归属 | 后台管理 → 基础库 → 含碳量检测库 |
| 模块类型 | 基础数据维护（轻量），非业务单据、无审核流、无版本化 |
| 核心对象 | 含碳量检测记录（以「检测报告」为维度维护） |
| 核心职责 | 维护样品检测报告信息：样品信息、委托 / 客户信息、检测机构、检测周期、检测项目与标准、检测报告附件 |
| 不做什么 | 检测业务流程（送检、采样、实验、报告出具）；不含排放因子；不含产品/工艺数据 |

**业务链路定位**：

```text
含碳量检测库 ──▶ 导出 xlsx / 报告附件在线预览与下载
```

- 上游：委托单位 / 客户 / 检测机构（信息直接录入，不引用独立主数据）
- 下游：**暂无**。本期为独立台账，对外出口为导出与报告附件预览 / 下载

### 1.2 对象结构

| 结构 | 对象 | 与主对象关系 | 主键 / 唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 含碳量检测记录 | 主对象 | 检测编码 | **单一对象，无子表** |
| 附件 | 报告附件 | 1:N（**支持多个**） | 文件 ID | 检测报告原件 / 扫描件，查看态可在线预览与下载 |

### 1.3 维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | **不设**：不分「系统预置 / 组织自建」，所有有权进入本模块的用户同等可编辑 |
| 新增 / 编辑 | 支持，均走弹窗 |
| 子表 | 无 |
| 导入 / 导出 | 导入：V1.0 不支持；导出：**支持**。按当前查询条件导出 xlsx / CSV，规格见业务 PRD §1.3 与场景 S06 |
| 状态与执行 | 使用状态（上架 / 下架）；支持行操作单个上/下架；批量上/下架见 Q11 |
| 关键唯一键 | 检测编码唯一（全租户）；**样品名称 + 报告日期**唯一 |
| 删除 | **仅「已下架」的记录可删除**，物理删除，删除后释放唯一键 |
| 历史兼容 | 检测记录变更**不回溯已核算结果**；需按新口径重算时走 E13 |

### 1.4 关键数据约束

| 约束ID | 约束 | 影响对象 |
| :--- | :--- | :--- |
| D01 | 检测编码**全租户唯一**，系统生成，编辑只读 | 主表 |
| D02 | **样品名称 + 报告日期** 唯一；下架记录仍占用该键，删除后释放 | 主表 |
| D03 | 报告附件支持**多个**，类型 `图片 / Word / Excel / PDF`；图片与 PDF 可在线预览，其余仅下载（R-006） |
| D04 | 检测标准默认 `GB/T 44290-2024`，可选「其他」 |
| D05 | 本模块不含「数据来源」「归属组织」「可见性」「引用状态」「审核状态」字段 | 主表 |

## 8. 待确认事项

### 8.1 已确认决策

| 编号 | 结论 |
| :--- | :--- |
| **字段模型（2026-11-02 调整）** | 以「检测报告」为维度维护：报告编号 / 样品名称 / 样品描述 / 委托单位 / 样品数量 / 检测周期（日期段）/ 收样日期 / 检测项目及结果 / 报告日期 / 检测标准 / 客户信息；报告附件支持多个、可在线预览与下载 |

| **制单信息（2026-11-02 调整）** | 查看态仅展示创建人 / 创建时间 / 更新时间 |
| **状态术语** | 用「上架 / 下架」，双向可逆、两态闭环 |
| **下架语义** | 不可新增引用，已引用保留、核算结果不回溯 |
| **导出** | **支持导出**。检测数据是第三方核查交付物 |
| **无下游引用** | 系统内不存在含碳率引用点；本期为独立台账 |
| **检测机构与委托单位投影（2026-11-06 调整）** | 新增「检测机构」（必填，列表 / 查询 / 表单 / 详情 / 导出）；「委托单位」仍为必填字段，但退出列表列与查询区，仅保留表单 / 详情 / 导出 |
