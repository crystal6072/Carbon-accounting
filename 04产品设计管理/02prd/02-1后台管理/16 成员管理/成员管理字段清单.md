# 成员管理字段清单

> **文档定位**：成员管理相关表结构的字段唯一真相源。业务 PRD 只引用字段名，不重复维护类型、必填与枚举。
> **依据**：产品碳足迹核算工具-用户体系 PRD（精简版）v3.5.2 §5.5、§5.6、§5.7、§5.8；《成员管理业务 PRD》V0.3
> **覆盖表**：租户成员关系
> **范围**：邮箱 `email` 在 account 表（平台账号字段清单覆盖），本清单只引用；「关联已有账号」「管理员移出」本期不实现，对应写入时机暂只走「新建」路径。
> **版本**：V0.2
> **更新时间**：2026-10-26

## 0. 表定位

成员关系是账号在租户上的挂载，不复制账号。账号唯一存储在 `account`（平台账号字段清单 §1）；主管理员身份由 `tenant_admin_relation` 生效记录表达（租户管理字段清单 §3），本表不建主管理员标记字段；角色绑定走 `role_member`（member_type = 2，角色管理字段清单 §4），本表不建角色关联字段。

```text
account（账号，全局唯一，平台账号字段清单覆盖）
  └─ 1:N ─ tenant_member（租户成员关系，本清单 §1）
              ├─ 被 role_member 引用（member_type = 2，角色管理字段清单覆盖）
              └─ 与 tenant_admin_relation 配对识别主管理员（租户管理字段清单覆盖）
```

推论：

| # | 推论 |
| :--- | :--- |
| 1 | 成员无独立登录凭证，登录名、手机号、姓名、邮箱、密码全部在 account 表，本表只存租户域属性 |
| 2 | 同账号同租户只保留 1 条生效成员关系，已移出行保留且不阻止同账号再次加入另起新行 |
| 3 | 成员状态只作用本租户，本表不写账号级状态，也不写租户级状态 |
| 4 | 主管理员不在本表建标记，按 tenant_admin_relation 生效记录派生，成员数与保护规则同样按派生结果计算 |
| 5 | 本表不建角色关联字段，角色 1 至 5 个的约束由 role_member 行数实时校验 |
| 6 | 密码重置记录复用 platform_password_reset_log，需平台账号字段清单扩展枚举，见 §3 D05 与 §4 T01 |

## 1. 租户成员关系

表名：`tenant_member`（即成员关系表，账号在租户上的挂载）

| 字段名 | 中文名 | 类型 | 必填 | 默认 | 说明 | 约束 | 写入时机 |
| :--- | :--- | :--- | :---: | :--- | :--- | :--- | :--- |
| id | 成员关系ID | bigint | 是 | 雪花ID | 主键 | 全局唯一 | 新建、关联 |
| tenant_id | 租户ID | bigint | 是 | 无 | 所属租户 | 外键 | 新建、关联 |
| account_id | 账号ID | bigint | 是 | 无 | 挂载的账号 | 外键 | 新建、关联 |
| dept_id | 部门ID | bigint | 否 | NULL | 当前所属部门，可空 | 外键；为空按仅本人 | 新建、编辑 |
| status | 成员状态 | tinyint | 是 | 1 | 本租户内的生效状态 | 取值 1 / 2 / 3 | 新建、禁用、启用、移出、退出 |
| joined_via | 加入方式 | tinyint | 是 | 无 | 区分加入来源 | 取值 1 / 2 | 新建、关联 |
| joined_at | 加入时间 | datetime | 是 | 当前时间 | — | 不可改 | 新建、关联 |
| removed_type | 移出方式 | tinyint | 否 | NULL | 区分移出来源 | 取值 1 / 2；仅移出时写 | 移出、主动退出 |
| removed_by | 移出人 | bigint | 否 | NULL | 操作人或本人账号ID | 外键 | 移出、主动退出 |
| removed_at | 移出时间 | datetime | 否 | NULL | 非空表示已移出 | — | 移出、主动退出 |
| created_by | 创建人 | bigint | 是 | 无 | 操作人账号ID | 外键 | 新建、关联 |
| created_at | 创建时间 | datetime | 是 | 当前时间 | — | 不可改 | 新建、关联 |
| updated_by | 更新人 | bigint | 是 | 无 | 最近一次操作人账号ID | 外键 | 新建、每次更新 |
| updated_at | 更新时间 | datetime | 是 | 当前时间 | — | 每次写操作刷新 | 新建、每次更新 |
| version | 版本号 | int | 是 | 0 | 乐观锁 | 每次更新加 1 | 新建、每次更新 |

**唯一索引**

| 索引名 | 字段 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| uk_tenant_member_effective | (tenant_id, account_id) | 唯一（生效范围） | 生效范围为 status 为 1 / 2，同账号同租户只保留 1 条生效关系；已移出行保留，重新加入另起新行 |
| idx_member_tenant_status | (tenant_id, status) | 普通 | 成员列表按租户与状态筛选、成员数用量实时统计 |
| idx_member_account | (account_id) | 普通 | 反查账号参加了哪些租户，供登录选租户与个人设置使用 |
| idx_member_dept | (tenant_id, dept_id) | 普通 | 按部门查成员，供数据范围计算使用 |

**外键**

| 字段 | 指向 | 约束 |
| :--- | :--- | :--- |
| tenant_id | tenant.id | 不可空；租户物理删除时本表记录保留（租户管理 PRD D03） |
| account_id | account.id | 不可空 |
| dept_id | 部门表 id（部门管理，本清单不覆盖） | 可空；部门删除时由部门模块联动处置 |
| created_by / updated_by / removed_by | account.id | removed_by 可空 |

**状态枚举取值（status）**

| 值 | 名称 | 含义 | 可登录本租户 |
| :---: | :--- | :--- | :---: |
| 1 | 正常 | 放行本租户登录 | 是 |
| 2 | 已禁用 | 拦截本租户登录，会话即时失效，可恢复 | 否 |
| 3 | 已移出 | 终态，不可登录本租户，记录保留；常规 UI 不提供操作（隐藏的高权限终态） | 否 |

**加入方式枚举取值（joined_via）**

| 值 | 名称 | 说明 |
| :---: | :--- | :--- |
| 1 | 手工新建 | 租户管理员在成员管理新建，建账号 |
| 2 | 关联已有账号 | 手机号命中已有账号，不建号不设密码 |

> 「关联已有账号（值 2）」本期不实现，当前 `joined_via` 只会出现 1（手工新建）。

**移出方式枚举取值（removed_type）**

| 值 | 名称 | 说明 |
| :---: | :--- | :--- |
| 1 | 管理员移出 | 离职场景，租户管理员操作 |
| 2 | 本人主动退出 | 成员在个人设置发起 |

> 「管理员移出（值 1）」本期不实现（移出收敛为隐藏的高权限终态）；「本人主动退出（值 2）」入口在个人设置模块（后续覆盖）。

**软删字段**

| 项 | 内容 |
| :--- | :--- |
| 是否有软删字段 | 无 |
| 说明 | 移出以 status = 3 表达，记录长期保留供审计与责任人追溯（用户体系 PRD §5.5.1-9、§5.5.1-12），不做逻辑删除也不做物理删除 |

**关联配置（不在本表）**

| 配置项 | 归属 | 作用 |
| :--- | :--- | :--- |
| 成员数上限 | tenant.member_limit（租户管理字段清单） | 新增成员闸门，用量由本表实时统计 |
| 主管理员身份 | tenant_admin_relation（租户管理字段清单） | 识别主管理员，决定禁用、移出、退出的保护拦截 |
| 邮箱 email | account.email（平台账号字段清单） | 选填账号级字段，编辑态维护、新建态不收集，平台账号同步可见 |
| 密码复杂度、锁定阈值 | 系统参数 | 作用于 account 表登录校验 |

## 2. 表间关系

```text
tenant（租户，租户管理字段清单覆盖）
  ├─ 1:N ─ tenant_member（成员关系，本清单 §1）
  │            ├─ 被 role_member 引用（member_type = 2，角色管理字段清单覆盖）
  │            └─ 与 tenant_admin_relation 配对识别主管理员（租户管理字段清单覆盖）
  └─ member_limit 作为新增成员闸门，用量由 tenant_member 实时统计

account（账号，平台账号字段清单覆盖）
  └─ 1:N ─ tenant_member（一个账号可挂多个租户成员关系）
```

关键约束：

1. 账号只有一份，成员关系是「账号 × 租户」的一行记录，不复制账号、不存凭证。
2. 成员状态只作用本租户；账号级登录闸门在 account.status，两者叠加才放行登录。
3. 主管理员不在 tenant_member 建标记字段，按 tenant_admin_relation 生效记录派生，避免双写不一致。
4. 角色绑定不建表，走 role_member（member_type = 2 指向 tenant_member.id）；移出时置 revoked_at，记录保留。
5. 已移出的成员关系行保留，不参与 (tenant_id, account_id) 生效唯一约束，支持同账号再次加入另起新行。
6. 成员数用量 = tenant_member 中 status 为 1 / 2 且 account.status 不为注销的行数实时统计（口径与租户管理 PRD D12 一致）。
7. 租户物理删除时 tenant_member 记录保留，成员关系随之不可登录（账号与成员关系保留为租户管理 PRD D03 决议）。

## 3. 设计决策

| 编号 | 事项 | 决议 | 落点 |
| :--- | :--- | :--- | :--- |
| D01 | 成员表形态 | 建「账号 × 租户」关系表，不建成员账号副本，不存登录凭证 | §0、§1 |
| D02 | 主管理员落点 | 不在本表建 is_primary 字段，按 tenant_admin_relation 生效记录派生，避免与租户管理双写 | §0 推论 4、§2 关键约束 3 |
| D03 | 成员唯一性 | (tenant_id, account_id) 生效范围唯一；已移出行保留且不阻止再次加入 | §1 唯一索引 |
| D04 | 状态表达 | 正常 / 已禁用 / 已移出三值，移出为终态但不删行，不用软删字段 | §1 status |
| D05 | 密码重置记录 | 复用 platform_password_reset_log，新增 reset_type = 3（租户管理员重置）；建号随机密码沿用 reset_type = 2；自填密码不写重置记录 | §4 T01 |
| D06 | 加入与移出来源 | 建 joined_via 与 removed_type 两个来源枚举，区分新建 / 关联与管理员移出 / 主动退出 | §1 |
| D07 | 部门字段 | dept_id 可空，为空按仅本人；不建部门历史表，调岗历史由审计日志留存 | §1 |
| D08 | 表名 | 用 tenant_member，承载账号在租户上的成员关系 | §1 |
