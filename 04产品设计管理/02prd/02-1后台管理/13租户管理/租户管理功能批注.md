## 1. 拟添加的批注清单

### 1.1 整体流程

#### B11-01 平台侧整体流程
**拟标注位置**：功能标题「租户管理」附近（全局说明）
**标记**：已确认

**批注内容**

- **适用场景**：平台侧持「租户管理」功能码的角色维护租户全生命周期：开户 → 配模块授权 → 指定主管理员 → 停用 / 启用 / 删除。
- **主流程**：进入租户管理 → 列表查询定位租户 → 新建开户（填「租户信息」+「其他」两段）→ 建后于详情页配置模块授权 → 日常维护（编辑、停用启用、调整上限、进入租户）→ 退租时先停用再删除。
- **开户闭环（系统自动，无独立按钮）**：保存成功即置「启用」并生成租户编号；同时自动完成三件事 —— 初始化本租户组织架构根组织（名称 = 租户名称，不可删除、可改名）、建立主管理员成员记录、在租户内自动创建内置角色「租户管理员」并分配给主管理员（默认勾选租户端全部功能点、数据范围读写均「全部」）。
- **分支**：主管理员有两种来源（选择已有登录账号 / 现场新建账号，见 B11-26）；编辑页可发起「指定 / 更换主管理员」；删除仅在停用状态可用。
- **结束**：删除为物理删除、不可恢复；其余操作保存后立即生效并写审计。全程无提交 / 审核 / 驳回节点。

#### B11-02 租户端「租户信息」整体流程
**拟标注位置**：租户端「租户信息」功能标题附近（全局说明）
**标记**：已确认

**批注内容**

- **适用场景**：租户成员在「系统管理 → 租户信息」维护本单位档案；不设「单位信息维护」功能点，可编辑性只由租户状态决定（C-03 已确认）。
- **流程**：首次登录且有待完善项时弹出引导 → 进入「系统管理 → 租户信息」→ 页面分三区块：法定资质信息（只读）、日常联络展示信息（可编辑）、业务属性信息（可编辑）→ 编辑区块二 / 区块三 → 点【保存修改】→ 立即生效并写一条操作审计。
- **结束**：保存即生效，无审批流；档案未完善不阻断登录与业务，只在完整度条与待完善清单提示。

### 1.2 全局规则说明

#### B11-03 全局规则（平台侧）
**拟标注位置**：功能标题「租户管理」附近（与 B11-01 同一全局说明入口）
**标记**：已确认（权限颗粒度为待确认，见 §4 C-08）

**批注内容**

1. **三段式**：租户 = 租户信息（主档统一字段 + 授权与配额 + 主管理员）+ 其他（按类型的扩展档案）+ 模块授权；类型差异全部收敛到「其他」段，新增类型只加字段定义、不改租户信息段。
2. **主档统一字段**：名称、类型、联系人（非必填）、有效期（非必填）；成员数上限归「授权与配额」；租户编号系统生成、创建后不可改。
3. **主体标识**：企业以统一社会信用代码（18 位）全平台唯一；政府单位以机关编码必填；机构 / 园区不设统一编码主档字段（按 A2 裁决，字段口径见 B11-27）。
4. **删除**：物理删除、无冷静期、无双人复核；仅停用状态可删；须输入租户当前全名精确匹配。
5. **状态闸门**：停用即全员掉线、数据冻结、拒绝登录与写操作；启用恢复登录，不启用此前单独停用的成员。
6. **角色隔离**：平台角色只授予平台人员，租户角色只在租户内生效；开户自动创建的「租户管理员」是租户权限起点，平台不代租户做岗位拆分。
7. **审计**：所有写操作写审计（只增不改不删）；状态变更与操作审计在详情页「操作记录」合并展示。
8. **权限**：菜单与按钮是否按角色细分可见性，原型未做任何限制 → **待确认**（见 §4 C-08）。

#### B11-04 扩展档案字段归属与租户可编辑性
**拟标注位置**：新建 / 编辑页「其他」段头、详情页「其他」段头（两处引用 B11-04）
**标记**：已确认（按 A3 / A4 裁决，以原型字段集与归属为准）

**批注内容**

- **字段集按类型**：企业 / 政府单位 / 机构 / 园区各一套预置字段（见 B11-27）；本期不提供页面增删字段（C-02 已确认不做），调整字段需改数据或代码。
- **归属三档（`editable_scope`）**：`platform` = 平台独占，纳入开户必填校验，租户端只读；`both` = 双方可维护；`tenant` = 租户自维护，不纳入开户必填。缺省 `tenant`；**当前预置字段集中无纯 `tenant` 档字段**。
- **租户可编辑性（`tenant_editable`）**：决定租户端「租户信息」把字段渲染成输入框（白底）还是只读文本（灰底）；`platform` 档一律只读；监管准入与区划归属类（园区地理位置区划、行政归属区划）亦只读。
- **平台侧口径**：开户表单只强校验 `platform` / `both` 档必填项；`tenant` 档必填字段的缺口在租户端以待完善清单呈现，不阻断开户。

### 1.3 业务状态说明

#### B11-05 租户状态与操作矩阵
**拟标注位置**：列表「状态」列旁、详情页状态标签旁
**标记**：已确认

**批注内容**

- **取值**：租户只有「启用 / 停用」两个状态；「已过期」不是状态，只是有效期的展示态（见 B11-06）。
- **操作矩阵**：

| 状态 | 编辑 | 调整上限 | 停用 | 启用 | 删除 | 模块授权 | 指定 / 更换主管理员 | 进入租户 | 成员可登录 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 启用 | 是 | 是 | 是 | — | — | 是 | 是 | 是 | 是 |
| 停用 | 是 | 是 | — | 是 | 是 | 是 | 是 | 是 | 否 |

- **进入条件**：新建保存后即为「启用」；「停用」由启用态经二次确认进入；「启用」由停用态经二次确认进入。
- **停用影响**：该租户全部会话立即失效、拒绝登录、拒绝一切写操作，数据保留；恢复后不启用此前被单独停用的成员。
- **删除前置**：须先停用；启用态在列表「更多」内删除入口置灰，提示「请先停用后再删除」。

#### B11-06 有效期展示态
**拟标注位置**：列表「有效期」列旁、详情页「有效期」行旁
**标记**：已确认（「今天」为演示固定值）

**批注内容**

- **展示态与判定**：起止均为空 = 长期有效；当前日期在区间内 = 有效期内；结束日在 30 天内 = 即将到期；已过结束日 = 已过期。
- **规则**：起止均非必填，结束日期不得早于开始日期；到期只提示，不自动停用、不自动拒绝登录、不自动续期。
- **原型表现（待核对）**：原型以固定「今天 = 2026-10-22」计算展示态，正式实现取服务器当前日期。

### 1.4 操作功能及对应业务规则

#### B11-07 列表与查询
**拟标注位置**：列表查询区、工具条与表格区域
**标记**：已确认（搜索按钮行为为原型已表现·待核对）

**批注内容**

- **查询项**：① 租户名称 / 租户编号 —— 名称按包含关系匹配，编号忽略大小写按包含匹配；② 租户类型 —— 企业 / 政府单位 / 机构 / 园区；③ 租户状态 —— 启用 / 停用。三个条件叠加生效，任一条件变化即回到第 1 页；「重置」清空全部条件。
- **展示列**：租户名称（点击进详情）、类型、状态、有效期（展示态标签）、创建时间、操作。
- **工具条**：显示当前范围「共 N 条 · 启用 N 条」与删除风险提示（删除须二次确认并输入全名、物理删除不可恢复）。
- **排序与分页**：启用状态在前，其余按更新时间倒序；每页 20 条。
- **操作列**：「查看 / 编辑 / 授权 / 停用（启用）」直接显示；「调整上限 / 进入租户 / 删除」收入「更多」下拉；启用态「更多」内删除置灰提示「请先停用后再删除」。
- **搜索按钮（待核对）**：原型中筛选为即时生效，「搜索」按钮暂无额外动作。需确认正式需求为「点击后查询」，或保留「即时筛选 + 按钮共存」。

#### B11-08 新建租户（开户）
**拟标注位置**：页头「新建」按钮、新建页「租户信息」段
**标记**：已确认

**批注内容**

- **入口**：列表页头「新建」，进入独立内容页 `/system/tenant/new`（不用弹窗）。
- **表单两段**：「租户信息」（主档统一字段 + 成员数上限 + 主管理员）与「其他」（按类型渲染的扩展字段）。
- **主档校验**：名称必填、长度 1～100；类型四选一（创建后不可改）；联系人姓名与手机号成对填写、手机号 11 位；有效期结束不早于开始；成员数上限取 1～1000 整数（默认 1000）。
- **「其他」段校验**：按所选类型加载启用字段；`platform` / `both` 档必填项未填即阻断保存并定位到字段；企业统一社会信用代码须为 18 位大写字母与数字；文本不超最大长度、数字可解析。
- **类型联动**：切换类型后重新加载该类型字段集，清空类型专属字段值、保留公共字段值。
- **主管理员（开户必填）**：来源二选一 —— 「选择已有登录账号」或「新建管理员账号」，规则见 B11-26；未指定阻断保存。
- **保存后系统动作**：生成租户编号（不在表单内）、置启用、写主档与扩展档案值、写状态变更记录与审计；自动建组织架构根组织、建成员记录、自动创建「租户管理员」角色并分配；现场新建账号时弹窗一次性展示初始密码（关闭不可再查、首次登录强制改密）。
- **模块授权**：开户不配置，建后于详情页配置（默认不勾选任何模块）。

#### B11-09 编辑租户
**拟标注位置**：列表「编辑」、详情页「编辑」、编辑页两段
**标记**：已确认

**批注内容**

- **入口**：列表操作列「编辑」或详情页「编辑」，进入 `/system/tenant/:id/edit`，带出现有值。
- **可改范围**：租户名称、联系人、有效期、成员数上限、「其他」段（`platform` / `both` 档字段）。
- **不可改**：租户类型（创建后不可改，表单置灰）、租户编号、状态（经停用 / 启用操作变更）；主管理员不在本页直接修改，通过页内「更换主管理员」操作发起（见 B11-17）。
- **校验与保存**：与新建一致；保存成功写审计（记变更字段前后值）并返回详情页。
- **主体标识变更（C-09 已确认并实现）**：企业统一社会信用代码发生变更时，保存前弹出「确认变更主体标识」二次确认，提示将影响对外报告与合同核对；确认后才写入并记审计，取消则保留原值、不保存。

#### B11-10 租户详情
**拟标注位置**：详情页各卡片
**标记**：已确认

**批注内容**

- **结构（六块）**：基本信息、其他（扩展档案只读复核）、模块授权、主管理员、成员与用量、操作记录。
- **基本信息**：租户名称、租户编号、租户类型、联系人（未填显示「未填（非必填）」）、有效期（起止 + 展示态）、成员数上限（含当前用量，用量含停用与已移出；达上限提示禁新增）、启用成员数、创建人 / 时间、更新人 / 时间。
- **其他**：按租户类型渲染扩展档案值（省市区 / 布尔 / 单选 / 多选做本地化展示，未填显示「未填」），只读；段头「编辑」跳转编辑页。字段由平台配置，租户可在租户端「租户信息」自行维护其业务属性字段，此处只读复核。
- **模块授权**：以标签展示已授权模块；用户体系为能力底座默认全开、不进本列表；取消授权后功能点下次请求即失效，重新授权后原勾选自动恢复。
- **主管理员**：在任主管理员（姓名 + 手机号）与账号标识、指定 / 更换入口、历史关系表（账号、关系状态、卸任去向、指定人 / 时间、卸任时间）；主管理员是成员标记不是角色，每租户同时仅 1 条生效关系，历史记录保留供追溯。
- **成员与用量**：只读引用（姓名 / 手机号 / 部门 / 角色 / 成员状态）；成员维护归租户端成员管理，本页不提供成员操作。
- **操作记录**：状态变更（新建 / 停用 / 启用，记前后状态与原因备注）与操作审计（字段前后值、操作人、时间）按时间倒序合并展示；审计只增不改不删；删除不写状态变更表、仅留审计。
- **顶部操作**：返回列表、编辑、调整上限、模块授权、进入租户、停用 / 启用、删除，按 B11-05 矩阵显隐。

#### B11-11 停用租户
**拟标注位置**：列表「停用」、详情页「停用」、确认弹窗
**标记**：已确认

**批注内容**

- **可操作条件**：仅启用状态可发起；停用状态不出现入口。
- **确认弹窗**：标题「确认停用」；正文说明停用即全员掉线、数据冻结（会话立即失效、拒绝登录与一切写操作、数据保留）；展示「N 名成员将全部掉线」影响提示；须勾选「已知悉」闸门方可提交。
- **结果**：置停用、写状态变更记录与审计，列表与详情刷新。

#### B11-12 启用租户
**拟标注位置**：列表「启用」、详情页「启用」、确认弹窗
**标记**：已确认

**批注内容**

- **可操作条件**：仅停用状态可发起。
- **确认弹窗**：标题「确认启用」；正文说明恢复登录能力、不启用此前单独停用的成员；展示「恢复后 N 名成员可登录」（按启用成员数统计）。
- **结果**：置启用、写状态变更记录与审计。

#### B11-13 删除租户（真删）
**拟标注位置**：列表「更多 → 删除」、详情页「删除」、确认弹窗
**标记**：已确认（级联清理范围为待确认，见 §4 C-05）

**批注内容**

- **前置**：仅停用状态可删；启用态入口置灰提示先停用。
- **闸门**：文本提示物理删除不可恢复、无冷静期；须输入租户当前全名，与实时名称精确一致才可提交；无双人复核。
- **清理范围（弹窗明示）**：租户记录、模块授权、全部状态变更记录；账号记录与成员关系记录保留，该租户成员的登录立即失效。
- **结果**：物理删除后列表不再出现；删除事件由审计长期留存（不写状态变更表）。

#### B11-14 模块授权
**拟标注位置**：列表「授权」、详情页「模块授权」、授权弹窗
**标记**：已确认

- **取消确认**：取消已开通模块须二次确认，提示「约 N 名成员的可用功能将失效」并勾选「已知悉」；影响人数按启用成员中持覆盖该模块角色的人数统计。
- **生效口径**：取消后功能点对下次请求即失效、菜单不渲染；租户已有角色的功能点勾选原样保留，重新授权后自动恢复。

#### B11-15 调整成员数上限

- **用量口径**：当前用量含主管理员、停用与已移出成员；已达上限时禁止新增成员。

#### B11-16 进入租户
**拟标注位置**：列表「更多 → 进入租户」、详情页「进入租户」、弹窗
**标记**：已确认

**批注内容**

- **资格与范围**：平台侧持「租户管理」功能码的角色发起；**原因必填**；启用与停用状态均可进入（停用期只读排查是主要场景）。
- **约束**：进入后顶部常驻横幅，业务数据只读、写操作全禁（前端禁用 + 接口拒绝）；只读覆盖业务数据、扩展档案与组织树。
- **审计**：进入与退出均写平台审计并同步写租户侧，客户可查。
- **定位**：排障 / 代核查通道，不能替代租户管理员的日常操作；与「切换租户」是两件事（本期单租户，不提供切换）。

#### B11-17 指定 / 更换主管理员
**拟标注位置**：详情页「主管理员」卡片、编辑页「更换主管理员」、弹窗
**标记**：已确认（原账号去向三选一为原型口径，PRD 待同步 S-06）

**批注内容**

- **性质**：主管理员是成员标记、不是角色；每租户同时仅 1 条生效关系，历史记录保留供追溯。
- **入口**：无在任主管理员时进入「指定」模式（按钮显示「指定主管理员」）；有在任时进入「更换」模式（按钮显示「更换主管理员」）。
- **接任者资格**：租户自有账号（平台账号不得兼任，否则绕过「进入租户」的只读与审计）、启用状态、非现任、未绑定其他租户（单租户模式：一个账号只能绑定一个租户）；非本租户成员的账号接任时自动建立成员记录，并受成员数上限约束（名额满则拒绝）。
- **原账号去向（三选一）**：降级为普通成员（收回「租户管理员」角色，保留成员身份，须至少保留 1 个其他角色）/ 禁用（收回角色，并停用该成员登录）/ 移出租户（收回角色，成员关系置「已移出」，账号不再属于本租户）。
- **角色接力**：接任者自动获得「租户管理员」角色与全部功能权限；租户内无该角色时先创建（口径与开户一致）。
- **结果**：原账号立即失权、刷新会话；写审计。

#### B11-18 租户端「租户信息」自助维护
**拟标注位置**：租户端「租户信息」页三区块与【保存修改】
**标记**：已确认

**批注内容**

- **三区块**：
  - 区块一 · 法定资质信息：主档身份（租户编号、租户名称、类型、状态、有效期、主管理员）+ `tenant_editable = 0` 的扩展字段，纯只读（灰底），提示「如需修改请联系平台」，不提供任何申请 / 编辑入口；
  - 区块二 · 日常联络展示信息：联络人姓名、联络电话，白底可编辑，成对填写、11 位手机号；
  - 区块三 · 业务属性信息：按租户类型渲染的 `tenant_editable = 1` 字段，白底可编辑。
- **保存**：区块二 / 区块三共用页面级【保存修改】；校验通过即按 `(租户ID, 字段编码)` 覆盖写入、立即生效，无审批；无变化时提示「暂无修改」；【重置】还原为已保存值。
- **校验**：长度 / 数值 / 选项合法；联络人姓名与电话成对、11 位；可自编辑必填字段为空时允许保存，但待完善清单继续提示（不硬阻断）。
- **留痕**：有实际变化时写**一条**租户侧操作审计（记变更字段前后值、提交人、时间），平台可在详情页「操作记录」查看；法定资质类字段不出现在审计明细中。
- **不做报告级联（C-04 已确认）**：报告引用的是「企业信息维护」的报告主体库，不是本页档案，因此本页保存不触发报告「待更新」。
- **只读情形**：租户停用期间整页只读（数据冻结，恢复后可继续维护）；可编辑性只由租户状态决定，不设「单位信息维护」功能点（C-03 已确认）。

#### B11-26 主管理员（来源、资格与角色初始化）
**拟标注位置**：新建页「主管理员来源 / 账号」区、编辑页「主管理员账号」区、详情「主管理员」卡片
**标记**：已确认（按 A1 裁决，以原型为准）

**批注内容**

- **开户必填**：未指定主管理员阻断保存（无主管理员则租户没有权限起点）。
- **来源二选一**：
  - **选择已有登录账号**：候选为**租户自有账号**（无平台角色）、启用状态、未绑定其他租户；平台账号不得兼任（否则等于绕过「进入租户」的只读与审计）；
  - **新建管理员账号**：填登录名（不区分大小写判重、不得为 11 位纯数字）、姓名、手机号（11 位、全局唯一）、邮箱（非必填）与初始密码（系统随机生成 8 位大小写字母 + 数字，或自定义 8～20 位且同时包含字母和数字）；开户成功弹窗一次性展示密码，关闭后不可再查，首次登录强制改密。
- **兼任上限**：单租户模式下，一个账号只能绑定一个租户（本期无选租户切换）。
- **角色初始化（系统自动，无按钮）**：开户 / 指定 / 更换时，在租户内自动创建内置角色「租户管理员」并分配给主管理员 —— 默认勾选租户端全部功能点（**不按租户类型过滤**）、数据范围读写均「全部」；该角色为租户内置保护角色：不可删除、不可停用，可复制、可由租户管理员收窄；实际生效范围仍受模块授权约束（有效功能 = 已开通模块内功能点 ∩ 角色勾选功能点）。
- **角色隔离**：主管理员的租户权限只来自租户角色；平台侧不接受把平台角色分配给租户成员，也不接受把租户角色分配给平台账号。
