## 0.1 字段真相源收敛结论（前置阻塞项，分歧 0）

**背景**：`04产品设计管理/02prd/02-1后台管理/08计算引擎配置/计算引擎配置字段清单.md`（V1.0 定稿）的 **§3 / §4 已定义「核算模型」与「模型公式绑定」字段**，且已按原型落地（`/model/list`）。同一对象若两处定义，将违反「字段清单是唯一真相源」。

**结论（采纳口径 A；Q00 已决策为"暂缓修订 08"）**：

| 项 | 结论 |
| :--- | :--- |
| **模型主对象字段归属** | **本清单**（模型编码 / 名称 / 核算边界 / 使用状态 / 适用行业 / 标准依据 / 因子开关 / 说明 / 制单信息） |
| **模型公式绑定子表字段归属** | **本清单**（引用公式 / 绑定对象类型 / 绑定对象编码 / 绑定对象名称 / 是否默认 / 排序号 / 备注） |
| **《计算引擎配置字段清单》的处置** | **本次不修订（P4）**：其 §1 / §2（计算公式 + 数据因素）继续有效；其 §3 / §4（核算模型 + 公式绑定）视为**现状快照**，**待后续回改**为指向本清单 |
| **过渡口径（关键）** | 在 08 完成回改前，**冲突时以本清单为准**；08 §3 / §4 仅作原型实现记录，新增字段不在 08 补充 |
| **理由** | 字段清单唯一真相源须与**模块归属一致**：模型是 A2-3 ~ A2-5 的物主；08 的主责应是「**计算公式**」（P1 的落地物） |
| **偏离登记** | 待 08 回改时，在**方案附录二**登记「核算模型字段真相源迁移（08 → 10模型管理）」 |

**可用性口径（分歧 2 结论 / P3）**

```text
唯一键 = 模型编码（不做版本化）

停用（默认）──启用──► 启用（冻结：不可编辑 / 不可删 / 绑定锁定；可被项目引用）
    ▲                    │
    └──────停用──────────┘  （下架：不可被新项目引用；可重新编辑）

编辑 / 删除 / 维护绑定：仅「停用」状态允许
追溯：模型为【模板】，项目引用时【复制快照】；模型后续改动【回写快照】，
      历史项目永远还原引用当时的配置（方案 §4.9 【口径 2 · 模板 + 引用即复制】）
```

> **偏离声明（须在方案附录二登记）**：方案 §4.9 将**核算模型**列入**口径 1（版本化 + 发布 + 不可变）**；本清单按业务决策 **P3** 改为 **口径 2（模板 + 引用即复制）**，与「工序 / 工艺流程」同口径。§4.9 的「禁止实时引用最新版本」原则**未被违反**——口径 2 仍是"引用后冻结"，只是追溯由**副本**而非"版本不可变"保证（§4.9 原文已说明该实现方式）。

## 1.7 产品总碳排放公式（**模型内表达式**，P19）

### 1.7.1 形态

```text
产品总碳排放公式 *                        [点击配置]
种植与培育+原材料获取+生产+运输与交付+使用+生命周期末期
```

- **默认只读展示**「各**末级**阶段核算结果累计和」（受控表达式）；点「点击配置」进**计算器式编辑器**；
- **汇总口径 = 最末级生命周期阶段**（其下不再有子阶段的阶段）；**父阶段不参与**（天然避免重复计算）；
- **计算公式不能为空** → 否则阻断启用；至少需含 **1 个末级阶段因素**；
- **不引用公式库**：因素是「**阶段核算结果**」（引擎按阶段汇总后代入）；
- 减碳扣减项以 `-` 表达（如 `-回收信用`）。

> **界面位置（P20）**：位于「工序与公式」步的**右栏**；左栏为**生命周期树形结构**（阶段 → 工序 → 排放项）。

### 1.7.2 公式编辑器（**计算器式**，对齐竞品）

```text
├─────────────────────────────┬─────────────────────────────┤
│  1  2  3  ⊕                 │ 可用的数据因素               │
│  4  5  6  ⊖                 │ [种植与培育] [原材料获取]      │
│  7  8  9  ⊗                 │ [生产] [运输与交付] [使用]     │
│  .  0  %  ⊘                 │ [生命周期末期] [生产过程] …    │
│  (  )  [  ]                 │                             │
├─────────────────────────────┴─────────────────────────────┤
│ [清空] [删除] [撤销]                          [取消] [确定] │
└───────────────────────────────────────────────────────────┘
```

| 区域 | 说明 |
| :--- | :--- |
| **表达式显示区** | 只读展示当前表达式；为空时提示「（空）」 |
| **计算器键盘** | 受控字符（与 08「计算公式」同一套）：`1-9 0 . % ( ) [ ]` + 运算符 `+ - * /`（运算符渲染为大圆按钮） |

| **恢复默认** | 回到「全部一级阶段相加」（开关联动见 §1.7.3） |

### 1.7.3 公式项子表（D35）

> **落库的是「表达式」**（字符串），不落"项行"；下表的"项"是表达式的解析结果，用于反查与校验。

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| 所属模型 | 引用 | 主表 |
| 公式表达式 | 文本 | 受控表达式（数字 + 运算符 + 阶段因素名） |
| 引用阶段数 | 数值（只读反查） | 表达式中命中的模型内阶段数 |

**约束**：① **表达式不能为空**（对齐竞品「计算公式不能为空」）；② 至少包含 **1 个阶段因素**；③ **父阶段与其子阶段不可同时出现在表达式中**（会重复计算）—— 冲突因素在**编辑器内置灰**，点击时给出原因提示；④ 阶段被移除 / 未加入模型时，其因素不再出现在「可用的数据因素」中。

## 5. 枚举值

### 5.1 使用状态

| 枚举值 | 含义 | 是否默认 | 备注 |
| :--- | :--- | :---: | :--- |
| 停用 | 未启用 / 已下架，**不可被新项目引用** | 是（新增默认） | **仅此状态可编辑、可删、可维护公式绑定**（D02 / D13）；可随时切换为「启用」 |
| 启用 | 生效，**可被项目引用** | 否 | **启用即冻结**；已引用项目的历史快照保留；下架需先「停用」 |

> **双态可逆**：启用 ⇄ 停用 双向可达，无终态。启用 / 停用**不影响已建项目的快照**（§4.9 口径 2）。

### 5.2 核算边界

| 枚举值 | 含义 | 是否默认 | 备注 |
| :--- | :--- | :---: | :--- |
| 摇篮到大门 | Cradle-to-Gate | 是 | 原型 `gate` |
| 摇篮到坟墓 | Cradle-to-Grave | 否 | 原型 `grave`；§4.3.1 定义"可扩展"，本期仅两值 |

### 5.3 开关类（**已全部移除**）

> **模型侧不再有任何因子规定开关**（P27）。原「生物碳固碳开关 / 是否允许手工指定因子 / 区域与年度口径」均已删除；
> 因子匹配规则与优先级仍由系统内置、随模型冻结、只读展示。

### 5.4 区域与年度口径（**已从模型移除**）

> **口径固定为「按项目核算周期年度取因子」**（原默认值），模型侧不再声明该字段；
> 「区域」取值引用数据字典（§C4 / C3），缺失时按「全国」兜底。
> 如后续确需「取最近年度 / 严格匹配」等历史追溯口径，作为**系统参数**提供，不进模型（避免增加建模负担）。

### 5.5 公式作用对象（**仅两处**，P20）

| 对象 | 含义 | 本期 | 备注 |
| :--- | :--- | :---: | :--- |
| **排放项（投入项 / 产出项）** | 一个投入产出物 = **1 条公式** | ✅ 开放 | 由**系统按映射表默认带出**（P17）；用户可覆盖 / 恢复默认；**每项至多 1 条** |
| **产品总碳排放公式** | 按**最末级阶段**汇总（`Σ 末级阶段结果`，可含减项） | ✅ 开放 | **模型内受控表达式**（P19 / P20）：默认只读展示 + 「点击配置」；**不能为空**、**启用前置条件**（D32 / D35） |
| 生命周期阶段 / 核算工序 | **系统自动汇总** | — | **不绑定公式**（**已取消「阶段默认公式」「工序默认公式」**，D36） |
| ~~模型公式绑定子表~~ | — | ❌ **废弃** | 阶段 / 工序不再有绑定行；`modelBindingSeed` 已清空（P20） |

**汇总关系（引擎自动，不写公式）**：**工序 = Σ 排放项结果**；**阶段 = Σ 其下工序结果**；产品总碳足迹 = 产品总公式。

> **兜底链已取消**：排放项未指定公式（且非「不计入」）→ **阻断启用**（D34），不再有"工序 / 阶段默认公式"兜底。

**产品总公式新增因素来源（归 08，待回改时同步）**：`阶段核算结果` —— 引用模型内阶段，由引擎汇总该阶段排放后代入（当前 08 仅有 活动数据 / 自定义变量 / 业务库取值 / 常量 四类）。

### 5.6 数据来源

**本模块不设「数据来源」字段**（模型仅平台级，见 §1.5 分歧 8）；若有需要，其口径须与基础库 / 因子库统一（**系统预置 / 组织自建**），且**可见性由它推导、不单独设字段**。
