## 1. 拟添加的批注清单

### 1.1 整体流程

#### CM-01 模型维护整体流程
**拟标注位置**：功能标题「模型管理」附近（全局说明）｜**标记**：已确认

- **适用场景**：在后台维护可复用的核算模型模板（目标与范围 + 产品建模），发布后前台「模型库」可见，可供新建核算项目直接引用。
- **流程**：进入模型管理 → 按名称 / 编码、状态查询定位 → 点击名称进入只读详情 → 对草稿 / 已停用模型编辑 / 删除，或发布 / 停用 / 重新启用 → 需要时「新建模型」走两步向导。
- **分支**：查看 / 编辑均复用两步向导（只读 / 可编辑态）；删除经二次确认后立即生效、列表刷新。
- **结束**：保存后立即生效并刷新列表。已发布模型需先停用才能编辑。

### 1.2 全局规则说明

#### CM-02 全局规则
**拟标注位置**：功能标题「模型管理」附近（与整体流程同一全局说明入口）｜**标记**：已确认

1. **平台级模板**：本页维护平台级核算模型；发布后前台「模型库」可见、可被引用；与「我的模型」（组织级）是两套入口、同一向导 UI。
2. **两步结构**：目标与范围（模型名称 / 编码 / 维护人 / 核算标准 / 系统边界 / 生命周期阶段 / 产品信息）+ 产品建模（数据项与过程节点）。
3. **模型编码**：系统生成、全局唯一、不可修改；作为模型副标识。
4. **发布机制**：平台模式下第 2 步额外提供「保存并发布」；仅「保存」落库为草稿。
5. **删除限制**：仅草稿 / 已停用可删除；已发布需先停用。
6. **变更不追溯**：编辑为直接覆盖，不影响已引用该模型的核算项目。

### 1.3 业务状态说明

#### CM-03 模型状态
**拟标注位置**：清单「状态」列旁｜**标记**：已确认

- **状态**：草稿 / 已发布 / 已停用。草稿 = 后台可见可编辑；已发布 = 前台模型库可见、需先停用才能编辑；已停用 = 前台不可见、可重新启用或删除。
- **状态机**：草稿 → 已发布 → 已停用 → 重新启用；删除仅限草稿 / 已停用。
- **对下游影响**：停用后前台不再展示，已引用该模型的项目不受影响。

### 1.4 操作功能及对应业务规则

#### CM-04 列表查询与重置
**拟标注位置**：查询区｜**标记**：已确认

- 查询项：模型名称 / 编码（模糊）、状态（单选）。两个条件叠加过滤；条件变化后回到第 1 页。「重置」清空全部条件。
- 列表列：模型编码（第一列）、模型名称（链接）、产品分类、系统边界、状态、版本、创建时间、更新时间、操作。

#### CM-05 列表操作（发布 / 停用 / 启用 / 删除）
**拟标注位置**：操作列｜**标记**：已确认

- 查看：任何状态可见（进入只读详情）。
- 编辑 / 发布 / 删除：仅非「已发布」状态可见；「已发布」时改为「停用」；已停用状态的「发布」显示为「重新启用」。
- 发布 / 停用为二次确认；删除仅限草稿 / 已停用，二次确认「删除后不可恢复」。

#### CM-06 详情页（只读）与操作
**拟标注位置**：详情标题 / 操作区｜**标记**：已确认

- 复用两步向导只读态，展示目标与范围 + 产品建模。
- 非「已发布」：编辑 / 发布（或重新启用）/ 删除；「已发布」：仅「停用」。已发布模型不可直接编辑，详情页若尝试编辑会拦截并提示先停用。

#### CM-07 新建模型（两步向导）
**拟标注位置**：右上角「新建模型」｜**标记**：已确认

- 编辑草稿 / 已停用模型进入同一向导可编辑态。
- 第 1 步「目标与范围」：模型名称、核算标准、行业标签、备注、产品名称 / 规格 / 分类 / 行业、声明单位、产品图片、系统边界、生命周期阶段。
- 第 2 步「产品建模」：在生命周期阶段下配置数据项与过程节点（与 PCF 步骤②同款：左树右表）。顶部步骤条展示当前步，已完成步可回看。
- 平台模式第 2 步额外提供「保存并发布」。

### 1.5 字段级说明

#### CM-08 字段：模型名称 / 模型编码
**拟标注位置**：模型名称 / 列表模型名称｜**标记**：已确认

- 模型名称：用户填写的模型标识，必填；用于模型库检索与引用。
- 模型编码：系统生成、全局唯一、不可修改；列表第一列展示。

#### CM-09 字段：产品分类 / 行业标签 / 核算标准
**拟标注位置**：产品分类 / 行业标签 / 核算标准｜**标记**：已确认

- 产品分类：模型归属分类，必填；用于模型库检索与引用（级联选择统计用分类目录）。
- 行业标签：可多选，用于模型库按行业筛选；可与产品「所属行业」不同。
- 核算标准：引用标准文件库（仅现行标准），必填；决定模型核算口径。

#### CM-10 字段：系统边界 / 生命周期阶段
**拟标注位置**：系统边界 / 生命周期阶段区域｜**标记**：已确认

- 系统边界：卡片式单选（引用数据字典 · 系统边界，仅展示已启用项），必填；修改后按适用边界重新带出生命周期阶段。
- 生命周期阶段：按适用边界带出，默认全部纳入、可取消；作为第 2 步数据项的挂靠结构。

#### CM-11 字段：产品图片
**拟标注位置**：产品图片｜**标记**：已确认

- 被核算产品的外观图片，作为模型识别依据；引用产品时自动带出也可自行上传；必填。
