## 1. 拟添加的批注清单

### 1.1 整体流程

#### B14-01 角色维护整体流程
**拟标注位置**：两个功能标题「平台角色管理」「角色管理（租户端）」附近（各自的全局说明入口）
**标记**：已确认

**批注内容**

- **适用场景**：平台侧由持有平台角色管理功能的平台人员维护平台岗位；租户侧由租户管理员维护本租户岗位。两个入口各看各的，任一侧页面都不承载对方切片。
- **平台侧流程**：进入平台角色管理 → 列表只显示平台角色 →「新增」建立角色档案（名称 / 标识 / 描述）→ 对角色点「授权」勾选功能菜单 → 平台账号在「平台账号」模块把角色指派给账号 → 角色页查看成员、可「移除成员」收回 → 岗位临时不用「停用」，确认无人持有「删除」。
- **租户侧流程**：进入租户端角色管理 → 列表只显示本租户角色 → 同样「新增」建档案 →「授权」时除勾选功能菜单外，按功能点配读写数据范围 → 成员由「成员管理」模块指派 → 角色页查看与移除成员。
- **分支**：新建有两个来源——从零「新增」，或从已有角色「复制」（带入功能勾选，租户角色还带入数据范围）；「授权」对内置角色只读，需先「复制」再调整。
- **衔接**：列表点角色名称进详情；详情页可直接发起授权 / 复制 / 修改 / 停用 / 启用 / 删除，也可返回列表；所有弹窗操作完成后列表与详情同步刷新。
- **结束**：保存与停启用即时生效，无提交、审核、驳回环节；删除为软删，记录保留供审计，角色生命终止于「已删除」。

### 1.2 全局规则说明

#### B14-02 全局规则
**拟标注位置**：两个功能标题附近（与整体流程同一全局说明入口）
**标记**：已确认（入口权限为待确认，见 §4）

**批注内容**

1. **适用范围与隔离**：平台角色管理只维护归属类型为平台的角色，租户端角色管理只维护本租户角色；平台角色只授予平台账号，租户角色只在租户内生效，两切片互不出现、互不指派、互不复制。
2. **归属类型建后不可改**：新建时固定为平台或租户，表单不提供选择与修改，也不提供「转为另一归属类型」的入口。
3. **内置角色**：平台内置 2 个（超级管理员、平台运营人员）；租户内置 1 个（租户管理员，开户时自动创建）。内置角色不可修改、不可删除，可复制；超级管理员与租户管理员额外不可停用。
4. **自定义角色上限**：每个切片各 20 个（停用计入、已删除不计），达到上限后阻断新建与复制。
5. **唯一性**：角色名称与角色标识均在归属范围内唯一（平台内 / 租户内各自判重，不跨切片）；已删除角色的名称与标识不释放。
6. **角色标识创建后不可修改**，格式限大写字母、数字、下划线且以字母开头（如 SUPER_ADMIN）。
7. **删除为软删**：角色进入「已删除」，功能勾选与成员历史保留供审计；有生效成员的角色不可删。
8. **变更立即生效**：授权、停用、启用保存后即时生效，持有者下次请求即按新权限执行；保存前提示将受影响的生效成员人数（租户「授权」弹窗已具备，平台弹窗待补，见 §4 R-01）。
9. **数据范围只属于租户切片**：平台角色只勾功能菜单、不配数据范围；租户角色按功能点配读写数据范围（见 B14-19）。
10. **勾选树只出现启用状态的功能**：停用的功能不出现在授权树中；保存时校验所勾功能均为启用状态；已被勾选的功能在菜单管理停用后，详情页该功能状态显示「停用」，不再作为有效权限。
11. **有效功能**：平台侧 = 角色勾选的功能；租户侧 = 已开通模块内功能点 ∩ 角色勾选功能点；成员持多角色时按功能点取并集，数据范围取最宽一档。
12. **指派出入口**：平台角色由「平台账号」模块分配（一人 1 至 5 个、至少 1 个），租户角色由「成员管理」模块分配；角色页只查看与移除成员，不提供添加成员入口。
13. **平台授权树范围**：当前展示菜单管理中的全部启用菜单，不按适用端过滤（含租户端功能）；本口径以原型为准，PRD §5.2 待同步修订（见 §4 D-01 / D-02）。
14. **演示数据**：列表中的角色、成员、创建时间等均为演示数据，正式实现以真实操作记录为准。

### 1.3 业务状态说明

#### B14-03 角色状态
**拟标注位置**：清单「状态」列旁、详情页「角色状态」行旁
**标记**：已确认

**批注内容**

- **含义**：角色有「启用」「停用」「已删除」三个状态。启用 = 生效，可被指派；停用 = 暂失效，关联与勾选保留，恢复后自动生效；已删除 = 终态，软删保留供审计。
- **进入条件**：新增与复制后默认为「启用」；「停用」由启用态经操作「停用」进入；「启用」由停用态经操作「启用」进入；「已删除」由「删除」进入，不可逆。
- **可进行的操作**：启用态可修改（自定义）、授权、复制、停用（保护角色除外）、删除（无生效成员）；停用态不可被指派，其余同启用态；已删除态不可编辑、授权、复制、停用、启用、指派，成员页只读。
- **状态变化**：启用与停用双向可达、可反复切换；删除后不可恢复，也不可再建同名 / 同标识角色。
- **成员状态是另一维度**：成员列表中的「生效 / 已停用」指成员本身的状态；成员被停用不收回其角色关联，恢复后权限随之恢复。
- **交互表现不算状态**：页面加载、保存中按钮暂不可点、清单为空等属于交互表现，在各操作下说明，不视为业务状态。

### 1.4 操作功能及对应业务规则

#### B14-04 平台角色管理列表
**拟标注位置**：列表表格区域与工具条
**标记**：已确认

**批注内容**

- **操作目的**：查看并维护平台角色（只含归属类型为平台的角色）。
- **展示内容**：选择框、#、角色名称（带类型徽章）、角色标识、状态、创建时间、操作。
- **类型徽章**：「保护角色」（超级管理员等受保护内置角色）、「内置」（普通内置角色）、「自定义」（新建或复制产生）。
- **行选择框**：仅自定义角色可勾选（用于批量删除），内置角色显示「—」。
- **排序与分页**：启用的角色排在前面，其余按创建时间倒序；每页 20 条。
- **工具条**：左侧「新增」「删除（N）」；右侧汇总「共 N 条 · 内置 X 条 · 自定义 Y / 20」与刷新按钮；汇总同时提示「本页只维护平台角色，租户角色由租户自建自管、只在本租户生效，与本页完全隔离、不混用」。
- **操作列**：「修改」仅自定义角色显示；「授权」「复制」恒显示；「停用 / 启用」按状态二选一；「删除」仅自定义角色显示。
- **无内容时**：暂无角色时表格为空（空态文案见 §4 X-05）。

#### B14-05 查询与重置
**拟标注位置**：清单上方查询区
**标记**：原型已表现·待核对

**批注内容**

- **操作目的**：按关键词快速定位角色。
- **查询项**：角色名称——输入即按当前列表即时过滤；实际同时匹配角色名称与角色标识（标识按大写口径匹配），标签仅写「角色名称」（见 §4 R-06）。
- **重置**：清空关键词，恢复当前范围完整清单。
- **原型表现（待核对）**：「查询」按钮点击后无额外动作（即时过滤已生效），与产品分类「搜索」按钮同型；正式需求是「点击后查询」还是「即时过滤 + 按钮共存」，需确认。

#### B14-06 新增角色
**拟标注位置**：页头「新增」按钮旁、新增弹窗
**标记**：已确认（新建与授权分两步，PRD §3.1 待同步，见 §4 D-07）

**批注内容**

- **操作目的**：建立一个新的角色档案。
- **入口**：页头「新增」。
- **操作过程**：打开弹窗，填写角色名称（必填）、角色标识（必填，提示「如 SUPER_ADMIN，归属范围内唯一」）、角色描述（选填）。
- **结果**：保存成功提示「角色已创建，请通过『授权』分配功能」；新角色状态为启用、无任何功能勾选、无成员，出现在列表中。
- **后续必须动作**：新角色不产生任何权限，需再通过「授权」勾选功能后才能被指派使用。
- **校验**：名称 / 标识必填；标识格式合法且归属范围内唯一；自定义角色数未满 20。任一不通过则阻断保存，弹窗内给出提示。
- **取消**：点「取消」或关闭弹窗不保存，再次打开不保留上次填写内容。

#### B14-07 修改角色
**拟标注位置**：操作列「修改」、修改弹窗
**标记**：已确认

**批注内容**

- **操作目的**：修改自定义角色的档案信息。
- **可操作条件**：仅自定义角色显示「修改」；内置角色只读，引导走「复制」。
- **操作过程**：打开弹窗带出现有内容；角色标识为只读（创建后不可修改）；可改角色名称与角色描述。
- **校验**：名称必填、最长 50 字符、归属范围内唯一。
- **结果**：保存成功提示「保存成功」，列表与详情刷新；档案修改不改变该角色已配的功能与数据范围。

#### B14-08 复制角色
**拟标注位置**：操作列「复制」、复制弹窗
**标记**：已确认

**批注内容**

- **操作目的**：以已有角色为模板快速建岗。
- **可操作条件**：内置与自定义角色均可复制；不可跨归属复制（平台角色只复制出平台角色，租户角色只复制出租户角色）。
- **操作过程**：打开弹窗，预填名称「源角色名 副本」、标识「源标识_COPY」、描述同源角色，均可修改。
- **携带内容**：复制结果带入源角色的功能勾选；租户角色同时带入每个功能点的读写数据范围。
- **结果**：复制结果恒为自定义角色、状态启用、无成员；提示「角色已复制，功能权限已带入，可再通过『授权』调整」。
- **校验**：同新增（名称 / 标识必填、格式与唯一性、未满 20）。

#### B14-09 删除角色（含批量）
**拟标注位置**：操作列「删除」、工具条「删除（N）」、删除确认弹窗
**标记**：已确认（批量删除 PRD 功能清单待补，见 §4 D-06）

**批注内容**

- **操作目的**：清理不再使用的岗位，记录保留供审计。
- **单个删除**：仅自定义角色可删；详情页中该角色仍有生效成员时，「删除」按钮禁用并提示「该角色下仍有 N 个生效成员，请先移除成员」。
- **批量删除**：列表勾选多个自定义角色后点「删除（N）」，确认弹窗逐条列出所选角色；批量执行时自动跳过内置角色与仍有生效成员的角色，被跳过的在结果提示中说明原因。
- **删除语义**：软删——角色进入「已删除」，功能勾选与成员历史保留供审计，名称与标识不释放，不可再建同名 / 同标识角色；已删除角色不可编辑、不可指派、不可启停。
- **确认弹窗提示**：「删除为软删，记录与功能勾选、成员历史保留供审计，名称与标识不释放；有生效成员引用时不可删。」

#### B14-10 停用角色
**拟标注位置**：操作列「停用」、停用确认弹窗
**标记**：已确认

**批注内容**

- **操作目的**：临时冻结岗位，保留全部配置。
- **可操作条件**：仅启用状态显示「停用」；超级管理员、租户管理员（保护角色）不显示停用入口。
- **操作过程**：点击后弹二次确认，标题「确认停用角色」，正文「确认停用角色『角色名』？」，并提示「停用立即生效，N 个生效成员将失去该角色权限（下次请求重算）；成员关联与功能勾选保留，恢复后自动生效」。
- **结果**：确认后角色停用，不再出现在任何分配角色下拉中；持有者下次请求按剩余角色重算权限。
- **取消**：点「取消」或关闭弹窗，状态不变。

#### B14-11 启用角色
**拟标注位置**：操作列「启用」、启用确认弹窗
**标记**：已确认

**批注内容**

- **操作目的**：恢复被停用的岗位。
- **可操作条件**：仅停用状态显示「启用」。
- **操作过程**：点击后弹二次确认，标题「确认启用角色」，提示「启用后该角色的关联与勾选恢复，成员权限同步恢复」。
- **结果**：确认后角色启用，关联与勾选恢复，重新可被指派；列表与详情刷新。
- **取消**：点「取消」或关闭弹窗，状态不变。

#### B14-12 平台「分配权限」
**拟标注位置**：平台「分配权限」弹窗
**标记**：已确认（授权树范围为原型口径，PRD §5.2 待同步，见 §4 D-01 / D-02）

**批注内容**

- **操作目的**：配置平台角色可使用的功能菜单；平台角色不配数据范围。
- **入口**：列表 / 详情的「授权」。
- **勾选树范围**：展示菜单管理中的全部启用菜单，不按适用端过滤（含租户端功能，本口径以原型为准）；分组节点不可勾选，仅承载层级；提供「展开 / 折叠」与「全选 / 不全选」。
- **只读规则**：内置角色（超级管理员、平台运营人员）只读，弹窗底部提示「内置角色不可修改，请走『复制』后调整」。
- **保存校验**：至少勾选 1 个菜单；所勾功能必须为启用状态；同一菜单不可重复勾选。
- **结果**：保存成功提示「权限已保存，立即生效并刷新缓存」；详情页功能菜单权限表同步刷新。
- **待补**：保存前的影响成员人数提示当前仅租户弹窗具备（见 §4 R-01）。

#### B14-13 平台角色详情
**拟标注位置**：平台角色详情页
**标记**：已确认

**批注内容**

- **进入方式**：列表点角色名称；面包屑为 系统管理 / 组织与权限 / 平台角色管理 / 角色名。

- **操作目的**：配置租户角色的功能菜单，并按功能点配读写数据范围。

- **影响提示**：弹窗顶部提示「仅显示已启用功能，保存后立即生效。本次变更将影响 N 个生效成员。」
- **默认范围**：勾选功能点时自动默认读「本部门」、写「仅本人」，可再调整；不适用数据范围的功能点（系统管理类）不出现范围控件。
- **只读规则**：内置非保护角色只读（提示「内置角色不可修改，请走『复制』后调整」）；租户管理员（保护角色）可收窄功能与范围。
- **保存校验**：至少勾选 1 个功能菜单；读写各配一档；写范围不得宽于读范围；「指定部门」必须选部门（规则见 B14-19）。
- **结果**：保存成功提示「权限与数据范围已保存，立即生效」。

#### B14-19 数据范围配置
**拟标注位置**：租户「分配权限」弹窗范围控件旁、详情页「读范围 / 写范围 / 指定部门」列头旁
**标记**：已确认（默认档与不可比较提示为原型口径，PRD 待补，见 §4 D-08）

**批注内容**

- **五档**：全部 / 本部门及下级 / 本部门 / 仅本人 / 指定部门。
- **读写各配一档**：每个适用数据范围的功能点分别选读范围与写范围；只配一侧不允许保存。
- **写不宽于读**：写范围档位不得宽于读范围（如读「本部门」时写不能选「全部」）；「指定部门」与部门档位之间无法比较宽窄时，保存被阻断并提示「两侧都选『指定部门』或都选部门档」（原型口径）。
- **指定部门**：读或写任一侧选「指定部门」时出现部门多选，候选项为本租户启用状态的组织节点；当前读写共用同一组部门（原型口径，字段清单待同步，见 §4 D-05）。
- **默认档**：新勾选的功能点默认读「本部门」、写「仅本人」（原型默认，PRD 未规定）。
- **不适用数据范围的功能点**：系统管理类（组织架构 / 成员管理 / 角色管理等）不出现范围控件、不配读写范围。
- **多角色合并**：同一功能点被多个角色配置时取最宽一档，实时计算、不落库。

#### B14-20 租户管理员（内置保护角色）
**拟标注位置**：租户端列表 / 详情中「租户管理员」角色名与徽章旁
**标记**：已确认

**批注内容**

- **来源**：平台管理员创建租户并关联主管理员后，系统在该租户内自动创建，创建人为「系统（开户初始化）」；主管理员的成员关系自动持有该角色。
- **默认权限**：默认勾选租户端全部功能点、数据范围读写均「全部」；实际生效仍受租户已开通模块约束（有效功能 = 已开通模块 ∩ 勾选功能点）。
- **保护规则**：不可删除、不可停用（列表 / 详情不出现删除与停用入口）；可复制。
- **可收窄**：功能勾选与数据范围允许被租户管理员调整，收窄后即时生效并提示影响成员人数。
- **定位**：租户侧权限起点；其他岗位角色由租户管理员按需新建，或复制本角色后调整。

### 1.5 字段说明

#### B14-21 角色名称
**拟标注位置**：新增 / 修改 / 复制弹窗「角色名称」旁、清单该列表头
**标记**：已确认

**批注内容**

- **业务含义**：岗位的展示名，列表与详情中识别角色的依据。
- **填写方式**：手工填写。
- **必填**：必填；为空提示「角色名称必填」并阻断保存。
- **长度上限**：最长 50 字符。
- **重复限制**：归属范围内唯一（平台内 / 租户内各自判重），重复提示「归属范围内已存在同名角色」。
- **可否修改**：自定义角色可改；内置角色不可改（只读，走复制）。
- **复制预填**：「源角色名 副本」，可改。

#### B14-22 角色标识
**拟标注位置**：新增 / 复制弹窗「角色标识」旁、清单该列表头
**标记**：已确认（格式与唯一范围为原型口径，字段清单待同步，见 §4 D-03 / D-09）

**批注内容**

- **业务含义**：角色的稳定标识，用于区分不同岗位与系统引用。
- **填写方式**：手工填写，输入框提示「如 SUPER_ADMIN，归属范围内唯一」。
- **必填**：新增 / 复制时必填；为空提示「角色标识必填」。
- **格式限制**：仅支持大写字母、数字与下划线，且以字母开头。
- **重复限制**：归属范围内唯一（不跨切片判重），重复提示「归属范围内已存在相同角色标识」。
- **可否修改**：创建后不可修改——编辑态只读并提示「创建后不可修改」，保存时拒绝变更。
- **复制预填**：「源标识_COPY」，可改。
- **内置角色标识**为系统固定值（如超级管理员、租户管理员），不可改。

#### B14-23 角色描述
**拟标注位置**：弹窗「角色描述」旁、详情页该行
**标记**：已确认（长度上限未校验，原型待修，见 §4 R-03）

**批注内容**

- **业务含义**：岗位职责说明，便于他人理解该角色的用途。
- **填写方式**：多行文本。
- **必填**：选填。
- **长度上限**：不超过 200 字符（文档口径；原型未做长度校验，列入待修）。
- **展示**：详情页展示，为空显示「—」；复制时默认带入源角色描述，可改。

#### B14-24 归属类型 / 生效租户
**拟标注位置**：详情页「归属类型」「生效租户」行旁
**标记**：已确认

**批注内容**

- **业务含义**：标明角色属于哪个切片、在哪个范围生效。平台角色显示「归属类型 = 平台」；租户角色显示「生效租户 = 租户名」。
- **可否修改**：新建时固定，建后不可改；表单中不出现该字段的选择与修改入口。
- **关联影响**：平台角色挂平台账号，只能被平台账号持有；租户角色挂租户成员关系，只在本租户内生效；两者互不引用。

#### B14-25 制单信息
**拟标注位置**：详情页「创建人 / 创建时间 / 最近更新」行
**标记**：已确认（原型中为演示数据）

- **创建人、创建时间**：新增时由系统记录，不可维护；租户管理员的创建人为「系统（开户初始化）」。
- **最近更新**：每次保存、停用、启用后刷新，展示为「更新人 · 更新时间」，用于追溯最近变更。
- **展示位置**：仅在详情页查看，不进清单列。
- **数据性质**：原型中为演示数据，正式实现按真实操作记录生成。
