# 角色管理字段清单

> **文档定位**：角色管理相关表结构的字段唯一真相源。业务 PRD 只引用字段名，不重复维护类型、必填与枚举。
> **依据**：产品碳足迹核算工具-用户体系 PRD（精简版）v3.5.1 §5.3、§5.7
> **覆盖表**：角色、角色与功能关联、角色功能点-指定部门、角色成员关联
> **版本**：V0.1
> **更新时间**：2026-10-21

---

## 0. 表定位

角色管理是一张角色表 + 三张关联表。平台与租户两个切片共用同一套表，靠角色表上的归属类型字段区分，不拆表、不建第二套。

```text
一个角色 = role 表 1 条记录
归属类型 = 平台（挂平台账号）/ 租户（挂成员关系）
平台切片 = 归属类型为平台的角色，只勾平台端功能，无数据范围
租户切片 = 归属类型为租户的角色，勾租户端功能，按功能点配读写数据范围
```

推论：

| # | 推论 |
| :--- | :--- |
| 1 | 角色只有一份，两切片是同一张表的两个筛选视图，不复制角色数据 |
| 2 | 归属类型建后不可改，不提供跨归属转换，两切片互不引用 |
| 3 | 平台角色不写租户标识（固定占位值），租户角色必写租户标识 |
| 4 | 数据范围只存在于租户切片，配在「角色 × 功能点」关联行上，不配在角色本体 |
| 5 | 功能引用功能管理目录表，本清单只存 function_id，不复制功能属性 |

## 1. 角色

表名：`role`

| 字段名 | 中文名 | 类型 | 必填 | 默认 | 说明 | 约束 | 写入时机 |
| :--- | :--- | :--- | :---: | :--- | :--- | :--- | :--- |
| id | 角色ID | bigint | 是 | 雪花ID | 主键 | 全局唯一 | 新建 |
| scope_type | 归属类型 | tinyint | 是 | 无 | 区分平台 / 租户切片 | 取值 1 / 2；新建时固定，建后不可改 | 新建 |
| tenant_id | 租户ID | bigint | 是 | 无 | 租户切片的归属租户 | 平台角色固定为 0 占位；租户角色为真实租户ID | 新建 |
| code | 角色标识 | varchar(64) | 是 | 系统生成（ROLE + 序号） | 角色的稳定标识 | 全局唯一，注册 / 初始化时置；内置角色固定为语义常量（如 `SUPER_ADMIN` / `TENANT_ADMIN`），自定义角色可改 | 新建（初始化 / 自建） |
| name | 角色名称 | varchar(50) | 是 | 无 | 列表与详情展示名 | 归属范围内唯一；长度 1 至 50 | 新建、编辑 |
| description | 角色描述 | varchar(200) | 否 | NULL | 岗位职责说明 | 长度不超过 200 | 新建、编辑 |
| is_builtin | 是否内置 | tinyint | 是 | 0 | 内置角色保护标记 | 取值 0 / 1；1 时不可改、不可删 | 新建（初始化置 1） |
| status | 角色状态 | tinyint | 是 | 1 | 生效闸门 | 取值 1 / 2 / 3 | 新建、停用、启用、删除 |
| created_by | 创建人 | bigint | 是 | 无 | 操作人账号ID | 外键 | 新建 |
| created_at | 创建时间 | datetime | 是 | 当前时间 | — | 不可改 | 新建 |
| updated_by | 更新人 | bigint | 是 | 无 | 最近一次操作人账号ID | 外键 | 新建、每次更新 |
| updated_at | 更新时间 | datetime | 是 | 当前时间 | — | 每次写操作刷新 | 新建、每次更新 |
| version | 版本号 | int | 是 | 0 | 乐观锁 | 每次更新加 1 | 新建、每次更新 |

**唯一索引**

| 索引名 | 字段 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| uk_role_scope_name | (scope_type, tenant_id, name) | 唯一 | 归属范围内唯一；平台角色 tenant_id = 0 占位，不用 NULL，避免唯一索引对 NULL 失效 |
| idx_role_tenant_status | (tenant_id, status) | 普通 | 租户角色列表按状态筛选 |

**外键**

| 字段 | 指向 | 约束 |
| :--- | :--- | :--- |
| created_by / updated_by | account.id | 只读引用，不做级联 |

**状态枚举取值（status）**

| 值 | 名称 | 含义 | 可被指派 |
| :---: | :--- | :--- | :---: |
| 1 | 启用 | 生效，可勾选、可指派 | 是 |
| 2 | 停用 | 暂失效，关联与勾选保留，恢复后自动生效 | 否 |
| 3 | 已删除 | 终态，软删保留供审计 | 否 |

**保护规则（不在字段上，由服务端校验）**

| # | 规则 |
| :--- | :--- |
| 1 | 内置角色（is_builtin = 1）不可改、不可删；超级管理员额外不可停用 |
| 2 | 自定义角色上限：平台 20 个；每租户 20 个（按 is_builtin = 0 且 status ≠ 3 计数） |
| 3 | 有生效成员引用（role_member 存在 revoked_at 为 NULL 的行）时不可删 |
| 4 | 已删除角色名称不释放，唯一索引不排除 status = 3 的行 |

**软删字段**

| 项 | 内容 |
| :--- | :--- |
| 是否有软删字段 | 无独立软删字段 |
| 说明 | 删除以 status = 3 表达，记录长期保留供审计追溯，不做物理删除 |

**关联配置（不在本表）**

| 配置项 | 归属 | 作用 |
| :--- | :--- | :--- |
| 已开通模块 | 租户管理（模块授权） | 与角色勾选取交集算有效功能 |
| 功能目录 | 功能管理（sys_function） | 角色勾选的数据源 |

## 2. 角色与功能关联

表名：`role_function`　关系：角色 N:N 功能（一个功能点一行，带读写数据范围）

| 字段名 | 中文名 | 类型 | 必填 | 默认 | 说明 | 约束 | 写入时机 |
| :--- | :--- | :--- | :---: | :--- | :--- | :--- | :--- |
| id | 关联ID | bigint | 是 | 雪花ID | 主键 | 全局唯一 | 角色保存 |
| role_id | 角色ID | bigint | 是 | 无 | 持有方 | 外键 | 角色保存 |
| function_id | 功能ID | bigint | 是 | 无 | 被勾选的功能 | 外键；适用端须与角色归属类型匹配；功能状态须为启用 | 角色保存 |
| read_scope | 数据范围-读 | tinyint | 否 | NULL | 读范围档位 | 取值 1 至 5；平台角色为空；租户角色且功能适用数据范围时必填 | 角色保存 |
| write_scope | 数据范围-写 | tinyint | 否 | NULL | 写范围档位 | 取值 1 至 5；不得宽于 read_scope | 角色保存 |
| granted_by | 操作人 | bigint | 是 | 无 | 操作人账号ID | 外键 | 角色保存 |
| granted_at | 配置时间 | datetime | 是 | 当前时间 | — | 不可改 | 角色保存 |

**唯一索引**

| 索引名 | 字段 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| uk_role_function | (role_id, function_id) | 唯一 | 同一角色同一功能只保留 1 行；取消勾选即物理删除，前后值记审计 |
| idx_function_role | (function_id, role_id) | 普通 | 反查某功能被哪些角色勾选（停用功能时统计影响面） |

**外键**

| 字段 | 指向 | 约束 |
| :--- | :--- | :--- |
| role_id | role.id | 不可空 |
| function_id | sys_function.id | 不可空；适用端与角色 scope_type 对应；status = 1 |
| granted_by | account.id | 不可空 |

**状态枚举取值**

| 字段 | 值 | 名称 | 说明 |
| :--- | :---: | :--- | :--- |
| read_scope / write_scope | 1 | 全部 | 租户内全部数据 |
| read_scope / write_scope | 2 | 本部门及下级 | 按部门树实时计算 |
| read_scope / write_scope | 3 | 本部门 | 仅成员所属部门 |
| read_scope / write_scope | 4 | 仅本人 | 按责任人判定，不按创建人 |
| read_scope / write_scope | 5 | 指定部门 | 部门列表见 role_function_dept |
| read_scope / write_scope | NULL | 不适用 | 平台角色，或功能不适用数据范围 |

**软删字段**

| 项 | 内容 |
| :--- | :--- |
| 是否有软删字段 | 无 |
| 说明 | 取消勾选即物理删除；变更前后值由审计日志留存（§5.3.2-4、§5.4.1-7） |

| :--- | :--- | :--- | :---: | :--- | :--- | :--- | :--- |

| member_type | 成员类型 | tinyint | 是 | 无 | 与角色归属类型对应 | 取值 1 / 2；平台角色只能为 1，租户角色只能为 2 | 指派角色 |
| member_id | 成员ID | bigint | 是 | 无 | 被授予对象 | member_type = 1 指向 account.id；= 2 指向租户成员关系 id | 指派角色 |
| granted_by | 授予人 | bigint | 是 | 无 | 操作人账号ID | 外键 | 指派角色 |

| revoked_by | 收回人 | bigint | 否 | NULL | 操作人账号ID | 外键 | 移除成员 |
| revoked_at | 收回时间 | datetime | 否 | NULL | 非空表示关联失效 | 收回后不可复用同一条 | 移除成员 |

**唯一索引**

| 索引名 | 字段 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| uk_role_member | (role_id, member_type, member_id) | 唯一（生效范围） | 同一角色同一成员只保留 1 条生效关联，收回后重新授予另起新行 |

**外键**

| 字段 | 指向 | 约束 |
| :--- | :--- | :--- |
| role_id | role.id | 不可空，且角色 status ≠ 3 |
| member_id | member_type = 1：account.id；member_type = 2：租户成员关系表 id（成员管理，本清单不覆盖） | 不可空 |

**状态枚举取值**

| 项 | 内容 |
| :--- | :--- |
| 是否有状态字段 | 无独立状态字段 |

| 派生状态 | 生效 / 已收回 两种取值 |
| 成员类型 | 1 = 平台账号；2 = 租户成员关系 |

**软删字段**

| 项 | 内容 |
| :--- | :--- |
| 软删字段 | revoked_at（配合 revoked_by） |
| 说明 | 移除成员只写 revoked_at，不物理删除，保留授予与收回双向痕迹供审计 |

## 5. 表间关系

```text
role（角色表，scope_type 分平台 / 租户两切片）
  ├─ 1:N ─ role_function（角色与功能关联，租户切片带读写数据范围）
  │            └─ 1:N ─ role_function_dept（指定部门列表，读 / 写各一组）
  ├─ 1:N ─ role_member（角色成员关联，平台挂账号 / 租户挂成员关系）
  └─ 被以下表引用（本清单不覆盖）
               ├─ sys_function.id ← role_function.function_id（功能管理）
               ├─ account.id ← role_member.member_id（member_type = 1，平台账号）
               ├─ 租户成员关系表 id ← role_member.member_id（member_type = 2，成员管理）
               └─ 部门表 id ← role_function_dept.dept_id（部门管理）
```

关键约束：

1. 一张角色表承载两切片，scope_type 建后不可改；平台角色 tenant_id = 0 占位，保证唯一索引生效。
2. 两切片互不引用：role_function.function_id 的适用端必须与 role.scope_type 对应；role_member.member_type 必须与 role.scope_type 对应。
3. 角色删除只置 status = 3，role_function 与 role_member 记录保留，供审计追溯历史授权。
4. 平台角色不产生数据范围，role_function.read_scope / write_scope 为空，不建 role_function_dept 行。
5. 写范围不宽于读范围：scope_type = 2 的部门列表须为 scope_type = 1 列表的子集。
6. 数据范围生效值不落库：多角色同一功能点取最宽一档，在查询时按角色并集实时计算。
7. 生效功能 = 已开通模块 ∩ 角色勾选功能点，模块数据在租户管理，不在本清单。

## 6. 设计决策

| 编号 | 事项 | 决议 | 落点 |
| :--- | :--- | :--- | :--- |
| D01 | 表结构 | 一张 role 表 + 三张关联表，平台与租户两切片共用 | §0 |
| D02 | 平台切片租户标识 | tenant_id 固定为 0 占位，不用 NULL，避免唯一索引失效 | §1 唯一索引 |
| D03 | 数据范围粒度 | 配在 role_function 行上，读写各一档；指定部门拆 role_function_dept 表 | §2、§3 |
| D04 | 角色编码 | **原型新增**：角色增加稳定标识 `code`（全局唯一，系统生成 `ROLE + 序号`；内置角色固定为语义常量，如 `SUPER_ADMIN` / `PLATFORM_OPERATOR` / `TENANT_ADMIN`）；自定义角色可改。内置角色既可用 `code` 也可按 `name` 识别，取消原「不设编码」口径 | §1 code |
| D04b | 超级管理员 / 保护角色属性 | 原型在 `is_builtin` 之外另设 `super_admin`（仅超级管理员为 true）与 `protected_role`（租户内置保护角色，如租户管理员，不可删不可停用）两个独立布尔属性，与 `is_builtin` 正交；本清单保护规则 §1 的三类约束（不可改名、不可删、不可停用）应按此三属性精确判定，而非仅按 `is_builtin` | §1 保护规则 |
| D05 | 角色状态 | 启用 / 停用 / 已删除三态，停用不删关联 | §1 状态枚举 |
| D06 | 删除语义 | status = 3 软删，名称不释放，关联记录保留 | §1 保护规则 |
| D07 | 取消勾选 | role_function 物理删除，前后值记审计，不做软删 | §2 软删说明 |
| D08 | 成员关联 | 移除成员写 revoked_at 软删，保留授予与收回痕迹 | §4 |
| D09 | 成员对象 | 一张 role_member 表用 member_type 区分平台账号与租户成员关系，不拆两表 | §4 |
| D10 | 部门引用清理 | 部门删除时由部门模块联动清理 role_function_dept，不在本表做级联 | §3 外键 |
| D11 | 表名 | 用 `role`，承载两切片；不用 platform_role / tenant_role 拆分 | §1 |
