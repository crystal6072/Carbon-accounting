# 行业库字段清单

> **文档定位**：行业库字段定义的唯一真相源（SST）。业务 PRD 和 Demo PRD 只引用字段名称，不重复维护枚举、必填性和字段口径。
> **适用类型**：基础数据维护（轻量）—— 非业务单据、**无审核流、无版本化**
> **核心定位**：行业库是「**通用 → 行业**」的**唯一扩展点**（方案 §4.2.5）；行业本身只作为**配置结果的锚点**存在，引擎与数据模型不感知具体行业（方案 §1.2）
> **维护形态**：**左树 + 右表 + 弹窗**（与「产品分类」交互一致；V0.1 范围收敛，见文末收敛记录）
> **成熟度**：粗纲
> **版本**：V0.1
> **更新时间**：2026-09-21

**五条「不设字段」的设计约定**

| 约定 | 说明 |
| :--- | :--- |
| **不承载任何「行业参数模板」字段**（**核心结论，对应 Q01**） | 采纳**口径 A**：行业库 = **行业分类字典 + 元数据 + 锚点**，**不挂**「默认阶段基线 / 默认因子集 / 默认规则模板 / 边界」等引用字段。理由：方案 **§4.2.4 修订说明**已明确「**基线不是独立对象**……**不另建『阶段基线』实体**」（附录二 · 已回改第 11 项）；方案 §1.2 的「行业库 + 阶段配置 + 因子集 + 规则模板参数」中，**阶段配置归生命周期阶段 A1-10、因子集归排放因子库 A2-6、规则模板归计算规则模板 A2-1 / 模型 A2-3**，行业库只提供组合的**锚点**。若在行业库再挂一套参数引用，等于**重建阶段基线实体**，造成两层维护（与 §4.2.4 冲突） |
| **不设「数据来源」字段** | 行业字典统一由平台维护，**不设「系统预置 / 组织自建」数据来源字段**（与物料库 / 能源库 / 生命周期阶段同口径，见原型 `industryMeta` / `IndustryItem` 注释「不设数据来源、不设引用状态、不做版本化」）；据此不设「可见性」字段，亦无「系统预置只读 / 组织自建可编辑」的权限分支 |
| **不设「行业层级」字段** | 由「上级行业」**推导**（上级为空 = 门类；上级非空则层级 = 上级层级 + 1，最多到小类，共四级），避免两处维护出现「层级 = 门类但已挂上级」的矛盾 |
| **不设「是否已被引用」字段** | 属只读反查信息，不作为可维护字段；详情页展示「引用本行业的模块与对象清单」，用于删除 / 禁用约束（D05） |
| **不设「行业核算指南」字段**（V0.1 收敛） | 竞品列表有该列（绿色链接），但方案 §2.3 A1-4 / §4.2.5 **均未提**该字段，且它不参与计算与校验。行业库定位为**轻量行业字典**，V0.1 只做行业分类维护，该字段**本期不做**（原 D07 / D10 随之废止）；若后续需要"指南查阅"，建议在**标准文件库（A1-3）**统一承载 |

> **与竞品的字段差异（逐项可解释）**：竞品 3 个业务字段 → 本清单 7 个。多出的 4 项中，**行业名称**为竞品同构字段，**行业编码 / 上级行业 / 排序号**为新增，理由已在表内逐条写明（唯一键可维护、方案要求「行业分类」、下游下拉排序）。「数据来源」V0.2 已移除（见 Changelog）。

## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 行业库 |
| 业务归属 | 后台管理 → 基础库 → 行业库（方案 §2.3 A1-4、§4.2.5、§八 P06） |
| 模块类型 | 基础数据维护（轻量），非业务单据、无审核流、无版本化 |
| 核心对象 | 行业 |
| 核心职责 | 维护**行业分类字典**，作为「通用 → 行业」的唯一扩展点与下游行业化配置的锚点。**行业库只回答「有哪些行业、叫什么、怎么分」，不回答「这个行业怎么算」** —— 阶段配置、因子集、规则模板分别归生命周期阶段（A1-10）、排放因子库（A2-6）、核算模型（A2-3） |

### 1.2 对象结构

| 结构 | 对象 | 与主对象关系 | 主键/唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 行业 | 主对象 | 系统内部 id（不对用户暴露）；业务唯一键 = **行业编码**（**必填**、全平台唯一，可直接填国标 `GB/T 4754` 代码）/ **同级行业名称**（D01 / D02） | **单一对象，无子表**；轻量基础数据；最多**四级**（GB/T 4754：门类 / 大类 / 中类 / 小类） |
| 自引用 | 上级行业 | N:1 | 行业编码 / 行业名称 | 指向本表另一条记录；不得自引用、不得成环、**不得挂到小类（第四级）之下**（D03 / D08） |
| 附件 | 行业核算指南 | 1:N | 附件 id / 外链 URL | 由附件管理（§C6）承载；**选填、可多个、可为外链**；仅用于查阅（D07） |
| 只读反查 | 引用情况 | — | — | 引用本行业的物料 / 能源 / 产品 / 工艺流程 / 工序 / 生命周期阶段清单（用于禁用与删除约束） |

```text
行业层级（最多四级 GB/T 4754，由「上级行业」推导，不设独立字段）：

制造业 C（门类，一级）
└── 木材加工和木、竹、藤、棕、草制品业 20（大类，二级）
    └── 人造板制造 202（中类，三级）
        └── 纤维板制造 2021（小类，四级）

有色金属冶炼和压延加工 32（门类，一级）   ← 跨行业样例，用于验证通用性
└── 常用有色金属冶炼 321（大类，二级）
    └── 铝冶炼 3216（中类，三级）
        └── 电解铝 3216..（小类，四级，对齐竞品「电解铝行业」）

下游「所属行业 / 适用行业」可选取任意层级节点（通常选小类 / 末级节点）；
上级节点兼作分类容器，是否允许被下游直接选中见 §9 Q06。
```

### 9.1 已确认决策（本次执行按此撰写）

| 编号 | 结论 |
| :--- | :--- |
| **Q01 口径 A（本次采用）** | **行业库 = 行业分类字典 + 元数据 + 锚点，不承载「行业参数模板」**。阶段配置 / 因子集 / 规则模板分别归 A1-10 / A2-6 / A2-3；行业库**不另建阶段基线实体**（对齐方案 §4.2.4 修订说明与附录二 · 已回改第 11 项）。**待业务确认** |
| **术语口径** | 「数据来源」只有「系统预置 / 组织自建」一个含义，仅用于权限判定；状态统一用「启用 / 禁用」 |

### 9.2 优先处理

**Q02：行业库是否承载「行业参数模板」（本任务最关键分歧）**

| 出处 | 表述 | 隐含结构 |
| :--- | :--- | :--- |
| 方案 §2.3 A1-4 | 行业分类与**行业参数模板**，供行业化配置复用 | 行业库承载参数 |
| 方案 §1.2 | 新行业通过「**行业库 + 阶段配置 + 因子集 + 规则模板参数**」组合接入 | 行业库只是**组合入口之一** |
| 方案 §4.2.4 D2 | **行业基线由行业库承载**，与核算模型解耦 | 阶段基线与行业库挂钩 |
| 方案 §4.2.4 修订说明 / 附录二 第 11 项 | 「**基线不是独立对象**……**不另建『阶段基线』实体**」 | 行业库**不承载**阶段集合 |

| 口径 | 结构 | 取舍 |
| :--- | :--- | :--- |
| **A（推荐，本清单已按此撰写）** | 行业库 = 行业分类字典 + 元数据；行业化配置通过**其他模块的「适用行业」字段**（生命周期阶段 / 物料 / 能源 / 因子 / 模型）反向关联实现 | 与 §4.2.4 一致；字段最少（8 项），最接近竞品；不引入对未交付模块的依赖 |
| B | 行业库挂「默认阶段基线（引用阶段库多选）/ 默认因子集（引用因子库）/ 默认规则模板（引用模型）」 | 与 §2.3 字面最贴，**但与 §4.2.4 修订说明冲突**（等于重建基线实体）；且引入对 **A2-6 因子库 / A2-3 模型**（均未交付）的强依赖，行业库会被阻塞 |

> **请业务确认口径 A。** 若改采 B，需同步修订方案 §4.2.4 与附录二第 11 项。

**Q03：组织能否自建行业**

| 出处 / 实际 | 情况 |
| :--- | :--- |
| 方案 §3.3.3 | 行业库列为 **`PUBLIC` 系统预置数据**（与 environment 因子、标准文件、计量单位、阶段基线并列）→ 暗示仅平台维护 |
| 业务实际 | 存在细分行业（如「电解铝」）、企业口径行业、客户指定行业需要自建 |

**建议**：**允许组织自建**（数据来源 = 组织自建，`ORG`），与《标准文件字段清单》Q03 的口径保持一致（该模块已按「允许」撰写，见方案附录二 · 待确认偏离第 7 项）。若采纳，需同步在方案附录二登记本模块的偏离。

**Q04：行业库 P2 优先级与下游强引用的冲突（必答）**

| :--- | :--- | :--- | :--- |
| 物料 A1-1 | 适用行业 | 多选 | **可降级**（不展示） |

| 方案 | 内容 | 代价 |
| :--- | :--- | :--- |
| **A（推荐）** | **行业库提前到 P0**，至少交付「系统预置行业 + 列表 / 新增 / 编辑 / 启停」最小闭环 | 排期前移；但**产品 / 工艺流程 / 工序的「所属行业」已实现为必填**，若不交付行业库，这三个模块的必填校验无法落地 |

**Q05：行业分类的层级与编码**

| 问题 | 结论（建议） |
| :--- | :--- |
| 层级 | **四级**（门类 / 大类 / 中类 / 小类），由「上级行业」推导（D08）；不支持五级及以上。**对齐原型** `IndustryLevel = 1|2|3|4`、`INDUSTRY_MAX_LEVEL = 4` 与 GB/T 4754 |
