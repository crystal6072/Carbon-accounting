## 1. 拟添加的批注清单

### 1.1 整体流程

#### B10-01 行业维护整体流程
**拟标注位置**：功能标题「行业库」附近（全局说明）｜**标记**：已确认

- **适用场景**：在后台维护轻量行业分类字典，作为物料 / 能源 / 产品 / 工艺 / 工序「适用行业 / 所属行业」的下拉数据源。
- **交互形态**：**左树 + 右表 + 弹窗**（与「产品分类」一致）；左侧为行业树，右侧随选中节点在「直接下级清单」与「行业详情面板」间切换。
- **流程**：进入行业库 → 左侧行业树选中节点（或停留在「全部行业」）→ 右侧展示该节点直接下级清单 / 该行业详情 → 按需查询、查看、新增或编辑 → 用「启用 / 禁用」控制能否被下游选用。
- **分支**：新增有三个入口 —— 页头「新增」（新增门类）、树底部「+ 新增门类」、树底部「+ 新增下级行业」（仅选中非末级节点时出现）。
- **衔接**：点清单「行业编码」打开查看弹窗；点左树非根节点切换为详情面板；查看 / 编辑均以弹窗完成。
- **结束**：保存后立即生效，行业树与清单同步刷新。全程没有提交、审核、驳回，也**不提供删除**。

### 1.2 全局规则说明

#### B10-02 全局规则
**拟标注位置**：功能标题「行业库」附近（与整体流程同一全局说明入口）｜**标记**：已确认（权限为待确认，见 §3）

1. **轻量行业字典**：本页只回答「有哪些行业、叫什么、怎么分级」，**不承载阶段基线 / 因子集 / 计算规则等行业参数**（口径 A）。
2. **四级分类（GB/T 4754）**：行业层级为**门类 / 大类 / 中类 / 小类，共四级**；层级**由「上级行业」推导**（不选上级 = 门类，选上级 = 该上级的下一级），**不设独立层级字段、不支持跳级、不支持五级及以上**。
3. **不设数据来源 / 引用状态 / 删除**：行业字典统一由平台维护，**不设「系统预置 / 组织自建」数据来源字段**；**不提供删除**（被下游引用的基础字典，删除风险高），不再使用时用「禁用」；「引用情况」不做可维护字段。
4. **编码必填且唯一**：行业编码**必填、全平台唯一**（可直接填国标 `GB/T 4754` 代码）。
5. **排序号选填**：控制同级展示顺序，越小越靠前，可留空；留空排在同级末尾。
6. **启用 / 禁用控制下游**：行业启用状态决定它是否出现在下游「适用行业 / 所属行业」下拉中；**禁用后下拉不再可选，历史引用数据保留不变**。
7. **变更不追溯**：编辑为直接覆盖，不保留历史版本；行业主数据变更**不追溯已建核算项目**，需按新基线重算走 **E13**。
8. **无流程节点**：没有提交、审核、驳回；不提供批量操作与操作日志。

### 1.3 业务状态说明

#### B10-03 使用状态
**拟标注位置**：清单「使用状态」列旁（详情面板相应引用）｜**标记**：已确认

- **含义**：行业只有「启用」「禁用」两个状态。启用 = 出现在下游「适用行业 / 所属行业」下拉中；禁用 = 不再出现在下拉中。
- **进入条件**：新增保存后默认为「启用」；「启用」由禁用态经操作「启用」进入；「禁用」由启用态经操作「禁用」进入。
- **可进行的操作**：无论启用还是禁用，都可以「查看」「编辑」；启用态可「禁用」，禁用态可「启用」；**任何状态都不提供删除**。
- **状态变化**：启用与禁用双向可达、可反复切换；变更状态只刷新使用状态与最后修改时间。
- **对下游的影响**：一旦禁用，下游「适用行业 / 所属行业」下拉不再可选该行业；**已引用该行业的历史数据保留不变**；行业主数据变更不追溯已建核算项目。

### 1.4 操作功能及对应业务规则

#### B10-04 行业树
**拟标注位置**：左侧「行业树」区域｜**标记**：已确认

- **操作目的**：按四级门类逐层定位要维护或查看的行业。
- **入口**：进入行业库即显示，位于页面左侧；树顶为「全部行业」（虚拟节点，表示不限行业），进入时**默认全部展开**。
- **展示规则**：节点右侧展示其**直接下级数量**；节点按各自排序号升序排列（留空排末尾）；树顶部提示「四级（GB/T 4754）」。
- **选中结果**：选中「全部行业」时，右侧展示**全部门类**清单；选中某个行业时，右侧切换为该行业的**详情面板**。
- **树操作**：树底部常驻「+ 新增门类」；选中**非末级**（层级未达小类）节点时出现「+ 新增下级行业」。

#### B10-05 新增门类
**拟标注位置**：页头「新增」、树底部「+ 新增门类」｜**标记**：已确认

- **操作目的**：建立一个新的顶级行业（门类）。
- **入口**：页头「新增」；或树底部「+ 新增门类」（常驻）。
- **操作过程**：打开弹窗，标题「新增行业」或「新增门类」；「上级行业」锁定为只读的「无上级（门类）」，用户不能改；填写行业编码、行业名称，按需填排序号、行业描述；「行业层级」自动显示「门类」。
- **结果**：保存成功后弹窗关闭，提示「保存成功」，行业树与清单刷新，使用状态为「启用」。

#### B10-06 新增下级行业
**拟标注位置**：树底部「+ 新增下级行业」｜**标记**：已确认

- **操作目的**：在当前所选行业下建立下一级行业。
- **入口**：「+ 新增下级行业」**只在左树选中非「全部行业」且层级未达小类（非末级）的节点时出现**。
- **操作过程**：打开弹窗，标题「新增下级行业」；「上级行业」锁定为只读的所选行业名称；填写其余内容；「行业层级」自动为「上级层级 + 1」。
- **结果**：保存成功后新行业挂在该节点下，行业树与清单刷新，使用状态为「启用」。

#### B10-07 清单
**拟标注位置**：清单表格区域与清单上方工具条｜**标记**：已确认

- **展示内容**：行业编码、行业名称、行业层级、排序号、使用状态、最后修改时间、操作。
- **展示规则**：① 清单范围 = 左树选中节点的**直接下级**（选中「全部行业」时展示门类）；② 每页 **20 条**；③ 同级内按排序号升序，留空排末尾且显示「-」。
- **工具条**：左侧显示当前范围名称（「全部行业」或所选行业）与「共 N 条 · 展示门类；点击左侧行业树节点查看该行业详情」。
- **操作列**：「查看」「编辑」恒显示；「启用 / 禁用」按当前状态二者只出现其一；**无删除**。
- **说明**：选中左树非根节点时，右侧切换为**行业详情面板**（非清单），查询区 / 工具条 / 清单不再展示。

#### B10-08 查询与重置
**拟标注位置**：清单上方查询区｜**标记**：已确认（搜索按钮行为为原型已表现·待核对）

- **查询项**：① 行业编码 —— 包含关系模糊匹配、忽略大小写；② 行业名称 —— 包含关系模糊匹配；③ 使用状态 —— 下拉「启用 / 禁用」，不选即为全部。
- **规则**：多个条件同时生效（叠加过滤）；只过滤当前范围内已展示的行业；任一条件变化后清单回到第 1 页；「重置」清空全部条件并恢复当前范围完整清单。
- **搜索按钮**：点「搜索」执行一次当前条件的筛选。
- **原型表现（待核对）**：原型中点「搜索」仅出现一次「查询完成」提示、不产生额外动作（条件输入后清单已即时收敛）。需确认正式需求是「点击后查询」还是保留「即时筛选 + 按钮共存」。

#### B10-09 查看行业
**拟标注位置**：清单操作列「查看」、清单「行业编码」链接、查看弹窗｜**标记**：已确认

- **操作目的**：只读核对某个行业的完整信息。
- **入口**：清单操作列的「查看」，或直接点击清单中的行业编码；任何状态均可查看。
- **展示内容**：行业编码、行业名称、上级行业、行业层级、排序号、使用状态、创建人、创建时间、最后修改时间、行业描述。
- **规则**：只读弹窗，不能在其中直接修改内容；门类「上级行业」显示「-」，排序号为空显示「-」，行业描述为空显示「-」。
- **结果**：底栏为「关闭」与「编辑」；点「关闭」不产生任何变更，点「编辑」切换到编辑弹窗并带出该行业内容。

#### B10-10 行业详情面板
**拟标注位置**：左树选中非根节点时的右侧详情面板｜**标记**：已确认

- **操作目的**：查看并维护选中的单个行业（选中左树节点即进入）。
- **顶部工具条**：行业名称 + 使用状态标签 + 层级提示；右侧「编辑」「启用 / 禁用」（按状态二者只出现其一）。
- **基本信息**：行业编码、行业名称、行业层级、上级行业（可点击跳转到上级详情）、排序号、使用状态、创建人、创建时间、最后修改时间、最后修改人。
- **行业描述**：单独区块展示，为空显示「-」。

#### B10-11 下游引用说明
**拟标注位置**：详情面板「下游引用说明」区｜**标记**：已确认

- **内容**：说明本行业的启用状态决定它是否出现在下游「适用行业 / 所属行业」下拉中；物料 / 能源为多选，产品信息 / 工艺流程 / 工序为单选必填；行业主数据变更不追溯已建核算项目。

#### B10-12 编辑行业
**拟标注位置**：清单操作列「编辑」、查看弹窗底栏「编辑」、详情面板「编辑」｜**标记**：已确认

- **操作目的**：修改行业信息，或把行业调整到另一个上级之下；任何状态均可编辑。
- **操作过程**：打开弹窗，标题「编辑行业」，带出现有内容；「上级行业」此时为下拉可选（新增锁定）；可修改行业编码、行业名称、上级行业、排序号、行业描述。
- **规则**：① 「行业层级」只读，随「上级行业」按「上级层级 + 1」重算；② 上级候选为**层级未达小类（非末级）**的行业，并**排除该行业自身及其全部下级**，避免成环；③ 下拉始终提供显式选项「无上级（门类）」，用于把行业改为门类；④ 使用状态不在表单中。
- **结果**：保存成功后弹窗关闭，提示「保存成功」，行业树与清单刷新。

#### B10-13 启用行业
**拟标注位置**：清单操作列「启用」、详情面板「启用」、确认弹窗｜**标记**：已确认

- **显示条件**：只在该行业当前为「禁用」时出现。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认启用」，正文「确认将行业『行业名称』（行业编码）启用？」；底栏「取消」与「确认启用」，不使用「确定」字样。
- **结果**：确认后该行业变为「启用」，提示「启用成功」，行业树与清单刷新；此时起可作为下游「适用行业 / 所属行业」候选。取消则状态不变。

#### B10-14 禁用行业
**拟标注位置**：清单操作列「禁用」、详情面板「禁用」、确认弹窗｜**标记**：已确认

- **显示条件**：只在该行业当前为「启用」时出现。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认禁用」，正文「确认将行业『行业名称』（行业编码）禁用？」，并提示「禁用后，下游『适用行业 / 所属行业』下拉中不再可选该行业；历史引用数据保留不变。」；底栏「取消」与「确认禁用」。
- **结果**：确认后该行业变为「禁用」，提示「禁用成功」；下游下拉不再可选该行业，历史引用数据保留。取消则状态不变。
- **说明**：本页**不提供删除**，禁用是唯一"退出"手段。

### 1.5 字段说明

#### B10-16 字段：上级行业
**拟标注位置**：表单「上级行业」内容旁，及查看 / 详情该行｜**标记**：已确认

- **业务含义**：该行业在分类树中的父级；为空表示门类。
- **填写方式**：新增门类 / 新增下级行业时**锁定为只读文本**；编辑时变为下拉可选。
- **可选范围**：**层级未达小类（非末级）**的行业（不限启用 / 禁用），并排除该行业自身及其全部下级；下拉始终提供显式选项「无上级（门类）」。
- **联动**：变更上级后，只读的「行业层级」立即按「上级层级 + 1」重算。

#### B10-17 字段：行业编码
**拟标注位置**：表单「行业编码」内容旁，及清单该列｜**标记**：已确认

- **业务含义**：行业的唯一业务标识。
- **填写方式**：手工填写，输入框提示「如 IND-0101」；可直接填国标 `GB/T 4754` 代码。
- **必填**：必填；为空提示「请输入行业编码」并阻断保存。
- **重复限制**：**全平台唯一**；与已有行业重复时保存被拦截（以接口校验为准）。

#### B10-18 字段：行业名称
**拟标注位置**：表单「行业名称」内容旁，及清单该列｜**标记**：已确认

- **业务含义**：行业的业务名称。
- **填写方式**：手工填写。
- **必填**：必填；为空提示「请输入行业名称」并阻断保存。
- **重复限制**：名称不要求同级唯一，允许重名。

#### B10-19 字段：行业层级
**拟标注位置**：表单「行业层级」内容旁，及清单 / 查看 / 详情该行｜**标记**：已确认

- **业务含义**：行业在树中的深度，展示为「门类 / 大类 / 中类 / 小类」，共四级。
- **来源**：**不由用户填写，随「上级行业」自动推导**（不选上级 = 门类，否则为上级层级 + 1）。
- **限制**：最多四级；末级（小类）不再提供「+ 新增下级行业」。

#### B10-20 字段：排序号
**拟标注位置**：表单「排序号」内容旁，及清单 / 查看 / 详情该行｜**标记**：已确认

- **业务含义**：决定同级行业的展示先后。
- **填写方式**：数字输入（自动过滤非数字），提示「越小越靠前，可留空」。
- **必填**：选填，默认为空。
- **排序口径**：同级内按排序号升序，**留空排在同级末尾**，清单中为空显示「-」。

#### B10-21 字段：行业描述
**拟标注位置**：表单「行业描述」内容旁，及查看 / 详情该区｜**标记**：已确认

- **业务含义**：行业的补充说明。
- **填写方式**：多行文本，提示「选填」，最长 **500 字符**。
- **必填**：选填。
- **展示**：查看弹窗与详情面板中展示，为空显示「-」；清单中不展示。

#### B10-22 使用状态（表单口径）
**拟标注位置**：清单「使用状态」列旁（引用 B10-03，不重复展开）｜**标记**：已确认

- 新增 / 编辑表单中**不出现**使用状态，用户不能在表单内改动它。

#### B10-24 弹窗的保存与取消
