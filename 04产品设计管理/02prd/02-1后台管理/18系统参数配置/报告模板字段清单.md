# 报告模板字段清单

> **文档定位**：报告模板字段定义的唯一真相源（SST）。业务 PRD 与 Demo PRD 只引用字段名称，不重复维护枚举、必填性与字段口径。
> **适用类型**：**配置类对象**（无审核流）—— 模板由研发线下整理并内置，后台仅维护模板信息、正文固定文字与启用状态。
> **原型基准（本版唯一依据）**：可运行原型 `06prototypes/系统原型/` → `src/pages/config/ReportTemplateListPage.tsx`、`src/pages/config/ReportTemplateFormPage.tsx`、`src/mock/config.ts` §3 报告模板；路由 `/config/report-template`
> **核心对象**：报告模板（`report_template`）→ 取值字段标签（`report_template_field`）→ 模板正文（`report_template_section` + 内容块）
> **模块归属**：后台管理（菜单「系统管理」）→ 系统参数配置 → 报告模板
> **核心用途**：决定报告正文的固定文字、取值字段标签的插入位置与模板启用状态；**不改变核算结果**
> **维护形态**：列表 + 详情 / 编辑页（模板信息 + 取值字段标签面板 + 富文本正文 + 预览弹窗）；**无「新建模板」入口，自定义模板仅由「复制」产生**
> **不做**：章节显隐 / 排序子表、固定文案子表、在线排版设计器（字体 / 页边距 / 图表样式）
> **成熟度**：定稿
> **版本**：V2.0
> **更新时间**：2026-11-10

## 0. 定位与边界

| 项 | 口径 |
| :--- | :--- |
| 管什么 | 模板名称 / 模板类型 / 适用行业 / 模板说明、正文固定文字与取值字段标签的插入、数据来源、启用状态 |
| 不管什么 | 取值字段编码与取值逻辑、系统装配内容、模板编号与版本生成、章节结构化显隐 / 排序、字体 / 页边距 / 图表样式 |
| 与报告生成的关系 | 生成报告时按启用模板装配正文，字段标签按编码自动取值；报告记录模板与版本，**存量报告不回溯** |
| 与核算的关系 | **无关系**。模板只影响报告呈现，不影响任何计算结果 |
| 系统预置模板 | 系统内置 1 个（`RPT-PCF-ZB13002-001`），整页只读，不可编辑 / 停用 / **删除**；仅可查看、预览、复制 |
| 自定义模板 | 由「复制」生成，可编辑、启用 / 停用、**删除** |
| **删除规则** | **按数据来源判定**：系统内置（系统预置）不允许删除 —— 列表不渲染删除入口，接口亦拒绝；自定义允许删除，**不要求先停用**（启用中的自定义模板亦可删）；删除需二次确认（危险态），删除后不可恢复 |

> 本期后台不做「边界 + 标准」的模板自动匹配与报告侧模板切换，后台仅维护模板启用状态；模板消费口径见《报告生成业务 PRD》。

## 1. 对象结构

```text
报告模板（report_template）  1 条 = 1 个模板
├── 模板信息：模板编号 / 名称 / 类型 / 适用行业 / 说明 / 数据来源 / 复制来源 / 状态 / 版本 / 更新时间
├── 取值字段标签（report_template_field，1:N，研发内置只读）
│   └── 标签编码 {{CODE}} / 字段名称 / 取值来源
└── 模板正文（report_template_section，1:N）
    ├── 章节编码 / 章节标题 / 是否锁定 / 是否显示
    └── 内容块：固定文字 text（可编辑） | 取值字段 field（锁定） | 系统装配 system（锁定）
```

| 结构 | 对象 | 关系 | 唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 报告模板 `report_template` | 顶层 | `template_no` | 一个模板一套标签与正文 |
| 子表 | 取值字段标签 `report_template_field` | 1:N | `(template_id, code)` | 研发线下打标签并内置，只读 |
| 子表 | 模板章节 `report_template_section` | 1:N | `(template_id, code)` | 富文本正文的初始章节结构 |
| 引用 | 行业库 | N:1 | `industry` | 可为空（空 = 全行业） |
| 引用 | 系统预置模板 | N:1 | `source_template_id` | 复制来源，仅自定义模板有值 |

## 2. 主表字段

表名：`report_template`

| 字段名 | 中文名 | 类型 | 必填 | 默认 | 说明 | 约束 | 写入时机 |
| :--- | :--- | :--- | :---: | :--- | :--- | :--- | :--- |
| id | 主键 | varchar(32) | 是 | 系统生成 | 预置模板与模板编号同值 | 全局唯一 | 新建 / 复制 |
| template_no | 模板编号 | varchar(32) | 是 | 系统生成 | 表单只读展示 | `RPT-YYYYMMDD-NNN`；全局唯一；预置模板固定 `RPT-PCF-ZB13002-001`（D01） | 复制 |
| template_name | 模板名称 | varchar(100) | 是 | 复制时为 `{原名称} 副本` | 列表主字段、详情链接 | 保存时唯一校验：非空（D02） | 编辑 |
| template_type | 模板类型 | varchar(20) | 是 | `碳足迹报告` | 列表展示 Tag，查询条件 | 枚举 `碳足迹报告` / `碳标签报告`（D03） | 编辑 |
| industry | 适用行业 | varchar(64) | 否 | 空 | 引用行业库；空展示为「全行业」 | 空 = 全行业（D04） | 编辑 |
| source | 数据来源 | varchar(16) | 是 | `自定义` | 列表 / 查询列「数据来源」Tag | 枚举 `系统预置` / `自定义`；系统写入不可编辑（D05） | 系统初始化 / 复制 |
| source_template_id | 复制来源 | varchar(32) | 否 | NULL | 记录被复制的模板 id | 仅 `source = 自定义` 时有值（D06） | 复制 |
| status | 状态 | varchar(16) | 是 | `disabled` | 列表 Tag：启用 / 停用 | 枚举 `enabled` / `disabled`，**两态、无草稿**（D08） | 启用 / 停用 |
| version | 版本号 | int | 是 | 1 | 表单由系统维护，只读展示 | 不可编辑（D12） | 复制 |
| remark | 模板说明 | varchar(200) | 否 | NULL | 表单 Textarea | ≤ 200 字（D13） | 编辑 |
| updated_at | 更新时间 | datetime | 是 | 当前时间 | 列表展示 `YYYY-MM-DD HH:mm` | 系统维护 | 保存 |
| boundary | 适用边界（保留） | varchar(20) | 否 | `全部` | Mock 数据结构中存在 | **界面未暴露**：列表 / 查询 / 表单均无此字段，本期不维护、不作为模板匹配键 | 数据初始化 |
| standard_no / standard_name | 适用标准（保留） | varchar(64) | 否 | 空 / `不限标准` | Mock 数据结构中存在 | **界面未暴露**：本期不维护、不校验标准文件库、不作为模板匹配键 | 数据初始化 |

> `boundary` / `standard_no` / `standard_name` 系原型 Mock 数据保留项，写在此处仅为说明数据现状；**不是本期可维护字段，也不构成需求**。

## 3. 取值字段标签（只读子表）

表名：`report_template_field`

| 字段名 | 中文名 | 类型 | 必填 | 说明 | 约束 |
| :--- | :--- | :--- | :---: | :--- | :--- |
| field_id | 标签 ID | varchar(16) | 是 | 模板内唯一 | 与内容块 `fieldId` 关联 |
| template_id | 所属模板 | varchar(32) | 是 | 引用 `report_template.id` | 随模板删除 |
| code | 标签编码 | varchar(32) | 是 | 如 `PRODUCT_NAME`，正文写作 `{{PRODUCT_NAME}}` | 研发内置白名单（D10） |
| label | 字段名称 | varchar(64) | 是 | 左侧面板展示名 | 只读 |
| source | 取值来源 | varchar(64) | 是 | 如「产品档案 / 基础信息」 | 只读，说明系统按什么业务来源取值 |

**原型内置标签白名单（9 个）**

| 编码 | 字段名称 | 取值来源 | 预览演示值 |
| :--- | :--- | :--- | :--- |
| `PRODUCT_NAME` | 产品名称 | 产品档案 / 基础信息 | 整竹砧板 ZB13002 |
| `PRODUCT_SPEC` | 产品规格型号 | 产品档案 / 基础信息 | Φ280 × 20 mm |
| `PRODUCER` | 生产者名称 | 企业信息 | 示例竹业有限公司 |
| `STANDARD` | 采用标准 | 核算配置 | GB/T 24067-2024 |
| `BOUNDARY` | 系统边界 | 核算配置 | 摇篮到大门 |
| `FUNCTIONAL_UNIT` | 声明单位 | 核算配置 | 1 件整竹砧板 |
| `UNIT_EMISSION` | 单位产品碳足迹 | 核算结果 | 2.36 kgCO₂e/件 |
| `TOTAL_EMISSION` | 合计碳排放 | 核算结果 | 23,600 kgCO₂e |
| `REPORT_NO` | 报告编号 | 系统生成 | PCF-2026-0001 |

> 标签由研发维护，后台不可新增、改名或删除；插入正文后生成 `contenteditable=false` 的只读节点，退格 / Delete 被拦截（D10）。

## 4. 模板正文与内容块

表名：`report_template_section`

| 字段名 | 中文名 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| section_id | 章节 ID | varchar(16) | 模板内唯一 |
| template_id | 所属模板 | varchar(32) | 随模板删除 |
| code | 章节编码 | varchar(32) | `SEC-*` |
| title | 章节标题 | varchar(100) | 富文本中渲染为三级标题 |
| locked | 是否锁定 | tinyint | 1 = 系统装配章节，标题带「系统装配 · 只读」标识 |
| visible | 是否显示 | tinyint | 原型全部为 1，无显隐操作入口 |
| blocks | 内容块 | json | `text` / `field` / `system` 三类（下表） |

| 内容块类型 | 可编辑 | 说明 |
| :--- | :---: | :--- |
| `text` 固定文字 | 是 | 正文固定文字，富文本编辑器内可增删改 |
| `field` 取值字段标签 | 否 | 点击左侧标签插入，插入后锁定；生成报告时按编码自动取值 |
| `system` 系统装配 | 否 | 核算结果 / 结论等由系统自动生成的内容，锁定 |

**原型预置模板正文基线（7 章，2 章锁定）**

| 顺序 | 章节编码 | 章节标题 | 锁定 | 内容块 |
| :---: | :--- | :--- | :---: | :--- |
| 1 | `SEC-INTRO` | 产品概述 | 否 | 固定文字 + `STANDARD` / `PRODUCT_NAME` / `PRODUCT_SPEC` / `PRODUCER` |
| 2 | `SEC-SCOPE` | 目标与范围 | 否 | 固定文字 + `FUNCTIONAL_UNIT` / `BOUNDARY` |
| 3 | `SEC-RESULT` | 核算结果 | **是** | 系统装配（清单分析表 / 阶段分布 / 单位碳足迹） |
| 4 | `SEC-CONCLUSION` | 结论与建议 | **是** | 系统装配（基于核算结果自动生成） |
| 5 | `SEC-METHOD` | 核算方法声明 | 否 | 固定文字 + `UNIT_EMISSION` / `TOTAL_EMISSION` |
| 6 | `SEC-DISCLAIMER` | 免责声明 | 否 | 固定文字 |
| 7 | `SEC-APPENDIX` | 附录 | 否 | 固定文字 |

> 章节在原型中仅用于生成富文本初始内容，**不提供章节子表、显隐勾选、拖拽排序或固定文案弹窗**；模板信息中「模板类型 / 适用行业 / 模板说明」可改，正文只改固定文字与插入标签。

## 6. 字段级约束

| 编号 | 约束 | 影响字段 |
| :--- | :--- | :--- |
| D01 | 模板编号 `RPT-YYYYMMDD-NNN` 由系统生成、全局唯一、表单只读；预置模板固定 `RPT-PCF-ZB13002-001` | `template_no` |
| D02 | 模板名称保存时唯一必填校验（非空），为空时红字提示「请填写模板名称」 | `template_name` |
| D03 | 模板类型二值单选；列表与查询区均可按类型过滤 | `template_type` |
| D04 | 适用行业可空，空 = 全行业；下拉取行业库选项 | `industry` |
| D05 | 数据来源由系统写入、不可编辑；`系统预置` 由系统初始化，`自定义` 由复制产生 | `source` |
| D06 | `source_template_id` 仅自定义模板有值，指向被复制的模板 | `source_template_id` |
| D07 | **删除规则**：仅 `source = 自定义` 渲染删除入口；系统预置不渲染删除按钮且接口拒绝删除。自定义模板删除**不受状态限制**（启用中也可删），需共享二次确认弹窗（危险态，文案「删除模板「{名称}」后不可恢复，是否删除？」），删除后不可恢复 | 整表 |
| D08 | 状态两态 `enabled` / `disabled`，**无草稿**；启用 / 停用均需二次确认；停用后不再用于新生成报告 | `status` |
| D09 | 复制：列表行「复制」→ `/config/report-template/new?copy={id}`，**无命名弹窗**；副本默认名 `{原名称} 副本`、`source = 自定义`、`status = disabled`、`version = 1`、新编号，深拷贝标签与章节内容块，记录 `source_template_id` | 整表 |
| D10 | 取值字段标签只读：编码 / 名称 / 取值来源由研发内置，后台不可增删改；插入正文后锁定，退格 / Delete 被拦截 | `report_template_field` |
| D11 | 系统装配内容块只读；锁定章节标题标注「系统装配 · 只读」 | `blocks` / `locked` |
| D12 | 模板编号、版本号由系统维护，表单只读展示 | `template_no` / `version` |
| D13 | 模板说明 ≤ 200 字 | `remark` |
| D14 | 正文：单一富文本编辑器（加粗 / 标题 / 列表 / 表格 / 插入字段标签，最小高度 520px），仅可改固定文字；系统预置模板为只读视图 | `blocks` |
| D15 | 「预览最终报告」把 `{{CODE}}` 替换为演示取值生成预览，**预览不保存任何修改** | 业务约束 |
| D16 | 保存仅校验模板名称非空；原型用内存态暂存正文 HTML，刷新页面不持久化（演示口径） | 业务约束 |
| D17 | 列表查询：模板名称（模糊）、模板类型、状态、数据来源，输入即生效；「搜索」仅反馈 Toast；分页 10 条/页 | 业务约束 |
| D18 | 本期无独立「新建模板」入口；空模板无标签与正文，须从列表「复制」已有模板后编辑 | 业务约束 |
| D19 | 存量报告不回溯：报告保存生成时的模板与版本，模板后续编辑 / 启停 / 删除不影响已生成报告 | 业务约束 |
| D20 | 模板变更不影响任何核算结果 | 业务约束 |

## 7. 表间关系

| 关系 | 基数 | 关联键 | 删除策略 |
| :--- | :--- | :--- | :--- |
| 报告模板 → 取值字段标签 | 1:N | `template_id` | 随模板删除 |
| 报告模板 → 模板章节 / 内容块 | 1:N | `template_id` | 随模板删除 |
| 报告模板 → 报告模板（复制来源） | N:1 | `source_template_id` | 源模板删除后置空，保留副本 |
| 行业库 → 报告模板 | 1:N | `industry` | 不级联 |
| 报告模板 → 报告 | 1:N（只读引用） | `template_no + version` | 报告保留快照，不跟随模板变更 |

## 8. 与 V1.0 的口径变更对照

> V1.0 依据 2026-10-27 的旧版原型（工作区根目录 `src/pages/config/` 副本，非可运行原型）编写；V2.0 起以 `06prototypes/系统原型/` 当前原型为准。

| 项 | V1.0（作废） | V2.0（原型为准） |
| :--- | :--- | :--- |
| 维护形态 | 章节子表（显隐 / 排序 / 固定文案弹窗） | 富文本正文 + 取值字段标签面板，无章节子表 |
| 状态 | 草稿 / 已启用 / 已停用 三态 | 启用 / 停用 两态 |
| 来源标识 | `is_preset`「是否预置」 | `source`「数据来源：系统预置 / 自定义」 |
| 模板类型 / 适用行业 | 无 | 有（Select，行业可空 = 全行业） |
| 适用边界 / 适用标准 | 查询项与模板匹配键 | 界面未暴露，仅 Mock 数据结构保留 |
| 新建入口 | 页头「新建模板」 | 无；自定义模板仅由「复制」产生 |
| 删除 | 草稿 / 停用可删，启用与预置不可删 | **系统预置不可删、自定义可删（不看状态）** |
| 复制 | 弹窗输入新名称 → 草稿态 | `?copy={id}` 直接进编辑页 → 停用态、默认名「副本」 |
| 章节基线 | 11 章 `S01–S11`，4 章锁定 | 7 章 `SEC-*`，2 章锁定（正文初始内容） |
| 变量 | 8 个中文占位符 `{产品名称}` 等 | 9 个英文编码 `{{PRODUCT_NAME}}` 等 |
| 模板编号 | `TPL-YYYYMMDDNNN` | `RPT-YYYYMMDD-NNN` |
