# 核算规则字段清单

> **文档定位**：核算规则字段定义的唯一真相源（SST）。业务 PRD 与 Demo PRD 只引用字段名称，不重复维护枚举、必填性与字段口径。
> **对齐依据（本版起）**：**以系统原型为准** —— `06prototypes/系统原型/src/pages/config/CalcRuleListPage.tsx`（列表）、`CalcRuleFormPage.tsx`（表单 / 详情）、`mock/config.ts`（`CalcRule` 接口、枚举、Mock 数据、摘要生成）、`ChangeLogModal.tsx`（留痕弹窗），以及下游 `ModelStepOne.tsx` / `ProjectStepOne.tsx` / `ModelStepTwo.tsx` / `ProjectStepTwo.tsx`。原型与旧版文档冲突时，一律按原型实际行为写入本文。
> **适用类型**：**配置类对象**（标准口径档案）—— **按标准号 = 一套规则**；**无审核流、无版本化、无单据下推**；变更不做修订号，用「变更留痕」表达。
> **核心对象**：核算规则（`calc_rule`）单表 + 变更留痕（`calc_rule_change_log`，原型为预留组件 / 数据，页面未挂入口）。
> **模块归属**：后台管理（菜单「系统管理」→ 系统参数配置 → 核算规则）；原型 `/config/calc-rule`、`/config/calc-rule/new`、`/config/calc-rule/:id`、`/config/calc-rule/:id/edit`。
> **核心用途**：结构化记录某标准规定的**取舍准则、可忽略排放项说明、分配方法与说明**，供列表 / 详情展示、表单内摘要预览文本生成，以及项目 / 模型步骤①「选择核算规则」时回显核算标准与取舍规则。**本对象不参与核算求值，不影响核算结果。**
> **维护形态**：列表（4 条件查询 + 6 列 + 行操作）+ 四段表单（基础信息 / 取舍准则 / 可忽略排放项 / 分配）+ 只读详情。
> **成熟度**：定稿
> **版本**：V2.0
> **更新时间**：2026-11-10

## 0. 对象结构

```text
核算规则（calc_rule）  1 条 = 1 个标准号
├── 基础信息：规则名称 / 标准号 / 标准名称（带出）/ 标准状态 / 适用行业 / 备注 / 规则状态 / 更新时间
├── 取舍准则：是否允许舍弃 / 单环节舍弃阈值 / 舍弃累计上限 / 补充说明
├── 可忽略排放项：单段多行文本（≤500 字）
├── 分配：是否允许分配（数据层）/ 分配方法 / 分配规则说明
└── 变更留痕（calc_rule_change_log，1:N，原型预留）
```

| 结构 | 对象 | 与主对象关系 | 唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 核算规则 `calc_rule` | 顶层 | `id`（原型中形如 `RULE-20261027001`） | 一个标准号对应一套规则（业务定位，见 D02） |
| 子表 | 变更留痕 `calc_rule_change_log` | 1:N | `id` | 组件 `ChangeLogModal` 与 Mock 数据已存在，**列表 / 表单页当前未挂载入口**（见 §8） |
| 引用 | 标准文件库（标准号 / 名称 / 状态）、行业库（适用行业） | — | 各编码 | 见 §7 |
| 下游 | 项目核算步骤①、模型步骤① / ②、报告详情 | — | `id` 存入下游 `calc_rule_no` | 见 §7 |

> **V1.0 → V2.0 结构变化**：删除忽略项清单子表 `calc_rule_ignore_item`、公式变量子表 `calc_rule_formula_var`；删除主表「取舍依据条款 / 必纳入贡献度阈值」「默认 GWP 口径整段」「计算公式整段」「分配层级 / 副产品处理 / 放弃原因开关 / 分配依据条款」「规则编号 `rule_no` / 修订号 `revision_no`」；状态由 `draft/enabled/archived` 改为 `draft/enabled/disabled`。详见 §9。

## 5. 派生与展示规则

### 5.1 摘要文本 `buildRuleSummary`

```text
【取舍准则】本标准不允许舍弃。                          ← allow_exclude = no
            舍弃单个环节影响 < {单环节}%；所有舍弃环节累计 < {累计}%。   ← allow_exclude = yes
【可忽略排放项】{ignore_rule || '—'}
【分配】不允许分配，无需配置分配规则。                    ← allow_allocate = no
        分配方法：{allocDefault}；说明：{allocRuleDesc || '—'}   ← allow_allocate = yes
```

- 表单「取舍准则」段底部只展示第一行（去掉「【取舍准则】」前缀），前缀为「摘要预览：」。
- 原型**无**摘要页、**无**导出规则摘要文件、**无** `{标准号}_核算规则摘要_V{修订号}.md` 命名。

### 5.2 下游「取舍规则」回显 `cutOffRuleTextOf`

```text
allow_exclude = no  → 「本标准不允许舍弃。」
allow_exclude = yes → 「单个环节影响 < {单环节}%；所有舍弃环节累计 < {累计}%。」+ 补充说明（如有）
```

- 项目核算步骤① / 模型步骤①选择规则后，写入其 `cutOffRule` 多行文本框，**可编辑**；同时按 `standard_no` 匹配标准文件库，回显「核算标准」（只读）。
- 报告详情页亦有「取舍规则」文本框。

## 6. 状态与行操作矩阵

| 当前状态 | 查看详情 | 编辑 | 启用 | 停用 | 删除 | 可被项目 / 模型选择 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| `draft` 草稿 | 是 | 是 | 是 | —（显示「启用」） | 是 | 否 |
| `enabled` 已启用 | 是 | 是 | — | 是 | **否** | 是 |
| `disabled` 已停用 | 是 | 是 | 是 | —（显示「启用」） | 是 | 否 |

| 操作 | 二次确认标题 | 确认文案 |
| :--- | :--- | :--- |
| 启用 | 确认启用 | 启用后规则「{rule_name}」可被模型只读引用，是否启用？ |
| 停用 | 确认停用 | 停用规则「{rule_name}」后将不再被模型引用，是否停用？ |
| 删除 | 确认删除 | 删除规则「{rule_name}」后不可恢复，是否删除？ |

> 状态闭环：`draft → enabled ⇄ disabled`，`draft / disabled → 启用 → enabled`；删除为终态。原型无 `archived`、无「重新启用（归档）」、无编辑保存触发的修订号 +1。

## 7. 表间关系

```text
标准文件库（standard_file）
   └── 核算规则（calc_rule）          1:1（业务定位）  standard_no
         └── 变更留痕（calc_rule_change_log）  1:N  rule_id（原型预留）

项目核算步骤① / 模型步骤①  ── 选择「已启用」规则 ──>  calc_rule.id 存入 calc_rule_no
        ├── 回显「核算标准」（按 standard_no 匹配标准文件库，只读）
        └── 回显「取舍规则」（cutOffRuleTextOf，可编辑）
模型 / 项目步骤②  ── 读取 allow_allocate ──>  门控「分配计算」入口（yes 才展示）
报告详情  ── 展示「取舍规则」文本
计算引擎  ── 无调用关系 ──>  calc_rule
```

| 关系 | 基数 | 关联键 | 说明 |
| :--- | :--- | :--- | :--- |
| 标准文件 → 核算规则 | 1:1 | `standard_no` | 标准状态带出并联动警示条；标准失效不自动停用规则 |
| 核算规则 → 变更留痕 | 1:N | `rule_id` | 原型有组件与数据，页面未挂入口 |
| 项目 / 模型 → 核算规则 | N:1（只读） | `id` → `calc_rule_no` | 仅 `enabled` 可选；只带回显文本与分配门控，**不传参给引擎** |
| 计算引擎 → 核算规则 | — | — | **无调用关系**（D15） |

## 9. V1.0 → V2.0 差异对照

| 项 | V1.0（旧文档口径） | V2.0（系统原型为准） |
| :--- | :--- | :--- |
| 表单分段 | 五段：取舍 / 忽略项 / GWP / 公式 / 分配 | **四段**：基础信息 / 取舍准则 / 可忽略排放项 / 分配 |
| 基础信息 | 规则编号 `rule_no`、修订号 `revision_no`、创建人等 13 字段 | 规则名称 / 标准号 / 标准名称 / 适用行业 / 备注 / 状态 / 更新时间；**无规则编号与修订号** |
| 取舍准则 | 允许舍弃 + 单环节 + 累计 + 必纳入贡献度 + 依据条款 + 补充说明 | 允许舍弃 + 单环节 + 累计 + 补充说明；**无必纳入贡献度、无依据条款、无阈值校验** |
| 忽略项 | 子表 `calc_rule_ignore_item`（对象类型 / 编码 / 忽略方式 / 理由 / 条款 / 排序） | **单段 ≤500 字文本** `ignore_rule` |
| GWP 口径 | 默认口径 / GWP 集 / 生物碳 / 结果单位 / 有效数字 | **整段删除** |
| 计算公式 | 方法 / 表达式 / 变量表 / 沙盒试算 | **整段删除** |
| 分配 | 层级顺序 / 默认方法（6 值）/ 副产品 / 放弃原因 / 依据条款 / 比例 100% | **分配方法（3 值）+ 分配规则说明**；数据层另有 `allow_allocate` |
| 状态 | `draft` / `enabled` / `archived`（归档） | `draft` / `enabled` / `disabled`（**停用**，可再启用） |
| 行操作 | 编辑 / 启用 / 归档 / 导出摘要 / 查看留痕 | 查看详情 / 编辑 / 启用或停用 / 删除（非启用态） |
| 列表列 | 规则编号 / 名称 / 标准号 / 行业 / 状态 / 修订号 / 更新时间 / 操作 | 规则名称（链接）/ 标准号 + 名称 / 适用行业 / 状态 / 更新时间 / 操作 |

| 枚举 | 13 组 | 8 组 |
