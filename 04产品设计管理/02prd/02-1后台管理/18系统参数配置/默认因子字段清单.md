# 默认因子字段清单

> **文档定位**：默认因子规则字段定义的唯一真相源（SST）。业务 PRD 与 Demo 只引用字段名称，不重复维护枚举、必填性与字段口径。
> **对齐依据（本版起）**：**以系统原型为准** —— `06prototypes/系统原型/src/pages/factor/DefaultFactorListPage.tsx`（列表 / 启停 / 批量启停 / 二次确认）、`DefaultFactorFormModal.tsx`（新增编辑弹窗）、`mock/config.ts` §2（`DefaultFactor` 接口、下拉常量、8 条演示数据）、`shared/components/Table.tsx`（`rowSelection` 行复选）。原型与旧版文档冲突时，一律按原型实际行为写入本文。
> **适用类型**：**配置类对象**（默认因子规则）—— **无审核流、无版本化、无单据下推**；一条规则 = 一个匹配键组合 → 一个因子引用。
> **核心对象**：默认因子规则（`default_factor_rule`）
> **模块归属**：后台管理（菜单「系统管理」→ 系统参数配置 → **默认因子**）；原型唯一路由 `/config/factor-default`；页面 `PageHeader` 面包屑为「因子库管理 / 默认因子」。
> **核心用途**：维护「类型 / 排放数据 → 默认因子」的**平台级**配置与启用状态。页面描述声明建模时用于预选推荐、可替换留痕；**当前原型未与建模页联调**，见 §6。
> **维护形态**：列表（6 条件查询 + 8 列 + 行操作 + 勾选批量启停）+ 新增 / 编辑弹窗；**无独立详情页、无只读反查入口**
> **数据性质**：前端 Mock（内存态），无后端接口、无持久化
> **成熟度**：定稿
> **版本**：V2.0
> **更新时间**：2026-11-10

## 0. 对象结构

```text
默认因子规则（default_factor_rule）  1 条 = 1 个匹配键组合 → 1 个因子
├── 匹配键：适用行业 + 生命周期阶段 + 类型 + 排放数据（编码 / 名称）+ 区域 + 适用年度
├── 目标因子：因子库 + 因子名称 + 生效版本 + 因子数值 + 因子单位
├── 优先级：整数（列表提示「数值越小越先命中」）
├── 状态：enabled / disabled / expired（仅由列表行操作与批量启停变更）
└── 备注 / 更新时间
```

| 结构 | 对象 | 关系 | 唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 默认因子规则 `default_factor_rule` | 顶层 | `id`（演示 `DF001`～`DF008`；新建 `DF${Date.now()}`） | 一条规则对应一个默认因子 |
| 取值源（Mock 常量） | 行业 / 阶段 / 类型 / 排放数据 / 区域 / 年度 / 因子库 / 可选因子 | — | 各常量 `value` | 原型不接后端库表；`OBJECT_OPTIONS` 按类型分组 |
| 派生展示 | 类型列 / 排放数据列 / 目标因子列 | — | — | 由主表字段拼接，不单独落表 |

> **V1.2 → V2.0 结构变化**：删除原型未定义的 `rule_no` / `rule_name` / `scope` / `tenant_id` / `locked_by_platform` / `expire_reason` / `created_by` / `created_at` / `updated_by`；补充 `factor_value`（因子数值）与 `object_name`（排放数据名称）；字段类型、必填性、默认值与控件形态全部按原型重写。详见 §7。

## 1. 主表字段

表名：`default_factor_rule`。字段名采用数据存储命名，并列出系统原型 `DefaultFactor` 接口属性名便于研发对齐。

| id | `id` | 主键 | varchar(32) | 是 | `DF${Date.now()}` | 系统生成，页面不展示 | 演示数据 `DF001`～`DF008`（D01） |

## 3. 列表与交互（原型实测）

### 3.1 查询区

| 顺序 | 字段 | 控件 | 逻辑 |
| :--: | :--- | :--- | :--- |
| 1 | 适用行业 | `Select`（全部 / 4 行业） | 等值过滤，空 = 不过滤 |
| 2 | 生命周期阶段 | `Select`（全部阶段 / 4 阶段） | 等值过滤 |
| 3 | 类型 | `Select`（全部 / 物料 / 能源） | 等值过滤 |
| 4 | 区域 | `Select`（全部 / 全国 / 浙江 / 福建 / 江西） | 等值过滤 |
| 5 | 适用年度 | `Select`（全部 / 不限 / 2023 / 2024 / 2025） | 等值过滤 |
| 6 | 状态 | `Select`（全部 / 已启用 / 已停用 / 已失效） | 等值过滤 |

- 过滤在 `useMemo` 中即时生效；「搜索」按钮仅 Toast `查询完成`；「重置」清空全部条件并回到第 1 页。
- 顶部告警条：存在 `expired` 时显示「有 N 条默认因子因引用因子失效而停用，请重新绑定」+「去处理」（点击把状态筛选置为 `expired`）。

### 3.2 表格列

| 顺序 | 列名 | 宽度 | 展示规则 |
| :--: | :--- | :--- | :--- |
| 1 | 勾选 | 44px | 表头「全选当前页」+ 行复选；`expired` 行禁用勾选；跨页保留已选 |
| 2 | 类型 | 100px | `objectType` 纯文本 |
| 3 | 排放数据 | 180px | `objectName \|\| objectCode`，单行省略 |
| 4 | 目标因子 | 260px | `{factorName} · {factorValue} {factorUnit}`，单行省略；**只展示名称 + 数值 + 单位，不含库名与版本** |
| 5 | 优先级 | 80px | 整数右对齐 |
| 6 | 状态 | 100px | `Tag`；`expired` 整行 `expired-row` 浅红底 |

- 分页：10 条/页。

### 3.3 行操作与批量操作

| 状态 | 编辑 | 启用 | 停用 | 删除 / 换因子 | 批量启停 |
| :--- | :---: | :---: | :---: | :--- | :---: |
| `enabled` 已启用 | 是 | — | 是 | 删除 | 可勾选 |
| `disabled` 已停用 | 是 | 是 | — | 删除 | 可勾选 |
| `expired` 已失效 | 是（换因子） | — | — | 换因子（打开编辑弹窗） | 不可勾选 |

- 单条启停与批量启停共用 `StatusAction { ids, status }` 与同一个二次确认弹窗；确认后逐条变更 `status` 与 `updatedAt`，清空勾选。
- 已失效、目标状态一致的记录跳过；原型按 `ids.length > 1` 判定是否为批量并生成文案。

### 3.4 二次确认与 Toast

| 触发 | 标题 | 正文 | 确认按钮 |
| :--- | :--- | :--- | :--- |
| 删除 | 确认删除 | 删除「{类型 / 排放数据}」后该配置将不再参与预选，是否删除？ | 确认删除（危险态） |
| 覆盖同键规则 | 覆盖已有规则 | 已存在相同配置的规则（{id}），是否覆盖保存？ | 覆盖保存 |
| 单条启停 | 确认启用 / 确认停用 | 对「{类型 / 排放数据}」执行启用 / 停用？ | 确认启用 / 确认停用 |
| 批量启停 | 确认批量启用 / 确认批量停用 | 对已勾选的 N 条默认因子规则执行启用 / 停用？ | 确认批量启用 / 确认批量停用 |

> 启停确认的 `tip`：启用「启用后参与建模预选；已失效规则需重新绑定因子，将被跳过」；停用「停用后不再参与业务端核算与预选；已失效规则将被跳过」。

| Toast | 文案 |
| :--- | :--- |
| 保存 / 查询 / 删除 | `保存成功` / `查询完成` / `已删除` |
| 启停成功 | `启用成功：1 条` / `停用成功：1 条`；批量时前缀「批量」，有跳过时追加「，跳过 M 条（已失效 / 状态未变化）」 |
| 无需变更 | `所选规则无需重复启用 / 停用` |

## 4. 字段级约束

| 编号 | 约束 | 影响字段 |
| :--- | :--- | :--- |
| D01 | 保存校验仅 3 项：`objectType` / `objectCode` / `factorName` 非空，分别 Toast「请选择类型」「请选择排放数据」「请选择目标因子」（error），不校验行业 / 阶段 / 区域 / 年度 / 优先级范围 | 三个必填字段 |
| D02 | 切换「类型」时清空 `objectCode`；`objectName` 由 `OBJECT_OPTIONS[objectType]` 的 `label` 带出，取不到时回退编码 | `objectType` / `objectCode` / `objectName` |
| D03 | 选择「因子库」时清空 `factorName`；选择「目标因子」后带出 `factorLib` / `factorVersion = 'V1'` / `factorValue` / `factorUnit`；因子下拉按所选库过滤 | 目标因子四项 |
| D04 | 唯一键 = `industry\|lifecycle\|objectType\|objectCode\|region\|year`；保存时若存在**同键且非 `expired`** 的其他规则，弹「覆盖已有规则」二次确认，确认后再保存 | 六个匹配键 |
| D05 | 新建默认 `enabled`；表单无状态控件；`expired` 为演示数据初始状态，原型**无自动置位逻辑**；编辑 `expired` 规则并更换 `factorName` 保存后恢复 `enabled` | `status` |
| D06 | 单条 / 批量启停均需二次确认；`expired` 不可勾选；跳过已失效与目标状态一致的记录并反馈条数；启停刷新 `updatedAt` | `status` / `updatedAt` |
| D07 | 删除需危险态二次确认，删除后移除行并清除勾选；`expired` 行不渲染删除，改为「换因子」 | `id` |
| D08 | 分页 10 条/页；查询条件变化回到第 1 页；表头全选仅作用于当前页 | 列表 |
| D09 | 全部规则平台级：原型无 `scope` / `tenant_id` / `locked_by_platform` 字段、无作用域列、无平台锁定列、无匹配测试入口、无匹配算法实现 | 规则级别 |
| D10 | 数据为前端 Mock：`fetchDefaultFactors()` 返回 Promise 浅拷贝，列表内 `setList` 更新，无接口、无持久化、无变更留痕、无导入导出 | 全局 |
