# 报告模板功能批注

> 原型是唯一的真实来源。凡原型已表现而现有文档未覆盖的，统一标记为「原型已表现·待核对」；尚未裁决的问题归入 §4.1；原型与文档不一致的点归入 §4.2。

## 0 说明

- **项**：报告模板（路由 `/config/report-template`、`/config/report-template/new?copy={id}`）
- **范围**：维护模板信息、正文固定文字与取值字段标签的插入位置、模板启用状态；取值字段编码与系统装配内容由研发内置，**不可改**。模板只影响报告呈现，**不改变核算结果**。
- **与其他功能关系**：上游为行业库（适用行业）；下游为报告生成（按启用模板装配正文）、报告（记录模板与版本，存量不回溯）。系统预置模板由研发线下整理并内置。
- **编号规则**：`RT-01` 起；RT-01 流程；RT-02~RT-04 操作；RT-10~RT-11 字段；RT-23 全局；RT-24~RT-26 待确认 / 同步 / 演示。
- **依据**：《报告模板字段清单 V2.0》《系统参数配置业务 PRD V0.5》《系统参数配置功能批注 V1.2》及当前原型（ReportTemplateListPage / ReportTemplateFormPage / mock/config.ts）。
- **标记口径**：已确认 / 原型已表现·待核对 / 待确认（仅 §4.1）。
- **版本记录**：V1.0（2026-11-10）初稿，以系统原型为准补全批注（去掉章节子表、状态收敛两态、删除规则按来源判定）。

## 4 待确认清单

### 4.1 需补充规则（待裁决，不作为需求依据）

1. 报告模板「固定文字」是否允许插入图片（Q03）。
2. 本期后台是否做「边界 + 标准」的模板自动匹配与报告侧模板切换（当前仅维护启用状态）。
3. 取值字段白名单后续是否扩充（当前 9 个固定编码）。

### 4.2 需原型同步调整（文档与原型差异）

1. 报告模板「复制为新模板」后副本是否自动置为自定义（原型表现如此，需固化）。
2. 各列表分页：文档 10 条/页，原型默认值需对齐。
3. Mock 数据保留 `boundary`（适用边界）/ `standard_no` / `standard_name` 字段但界面未暴露，需确认是否彻底移除或后续启用。
4. 正文固定文字插入图片能力是否需原型支持（待 Q03 裁决）。
