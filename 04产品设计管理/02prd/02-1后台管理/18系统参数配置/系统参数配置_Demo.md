# 系统参数配置（后台）_Demo

> **文档定位**：本模块前端 Demo 的实现规格。只定义**页面骨架、控件选型、交互、校验展示、Mock 数据、原型落点**；业务口径与验收标准见《系统参数配置业务 PRD》。
> **依赖文档（本文件不重复定义）**：
> - `系统参数配置业务PRD.md`（V0.7）— 业务规则 R-001～R-020、状态矩阵、验收 AC01～AC22
> - `核算规则字段清单.md` / `默认因子字段清单.md` / `报告模板字段清单.md` / `存储与消息配置字段清单.md` — 字段名、枚举、必填性、长度
> **维护形态**：混合型 —— 核算规则 / 报告模板为**独立列表 + 独立编辑页**；默认因子为**列表 + 弹窗**；存储配置为**单页表单**；消息配置为**单页 2 页签（站内信配置 / 消息模板配置）**
> **页面基准**：1440px 桌面端；最小有效宽度 1280px，低于该宽度表格区横向滚动，不承诺移动端
> **成熟度**：定稿
> **版本**：V1.4
> **更新时间**：2026-11-10

## 1. 全局约定

### 1.1 页面壳

| 项 | 规格 |
| :--- | :--- |
| 容器 | 内容区左右内边距 24px，最大内容宽 1440px，超出居中 |
| 分组容器 | 统一用 `Card`（白底 / 1px 边框 / 圆角 8px / 内边距 20px），卡片间距 16px |
| 页面标题 | `PageHeader`：标题在左，页面级主动作在右；副标题仅核算规则编辑页使用（显示规则编号 + 修订号） |
| 面包屑 | 列表页：`系统管理 / 系统参数配置 / 核算规则`；编辑页：`… / 核算规则 / 编辑规则` |
| 页签 | 仅消息配置使用，共 2 个（站内信配置 / 消息模板配置）；页签态写入 URL query（`?tab=inapp` / `?tab=template`），刷新保持 |
| 滚动 | 列表页整页滚动、表头吸顶；核算规则编辑页内容区独立滚动，右侧锚点导航 sticky |

### 1.2 按钮位置总表

| 位置 | 按钮 | 说明 |
| :--- | :--- | :--- |
| 页面标题区右侧 | 新建规则 / 新增默认因子 / 保存（配置页） | 页面级主动作，最多 2 个；**报告模板列表无「新建模板」，自定义模板仅由行「复制」进入** |
| 查询区右下 | 重置 → 搜索 | 顺序固定，右对齐 |

| 表格操作列（左对齐，`TextAction`） | 编辑 / 启用 / 停用 / 删除 / 归档 / 复制 / 查看留痕 | 不可用动作**不渲染**，不出现置灰假入口；默认因子已失效行仅显示「编辑 / 换因子」 |

### 1.3 表格通用

| 场景 | 规则 |
| :--- | :--- |
| 分页 | 默认 20 条/页，可选 20 / 50 / 100；显示「共 N 条」；**报告模板列表按当前原型为 10 条/页**（`PAGE_SIZE = 10`），详见 §4.1.2 |
| 空值 | 统一 `-`，禁止空串、`null`、中文破折号 |
| 主数据引用 | 有编码的展示 `{编码} {名称}`（如 `GB/T 24067-2024 温室气体 产品碳足迹…`） |
| 状态列 | `Tag` 组件；颜色仅辅助，文案取字段清单中文枚举 |
| 长文本 | 单行省略 + `title` 悬浮；详情/编辑页完整展示 |
| 时间 | `YYYY-MM-DD HH:mm` 列表展示，留痕用 `YYYY-MM-DD HH:mm:ss` |
| 数值 | 百分比右对齐保留 0–2 位（按字段清单），优先级整数右对齐 |
| 操作列 | 固定右侧，宽度 160px（核算规则 200px），超过 4 个动作收进「更多」`Dropdown` |
| 行高亮 | 仅「已失效」默认因子与「标准已失效」规则整行浅红/浅灰底，其余不加底色 |

### 1.4 弹窗通用

| 项 | 规格 |
| :--- | :--- |
| 结构 | 左标题 + 右 `×` → 标题下分割线 → 内容区（可滚动） → 底栏上分割线 → 按钮 |
| 宽度 | 常规 560px；默认因子编辑 720px；启停二次确认 560px；忽略项 640px；消息模板编辑 / 预览 560px |
| 关闭行为 | 有未保存修改时二次确认「放弃本次修改？」；只读弹窗直接关闭 |
| 层级 | 弹窗内不再叠加第三个弹窗（忽略项弹窗内不打开选择器弹窗，改用行内下拉搜索） |

### 1.5 反馈与二次确认

| 操作 | 反馈 | 文案 |
| :--- | :--- | :--- |
| 保存成功 | Toast success | `保存成功` |
| 启用规则 | Toast | `规则已启用` |
| 归档规则 | Toast | `规则已归档` |
| 启用 / 停用默认因子 | Toast | `启用成功：1 条` / `停用成功：1 条` |
| 批量启用 / 停用默认因子 | Toast | `批量启用成功：N 条，跳过 M 条（已失效 / 状态未变化）` |
| 导出摘要 | Toast + 下载 | `导出成功` |
| 测试连接成功 / 失败 | Toast 或卡片内结果条 | `连接成功` / `连接失败：{原因}` |
| 保存站内信配置 | Toast | `站内信配置已保存` |
| 保存消息模板 | Toast | `消息模板已保存` |
| 校验失败 | 字段下方红字 + 顶部汇总条（`共 N 项待修正`） | 见各页校验表 |
| 未知异常 | Toast error | `操作失败，请稍后重试` |

**二次确认弹窗文案**

| 触发 | 标题 | 正文 | 确认按钮 |
| :--- | :--- | :--- | :--- |
| 编辑已启用规则 | 确认修改 | 该规则已启用，修改后修订号 +1 并记录留痕，是否继续？ | 继续修改 |
| 归档规则 | 确认归档 | 归档后规则只读且不可编辑，重新启用后方可修改，是否归档？ | 确认归档 |
| 停用报告模板 | 确认停用 | 停用模板「{名称}」后，该模板将不再用于新生成的报告，是否停用？ | 确认停用 |
| 启用报告模板 | 确认启用 | 启用模板「{名称}」后，该模板可用于新生成的报告，是否启用？ | 确认启用 |
| 删除报告模板（仅自定义） | 确认删除 | 删除模板「{名称}」后不可恢复，是否删除？ | 确认删除 |
| 删除默认因子 | 确认删除 | 删除后该匹配键不再参与预选，是否删除？ | 确认删除 |
| 启用 / 停用默认因子 | 确认启用 / 确认停用 | 对「{匹配键}」执行启用 / 停用？启用后参与建模预选，停用后不参与 | 确认启用 / 确认停用 |
| 批量启用 / 停用默认因子 | 确认批量启用 / 确认批量停用 | 对已勾选的 N 条默认因子规则执行启用 / 停用？已失效规则将被跳过 | 确认批量启用 / 确认批量停用 |
| 覆盖同键默认因子 | 覆盖已有规则 | 该匹配键已存在规则（{规则编号}），是否覆盖？ | 覆盖保存 |

### 1.6 配置级别与权限

| 角色 | 可见范围 | 可编辑 |
| :--- | :--- | :--- |
| 平台运营管理员 | 平台级 | 全部；存储、站内信配置与消息模板仅此角色可改 |
| 专业配置人员 | 平台级 | 核算规则、默认因子、报告模板 |
| 组织管理员 | 本租户（`SUB_TREE`） | 复制后的模板；消息配置只读；默认因子只读 |
| 其他角色 | — | 菜单不可见 |

- 默认因子全部规则为**平台级**，作用于整个平台：不设作用域切换、不设租户级配置、不设平台锁定；列表与表单均不出现相关控件。
- 无编辑权限的页面：隐藏新建/编辑/保存/批量启停按钮；批量启停仅在未勾选时禁用，不出现其他假入口。

### 1.7 空态 / 加载 / 错误态

| 状态 | 表现 |
| :--- | :--- |
| 列表空（无数据） | 插画 + 主文案 + 主按钮（有权限时）；核算规则：`还没有配置核算规则` + `新建规则` |
| 列表空（筛选无结果） | `没有符合条件的记录` + `重置筛选` |
| 加载 | 表格骨架屏 5 行；配置页卡片骨架 3 块 |
| 加载失败 | 卡片内错误条 + `重新加载`，不整页白屏 |
| 段级校验失败 | 对应段卡片标题旁红色圆点 + 锚点导航项红点 |

### 1.8 假功能声明（必须落在 UI 与验收话术）

| 项 | UI 表现 | 说明 |
| :--- | :--- | :--- |
| 存储「测试连接」 | 正常返回「连接成功 / 失败」并刷新验证状态 | **Mock 实现**，不发真实网络请求；页面底部保留一行灰色说明：`当前为演示环境，存储未真实对接对象存储` |

| 邮件 / 短信通道 | 页面不出现 | 本期不做，无置灰入口 |

#### 2.1.2 查询区（6 列网格）

| 操作 | `draft` | `enabled` | `archived` | 点击结果 |
| :--- | :--: | :--: | :--: | :--- |
