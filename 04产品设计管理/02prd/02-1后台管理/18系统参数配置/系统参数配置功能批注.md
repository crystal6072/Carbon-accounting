# 系统参数配置功能批注

> 原型是唯一的真实来源。凡原型已表现而现有文档未覆盖的，统一标记为「原型已表现·待核对」；尚未裁决的问题归入 §4.1；原型与文档不一致的点归入 §4.2。

## 0 说明

- **项**：系统参数配置（路由 `/config`，含 核算规则 / 默认因子 / 报告模板 / 存储配置 / 消息配置）
- **范围**：系统级参数与模板的统一配置入口；本模块仅做标准口径记录与展示，多数配置不参与核算求值。消息配置本期简化为**仅站内信配置 + 消息模板配置**。
- **与其他功能关系**：上游为系统 / 平台预置数据；下游为核算、报告、存储、站内信通知。默认因子、存储、站内信配置为全局（平台级）；默认因子全部规则均为平台级，不设租户级、不设平台锁定；核算规则 / 报告模板含系统预置（只读）。
- **编号规则**：`CF-01` 起；CF-01~CF-03 各功能定位；CF-04 列表/查询/行操作（通用）；CF-08 二次确认；CF-10 核算规则字段；CF-12 报告模板字段；CF-13 存储配置；CF-14 消息配置；CF-23~CF-26 全局。
- **依据**：《系统参数配置业务 PRD》《核算规则字段清单》《默认因子字段清单》《报告模板字段清单》《存储与消息配置字段清单》及当前原型。
- **标记口径**：已确认 / 原型已表现·待核对 / 待确认（仅 §4.1）。
- **版本记录**：V1.0（2026-10-28）初稿，按原型补全批注；V1.1（2026-11-10）默认因子口径收敛：全部平台级、去掉平台锁定与匹配测试、新增启用停用与批量启停；V1.2（2026-11-10）消息配置简化为仅「站内信配置 + 消息模板配置」，同步 CF-14 / CF-23 与待确认清单。

## 4 待确认清单

### 4.1 需补充规则（待裁决，不作为需求依据）

1. 核算规则是否支持导入 / 批量维护（Q01）。
2. 系统预置核算规则由谁维护、可否被组织覆盖（Q02）。
3. 默认因子是否按更多维度（如产品）细化（衍生）。
4. 报告模板「固定文字」是否允许插入图片（Q03）。
5. 存储配置是否真实接入对象存储（Q04）。
6. 消息配置后续是否扩展更多事件或邮件通道（Q05）。

### 4.2 需原型同步调整（文档与原型差异）

1. 各列表分页：文档 20 条/页，原型默认值需对齐。
2. 默认因子「对象类型」原型为 物料/能源/运输，文档以对象类型为主维度，需确认运输类是否纳入。
3. 报告模板「复制为新模板」后副本是否自动置为自定义（原型表现如此，需固化）。
4. 消息配置本期只做站内信配置与消息模板配置，需确认顶栏铃铛演示数据与正式投递口径的衔接方式。
