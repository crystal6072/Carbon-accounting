# 默认因子功能批注

> 原型是唯一的真实来源。凡原型已表现而现有文档未覆盖的，统一标记为「原型已表现·待核对」；尚未裁决的问题归入 §4.1；原型与文档不一致的点归入 §4.2。

## 0 说明

- **项**：默认因子（菜单「系统管理 → 系统参数配置 → 默认因子」；唯一路由 `/config/factor-default`；页面面包屑为「因子库管理 / 默认因子」）
- **范围**：维护「类型 / 排放数据 → 默认因子」的**平台级**配置与启用状态。页面描述声明建模时用于预选推荐、可替换留痕；**当前原型未与建模页联调**。一条规则 = 一个匹配键组合 → 一个因子引用。
- **与其他功能关系**：上游为行业库、生命周期阶段、物料库 / 能源库、排放因子库、数据字典（取值均来自原型 Mock 常量，未接后端库表）；下游为项目建模（预选口径，原型未联调）；无作用域 / 租户级 / 平台锁定 / 匹配测试。
- **编号规则**：`YZ-01` 起；YZ-01 流程；YZ-02~YZ-04 操作；YZ-10~YZ-11 字段；YZ-23 全局；YZ-24~YZ-26 待确认 / 同步 / 演示。
- **依据**：《默认因子字段清单 V2.0》《系统参数配置业务 PRD V0.7》《系统参数配置功能批注 V1.2》及当前原型（DefaultFactorListPage / DefaultFactorFormModal / mock/config.ts）。
- **标记口径**：已确认 / 原型已表现·待核对 / 待确认（仅 §4.1）。
- **版本记录**：V1.0（2026-11-10）初稿，以系统原型为准补全批注（口径收敛：全部平台级、去作用域 / 锁定 / 匹配测试、新增启用停用与批量启停）。

## 4 待确认清单

### 4.1 需补充规则（待裁决，不作为需求依据）

1. 默认因子是否按更多维度（如产品）细化（Q01 衍生）。
2. 默认因子「推荐预选」是否接入项目建模、与 E03 阻断联动（T04，业务已确认一期接入，原型未联调）。
3. 因子下架 / 库下架 / 版本转历史是否自动置 `expired` 并写失效原因（原型未实现）。
4. 是否补匹配算法、精确度打分、只读反查与变更留痕后端接口（T08）。

### 4.2 需原型同步调整（文档与原型差异）

1. 默认因子「类型」原型仅 物料 / 能源 两项，旧版文档曾含 运输 / 排放物 / 不限，需确认是否扩充枚举（原型未做）。
2. 数据为前端 Mock，无接口、无持久化、无变更留痕、无导入导出、无只读反查（落地前需确认）。
3. 优先级原型无上限与范围校验；行业 / 区域 / 年度 / 优先级范围未校验。
4. 各列表分页：文档 10 条/页，原型默认值需对齐。
