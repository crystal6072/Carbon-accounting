# 存储与消息配置字段清单

> **文档定位**：存储配置与消息配置字段定义的唯一真相源（SST）。业务 PRD 与 Demo PRD 只引用字段名称，不重复维护枚举、必填性与字段口径。
> **适用类型**：**基础设施配置类对象** —— **无审核流、无版本化、无单据下推**；保存即生效（对新建数据）。
> **核心对象**：存储配置（`storage_config`）/ 存储用量（`storage_usage`，只读）/ 站内信配置（`message_inapp_config`）/ 消息模板（`message_template`）/ 站内信消息（`message_inbox`，只读）
> **模块归属**：后台管理（菜单「系统管理」）→ 系统参数配置 → 存储配置 / 消息配置；原型 `/config/storage`、`/config/message`
> **本期边界**：存储为**验收演示的模拟实现**（保存配置 + Mock 测试连接，**不接入真实对象存储**）；**消息配置简化为「站内信配置 + 消息模板配置」**：仅站内信通道，不做事件订阅矩阵、邮件 / 短信通道、频控 / 免打扰、发送记录、测试发送与失败重试；站内信在顶栏铃铛查看并可标记已读（T05 / T06 调整）
> **维护形态**：存储单页表单 + 用量表；消息单页 2 页签（站内信配置表单 + 消息模板列表 / 编辑弹窗）
> **成熟度**：定稿
> **版本**：V1.2
> **更新时间**：2026-11-10

---

## 0. 对象结构

```text
存储配置（storage_config）            全局唯一 1 条（平台级）
└── 存储用量（storage_usage）          1:N，按租户汇总，只读

消息配置
├── 站内信配置（message_inapp_config） 全局唯一 1 条（平台级）
└── 消息模板（message_template）       1 条 = 1 个内置事件的站内信模板

消费端（非配置对象）
└── 站内信消息（message_inbox）        N 条，顶栏铃铛只读展示，可标记已读
```

| 结构 | 对象 | 关系 | 唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 存储配置 `storage_config` | 全局 1 条 | `id`（固定 1） | 平台级，租户只读用量 |
| 只读表 | 存储用量 `storage_usage` | 1:N | `tenant_id` | 由附件管理统计写入 |
| 主表 | 站内信配置 `message_inapp_config` | 全局 1 条 | `id`（固定 1） | 平台级，控制是否产生新消息与保留天数 |
| 主表 | 消息模板 `message_template` | 全局 1:N | `event_code` | 7 个内置事件各 1 条，不可增删 |
| 只读表 | 站内信消息 `message_inbox` | 1:N | `id` | 铃铛展示，标记已读回写 `read_at` |

## 1. 存储配置

表名：`storage_config`（全表仅 1 条，`id = 1`）

| 字段名 | 中文名 | 类型 | 必填 | 默认 | 说明 | 约束 | 写入时机 |
| :--- | :--- | :--- | :---: | :--- | :--- | :--- | :--- |
| id | 主键 | bigint | 是 | 1 | 单例配置 | 固定为 1（D01） | 初始化 |
| storage_type | 存储方式 | varchar(16) | 是 | `local` | 底层存储类型 | 枚举 `local` 本地存储 / `object` 对象存储（D02） | 初始化、编辑 |
| endpoint | 服务地址 | varchar(200) | 否 | NULL | 对象存储 Endpoint | `storage_type = object` 时必填；URL 格式（D03） | 编辑 |
| region | 区域 | varchar(64) | 否 | NULL | 对象存储 Region | `storage_type = object` 时必填 | 编辑 |
| bucket | 存储桶 | varchar(100) | 否 | NULL | Bucket 名称 | `storage_type = object` 时必填；小写字母 / 数字 / 短横线（D04） | 编辑 |
| access_domain | 访问域名 | varchar(200) | 否 | NULL | CDN 或自定义域名 | 可为空（用默认域名） | 编辑 |
| path_prefix | 路径前缀 | varchar(100) | 否 | `pcf` | 对象键前缀 | 仅字母 / 数字 / `/` / `-` | 编辑 |
| access_key_id_enc | AccessKey ID | varchar(500) | 否 | NULL | 加密存储 | **不回显**，前端仅显示掩码（D05） | 编辑 |
| access_key_secret_enc | AccessKey Secret | varchar(500) | 否 | NULL | 加密存储 | **不回显**；不可逆查询（D05） | 编辑 |
| max_file_size_mb | 单文件上限 | int | 是 | 50 | 单个附件最大体积 | 1–500（D06） | 编辑 |
| allowed_extensions | 允许格式 | varchar(200) | 是 | `pdf,jpg,jpeg,png,xlsx,docx` | 白名单 | 逗号分隔；命中白名单外阻断上传（D07） | 编辑 |
| image_max_edge | 图片最大边长 | int | 否 | 2048 | 上传图片压缩阈值 | 200–8192；为空不压缩 | 编辑 |
| tenant_quota_gb | 租户容量配额 | int | 是 | 10 | 单租户可用容量 | 1–10240（D08） | 编辑 |
| max_attachment_per_tenant | 单租户附件数上限 | int | 否 | 5000 | 附件条数上限 | ≥ 1；为空不限 | 编辑 |
| overflow_policy | 超限策略 | varchar(16) | 是 | `warn` | 超配额时的行为 | 枚举 `warn` 仅告警 / `block` 禁止上传（D09） | 编辑 |
| retention_days | 附件保留期 | int | 是 | 0 | 业务附件保留天数 | 0 = 永久；> 0 时按天清理（D10） | 编辑 |
| recycle_bin_days | 回收站保留天数 | int | 是 | 30 | 删除后可恢复时长 | 0–365 | 编辑 |
| keep_report_forever | 报告与凭证永久保留 | tinyint | 是 | 1 | 是否豁免保留期 | 1 是 / 0 否（D11） | 编辑 |
| verify_status | 验证状态 | varchar(16) | 是 | `unverified` | 连通性测试结果 | 枚举 `unverified` / `verified` / `failed`（D12） | 测试连接、保存 |
| last_verify_at | 最近验证时间 | datetime | 否 | NULL | — | — | 测试连接 |
| last_verify_message | 最近验证信息 | varchar(500) | 否 | NULL | 成功提示或失败原因 | — | 测试连接 |
| updated_by | 更新人 | varchar(64) | 是 | 当前登录人 | — | — | 保存 |
| updated_at | 更新时间 | datetime | 是 | 当前时间 | — | — | 保存 |

> **模拟实现说明（T06 已确认）**：本表为**验收演示功能**。`verify_status` / `last_verify_at` / `last_verify_message` 由 Mock 服务写入——按预设规则返回结果（如 Endpoint 含 `invalid` 判失败），**不发起真实网络探测、不写入任何真实对象、不执行真实清理任务**。对外交付说明与验收文档必须标注「存储未真实对接」，不得以此宣称已完成对象存储接入。

## 3. 站内信配置（单例）

表名：`message_inapp_config`（全表仅 1 条，`id = 1`）

| 字段名 | 中文名 | 类型 | 必填 | 默认 | 说明 | 约束 | 写入时机 |
| :--- | :--- | :--- | :---: | :--- | :--- | :--- | :--- |
| id | 主键 | bigint | 是 | 1 | 单例配置 | 固定为 1（D13） | 初始化 |
| enabled | 是否启用 | tinyint | 是 | 1 | 是否产生站内信 | 1 启用 / 0 停用；停用后不再产生新消息，已有消息保留（D14） | 编辑 |
| retention_days | 消息保留天数 | int | 是 | 30 | 超过天数的消息可清理 | 0–365；0 = 永久（D15）；演示环境不执行真实清理 | 编辑 |
| updated_by | 更新人 | varchar(64) | 是 | 当前登录人 | — | — | 保存 |
| updated_at | 更新时间 | datetime | 是 | 当前时间 | — | — | 保存 |

> 站内信为**系统内置通道**：无 SMTP / 网关 / 密钥参数，无验证状态与「测试发送」。事件清单系统内置、接收人由事件自动确定，不配置接收对象、频控与免打扰。

## 4. 消息模板

表名：`message_template`（内置 7 条，事件唯一）

| 字段名 | 中文名 | 类型 | 必填 | 默认 | 说明 | 约束 | 写入时机 |
| :--- | :--- | :--- | :---: | :--- | :--- | :--- | :--- |
| id | 主键 | bigint | 是 | 雪花ID | — | — | 初始化 |
| event_code | 事件编码 | varchar(32) | 是 | 无 | 内置事件标识 | 枚举见 §6；全局唯一（D16）；不可增删 | 初始化 |
| event_name | 事件名称 | varchar(50) | 是 | 带出 | 展示名 | 系统内置，只读 | 初始化 |
| title | 消息标题 | varchar(100) | 是 | 无 | 支持变量 | ≤ 100 字；变量须在白名单内（D17） | 编辑 |
| content | 消息正文 | varchar(1000) | 是 | 无 | 支持变量 | ≤ 1000 字；变量须在白名单内（D17） | 编辑 |
| variable_codes | 变量清单 | varchar(300) | 否 | NULL | 标题 / 正文使用的变量（只读解析） | 自动解析 | 编辑 |
| status | 模板状态 | varchar(16) | 是 | `enabled` | 模板启停 | 枚举 `enabled` / `disabled`（D18） | 编辑 |
| updated_by | 更新人 | varchar(64) | 是 | 当前登录人 | — | — | 编辑 |
| updated_at | 更新时间 | datetime | 是 | 当前时间 | — | — | 编辑 |

> 唯一键：`event_code`（D16）。本期一个事件仅一条站内信模板，**不新增 / 删除模板**，只编辑标题、正文与启用状态。

## 5. 站内信消息（只读，消费端）

表名：`message_inbox`（顶栏铃铛展示）

| 字段名 | 中文名 | 类型 | 必填 | 说明 | 约束 |
| :--- | :--- | :--- | :---: | :--- | :--- |
| id | 主键 | bigint | 是 | 全局唯一 | — |
| event_code | 事件编码 | varchar(32) | 是 | 触发事件 | 引用内置事件 |
| title | 消息标题 | varchar(100) | 是 | 渲染后标题 | — |
| content | 消息正文 | varchar(1000) | 是 | 渲染后正文 | — |
| receiver_id | 接收人 ID | bigint | 是 | 由事件自动确定 | — |
| receiver_name | 接收人 | varchar(64) | 是 | 冗余展示 | — |
| sent_at | 发送时间 | datetime | 是 | 入库时间 | — |
| read_at | 已读时间 | datetime | 否 | 仅站内信 | 铃铛「标记已读」回写；未读为空 |

> 本表仅用于铃铛展示：不提供发送记录查询页、失败状态、失败原因、重试次数与测试发送。送达即入库，已读以 `read_at` 为准（D19）；演示环境为 Mock 数据，不随真实事件产生。

## 6. 枚举

| 枚举 | 字段 | 取值 | 展示 |
| :--- | :--- | :--- | :--- |
| 存储方式 | `storage_type` | `local` / `object` | 本地存储 / 对象存储 |
| 超限策略 | `overflow_policy` | `warn` / `block` | 仅告警 / 禁止上传 |
| 验证状态 | `verify_status` | `unverified` / `verified` / `failed` | 未验证 / 已验证 / 验证失败（仅存储） |
| 模板状态 | `message_template.status` | `enabled` / `disabled` | 已启用 / 已停用 |

**内置事件编码（模板归类用，不做订阅配置）**

| 事件编码 | 事件名称 | 默认接收 |
| :--- | :--- | :--- |
| `CALC_DONE` | 核算完成 | 项目创建人 |
| `CALC_FAILED` | 核算失败 | 项目创建人 |
| `CHECK_BLOCKED` | 检测存在阻断项 | 项目创建人 |
| `REPORT_GENERATED` | 报告生成完成 | 报告创建人 |
| `SHARED_DATA_UPDATED` | 共享数据集更新 | 关联项目负责人 |
| `MEMBER_CHANGED` | 成员 / 角色变更 | 组织管理员 |
| `QUOTA_WARNING` | 存储配额预警 | 组织管理员 |

**模板变量白名单（D17）**：`{产品名称}` `{项目编号}` `{报告链接}` `{租户名称}` `{用量}`。

## 7. 字段级约束

| 编号 | 约束 | 影响字段 |
| :--- | :--- | :--- |
| D01 | 存储配置为单例，`id` 固定 1，不允许新增记录 | `storage_config` |
| D02 | 存储方式两值；切换为 `object` 时二次确认并提示「仅影响新上传附件」 | `storage_type` |
| D03 | `storage_type = object` 时 `endpoint` / `region` / `bucket` 必填 | 连接参数 |
| D04 | Bucket 命名仅小写字母、数字、短横线，长度 3–63 | `bucket` |
| D05 | 密钥加密存储，任何接口不返回明文；前端仅展示掩码与「已配置」状态 | 两个密钥字段 |
| D06 | 单文件上限 1–500 MB | `max_file_size_mb` |
| D07 | 上传格式白名单外阻断，提示允许格式 | `allowed_extensions` |
| D08 | 租户容量配额 1–10240 GB | `tenant_quota_gb` |
| D09 | `overflow_policy = block` 时超配额阻断上传；`warn` 时放行并触发 `QUOTA_WARNING` | `overflow_policy` |
| D10 | 保留期 0 表示永久；> 0 时必须 ≥ 回收站天数 | `retention_days` / `recycle_bin_days` |
| D11 | `keep_report_forever = 1` 时报告与凭证不参与清理 | `keep_report_forever` |
| D12 | 修改连接参数后 `verify_status` 重置为 `unverified` | `verify_status` |
| D13 | 站内信配置为单例，`id` 固定 1，不允许新增记录 | `message_inapp_config` |
| D14 | 停用站内信后不再产生新消息，已有消息保留 | `enabled` |
| D15 | 消息保留天数 0–365，0 = 永久；演示环境不执行真实清理 | `message_inapp_config.retention_days` |
| D16 | 事件编码为内置枚举、不可增删；一个事件仅一条模板 | `message_template.event_code` |
| D17 | 模板标题 / 正文的变量仅允许白名单 5 个，其他变量保存时报错 | `title` / `content` |
| D18 | 停用模板后对应事件不再投递站内信 | `message_template.status` |
| D19 | 站内信送达 = 已入库；已读以 `read_at` 为准 | `message_inbox.read_at` |
| D20 | 所有配置变更写变更留痕（前值 / 后值 / 操作人 / 时间） | 全部 |
| D21 | 存储测试连接为模拟实现，不得对外声称已接入真实对象存储；验收文档须声明 | 业务约束 |
| D22 | 消息不做事件订阅矩阵、邮件 / 短信通道、频控 / 免打扰、发送记录查询、测试发送与失败重试；页面不出现相关入口 | 业务约束 |

> 原 V1.1 中 D13–D28 属于事件订阅 / 邮件通道 / 发送记录 / 重试的约束，随本期范围缩减一并作废，消息侧约束重编为 D13–D19。

## 8. 表间关系

| 关系 | 基数 | 关联键 | 删除策略 |
| :--- | :--- | :--- | :--- |
| 存储配置 → 存储用量 | 1:N | 配置为全局，用量按租户 | 用量随租户删除清理 |
| 站内信配置 → 站内信消息 | 1:N | 全局单例配置控制是否产生新消息 | 停用不删除已有消息 |
| 消息模板 → 站内信消息 | 1:N | `event_code` | 模板不可删；停用不删除已有消息 |
