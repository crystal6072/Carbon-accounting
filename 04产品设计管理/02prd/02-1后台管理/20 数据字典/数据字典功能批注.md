## 1. 拟添加的批注清单

### 1.1 整体流程

#### DD-01 数据字典整体流程
**拟标注位置**：功能标题「数据字典」附近（全局说明）｜**标记**：已确认

- **适用场景**：平台级枚举口径的统一维护入口。左侧维护「字典类型」，右侧维护该类型下的「字典项」；「系统边界」「租户类型」等字典被核算边界、租户开户等业务引用。
- **流程**：左侧选择字典类型（内置类型标「内置」）→ 右侧按编码 / 名称查询该类型下的字典项 → 「新增字典项」维护取值 → 「编辑 / 禁用 / 启用 / 删除」管理状态 → 需要时「新增类型」扩展新字典类型。
- **分支**：禁用 / 删除经二次确认后生效。
- **结束**：保存后立即生效并刷新列表（原型为内存态，刷新页面回到初始）。

### 1.2 全局规则说明

#### DD-02 全局规则
**拟标注位置**：功能标题「数据字典」附近（与整体流程同一全局说明入口）｜**标记**：原型已表现·待核对

1. **平台级口径**：本页维护平台级枚举字典；被核算边界、租户开户等业务引用。
2. **两级结构**：字典类型（分类）+ 字典项（取值）；同一类型下的字典项编码唯一。
3. **内置类型**：如 `system_boundary` 由系统预置、用户不可新增；内置类型在类型列表标「内置」标签。
4. **字典项编码稳定性**：同一类型下唯一，一经被业务引用建议不再修改，以免破坏引用关系。
5. **无流程节点**：没有提交、审核、驳回，也没有操作日志入口。

### 1.3 业务状态说明

#### DD-03 字典项状态
**拟标注位置**：字典项列表「状态」列旁｜**标记**：已确认

- **状态**：启用 / 禁用。启用 = 可被业务引用；禁用 = 不再出现在新的引用选择中。
- **进入条件**：新增保存后默认为「启用」；「启用」由禁用态经行操作「启用」进入；「禁用」由启用态经行操作「禁用」进入。
- **可进行的操作**：无论启用还是禁用，都可「编辑」；禁用态多出「启用」与「删除」，启用态多出「禁用」。
- **对下游影响**：字典项一旦禁用，新的引用不能再选它；已引用该字典项的历史数据保留。

### 1.4 操作功能及对应业务规则

#### DD-04 字典类型选择
**拟标注位置**：左侧字典类型区 / 「新增类型」｜**标记**：已确认

- 类型区列出全部字典类型，内置类型标「内置」；点击类型后右侧切换为该类型下的字典项列表。
- 「新增类型」打开抽屉表单，录入字典类型编码 / 名称 / 说明；编码需全局唯一、大写字母开头。

#### DD-05 字典项查询与重置
**拟标注位置**：查询区｜**标记**：已确认

- 查询项：字典项编码（精确 / 前缀匹配）、字典项名称（模糊匹配）。两者叠加过滤；「搜索」执行、「重置」清空。
- 查询仅作用于当前选中的字典类型。

#### DD-06 字典项列表与操作
**拟标注位置**：字典项表格 / 操作列｜**标记**：已确认

- 展示列：字典项编码、字典项名称、排序号、状态、说明、操作。
- 操作：编辑（修改名称 / 排序号 / 说明 / 状态）、禁用 / 启用（切换可用状态，二次确认）、删除（移除字典项，二次确认）。

#### DD-07 新增 / 编辑字典项
**拟标注位置**：字典项弹窗表单｜**标记**：已确认

- 字段：所属字典类型（只读，显示当前类型编码 + 名称）、字典项编码（必填、同类型唯一）、字典项名称（必填）、排序号（必填、数值越小越靠前）、说明（选填）。
- 编码 / 名称 / 排序号必填校验通过后保存；保存中按钮禁用防重复提交。

#### DD-08 新增字典类型
**拟标注位置**：类型弹窗表单｜**标记**：已确认

- 字段：字典类型编码（必填、全局唯一、大写字母开头、仅含大写字母 / 数字 / 下划线，输入自动转大写）、字典类型名称（必填）、说明（选填）。
- 保存后该类型出现在左侧类型列表；内置类型由系统预置、用户不可新增。

#### DD-09 删除 / 禁用二次确认
**拟标注位置**：确认弹窗｜**标记**：已确认

- 删除 / 禁用 / 启用操作前弹出二次确认：展示目标字典项的名称与编码，确认后方可执行，取消则不改动。
- 删除为物理删除；若该字典项已被业务引用（如系统边界、租户类型），删除可能破坏引用，操作前需评估。

| 编号 | 问题 | 当前原型表现 |
| :--- | :--- | :--- |
| D-01 | 内置字典类型（如 system_boundary）是否允许编辑 / 删除 | 原型仅「新增类型」对自定义类型开放；内置类型标「内置」，未提供编辑 / 删除入口 |

| D-03 | 字典项是否支持跨类型移动 | 原型未提供移动能力，编码绑定所属类型 |
