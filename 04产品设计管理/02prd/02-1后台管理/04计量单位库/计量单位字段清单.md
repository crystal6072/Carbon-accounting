| 约定 | 说明 |

| **不设「是否可换算」字段** | 「单位类型能否换算」是**系统内置规则**：数量类不可换算（件 / 双 / 个 之间无固定换算），其余类型可换算。不开放为用户字段 |

## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 计量单位库 |
| 业务归属 | 后台管理 → 基础库 → 计量单位库（方案 §2.3 A1-9、§4.2.3、§八 P11） |
| 模块类型 | 基础数据维护（一本**单位字典**），**非业务单据、无审核流、无版本化** |
| 核心对象 | 计量单位（单一对象，无子表） |
| 核心职责 | ① 统一填报口径 ② 支撑单位换算（否则 `活动数据 × 排放因子` 无法计算，触发 **E04**）③ 统一功能单位与结果口径 ④ 支撑质量平衡校验（方案 §4.2.3） |

### 1.2 对象结构

| 结构 | 对象 | 与主对象关系 | 主键/唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 计量单位 | 主对象 | 单位符号 + 单位类型 | **单一对象，无子表**；换算信息以字段形式挂在单位上（关联基准单位 + 换算系数） |
| 字典 | 单位类型 | — | 类型编码 | **系统内置枚举**，不开放维护 |
| 只读反查 | 引用情况 | — | — | 引用本单位的物料 / 能源 / 工序 / 产品 / 因子清单（用于禁用与删除约束） |

**换算机制：基准中转（【待确认 Q01】）**

```text
每个单位类型先指定 1 个基准单位（如重量 → 千克）。
其他单位只记录「自己相对基准单位的系数」。
两个单位互转时，系统自动经基准单位走两步：

    值_B = 值_A × 系数_A ÷ 系数_B

重量类型示例：
    千克：基准，系数 1
    吨  ：系数 1000        ⇒ 1 吨 = 1000 千克
    克  ：系数 0.001       ⇒ 1 克 = 0.001 千克

    吨 → 克：1000 ÷ 0.001 = 1,000,000  ⇒ 1 吨 = 1,000,000 克 ✅

为什么这样做：N 个单位只需 N 条记录；不会出现「吨→克」与「克→吨」互相矛盾的情况。
```

> 备选口径（方案 §4.2.3 原文）：为每两个单位单独维护一条换算关系。代价是维护量按 N² 增长，且需额外校验矛盾关系。**取舍见 §9 Q01。**

### 1.3 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | **系统预置**（平台运营维护，全体租户只读） + **组织自建**（组织管理员维护，本组织可编辑） |
| ERP是否数据源 | 否 |
| 新增编辑 | 支持（系统预置单位仅平台运营可维护） |
| 子表 | 无 |
| 导入导出 | 导出：支持；导入：V0.1 不支持（【待确认 Q09】） |
| 状态与执行 | 使用状态（启用 / 禁用）；**无版本化、无审核流、无外部系统推送、无单据下推** |
| 关键唯一键 | 「单位符号 + 单位类型」唯一；每个类型下「基准单位」唯一 |
| 历史兼容 | 单位变更不追溯已有核算结果；需按新口径重算时走 **E13**（方案 §5.4 / §4.9） |

### 1.4 关键数据约束

| 约束ID | 约束 | 影响对象 |
| :--- | :--- | :--- |
| D01 | 「单位符号 + 单位类型」唯一；符号不得为空、不得含空格 | 主表 |
| D02 | **每个单位类型下有且仅有 1 个基准单位**；基准单位不可禁用、不可删除、不可改类型 | 主表 |
| D03 | 非基准单位的「关联基准单位」必须是**同类型**的基准单位，不允许跨类型 | 主表 |
| D04 | 换算系数必须为**正数**（不允许 0 / 负数）；基准单位的系数恒为 1 且不可编辑 | 主表 |
| D05 | 数据来源 = 系统预置时，租户**只读**（不可编辑 / 禁用 / 删除） | 主表 |
| D06 | 数量类类型下，任意两单位之间**不可换算**（系统内置规则，不设字段） | 主表 |
| D07 | **跨类型换算一律不支持**（如 体积 m³ ↔ 重量 kg 需密度，本期不做）→ 判定不可换算，触发 **E04** | 主表 |
| D08 | 已被引用的单位**不可删除、不可禁用**（避免历史数据口径漂移，【待确认 Q05】） | 主表 |

## 5. 枚举值

### 5.1 单位类型（系统内置，共 8 类）

| 枚举值 | 含义 | 基准单位 | 是否可换算 | 备注 |
| :--- | :--- | :--- | :---: | :--- |
| 重量 | 质量类 | `kg` 千克 | 是 | t / kg / g / mg |
| 能量 | 能量类 | `kWh` 千瓦时 | 是 | kWh / MJ / GJ / kcal；**「吨蒸汽」类应经能源库热值折算**，不在本模块做 |
| 距离 | 长度类 | `km` 千米 | 是 | km / m |
| 体积 | 体积类 | `m³` 立方米 | 是 | m³ / L |
| 面积 | 面积类 | `m²` 平方米 | 是 | m² / ha |
| 时间 | 时间类 | `h` 小时 | 是 | h / min / s |
| 数量 | 计件类 | **无基准单位** | **否** | 个 / 件 / 双 / 套 —— 彼此不可互换，各自独立 |
| 碳排放量 | 结果表达单位 | `kgCO₂e` | 是 | gCO₂e / kgCO₂e / tCO₂e；本期 CO₂e ≡ CO₂（**已确认 Q03 单列**） |

### 5.2 数据来源

| 枚举值 | 含义 | 是否默认 | 备注 |
| :--- | :--- | :---: | :--- |
| 系统预置 | 平台统一维护的单位 | 否 | 全平台只读，租户可引用 |
| 组织自建 | 租户自行维护的单位 | 是 | 本组织可编辑，上级可见 |

### 5.3 使用状态

| 枚举值 | 含义 | 是否默认 | 备注 |
| :--- | :--- | :---: | :--- |
| 启用 | 可被业务选用 | 是 | 新增默认启用 |
| 禁用 | 不可被新业务选用 | 否 | 基准单位、系统预置单位、已被引用的单位不可禁用 |
