## 1. 拟添加的批注清单

### 1.1 整体流程

#### B07-01 单位维护整体流程
**拟标注位置**：功能标题「计量单位库」附近（全局说明）｜**标记**：已确认

- **适用场景**：在后台维护一本统一的单位字典，作为物料、能源、工序、产品、排放因子的单位引用源，并支撑单位换算。
- **流程**：进入计量单位库 → 清单按单位类型分组展示全部单位 → 按需查询、点名称进详情核对 → 新增或编辑单位 → 用「启用 / 禁用」控制能否被新业务选用。
- **分支**：新增 / 编辑走**独立页面**（非弹窗）；查看走**独立详情页**；详情页也可直接「编辑」「启用 / 禁用」。
- **衔接**：清单点单位名称进入详情；详情 / 编辑页均可「返回列表」或浏览器返回。
- **结束**：保存后立即生效并跳转到详情 / 列表。全程没有提交、审核、驳回。

### 1.2 全局规则说明

#### B07-02 全局规则
**拟标注位置**：功能标题「计量单位库」附近（与整体流程同一全局说明入口）｜**标记**：已确认（权限为待确认，见 §3）

1. **一本单位字典**：本页维护统一的单位字典；单位是核算引擎的底层依赖，**设计以简单为目标**，不做类型维护、不做公式换算。
2. **单位类型系统内置**：单位类型共 **8 类**（重量 / 能量 / 距离 / 体积 / 面积 / 时间 / 数量 / 碳排放量），为**系统内置枚举，不开放维护**；「碳排放量」单列一类（gCO₂e / kgCO₂e / tCO₂e）。
3. **不设数据来源 / 引用状态**：单位字典统一由平台维护，**不设「系统预置 / 组织自建」数据来源字段**，所有单位对有权进入本模块的用户同等可编辑（相对方案 §3.3.3 为有意偏离）。
4. **基准单位规则**：每个单位类型（**「数量」除外**）有且仅有 **1 个基准单位**；基准单位**不可禁用、不可删除、不可改类型**，换算系数恒为 1；「数量」类无基准单位、各单位相互独立。
5. **非基准单位**：必须关联**同类型**的基准单位，并填写相对于基准单位的**换算系数（正数）**。
6. **唯一键**：**「单位符号 + 单位类型」唯一**；单位符号不得包含空格；单位名称不要求唯一。
7. **编辑锁定**：**单位类型与「是否基准单位」在编辑时不可修改**（仅在新增时确定）。
8. **引用不阻断**：「引用情况」仅作详情页只读反查，**不据其阻断禁用 / 删除**（禁用 / 删除仅按「是否基准单位 + 使用状态」判定）。
9. **变更不追溯**：编辑为直接覆盖，不保留历史版本；修改已被引用单位的换算系数需二次确认，**已核算项目既有结果不变、不自动重算**，需按新口径重算走 **E13**。
10. **无流程节点**：没有提交、审核、驳回，也没有操作日志入口。

### 1.3 业务状态说明

#### B07-03 使用状态
**拟标注位置**：清单「使用状态」列旁｜**标记**：已确认

- **含义**：单位只有「启用」「禁用」两个状态。启用 = 可被新业务选用；禁用 = 不再出现在新业务的单位选择中。
- **进入条件**：新增保存后默认为「启用」；「启用」由禁用态经行操作「启用」进入；「禁用」由启用态经行操作「禁用」进入。
- **可进行的操作**：无论启用还是禁用，都可以「查看」「编辑」；禁用态多出「启用」与「删除」，启用态多出「禁用」。
- **基准单位例外**：**基准单位不可禁用**（受保护），其操作列不出现「禁用 / 删除」。
- **状态变化**：启用与禁用双向可达、可反复切换；变更状态只刷新使用状态与更新时间，不改动其他内容。
- **对下游的影响**：单位一旦禁用，新的业务不能再选它；**已引用该单位的历史数据不受影响**。
- **删除前提**：删除仅对「已禁用」的**非基准**单位开放，删除不可恢复。

### 1.4 操作功能及对应业务规则

#### B07-04 清单
**拟标注位置**：清单表格区域与清单上方工具条｜**标记**：已确认

- **展示内容**：单位名称、单位符号、单位类型、基准标记、关联基准单位、换算系数、使用状态、操作。
- **展示规则**：① 每页 **20 条**；② 列表**按单位类型分组展示**，类型顺序固定（重量 → 能量 → 距离 → 体积 → 面积 → 时间 → 数量 → 碳排放量），**组内基准单位排在前面**。
- **工具条**：左侧显示「单位字典」与「共 N 条 · 已选 N 条」及口径提示；右侧为「批量启用」「批量删除」。
- **操作列**：「查看」「编辑」恒显示；「禁用」（启用态且非基准）、「启用」（禁用态）、「删除」（禁用态且非基准）按条件显示。
- **勾选**：行首复选框 + 表头「全选当前页」；勾选按当前列表求交集，被删除 / 筛掉的条目自动移出选择集。

#### B07-05 查询与重置
**拟标注位置**：清单上方查询区｜**标记**：已确认（搜索按钮行为为原型已表现·待核对）

- **查询项**：① 单位名称 —— 包含关系模糊匹配；② 单位符号 —— 包含关系模糊匹配、忽略大小写；③ 单位类型 —— 下拉（8 类）；④ 使用状态 —— 下拉「启用 / 禁用」，不选即为全部。
- **规则**：多个条件同时生效（叠加过滤）；任一条件变化后清单回到第 1 页；「重置」清空全部条件并恢复完整清单。
- **搜索按钮**：点「搜索」执行一次当前条件的筛选。
- **原型表现（待核对）**：原型中点「搜索」仅出现一次「查询完成」提示、不产生额外动作（条件输入后清单已即时收敛）。需确认正式需求是「点击后查询」还是保留「即时筛选 + 按钮共存」。

#### B07-06 新增单位
**拟标注位置**：页头「新增」按钮旁｜**标记**：已确认

- **操作目的**：建立一个新的单位字典记录。
- **入口**：页头「新增」，进入独立新增页；恒可操作。
- **操作过程**：填写单位名称、单位符号，选择单位类型，按需设定「是否基准单位」、关联基准单位、换算系数、备注。
- **结果**：保存成功后提示「保存成功」并进入该单位详情页，使用状态为「启用」。
- **取消或失败**：点「取消」或浏览器返回不保存；校验不通过时给出提示（见 B07-16）。

#### B07-07 单位详情
**拟标注位置**：详情页「基本信息」区｜**标记**：已确认

- **操作目的**：只读核对某个单位的完整信息与换算关系。
- **入口**：清单点单位名称；任何状态均可查看。
- **展示内容**：基本信息（单位名称、单位符号、单位类型、基准标记、关联基准单位、换算系数、换算关系、使用状态、备注）+ 引用情况 + 制单信息。
- **换算关系**：以一句话描述，如 `1 t = 1000 kg`；基准单位显示「基准单位，换算系数恒为 1」；「数量」类显示「数量类无基准单位，不可换算」。
- **底栏操作**：「返回列表」；「禁用 / 启用」按当前状态二者只出现其一（基准单位不出现）；「编辑」进入编辑页。

#### B07-08 引用情况（只读反查）
**拟标注位置**：详情页「引用情况」区｜**标记**：已确认

- **操作目的**：查看哪些下游模块 / 对象引用了本单位。
- **展示内容**：引用模块、引用对象、引用字段；顶部显示「共 N 条 · 只读反查，仅作参考」。
- **规则**：**只读反查，仅作参考**，不作为删除 / 禁用的阻断条件；无引用时显示「暂无下游引用」。

#### B07-09 编辑单位
**拟标注位置**：清单操作列「编辑」、详情页「编辑」｜**标记**：已确认

- **操作目的**：修改单位信息；任何状态均可编辑，不区分启用与禁用。
- **操作过程**：进入独立编辑页，带出现有内容；**单位类型与「是否基准单位」为只读，不可修改**；可修改单位名称、单位符号、关联基准单位、换算系数、备注。
- **换算系数变更（R-010）**：修改**非基准单位**的换算系数并保存时，弹二次确认「确认保存」，正文「单位『X』的换算系数已变更，将影响该单位后续参与核算的口径。」，提示「已核算项目的既有结果不变，不自动重算；需按新口径重算时走 E13（R-010）。」；确认后才真正保存，取消则不保存。
- **结果**：保存成功后提示「保存成功」并进入详情页。

#### B07-10 启用单位
**拟标注位置**：清单操作列「启用」、详情页「启用」、确认弹窗｜**标记**：已确认

- **显示条件**：只在该单位当前为「禁用」时出现（基准单位不会被禁用，故不涉及）。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认启用」，正文「确认启用单位『单位名称』（单位符号）？」，提示「启用后该单位可被新的业务选用。」；底栏「取消」与「确认启用」，不使用「确定」字样。
- **结果**：确认后变为「启用」，提示「启用成功」，列表 / 详情刷新。取消则状态不变。

#### B07-11 禁用单位
**拟标注位置**：清单操作列「禁用」、详情页「禁用」、确认弹窗｜**标记**：已确认

- **显示条件**：只在该单位当前为「启用」**且非基准单位**时出现；**基准单位受保护，不显示禁用入口**。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认禁用」，正文「确认禁用单位『单位名称』（单位符号）？」，提示「禁用后该单位不可被新的业务选用；已引用该单位的历史数据不受影响。禁用后可执行删除。」；底栏「取消」与「确认禁用」。
- **结果**：确认后变为「禁用」，提示「禁用成功」；禁用后非基准单位出现「删除」入口。取消则状态不变。

#### B07-12 删除单位
**拟标注位置**：清单操作列「删除」、确认弹窗｜**标记**：已确认

- **显示条件**：**仅对该单位为「已禁用」且非基准单位时显示**；启用态与基准单位均不出现删除入口。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认删除」，正文「确认删除单位『单位名称』（单位符号）？」，提示「删除为不可逆操作。仅『已禁用』的非基准单位可删除；基准单位受保护不可删除（R-003）。」。
- **结果**：确认后删除，提示「删除成功」，列表刷新；删除不可恢复。取消则不删除。

#### B07-13 批量启用 / 批量删除
**拟标注位置**：清单工具条「批量启用」「批量删除」、批量确认弹窗、批量结果弹窗｜**标记**：已确认

- **操作目的**：对勾选的多条单位一次性启用或删除。
- **可操作条件**：需先勾选至少一条；未勾选时按钮不可点。
- **操作过程**：点击「批量启用」或「批量删除」→ 二次确认弹窗，正文「将对已勾选的 N 条单位执行批量启用 / 删除？」；批量启用提示「启用后该批单位可被新的业务选用；基准单位开关不适用。」，批量删除提示「删除为不可逆操作，且仅『已禁用』的非基准单位可删除；基准单位受保护不可删除。」，并提示「逐条执行，完成后返回『成功条数 + 跳过清单与原因』」；底栏「取消」与「确认批量启用 / 确认批量删除」（处理中显示「处理中…」）。
- **结果**：完成后弹出「批量操作结果」，显示「成功 N 条，跳过 N 条。跳过条目未做任何改动。」，并以表格列出被跳过条目的「单位名称 / 单位符号 / 跳过原因」；无跳过时显示「没有被跳过的单位」。底栏「知道了」。
- **规则**：逐条执行、不整体回滚；命中基准单位 / 不满足条件的条目跳过并返回原因。

### 1.5 字段说明（新增 / 编辑页）

#### B07-15 字段：单位名称
**拟标注位置**：表单「单位名称」内容旁，及清单该列｜**标记**：已确认

- **业务含义**：单位的中文名称（如「千克」）。
- **填写方式**：手工填写，输入框提示「如 千克」。
- **必填**：必填；为空提示「请输入单位名称」并阻断保存。
- **重复限制**：**不要求唯一**，允许重名（唯一性由「符号 + 类型」保证）。

#### B07-16 字段：单位符号
**拟标注位置**：表单「单位符号」内容旁，及清单该列｜**标记**：已确认

- **业务含义**：单位的符号（如 `kg`）。
- **填写方式**：手工填写，输入框提示「如 kg（不得包含空格）」。
- **必填**：必填；为空提示「请输入单位符号」并阻断保存。
- **格式限制**：**不得包含空格**；含空格时提示「单位符号不得包含空格」。
- **重复限制**：**「单位符号 + 单位类型」唯一**；与同类型已有符号重复时保存被拦截（以接口校验为准）。

#### B07-17 字段：单位类型
**拟标注位置**：表单「单位类型」内容旁，及清单「单位类型」列｜**标记**：已确认

- **业务含义**：单位所属的物理量类型，共 8 类（重量 / 能量 / 距离 / 体积 / 面积 / 时间 / 数量 / 碳排放量）。
- **填写方式**：下拉单选；**系统内置枚举，不开放维护**。
- **必填**：必填；未选提示「请选择单位类型」并阻断保存。
- **可否修改**：**编辑时只读，不可修改**。
- **联动**：切换类型会重置「关联基准单位」；选「数量」类时**强制为非基准单位**，且不出现基准单位与换算关系。

#### B07-18 字段：是否基准单位
**拟标注位置**：表单「是否基准单位」内容旁，及清单「基准标记」列｜**标记**：已确认

- **业务含义**：是否为该类型下的基准单位；每类型（「数量」除外）有且仅有 1 个。
- **填写方式**：下拉「否（非基准单位）/ 是（基准单位）」；若该类型已存在基准单位，「是」选项置灰不可选（提示「是（该类型已存在基准单位）」）。
- **可否修改**：**编辑时只读，不可修改**；「数量」类强制为「否」。
- **联动**：选「是」时，换算系数锁定为 1、清空关联基准单位。

#### B07-19 字段：关联基准单位
**拟标注位置**：表单「关联基准单位」内容旁，及清单该列｜**标记**：已确认

- **业务含义**：非基准单位所对应的同类型基准单位。
- **填写方式**：下拉单选，选项为**同类型、启用中的基准单位**（展示为「名称（符号）」）。
- **必填**：非基准单位（且非「数量」类）必填；未选提示「非基准单位必须选择关联基准单位」。
- **不适用**：基准单位、**「数量」类**不填写（数量类无基准单位，下拉占位显示「数量类无基准单位」）。

#### B07-20 字段：换算系数
**拟标注位置**：表单「换算系数」内容旁，及清单该列｜**标记**：已确认

- **业务含义**：本单位 → 基准单位的乘数（如吨 → 千克为 1000）。
- **填写方式**：数字输入，占位提示「本单位 → 基准单位的乘数（正数）」。
- **必填与取值范围**：非基准单位（且非「数量」类）必填，且**必须为正数**；非正数提示「换算系数必须为正数」。
- **锁定**：基准单位恒为 1 且不可编辑；「数量」类不适用。
- **变更确认**：编辑非基准单位的换算系数并保存时，弹二次确认（R-010，见 B07-09）。

#### B07-21 字段：备注
**拟标注位置**：表单「备注」内容旁，及详情页该行｜**标记**：已确认
