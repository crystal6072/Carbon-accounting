## 1. 需求概述

### 1.1 需求背景

计量单位库**不是一个业务功能，而是核算引擎的底层依赖设施**（方案 §4.2.3）。它承担四项职责：

| # | 作用 | 缺失的后果 |
| :--- | :--- | :--- |
| ① | **统一填报口径**：吨、kg、m³、度、双、件……用统一字典下拉选择 | 同一物料在不同工序用不同单位填报，数据无法比对 |
| ② | **支撑单位换算**：活动数据单位与因子单位常不一致（如活动数据「12000 度」、因子 `kgCO₂e/kWh`），**没有换算关系则无法计算** | 触发异常 **E04**，**阻断核算与报告** |
| ③ | **统一功能单位与结果口径**：功能单位（每双 / 每件 / 每千克）与结果单位（gCO₂e / kgCO₂e / tCO₂e） | 结果口径不统一，产品之间不可比 |
| ④ | **支撑质量平衡校验**：投入 / 产出 / 损耗的加总依赖单位可换算 | 异常 **E09** 的常见原因就是单位不统一 |

**本模块的定位就是「一本单位字典」，设计以简单为目标**：字段少、规则少、不做类型维护、不做公式换算。

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :--- | :--- | :--- |
| G1 | 提供覆盖核算全链路的单位字典 | 8 个单位类型齐备，各类型有且仅有 1 个基准单位 |
| G2 | 同类型单位之间可正确换算 | 任取两个同类型单位，可换算出正确结果 |
| G3 | 不可换算时明确阻断 | 跨类型或数量类换算判定为不可换算，触发 **E04** |
| G4 | 区分系统预置与组织自建 | 系统预置单位对租户只读；组织自建单位可编辑 |
| G5 | 单位变更不污染历史结果 | 变更后已核算结果不变；需按新口径重算时走 **E13** |

### 1.3 In Scope / Out of Scope

**In Scope**

| 能力 | 说明 |
| :--- | :--- |
| 单位列表与查询 | 按名称、符号、类型、数据来源、状态筛选 |
| 新增 / 编辑单位 | 名称、符号、类型、基准标记、关联基准单位、换算系数 |
| 查看单位 | 独立详情页 + 引用情况 |
| 启用 / 禁用单位 | 行操作 + 二次确认 |
| 导出 | 导出当前查询结果 |

**Out of Scope**

| 不做项 | 说明 |
| :--- | :--- |
| 单位类型字典维护 | 单位类型为**系统内置枚举**，不开放维护 |
| 审核流 / 版本化 / 外部推送 / 单据下推 | 基础字典，均不涉及 |
| 公式型换算 | 只支持乘除系数（【待确认 Q02】） |
| 按物料专属换算 | 如木材 m³ ↔ kg 需含水率与密度，本期不支持（方案 §十一 待确认事项 #1） |

| 能源热值折算 | 「吨蒸汽 → kWh」等由**能源库的热值 / 折算系数**承载（方案 §4.2.1） |
| Excel 导入 | V0.1 不支持（【待确认 Q09】） |

## 2. 用户与使用场景

### S01 维护系统预置单位

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 平台需要新增一个通用单位（如「兆瓦时 MWh」） |
| 操作流程 | 平台运营新增单位 → 填写名称、符号、类型、基准标记、关联基准单位、换算系数 → 保存 |
| 预期结果 | 数据来源 = 系统预置；全体租户只读可见并可引用 |

### S02 维护组织自建单位

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 企业有行业特有的计量单位需要补充 |
| 操作流程 | 组织管理员新增单位 → 数据来源选「组织自建」→ 保存 |
| 预期结果 | 单位归属本组织，仅本组织及上级可见，可编辑 |

### S03 维护换算关系

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 新增了非基准单位，需要声明它与基准单位的关系 |
| 操作流程 | 在单位表单中选择「关联基准单位」并填写「换算系数」→ 保存 |
| 预期结果 | 换算关系生效；该单位可与同类型任意单位互转 |

### S04 启用 / 禁用单位

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 某单位不再使用 |
| 操作流程 | 行操作点「禁用」→ 二次确认 → 确认 |
| 预期结果 | 禁用后不可被新业务选用；已引用该单位的业务数据不受影响 |

### S05 单位被引用后的限制

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 单位已被物料 / 能源 / 工序 / 产品 / 因子引用 |
| 操作流程 | 尝试禁用或删除该单位 |
| 预期结果 | **不可禁用、不可删除**；详情页可查看引用清单 |

### S06 查看单位详情

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要确认某单位的口径或被谁使用 |
| 操作流程 | 列表点名称进入详情页 → 查看单位信息与引用情况 |
| 预期结果 | 展示完整字段与引用清单 |

### S07 换算关系缺失时的表现（对应 E04）

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 活动数据单位与因子单位不可换算（跨类型，或数量类之间） |
| 操作流程 | 填报活动数据并匹配因子 → 执行检测 / 核算 |
| 预期结果 | 检测判定 **E04（因子单位不匹配）**；若为阻断级则**阻断核算与报告**，提示补换算关系或重选因子 |

## 4. 单位类型与基准单位规则

### 4.1 单位类型（系统内置，共 8 类）

| 单位类型 | 基准单位 | 是否可换算 | 说明 |
| :--- | :--- | :---: | :--- |
| 重量 | `kg` 千克 | 是 | t / kg / g / mg |
| 能量 | `kWh` 千瓦时 | 是 | kWh / MJ / GJ / kcal；蒸汽类经能源库热值折算（【待确认 Q07】） |
| 距离 | `km` 千米 | 是 | km / m |
| 体积 | `m³` 立方米 | 是 | m³ / L |
| 面积 | `m²` 平方米 | 是 | m² / ha |
| 时间 | `h` 小时 | 是 | h / min / s |
| 数量 | **无** | **否** | 个 / 件 / 双 / 套 —— 彼此不可互换 |
| 碳排放量 | `kgCO₂e` | 是 | gCO₂e / kgCO₂e / tCO₂e（**已确认单列**） |

> 「单位类型」与「是否可换算」都是**系统内置规则**，不作为用户可维护的字段或字典。

### 4.2 基准单位规则

| # | 规则 |
| :--- | :--- |
| B1 | **每个单位类型下有且仅有 1 个基准单位** |
| B2 | 基准单位**不可禁用、不可删除、不可修改单位类型**；「基准标记」在编辑时不可改（【待确认 Q04】） |
| B3 | 基准单位的换算系数恒为 **1**，不可编辑 |
| B4 | 「数量」类型**无基准单位**，该类型下所有单位相互独立 |
| B5 | 非基准单位必须关联**同类型**的基准单位 |

### 4.3 功能单位与结果单位（由类型推导，不设字段）

| # | 规则 |
| :--- | :--- |
| B6 | **功能单位**取「数量类 + 重量类 + 体积类」中可用于产品计量的单位（如 双 / 件 / 个 / kg / m³） |
| B7 | **结果单位**取「碳排放量」类型（gCO₂e / kgCO₂e / tCO₂e） |
| B8 | 本期结果口径为 CO₂：**CO₂e ≡ CO₂**，统一用 CO₂e 表达（方案 §6.1.1） |

## 5. 换算规则

### 5.1 换算机制：基准中转

```text
每个单位类型先指定 1 个基准单位，其他单位只记「自己相对基准单位的系数」。
两个单位互转时，系统自动经基准单位走两步：

    值_B = 值_A × 系数_A ÷ 系数_B

重量类型示例：
    千克：基准，系数 1
    吨  ：系数 1000        ⇒ 1 吨 = 1000 千克
    克  ：系数 0.001       ⇒ 1 克 = 0.001 千克

    吨 → 克：1000 ÷ 0.001 = 1,000,000  ⇒ 1 吨 = 1,000,000 克 ✅
```

| # | 规则 |
| :--- | :--- |
| U1 | 换算统一以**基准单位**为中转；系统不存储任意两单位之间的直接换算关系 |
| U2 | 换算存储为**单向**（单位 → 基准单位）；反向换算由系统取倒数实现 |
| U3 | 仅当两单位**同类型且该类型可换算**时换算成立；其余一律判定为**不可换算** |
| U4 | **数量类单位之间不可换算** |
| U5 | **跨类型换算一律不支持**（如体积 ↔ 重量需密度），触发 **E04** |

> 备选口径（方案 §4.2.3 原文）：为每两个单位单独维护换算关系。代价是维护量按 N² 增长，且需校验 `A→B` 与 `B→A` 的系数是否自洽。**取舍见 §9 Q01。**

### 5.2 系数与精度

| # | 规则 |
| :--- | :--- |
| U6 | 换算系数必须为**正数**，不允许 0 或负数 |
| U7 | **不支持公式型换算**（含含水率、密度的非线性关系），本期仅乘除系数 |
| U8 | 计算精度：**先换算到因子单位再相乘**，与方案 §6.1.1 公式保持一致（不设换算小数位字段） |

### 5.3 换算在核算链路中的位置

```text
方案 §6.1.1：
碳排放量 = 活动数据 × 排放因子 × 【单位换算系数】 × 分配系数
                                  ↑ 本模块提供
活动数据（填报单位）→ 经基准单位中转 → 换算为因子单位 → 参与计算
```

| # | 规则 |
| :--- | :--- |
| U9 | 换算发生在**因子匹配之后、计算之前**，由核算引擎调用本模块的换算规则 |
| U10 | 不可换算时触发 **E04**；若为阻断级，**不得按 0 排放计算**，阻断核算与报告（方案 §5.4 / §5.5） |
| U11 | 换算来源须可追溯：核算结果记录「活动数据原值 + 原单位 + 换算系数 + 因子单位」 |
| U12 | 换算缺失时是否允许人工指定换算，见 §9 Q10 |

### 5.4 质量平衡

| # | 规则 |
| :--- | :--- |
| U13 | 质量平衡校验（**E09**）要求投入 / 产出 / 损耗在**同一单位口径**下加总；系统按基准单位统一换算后比较 |
| U14 | 单位类型不统一（如一边 kg、一边 个）是 E09 误报的常见原因；本模块提供统一基准是规避手段 |

## 6. 业务规则

| 规则编号 | 规则名称 | 触发条件 | 处理逻辑 | 例外策略 |
| :--- | :--- | :--- | :--- | :--- |
| R-001 | 单位符号唯一 | 新增 / 编辑保存时 | 「单位符号 + 单位类型」唯一；同符号可出现在不同类型下（【待确认 Q08】）。名称不做唯一（【待确认 Q06】） | 重复时阻断保存 |
| R-002 | 基准单位唯一 | 新增 / 编辑保存时 | 每个类型下有且仅有 1 个基准单位；已存在时不可再标记 | 命中时阻断并提示 |
| R-003 | 基准单位保护 | 对基准单位操作时 | 不可禁用、不可删除、不可改类型、编辑时不可改基准标记、系数恒为 1 | 无例外，不渲染假入口 |
| R-004 | 非基准单位关联基准单位 | 保存非基准单位时 | 必须选择**同类型**的基准单位 | 未选或跨类型时阻断 |
| R-005 | 换算系数合法性 | 保存时 | 必须为正数，不允许 0 / 负数 | 命中时阻断 |
| R-006 | 换算适用范围 | 请求换算时 | 仅「同类型 + 该类型可换算」成立；**数量类不可换算**；**跨类型不可换算 → E04** | 无例外 |
| R-007 | 系统预置单位只读 | 租户尝试编辑系统预置单位时 | 只读，不可编辑、不可禁用、不可删除 | 仅平台运营可维护 |
| R-008 | 组织自建单位可编辑 | 编辑组织自建单位时 | 可编辑名称、符号、关联基准单位、换算系数、备注；**基准标记不可改** | 见 R-009 / R-010 |
| R-009 | 被引用单位不可禁用 / 删除 | 对已被引用的单位操作时 | 不可禁用、不可删除（避免历史数据口径漂移，【待确认 Q05】） | 命中时阻断并列出引用清单 |
| R-010 | 变更不追溯历史 | 修改单位或换算系数后 | 已核算项目的既有结果**不变**，不自动重算（【待确认 Q11】）；需按新口径重算时走 **E13** | 修改已被引用的换算系数时需二次确认并提示影响范围 |

## 7. 状态与操作矩阵

### 7.1 状态维度说明

### 7.2 操作矩阵

| 数据来源 | 基准标记 | 引用状态 | 编辑 | 启用 | 禁用 | 删除 | 被新业务选用 |
| :--- | :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| 系统预置 | 任意 | 任意 | 否（仅平台运营） | — | 否（R-003 / R-007） | 否 | 是 |
| 组织自建 | 基准 | 任意 | 仅说明性字段 | — | 否（R-003） | 否（R-003） | 是 |
| 组织自建 | 非基准 | 未被引用 | 是 | — | 是 | 是 | 是 |
| 组织自建 | 非基准 | 已被引用 | 是（换算系数变更需二次确认，R-010） | 是 | 否（R-009） | 否（R-009） | 是 |
| 组织自建 | 非基准 | 已被引用且已禁用 | 是 | 是 | — | 否 | 否 |

**闭环校验**

- 启用 ↔ 禁用双向可达（基准单位、系统预置单位、已被引用单位除外，属**受保护**不可禁用）；
- 「已被引用」不构成编辑限制，但**构成禁用与删除限制**；
- 无版本维度、无审核分支；基准单位无删除路径。
