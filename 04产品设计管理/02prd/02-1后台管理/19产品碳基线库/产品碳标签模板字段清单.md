# 产品碳标签模板字段清单

> 版本：V1.0（2026-10-28，按原型整理）
> 模块路径：产品碳基线库 → 产品碳标签模板（路由 `/baseline/label`）

## 1 列表字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 模板名称 | 文本 | 是 | 链接进编辑 |
| 适用分类 | 枚举 | 否 | 竹木/建材/钢铁/化工/纺织/电子/食品/其他 |
| 主色调 | 颜色 | 是 | 色块 + 色值（如 `#1a8924`） |
| 状态 | 枚举 | 是 | 草稿 / 已发布（Tag） |
| 更新时间 | 日期 | 系统 | 最近更新 |
| 操作 | 操作 | — | 编辑 / 删除 |

## 2 模板编辑字段

### 2.1 基础信息

| 字段 | 类型 | 必填 | 校验 / 说明 |
| --- | --- | --- | --- |
| 模板名称 | 文本 | 是 | 唯一 |
| 适用分类 | 枚举 | 否 | 下拉选择 |
| 状态 | 枚举 | 是 | 草稿 / 已发布 |

### 2.2 全局皮肤

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 预设皮肤 | 枚举 | 否 | 环保绿 `#1a8924` / 商务蓝 `#1890ff` |
| 微调主色 | 颜色 | 否 | 取色器，联动预览 |

### 2.3 模块配置（六大模块，开关 + 字段勾选）

| 模块 | 关键字段 | 说明 |
| --- | --- | --- |
| 头部区 | Logo / 主标题 / 副标题 | 开关控制显隐 |
| 核心指标 | 产品名 / 碳排值 / 单位 | 开关 + 字段勾选 |
| 认证详情 | 认证机构 / 标准 / 时间 + 在线查看报告图标 | 开关 |
| 排放构成 | 边界文字 + 阶段范围（一级/全部）+ 图表类型（进度条/表格） | 开关 |
| 产品信息 | 图片 / 名称 / 公司 / 产地 / 规格 / 密度 / 含水率 / 生物碳 / 场景文本 | 开关 + 字段勾选 |
| 适用场景 | g1~g4 四张场景图 | 开关 |

### 2.4 二维码规则

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 域名前缀 | 文本 | 只读 | 平台统一配置 |
| 附加参数 | 文本 | 否 | 如 `&src=app` |
| 权限 | 枚举 | 是 | 公开 / 内部（内部追加 `&scope=internal`） |
