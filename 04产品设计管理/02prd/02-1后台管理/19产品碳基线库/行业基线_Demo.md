# 行业基线_Demo

> **文档定位**：本模块前端 Demo 的实现规格。只定义**页面骨架、控件选型、交互、校验展示、Mock 数据、原型落点**；业务口径与验收标准见《行业基线业务 PRD》（V1.1），字段名、枚举、必填性与长度上限见《行业基线字段清单》（V1.1）。
> **依赖文档（本文件不重复定义）**：
> - `行业基线业务PRD.md`（V1.1）— 业务规则 R-001～R-020、状态矩阵、对标匹配规则
> - `行业基线字段清单.md`（V1.1）— 字段名、枚举、必填性、D01～D19 约束
> **维护形态**：列表页 + 独立新增/编辑页（整页，上表单 + 下阶段值表格）+ 独立详情页
> **页面基准**：1440px 桌面端；最小有效宽度 1280px，低于该宽度表格区横向滚动，不承诺移动端
> **成熟度**：定稿
> **版本**：V1.0
> **更新时间**：2026-10-27

## 1. 全局约定

### 1.1 页面壳

| 项 | 规格 |
| :--- | :--- |
| 容器 | 内容区左右内边距 24px，最大内容宽 1440px，超出居中 |
| 分组容器 | 统一用 `Card`（白底 / 1px 边框 / 圆角 8px / 内边距 20px），卡片间距 16px |
| 页面标题 | `PageHeader`：标题在左，页面级主动作在右；详情/编辑页副标题显示基线编号 |
| 面包屑 | 列表：`后台管理 / 产品碳基线库 / 行业基线录入`；编辑：`… / 行业基线录入 / 编辑基线`；详情：`… / 行业基线录入 / 基线详情` |
| 滚动 | 列表页整页滚动、表头吸顶；编辑/详情页内容区独立滚动 |

### 1.2 按钮位置总表

| 位置 | 按钮 | 说明 |
| :--- | :--- | :--- |
| 列表页标题区右侧 | 新增基线 | 页面级主动作 |
| 列表查询区右下 | 重置 → 搜索 | 顺序固定，右对齐 |
| 列表操作列（`TextAction`，左对齐） | 查看 / 编辑 / 发布 / 归档 / 重新发布 / 复制为新基线 / 删除 | 不可用动作**不渲染**，不出现置灰假入口 |
| 编辑页页头 | `BackButton`（最左）→ 按状态显示 `保存草稿` / `发布` / `保存并发布` | 草稿可存草稿或发布；已发布只「保存并发布」（重校验） |
| 详情页页头 | `BackButton` → 编辑 / 归档 / 重新发布 / 复制为新基线 | 按状态显隐 |
| 弹窗底栏 | 取消 → 确认 | 右侧主按钮实心，左侧次按钮幽灵 |

### 1.3 表格通用

| 场景 | 规则 |
| :--- | :--- |
| 分页 | 默认 20 条/页，可选 20 / 50 / 100；显示「共 N 条」 |
| 空值 | 统一 `-`，禁止空串、`null`、中文破折号 |
| 主数据引用 | 有编码的展示 `{编码} {名称}`（如 `C2021 纤维板制造`） |
| 状态列 | `Tag`：草稿=灰、已发布=绿、已归档=黄（淡）；文案取字段清单中文枚举 |
| 数据来源列 | `Tag`：系统预置=蓝、组织自建=紫；无颜色强约束 |
| 时间 | `YYYY-MM-DD HH:mm` |
| 数值 | 基线总值、阶段值右对齐，展示 2 位小数；阶段占比展示 1 位小数 + 百分比 |
| 操作列 | 固定右侧，宽度 200px（>4 个动作收进「更多」`Dropdown`） |

### 1.4 弹窗通用

| 项 | 规格 |
| :--- | :--- |
| 结构 | 左标题 + 右 `×` → 标题下分割线 → 内容区 → 底栏上分割线 → 按钮 |
| 宽度 | 常规 480px；编辑已发布确认 520px；边界切换清空 520px；删除 440px |
| 关闭行为 | 有未保存修改时二次确认「放弃本次修改？」；只读弹窗直接关闭 |

### 1.5 反馈与二次确认

| 操作 | 反馈 | 文案 |
| :--- | :--- | :--- |
| 保存草稿 | Toast success | `已保存草稿` |
| 发布成功 | Toast success | `基线已发布` |
| 归档 | Toast | `基线已归档` |
| 重新发布 | Toast | `基线已重新发布` |
| 删除（草稿） | Toast | `基线已删除` |
| 校验失败 | 字段下方红字 + 顶部汇总条（共 N 项待修正） | 见 §6 |
| 未知异常 | Toast error | `操作失败，请稍后重试` |

**二次确认弹窗文案**

| 触发 | 标题 | 正文 | 确认按钮 |
| :--- | :--- | :--- | :--- |
| 发布（草稿行） | 确认发布 | 发布后基线将对外可引用，且编辑需重新校验，是否发布？ | 确认发布 |
| 归档 | 确认归档 | 归档后基线退出对标候选，仅保留可查，是否归档？ | 确认归档 |
| 重新发布（已归档） | 确认重新发布 | 重新发布后基线将再次对外可引用，是否继续？ | 确认发布 |
| 删除（草稿，未被引用） | 确认删除 | 该基线未发布且无引用记录，删除后不可恢复，是否删除？ | 确认删除 |
| 编辑已发布 | 确认编辑已发布基线 | 该基线已被 N 份报告引用，历史报告按引用快照不受影响，新报告将使用新值。请填写变更原因。 | 继续编辑 |
| 切换系统边界 | 边界变更将清空已录阶段值 | 不同边界的阶段集合不同，切换「{原}→{新}」将清空当前阶段值，是否继续？ | 继续切换 |

### 1.6 作用域与权限（数据来源 + 归属组织）

| 数据来源 | 平台运营 | 组织管理员 | 其他角色（专业配置/核算/审核） |
| :--- | :---: | :---: | :---: |
| 系统预置 | 可新增/编辑/发布/归档 | 只读 | 只读 |
| 组织自建 | 只读（平台不代管租户数据） | 可新增/编辑/发布/归档（本组织） | 只读（上级组织可见） |

> 列表页默认按当前用户的数据权限过滤；平台运营看到全平台（含各组织自建，但标记为组织自建且只读）；组织管理员看到平台预置（全）+ 本组织及上级自建。

### 3.5 阶段值子表

| 列 | 控件 | 规则 |
| :--- | :--- | :--- |
| 勾选（一级） | Checkbox | 必覆盖该边界下全部一级（D08）；未勾选行置灰不可录 |
| 阶段名称 | 只读（快照） | 带出即锁定（D12） |
| 阶段值 | 数字输入 | `≥ 0`、4 位小数；不允许空（空≠0，D07） |
| 先进值 | 数字输入 | 选填；须 `≤ 阶段值`，否则提示「疑似口径填反」（N6） |
| 样本数 | 数字输入 | 选填，`≥ 0` |
| 占比 | 只读 | `阶段值/总值`，1 位小数 |
| 二级展开 | 行内展开 / 折叠 | 二级选填；展开后可录；二级只展示不计总（N5） |
| 行备注 | 文本（悬浮/展开） | ≤200 |

## 5. 关键交互

| # | 交互 | 行为 |
| :-- | :--- | :--- |
| I1 | 选「适用行业 + 系统边界」后 | 自动从阶段库带出该边界适用的阶段，按层级展示，一级预勾选（必填锁定），二级折叠 |
| I2 | 展开二级录入 | 二级行出现；二级之和须等于所属一级（D10），否则发布/保存阻断；二级不计入总值 |
| I3 | 切换系统边界 | 触发二次确认（1.5），确认后清空阶段值并重新带出 |
| I4 | 修改功能单位 | 保留数值，提示「单位变更后原数值需复核」 |
| I5 | 手工覆盖基线总值 | 高亮 + 强制差异说明（C-04） |
| I6 | 编辑已发布记录 | 进入编辑页即展示变更原因必填条 + 引用提示（1.5）；保存时重新校验 |
| I7 | 复制为新基线 | 打开新增页，所有字段预填（编号/基准年同原值待生成）；用户改边界/分类/年份后存为草稿 |
| I8 | 发布 / 重新发布 | 跑 §6 校验；通过则状态置已发布/重新发布并 Toast；失败顶部汇总条定位 |
| I9 | 行操作按状态显隐 | 不可用动作不渲染（草稿无归档；已发布无发布/删除；已归档无编辑/删除） |

## 6. 校验与反馈（前端）

| 编号 | 校验项 | 触发 | 表现 |
| :--- | :--- | :--- | :--- |
| F-01 | 行业必须末级且启用 | 失焦/保存 | 选到非末级或禁用项：下拉禁用 + 红字「请选择末级行业」 |
| F-02 | 必填项完整（名称/行业/边界/基准年/单位/口径/GWP/来源类型/发布机构） | 保存/发布 | 字段下方红字；顶部「共 N 项待修正」 |
| F-03 | 一级阶段全覆盖 | 保存/发布 | 缺失项列出（如「生产」未录入），定位到行 |
| F-04 | 阶段值合法（≥0、4 位小数、非空） | 失焦/保存 | 红字提示 |
| F-05 | 二级之和 = 所属一级（容差 0.01） | 保存/发布 | 定位到一级行，提示「二级合计与一级不一致」 |
| F-06 | 总值一致（±0.5%） | 保存/发布 | 超差阻断；已填差异说明方可解除 |
| F-07 | 同身份唯一（数据来源+归属组织+身份） | 发布 | 提示「同身份已存在基线，请编辑或调整分类/边界/年份」 |
| F-08 | 先进值方向 | 失焦 | 提示「先进值应 ≤ 阶段值，疑似口径填反」 |
| F-09 | 变更原因（编辑已发布） | 保存并发布 | 必填，未填不可保存 |
| F-10 | 依据文件（对外披露） | 提示 | 未附文件时详情标注「未附依据」，不阻断 |

> 后端仍以字段清单 D01～D19 为准；前端校验为体验前置，不替代后端。

## 9. 与既有 Demo 的差异点

| 差异 | 说明 |
| :--- | :--- |
| 编辑页为整页而非弹窗 | 因阶段值子表 + 实时汇总复杂，采用整页表单（与字段清单维护形态一致） |
| 操作列动作随状态变化且不渲染不可用项 | 草稿/已发布/已归档三态动作互斥，按 §1.2 不渲染假入口 |
| 新增「编辑已发布」二次确认 + 变更原因 | 因无版本化，已发布可直接编辑，需显式确认并留痕（业务 PRD E3） |
| 数据来源双色 Tag | 系统预置 / 组织自建区分，体现跨租户共享参考数据的归属 |
| 阶段值子表带出逻辑 | 依赖生命周期阶段库按边界过滤，非本模块自有数据 |
