# 行业基线字段清单

> **文档定位**：行业基线字段定义的唯一真相源（SST）。业务 PRD 与 Demo PRD 只引用字段名称，不重复维护枚举、必填性和字段口径。
> **适用类型**：基础数据维护（含发布）—— 非业务单据、**无审核流、无版本化**
> **核心对象**：**行业排放强度基准**（行业 + 系统边界 + 基准年 + 排放口径下的单位产品排放基准值，及其分阶段拆分）
> **维护形态**：列表 + 独立新增/编辑页（上表单 + 下阶段值表格）+ 独立详情页
> **成熟度**：定稿
> **版本**：V1.1
> **更新时间**：2026-10-27

---

## 0. 术语与口径声明

> 本节是本清单与《生命周期阶段字段清单》《行业库字段清单》对齐的基础，评审前必读。

| 术语 | 本模块口径 | 明确不承载 |
| :--- | :--- | :--- |
| **行业基线**（`IndustryBaseline`） | 某一**末级行业**（可细分到产品分类）在某一**系统边界 + 基准年 + 排放口径**下，单位产品的排放强度基准值 | 阶段骨架、核算公式、排放因子、项目内阶段排除 |
| **分阶段** | **生命周期阶段**（一级必填、二级选填下钻），与《生命周期阶段字段清单》的阶段字典同源 | **不是**时间分期（2025 / 2030 / 2035 目标值）；时间维度只有「基准年」 |
| **阶段基线**（易混词） | 生命周期阶段库按系统边界查询出的**阶段集合**（只有骨架、无数值），见《生命周期阶段字段清单》§1.2 | 与本模块**不是同一对象**；本模块不产生、不修改阶段集合 |
| **数据来源** | 仅一个含义：**系统预置 / 组织自建**，用于权限与可见性判定 | 不指「数据是怎么来的」（后者由「来源类型」承载，见 §5.3） |
| **对标引用** | 下游按规则匹配到基线后，**复制快照**使用 | 不参与核算计算，不进入核算链路 |

**三条硬边界**：

| # | 边界 |
| :-- | :--- |
| 1 | 本模块数值**不参与核算**，只用于对标、报告披露与优势分析；核算结果不因基线变化而改变 |
| 2 | 本模块**不回写**行业库、生命周期阶段库；三者是「字典 → 数值库」的单向引用关系（对齐《行业库字段清单》§9.1 口径 A） |
| 3 | 「行业基线由行业库承载」的旧表述**不适用于本模块**：行业库只提供行业编码，基线数值落在本模块 |

## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 行业基线录入（核心对象：行业基线） |
| 业务归属 | 后台管理 → 产品碳基线库 → 行业基线录入（需求边界 §2.2；方案 §八 页面清单待增补 **P33**） |
| 模块类型 | 基础数据维护 + 发布；**无审核流、无版本化** |
| 核心职责 | 维护**行业级排放强度基准值**及其分阶段拆分，供报告与对标分析取用 |
| 与「阶段基线」的分工 | 阶段库回答「用哪些阶段」，本模块回答「每个阶段行业水平是多少」 |
| 数据性质 | 参考数据（reference data），**不做权威背书**：来源、年份、发布机构必须留痕（需求边界 §2.2「不等同于政府或行业权威基准发布平台」） |
| 优先级 | P0（一期「产品碳基线库」交付项，需求边界 §2.2、业务分析 BR-05） |

### 1.2 对象结构

```text
行业基线（IndustryBaseline） 1
   ├── N  阶段基准值（BaselineStageValue）   ← 一级阶段必填、二级阶段选填下钻
   ├── N  依据文件（附件，复用附件管理，不建独立实体）
   └── 0/1 归属组织（仅组织自建基线有值）

按数据来源分两类，互不覆盖：
系统预置（PUBLIC，orgId 为空）   ← 平台运营维护，全租户只读
组织自建（ORG，orgId = 本组织）  ← 租户维护，本组织及上级可见
```

| 结构 | 对象 | 与主对象关系 | 唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 行业基线 | 主对象 | 基线编号 `baselineCode` | 业务身份 = 数据来源 + 归属组织 + 行业 + 产品分类组合 + 边界 + 基准年 + 口径 + GWP 版本 |
| 子表 | 阶段基准值 | 1:N | 基线编号 + 阶段编码 | 阶段编码引用阶段库，阶段名称**引用即复制** |
| 附件 | 依据文件 | 1:N | 附件 id | 由附件管理承载，仅用于查阅与披露举证 |
| 只读反查 | 引用情况 | — | — | 引用该基线的报告 / 对标分析清单，用于归档与变更影响提示 |

> **不设版本表、不设版本号**：基线是参考数据，历史可追溯由**下游引用快照**保证（D14），主数据侧只保留一条当前记录 + 操作日志。变更直接作用于当前记录，不允许同一身份并存多版。

### 1.3 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | **系统预置**（`PUBLIC`，平台运营维护，全租户只读）/ **组织自建**（`ORG`，租户维护，本组织及上级可见） |
| 可见性 | 由「数据来源 + 归属组织」推导，**不单独设字段** |
| 数据获取 | 用户手工录入；首发系统预置数据由平台一次性导入（不开放界面导入） |
| 新增 / 编辑 | 草稿可编辑；**已发布可编辑，但保存须通过发布校验**（D11），并记入操作日志 |
| 子表 | 阶段基准值（增删改） |
| 导入导出 | 均**不在界面开放**（对齐基础库口径） |
| 状态与执行 | 草稿 / 已发布 / 已归档；**无版本化、无审核流**、无外部系统推送 |
| 关键唯一键 | 基线编号全平台唯一；**同一「数据来源 + 归属组织 + 业务身份」下仅一条记录**（D02） |
| 历史兼容 | 基线变更**不追溯**已出报告（引用快照冻结）；需按新数值对标须重新生成报告版本 |

### 1.4 关键数据约束

| 约束ID | 约束 | 影响对象 | 违反处理 |
| :--- | :--- | :--- | :--- |
| D01 | 基线编号系统生成、全平台唯一、**不可修改**；格式 `IB-{基准年}-{行业编码}-{3位流水}` | 主表 | 阻断保存 |
| D02 | **同一「数据来源 + 归属组织 + 业务身份」下仅一条记录**（不分版本）；组织自建可与平台预置同身份并存，但同一组织内不得重复 | 主表 | 阻断新增 / 发布 |
| D03 | 适用行业**必填**，只能选**末级行业**（无下级子节点）且为启用状态；上级节点不可选 | 主表 | 阻断保存 |
| D04 | 系统边界**必填单选**；同一基线不得跨边界（不同边界不可比），需要两个边界则建两条 | 主表 | 阻断保存 |
| D05 | 基准年必填、4 位整数、`≤ 当前年`、**创建后不可修改**；数据期间须落在基准年内 | 主表 | 阻断保存 |
| D06 | 功能单位必填（`unitValue > 0` + `unitCode` 来自启用状态的计量单位库） | 主表 | 阻断保存 |
| D07 | 阶段基准值必填、`≥ 0`、最多 4 位小数；同一基线内阶段编码不重复；**不允许留空代 0** | 子表 | 阻断保存 |
| D08 | 所选边界下**一级阶段必须全覆盖**（阶段集合 = 阶段库中该边界适用的阶段） | 子表 | 阻断发布 / 保存 |
| D09 | Σ 一级阶段值 = 基线总值，容差 **±0.5%**；超差或手工覆盖总值时**必须填写差异说明** | 主表 / 子表 | 超差阻断，覆盖需说明 |
| D10 | 二级阶段存在时，**二级之和 = 所属一级阶段值**（容差 0.01），且**不进入总值汇总** | 子表 | 阻断发布 / 保存 |
| D11 | **已发布可编辑**，但保存时须重新通过 D08 / D09 / D10 校验；编辑已发布记录须二次确认并写入操作日志 | 主表 | 校验失败即阻断保存 |
| D12 | 阶段名称、阶段层级**引用即复制**；阶段库改名 / 调层级 / 禁用不回写已发布基线 | 子表 | 系统行为 |
| D13 | 已归档基线**保留可查**，不得物理删除；可通过「重新发布」回到已发布（须重新校验） | 主表 | 阻断删除 |
| D14 | 下游引用**引用即复制快照**（基线编号 + 基准年 + 阶段值 + 引用时间）；基线后续变更不回溯历史报告 | 下游 | 系统行为 |
| D15 | 基线数值**不参与核算**；不得被核算引擎读取为因子或活动数据 | 下游 | 架构约束 |
| D16 | 口径为 `biogenic` 或含生物源分项时，报告侧须与生物碳对称规则（E16）口径一致，否则标注「口径不可比」 | 下游 | 提示，不阻断 |
| D17 | 功能单位与报告声明单位不一致时**禁止自动换算**（换算需密度 / 含水率等参数），仅提示「单位不可比」 | 下游 | 提示，不阻断 |
| D18 | 「数据来源」「归属组织」**系统写入、不可编辑**；系统预置对租户只读，组织自建仅本组织（及上级）可编辑 | 主表 | 阻断编辑 |
| D19 | 组织自建基线**不得覆盖、不得顶替**同身份的平台预置基线；对标时平台预置优先（见业务 PRD §5.2） | 下游 | 系统行为 |

## 2. 字段定义

### 2.1 主对象：行业基线（IndustryBaseline）

| 字段名称 | 英文名 | 类型 | 来源 | 必填 | 列表 | 查询 | 新增/编辑 | 说明与校验 |
| :--- | :--- | :--- | :--- | :---: | :---: | :---: | :---: | :--- |
| 基线编号 | `baselineCode` | string | 系统 | 是 | 是 | 是（精确/模糊） | 只读 | `IB-2025-C2021-001`；唯一、不可改（D01） |
| 基线名称 | `baselineName` | string | 用户 | 是 | 是 | 是（模糊） | 是 | ≤80 字符；建议含「年份 + 行业 + 边界」，如「2025 纤维板行业碳足迹基准 · 摇篮到大门」 |
| 数据来源 | `dataSource` | enum `DataSource` | 系统 | 是 | 是 | 是（下拉） | 只读 | 系统预置 / 组织自建；平台运营创建 = 系统预置，租户创建 = 组织自建（D18） |
| 归属组织 | `orgId` / `orgName` | string | 系统 | 条件 | 是 | 是（下拉，仅组织自建） | 只读 | 组织自建时必填；系统预置为空，列表显示「全平台」 |
| 适用行业 | `industryCode` | string | 行业库 | 是 | 是 | 是（下拉） | 是 | 单选、**仅末级行业**、仅启用状态（D03） |
| 行业路径 | `industryPath` | string | 派生 | 是 | 否 | 否 | 只读 | 由 `industryCode` 逐级拼接，如「制造业/木材加工…/纤维板制造」 |
| 适用产品分类 | `productCategoryCodes` | string[] | 产品分类树 | 否 | 是（标签） | 是（多选） | 是 | 多选；**为空 = 该行业全品类**；同行业不同品类差异大时必须细分 |
| 系统边界 | `boundary` | enum `Boundary` | 数据字典 | 是 | 是 | 是（下拉） | 是 | `gate` / `grave`；单选（D04） |
| 基准年 | `baseYear` | int | 用户 | 是 | 是 | 是（区间） | **仅新增可填** | 4 位，`≤ 当前年`；创建后不可改（D05） |
| 数据期间 | `periodStart` / `periodEnd` | date | 用户 | 否 | 否 | 否 | 是 | 行业统计数据区间；须在基准年内 |
| 功能单位数值 | `unitValue` | decimal | 用户 | 是 | 否 | 否 | 是 | `> 0`，默认 `1` |
| 功能单位 | `unitCode` | string | 计量单位库 | 是 | 是（拼展示） | 否 | 是 | 启用状态；列表展示为 `1 m³`、`1 kg` |
| 排放口径 | `caliber` | enum `Caliber` | 系统枚举 | 是 | 是 | 是（下拉） | 是 | `total` / `fossil` / `biogenic` / `luluc`；与核算四口径一致（§5.2） |
| GWP 版本 | `gwpVersion` | string | 数据字典 | 是 | 否 | 是（下拉） | 是 | 如 `IPCC AR6 GWP100`；口径不一致禁止对标 |
| 基线总值 | `totalEmission` | decimal | 系统汇总 | 是 | 是 | 否 | 条件可编辑 | 默认 = Σ 一级阶段值；可手工覆盖，覆盖必填差异说明（D09）；4 位小数 |
| 差异说明 | `totalDiffReason` | string | 用户 | 条件 | 否 | 否 | 是 | 总值被覆盖或超差时必填；≤200 字符 |
| 来源类型 | `sourceType` | enum `BaselineSourceType` | 用户 | 是 | 是 | 是（下拉） | 是 | 行业统计 / 文献研究 / 第三方数据库 / 企业实测汇总 / 标准限值（§5.3） |
| 发布机构 | `issuer` | string | 用户 | 是 | 否 | 否 | 是 | ≤100 字符；如「中国林产工业协会」「某企业」「平台测算」 |
| 依据文件 | `attachments` | 附件[] | 附件管理 | 否 | 否 | 否 | 是 | 报告 / 白皮书 / 统计年鉴；**对外披露时必填** |
| 数据质量 | `dataQuality` | enum `DataQuality` | 用户 | 否 | 是 | 是（下拉） | 是 | 高 / 中 / 低（§5.4）；影响对标结论的置信提示 |
| 状态 | `status` | enum `BaselineStatus` | 系统 | 是 | 是 | 是（下拉） | 只读 | 草稿 / 已发布 / 已归档（§5.5）；走行操作 |
| 备注 | `remark` | string | 用户 | 否 | 否 | 否 | 是 | ≤500 字符；承载口径差异、样本范围说明 |
| 创建人 / 创建时间 | `createdBy` / `createdAt` | string | 系统 | 是 | 否 | 否 | 只读 | 置底 |
| 更新人 / 更新时间 | `updatedBy` / `updatedAt` | string | 系统 | 是 | 是（排序） | 否 | 只读 | 置底；列表默认按此倒序；已发布记录的每次修改都更新此字段 |

### 2.2 子对象：阶段基准值（BaselineStageValue）

| 字段名称 | 英文名 | 类型 | 来源 | 必填 | 列表 | 新增/编辑 | 说明与校验 |
| :--- | :--- | :--- | :--- | :---: | :---: | :---: | :--- |
| 阶段编码 | `stageCode` | string | 生命周期阶段库 | 是 | 是 | 是（选择） | 仅启用状态；按所选边界过滤（D08） |
| 阶段名称 | `stageName` | string | 阶段库快照 | 是 | 是 | 只读 | **引用即复制**；阶段改名不回写（D12） |
| 阶段层级 | `stageLevel` | int | 阶段库 | 是 | 是（缩进） | 只读 | 1 一级 / 2 二级 |
| 上级阶段 | `parentStageCode` | string | 阶段库 | 否 | 否 | 只读 | 二级阶段必填；一级为空 |
| 阶段基准值 | `stageEmission` | decimal | 用户 | 是 | 是 | 是 | kgCO₂e / 功能单位；`≥ 0`，4 位小数（D07） |
| 行业先进值 | `advancedValue` | decimal | 用户 | 否 | 是 | 是 | 行业前 10% 均值（P5 或最优十分位）；须 `≤ stageEmission`，否则提示口径填反 |
| 阶段占比 | `stageShare` | decimal | 派生 | 是 | 是（进度条） | 只读 | `stageEmission / totalEmission × 100%`，保留 1 位小数；总值为 0 时显示「—」 |
| 样本数 | `sampleSize` | int | 用户 | 否 | 否 | 是 | `≥ 0`；支撑数据质量判定 |
| 行备注 | `remark` | string | 用户 | 否 | 否 | 是 | ≤200 字符；承载该阶段的口径偏差说明 |
| 合计校验标记 | `sumCheck` | enum | 派生 | 是 | 否 | 只读 | `通过 / 超差 / 缺阶段`，用于发布与保存前置提示（D08 / D09） |

**阶段覆盖与粒度**

| # | 规则 |
| :-- | :--- |
| S1 | 一级阶段**必填全覆盖**；二级阶段**选填下钻**，未录入则仅按一级展示 |
| S2 | 二级阶段录入时，其所属一级阶段必须已录入；否则阻断 |
| S3 | 二级阶段**只做展示与行业结构参考，不进入总值汇总**（避免重复计入） |
| S4 | 边界 = `gate` 时，只带出适用该边界的阶段（通常为原材料获取、生产，木竹另含种植与培育）；`grave` 带出全阶段 |
| S5 | 「阶段适用边界」的来源 = 阶段库的「适用系统边界」字段（为空 = 全边界通用），本模块不另设纳入规则 |
| S6 | 阶段不得重复录入同一 `stageCode` |

### 2.3 只读反查与派生字段

| 字段 | 说明 | 用途 |
| :--- | :--- | :--- |
| 引用情况 `referenceList` | 引用本基线的报告（P26）、对标分析（优势分析 / 减排诊断）清单 | 归档 / 修改前影响提示；不阻断操作 |
| 阶段覆盖率 `coverage` | 已录入一级阶段数 / 该边界适用一级阶段数 | 编辑页实时提示、发布校验 |

### 2.4 不设字段的设计约定

| 约定 | 理由 |
| :--- | :--- |
| **不设「版本号 / 版本表」** | 基线属参考数据，**本期明确不做版本化**。历史可追溯由下游引用快照保证（D14），主数据侧只留一条当前记录 + 操作日志；需要留档对比时另存离线文件 |
| **不设「纳入规则」字段**（必须 / 可选 / 不纳入） | 纳入规则属阶段库与项目 P20 的职责；本模块只按边界带出阶段，重复设置会造成两处维护冲突 |
| **不设「适用行业」多选** | 一条基线对应一个末级行业，多行业可比性不成立；需要多行业时建多条 |
| **不设「项目 / 报告」外键** | 下游引用即复制快照，不做实时关联（D14） |
| **不设「是否生效」开关** | 用状态（草稿 / 已发布 / 已归档）唯一表达，避免「发布」与「启用」两套状态并存 |
| **不设「可见性」字段** | 由「数据来源 + 归属组织」推导（D18） |
| **不设「目标年 / 分时间阶段」字段** | 「分阶段 = 生命周期阶段」；若后续需要 2030 / 2035 目标值，另立「行业减排目标」对象 |

## 3. 字段联动与派生口径

### 3.1 编辑页联动

```text
选择「适用行业」（仅末级）+「系统边界」
        ↓
按边界从阶段库带出阶段（已禁用阶段不出现）
        ↓
预勾选并锁定一级阶段行（必填），二级阶段可选「展开录入」
        ↓
录入 stageEmission → 实时计算 stageShare / totalEmission / coverage
        ↓
sumCheck = 通过 → 「发布 / 保存」可用；否则置灰并列出原因
```

| # | 联动 |
| :-- | :--- |
| C1 | 修改「系统边界」→ 清空已录阶段值并二次确认（不同边界阶段集合不同） |
| C2 | 修改「功能单位」→ 保留数值，提示「单位变更后原数值需复核」 |
| C3 | 「基准年」只在新增时可填，创建后只读；需换年份请新增一条基线 |
| C4 | 修改一级阶段值 → 二级阶段值不自动按比例缩放，仅提示「二级之和已不等于一级」 |
| C5 | 手工覆盖 `totalEmission` → 强制填写 `totalDiffReason`，且 `stageShare` 按覆盖值计算 |
| C6 | 编辑已发布记录 → 顶部固定提示「该基线已被 N 份报告引用，修改不影响历史报告的快照值」，保存时重新校验 |

### 3.2 数值精度

| 字段 | 精度 | 说明 |
| :--- | :--- | :--- |
| `stageEmission` / `advancedValue` / `totalEmission` | 4 位小数 | 展示按 2 位小数四舍五入，导出与计算用 4 位 |
| `stageShare` | 1 位小数 | 展示值；后端保留 2 位，避免合计不为 100% |
| 容差 | 总值 ±0.5%；二级合计 ±0.01 | 见 D09 / D10 |

## 5. 枚举值

### 5.1 系统边界（引用「数据字典 · 系统边界」）

| 编码 | 含义 | 备注 |
| :--- | :--- | :--- |
| `gate` | 摇篮到大门 | 通常含原材料获取 + 生产；木竹另含种植与培育 |
| `grave` | 摇篮到坟墓 | 含运输、使用、生命周期末期 |

> 取值来源与《生命周期阶段字段清单》§5.2 完全一致，本模块不新增枚举。

### 5.2 排放口径（`Caliber`）

| 枚举值 | 含义 | 备注 |
| :--- | :--- | :--- |
| `total` | 总量（不含生物源 CO₂） | 默认口径，与核算结果首列一致 |
| `fossil` | 化石源 | — |
| `biogenic` | 生物源 | 与 E16 生物碳对称规则相关（D16） |
| `luluc` | 直接土地利用变化 | 木竹 / 生物质原料常用 |

### 5.3 来源类型（`BaselineSourceType`）

| 枚举值 | 含义 | 典型举证 |
| :--- | :--- | :--- |
| 行业统计 | 协会 / 统计年鉴的行业汇总值 | 统计年报、协会发布数据 |
| 文献研究 | 公开论文 / LCA 研究报告 | 文献 PDF、DOI |
| 第三方数据库 | 商业或公共 LCA 数据库 | 数据库名称 + 版本 + 数据集 ID |
| 企业实测汇总 | 平台内企业实测数据脱敏汇总 | 样本数、汇总口径说明 |
| 标准限值 | 标准 / PCR 中给出的限值或推荐值 | 标准编号 + 条款 |

### 5.4 数据质量（`DataQuality`）

| 枚举值 | 含义 | 对标结论展示 |
| :--- | :--- | :--- |
| 高 | 一手统计或大样本实测（≥30） | 正常展示 |
| 中 | 文献 / 数据库，样本有限 | 展示「参考」标记 |
| 低 | 估算 / 单一样本 / 口径待核 | 展示「仅供参考」并提示 |

### 5.5 基线状态（`BaselineStatus`）

| 枚举值 | 含义 | 可编辑 | 可被对标引用 |
| :--- | :--- | :---: | :---: |
| 草稿 | 录入中，未对外 | 是 | 否 |
| 已发布 | 生效记录，对外可引用 | 是（须重新校验，D11） | 是 |
| 已归档 | 主动退出对标，或历史数据停用 | 否（可先重新发布） | 否（历史报告可回显快照） |

### 5.6 数据来源（`DataSource`）

| 枚举值 | 归属 | 维护方 | 可见范围 | 可编辑 |
| :--- | :--- | :--- | :--- | :--- |
| 系统预置 | `PUBLIC` | 平台运营 | 全租户只读 | 仅平台运营 |
| 组织自建 | `ORG` | 租户管理员 | 本组织及上级组织 | 仅本组织（上级只读） |

> 该枚举是相对《物料字段清单》《行业库字段清单》「不设数据来源」的**有意偏离**：基线是跨租户共享的参考数据，必须区分平台基准与企业自建，且报告披露需要标注，故保留该字段。需在方案附录二登记。

### 5.7 功能单位（引用计量单位库）

不新增枚举；取启用状态的计量单位，按「数值 + 单位」组合展示（如 `1 m³`、`1000 kg`、`1 双`）。
