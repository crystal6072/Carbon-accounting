# 产品碳标签模板业务 PRD

> 版本：V1.0（2026-10-28，按原型整理）
> 模块路径：产品碳基线库 → 产品碳标签模板（路由 `/baseline/label`）

## 1 模块定位

为产品碳标签提供可视化模板配置能力：运营人员通过「模块开关 + 主色调 + 二维码规则」快速拼装一张手机端 H5 碳标签，并实时预览效果。配置结果由下游标签生成 / 打印模块按模板渲染。

## 2 功能流程

1. 进入「产品碳标签模板」列表（路由 `/baseline/label`）。
2. 点击「新建模板」进入编辑页（左 40% 配置、右 60% 手机端实时预览）。
3. 填写基础信息、选择全局皮肤、勾选并配置六大模块、配置二维码规则。
4. 右侧预览随配置即时变化；点击「保存模板」回到列表。
5. 列表行支持编辑 / 删除（删除原型未做二次确认，建议补）。

## 3 页面与操作

- **列表页**：列 = 模板名称（链接）/ 适用分类 / 主色调（色块+色值）/ 状态（草稿·已发布 Tag）/ 更新时间 / 操作（编辑·删除）。
- **编辑页**：
  - 基础信息：模板名称（必填）、适用分类（下拉：竹木/建材/钢铁/化工/纺织/电子/食品/其他）、状态（草稿/已发布）。
  - 全局皮肤：内置两款预设（环保绿 `#1a8924`、商务蓝 `#1890ff`）+ 取色器微调主色；主色联动所有开关轨道与手机端头部/指标/图表。
  - 模块配置：六大模块（头部区、核心指标、认证详情、排放构成、产品信息、适用场景），每个模块独立开关控制右侧卡片显隐，字段级勾选控制明细项。
  - 二维码规则：域名前缀（平台统一配置、只读）、附加参数（选填）、权限（公开/内部，内部追加 `&scope=internal`）。
  - 实时预览：右侧 60% 手机框，随皮肤/模块/字段即时变化。

## 4 业务规则（原型已表现）

- 模板名称为唯一必填项。
- 主色调即时联动预览（所见即所得）。
- 模块开关与字段勾选共同决定预览卡片与明细。
- 二维码 URL = `前缀[批次号]附加参数[&scope]`。
- 状态：草稿 / 已发布（是否前端生效控制见 §待确认）。
