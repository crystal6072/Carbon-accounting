## 1. 拟添加的批注清单

### 1.1 整体流程

#### B04-01 工序维护整体流程
**拟标注位置**：功能标题「工序」附近（全局说明）
**标记**：已确认

**批注内容**

- **适用场景**：平台 / 组织管理员在后台维护「工序」——即产品制造过程中一道具体的操作单元（含其投入物与产出物），供工艺流程组装、产品信息库建档时选用。
- **流程**：进入工序 → 列表按条件查询（支持按工序类型分组）→ 查看核对 → 新增 / 编辑（维护基本信息 + 投入项 / 产出项）→ 用「启用 / 禁用」控制该工序能否被工艺流程引用。
- **衔接**：列表操作列「查看 / 编辑」不离开本页，以弹窗完成。
- **结束**：保存后立即生效并刷新列表；没有提交、审核、驳回，不做版本化；可用「删除」移除（仅禁用态可删）。

### 1.2 全局规则说明

#### B04-02 全局规则
**拟标注位置**：功能标题「工序」附近（与整体流程同一全局说明入口）
**标记**：已确认（权限、数据可见范围为待确认，见 §4）

**批注内容**

1. **适用范围**：工序是制造过程的最小可复用单元；本身不直接参与碳排计算，碳排发生在「产品引用工序 → 复制为产品工序」之后。
2. **可被引用条件**：仅「启用」态的工序可被工艺流程 / 产品信息库选用；「禁用」态不可被新引用，已引用它的流程 / 产品与已生成的核算结果不受影响。
3. **不记录数量**：工序**不设基准数量 / 基准单位**，投入产出**不记录合计、不计算损耗**（仅作物料 / 流向 / 单位登记）。
4. **停用方式**：用「禁用」代替删除；禁用不影响它作为工序单元的结构作用。
5. **不做版本化**：编辑直接覆盖，不保留历史版本。
6. **统一限制**：工序编码与工序名称必填；使用状态不在表单内改动；不设「归属组织 / 可见性」（工序库瘦身，可见范围由创建主体自动判定）。
7. **权限**：谁可维护、谁只能查看，原型未做任何限制 → **待确认**（见 §4）。

### 1.3 业务状态说明

#### B04-03 使用状态
**拟标注位置**：清单「使用状态」列旁（确认弹窗内相应引用）
**标记**：已确认

**批注内容**

- **含义**：工序只有「启用」「禁用」两个状态。启用 = 可被工艺流程 / 产品信息库选用；禁用 = 不再出现在新引用中。
- **进入条件**：新增保存默认「启用」；启用↔禁用经行操作双向切换。
- **可进行的操作**：查看 / 编辑 / 禁用（启用态）或 启用 + 删除（禁用态）恒可操作。
- **对下游的影响**：禁用后新流程 / 产品不能再选它；已引用该工序的工艺流程与已生成的核算结果不受影响；含有该禁用工序的工艺流程详情会给出黄色提示条。

### 1.4 操作功能及对应业务规则

#### B04-04 列表与查询
**拟标注位置**：清单表格区域与清单上方查询区
**标记**：已确认

**批注内容**

- **列表列**：工序编码（链接）、工序名称、工序类型、使用状态、更新时间、操作。
- **查询项**：工序编码（包含匹配）、工序名称（包含匹配）、工序类型、使用状态；多条件叠加，任一变化回到第 1 页；「重置」清空全部。
- **按工序类型分组**：列表提供「按工序类型分组」开关，开启后按 主 / 辅 / 处置 分块展示（不分页）。
- **导出**：列表提供「导出」按钮（原型 `toast` 模拟）。
- **操作列**：查看 / 编辑恒显；启用态多出「禁用」，禁用态多出「启用 + 删除」。

#### B04-05 新增 / 编辑工序表单
**拟标注位置**：页头「新增」、清单「编辑」、详情「编辑」
**标记**：已确认

**批注内容**

- **新增入口**：页头「新增」；或在详情页点「编辑」。
- **表单字段**：工序编码（新增可填、编辑只读）、工序名称（必填）、工序类型（必填：主 / 辅 / 处置）、工序图标（选填，本地上传）、工序描述（选填）。
- **不进表单**：使用状态、制单信息、投入产出（子表内维护）。
- **保存结果**：保存成功提示「保存成功」，列表刷新；编码唯一校验。

#### B04-06 投入项 / 产出项子表
**拟标注位置**：表单「投入项」「产出项」子表
**标记**：已确认（计算公式列原型未实现，见 §4）

**批注内容**

- **投入项列**：序号、流类型、物料、单位、备注（+ 删除、+ 添加）。
- **产出项列**：序号、流类型、物料、单位、排放物类别、备注（+ 删除、+ 添加）。
- **流类型**：投入项可选 原料 / 能源 / 中间品 等；产出项可选 产品 / 中间品 / 排放物 等。
- **排放物类别**：仅产出项且流类型为「排放物」时必选。
- **计算公式**：公式下沉为已确认设计（引用计算引擎配置·计算公式 08），系统按流类型 / 名称关键词默认带出、可覆盖或「不参与计算」；**但原型（表单 / 详情 / 列表 / 查看工序弹窗）均未实现该列，待补充**（见 §4 Q26）。

#### B04-07 校验规则
**拟标注位置**：表单底栏「保存」「取消」
**标记**：已确认

**批注内容**

- **校验（任一不通过即阻断保存，已填内容保留）**：
  1. 产出项 ≥ 1；
  2. 每行须填写齐全（流类型 / 物料 / 单位等）；
  3. 流类型为「排放物」时须选排放物类别；
  4. 投入 + 产出合并判重（相同 流类型 + 物料 视为重复）。
- **禁止自身闭环**：投入与产出不能形成自身物料闭环（校验拦截）。
- **取消**：点「取消」或关闭不保存任何内容。

#### B04-08 联动
**拟标注位置**：子表「物料 / 流类型」单元格
**标记**：已确认

**批注内容**

- **换物料自动带出默认单位**：选择物料后，单位按物料主数据默认带出，可改。
- **换流类型清空物料 / 单位 / 类别**：流类型变更后，物料、单位、排放物类别清空重选（避免类型与物料错配）。

#### B04-09 查看工序（详情）
**拟标注位置**：清单「查看」、编码链接、查看弹窗
**标记**：已确认（制单信息为演示数据；计算公式列未实现）

**批注内容**

- **展示内容**：工序编码、工序名称、工序类型、使用状态、工序图标、创建人、创建时间、最后修改时间、工序描述 + 投入产出表（流类型 / 物料 / 单位 / 排放物类别 / 备注）。
- **只读**：底栏「关闭 / 编辑」；**子表无「计算公式」列**（见 §4 Q26）。
- **制单信息**：原型为演示值（见全局批注「演示数据」）。

#### B04-10 启用 / 禁用 / 删除确认
**拟标注位置**：清单「启用 / 禁用 / 删除」、二次确认弹窗
**标记**：已确认（删除约束为待确认，见 §4）

**批注内容**

- **启用**：仅禁用态显示；二次确认 → 确认后变启用，提示「启用成功」。
- **禁用**：仅启用态显示；二次确认正文补充「禁用后，新流程 / 产品建档时不可再选择该工序；历史引用数据保留不变。」→ 确认后变禁用，提示「禁用成功」。
- **删除**：仅禁用态显示；二次确认；**已引用该工序的工艺流程 > 0 时是否阻断删除待确认**（见 §4）。
- **取消**：点「取消」或关闭，状态 / 数据不变。
