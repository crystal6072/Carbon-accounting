## 1. 拟添加的批注清单

### 1.1 整体流程

#### B03-01 工艺流程维护整体流程
**拟标注位置**：功能标题「工艺流程」附近（全局说明）
**标记**：已确认

**批注内容**

- **适用场景**：平台 / 组织管理员在后台维护「工艺流程」——即一套描述产品制造过程的工序链模板，供产品信息库建档、我的工艺库引用时选用。
- **流程**：进入工艺流程 → 列表按条件查询 → 查看核对（或点编码进详情）→ 新增 / 编辑（在弹窗内维护基本信息 + 组装工序明细）→ 用「启用 / 禁用」控制该流程能否被产品引用。
- **衔接**：列表操作列的「查看 / 编辑」不离开本页，以弹窗完成；新增 / 编辑表单内嵌「工序明细」画布，可「查看工序」只读核对某道工序的完整信息。
- **结束**：保存后立即生效并刷新列表；整个流程没有提交、审核、驳回，也不做版本化（编辑直接覆盖），可用「删除」移除（仅禁用态可删）。

### 1.2 全局规则说明

#### B03-02 全局规则
**拟标注位置**：功能标题「工艺流程」附近（与整体流程同一全局说明入口）
**标记**：已确认（权限、数据可见范围为待确认，见 §4）

**批注内容**

1. **适用范围**：工艺流程是产品制造过程的工序链模板；本身不直接参与碳排计算，碳排发生在「产品引用工艺流程 → 复制为产品工艺与工序」之后。
2. **可被引用条件**：仅「启用」态的工艺流程可被产品信息库 / 我的工艺库选用；「禁用」态不可被新引用，但已引用它的产品与已生成的核算结果不受影响。
3. **不记录数量**：工艺流程及其工序明细**不记录基准数量 / 基准单位、不合计投入产出、不计算损耗**（与工序口径一致）；投入项仅作物料 / 流向登记。
4. **停用方式**：用「禁用」代替删除；禁用不影响它作为工序链模板的结构作用。
5. **不做版本化**：编辑为直接覆盖，不保留历史版本，也不改变已复制出去的产品工艺与核算结果。
6. **统一限制**：工艺流程编码与工艺流程名称必填；使用状态不在表单内改动，只走行操作；不设「基准数量 / 基准单位」（已按原型移除）。
7. **归属组织 / 可见性**：由创建主体自动判定（运营管理员创建 = 全平台只读，用户自建 = 仅创建人可见），**表单不维护**，仅详情展示。
8. **权限**：谁可维护、谁只能查看，原型未做任何限制 → **待确认**（见 §4）。

### 1.3 业务状态说明

#### B03-03 使用状态
**拟标注位置**：清单「使用状态」列旁（确认弹窗内相应引用）
**标记**：已确认

**批注内容**

- **含义**：工艺流程只有「启用」「禁用」两个状态。启用 = 可被产品信息库新建产品时选用；禁用 = 不再出现在新工艺流程的选择中。
- **进入条件**：新增保存后默认为「启用」；启用↔禁用经行操作「启用 / 禁用」双向切换。
- **可进行的操作**：查看 / 编辑 / 禁用（启用态）或 启用 + 删除（禁用态）恒可操作；本页任何状态都不提供「提交 / 审核」。
- **状态变化**：启用与禁用双向可达，可反复切换；变更状态只刷新使用状态与最后修改时间，不改动其他内容。
- **对下游的影响**：禁用后新产品建档时不能再选它；已引用该流程的产品与已生成的核算结果不受影响。
- **删除限制**：仅「禁用」态提供「删除」；删除为物理删除，已引用的产品不可删（见 R-013 / §4 待确认）。

### 1.4 操作功能及对应业务规则

#### B03-04 列表与查询
**拟标注位置**：清单表格区域与清单上方查询区
**标记**：已确认

**批注内容**

- **列表列**：工艺流程编码（链接）、工艺流程名称、适用产品分类、所属行业、所属生命周期阶段、使用状态、工序数量、已复制产品数、更新时间、操作。
- **查询项**：工艺流程编码（包含匹配）、工艺流程名称（包含匹配）、适用产品分类、所属行业、所属生命周期阶段、使用状态；多条件叠加，任一变化回到第 1 页；「重置」清空全部条件。
- **搜索按钮保留**：点「搜索」执行一次当前条件筛选；输入即时过滤与按钮点击结果一致。
- **导出**：列表提供「导出」按钮（原型为 `toast` 模拟，含工序明细），导出范围 = 当前查询结果。
- **操作列**：查看 / 编辑恒显；启用态多出「禁用」，禁用态多出「启用 + 删除」。

#### B03-05 新增 / 编辑工艺流程表单
**拟标注位置**：页头「新增」按钮、清单「编辑」、查看弹窗「编辑」
**标记**：已确认

**批注内容**

- **新增入口**：页头「新增」；或在详情页点「编辑」。
- **表单字段**：工艺流程编码（新增可填、编辑只读）、工艺流程名称（必填）、适用产品分类（必填，说明性字段、不构成引用约束）、所属行业（必填、单值）、所属生命周期阶段（必填、单值）、工艺流程描述（选填）。
- **不进表单**：使用状态、归属组织、可见性、是否含处置工序、工序数量、已复制产品数、模板更新标记均不出现在表单。
- **保存结果**：保存成功提示「保存成功」，列表刷新；编码唯一校验，重复阻断保存。

#### B03-06 工序明细组装（画布 / 列表）
**拟标注位置**：表单内「工序明细」画布 / 列表切换区
**标记**：已确认

**批注内容**

- **目的**：把若干道工序按制造顺序串成一条链，作为工艺流程的内容。
- **视图**：支持「画布 / 列表」两种视图切换 + 画布全屏；画布节点 = 序号 + 工序名 + 删除 + 工序下拉 + 投入 / 产出概览；保留拖拽排序、节点间「+」插入；取消「撤销」（节点 × 删除即可）。
- **操作**：添加工序（下拉选已有工序）、插入工序（节点间「+」）、删除工序、拖拽调整顺序。
- **序自动生成**：工序顺序按画布节点顺序自动生成（1..n），不手工填写。
- **查看工序**：点节点可查看该工序的只读详情（见 B03-15）。

#### B03-07 工序明细校验
**拟标注位置**：表单底栏「保存」「取消」
**标记**：已确认（首道 / 末道口径为待确认，见 §4）

**批注内容**

- **校验（任一不通过即阻断保存，已填内容保留）**：
  1. 工序数量 ≥ 1（至少添加一道工序）；
  2. 每行须选择工序；
  3. 引用的工序不能为「禁用」态；
  4. 工序顺序须连续（1..n）。
- **三条链提示级（不阻断）**：首道投入须含原料 / 能源、末道产出须含产品、相邻工序物料衔接断点——当前原型为**提示级**，与产品信息库「末道产出阻断」跨模块口径不一致（见 §4 Q25）。
- **取消**：点「取消」或关闭不保存任何内容。

#### B03-08 查看工艺流程（详情）
**拟标注位置**：清单「查看」、编码链接、查看弹窗
**标记**：已确认（制单信息为原型演示数据）

**批注内容**

- **展示内容**：工艺流程编码、工艺流程名称、适用产品分类、所属行业、所属生命周期阶段、使用状态、是否含处置工序、归属组织、可见性、创建人、创建时间、最后修改时间、工艺流程描述。
- **只读**：不能在详情内直接修改；底栏「关闭 / 编辑」。
- **只读明细**：工序数量（系统计算）、已复制产品数（系统关联、仅提示、不构成删除约束）；模板更新标记仅在提示文本体现（见 B03-17）。
- **引用禁用工序提示**：若明细中含已禁用的工序，详情给出黄色提示条。

#### B03-09 详情只读信息字段
**拟标注位置**：详情「是否含处置工序 / 归属组织 / 可见性 / 制单信息」行
**标记**：已确认（归属组织 / 可见性为系统自动；制单信息为演示数据）

**批注内容**

- **是否含处置工序**：系统计算（明细中是否含「处置」类工序），用于阶段归属提示。
- **归属组织**：由创建主体自动判定，表单不维护，仅详情展示。
- **可见性**：`ORG`（仅创建组织）/ `PUBLIC`（全平台只读），由创建主体自动判定，表单不维护。
- **制单信息**：创建人 / 创建时间 / 最后修改时间，由系统记录，原型中为演示值（见全局批注「演示数据」）。

#### B03-10 查看工序弹窗
**拟标注位置**：表单画布节点「查看工序」、详情工序明细节点
**标记**：已确认（计算公式列原型未实现，见 §4）

**批注内容**

- **目的**：只读核对某道工序的完整信息（仅该工序，不含工艺流程级状态 / 制单信息）。
- **展示内容**：工序编码、工序名称、工序类型、工序描述 + 投入项 / 产出项（流类型 / 物料 / 单位 / 排放物类别 / 备注）。
- **不展示**：使用状态、制单信息、以及**「计算公式」列**（公式下沉为已确认设计，但原型尚未实现该列，见 §4）。
- **底栏**：关闭 / 编辑（跳到工序编辑，若有权限）。

#### B03-11 启用 / 禁用 / 删除确认
**拟标注位置**：清单「启用 / 禁用 / 删除」、二次确认弹窗
**标记**：已确认（删除约束为待确认，见 §4）

**批注内容**

- **启用**：仅禁用态显示；点「启用」→ 二次确认「确认将工艺流程『名称』（编码）启用？」→ 确认后变启用，提示「启用成功」。
- **禁用**：仅启用态显示；点「禁用」→ 二次确认，正文补充「禁用后，新产品建档时不可再选择该工艺流程；历史引用数据保留不变。」→ 确认后变禁用，提示「禁用成功」。
- **删除**：仅禁用态显示；二次确认（原型文案为删除不可恢复）；**已引用该流程的产品 > 0 时是否阻断删除待确认**（见 §4 R-013）。
- **取消**：点「取消」或关闭，状态 / 数据不变。

#### B03-12 已复制产品数 / 模板更新标记（只读明细）
**拟标注位置**：列表「已复制产品数」列、详情提示文本
**标记**：已确认（模板更新标记仅详情提示，不在列表列）

**批注内容**

- **已复制产品数**：系统自动关联，列表展示该流程被多少产品复制引用；**仅作提示，不构成删除约束**（已确认 Q10）。
- **模板更新标记**：工艺流程被复制为产品工艺后，若源模板发生更新，副本可被标记「模板已更新」；原型在详情提示文本体现，不在列表列单独展示（Q09 待确认）。
