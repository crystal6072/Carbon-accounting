## 1. 需求概述

### 1.1 需求背景

工序是**投入产出流的载体**，是活动数据填报与排放计算的最小单元（方案 §1.4 术语）。它回答「这个生产环节投入什么、产出什么」，为后续的排放因子匹配与碳排放计算提供挂载点。

本模块是**模板库**：工序被工艺流程引用、被产品版本复制。工序本身**不做版本化**（已确认 Q06），通过「**模板可自由编辑 + 引用即复制**」的机制保证已建模型不受后续调整影响（已确认 Q15 / Q20）。

> **公式下沉（2026-09-24 起，核算模型已废弃）**：工序不再只是「有哪些投入产出物」的载体，而是**排放项级公式的唯一挂载点**——每个投入 / 产出项绑定一条「计算公式」（系统按流类型 / 名称默认带出，可手工覆盖或「不参与计算」），公式随工序 → 工艺流程 → 产品 → 项目整条链「引用即复制」带入。**产品总碳排放不再需要配置**，固定为「各工序排放之和」（工序排放 = Σ 其投入产出项结果，引擎自动汇总）。

| # | 目标 | 可验证口径 |

| G2 | 工序可按类型区分与筛选 | 工序类型枚举为主工序 / 辅助工序 / 处置工序，支持筛选 |

| G5 | 复制到产品版本后保留来源可追溯 | 副本带「来源模板标识（工序编码 + 复制时点）」，可回溯来源 |

## 2. 用户与使用场景

### S01 新建工序

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 有一个新的生产环节需要纳入核算 |
| 操作流程 | 进入工序 → 页头「新增」→ 填写工序编码、工序名称、工序类型（必填）、工序图标（选填，本地上传）、工序描述（选填）→ 维护投入项（原辅料 / 能源 / 自然资源输入）与产出项（中间品 / 产品 / 副产品 / 排放物），每行选择物料与单位 → 保存 |
| 预期结果 | 工序创建成功，编码唯一；投入项 / 产出项校验通过；工序可被工艺流程引用 |

### S02 编辑工序（含被引用之后）

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 工序定义需要修正 |
| 操作流程 | 列表点「编辑」→ 修改内容 → 保存 |
| 预期结果 | **无论该工序是否已被工艺流程或产品引用，均可自由编辑**（模板口径）；编辑**不触碰**任何已建副本，不产生下游变更通知 |

### S03 维护投入项 / 产出项

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 工序的投入或产出发生变化 |
| 操作流程 | 在投入项区域选择流类型（原辅料 / 能源 / 自然资源输入）并引用物料或能源、选择单位 → 在产出项区域选择流类型（中间品 / 产品 / 副产品 / 排放物）并引用物料与单位，流类型 = 排放物时须选择排放物类别（废气 / 废水 / 废渣） → 保存（**不填数量**，数量到核算模型 / 数据录入阶段填写） |
| 预期结果 | 行级校验通过（流类型必填、物料必填、单位必填、排放物类别必填、行内不重复）；产出项至少 1 条 |

## 4. 投入产出流规则（本章为核心）

### 4.1 两张子表的结构与边界（已确认 Q01）

> 本口径为对方案 §4.2.2 的偏离，**方案已同步回改**（方案 v1.2 r4，见方案「附录二 · 基础库落地偏离清单」第 7 项）。同批次回改的还有：工序不做版本化（第 8 项）、模板 + 引用即复制（第 9 项）、中间品不记录上下游关联（第 10 项）。
>
> **2026-09-21 新增偏离（第 11 项）**：流类型枚举由方案 §4.2.2 的 5 类调整为 **7 类** —— 投入项 = 原辅料 / 能源 / 自然资源输入，产出项 = 中间品 / 产品 / 副产品 / 排放物；其中「原料投入」改名「原辅料」、「成品」改名「产品」，新增「自然资源输入」「排放物」（中间品保留）。**方案 §4.2.2 需同步回改。**

```text
工序
├── 投入项（1:N）
│   └── 流类型 ∈ { 原辅料 → 引用物料库；能源 → 引用能源库；自然资源输入 → 引用物料库 }
└── 产出项（1:N）
    └── 流类型 ∈ { 中间品, 产品, 副产品, 排放物 }（均引用物料库）
        └── 排放物：须标注排放物类别 ∈ { 废气, 废水, 废渣 }
```

| # | 规则 |
| :--- | :--- |
| F1 | 投入项与产出项是**两张独立的子表**，序号各自独立编号 |
| F2 | 两张表字段大体一致（序号 / 流类型 / 物料 / 单位 / 备注），差异在于**可选物料不同**（投入侧可选物料或能源，产出侧只可选物料）；**均不含数量**（数量在核算模型 / 数据录入时填写） |
| F3 | 「排放物类别」**仅存在于产出项且流类型 = 排放物**时；**不设**「是否主产出」「产出分配依据」（已确认 2026-09-21） |
| F4 | 产出项**至少 1 条**；投入项数量不限（但须满足后续因子匹配需要） |

### 4.2 7 类流的定义与使用边界（投入 3 类 + 产出 4 类）

## 7. 上下游与引用关系

| 方向 | 关联模块 | 引用字段 | 联动规则 |
| :--- | :--- | :--- | :--- |
| 上游 | 物料库（A1-1） | 物料 | 投入项（原辅料 / 自然资源输入）与产出项（中间品 / 产品 / 副产品 / 排放物）引用；禁用物料不可新选 |
| 上游 | 能源库（A1-2） | 能源 | 投入项（能源）引用；禁用能源不可新选 |
| 上游 | 计量单位库（A1-9） | 单位 | **单位引用计量单位库**（默认取物料默认单位，可覆盖）；单位**换算**校验在核算填报（P22），不可换算触发 E04 |
| 上游 | 计算引擎配置（08）· 计算公式 | 计算公式 | 投入 / 产出项每行绑定**一条**计算公式（F23 / R-023）；系统按 F24 默认带出，用户可覆盖 |
| 下游 | 工艺流程（A1-7） | 工序 | **模板间为引用关系**（工序编码），工艺流程组合工序为有序队列；工序模板变更后工艺流程模板展示最新；**工序被禁用 / 删除后需在工艺流程侧调整**（本模块不做引用校验，R-016） |
| 下游 | 产品信息库（A1-6 / P08） | 工序、投入项 / 产出项（含公式） | **复制**为产品版本副本并冻结（**公式随工序一并复制**）；副本保留来源模板标识；模板变更不回写副本 |
| 下游 | 核算项目 · 工序与数据（原 P20 / P22） | 工序、投入项 / 产出项（含公式） | 间接使用（经产品版本副本）；项目内公式**随工序带入、前台只读** |
| 下游 | 数据填报（P22） | 工序、投入项 / 产出项 | 以工序为最小单元填报活动数据（**数量 = 工序单耗在此填写**，单位取自工序数据项）；公式决定填报字段（公式的 `activity` 因素）与因子匹配（公式的 `parameter` 因素） |

> **引用 vs 复制的边界（重要）**：`工序模板 → 工艺流程模板` 是**引用**（两者都是模板，实时候选最新）；`工艺流程 / 工序 → 产品版本` 是**复制**。因此模板层的调整会影响其他模板的展示，但**不会影响已建的产品版本与项目**。

> - **Q02 / Q03（已关闭）**：**工序只维护「输入数据项 / 输出数据项清单」，不填具体数值**。因此：
>   ① 子表**不含**「数量」「单位」，主对象**不含**「基准数量」「基准单位」；
>   ② F12 / F14 / F19、R-008、D07 原口径随之失效；
>   ③ R-009 / F13 的单位引用与换算约束**前移至核算填报（P22）**，不可换算仍按方案 §5.4 触发 **E04**。
> - **Q13（已关闭）**：单位不可换算不在本模块处理，统一在核算填报阶段阻断（E04）；工序模板侧不做单位校验，避免过度限制模板录入。
> - **流类型枚举调整（2026-09-21 已确认）**：投入项 = **原辅料 / 能源 / 自然资源输入**；产出项 = **中间品 / 产品 / 副产品 / 排放物**（共 **7 类**）。原「原料投入」改名「原辅料」、「成品」改名「产品」；**新增**「自然资源输入」「排放物」；**中间品保留**，工序链衔接口径不变。新增「**排放物类别**（废气 / 废水 / 废渣）」字段与 **R-021**；自然资源输入与排放物**复用物料库**承载；方案 §4.2.2 需同步回改（偏离第 11 项）。
> - **工序库瘦身（2026-09-21 已确认）**：
>   ① **不设「归属组织」「可见性」** —— 可见范围由**创建主体**自动判定（运营管理员创建 = 全平台可见可引用；用户自建 = 仅创建人可见），页面不展示；
>   ② **不设「引用状态」** —— 删除规则改为「**仅禁用状态可删除**」（R-016 修订），工序库只保留「使用状态」一个维度，引用情况反查一并取消（关闭 Q07 / Q14）；代价是删除后不校验工艺流程引用，容错归工艺流程侧；
>   ③ **不设「是否主产出」「产出分配依据」** —— 主次由**流类型**（产品 / 副产品）表达，分配由「分配规则管理」承载（关闭 Q09 / Q11）；
>   ④ **~~「含中间品」仅详情展示~~ → 改为「不设『是否含中间品』字段」**（2026-09-21 二次确认：新增 / 编辑页无该字段，详情页同步取消展示）；
>   ⑤ **补回「单位」** —— 投入 / 产出项每行记录单位（默认取物料默认单位、可覆盖，引用计量单位库），数量仍不记录，新增 **R-022 / F12a**；
>   ⑥ **数量口径明确**：数量 = 「**工序单耗**」（本工序单位产品对应的物料消耗量 / 产出量），在核算模型创建 / 数据录入（P22）阶段填写。
