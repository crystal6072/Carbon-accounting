## 1. 需求概述

### 1.1 需求背景

工艺流程把工序按顺序装配为**可复用的生产路径**，处在「工序 → 工艺流程 → 产品 → 核算项目」链条的中间层。

两条已确认的关键口径决定了本模块的形态：

1. **不做版本化（已确认 Q05）**：工艺流程与工序一致，不设版本号与版本状态。方案 §2.3 A1-7 原文要求的「版本管理」经业务确认取消，须回改方案（登记为基础设施落地偏离）。
2. **引用即复制（已确认 Q20 / Q21）**：`工序模板 →（引用）→ 工艺流程模板 →（复制）→ 产品`。模板层之间是引用，进入产品时复制并冻结，因此**不需要版本化也能保证已建产品与已核算项目不受模板调整影响**。

因此本模块只承担一个职责：**把工序装配成有序、可校验的工序链，并可通过启用 / 禁用控制其被引用的范围**。

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :--- | :--- | :--- |
| G1 | 支持把工序装配为有序工序链 | 工序明细可增删改序，顺序连续不重复，同一工序允许重复出现并以序号区分 |
| G2 | 支持工序链的合理性校验 | 首道投入、末道产出、中间衔接三条校验**均为提示级、不阻断保存**；校验结果在明细行可见（§4.3） |
| G3 | 通过启用 / 禁用控制引用范围 | 仅「启用」的工艺流程可被产品引用；禁用流程不出现在产品侧候选列表 |
| G4 | 工艺流程模板可自由维护 | 被引用或被复制后仍可编辑，不影响已建副本 |
| G5 | 被产品复制后可追溯 | 副本保留来源模板标识；模板更新仅在副本上标记，不回写 |

## 2. 用户与使用场景

### S01 新增工艺流程

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 有一条新的生产路径需要沉淀为可复用模板 |
| 操作流程 | 进入工艺流程 → 页头「新增」→ 填写基本信息（**所属行业、所属生命周期阶段为必填**）→ 在**流程画布**上添加工序节点（仅可选启用中的工序）、按左→右顺序排列 → 保存 |
| 预期结果 | 保存成功即为**启用**状态、可被产品引用；节点自左向右即工序顺序（自动连续、不重复）；工序链校验结果在节点上可见（首道投入 / 末道产出 / 中间衔接均为提示级，不阻断保存） |

### S02 编辑工艺流程

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 工艺流程内容需要修正 |
| 操作流程 | 列表点「编辑」→ 修改（含工序明细）→ 保存 |
| 预期结果 | **任何状态下均可编辑**（模板不被引用锁定）；保存不回写已建副本；若引用的工序已被禁用，明细校验会提示并禁止新选 |

### S03 调整工序顺序与增删工序行

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 工序链的顺序或组成发生变化 |
| 操作流程 | 在工序明细中新增 / 删除行，或上移 / 下移调整顺序 → 保存 |
| 预期结果 | 顺序连续性校验通过；末道产出为成品、中间衔接断点均以**提示**形式展示（不阻断保存） |

### S04 启用 / 禁用

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 工艺流程需要（或不再需要）被产品引用 |
| 操作流程 | 行操作点「禁用」/「启用」→ 二次确认 → 确认 |
| 预期结果 | **仅「启用」**的工艺流程可被产品引用（Q11）；禁用后不出现在产品侧候选列表；已复制到产品的副本不受影响 |

### S05 删除工艺流程

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 工艺流程不再需要 |
| 操作流程 | 先「禁用」→ 行操作点「删除」→ 二次确认 → 确认 |
| 预期结果 | **启用状态不提供删除入口**；禁用后允许删除，**不检查是否被引用 / 被复制**（Q10）；若已被产品复制，副本保留来源模板标识、内容不受影响 |

### S06 被产品引用后的表现

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 工艺流程已被产品复制 |
| 操作流程 | 查看工艺流程详情 |
| 预期结果 | 列表可见「已复制产品数」，基本信息区给出复制情况提示；**详情页不呈现「适用产品」只读反查**（2026-09-21 补充确认）；**模板仍可自由编辑、亦可禁用与删除**；不出现「不可编辑」假入口限制 |

### S07 查看工艺详情与操作日志

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要查看工序链完整定义或历史变更 |
| 操作流程 | 列表点编码 / 名称进入详情页 → 查看基本信息、工序明细 → 展开操作日志 |
| 预期结果 | 展示完整字段与制单信息；工序明细附首末道标识与衔接校验状态；操作日志可折叠并分页 |

## 4. 工艺流程装配规则

### 4.1 工序装配方式

| # | 规则 |
| :--- | :--- |
| A1 | 工序明细**只能引用「启用」状态的工序**；已禁用的工序不可新选 |
| A2 | 工序明细**至少 1 行**（D02） |
| A3 | 工序明细**不允许在本模块新增工序定义**；本模块只做引用与排序 |
| A4 | 工序的投入项 / 产出项（投入产出流）在本模块**只读展示**，维护归属为「工序管理」（A1-8） |

### 4.2 顺序规则

| # | 规则 |
| :--- | :--- |
| A5 | 工序顺序**连续且不重复**（D04）：由**流程画布节点自左向右的顺序自动生成**（新增 / 删除 / 插入节点后自动重排），不允许手工跳号 |
| A6 | **同一工序允许在一个工艺流程中重复出现**（已确认 Q02），以节点序号区分（例如"干燥"出现两次）；衔接校验按相邻节点逐对进行 |
| A6b | **画布交互（与产品信息库一致，2026-09-24 对齐）**：节点 = 一个工序；节点结构 = 序号 + 工序名 + ×删除 + 工序下拉 + 投入 / 产出投影；支持末尾「+ 添加工序」、节点间「+」插入、节点 × 删除、**鼠标拖拽节点调整顺序**（拖拽后自动重排序号与工序顺序）；**取消「撤销」**；支持**「画布 / 列表」视图切换 + 画布全屏**（全屏复用同一画布，可拖拽 / 插入 / 删除 / 双击查看） |

### 4.3 工序链校验规则（**Q03 已确认结论落地，本章为核心**）

> **归属（唯一执行方）**：校验**在本模块执行**——工序链在本模块成形。
> 工序模块（A1-8）为单工序、不含上下游，**不做衔接校验**；产品信息库侧仅做组合完整性兜底，**不重复做衔接校验**（避免两处都校验或都不校验）。
> 本节内容需与 `工序业务PRD.md` Q04 对齐：工序侧据此删除 / 明确不做衔接校验。

**校验对象**：工艺流程的工序明细，按「工序顺序」排序后**相邻两行逐对校验**。

| # | 校验规则 | 判定依据 | 级别 |
| :--- | :--- | :--- | :--- |
| A7 | **末道产出为成品** | 末道工序的产出项中应存在「流类型 = 成品」的项；若末道产出仅为中间品则命中 | **提示**（不阻断保存；明细行与保存结果均给出提示，2026-09-21 修订） |
| A8 | **首道投入合规** | 首道工序的投入项应为原辅料 / 能源 / 自然资源输入（不应全部为「中间品」）；命中异常时给出提示 | **提示**（不阻断保存，2026-09-21 修订） |
| A9 | **上下游衔接** | 取上游工序产出中流类型 ∈ {中间品, 产品} 的集合，与本工序全部投入项集合求**交集**：交集非空即衔接通过；为空即「衔接断点」 | **提示**（不阻断保存，明细行标「衔接断点」并给出断点说明） |
| A10 | **判定口径** | 按**物料对象一致**（引用对象编码一致）判定，**不按名称文本**判定；副产品、排放物**不参与**衔接判定（与工序 PRD F6 一致） | — |
| A11 | **校验时机与呈现** | 明细变更时**实时提示** + 保存时校验；合规项标注「已衔接」，首道行标注「首道」，异常行标注「衔接断点」并展示断点原因 | — |
| A12 | **校验范围** | 校验只读引用工序的投入产出流，**不在本模块修改**；工序的投入产出流变更后，本模块重新计算校验结果（引用关系为实时取最新工序模板） | — |

> **级别汇总（2026-09-21 修订）**：三条工序链校验（A7 末道产出为成品、A8 首道投入合规、A9 上下游衔接）**全部为提示级，均不阻断保存**（业务确认：C1 不阻断、首道投入也放开）。
> 因此本模块的**阻断级校验**只剩：工序明细至少 1 行（R-002）、只能引用启用中的工序（R-003）、工序顺序连续不重复（R-004）、编码唯一（R-001）。
> **口径说明（可调整）**：A9 采用「交集非空即通过」的宽松口径——上游同时产出多种中间品时，只要下游投入命中其一即视为衔接。若业务要求「逐项对齐」或「全量匹配」，需另行确认后修订 A9。
