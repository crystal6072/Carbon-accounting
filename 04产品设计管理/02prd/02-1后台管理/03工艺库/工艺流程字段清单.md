## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 工艺流程 |
| 业务归属 | 后台管理 → 基础库 → 工艺库 → 工艺流程（方案 §2.3 A1-7、§八 P09） |
| 模块类型 | 完整主数据（带可维护子表：工序明细），**不做版本化**（已确认 Q05） |
| 核心对象 | 工艺流程（含工序明细） |
| 核心职责 | 把工序按顺序装配为可复用的生产路径，作为产品信息库组合产品、核算项目生成核算工序的中间层 |

### 1.2 对象结构

| 结构 | 对象 | 与主对象关系 | 主键/唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 工艺流程 | 主对象 | 工艺流程编码 | **不做版本化**（已确认 Q05）；模板可自由编辑，被引用 / 被复制后仍可编辑（D07） |
| 子表 | 工序明细 | 1:N | 工艺流程 + 工序顺序 | 引用「工序管理」的工序，构成有序工序链；同一工序**允许重复出现**，以序号区分（D03） |
| 只读明细 | 引用/复制情况 | — | — | 「已复制产品数」为系统计算字段（列表展示）；「适用产品」仅定义、**界面不展示只读反查**（2026-09-21 补充确认） |

### 1.3 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | 人工维护（专业配置人员维护平台级、组织管理员维护组织自建，方案 §7.2） |
| ERP是否数据源 | 否 |
| 新增编辑 | 支持（**模板可自由编辑**：被引用或被复制后仍可编辑，不回写已建副本，D07 / D08） |
| 子表 | 可维护（工序明细） |
| 导入导出 | 导出：支持（【待确认 Q15】范围）；导入：V0.1 不支持（【待确认 Q08】） |
| 状态与执行 | **不做版本化**（已确认 Q05）；使用状态（启用 / 禁用），**仅「启用」可被产品引用**（已确认 Q11）；**引用方式 = 复制（在产品侧）**；无审核流、无外部系统推送、无单据下推 |
| 关键唯一键 | 工艺流程编码（唯一，范围【待确认 Q07】）；同一工艺流程内「工序顺序」唯一 |
| 历史兼容 | 无历史版本概念；已复制到产品的副本**不随模板更新**，仅标记「模板已更新」（【待确认 Q09】） |

### 1.4 关键数据约束

| 约束ID | 约束 | 影响对象 |
| :--- | :--- | :--- |
| D01 | 工艺流程编码唯一（【待确认 Q07】唯一范围）；**「所属行业」「所属生命周期阶段」为必填**（2026-09-21 新增） | 主表 |
| D02 | 工序明细至少 1 行；工序引用只能选**启用中**的工序 | 工序明细 |
| D03 | 同一工艺流程内，同一工序**允许重复出现**，以「序号」区分（已确认 Q02） | 工序明细 |
| D04 | 工序顺序不重复且必须连续 | 工序明细 |
| D05 | 首道工序的投入建议含原辅料 / 能源 / 自然资源输入（不应全部为中间品）：未命中时**仅提示、不阻断保存**（已确认 Q03，2026-09-21 修订） | 工序明细 |
| D06 | 末道工序的产出建议为「成品」：未命中时**仅提示、不阻断保存**（已确认 Q03，2026-09-21 修订） | 工序明细 |
| D07 | **工艺流程不做"被引用后不可编辑"处理**：模板可自由编辑，已建副本由产品侧持有（沿用工序的「模板 + 复制」口径） | 主表 |
| D08 | **删除规则**：仅「禁用」状态的工艺流程可删除，**不依赖引用 / 复制状态**（已确认 Q10，与工序 D14 口径一致）；副本保留来源模板标识、不受影响 | 主表 |
| D09 | 被复制的工艺流程保留来源模板标识（工艺流程编码 + 复制时点） | 主表 / 产品侧副本 |
| D10 | **仅「启用」状态的工艺流程可被产品引用**（已确认 Q11） | 主表 |
| D11 | 上下游衔接校验在**本模块执行**：中间衔接为**提示级**、不阻断保存（已确认 Q03） | 工序明细 |
