## 1. 拟添加的批注清单

### 1.1 整体流程

#### B08-01 阶段维护整体流程
**拟标注位置**：功能标题「生命周期阶段」附近（全局说明）｜**标记**：已确认

- **适用场景**：在后台维护生命周期阶段字典，作为组织填报、检测、汇总与报告共用的阶段骨架，并向核算项目输出阶段基线。
- **流程**：进入生命周期阶段 → 清单按一级 / 二级分组展示全部阶段 → 按需查询、点名称查看核对 → 新增或编辑阶段 → 用「启用 / 禁用」控制能否被新项目加载。
- **分支**：新增只有页头「新增」一个入口；查看、编辑均以弹窗完成，不离开本页。
- **衔接**：清单点阶段名称进入查看弹窗；查看弹窗可直接「编辑」。
- **结束**：保存后立即生效并刷新清单。全程没有提交、审核、驳回。

### 1.2 全局规则说明

#### B08-02 全局规则
**拟标注位置**：功能标题「生命周期阶段」附近（与整体流程同一全局说明入口）｜**标记**：已确认（权限为待确认，见 §3）

1. **轻量字典**：本页维护生命周期阶段字典；**无审核流、无版本化**。
2. **层级仅两级**：阶段层级**仅支持一级 / 二级，不支持三级**；一级阶段无上级，**二级阶段必须选择所属一级阶段**。
3. **边界适用口径（V0.2 起）**：阶段与行业解耦，**不设「适用行业」与「按边界的纳入规则」字段**；阶段通过「**适用系统边界**」声明其在哪些系统边界下适用，**多选、引用「数据字典 · 系统边界」**，**为空 = 全边界通用**。
4. **不设数据来源 / 引用状态**：阶段字典统一由平台维护，**不设「系统预置 / 组织自建」数据来源字段**，所有阶段对有权进入本模块的用户同等可编辑。
5. **唯一与排序**：**阶段编码唯一**；**同一上级下阶段名称唯一**；**同级内阶段顺序不重复**，一级与二级各自独立排序。
6. **编辑锁定**：阶段编码**编辑时只读**；**存在下级阶段时不允许修改阶段层级**（避免二级阶段失去上级）。
7. **删除限制**：本页**仅「已禁用」的阶段可删除**，启用态不展示删除入口；**一级阶段下仍有二级阶段时阻断删除**。
8. **变更不追溯**：编辑为直接覆盖，不保留历史版本；已加载该阶段的在途项目**按基线快照运行、不受影响**，需按新基线重算走 **E13**。
9. **无流程节点**：没有提交、审核、驳回；不提供批量操作、勾选与操作日志。
10. **级联禁用（V1.2 新增）**：禁用**一级阶段**时，其下全部二级阶段**同步禁用**；**启用一级阶段不级联**，子阶段保持各自状态、需按需单独启用。

### 1.3 业务状态说明

#### B08-03 使用状态
**拟标注位置**：清单「使用状态」列旁｜**标记**：已确认

- **含义**：阶段只有「启用」「禁用」两个状态。启用 = 可被新项目加载；禁用 = 不再被新项目加载。
- **进入条件**：新增保存后默认为「启用」；「启用」由禁用态经行操作「启用」进入；「禁用」由启用态经行操作「禁用」进入。
- **可进行的操作**：无论启用还是禁用，都可以「查看」「编辑」；禁用态多出「启用」与「删除」，启用态多出「禁用」。
- **状态变化**：启用与禁用双向可达、可反复切换；变更状态只刷新使用状态，不改动其他内容。
- **对下游的影响**：阶段一旦禁用，新项目不能再加载它；**已加载该阶段的在途项目按基线快照运行、不受影响**。
- **级联禁用（V1.2 新增）**：禁用一级阶段时，其下全部二级阶段同步禁用；启用一级阶段**不级联**。
- **删除前提**：删除仅对「已禁用」阶段开放，删除后不可恢复；一级阶段有二级时不可删除。

### 1.4 操作功能及对应业务规则

#### B08-04 清单（按一级 / 二级分组）
**拟标注位置**：清单表格区域与清单上方工具条｜**标记**：已确认

- **展示内容**：阶段名称、阶段层级、适用系统边界、使用状态、操作。
- **展示规则**：① 每页 **20 条**；② 清单**按一级 / 二级分组展示**，一级阶段为其下二级阶段的分组行，**二级阶段缩进于其一级阶段之下**；③ 一级阶段行右侧展示「N 个二级」（其直接下级数量）。
- **筛选口径**：筛选命中某个二级阶段时，**其所属一级阶段作为分组行一并展示，但不计入结果数**；工具条「共 N 条」统计的是命中结果数（不含分组上下文行）。
- **工具条**：左侧显示「阶段列表」与「共 N 条」及分组口径提示。
- **操作列**：「查看」「编辑」恒显示；「启用」「禁用」按当前状态二者只出现其一；「删除」仅对已禁用阶段显示。
- **无批量 / 勾选**：本页不提供勾选与批量操作。

#### B08-05 查询与重置
**拟标注位置**：清单上方查询区｜**标记**：已确认（搜索按钮行为为原型已表现·待核对）

- **查询项**：① 阶段名称 —— 包含关系模糊匹配；② 阶段层级 —— 下拉「一级 / 二级」，不选即为全部；③ 使用状态 —— 下拉「启用 / 禁用」，不选即为全部。
- **规则**：多个条件同时生效（叠加过滤）；任一条件变化后清单回到第 1 页；「重置」清空全部条件并恢复完整清单。
- **搜索按钮**：点「搜索」执行一次当前条件的筛选。
- **原型表现（待核对）**：原型中点「搜索」仅出现一次「查询完成」提示、不产生额外动作（条件输入后清单已即时收敛）。需确认正式需求是「点击后查询」还是保留「即时筛选 + 按钮共存」。

#### B08-06 新增阶段
**拟标注位置**：页头「新增」按钮旁｜**标记**：已确认

- **操作目的**：建立一个新的生命周期阶段。
- **入口**：页头「新增」；恒可操作。
- **操作过程**：打开弹窗，标题「新增阶段」；**阶段编码默认自动带出（如 `LS-NN`）**、可修改；填写阶段名称，选择阶段层级（二级需选上级阶段），阶段顺序默认按「同级最大值 + 10」带出，按需选适用系统边界、填阶段描述。
- **结果**：保存成功后弹窗关闭，提示「保存成功」，清单刷新，使用状态为「启用」。
- **取消或失败**：点「取消」或关闭弹窗不保存任何内容；校验不通过时给出提示（见 B08-13）。

#### B08-07 查看阶段
**拟标注位置**：清单操作列「查看」、清单「阶段名称」链接、查看弹窗｜**标记**：已确认

- **操作目的**：只读核对某个阶段的完整信息与适用系统边界。
- **入口**：清单操作列的「查看」，或直接点击清单中的阶段名称；任何状态均可查看。
- **展示内容**：基本信息（阶段编码、阶段名称、阶段层级、上级阶段、阶段顺序、使用状态、阶段描述）+ 适用系统边界 + 制单信息。
- **适用系统边界**：多选展示；为空显示「全边界通用」标签，并提示「引用『平台支撑 · 数据字典 · 系统边界』；为空表示适用于全部系统边界」。
- **规则**：只读弹窗，不能在其中直接修改内容；一级阶段「上级阶段」显示「-」，阶段描述为空显示「-」。
- **结果**：底栏为「关闭」与「编辑」；点「关闭」不产生任何变更，点「编辑」切换到编辑弹窗并带出该阶段内容。

#### B08-08 编辑阶段
**拟标注位置**：清单操作列「编辑」、查看弹窗底栏「编辑」｜**标记**：已确认

- **操作目的**：修改阶段信息；任何状态均可编辑，不区分启用与禁用。
- **操作过程**：打开弹窗，标题「编辑阶段」，带出现有内容；**阶段编码为只读，不可修改**；可修改阶段名称、阶段层级、上级阶段、阶段顺序、适用系统边界、阶段描述。
- **联动**：① 变更「阶段层级」时，阶段顺序按新层级「同级最大值 + 10」重算；② 变更「上级阶段」时，二级阶段顺序按该一级阶段范围内「最大值 + 10」重算。
- **限制**：**存在下级阶段时，「阶段层级」不可修改**（避免二级阶段失去上级）。
- **结果**：保存成功后弹窗关闭，提示「保存成功」，清单刷新。

#### B08-09 启用阶段
**拟标注位置**：清单操作列「启用」、确认弹窗｜**标记**：已确认

- **显示条件**：只在该阶段当前为「禁用」时，操作列才显示「启用」。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认启用」，正文「确认将一级 / 二级阶段『阶段名称』（阶段编码）启用？」，并提示「启用后该阶段可被新项目按『系统边界』加载。」；底栏「取消」与「确认启用」，不使用「确定」字样。
- **结果**：确认后该阶段变为「启用」，提示「启用成功」，清单刷新。取消则状态不变。**启用不级联**：其下二级阶段保持各自状态，不随一级阶段一并启用。

#### B08-10 禁用阶段
**拟标注位置**：清单操作列「禁用」、确认弹窗｜**标记**：已确认

- **显示条件**：只在该阶段当前为「启用」时，操作列才显示「禁用」。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认禁用」，正文「确认将一级 / 二级阶段『阶段名称』（阶段编码）禁用？」，提示「禁用后该阶段不可被新项目加载；已加载该阶段的在途项目按基线快照运行、不受影响。禁用后可执行删除。」；底栏「取消」与「确认禁用」。
- **级联禁用（V1.2 新增）**：禁用**一级阶段**时，其下全部二级阶段**同步禁用** —— 确认弹窗提示追加「其下 N 个二级阶段将同步禁用」（N = 启用态二级阶段数，无启用态子级时不显示该句）；确认后 toast 提示「禁用成功，其下 N 个二级阶段已同步禁用」。**启用不级联**（见 B08-09）。
- **结果**：确认后该阶段变为「禁用」，提示「禁用成功」；禁用后出现「删除」入口。取消则状态不变。

#### B08-11 删除阶段
**拟标注位置**：清单操作列「删除」、确认弹窗｜**标记**：已确认

- **显示条件**：**仅对该阶段当前为「禁用」时显示**；启用态不出现删除入口。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认删除」，正文「确认将一级 / 二级阶段『阶段名称』（阶段编码）删除？」，提示「删除后不可恢复。仅『已禁用』的阶段可删除；当前使用状态为『禁用 / 启用』。」。
- **一级阶段有下级时阻断**：删除某个一级阶段，若其下仍有二级阶段，弹窗内以红色提示「删除失败：该一级阶段下存在 N 个二级阶段，请先处理其下二级阶段后再删除。」，且「确认删除」按钮置灰不可点。
- **结果**：确认后删除，提示「删除成功」，清单刷新；删除不可恢复。取消则不删除。

### 1.5 字段说明

#### B08-13 弹窗的保存与取消
**拟标注位置**：新增 / 编辑弹窗底栏「保存」「取消」｜**标记**：已确认

- **保存**：点击后先校验，通过后保存并关闭弹窗，提示「保存成功」，清单刷新；保存过程中按钮显示「保存中…」并暂时不可点击。
- **校验规则（任一不通过即阻断保存，弹窗不关闭，已填内容保留）**：
  1. 阶段编码未填写 → 「请输入阶段编码」；与已有阶段重复 → 「阶段编码已存在（D01）」；
  2. 阶段名称未填写 → 「请输入阶段名称」；同一上级下重复 → 「同一上级下的阶段名称不得重复（D04）」；
  3. 二级阶段未选上级 → 「二级阶段必须选择上级阶段（D02）」；
  4. 阶段顺序非 1～99 整数或超出范围 → 相应提示；同级内重复 → 「同级内阶段顺序不重复（D05）」。
- **取消**：点「取消」或关闭弹窗不保存任何内容；再次打开时不保留上次填写的内容。

#### B08-14 字段：阶段编码
**拟标注位置**：表单「阶段编码」内容旁，及查看弹窗该行｜**标记**：已确认

- **业务含义**：阶段的唯一业务标识。
- **填写方式**：手工填写，输入框提示「如 LS-07」；**新增时默认自动带出（`LS-NN`）**。
- **必填**：必填；为空提示「请输入阶段编码」。
- **可否修改**：**编辑时只读，不可修改**。
- **重复限制**：**全量唯一**；重复提示「阶段编码已存在（D01）」。

#### B08-15 字段：阶段名称
**拟标注位置**：表单「阶段名称」内容旁，及清单该列｜**标记**：已确认

- **业务含义**：阶段的业务名称（如「原材料获取」）。
- **填写方式**：手工填写。
- **必填**：必填；为空提示「请输入阶段名称」。
- **重复限制**：**同一上级下唯一**（一级阶段之间唯一；同一一级下的二级阶段之间唯一）；重复提示「同一上级下的阶段名称不得重复（D04）」。

#### B08-16 字段：阶段层级
**拟标注位置**：表单「阶段层级」内容旁，及清单该列｜**标记**：已确认

- **业务含义**：阶段所处层级，仅「一级 / 二级」，不支持三级。
- **填写方式**：下拉单选（一级 = 无上级；二级 = 必选上级）。
- **可否修改**：**存在下级阶段时不可修改**（编辑置灰）。
- **联动**：变更层级时，阶段顺序按新层级「同级最大值 + 10」重算。

#### B08-17 字段：上级阶段
**拟标注位置**：表单「上级阶段」内容旁，及查看弹窗该行｜**标记**：已确认

- **业务含义**：二级阶段所属的一级阶段；一级阶段无上级。
- **填写方式**：下拉单选，选项为全部一级阶段（展示为「名称（编码）」），按阶段顺序排列。
- **必填**：**二级阶段必填**；未选提示「二级阶段必须选择上级阶段（D02）」；一级阶段时该项不可填（显示「一级阶段无上级」）。
- **联动**：变更上级时，二级阶段顺序按该一级阶段范围内「最大值 + 10」重算。

#### B08-18 字段：阶段顺序
