# 排放因子库字段清单

> **文档定位**：排放因子库字段定义的唯一真相源（SST）。业务 PRD 和 Demo PRD 只引用字段名称，不重复维护枚举、必填性和字段口径。
> **适用类型**：**核算模型域对象** —— **多库 + 库级版本化 + 发布**（方案 §4.9 口径 1）；**无审核流**、无单据下推
> **核心对象**：**因子库（FactorLibrary）→ 库版本（FactorLibraryVersion）→ 库内因子（FactorItem）** 三级结构；版本化载体为**库版本**
> **模块归属**：后台管理 → 核算模型 → 排放因子库（方案 §2.3 A2-6 / A2-7、§4.4、§八 P15；原型 `/model/factor`）。**前台「我的因子库」独立成文**（字段同源、对象分离，见 `02prd/02-2前台业务功能/03我的因子库/我的因子库字段清单.md`）
> **核心用途**：提供「**活动数据 → 碳排放量**」的换算系数（方案 §1.4 术语）；本期口径 **CO₂ / CO₂e（CO₂e ≡ CO₂）**
> **维护形态**：库列表（搜索 + 筛选 + 卡片网格）+ 库详情（左分类树 + 右因子表）+ 库版本管理 + 库内因子维护 + 外部库整库导入
> **成熟度**：粗纲
> **版本**：V0.5
> **更新时间**：2026-10-14

> **与基础库的差异声明**：基础库模块（物料 / 能源）已**移除「数据来源」**字段；本模块亦**不再在因子级设来源字段** —— 归属档位由**库来源 + 库维护方**表达（商业数据库 = 平台只读；自建库 = 平台级或组织级）。
> **与前台的关系声明**：后台「因子库」为**多库 + 库级版本化 + 发布**；前台「我的因子库」为**组织私有库**（收藏副本 + 手工新增，**不发布、不参与共享、不版本化**）。两者共用因子统一字段集（`FactorItem` / `MyFactor` 字段同源），但**对象与生命周期不同**。
> **字段精简声明（V0.3 修订）**：因子（`FactorItem` / `MyFactor`）**不设「因子分类」「适用行业」**，也**不设任何「来源信息」**（见下条）。原「因子分类枚举（材料 / 能源 / 运输 / 废弃物处理 / 末期处理 / 生物碳）」**从因子主对象取消**，仅降级为**核算结果的「排放源归类」**口径保留（原型 `PcfCalcSourceType`，**非因子字段**，见 §5.4 迁移说明）；因子的匹配 / 分类相关表述改用**已有字段**表达 —— **适用对象 / 适用阶段 + 单位 + 区域 / 年度**。
> **来源信息移除声明（V0.3 修订）**：因子**不再设「来源信息」**——即不再有 来源类别（`sourceCategory`）、发布年份（`publishYear`）、发布日期（`publishDate`）、发布国家 / 组织（`publisherRegion`）、发布机构全称 / 简称（`publisherFullName` / `publisherShortName`）、数据来源文件（`dataSourceFile`）。因此**因子详情不再有「来源信息」区块**，**因子表单不再有「来源信息」页签（表单只剩「因子信息」）**；「来源」语义统一由**库来源（商业数据库 / 自建库）**表达。

## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 排放因子库 |
| 业务归属 | 后台管理 → 核算模型 → 排放因子库（方案 §2.3 A2-6 / A2-7、§4.4、§八 P15）；**前台「我的因子库」独立成文**（方案 §2.3 B4、§八 P29） |
| 模块类型 | **核算模型域对象**（配置类），非业务单据；**多库 + 库级版本化 + 发布**、**无审核流** |
| 核心对象 | **因子库（FactorLibrary）→ 库版本（FactorLibraryVersion）→ 库内因子（FactorItem）** |
| 核心职责 | 提供「**活动数据 → 碳排放量**」的换算系数，使 `碳排放量 = 活动数据 × 排放因子 × 单位换算系数 × 分配系数` 可计算（方案 §6.1.1）。**本模块只回答"用多大系数换算"，不回答"活动量是多少"** |

### 1.2 对象结构

| 结构 | 对象 | 与主对象关系 | 主键/唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | **因子库（FactorLibrary）** | 顶层对象 | **库编码** | 一个平台可有多个库；库来源两类（`external` / `builtin`） |
| 子表 | **库版本（FactorLibraryVersion）** | 1:N（挂在因子库下） | 库编码 + 版本号 | **版本化载体**；状态 draft / published / history；**发布后不可改，只能新建版本或回滚到历史版本** |

```text
因子库（FactorLibrary）
├── 库编码 / 库名称 / 库来源（external 商业数据库｜builtin 自建）
├── 库描述 / 维护方 / 当前发布版本 / 版本数 / 因子数
└── 库版本（FactorLibraryVersion，1:N）
    ├── 版本号（外部库 3.11｜自建库 V1.0）/ 适用年度（选填）
    ├── 版本状态：draft 草稿 → published 生效中 → history 历史版本（另有回滚边：history → published）
    ├── 基于版本（快照来源）/ 更新说明 / 因子数 / 发布人 / 首次发布时间 / 最近一次生效时间
    └── 库内因子（FactorItem，1:N）—— 统一字段集（16 项，V0.4 对齐原型）
        ├── 因子编码 / 名称 / 因子别名 / 英文名称 / 适用场景 / 单位类别
        ├── 录入方式（总指标 / 分指标）+ GWP 分项口径（化石 / 生物碳 / 土地利用）
        ├── 因子数值 + 分子单位 + 分母单位 + 适用区域
        ├── 归属库 libraryId / 归属库版本 libraryVersionId
        ├── ext 扩展对象（商业数据库专有，选填）
        └── exchanges 输入输出子表（商业数据库专有，选填，含碳类型）

发布规则（软件发版模型：同一库同时只有一个「生效中」版本）：
├── 草稿 draft：可编辑 / 可删除；前台不可见、不参与匹配
├── 生效中 published：前台默认展示；发布后不可修改
├── 历史版本 history：发布新版本或回滚时，上一生效中版本自动转历史；只读，仅供追溯
├── 回滚：历史版本 → 生效中（当前生效版本自动转历史），内容不变、不新增版本号
└── 发布时间：publishedAt = 首次发布时间（回滚不覆盖）；lastActivatedAt = 最近一次生效时间
```

**因子单位为何拆为「分子单位 + 分母单位」**

```text
因子的物理含义是一个复合单位比值，例如：  kgCO₂e / kWh

分子 = 碳排放量类单位（引用计量单位库的「碳排放量」类型：gCO₂e / kgCO₂e / tCO₂e）
分母 = 活动量类单位（重量 / 能量 / 体积 / 距离 / 数量 …，须与活动数据单位同类型、可换算）

为什么不设单一「因子单位」字段：
  计量单位库（A1-9）维护的是【单一单位】，不含复合单位；
  若用一个自由文本字段写 "kgCO₂e/kWh"，系统无法校验分母类型，
  也就无法自动判定 E04（因子单位与活动单位不可换算）。
```

### 5.4 排放源归类（**非因子字段**，V0.3 迁移）

> **迁移说明（V0.3）**：原「因子分类（系统内置 6 类）」**不再属于因子字段** —— 因子（`FactorItem` / `MyFactor`）**不设 `category` / `industries`**，因子表单 / 详情 / 匹配**均不含分类**。该 6 类枚举**降级为核算结果的「排放源归类」展示口径**（原型 `PcfCalcSourceType = FactorCategory`，挂载在**核算结果 §4.7「排放源」维度**，系统内置、不开放维护），不再作为因子维护与自动匹配的维度。
> 因子的匹配 / 分类相关表述改用**已有字段**表达：**适用对象 / 适用阶段 + 单位 + 区域 / 年度**。

下表为**核算结果「排放源」维度的归类口径**（非因子字段，供结果汇总与报告展示）：

| 归类 | 含义 | 典型支撑对象 | 因子单位示例 | 备注 |

## 9. 待确认事项

### 9.1 已确认 / 已修订决策

| 编号 | 结论 |
| :--- | :--- |
| **因子表达口径（方案 §6.1.1 / Q01）** | 因子分母采用「**按物理量**」口径：分母 = 实物量单位（`kg` / `m³` / `L` / `kWh` / `t·km`）；能源库**不需「热值 + 热值单位」**（本期不落） |
| **因子规定本版本固定（方案 §4.3.1 · D4）** | **不做因子规定配置页**：匹配规则与优先级由核算模型结构化配置段承载、随模型版本冻结、只读展示；**匹配结果始终人工确认、可替换留痕** |
| **多库 + 库级版本化（V0.2）** | 版本化载体 = **库版本**（弃用因子级版本）；**发布后不可改，只能新建版本**；发布新版本时上一已发布版本**自动冻结**；前台默认展示最新已发布版本 |
| **前后台对象分离（V0.2）** | 后台「因子库」= 多库 + 库级版本化 + 发布；前台「我的因子库」= 组织私有库（收藏副本 + 手工新增），**不发布、不参与共享、不版本化**；**字段同源、对象分离** |
| **不设因子级「来源」/「版本」/「版本状态」/「有效期」** | 来源由库来源推导；版本化上移到库版本；有效期由版本状态承载 |
| **不设因子级「分类 / 适用行业 / 来源信息」（V0.3）** | 分类降级为**核算结果的排放源归类**（非因子字段）；来源由**库来源**表达；因子的「来源信息」类字段（来源类别 / 发布年份 / 发布日期 / 发布国家·组织 / 发布机构全称·简称 / 数据来源文件）**全部取消** |
