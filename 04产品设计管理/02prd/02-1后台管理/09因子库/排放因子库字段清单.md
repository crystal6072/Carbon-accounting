# 排放因子库字段清单

> **文档定位**：排放因子库字段定义的唯一真相源（SST）。业务 PRD 和 Demo PRD 只引用字段名称，不重复维护枚举、必填性和字段口径。
> **适用类型**：**核算模型域对象** —— 与基础库模块（物料 / 能源 / 计量单位 / 标准文件）不同，**有版本化 + 有效期**（方案 §4.9 口径 1）；**无审核流**、无单据下推
> **模块归属**：**两处复用一套字段** —— 后台管理 → 核算模型 → 排放因子库（方案 §2.3 A2-6 / A2-7、§4.4、§八 P15；原型 `/model/factor`）+ 前台业务平台 → 我的因子库（方案 §2.3 B4、§八 P29；原型 `/pcf/my-factor`）
> **核心用途**：提供「**活动数据 → 碳排放量**」的换算系数（方案 §1.4 术语）；本期口径 **CO₂ / CO₂e（CO₂e ≡ CO₂）**
> **维护形态**：列表 + 独立详情页 + 独立新增/编辑页 + Excel 批量导入
> **成熟度**：粗纲
> **版本**：V0.1
> **更新时间**：2026-09-21

## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 排放因子库 |
| 业务归属 | 后台管理 → 核算模型 → 排放因子库（方案 §2.3 A2-6 environment 库 / A2-7 自定义因子库、§4.4、§八 P15）；前台 → 我的因子库（方案 §2.3 B4、§八 P29） |
| 模块类型 | **核算模型域对象**（配置类），非业务单据；**有版本化 + 有效期**、**无审核流** |
| 核心对象 | 排放因子（一个版本 = 一条版本记录，承载在「因子编码」之下） |
| 核心职责 | 提供「**活动数据 → 碳排放量**」的换算系数，使 `碳排放量 = 活动数据 × 排放因子 × 单位换算系数 × 分配系数` 可计算（方案 §6.1.1）。**本模块只回答"用多大系数换算"，不回答"活动量是多少"** |

| 只读反查 | 引用情况 | — | — | 引用本因子的活动数据（P22）/ 核算项目清单（用于编辑与删除约束，D09） |

**因子单位为何拆为「分子单位 + 分母单位」**

```text
因子的物理含义是一个复合单位比值，例如：  kgCO₂e / kWh

分子 = 碳排放量类单位（引用计量单位库的「碳排放量」类型：gCO₂e / kgCO₂e / tCO₂e）
分母 = 活动量类单位（重量 / 能量 / 体积 / 距离 / 数量 …，须与活动数据单位同类型、可换算）

为什么不设单一「因子单位」字段：
  计量单位库（A1-9）维护的是【单一单位】，不含复合单位；
  若用一个自由文本字段写 "kgCO₂e/kWh"，系统无法校验分母类型，
  也就无法自动判定 E04（因子单位与活动单位不可换算）。
```

> **备选口径 B**：设单一「因子单位」自由文本字段（如 `kgCO₂e/kWh`），E04 由人工判断。代价是丧失自动校验能力，**不推荐**。取舍见 §9 Q02 / Q05。

### 5.2 来源（数据来源，仅用于权限判定）

| 枚举值（展示） | 数据来源枚举 | 含义 | 是否默认 | 备注 |
| :--- | :--- | :--- | :---: | :--- |

### 9.2 优先处理

**Q01：因子的表达口径 —— 「按物理量」还是「按能量」（跨模块阻塞项）**

| 口径 | 含义 | 对能源库的影响 |
| :--- | :--- | :--- |
| **A（本清单推荐）** | 因子分母 = **实物量单位**（`kg` / `m³` / `L` / `kWh` / `t·km` …） | 能源库**不需要**「热值 + 热值单位」—— **与能源库现状（6 项、不落热值）一致** |
| B | 因子分母 = **能量单位**（`MJ` / `kWh`） | 能源库**必须补**「热值 + 热值单位」，且需允许活动数据侧覆盖批次热值 |
| C | 两套口径并存 | 能源库补热值，且引擎需按单位自动判路径，E04 与自动匹配复杂度上升 |

> **本清单已按口径 A 撰写**（因子分母为实物量单位）。该结论**决定能源库「热值 + 热值单位」是否必需**，与方案**附录二 · 后续动作第 5 项**及 `04prompt/2-13能源字段清单.md` 直接相关：**若采纳 A，则能源库"不落热值"的现状无需回改**。**请业务确认。**
