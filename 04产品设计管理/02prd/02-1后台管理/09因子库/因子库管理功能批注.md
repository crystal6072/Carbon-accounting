## 1. 拟添加的批注清单

### 1.1 整体流程

#### B13-01 因子库维护整体流程
**拟标注位置**：页面标题「因子库管理」附近（全局说明）
**标记**：已确认

**批注内容**

- **适用场景**：平台 / 组织管理员在后台维护排放因子库，为核算引擎提供「活动数据 → 碳排放量」的换算系数。没有有效因子，核算无法进行。
- **流程**：进入「因子库管理」→ 库列表以卡片网格展示全部因子库 → 新建因子库（选择库来源）→ 进入库详情 → 新建库版本（草稿）→ 在草稿版本内维护库内因子 → 发布版本（原生效版本自动转历史、前台可见）。
- **分支**：由「库来源」分两条支路 —— **商业数据库**只能通过整库导入建立、库内因子只读；**自建库**可在草稿版本内逐条新增 / 编辑 / 删除因子，也可批量导入。
- **衔接**：库列表点库名称 / 「查看」进入库详情；库详情点因子名称进入因子详情页；因子新增 / 编辑走**独立页面**（非弹窗）；库的新建 / 编辑、库版本的新建、导入走**弹窗**。
- **结束**：发布新版本后，该库的上一生效中版本自动转为历史版本；全流程没有提交、审核、驳回，也没有「作废 / 终结」状态。已发布内容要变更，一律通过「新建版本」承载。
- **更新循环**：需要更新因子时，回到库详情 → 新建版本（以当前生效版本因子为快照生成草稿）→ 在草稿内维护 → 再次发布。
- **回滚循环**：新版本发布后发现问题，可在「版本记录」中把某个历史版本**回滚**为生效版本（当前生效版本自动转历史），无需新建版本。

### 1.2 全局规则说明

#### B13-02 全局规则
**拟标注位置**：页面标题「因子库管理」附近（与整体流程同一全局说明入口）
**标记**：已确认（其中权限、库编码、库来源文案为待确认，见 §3）

**批注内容**

1. **三层结构**：本模块维护「**因子库 → 库版本 → 库内因子**」三级对象；**版本化的载体是「库版本」**（不是单个因子），发布与转历史都以库版本为单位。
2. **多库**：平台可维护多个因子库，库之间彼此独立；因此浏览采用「**库列表 → 库详情**」层级导航，不用顶部 Tab 切库。
3. **库来源两类**：**商业数据库**（枚举 `external`，整库导入、库内因子只读）与**自建库**（枚举 `builtin`，库内因子可增删改、可批量导入）。库来源在新建时选定，**编辑时不可更改**。
4. **库级版本化**：一个库可有多个版本；版本状态为**草稿 / 生效中 / 历史版本**（软件发版模型）；**同一库同时只有一个「生效中」版本**、至多一个草稿版本。
5. **发布即转历史**：发布新版本时，该库的**上一生效中版本自动转为「历史版本」**，同时该版本成为库的当前生效版本；**发布前校验草稿因子数 > 0（空版本不可发布）**、**版本号库内唯一**。
5.1 **回滚**：新版本有问题时，可把某个**历史版本直接回滚为生效版本**（当前生效版本自动转历史）；**版本内容不变、不新增版本号**；`publishedAt`（首次发布时间）不覆盖，仅更新 `lastActivatedAt`（最近一次生效时间）。**无「版本级下架」**——让版本下线只能「发布新版本替代」或「整库下架」。
6. **发布后不可修改**：任一版本一旦发布，其库内因子不可再改，也不可删除该版本；要变更只能「新建版本」或「回滚到历史版本」。
7. **变更不追溯**：发布新版本不影响已建核算项目与前台「我的因子库」的收藏副本；历史结果记录当时所用的「库 + 库版本」，需按新因子重算时按项目规则走重算流程。
8. **删除约束**：**已发布过的库须先「整库下架」才可删除**（下架后前台不可见、不参与匹配，历史结果与收藏副本仍可追溯）；**未发布库可直接删除**；库版本**仅草稿可删**（生效中 / 历史版本只读）；**商业数据库因子不可逐条删除、不可编辑**。
9. **不做匹配规则配置**：因子怎么匹配、谁优先，归核算模型 / 活动数据侧（本模块只提供因子数据，不做匹配规则配置页、不做因子规定配置页）。
10. **初始数据**：新建库保存后，系统自动为其创建一个**草稿版本 V1.0**（初始版本），库此时处于「未发布」。
11. **权限**：谁可维护因子库（平台级 / 组织级）、页面与按钮的可见性，原型未做任何限制 → **待确认**（见 §3）。
12. **演示数据说明**：原型库内数据为前端演示数据（含库编码、版本、因子），正式实现需由系统按真实维护记录生成。
13. **整库下架 / 上架**：库级开关，按钮文案为「下架 / 上架」，**库列表卡片与库详情页页头均可操作**。下架后**前台不可见、不参与因子匹配**；**版本状态不变**、库数据保留，可随时「上架」恢复；**下架是删库的前置条件**（已发布库须先下架才可删除）；下架期间不可发布 / 回滚（须先上架）。

**附：全局状态机（2026-10-14 补充，与 B13-04 / B13-05 / B13-10 / B13-16 / B13-16b / B13-17 配套阅读）**

```text
① 版本状态机（软件发版模型：同一库同时只有一个「生效中」版本）

    草稿 ──── 发布 ───► 生效中 ──── 发布新版本 ───► 历史版本
     │                                                ▲
     │ 删除                                            │ 回滚
     │（版本直接消失，不是「变成草稿」）                │（直接设为生效）
     ▼                                                │
  （不存在） ◄────────────────────────────────────────┘

  转移边：
  · 发布        草稿 → 生效中；同时原生效中版本自动转历史版本
  · 发布新版本  生效中 → 历史版本（被新版本替代）
  · 回滚        历史版本 → 生效中；同时当前生效中版本自动转历史版本
  · 删除（终止边）仅草稿可删，版本直接消失 —— 不存在「生效中 / 历史版本被删后回到草稿」

② 库级状态机（由版本状态 + 下架标记推导，决定删库入口）

    未发布 ── 库内首个版本被发布 ─► 已发布 ── 下架 ─► 已下架
      │                              │                   │
      │ 可直接删除                    │                   │ 上架
      ▼                              ▼                   ▼
    （删除）                    （不可删除，          （可删除）
                                 须先下架）
```

> **读图要点**：①「生效中」是唯一出口版本——发布新版本或回滚都是**原子替换**（一个进、一个出），不会出现零生效中；②「删除」只作用在草稿上，是终止边；③「下架」是库级开关，不改版本状态，但它是删库的前置条件。

### 1.3 业务状态说明

#### B13-03 库来源
**拟标注位置**：库列表卡片的来源标签、「新建因子库」弹窗「库来源」字段、库详情「库信息卡」的库来源行
**标记**：已确认（展示文案为待确认）

**批注内容**

- **含义**：说明因子库的获取方式，**决定库内因子能否被逐条维护**。
- **两种取值与口径**：
  - **商业数据库**（`external` 商业数据库）：由整库导入建立；**库内因子只读**，不可逐条增删改；如需更新，**新建版本后重新整库导入**。
  - **自建库**（`builtin`）：由平台 / 组织自行维护；**库内因子可增删改**，支持批量导入。
- **进入条件**：新建库时选择；**编辑库时库来源锁定，不可更改**。
- **可进行的操作**：两类库都支持「新建版本」「发布」「查看」；只有自建库的草稿版本额外支持「新增因子」「编辑 / 删除因子」。
- **对下游的影响**：库来源不改变「发布后前台可见、可被匹配」的规则，只改变库内因子的可维护性。
- **展示方式**：原型以标签展示，商业数据库为「商业数据库」、自建库为「自建库」，并附一句来源说明（「整库导入 · 库内只读」/「可新增 / 编辑 / 导入」）。
- **已统一（2026-10-14）**：库来源展示名统一为「**商业数据库**」（枚举 `external` / `builtin`），文档与原型一致（见 §3 X-01）。

#### B13-04 版本状态
**拟标注位置**：库详情「版本记录」Tab 的版本状态列、「当前版本」切换下拉、库详情顶部版本操作按钮
**标记**：已确认

**批注内容**

- **含义**：库版本的发布状态，决定该版本是否前台可见、能否被匹配、能否被编辑。
- **三个状态与口径**（软件发版模型：同一库同时只有一个「生效中」版本）：
  - **草稿**：新建 / 编辑中，未发布；**前台不可见、不参与匹配**；自建库草稿可编辑库内因子，可发布、可删除。
  - **生效中**（`published`）：当前对外生效的版本（唯一）；**前台默认展示、可被匹配**；**发布后不可修改**，只能新建版本或回滚。
  - **历史版本**（`history`）：被新版本或回滚替代的历史版本；**只读、仅供追溯**，前台可查历史，不参与匹配；**可回滚重新设为生效**。
- **进入条件**：新建版本即「草稿」；草稿经「发布」进入「生效中」；发布新版本或回滚时，该库上一生效中版本自动进入「历史版本」。
- **变化方向**：草稿 → 生效中 → 历史版本；另有回滚边：历史版本 → 生效中（内容不变、不新增版本号）。
- **对下游的影响**：只有「生效中」版本内的因子可被业务侧引用与匹配；草稿、历史版本均不可被新项目匹配（历史项目仍可追溯其当时所用版本）。
- **展示方式**：版本记录表以状态标签展示；库内因子 Tab 的「当前版本」下拉同步展示「版本号（状态）」。
- **状态机全景**：见 B13-02 附注「全局状态机 · ① 版本状态机」（含发布 / 发布新版本 / 回滚 / 删除四条边）。

#### B13-05 库级状态
**拟标注位置**：库列表卡片「已发布 / 未发布 / 已下架」、「版本记录」Tab
**标记**：已确认

**批注内容**

- **含义**：由版本状态推导的库整体状态，影响库能否删除与上下架。
- **三种取值**：
  - **未发布**：该库还没有任何生效中版本（如新建后仅有一个草稿 V1.0）。
  - **已发布**：该库存在生效中版本（前台可见）。
  - **已下架**：整库下架中（前台不可见、不参与匹配；版本状态不变）。
- **规则**：**已发布库须先「下架」才可删除**（下架后不在前台可见、不参与匹配，历史结果仍可追溯）；**未发布库可直接删除**（连同其全部版本与库内因子一并删除）。
- **推导关系**：新建库 → 自动生成草稿 V1.0 → 库为「未发布」；库内某版本被发布后 → 库转为「已发布」；对已发布库执行「下架」→ 库为「已下架」（此时才出现删除入口）。
- **状态机全景**：见 B13-02 附注「全局状态机 · ② 库级状态机」（未发布 → 已发布 → 已下架，及删库入口出现条件）。

### 1.4 操作功能及对应业务规则

#### B13-06 库列表
**拟标注位置**：库列表卡片网格区域、卡片内容与卡片操作区
**标记**：已确认

**批注内容**

- **操作目的**：总览平台全部因子库，快速进入某个库进行维护或查看。
- **展示形式**：卡片网格（非表格）；每张卡片展示：**库名称**（可点，进入库详情）、**库来源标签**、**库编码**、**库描述**、**维护方**、**版本数**、**因子数**、**已发布 / 未发布**、来源说明、**更新时间**。
- **操作列**：「查看」（进入库详情）、「编辑」（打开编辑弹窗）、「删除」（二次确认后删除），三者恒显示。
- **无分页 / 无勾选 / 无批量**：本页为卡片网格，不提供分页、勾选与批量操作。
- **无内容时**：显示「暂无因子库」；加载过程中显示「加载中…」。

#### B13-07 库查询与重置
**拟标注位置**：库列表上方查询条
**标记**：已确认（搜索按钮行为、状态筛选为待核对 / 待确认）

**批注内容**

- **操作目的**：在库列表中快速定位目标库。
- **查询项**：① **库名称 / 编码** —— 一个输入框，按名称或编码**包含关系模糊匹配、忽略大小写**；② **库来源** —— 下拉选择「商业数据库 / 自建库」，不选即为全部。
- **规则**：两个条件叠加过滤；输入条件后列表**即时收敛**（无需点按钮）；「重置」清空全部条件并恢复完整列表。
- **搜索按钮**：点「搜索」原型只出现一次「查询完成」提示、不产生额外动作（输入时列表已即时收敛）。
- **待确认**：文档提到库列表可按「来源 / **状态**」筛选，原型**没有「状态（未发布 / 已发布）」筛选**（见 §3 X-03）。

#### B13-08 新建因子库
**拟标注位置**：页头「新建因子库」按钮、「新建因子库」弹窗
**标记**：已确认（库编码为待确认）

**批注内容**

- **操作目的**：建立一个新因子库。
- **入口**：库列表页头「新建因子库」。

#### B13-16b 回滚到历史版本（**2026-10-14 新增**）
**拟标注位置**：版本记录行「回滚到此版本」按钮、库详情页头「回滚到此版本（X）」按钮旁
**标记**：已确认

**批注内容**

- **操作目的**：新发布的版本有问题时，直接把某个历史版本恢复为生效版本，无需新建版本。

#### B13-21 商业数据库整库导入
**拟标注位置**：库详情页头「整库导入」按钮、导入弹窗

- **操作过程（三步）**：

- **待确认**：① 文档描述商业数据库为「**整库导入**（结构性数据，非模板逐条录入）」，原型统一降级为 **CSV 模板导入**（见 §3 X-07）；② 文档要求**自建库支持 Excel 批量导入**，原型库详情**仅商业数据库有导入入口**，自建库无入口（见 §3 X-07）；③ 文档要求「导入记录 / 批次留痕」，原型**未实现**（见 §3 X-08）。

#### B13-38 因子值 与 GWP 分项口径
**拟标注位置**：因子表单「因子值（温室气体：总体）」/ 分项输入与「合计」、分指标明细表、因子详情指标明细
