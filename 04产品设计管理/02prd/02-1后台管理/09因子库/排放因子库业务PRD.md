## 1. 需求概述

### 1.1 需求背景

因子库是核算引擎的**换算系数来源** —— 提供「**活动数据 → 碳排放量**」的换算系数（方案 §1.4 术语），使核算链路成立：

```text
碳排放量 = 活动数据 × 排放因子 × 单位换算系数 × 分配系数     （方案 §6.1.1）
```

**没有有效因子，则核算无法进行** —— 方案 §5.4 **E03** 明确规定：因子缺失**阻断计算与报告，禁止按 0 排放**。

因子库同时承接**标准差异的一部分**：方案 §4.3.1 把「因子规定」列为核算模型七要素之一，但**决策 D4** 明确本版本**固定因子规定、不做配置页** —— 匹配规则与优先级由系统内置预置，作为模型的**结构化配置段**随模型版本冻结、只读展示；**真正开放配置的是因子数据本身**（CRUD / Excel 导入 / 区域年度 / 版本）。因此：

| 归属 | 模块 | 因子库的角色 |
| :--- | :--- | :--- |
| 有哪些因子、数值多少、什么单位、适用什么对象 / 阶段 / 区域 / 年度 | **因子库（本模块）** | 唯一维护方 |
| 因子怎么匹配（活动类型 + 阶段 + 区域 + 年度 → 因子类型）、谁优先 | **核算模型 A2-3（D4）** | 因子库**只遵循**，不做配置页 |
| 活动量是多少、数据从哪来、DQR 多少 | **活动数据（§4.6）** | 因子库不承载 |
| 生物碳是否计入、是否对称 | **核算模型（§6.5）+ 项目** | 因子库只提供**负因子 + 生物碳标记** |

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :--- | :--- | :--- |
| G1 | 提供因子字典 | 字段覆盖方案 §4.4 全部关键字段（名称 / 数值 / 单位 / 适用对象 / 适用阶段 / 区域 / 适用年度 / 来源 / 版本 / 有效期 / 状态 / 归属组织 / 数据质量等级） |
| G2 | 参与计算的活动数据 100% 匹配到有效因子 | 无有效因子时触发 **E03** 阻断，禁止按 0 排放 |
| G3 | 单位不可换算时被阻断 | 因子分母单位 ↔ 活动单位不可换算时触发 **E04** 阻断 |
| G4 | 自定义因子优先且可追溯 | 匹配优先级「组织自建 > 系统预置」；结果可还原所用因子版本（方案 §6.3） |
| G5 | 版本化与有效期可追溯 | 发布后不可变、只能出新版本；结果记录所用因子版本；历史项目可按当年因子追溯 |
| G6 | 生物碳负因子可用且对称 | 负因子计入由模型开关控制；吸收计入后末期未对称处理触发 **E16** |
| G7 | 划清与匹配规则 / 活动数据的边界 | 因子库**不含**匹配规则配置页，**不含**活动量字段（§4） |

### 1.3 In Scope / Out of Scope

**In Scope**

| 能力 | 说明 |
| :--- | :--- |
| 因子列表与查询 | 按分类、名称、区域、年度、来源、版本状态、使用状态筛选 |
| 新增 / 编辑 / 查看因子 | 元数据与数值维护；详情含引用情况（引用本因子的活动数据 / 项目） |
| **版本化与发布** | 草稿 → 已发布 → 已冻结；**发布后不可改，只能出新版本** |
| 有效期维护 | 生效日期 / 失效日期 |
| 启用 / 禁用 | 行操作 + 二次确认；支持批量启用 / 禁用 |
| **Excel 批量导入** | 模板导入 + 导入批次留痕（环境库运营端 / 自定义库用户端） |
| 导出 | 导出当前查询结果 |
| 两档来源 | `environment 库`（系统预置只读）/ `自定义因子库`（组织自建可编辑） |
| 因子匹配（业务侧） | 按「活动类型 + 阶段 + 区域 + 年度」自动推荐 → **人工确认 / 替换 / 留痕** |
| 生物碳负因子 | 数值为负 + 「生物碳类型」标记 |

**Out of Scope**

| 不做项 | 说明 |
| :--- | :--- |
| **因子规定配置页** | **决策 D4**：匹配规则与优先级由核算模型的结构化配置段承载、随模型冻结、**只读展示**；本模块不做配置入口 |
| **因子匹配规则配置页** | 同上，归核算模型 A2-3 |
| CH₄ / N₂O 特征化与 GWP 集 | 方案 §6.1.2，**仅预留「气体种类」字段**（本期固定 CO₂） |
| 背景库商用授权对接 | 方案 §十一 2（平台决策，见 Q14） |
| 活动量 / 数据获取方式 / 数据状态 / 凭证 | 属**活动数据**（方案 §4.6），在 P22 填报 |
| 计算引擎算法与公式实现 | 方案 §6.1 |
| 「吸收量依据」的填报粒度 | 方案 §十一 4；归**物料库 / 项目**，不在本模块（见 Q11） |
| 审核流 / 单据下推 / 外部系统同步 | 因子库为配置类对象，均不涉及 |

## 2. 用户与使用场景

### S01 维护 environment 库（平台侧）

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 平台需要录入背景因子（如省级电网因子逐年发布） |
| 操作流程 | 平台运营新增因子 → 选因子分类 → 填数值、分子 / 分母单位、适用对象 / 阶段 → 电力类填区域 + 年度 → 填 DQR → 发布 |
| 预期结果 | 因子创建成功，来源 = 系统预置（`environment 库`），版本状态 = 已发布；全体租户可引用 |

### S02 专业配置人员维护平台级因子

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需补充平台级通用因子 |
| 操作流程 | 同 S01 |
| 预期结果 | 同上；**平台级因子不可被租户编辑** |

### S03 组织自建自定义因子

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 组织有自有因子（如自有供应商材料因子、企业实测因子） |
| 操作流程 | 在前台「我的因子库」新增因子 → 填写完整信息 → 发布 |
| 预期结果 | 来源 = 组织自建（`自定义因子库`），归属组织 = 本组织；**本组织及上级可见，其他租户不可见**；**匹配时优先于系统预置因子** |

### S04 Excel 批量导入因子

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要批量录入因子（运营端导入背景库 / 用户端导入自有因子） |
| 操作流程 | 下载模板 → 填写 → 上传导入 → 系统按「因子编码 + 版本」判重并校验单位 / 枚举 → 返回导入结果 |
| 预期结果 | 成功行入库；失败行返回失败清单与原因；**导入批次与来源留痕**（方案 §4.4） |

### S05 因子版本管理与有效期

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 因子数值 / 区域 / 年度需更新（如电网因子发布新年份） |
| 操作流程 | 在既有因子编码下**新建版本** → 填新数值 / 年度 → 发布 → 旧版本自动转「已冻结」 |
| 预期结果 | 新版本可被新匹配引用；**旧版本冻结不可改，仅供历史结果追溯**；**已建项目不追溯**，需重算走 **E13** |

### S06 因子匹配（**核心场景**）

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 活动数据填报完成，需匹配排放因子 |
| 操作流程 | 系统按「活动类型 + 阶段 + 区域 + 年度」自动推荐因子（**组织自建优先**）→ 用户核对 → **确认 / 替换** → 留痕 |
| 预期结果 | 每条参与计算的活动数据匹配到**一条有效因子**；替换记录留痕；无有效因子时触发 **E03** |

### S07 单位不一致时的处理

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 因子分母单位与活动数据单位不可换算 |
| 操作流程 | 系统经计量单位库检验 → 不可换算则提示 → 用户补充换算关系或改选因子 |
| 预期结果 | 补换算关系后可通过；否则触发 **E04** 阻断，**记录换算来源**（方案 §5.4） |

### S08 生物碳负因子的使用与固碳开关联动

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 项目涉及生物碳固碳（如原竹） |
| 操作流程 | 引用「生物碳因子（负排放）」→ 模型侧开启固碳开关 → 计入吸收 → 摇篮到坟墓项目在末期配置**生物碳释放**或注明长期储存 |
| 预期结果 | 吸收计入生效；若末期未对称处理，触发 **E16**（方案 §6.5） |

### S09 因子被引用后的编辑 / 禁用 / 删除限制

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 因子已被活动数据匹配引用，或已发布 |
| 操作流程 | 尝试编辑 / 禁用 / 删除该因子 |
| 预期结果 | **不可编辑、不可删除**（对齐 §4.9）；详情页展示「引用本因子的活动数据 / 项目清单」；如需变更以**新版本**承载 |

### S10 查看因子详情与引用情况

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要确认因子信息或被谁使用 |
| 操作流程 | 列表点名称进入详情 → 查看元数据、版本历史、引用情况 |
| 预期结果 | 展示完整字段 + 版本历史 + 引用清单 |

## 4. 因子库的定位边界（**核心章节之一**）

### 4.1 「管什么 / 不管什么」总表

| 边界对象 | 归属模块 | 因子库的写法 |
| :--- | :--- | :--- |
| 因子的数值 / 单位 / 适用对象 / 适用阶段 / 区域 / 年度 / 版本 / 有效期 / 状态 / 来源 / 归属组织 / DQR | **因子库** | 本模块维护 |
| **因子匹配规则与优先级**（活动类型 + 阶段 + 区域 + 年度 → 因子类型；组织自建 > 系统预置） | **核算模型 A2-3（D4）** | **不在因子库做配置页**；因子库只**遵循**该规则，匹配结果人工确认可替换 |
| 因子分类字典 / 气体种类字典 | **因子库（系统内置枚举）** | 本模块承载，不开放维护 |
| 活动量（数量 / 单位 / 数据期间 / 数据获取方式 / DQR / 数据状态 / 凭证） | **活动数据 §4.6 / P22** | 只引用，不定义 |
| 单位定义、换算关系、单位类型 | **计量单位库 A1-9** | 只引用（因子单位与活动单位须可换算，否则 E04） |

## 5. 因子来源与匹配机制（**核心章节之二**）

### 5.1 因子表达的基准口径（**已确认**）

```text
因子 = 因子数值 + 因子分子单位 + 因子分母单位
     = 数值  [碳排放量单位] / [活动量单位]

示例：
  电力（全国电网）：  0.5703  kgCO₂e / kWh
  天然气燃烧：        2.1622  kgCO₂e / m³
  原竹（材料因子）：  0.0380  kgCO₂e / kg
  公路货运（运输）：  0.1070  kgCO₂e / (t·km)
  原竹固碳（生物碳）： -1.8300 kgCO₂e / kg    ← 负排放因子
```

**已确认结论（本次）**：因子分母采用 **「按物理量」** 口径 —— 分母为**活动量的实物量单位**（`kg` / `m³` / `L` / `kWh` / `t·km` / `件`），分子恒为**碳排放量单位**（`kgCO₂e`）。

| 口径 | 结论 | 对能源库的影响 |
| :--- | :--- | :--- |
| **按物理量（本次采纳）** | 活动数据直接用实物量 × 因子，**1 次换算** | 能源库**不需要**「热值 + 热值单位」—— 与其现状（6 项、不落热值）**一致**，无需回改 |
| 按能量（未采纳） | 需先「实物量 × 热值 → 能量」再 × 因子 | 能源库须补「热值 + 热值单位」，且需支持活动数据侧覆盖批次热值 |
| 两套并存（未采纳） | 靠单位区分计算路径 | E04 校验与自动匹配复杂度翻倍 |

> **本结论关闭方案「附录二 · 后续动作第 5 项」**：因子表达口径已定为**按物理量**，能源库的「热值 + 热值单位」**本期不落**（与 `04prompt/2-13能源字段清单.md`、方案附录二第二节第 5 项一致）。**该结论需业务在 §9 Q01 正式追认。**

## 6. 业务规则

## 7. 状态与操作矩阵

### 7.1 状态维度说明

| 状态维度 | 取值 | 来源 |
| :--- | :--- | :--- |
| 数据来源 | 系统预置（`environment 库`）/ 组织自建（`自定义因子库`） | 字段清单（决定可编辑性与可见范围） |

### 7.2 操作矩阵

| 数据来源 | 版本状态 | 引用状态 | 编辑 | 发布 | 禁用 | 删除 | 被匹配引用 |
| :--- | :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| 系统预置 | 草稿 | 未被引用 | 否（仅平台运营） | 是（仅平台运营） | — | 否（R-008） | 否 |

| 系统预置 | 已发布 | 已被引用 | 否 | — | 否 | 否 | 是 |
| 系统预置 | 已冻结 | 任意 | 否 | 否 | 否 | 否 | 否（仅供追溯） |
| 组织自建 | 草稿 | 未被引用 | 是 | 是 | — | 是 | 否 |
| 组织自建 | 已发布 | 未被引用 | **否**（R-002，须新建版本） | — | 是 | 否 | 是 |
| 组织自建 | 已发布 | 已被引用 | 否 | — | 否（R-008） | 否（R-008） | 是 |
| 组织自建 | 已冻结 | 任意 | 否 | 否 | 否 | 否 | 否（仅供追溯） |

**闭环校验**

- 版本状态：草稿 → 已发布 → 已冻结 正向可达，无回退（保证「发布后不可变」）；
- 组织自建草稿版本有完整生命周期（编辑 / 发布 / 删除）；
- 「已发布」构成**编辑封锁**（只能新建版本）；「已被引用」再叠加**禁用、删除**限制（R-008）；
- 系统预置因子：租户侧**全锁**，仅平台运营可维护（R-004）；
- 「禁用 / 冻结」为**软停用**：已匹配处仍只读回显 + 标注「已禁用 / 已冻结」，不影响历史结果；
- 无审核分支，无死状态。
