## 1. 需求概述

### 1.1 需求背景

因子库是核算引擎的**换算系数来源** —— 提供「**活动数据 → 碳排放量**」的换算系数（方案 §1.4 术语），使核算链路成立：

```text
碳排放量 = 活动数据 × 排放因子 × 单位换算系数 × 分配系数     （方案 §6.1.1）
```

**没有有效因子，则核算无法进行** —— 方案 §5.4 **E03** 明确规定：因子缺失**阻断计算与报告，禁止按 0 排放**。

**V0.2 的重大变化（多库模型）**：原模型是「扁平单表 + 因子级版本」，因子自带 `source`（系统预置 / 组织自建）与版本字段。随商业数据库（如 Ecoinvent 3.11、CPCD 等整库导入、库内只读）与行业实测库的引入，扁平单表已无法承载：

| 变化 | 口径 |
| :--- | :--- |
| **多库** | 一个平台可有多个因子库（如「中国官方排放因子库」「行业实测因子库」「Ecoinvent」），库之间彼此独立 |
| **库来源两类** | `external` 商业数据库（整库导入、**库内只读**）+ `builtin` 自建库（因子可增删改、批量导入） |
| **库级版本化** | 版本化载体由「因子」**上移到「库版本（FactorLibraryVersion）」**；一个库多版本，发布后不可改、只能新建版本；发布新版本时**上一已发布版本自动冻结** |
| **前后台对象分离** | 后台 = 平台级/运营侧的「因子库」维护面；前台 = 组织私有的「我的因子库」（收藏副本 + 自建），**不发布、不版本化**（见《我的因子库业务 PRD》） |

因子库同时承接**标准差异的一部分**：方案 §4.3.1 把「因子规定」列为核算模型七要素之一，但**决策 D4** 明确本版本**固定因子规定、不做配置页** —— 匹配规则与优先级由系统内置预置，作为模型的**结构化配置段**随模型版本冻结、只读展示；**真正开放配置的是因子库数据本身**（多库 CRUD / 库版本发布 / 区域年度 / Excel 导入）。因此：

| 归属 | 模块 | 因子库的角色 |
| :--- | :--- | :--- |
| 有哪些库、库有哪些版本、库内有哪些因子、数值多少、什么单位、适用什么对象 / 阶段 / 区域 / 年度 | **因子库（本模块）** | 唯一维护方 |
| 因子怎么匹配（活动类型 + 阶段 + 区域 + 年度 → 因子类型）、谁优先 | **核算模型 A2-3（D4）** | 因子库**只遵循**，不做配置页 |
| 活动量是多少、数据从哪来、DQR 多少 | **活动数据（§4.6）** | 因子库不承载 |
| 收藏副本、更新提醒、一键更新 | **我的因子库（前台）** | 本模块负责后台侧「已发布版本可供前台收藏」 |

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :--- | :--- | :--- |
| G1 | 支持多因子库 | 平台可维护多个库，每个库有编码、名称、来源（商业数据库 / 自建）、维护方、当前发布版本、版本数、因子数 |
| G2 | 库级版本化与发布 | 一个库多版本；版本状态 = 草稿 / 生效中 / 历史版本；**同一库同时只有一个「生效中」版本**；发布后不可修改，只能新建版本；发布新版本时上一生效版本**自动转历史** |
| G3 | 前台默认展示当前生效版本 | 业务侧引用时默认取「当前生效版本」，历史版本可追溯；**新版本有问题可回滚**，直接把历史版本重新设为生效 |
| G4 | 商业数据库整库导入且只读 | `external` 库通过整库导入建立，库内因子**不可逐条增删改** |
| G5 | 自建库因子可维护 | `builtin` 库内因子可增删改、批量导入 |
| G6 | 参与计算的活动数据 100% 匹配到有效因子 | 无有效因子时触发 **E03** 阻断，禁止按 0 排放 |
| G7 | 单位不可换算时被阻断 | 因子分母单位 ↔ 活动单位不可换算时触发 **E04** 阻断 |
| G8 | 收藏副本不随源库自动变化 | 前台收藏 = 复制式快照；源库发布新版本**不自动影响**副本，仅通过「更新提醒 + 一键更新」手动刷新（见《我的因子库业务 PRD》） |
| G9 | 划清与匹配规则 / 活动数据的边界 | 因子库**不含**匹配规则配置页，**不含**活动量字段（§4） |
| G10 | 生物碳负因子可用且对称 | 负因子计入由模型开关控制；吸收计入后末期未对称处理触发 **E16** |

### 1.3 In Scope / Out of Scope

**In Scope**

| 能力 | 说明 |
| :--- | :--- |
| 因子库列表与查询 | **库列表（搜索 + 按来源 / 状态筛选 + 卡片网格）** |
| 新建 / 编辑因子库 | 库信息卡维护（编码、名称、来源、描述、维护方） |
| **库版本管理** | 新建版本（草稿，以当前生效版本为快照）→ 发布（原生效版本自动转历史）→ 查看版本记录 |
| **版本回滚** | 直接把历史版本重新设为生效（当前生效版本自动转历史）；版本内容不变、不新增版本号 |
| **库内因子维护** | 自建库内因子增删改；外部库只读 |
| **商业数据库整库导入** | 整库导入、库内只读；库内因子列表按「单位类别」展示、按 ISIC 门类分类 |
| **Excel 批量导入** | 自建库模板导入 + 导入批次留痕 |
| 导出 | 导出当前查询结果 |
| 库 / 版本 / 因子删除约束 | 草稿版本可编辑 / 删除；**已发布库须先「下架」才可删除**；未发布库可直接删除 |
| **整库下架 / 上架** | 库级下架：前台不可见、不参与匹配；数据保留、可重新上架；**下架后才可删库**。列表卡片与库详情均可操作，按钮文案「下架 / 上架」 |
| 因子匹配（业务侧） | 按「活动类型 + 阶段 + 区域 + 年度」自动推荐 → **人工确认 / 替换 / 留痕** |
| 生物碳负因子 | 数值为负 + 「生物碳类型」标记 |
| 前台可收藏 | 已发布版本因子供前台「我的因子库」收藏（复制副本） |

**Out of Scope**

| 不做项 | 说明 |
| :--- | :--- |

| **因子匹配规则配置页** | 同上，归核算模型 A2-3 |
| **顶部 Tab 切库** | 库数量会持续增长，采用「库列表 → 库详情」层级导航（不因库多而溢出、不可扩展） |
| **前台我的因子库的发布 / 版本化** | 前台私有库**不发布、不参与平台共享、不版本化**，见《我的因子库业务 PRD》 |
| CH₄ / N₂O 特征化与 GWP 集 | 方案 §6.1.2，**仅预留「气体种类」字段**（本期固定 CO₂） |

| 活动量 / 数据获取方式 / 数据状态 / 凭证 | 属**活动数据**（方案 §4.6），在 P22 填报 |
| 计算引擎算法与公式实现 | 方案 §6.1 |
| 审核流 / 单据下推 / 外部系统同步 | 因子库为配置类对象，均不涉及 |

### 4.2 为什么采用「库列表 → 库详情」而非顶部 Tab 切库

| 论据 | 说明 |
| :--- | :--- |
| 库数量会持续增长 | 平台会不断新增商业数据库（各版本）与自建库，**顶部 Tab 在库多时会溢出、不可扩展** |

## 5. 因子来源与匹配机制（**核心章节之二**）

### 5.1 因子表达的基准口径（**已确认**）

```text
因子 = 因子数值 + 因子分子单位 + 因子分母单位
     = 数值  [碳排放量单位] / [活动量单位]

示例：
  电力（全国电网）：  0.5703  kgCO₂e / kWh
  天然气燃烧：        2.1622  kgCO₂e / m³
  原竹：              0.0380  kgCO₂e / kg
  公路货运（运输）：  0.1070  kgCO₂e / (t·km)
  原竹固碳（生物碳）： -1.8300 kgCO₂e / kg    ← 负排放因子
```

**已确认结论**：因子分母采用 **「按物理量」** 口径 —— 分母为**活动量的实物量单位**（`kg` / `m³` / `L` / `kWh` / `t·km` / `件`），分子恒为**碳排放量单位**（`kgCO₂e`）。

| 口径 | 结论 | 对能源库的影响 |
| :--- | :--- | :--- |
| **按物理量（本次采纳）** | 活动数据直接用实物量 × 因子，**1 次换算** | 能源库**不需要**「热值 + 热值单位」—— 与其现状（6 项、不落热值）**一致**，无需回改 |
| 按能量（未采纳） | 需先「实物量 × 热值 → 能量」再 × 因子 | 能源库须补「热值 + 热值单位」，且需支持活动数据侧覆盖批次热值 |
| 两套并存（未采纳） | 靠单位区分计算路径 | E04 校验与自动匹配复杂度翻倍 |

> **本结论关闭方案「附录二 · 后续动作第 5 项」**：因子表达口径已定为**按物理量**，能源库的「热值 + 热值单位」**本期不落**（与 `04prompt/2-13能源字段清单.md`、方案附录二第二节第 5 项一致）。**该结论需业务在 §9 Q01 正式追认。**

### 5.2 库来源与维护权限

| 库来源 | 代码 | 库内因子 | 谁能维护 | 导入方式 | 可见性 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **商业数据库** | `external` | **只读**（不可逐条增删改） | 平台运营管理员 / 专业配置人员（整库导入 + 版本发布） | **整库导入** | 平台级（`PUBLIC` 只读） |
| **自建库** | `builtin` | **可增删改** | 平台运营管理员 / 专业配置人员（平台级）或组织管理员（组织自建） | 手工新增 + **Excel 批量导入** | 平台级 `PUBLIC` 或组织级 `ORG`（由维护方决定） |

> **后台与前台的关系（V0.2 修订，前后台对象分离）**：后台「排放因子库」= **多库维护面**（含商业数据库与自建库，库级版本化 + 发布）；前台「我的因子库」= **组织私有库**（收藏副本 + 手工新增，**不发布、不版本化**）。两者**字段同源**（库内因子与我的因子共用统一字段集），但**对象与生命周期不同** —— 详见《我的因子库业务 PRD》与字段清单。

### 5.3 库级版本化与发布（**软件发版模型，V0.6 起**）

```text
因子库（FactorLibrary）
  └── 库版本（FactorLibraryVersion）—— 版本化载体（同一库同时只有一个「生效中」版本）
        ├── 草稿 draft       ：可编辑 / 可删除；前台不可见、不参与匹配
        ├── 生效中 published ：当前对外生效的版本（唯一）；发布后不可修改，只能新建版本
        └── 历史版本 history ：曾生效过、已被新版本或回滚替代；只读，可回滚重新设为生效

状态流转：
  草稿 ──发布──► 生效中 ──发布新版本──► 历史版本
   │                                      ▲
   │ 删除                                 │ 回滚
   │（版本直接消失，不是「变成草稿」）      │
   ▼                                      │
  （不存在） ◄─────────────────────────────┘

  四条边：① 发布（草稿 → 生效中，原生效中自动转历史）；② 发布新版本（生效中 → 历史版本）；
  ③ 回滚（历史版本 → 生效中，当前生效中自动转历史）；④ 删除（终止边，仅草稿可删）。
  **不存在「生效中 / 历史版本被删后回到草稿」**——这两个状态只能被发布 / 回滚替代。

库级状态机（由版本状态 + `offline` 推导，决定删库入口）：
  未发布 ──首个版本被发布──► 已发布 ──下架──► 已下架
   │                          │                 │
   │ 可直接删除                │                 │ 上架
   ▼                          ▼                 ▼
  （删除）               （不可删除，        （可删除）
                         须先下架）
```

| # | 规则 |
| :--- | :--- |
| V1 | 外部库版本号形如 `3.11` / `3.12`；自建库版本号形如 `V1.0` / `2024` |
| V2 | **草稿版本**：可编辑库内因子（自建库）、可删除；前台不可见、不参与匹配 |
| V3 | **发布**：草稿 → 生效中；**发布后不可修改，只能新建版本** |
| V4 | **自动转历史**：发布新版本时，**上一生效版本自动转「历史版本」**；任一库**至多一个生效中版本** |
| V5 | **前台默认展示当前生效版本**；历史版本可追溯、只读 |
| V6 | 草稿版本可编辑 / 删除；**已发布库须先「整库下架」才可删除**（防止误删线上库；下架后库已不在前台可见、不参与匹配，历史结果与收藏副本仍可追溯）；**未发布库可直接删除** |
| V7 | 版本可含 `适用年度`（选填，如自建库按 `2024` 年度管理）；商业数据库版本号即其数据版本 |
| V8 | **回滚**：历史版本 → 生效中（当前生效版本自动转历史版本），即**直接把历史版本重新设为生效**；版本内容不变、**不新增版本号**；已建项目不受影响（核算结果按当时版本冻结） |
| V9 | **空版本校验**：草稿版本因子数为 0 时**禁止发布**（避免前台出现无有效因子的库，触发 E03）；**版本号在库内唯一**，重复时阻断 |
| V10 | **整库下架 / 上架**（库级 `offline`）：下架后前台不可见、不参与匹配；**版本状态不变**（仍保留生效中版本）、库数据保留、可随时重新上架；**下架后才可删库**（已发布库须先下架才可删除，未发布库可直接删）；下架期间不可发布 / 回滚（须先上架） |

**发布时间拆分（V0.6）**：`publishedAt` = **首次发布时间**（仅首次由草稿发布时写入，回滚不覆盖）；`lastActivatedAt` = **最近一次生效时间**（每次发布 / 回滚均更新）。版本列表排序按**版本号 / 创建时间**（稳定，不随回滚变化）。

**版本号语义（V0.6）**：版本号在库内唯一、**单调递增（= 发布次序，不表示血缘）**；血缘通过 `basedOnVersionNo`（新建版本时的快照来源版本号）记录。

> **V0.6 变更说明**：删除「版本级下架」及原「防空在线版本」校验——发布即自动转历史使 `published` 恒唯一，原校验在任何状态下都会命中，导致版本下架按钮永久禁用（死功能）。「下架」一词自此**仅指整库下架**（V10）。

## 6. 业务规则

| 规则编号 | 规则名称 | 触发条件 | 处理逻辑 | 例外策略 |
| :--- | :--- | :--- | :--- | :--- |
| R-001 | 库唯一性与编号 | 新建 / 编辑库时 | 「**库编码**」全局唯一、编辑只读；库名称不唯一 | 重复时阻断保存 |
| R-002 | **库级版本化与发布** | 保存 / 发布 / 回滚版本时 | 修改**不改生效中版本**，须**新建版本**；「生效中」后不可修改；**发布新版本时上一生效版本自动转「历史版本」**；**回滚直接把历史版本重新设为生效**（当前生效版本转历史，内容不变、不新增版本号）；**发布前校验版本非空、版本号库内唯一**；前台默认展示当前生效版本（V1～V10，对齐 §4.9） | 命中时阻断并提示「新建版本」/「整库下架」入口 |
| R-003 | 库版本与适用年度 | 新建版本时 | 版本号必填（外部库形如 `3.11`、自建库形如 `V1.0`）；适用年度选填；有版本则版本状态 = 草稿 | 命中时阻断 |
| R-004 | **库来源与权限** | 编辑 / 删除库内因子时 | **商业数据库的库内因子只读**（不可逐条增删改）；**自建库的库内因子可增删改** | 命中时阻断；商业数据库仅可整库替换为新版本 |
| R-005 | **因子匹配与优先级** | 活动数据匹配因子时 | 按「活动类型 + 阶段 + 区域 + 年度」自动推荐；**组织自建 > 平台级/商业数据库**；**人工确认可替换并留痕**；候选仅取**已发布版本**（M2 / M3 / M5） | 规则不覆盖时人工指定因子 |
| R-006 | **单位一致性校验** | 匹配 / 核算前置校验时 | 因子分母单位 ↔ 活动单位须**可换算**（经计量单位库基准中转）；不可换算阻断并记录换算来源（**E04**，D05） | 补换算关系后放行 |
| R-007 | **因子缺失阻断** | 核算前置校验时 | 参与计算的活动数据无有效因子 → 阻断计算与报告，**禁止按 0 排放**（**E03**） | 无例外 |
| R-008 | 删除约束 | 删除库 / 版本 / 因子时 | **草稿版本可编辑 / 删除**；**已发布过的库须先「整库下架」才可删除**（下架后前台不可见、不参与匹配，历史结果与收藏副本仍可追溯）；**未发布库可直接删除**；商业数据库内因子不可逐条删改；**生效中 / 历史版本不可修改、不可删除，只能新建版本或回滚**（Q10） | 命中时阻断并提示先「下架」 |
| R-009 | Excel / 整库导入规则 | 导入时 | 自建库按「编码 + 库版本」判重、模板校验；商业数据库走整库导入（库内只读）；失败行返回清单；**批次留痕**（I1～I4） | 部分成功，不整体回滚 |
| R-010 | 生物碳负因子与变更不追溯 | 生物碳因子使用 / 库版本发布时 | 生物碳吸收因子数值为负，计入受模型开关控制；吸收计入后末期须**对称**，否则 **E16**（B-region-1～3）。**库版本发布不追溯已建项目**（项目快照冻结，对齐 §4.9），需重算走 **E13** | 发布时提示受影响范围；**不做自动重算** |
| R-011 | **整库下架 / 上架** | 下架 / 上架因子库时 | **整库下架**：库级 `offline = true`，前台不可见、**不参与因子匹配**；**版本状态不变**（仍保留生效中版本）、库数据保留；**整库上架**：`offline = false`，恢复前台可见与匹配。下架库可重新上架（V10）。**「下架」仅指整库下架**（无版本级下架）；**下架是删库的前置条件**（已发布库须先下架才可删除） | 已下架库可删除；下架期间不可发布新版本 / 不可回滚（须先上架） |

> 规则总数 **11 条**（V0.5 新增 R-011「整库下架 / 上架」）。

## 7. 状态与操作矩阵

### 7.1 状态维度说明

| 状态维度 | 取值 | 来源 |
| :--- | :--- | :--- |
| **库来源** | `external` 商业数据库 / `builtin` 自建 | 字段清单（决定库内因子可编辑性） |
| **版本状态** | `draft` 草稿 / `published` 生效中 / `history` 历史版本 | 字段清单（**本模块特有**，决定是否前台可见 / 可被匹配引用；同一库同时只有一个「生效中」） |
| 库级状态 | 未发布（无生效中版本）/ 已发布（存在生效中版本且未下架）/ **已下架**（整库下架 `offline`） | 由版本状态 + 下架标记推导（已发布库须先下架才可删除） |
| 引用状态 | 未被引用 / 已被引用 | 系统自动关联（只读，反查活动数据 / 项目） |
| 收藏状态 | 未被收藏 / 已被收藏（前台） | 系统自动关联（前台「我的因子库」收藏本库因子的记录数） |

> 本模块**有版本维度**（库级）、**无审核维度**。

### 7.2 操作矩阵（库来源 × 版本状态 × 引用/收藏状态）

**A. 因子库（库级）**（「下架 / 上架」在库列表卡片与库详情页页头均可操作）

| 库来源 | 库级状态 | 新建版本 | 编辑库信息 | 下架 / 上架 | 删除库 |
| :--- | :--- | :---: | :---: | :---: | :---: |
| `external` 商业数据库 | 未发布 | 是 | 是 | —（无生效中版本） | **是**（未发布库可直接删） |
| `external` 商业数据库 | 已发布 | 是 | 受限（**库来源锁定**；名称 / 维护方 / 描述可改） | **下架** | **否**（须先下架） |
| `external` 商业数据库 | 已下架 | 是 | 受限 | **上架** | **是**（下架后可删） |
| `builtin` 自建 | 未发布 | 是 | 是 | — | **是**（未发布库可直接删） |
| `builtin` 自建 | 已发布 | 是 | 受限（**库来源锁定**；名称 / 维护方 / 描述可改） | **下架** | **否**（须先下架） |
| `builtin` 自建 | 已下架 | 是 | 受限 | **上架** | **是**（下架后可删） |

**B. 库版本（版本级）**

| 版本状态 | 编辑库内因子 | 发布 | **回滚** | 删除版本 | 前台可见 | 可被匹配引用 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| `draft` 草稿 | 是（仅自建库） | 是（**须因子数 > 0**；发布后原生效版本自动转历史） | — | 是 | 否 | 否 |
| `published` 生效中 | **否**（R-002） | — | — | 否 | **是**（默认展示） | **是**（库未下架时） |
| `history` 历史版本 | 否 | 否 | **是**（重新设为生效，当前生效版本自动转历史） | 否 | 是（历史可追溯） | 否 |

> **无「版本级下架」**（V0.6 删除）：`published` 恒唯一使原「防空在线版本」校验必然命中，该功能为死按钮；让版本下线只能「发布新版本替代」或「整库下架」。

**C. 库内因子（因子级，叠加引用 / 收藏状态）**

| 库来源 | 版本状态 | 引用/收藏状态 | 编辑因子 | 删除因子 | 被匹配引用 | 收藏副本受影响 |
| :--- | :--- | :--- | :---: | :---: | :---: | :---: |
| `external` 商业数据库 | 任意 | 任意 | 否（整库只读） | 否 | 是（生效中版本） | 否（副本不自动变） |
| `builtin` 自建 | `draft` | 未被引用 | 是 | 是 | 否 | 否 |
| `builtin` 自建 | `published` | 未被引用 | **否**（须新建版本） | 否 | 是 | 是（发布新版本后触发更新提醒） |
| `builtin` 自建 | `published` | 已被引用 | 否 | 否 | 是 | 是 |
| `builtin` 自建 | `history` | 任意 | 否 | 否 | 否（仅供追溯） | 否 |

**闭环校验**

- 版本状态：草稿 → 生效中 → 历史版本 正向可达，另有 历史版本 → 生效中（回滚）一条可控回退边；
- 发布新版本或回滚时，原生效中版本**必然**转历史版本，任一库**至多一个生效中版本**；生效中版本被发布 / 回滚替代后**永不为零**（替代是原子替换）；
- 草稿版本有完整生命周期（编辑 / 发布 / 删除）；**因子数为 0 的草稿不可发布**（空版本校验，V9）；
- 「生效中」构成**编辑封锁**（只能新建版本或回滚到历史版本）；**已发布库须先「下架」才可删除**（未发布库可直接删除）；
- **回滚不改版本内容、不新增版本号**：只切换"哪个版本生效"，历史版本内容与首次发布时间 `publishedAt` 不变，仅更新 `lastActivatedAt`；
- 商业数据库：库内因子全锁（只读），仅可通过「新建版本 + 整库再导入」更新；
- 「历史版本」为**只读追溯**：已匹配处仍只读回显 + 标注「历史版本」，不影响历史结果；前台收藏副本**不自动变化**；
- **整库下架**为库级开关：前台不可见 / 不匹配，但版本状态不变、可重新上架（下架不产生「零生效中版本」）；**下架是删库的前置条件**；
- 无审核分支，无死状态。
