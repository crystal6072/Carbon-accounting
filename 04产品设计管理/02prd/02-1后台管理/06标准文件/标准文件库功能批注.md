## 1. 拟添加的批注清单

### 1.1 整体流程

#### B09-01 标准维护整体流程
**拟标注位置**：功能标题「标准文件库」附近（全局说明）｜**标记**：已确认

- **适用场景**：在后台维护核算依据的标准文件字典，作为核算模型、排放因子等引用标准时的依据。
- **流程**：进入标准文件库 → 清单展示全部标准 → 按需查询、点标准号进详情核对 → 新增或编辑标准。
- **分支**：新增 / 编辑走**独立页面**（非弹窗）；查看走**独立详情页**；详情页也可直接「编辑」「删除」。
- **衔接**：清单点标准号 / 标准名称进入详情；详情 / 编辑页均可「返回列表」或浏览器返回。
- **结束**：保存后立即生效并跳转到详情 / 列表。全程没有提交、审核、驳回。

### 1.2 全局规则说明

#### B09-02 全局规则
**拟标注位置**：功能标题「标准文件库」附近（与整体流程同一全局说明入口）｜**标记**：已确认（权限为待确认，见 §3）

1. **一本标准字典**：本页维护核算依据的标准文件字典；**一个标准号 = 一条记录**，**版本年份并入标准号**（不再单独维护版本 / 替代关系）。
2. **无使用状态、无数据来源**：标准文件**不设「使用状态（启用 / 禁用）」与「数据来源」字段**，统一维护；不再使用时**直接删除**（删除入口替代禁用）。
3. **来源链接与附件二选一**：每条标准的「来源链接」与「附件」**至少填写一个**（D03）。
4. **日期约束**：**实施日期不得早于发布日期**（D04）。
5. **标准号唯一**：标准号全量唯一，新增与编辑保存时均校验（D01 / R-001）。
6. **标准状态为自由文本**：标准状态为录入框（自由文本），常用「现行 / 被替代 / 作废」，新建默认「现行」，不强制枚举。
7. **附件边界**：附件**选填、可多个**；附件**仅限企业内部查阅，不得作为对外交付物、不得跨租户共享**（A3 / A6）；**附件缺失不影响模型绑定、核算与报告**（核算基于元数据与来源链接，A4）。
8. **无流程节点**：没有提交、审核、驳回；不做版本化；删除为不可逆操作。

### 1.3 操作功能及对应业务规则

> 说明：标准文件库**无「使用状态」业务状态**（不设启用 / 禁用），故不单列业务状态；删除为唯一"退出"手段。

#### B09-03 清单
**拟标注位置**：清单表格区域与清单上方工具条｜**标记**：已确认

- **展示内容**：标准号、标准名称、标准状态、发布日期、实施日期、操作。
- **展示规则**：每页 **10 条**；标准号、标准名称为可点链接（进入详情）；空值显示「-」。
- **工具条**：左侧显示「标准字典」与「共 N 条」及「『来源链接』与『附件』二选一；附件仅限内部查阅，不得作为对外交付物（A3）」提示。
- **操作列**：「查看」「编辑」「删除」恒显示（删除不受状态限制，标准文件无启用 / 禁用）。
- **无勾选 / 批量**：本页不提供勾选与批量操作。

#### B09-04 查询与重置
**拟标注位置**：清单上方查询区｜**标记**：已确认（搜索按钮行为为原型已表现·待核对）

- **查询项**：① 标准号 —— 包含关系模糊匹配、忽略大小写；② 标准名称 —— 包含关系模糊匹配（匹配中文标准名称）；③ 标准状态 —— 包含关系模糊匹配（录入框，如「现行」）。
- **规则**：多个条件同时生效（叠加过滤）；任一条件变化后清单回到第 1 页；「重置」清空全部条件并恢复完整清单。
- **搜索按钮**：点「搜索」执行一次当前条件的筛选。
- **原型表现（待核对）**：原型中点「搜索」仅出现一次「查询完成」提示、不产生额外动作（条件输入后清单已即时收敛）。需确认正式需求是「点击后查询」还是保留「即时筛选 + 按钮共存」。

#### B09-05 新增标准文件
**拟标注位置**：页头「新增」按钮旁｜**标记**：已确认

- **操作目的**：建立一条新的标准文件记录。
- **入口**：页头「新增」，进入独立新增页；恒可操作。
- **操作过程**：填写标准号、标准状态（默认「现行」）、中文标准名称，按需填英文标准名称、发布日期、实施日期、发布单位、主管部门、归口部门、来源链接，或上传附件。
- **结果**：保存成功后提示「保存成功」并进入该标准详情页。
- **取消或失败**：点「取消」或浏览器返回不保存；校验不通过时给出提示（见 B09-12）。

#### B09-06 查看标准文件（详情）
**拟标注位置**：清单操作列「查看」、清单标准号 / 名称链接、详情页｜**标记**：已确认

- **操作目的**：只读核对某条标准的完整信息与附件。
- **入口**：清单操作列的「查看」，或点击清单中的标准号 / 标准名称。
- **展示内容**：基本信息（标准号、标准状态、中文标准名称、英文标准名称、发布日期、实施日期、发布单位、主管部门、归口部门、来源链接）+ 标准文件附件。
- **来源链接**：以可点击链接展示，新窗口打开。
- **附件**：展示附件清单（名称、大小、上传时间）与「在线预览」；无附件时显示「暂无附件（已提供来源链接）」。
- **底栏操作**：「返回列表」「删除」「编辑」。

#### B09-07 标准文件附件
**拟标注位置**：详情页「标准文件附件」区、编辑页附件区｜**标记**：已确认

- **业务含义**：标准文本的附件载体；选填、可多个，与「来源链接」二选一。
- **展示 / 操作**：详情页可「在线预览」（PDF / 图片）；编辑页可「选择附件」上传、「移除」已上传附件、「在线预览」。
- **边界**：附件**仅限企业内部查阅，不得作为对外交付物、不得跨租户共享**（A3 / A6）；**附件缺失不影响模型绑定、核算与报告**（A4）。
- **数据性质**：原型中附件在本地内存读取（PDF / 图片转 data URL 供预览），正式实现由附件管理下发地址。

#### B09-08 编辑标准文件
**拟标注位置**：清单操作列「编辑」、详情页「编辑」｜**标记**：已确认

- **操作目的**：修改标准文件信息。
- **操作过程**：进入独立编辑页，带出现有内容；可修改全部字段（标准号、名称、状态、日期、单位、部门、来源链接、附件）。
- **结果**：保存成功后提示「保存成功」并进入详情页。

#### B09-09 删除标准文件
**拟标注位置**：清单操作列「删除」、详情页「删除」、确认弹窗｜**标记**：已确认

- **显示条件**：清单与详情页均恒显示「删除」（标准文件无启用 / 禁用，删除不受状态限制）。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认删除」，正文「确认删除标准文件『标准号《中文标准名称》』？」，提示「删除为不可逆操作，删除后不可恢复。」；底栏「取消」与「确认删除」，不使用「确定」字样。
- **结果**：确认后删除，提示「删除成功」并返回列表；删除不可恢复。取消则不删除。

### 1.4 字段说明（新增 / 编辑页）

#### B09-11 字段：标准号
**拟标注位置**：表单「标准号」内容旁，及清单该列｜**标记**：已确认

- **业务含义**：标准的唯一业务标识；**版本年份并入标准号**（如 `GB/T 24067-2024`）。
- **填写方式**：手工填写，输入框提示「如 GB/T 24067-2024」，字段提示「含年份」。
- **必填**：必填；为空提示「请输入标准号」。
- **重复限制**：**全量唯一**；重复提示「标准号『X』已存在，标准号唯一（R-001 / D01）」。

#### B09-12 字段：标准状态
**拟标注位置**：表单「标准状态」内容旁，及清单该列｜**标记**：已确认

- **业务含义**：标准的效力状态，为**自由文本**（非常规枚举）。
- **填写方式**：录入框；常用「现行 / 被替代 / 作废」，新建默认「现行」。
- **必填**：必填；为空提示「请输入标准状态」。

#### B09-13 字段：中文标准名称
**拟标注位置**：表单「中文标准名称」内容旁，及清单「标准名称」列｜**标记**：已确认

- **业务含义**：标准的中文名称。
- **填写方式**：手工填写，占位提示「如 温室气体 产品碳足迹 量化要求和指南」。
- **必填**：必填；为空提示「请输入中文标准名称」。

#### B09-14 字段：英文标准名称
**拟标注位置**：表单「英文标准名称」内容旁，及详情页该行｜**标记**：已确认

- **业务含义**：标准的英文名称。
- **填写方式**：手工填写。
- **必填**：选填。

#### B09-15 字段：发布日期
**拟标注位置**：表单「发布日期」内容旁，及清单 / 详情该行｜**标记**：已确认

- **业务含义**：标准的发布日期。
- **填写方式**：日期选择。
- **必填**：必填；未选提示「请选择发布日期」。

#### B09-16 字段：实施日期
**拟标注位置**：表单「实施日期」内容旁，及清单 / 详情该行｜**标记**：已确认

- **业务含义**：标准的实施日期。
- **填写方式**：日期选择；字段提示「须 ≥ 发布日期（D04）」。
- **必填**：必填；未选提示「请选择实施日期」；早于发布日期提示「实施日期不得早于发布日期（D04）」。

#### B09-17 字段：发布单位
**拟标注位置**：表单「发布单位」内容旁，及详情页该行｜**标记**：已确认

- **业务含义**：发布该标准的单位。
- **填写方式**：手工填写，占位提示「如 国家市场监督管理总局、国家标准化管理委员会」。
- **必填**：必填；为空提示「请输入发布单位」。

#### B09-18 字段：主管部门 / 归口部门
**拟标注位置**：表单「主管部门」「归口部门」内容旁，及详情页该行｜**标记**：已确认

- **业务含义**：标准的主管部门 / 归口部门。
- **填写方式**：手工填写。
- **必填**：选填。

#### B09-19 字段：来源链接
**拟标注位置**：表单「来源链接」内容旁，及详情页该行｜**标记**：已确认

- **业务含义**：标准文本的在线来源地址；与「附件」二选一。
- **填写方式**：手工填写，字段提示「选填；与『附件』二选一（至少填一个，D03）；须为 http/https 链接」。
- **必填**：选填，但与附件**至少填一个**；两者均空提示「『来源链接』与『附件』二选一，请至少填写一个（D03）」。
- **格式限制**：填写时须为合法 URL（http:// 或 https://），否则提示「来源链接须为合法 URL（http:// 或 https://，D05）」。

#### B09-20 字段：标准文件附件
**拟标注位置**：表单「标准文件附件」区｜**标记**：已确认

- **业务含义**：标准文本附件；选填、可多个，与「来源链接」二选一。
- **填写方式**：「选择附件」上传（可多选）；已上传附件可「在线预览」「移除」。
- **边界**：仅限内部查阅、不得对外交付；缺失不影响核算（A3 / A4）。

#### B09-21 弹窗 / 页面的保存与取消
**拟标注位置**：新增 / 编辑页底栏「保存」「取消」｜**标记**：已确认

- **保存**：点击后先校验，通过后保存并跳转详情页，提示「保存成功」；保存过程中按钮显示「保存中…」并暂时不可点击。
- **校验规则（任一不通过即阻断保存）**：标准号未填 / 重复、中文标准名称未填、标准状态未填、发布日期未选、实施日期未选 / 早于发布日期、发布单位未填、来源链接格式非法、来源链接与附件均未填。
- **取消**：点「取消」或浏览器返回不保存任何内容。
