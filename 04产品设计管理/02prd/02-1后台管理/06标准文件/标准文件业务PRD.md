## 1. 需求概述

### 1.1 需求背景

标准文件是**核算依据的载体**。方案 §4.2.5 明确：标准文件库用于沉淀核算依据，**供核算模型绑定引用**；而**标准差异由不同版本的核算模型承载**（方案 §4.3.1）。因此本模块**只提供"依据"，不定义"怎么算"** —— 算法规矩在核算模型里。

**决策 D3**：本版本首发标准依据对齐 **`GB/T 24067-2024`**，首个核算模型绑定该标准文件，因此本模块至少需交付「一条预置标准 + 模型可绑定」的最小闭环。

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :--- | :--- | :--- |
| G1 | 提供标准文件字典 | 字段覆盖：标准号 / 中文标准名称 / 英文标准名称 / 标准状态 / 发布日期 / 实施日期 / 发布单位 / 来源链接 / 主管部门 / 归口部门 / 附件 |
| G2 | 支撑首个核算模型 | 系统内置 `GB/T 24067-2024`，可被首个核算模型绑定 |
| G3 | 依据可溯源 | 每条标准即一个标准号（含年份），附「来源链接」或「附件」之一 |
| G4 | 维护无约束 | 标准文件随时可编辑、可删除（无引用约束，V0.3） |
| G5 | 版权风险可控 | 附件仅限内部查阅，明确不得作为对外交付物 |

### 1.3 In Scope / Out of Scope

**In Scope**

| 能力 | 说明 |
| :--- | :--- |
| 标准文件列表与查询 | 列表仅展示标准号 / 标准名称 / 标准状态 / 发布日期 / 实施日期；查询按标准号、标准名称、标准状态 |
| 新增 / 编辑标准文件 | 元数据维护（含首发 `GB/T 24067-2024`）；随时可编辑 |
| 查看标准文件 | 独立详情页，字段与新增 / 编辑页一致 |
| 附件上传 / 替换 | 选填、可多个；与「来源链接」二选一；支持在线预览（PDF / 图片） |
| 来源链接维护 | 选填；与「附件」二选一 |
| 标准状态维护 | 录入框（自由文本）；表单内维护 |
| 删除 | 随时可删除（无引用约束） |

**Out of Scope**

| 不做项 | 说明 |
| :--- | :--- |
| 审核流 / 版本化 | 基础数据，均不涉及；标准号本身含年份即表达版本 |
| **在标准文件内定义算法** | 算法规矩（阶段 / 计算规则 / 检测规则 / 报告规定）归**核算模型**（§4.3.1） |
| 标准类型 / 适用范围 / 被替代标准 | V0.2 移除；由标准号与标准状态承载 |
| 数据来源 / 使用状态（启用 / 禁用） | V0.2 移除；统一维护，删除入口替代禁用 |
| 模型引用与引用约束 | V0.3 移除；标准文件无引用约束，随时可编辑、可删除 |
| Excel 导入 | V0.1 不支持 |
| 附件对外分发 | **一律不允许**（版权边界，见 §4） |

### 1.4 涉及角色

| 角色 | 数据域 | 在本模块的职责 |
| :--- | :--- | :--- |
| 后台管理员 | 平台域 | 维护标准文件字典 |
| 组织管理员 | `SUB_TREE` | 维护组织可能自建的标准（本期不区分数据来源） |
| 专业配置人员 | `SUB_TREE`（只读业务） | 在核算模型（P14）中**绑定标准依据** |
| 核算人员 / 审核员 | `CURRENT` / `SUB_TREE` | 只读（报告披露需引用标准信息） |

### 1.5 影响范围

| 方向 | 模块 | 影响 |
| :--- | :--- | :--- |
| 上游 | 附件管理（§C6） | 承载标准文件附件的存储、鉴权、审计 |

| 下游 | 核算项目 | 间接（经模型快照）追溯核算依据 |

## 2. 用户与使用场景

### S01 维护标准文件

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要录入一个新的核算标准（如首发录入 `GB/T 24067-2024`） |
| 操作流程 | 新增标准文件 → 填写标准号、中文 / 英文标准名称、标准状态、发布日期、实施日期、发布单位、主管部门、归口部门 → 填写「来源链接」或上传「附件」（至少一个） → 保存 |
| 预期结果 | 标准文件创建成功；可被核算模型绑定 |

### S02 上传 / 维护来源链接与附件

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要为标准补充官方链接或电子文本供内部查阅 |
| 操作流程 | 编辑标准文件 → 填写来源链接或上传附件（可多个）→ 保存 |
| 预期结果 | 二者至少存在其一（保存校验）；附件通过附件管理的鉴权访问并**支持在线预览**（PDF / 图片，A7）；**仅限内部查阅，不得作为对外交付物**（§4） |

### S03 标记标准为「被替代 / 作废」

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 标准已被新版替代或已废止 |
| 操作流程 | 编辑标准文件 → 修改标准状态 → 保存 |
| 预期结果 | 状态变更生效；**不可被新的核算模型引用** |

### S04 删除标准文件

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 标准已不再需要 |
| 操作流程 | 列表或详情页 → 删除 → 二次确认 |
| 预期结果 | 删除成功（不可逆）；标准文件**无引用约束**，随时可删除 |

### S05 在核算模型中引用标准文件

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 配置核算模型时需要绑定标准依据 |
| 操作流程 | 在核算模型（P14）的模型基本信息中选择标准依据 → 保存 → 发布模型 |
| 预期结果 | 模型绑定成功；只能选到**标准状态 = 现行**的标准（R-005） |

### S06 查看标准文件详情

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要确认标准信息 |
| 操作流程 | 列表点标准号 / 名称进入详情页 → 查看元数据、来源链接、附件 |
| 预期结果 | 展示与新增 / 编辑页**完全一致**的字段 |

## 4. 附件与版权边界

> 本章锁定标准文件附件的合规边界，**不得放松**。

| # | 规则 |
| :--- | :--- |
| A1 | 「来源链接」与「附件」**二选一，至少填写一个**（可都填） |
| A2 | 附件由**附件管理（§C6）**承载：存储隔离、访问鉴权、操作审计全留痕 |
| A3 | **版权边界**：GB/T 与 ISO 标准文本均受版权保护，内部分发亦可能受限 |

| 场景 | 是否允许 |
| :--- | :--- |
| 企业内部查阅（平台 / 租户自有人员） | 允许（按结论） |
| **作为对外交付物**（报告附件、客户交付） | **一律不允许** |
| **租户间共享**（SaaS 多租户下跨租户可见） | **不允许** |

| # | 规则 |
| :--- | :--- |
| A4 | 附件缺失不影响标准文件的业务能力：模型绑定、核算、报告均基于**元数据**与**来源链接** |
| A5 | 附件替换需保留历史（由附件管理的审计能力承载），避免"依据被静默改写" |
| A6 | ~~已废止~~ 导出功能已下线（2026-10-13，见变更记录 V0.6），原「导出仅含元数据、不含附件」规则不再适用 |
| A7 | **附件支持在线预览**：PDF / 图片（jpg / jpeg / png / gif / webp / bmp / svg）直接在线渲染；其他格式提示下载后查阅。预览鉴权由**附件管理（§C6）**承载，仍受「仅内部查阅」约束（A3） |

| :--- | :--- | :--- | :--- | :--- |

| R-010 | 附件规则与版权边界 | 上传 / 访问附件时 | 附件选填、可多个；仅限内部查阅；**不得作为对外交付物、不得跨租户共享**（§4 A3） | 无例外 |

## 6. 状态与操作矩阵

### 6.1 状态维度说明

| 状态维度 | 取值 | 来源 |
| :--- | :--- | :--- |
| 标准状态 | 自由文本（常用：现行 / 被替代 / 作废） | 字段清单（业务状态，按「现行」判定可否被引用） |

> 本模块**无版本维度、无数据来源维度、无使用状态维度、无引用维度、无审核维度**（V0.3）。

### 6.2 操作矩阵

| 标准状态 | 编辑 | 删除 | 被新模型引用 |
| :--- | :---: | :---: | :---: |
| 现行 | 是 | 是 | 是 |
| 被替代 / 作废 | 是 | 是 | 否（R-008） |

**闭环校验**

- 标准状态为自由文本，按「现行」判定能否被引用，可随时修改；
- 标准文件**随时可编辑、可删除**（无引用约束，R-007 / R-009）；
- 无版本维度、无数据来源维度、无引用维度、无审核分支。
