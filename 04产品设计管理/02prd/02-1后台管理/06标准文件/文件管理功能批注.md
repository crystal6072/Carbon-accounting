# 文件管理功能批注

> 原型是唯一的真实来源。凡原型已表现而现有文档未覆盖的，统一标记为「原型已表现·待核对」；尚未裁决的问题归入 §4.1；原型与文档不一致的点归入 §4.2。

## 0 说明

- **项**：文件管理（路由 `/basic/file`，复用标准文件库页面）
- **范围**：标准 / 单据 / 其他类文件统一存档、检索与版本留存；标准计入核算标准准入清单，单据支撑核算与核查凭证引用；支持在线预览与按次上传生成版本。
- **与其他功能关系**：上游为系统预置标准库、单据业务（核算 / 报告 / 核查）；下游为报告 / 核算引用与凭证调取。本期不做引用反查、版本对比、版本回滚、单版本删除、批量、导出。
- **编号规则**：`FM-01` 起；FM-01~FM-04 流程 / 操作 / 状态；FM-05~FM-06 列表 / 查询；FM-10~FM-13 字段；FM-23~FM-27 全局。
- **依据**：《文件管理字段清单》《文件管理_Demo》及当前原型。
- **标记口径**：已确认 / 原型已表现·待核对 / 待确认（仅 §4.1）。
- **版本记录**：V1.0（2026-10-28）初稿，按原型补全批注。

## 4 待确认清单

### 4.1 需补充规则（待裁决，不作为需求依据）

1. 单据是否需要「作废」状态（Q01）。
2. 单据是否本期开放「关联对象」选择（Q02）。
3. 一个单据多附件时拆记录还是一条多文件（Q03）。
4. 标准「换年份」用新记录还是新版本（Q04）。
5. 单据类型走数据字典还是固定枚举（Q05）。
6. 单据是否允许跨租户共享（Q06）。
7. 是否增加「其他」兜底值（Q07）。
8. 列表是否需要「最近更新」列 / 「仅看有版本」筛选（衍生）。

### 4.2 需原型同步调整（文档与原型差异）

1. **列表/查询**：Demo/字段清单设计「类型 Tab + 自适应列 + 分 Tab 查询」，原型为单列表 + 类型下拉、列集不同（含创建人/业务编号列）。
2. **分页**：文档 20 条/页，原型 10 条。
3. **能力缺口**：本期不做引用反查、版本对比、版本回滚、单版本删除、批量、导出（原型也未提供）。
