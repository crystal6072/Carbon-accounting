# 标准文件字段清单

> **文档定位**：标准文件字段定义的唯一真相源（SST）。业务 PRD 和 Demo PRD 只引用字段名称，不重复维护枚举、必填性和字段口径。
> **适用类型**：基础数据维护（轻量）—— 非业务单据、**无审核流、无版本化**
> **核心用途**：沉淀核算依据的标准文件，**供核算模型绑定引用**（方案 §4.2.5）
> **维护形态**：列表 + 独立详情页 + 独立新增/编辑页
> **成熟度**：粗纲
> **版本**：V0.5
> **更新时间**：2026-10-08

## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 标准文件 |
| 业务归属 | 后台管理 → 基础库 → 标准文件库（方案 §2.3 A1-3、§4.2.5、§八 P05） |
| 模块类型 | 基础数据维护（轻量），非业务单据、无审核流、无版本化 |
| 核心对象 | 标准文件（一个标准号 = 一条记录） |
| 核心职责 | 沉淀核算依据的标准文件，**供核算模型绑定引用**；标准差异由不同版本的核算模型承载（方案 §4.2.5、§4.3.1） |

### 1.2 对象结构

| 结构 | 对象 | 与主对象关系 | 主键/唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 标准文件 | 主对象 | **标准号**（含年份） | 一个标准号 = 一条记录，不引入版本化字段 |
| 附件 | 标准文件附件 | 1:N | 附件 id | 由附件管理（§C6）承载；选填、可多个；与「来源链接」二选一 |

```text
版本与替代关系的表达（V0.2）：
标准号本身含年份，不同版本即不同标准号，各自独立成记录：
  GB/T 24067-2018（标准状态 = 被替代）
  GB/T 24067-2024（标准状态 = 现行）
不再设「被替代标准」自引用字段，新旧关系由「标准号 + 标准状态」表达。
```

### 1.3 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | 本期不区分系统预置 / 组织自建，统一维护（对齐「产品分类 / 物料库」的轻量字典口径） |

## 2. 枚举值

### 2.1 标准状态

**「标准状态」为录入框（自由文本），非枚举受控** —— 由用户直接录入，以适配不同发布机构的状态表述。

| 常用取值（录入提示） | 含义 | 是否可被新模型引用 | 备注 |
| :--- | :--- | :---: | :--- |
| 现行 | 当前有效、可依据执行 | 是 | 新建默认 |
| 被替代 | 已被新版标准替代 | 否 | — |
| 作废 | 已废止、不再适用 | 否 | — |

> 常用取值仅作**录入提示**，不限制用户录入「即将实施 / 废止」等其他表述；引用准入按「标准状态 = 现行」判定。
