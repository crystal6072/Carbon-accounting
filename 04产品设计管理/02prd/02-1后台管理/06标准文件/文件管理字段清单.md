## 0. 对象结构

```text
文件（file_doc）  1 ─── N  文件版本（file_version）
  ├─ 文件类型 = 标准 → 填标准专有字段，可有 0～N 个版本（仅来源链接时 0 个）
  └─ 文件类型 = 单据 → 填单据专有字段，至少 1 个版本
```

| 结构 | 对象 | 与主对象关系 | 唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 文件 | 主对象 | 文件编码 | 一条记录 = 一份文件 / 一份单据；**类型创建后不可改** |
| 子表 | 文件版本 | 1:N | 版本 ID | **每次上传追加一条**，不覆盖、不删除历史版本 |

**版本口径（核心）**

| 场景 | 是否产生新版本 |
| :--- | :---: |
| 新增文件并上传 1 个文件 | 是（生成 V1） |
| 编辑时只改元数据（名称 / 标准号 / 单据类型等），未上传新文件 | **否**（版本号不变） |
| 编辑时上传了新文件 | 是（版本号 +1，旧版本保留） |

> 一个版本 = **一个文件**，不做"一个版本多个附件"。同一份单据有多个附件（发票 + 合同 + 报告）时拆成多条记录，各走各的版本。

## 2. 枚举值

### 2.1 文件类型

| 取值 | 含义 | 数据域 | 允许无版本 | 典型场景 |
| :--- | :--- | :--- | :---: | :--- |
| 标准 | 核算依据的标准文本 | 平台级（全租户可见） | 是（仅填来源链接时） | GB/T 24067-2024、LY/T 3436-2025 |
| 单据 | 支撑核算 / 核查的业务凭证 | 所属租户 | 否（至少 1 个版本） | 检测报告、采购发票、运输单据、能耗台账、供应商依据 |

> 文件类型**固定两级，不扩展三级**；单据的业务细分由「单据类型」字典承担，不新增文件类型枚举值。

### 2.2 单据类型（引用数据字典，预置项）

| 字典项 | 说明 | 是否预置 |
| :--- | :--- | :---: |
| 检测报告 | 含碳量 / 含水率 / 热值等检测报告 | 是 |
| 采购发票 | 原辅料、能源采购凭证 | 是 |
| 运输单据 | 运单、磅单、运费结算单 | 是 |
| 能耗台账 | 电表 / 燃气表 / 蒸汽抄表台账 | 是 |
| 供应商依据 | 供应商碳足迹声明、核查报告 | 是 |
| 其他 | 兜底 | 是 |

> 字典项由后台「数据字典」维护，新增无需改代码；停用的字典项不可再被新选，已引用处只读回显。

### 2.3 标准状态

**录入框（自由文本），非枚举受控**（沿用旧清单 §2.1）：常用取值「现行 / 被替代 / 作废」仅作录入提示；核算模型引用准入按「标准状态 = 现行」判定。

### 2.4 格式与大小白名单（按类型）

| 文件类型 | 允许格式 | 单文件上限 | 预览方式 |
| :--- | :--- | :---: | :--- |
| 标准 | PDF、jpg / jpeg / png / webp / bmp | 50 MB | PDF / 图片在线渲染；其他提示下载 |
| 单据 | PDF、jpg / jpeg / png / webp / bmp、xls / xlsx、doc / docx | 20 MB | PDF / 图片在线渲染；Office 转 PDF 预览；其他提示下载 |

## 3. 关键数据约束

| 约束ID | 约束 | 影响对象 |
| :--- | :--- | :--- |
| D01 | **「文件编码」唯一**，系统生成、创建后不可修改 | 主表 |
| D02 | **「文件类型」必填，且创建后不可修改**（切换类型会导致字段体系与历史数据不一致） | 主表 |
| D03 | 类型 = 标准时，**「标准号」唯一** | 主表 |
| D04 | 类型 = 标准时，**「来源链接」与「版本文件」二选一**，至少存在其一（可都填） | 主表 / 版本 |
| D05 | 类型 = 标准时，**实施日期 ≥ 发布日期** | 主表 |
| D06 | 「来源链接」非空时须为合法 URL（`http://` / `https://`） | 主表 |
| D07 | 类型 = 单据时，**「单据编号」在同一租户内唯一** | 主表 |
| D08 | 类型 = 单据时，「单据类型」必填，取值来自数据字典中**启用**的字典项 | 主表 |
| D09 | **每次上传生成新版本号（+1）**；版本号只读、不可手填、不可覆盖 | 版本 |
| D10 | 同一文件下**「是否当前版本」有且仅有一条**，取最大版本号 | 版本 |
| D11 | 历史版本**不可编辑、不可单独删除**，仅可预览与下载 | 版本 |
| D12 | 数据域：标准 = 平台级（全租户只读可见）；单据 = 所属租户（跨租户不可见） | 主表 |
| D13 | 上传时校验格式与大小（§2.4），并按 MIME / 魔数二次校验，防止改后缀 | 版本 |
| D14 | 删除文件 = **删除整条记录（含全部版本）**，二次确认，不可恢复 | 主表 |
| D15 | 预览与下载须**鉴权 + 留审计**（人、时间、IP）；对外披露类文件加水印 | 版本 |

## 5. 与旧口径的差异（供业务 PRD 重写参考）

| 项 | 旧清单（标准文件 V0.6） | 本清单（文件管理 V0.1） |
| :--- | :--- | :--- |
| 模块定位 | 基础库轻量字典 | **文件台账**（标准 + 单据） |
| 版本 | **无版本化** | **文件版本**（每次上传 = 一个版本；标准号换年份仍新建记录） |
| 字段体系 | 一套字段 | **公共 + 标准专有 + 单据专有** 三段式 |
| 唯一约束 | 标准号唯一 | 文件编码唯一 + 标准号唯一（仅标准）+ 单据编号同租户唯一（仅单据） |
| 附件 | 可多个、与来源链接二选一 | 每次上传一个文件并生成版本；标准与来源链接二选一，单据必须有文件 |
| 删除 | 随时可删 | 整条删除（含版本），二次确认 |
| 权限 | 未区分 | **标准 = 平台级；单据 = 租户级** |
| 列表 | 固定 5 列 | 按类型 Tab 自适应列 |
