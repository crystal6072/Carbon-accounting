# 计算引擎配置字段清单

> **文档定位**：计算引擎配置字段定义的唯一真相源（SST）。
> **适用模块**：后台管理 → 核算模型（`/model/calc-engine` 计算公式、`/model/list` 模型管理）。
> **核心对象**：计算公式、数据因素（公式子表）、核算模型、模型公式绑定。
> **版本**：V1.0。
> **更新时间**：2026-09-22。
> **口径基准**：以 `06prototypes/6-1系统原型骨架/src/pages/calcEngine`、`src/pages/model` 与 `src/mock` 的实际实现为准。

## 0. 字段清单说明

| 项目 | 说明 |
| :--- | :--- |
| 功能定位 | 计算引擎配置 = **计算公式**（决定「怎么算」）+ **核算模型**（决定「算在哪」）。 |
| **边界说明（2026-10-09）** | 本文覆盖的是后台「**计算公式**」（`/model/calc-engine`，`FM-xxx`，**服务工艺库 / 产品工艺的投入产出流**）。**前台「产品碳足迹核算」项目引用的「核算公式」是另一套对象**：菜单 `/model/formula`「**公式管理**」（`FC-xxx`，行级 / 阶段汇总 / 全局三层受控表达式），**由项目步骤①引用并作为核算引擎的唯一计算入口** —— 其字段与业务规则见同目录《**公式管理字段清单**》《**公式管理业务 PRD**》；口径见《整体设计方案》§6.1.1（2026-10-09 补充修订声明）与〔前台〕《碳足迹核算业务 PRD》§6。两者**不可混用**。 |
| 对象边界 | 原型**不引入「阶段计算方案」「计算明细行」中间层**：公式保持跨阶段复用，阶段 / 工序 / 投入项归属由建模侧的「公式绑定」承担。 |
| 字段编码 | 使用英文 snake_case，研发可按实际表结构调整。 |
| 表达式口径 | 受控表达式：**已定义的数据因素名称** + 数字 + `+ - * / ( ) [ ] %`；括号必须闭合，不支持脚本。 |
| 公式类型口径 | 按「输入口径」分四类：因子公式 / 能耗公式 / 碳排公式 / 其他。方法与排放源差异由建模时的绑定对象承担，不体现在公式类型上。 |
| 正负项口径 | 公式侧用「是否允许负值结果」控制结果能否为负；建模侧由绑定的公式模板（如含 `方向系数 = -1`）实现扣减。 |
| 轻量口径 | **计算公式不做审核流程、不做版本化**，可直接编辑；变更不追溯已核算的历史结果；使用状态为启用 / 禁用。 |
| 安全边界 | 不支持任意脚本执行，只允许受控运算符、括号与已定义数据因素。 |

## 2. 数据因素（公式子表）

公式由「数据因素 + 运算符」点选生成，数据因素即公式表达式中的运算项名称。

| 字段名称 | 字段编码 | 字段类型 | 是否必填 | 默认值 | 枚举值/取值范围 | 校验规则 | 字段说明 | 所属页面/模块 |
| :--- | :--- | :--- | :---: | :--- | :--- | :--- | :--- | :--- |
| 因素名称 | factor_name | 文本 | 是 | 活动数据（默认首行） | 1-50 字符 | **同一公式内不得重复**；不得为空 | 直接作为公式表达式中的运算项名称 | 公式新增/编辑 |
| 因素来源 | factor_source_type | 枚举 | 是 | 活动数据 | 活动数据/自定义变量/业务库取值/常量 | 必填；决定取值方式与后续校验 | 因素取数方式 | 公式新增/编辑 |
| 来源库 | factor_source_lib | 枚举 | 条件必填 | 排放因子库 | 排放因子库/能源库/物料库/自定义常量 | 因素来源为「业务库取值」或「常量」时必填；「自定义常量」标识常量行 | 业务库取值 / 常量的来源库 | 公式新增/编辑 |
| 引用对象编码 | factor_source_object_code | 引用 | 条件必填 | 无 | 排放因子库 / 能源库 / 物料库条目 | 因素来源为「业务库取值」时必须选择；未选阻断 | 引用对象标识 | 公式新增/编辑 |
| 引用对象名称 | factor_source_object_name | 文本 | 条件必填 | 无 | 1-200 字符 | 选中引用对象后自动带出，只读 | 冗余展示 | 公式新增/编辑 |
| 因素数值 | factor_value | 文本 | 条件必填 | 无 | 数值或可求值表达式 | 因素来源为「常量」时必须填写（如 `44/12`、`-1`）；业务库取值由库带出 | 因素取值 | 公式新增/编辑 |
| 因素单位 | factor_unit | 枚举 | 条件必填 | 无 | 计量单位候选（kg/t/kWh/GJ/t·km 等） | 活动数据、自定义变量、常量必须填写单位；业务库取值的复合单位由库带出（如 `kgCO₂e/kWh`） | 因素单位 | 公式新增/编辑 |

**数据因素行类型（4 类）**

| 因素来源 | 取值方式 | 行内可维护项 | 试算时 |
| :--- | :--- | :--- | :--- |
| 活动数据 | 运行时由填报侧取值 | 因素名称、单位 | 手填样例入参 |
| 自定义变量 | 运行时由填报 / 项目参数取值 | 因素名称、单位 | 手填样例入参 |
| 业务库取值 | 引用排放因子库 / 能源库 / 物料库，数值与单位由库带出 | 来源库、引用对象 | 自动带出、只读 |
| 常量 | 公式内固定数值 | 常量名称、常量值、单位 | 自动带出、只读 |

**子表级约束**
- 至少 1 条数据因素（新增公式时预置 1 行「活动数据」，单位为 `kg`）。
- 因素名称在同一公式内唯一；重名阻断保存。
- 因素名称即表达式运算项，公式校验以「已定义因素名称」为白名单。

| :--- | :--- | :--- |

## 5. 试算与校验

公式详情页「试算」入口弹出的即时校验与试算，**纯前端计算、不落库**（无试算记录实体）。

| 项目 | 内容 |
| :--- | :--- |
| 校验项 1 | 计算公式只使用已定义的数据因素与运算符（否则回显非法片段） |
| 校验项 2 | 数据因素完整：业务库取值已选引用对象、常量已填值（否则列出待补因素名称） |
| 校验项 3 | 结果单位为碳排放量单位（要求以 `CO₂e` 结尾） |
| 样例入参 | 活动数据、自定义变量为**手填**；支持多值（英文逗号分隔，按 Σ 求和）；业务库取值、常量自动带出、只读 |
| 入参校验 | 手填项为空 → 阻断并提示「「{因素名称}」样例入参不能为空」；非数值 → 提示须为数值 |
| 试算结果 | 输出数值 + 公式结果单位；按 **4 位小数** 格式化（超出为 `-`） |
| 持久化 | **无**（不记录试算人、试算时间、样例结果） |

| 循环对象 | loop_object | 活动数据记录/物料消耗记录/能源消耗记录/运输记录/燃料记录/制冷剂记录/废弃物记录/末期处理记录/项目参数/不循环 | 字典已定义，**绑定弹窗未提供该字段** |

## 7. 关键约束与联动规则

| 编号 | 约束 | 触发环节 | 处理 |
| :--- | :--- | :--- | :--- |
| D01 | 公式不做审核、不做版本化 | 编辑 | 可直接编辑覆盖；变更不追溯已核算结果 |
| D02 | 公式名称、适用行业、公式类型、计算公式、数据因素完整性必填 | 保存 | 任一缺失阻断保存 |
| D03 | 数据因素名称同一公式内唯一 | 保存 | 重复阻断 |
| D04 | 业务库取值必须选择引用对象；常量必须填写常量值 | 保存 | 缺失阻断 |
| D05 | 活动数据 / 自定义变量 / 常量必须填写单位 | 保存 | 缺失阻断（业务库取值单位由库带出） |
| D06 | 计算公式只能引用已定义因素名 + `+ - * / ( ) [ ] %` | 保存 / 试算 | 含非法内容或括号不闭合阻断 |
| D07 | 仅「启用」公式可作为绑定候选 | 绑定 | 候选过滤 + 保存校验双重拦截 |
| D08 | 仅「启用」公式可被删除（须先禁用） | 删除 | 阻断并提示先禁用 |
| D09 | 仅「草稿」模型可编辑基本信息与维护绑定 | 编辑 / 绑定 | 已发布阻断并提示先停用 |
| D10 | 仅「草稿」模型可删除 | 删除 | 阻断；删除同时清理该模型全部绑定行 |
| D11 | 已发布模型绑定冻结 | 绑定 | 阻断 |
| D12 | 同「模型 + 对象类型 + 对象编码」下默认唯一 | 绑定 / 设为默认 | 自动将其余行 `is_default` 置否 |
| D13 | 同一对象不可重复绑定同一公式 | 绑定 | 阻断 |
| D14 | 公式禁用 / 删除后历史绑定保留 | 绑定展示 | 详情在公式名后标注「已禁用」或显示「公式已删除」 |
