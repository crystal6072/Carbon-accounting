## 1. 功能全局说明

### 1.1 功能定位

计算公式是核算引擎的**轻量算法配置对象**，回答「**一类计算项怎么算**」：

- 公式只定义算法本身（数据因素 + 受控表达式 + 结果口径），**不记录适用模型 / 适用生命周期阶段**，可跨阶段、跨模型复用；
- 公式「算在哪」（阶段 / 工序 / 投入项 / 产出项归属）由核算模型的公式绑定承担，公式自身不关联生命周期阶段（页面不提供阶段选择，详情页亦不展示该字段）；
- 使用状态分**启用 / 禁用**两态，仅「启用」公式可作为建模时的绑定候选；**不做审核流程、不做版本化**，编辑为直接覆盖，变更不追溯已核算的历史结果。

| :--- | :--- | :--- |

### 1.3 系统自动维护字段（表单不暴露，保存时由系统写入）

以下字段在新增 / 编辑表单中**均不可见、不可维护**，由系统按固定口径生成；后文按钮与规则不再重复说明：

| 字段 | 口径 |
| :--- | :--- |
| 公式编码 `code` | `FM-{三位序号}`，取全库最大序号 + 1，系统生成后不可修改 |
| 结果名称 `resultName` | 固定「碳排放量」 |
| 结果单位 `resultUnit` | 固定 `kgCO₂e` |
| 是否支持循环求和 `supportsSumLoop` | 固定「是」（多值入参按 Σ 语义逐值求和） |
| 数据归属 `dataOwnerType` | 固定「组织自建」 |
| 归属组织 `ownerOrg` | 原型固定「空天碳示范组织」 |
| 使用状态 `status` | 新增时默认「启用」，之后只走行操作 / 详情页操作切换 |
| 制单信息 | 创建人 = 当前用户、创建 / 更新时间 = 系统时间；编辑只刷新更新人与更新时间 |
| 是否允许负值结果 `supportsNegativeResult` | 表单不暴露开关：新建固定「否」；编辑时按历史值保留（预置 FM-006 回收信用法为「是」，编辑保存不受影响） |

### 1.4 上下游关系（引用，不重复定义）

| 关系 | 说明 |
| :--- | :--- |
| 行业库 | 「适用行业」多选引用行业库（原型取行业库启用项），至少 1 项 |
| 排放因子库 / 能源库 / 物料库 | 数据因素「因子」类引用排放因子库对象，选择后数值与单位由库带出（原型下拉取排放因子库） |
| 核算模型（建模侧） | 仅「启用」公式可被绑定；公式禁用 / 删除后历史绑定行保留 |

## 2. 业务规则说明

> 规则口径与《计算引擎配置业务PRD》§12 同源（R01–R10、R11、R13、R22）；本文按保存 / 因素 / 表达式 / 状态 / 试算 / 列表分组归并，编号便于交叉引用。

### 2.1 保存校验（新增 / 编辑，前端即时报错 + 服务端同口径拦截）

| 规则 | 内容 | 不满足时 |
| :--- | :--- | :--- |
| R01 | 公式名称必填（首尾空格不计） | 行内错误「请输入公式名称」 |
| R02 | 适用行业必填且至少 1 项 | 行内错误「请选择适用行业（至少 1 项）」 |
| R01 | 公式类型必填（因子公式 / 能耗公式 / 碳排公式 / 其他） | 行内错误「请选择公式类型」 |
| R10 | 公式说明 ≤ 1000 字符，带字数计数 | 超长阻断 |
| R03–R07 | 数据因素规则见 §2.2 | 汇总展示在「算法配置」区顶部错误条 |
| R08 / R09 | 计算表达式规则见 §2.3 | 同上 |

多处未通过时 toast「请先完善必填项」；错误定位到具体因素时在提示中点名该因素。

### 2.2 数据因素规则

| 规则 | 内容 |
| :--- | :--- |
| R03 | 至少 1 项数据因素（删除到 0 项阻断保存） |
| R04 | 因素名称非空，且同一公式内唯一；重名新建时自动追加序号 |
| R05 | 「因子」类必须选择引用对象，未选时阻断并指名 |
| R06 | 「常量」类必须填写常量值（如 `44/12`、`-1`、氧化率），未填阻断并指名 |
| R07 | 非因子类（活动数据 / 变量 / 常量 / 参数）必须填写单位 |
| 带出 | 「因子」类选择对象后：数值 = 因子值、单位 = 因子复合单位（如 `kgCO₂e/kWh`），只读不可手改；名称仍为默认名（因子 / 因子N）时同步改为因子名称（唯一化），已自定义则不覆盖 |
| 行类型 | 表单可维护四类行：活动数据（系统默认首行，类型固定不可切换）、常量 / 变量 / 因子（行内下拉可互切，切换即重置取值并重命名）；预置数据中的「参数（运行时填入）」行原型以固定标签展示，不开放类型切换 |
| 交互约束 | 任意行（含活动数据行）均可删除，最终受「至少 1 项」约束 |

### 2.3 计算表达式规则（受控表达式，不支持脚本）

| 规则 | 内容 |
| :--- | :--- |
| R08 | 表达式只能由**已定义的数据因素名称**、数字与 `+ - * / ( ) [ ] %` 组成；含其他内容即阻断，并回显非法片段 |
| R09 | 括号必须闭合（`( )`、`[ ]` 均可作分组） |
| 生成方式 | 只读输入框 + 「配置」按钮：弹窗内键盘点选数字 / 运算符、点选因素标签自动拼接，**不允许手写表达式** |
| 试算换算 | `[ ]` 视作分组括号；`数字%` 视作百分比；因素名按「名称从长到短」替换为样例数值 |

### 2.4 状态与删除约束

| 规则 | 内容 |
| :--- | :--- |
| R11 | 公式无审核、无版本化，任何状态均可直接编辑（直接覆盖，不追溯历史结果） |
| R13 | **仅「已禁用」公式可删除**（物理删除、不可恢复）；启用中删除被服务端拦截并提示「请先禁用该公式，再执行删除」 |
| R21 | 公式禁用 / 删除后建模侧历史绑定保留（删除弹窗提示先在建模侧解除绑定） |
| 变更留痕 | 编辑 / 启停均刷新更新人与更新时间；删除不留痕 |

### 2.5 试算规则（前端即时、不落库）

| 规则 | 内容 |
| :--- | :--- |
| R22 | 完整性校验 3 项：① 表达式只使用已定义因素与运算符；② 数据因素完整（因子已选对象、常量已填值）；③ 结果单位为碳排放量单位（`CO₂e` 结尾）。任一项不通过即提示「存在未通过项，请先修正」 |
| 入参 | 活动数据 / 变量手填样例入参（多值以英文逗号分隔，按 Σ 求和处理）；因子 / 常量自动带出、只读 |
| 输出 | 试算结果按 4 位小数展示 + 结果单位；不生成试算记录、不影响公式数据 |

### 2.6 列表与查询规则

| 规则 | 内容 |
| :--- | :--- |
| 列表列 | 公式名称（点击进详情）、公式编码、公式类型、适用行业、数据因素（N 项）、使用状态、更新时间、操作；**不再展示「计算公式」「结果单位」**（两者仍可按表达式关键字检索，见「查询」） |
| 排序 | 按公式编码升序（分页内稳定） |
| 查询 | 关键字（名称 / 编码 / 表达式模糊匹配）+ 公式类型 + 使用状态；条件变化自动回第 1 页；「重置」清空条件 |
| 分页 | 每页 20 条 |
| 查询行为 | 原型为前端即时过滤，「搜索」按钮仅 toast 提示（查询完成），不发起后端请求 |
| 导出 | 原型为模拟：toast「导出任务已创建，共 N 条」 |

## 4. 状态机说明

### 4.1 状态定义

| 状态 | 含义 | 进入方式 |
| :--- | :--- | :--- |
| 启用 | 可作为建模绑定候选 | 新增默认；禁用态执行「启用」 |
| 禁用 | 软停用，不作为绑定候选，仍保留数据 | 启用态执行「禁用」 |
| （删除） | 终态：记录物理移除、不可恢复 | 仅禁用态执行「删除」 |

### 4.2 状态流转

```text
        ┌──────────── 启用（初始态 / 新增默认）────────────┐
        │                                                │
        │ 禁用（二次确认）              启用（二次确认）  │
        ▼                                                │
   ┌─────────┐                                          │
   │  禁用   │ ────────── 删除（二次确认，仅禁用态可达）─┴─▶（记录移除）
   └─────────┘
```

### 4.3 迁移表

| 迁移 | 触发操作 | 约束 | 确认 |
| :--- | :--- | :--- | :--- |
| 启用 → 禁用 | 禁用 | 无（任意启用态可禁用） | 二次确认 |
| 禁用 → 启用 | 启用 | 无，双向可达 | 二次确认 |
| 禁用 → 删除 | 删除 | 仅禁用态入口可见；启用态由服务端兜底拦截（R13） | 二次确认 |

状态变更只刷新状态、更新人、更新时间，不改动公式算法内容；编辑不受状态限制（R11）。

### 4.4 状态 × 操作矩阵

| 操作 | 启用 | 禁用 |
| :--- | :---: | :---: |
| 查看 / 试算 | 是 | 是 |
| 编辑（直接覆盖） | 是 | 是 |
| 禁用 | 是 | — |
| 启用 | — | 是 |
| 删除 | — | 是 |
