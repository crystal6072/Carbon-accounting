# 公式管理字段清单

> **文档定位**：后台「核算配置 · 公式管理」字段定义的唯一真相源（SST）。
> **适用模块**：后台管理 → 核算配置 → 公式管理（`/model/formula`）。
> **核心对象**：公式配置（主对象）+ 层公式（固定 3 条子对象）+ 变量库（系统内置，非用户维护）。
> **版本**：V1.0。
> **更新时间**：2026-10-09。
> **口径基准**：以 `06prototypes/6-1系统原型骨架/src/pages/formula/`（`formulaMeta.ts` / `FormulaListPage.tsx` / `FormulaEditPage.tsx` / `FormulaTestModal.tsx`）的实际实现为准。
> **关联**：字段结构见本文；业务规则见同目录《公式管理业务 PRD》；核算侧口径见〔前台〕《碳足迹核算业务 PRD》§6、《碳足迹核算字段清单》§1.1 与《整体设计方案》§6.1.1。

## 0. 字段清单说明

| 项目 | 说明 |
| :--- | :--- |
| 功能定位 | 公式管理 = **配置「怎么算」的唯一入口**：一个公式配置内含**三层受控表达式**（行级 / 阶段汇总 / 全局），由前台核算项目在步骤①引用「已发布」版本，**核算引擎据此执行全部计算**。 |
| 与「计算公式」的区别 | 后台 **`/model/calc-engine`「计算公式」（`FM-xxx`）服务于工艺库 / 产品工艺的投入产出流**；本模块 **`/model/formula`「公式管理」（`FC-xxx`）服务于前台产品碳足迹核算项目**。两者**对象不同、不可混用**（见《计算引擎配置字段清单》§0 边界说明）。 |
| 对象边界 | 一个**公式配置** = 基本信息 + **固定 3 条层公式**（行级 / 阶段汇总 / 全局）+ 引用的**系统内置变量库**。**不引入**「阶段计算方案」「计算明细行」「公式绑定」中间层。 |
| 表达式口径 | 受控表达式：**变量占位 `[作用域.字段]` + 数字 + `+ − × ÷ ( )` 与 `SUM()`**；不支持脚本。展示层用全角 `× ÷ −`，引擎归一化为 `* / -`。 |
| 变量口径 | 变量由**系统内置**（不可增删改），随作用域变化；变量取值由**核算引擎在运行时注入**（详见 §3）。 |
| 状态口径 | **两态**：草稿 / 已发布。**草稿可编辑、可删除；已发布只读、不可删除**（须先「取消发布」）。 |
| 版本口径 | 公式配置**不做版本化流转**：`version` 为**展示用文本**（如 `v2.1`），不参与状态机；项目引用时按**名称 + 版本文本**快照到项目（`formulaName`）。 |
| 轻量口径 | **不做审核流程**；编辑为**实时保存**（无「保存」按钮），变更不追溯已核算的历史结果（E13）。 |
| 安全边界 | 不支持任意脚本执行，仅允许受控运算符、括号与**当前作用域变量库内**的变量占位。 |

## 1. 公式配置（主对象）

| 字段名称 | 字段编码 | 字段类型 | 是否必填 | 默认值 | 枚举值/取值范围 | 校验规则 | 字段说明 | 所属页面/模块 |
| :--- | :--- | :--- | :---: | :--- | :--- | :--- | :--- | :--- |
| 公式配置编码 | formula_config_id | 文本 | 是 | 系统生成 | `FC-{编号}`（新建取时间戳后 6 位；预置示例 `FC-1001`/`FC-1002`/`FC-1003`） | 全局唯一；系统生成、不可编辑 | 公式配置唯一标识 | 列表卡片 / 编辑页 |
| 公式配置名称 | formula_config_name | 文本 | 是 | 「新公式配置」 | 1–100 字符 | trim 后非空；新增时弹窗输入，空值拒绝 | 如「竹地板产品碳足迹核算公式」 | 列表卡片 / 编辑页 |
| 描述 | formula_config_description | 长文本 | 否 | 「新建公式配置，请完善各作用域公式后保存。」 | 文本 | 原型不设长度校验 | 公式口径说明 | 列表卡片 / 编辑页 |
| 状态 | formula_config_status | 枚举 | 是 | 草稿 | `draft`（草稿）/ `published`（已发布） | 新增默认「草稿」；**已发布**：不可编辑、不可删除 | 公式配置生命周期状态 | 列表卡片 / 编辑页 |
| 版本号 | formula_config_version | 文本 | 是 | `v1.0` | `v{x}.{y}` 文本 | 展示用；原型不自动递增、不可编辑 | 公式版本展示（非版本化流转） | 列表卡片 / 编辑页 |
| 更新人 | updated_by | 系统字段 | 是 | 系统生成 | 用户 | 不可编辑 | 最近更新人 | 列表卡片 / 编辑页 |
| 更新时间 | updated_at | 系统字段 | 是 | 系统生成 | `YYYY-MM-DD HH:mm` | 不可编辑 | 最近更新时间 | 列表卡片 / 编辑页 |

> **不存在的字段（重要）**：公式配置**没有**「审核状态」「生效时间」「适用行业」「适用边界」「绑定模型 / 绑定阶段」——适用范围一律由**项目在步骤①引用**承担；也**没有**「保存」按钮（**实时保存**）。

## 2. 层公式（固定 3 条子对象）

一个公式配置**固定含 3 条层公式**，key 与作用域由系统固定，用户只维护**表达式**。

| 字段名称 | 字段编码 | 字段类型 | 是否必填 | 默认值 | 校验规则 | 字段说明 |
| :--- | :--- | :--- | :---: | :--- | :--- | :--- |
| 作用域 | formula_scope | 枚举 | 是 | 系统固定 | `row`（行级）/ `stage`（阶段汇总）/ `global`（全局） | 决定变量库与引擎执行层 |
| 公式标识 | formula_key | 文本 | 是 | 系统固定 | `row-formula` / `stage-sum` / `global-footprint` | 层公式唯一标识 |
| 展示编码 | formula_code | 文本 | 是 | 系统固定 | `row` / `stage.sum` / `global.footprint` | 界面展示用 |
| 公式名称 | formula_name | 文本 | 是 | 系统固定 | 「行级公式」/「阶段汇总公式」/「产品碳足迹公式」 | 编辑器 Tab 名称 |
| 表达式 | formula_expression | 长文本 | 是 | 见 §2.2 | ① 非空；② 变量占位须在**当前作用域变量库**内；③ 语法合法（运算符 / 括号 / `SUM()` 成对匹配、可求值） | 该层计算公式 |

### 2.1 层公式清单（固定）

| # | Tab 文案 | 作用域 | 公式标识 | 展示编码 | 作用 |
| :-: | :--- | :--- | :--- | :--- | :--- |
| ① | 行级公式 | `row` | `row-formula` | `row` | 对**每一条阶段数据项（行）**求值 → 行碳排 |
| ② | 阶段汇总公式 | `stage` | `stage-sum` | `stage.sum` | 汇总**该阶段各行碳排** → 阶段碳排 |
| ③ | 全局公式 | `global` | `global-footprint` | `global.footprint` | 汇总**各阶段碳排** → 核算结果（单位产品碳足迹） |

### 2.2 默认表达式

```text
① 行级公式      [当前行.活动数据] × [当前行.单位换算系数] × [当前行.排放因子]
② 阶段汇总公式   SUM([当前阶段.总碳排])
③ 全局公式      SUM([当前阶段.总碳排])
```

### 2.3 校验提示分级（`validateFormula`）

| 作用域 | 级别 | 触发条件 | 提示 |
| :--- | :--- | :--- | :--- |
| 通用 | error | 表达式为空 | 「公式为空，请点击左侧变量或使用上方运算符编写公式」 |
| 通用 | error | 含未定义变量 | 「存在未定义变量：[xxx]」 |
| 通用 | error | 语法错误 / 不可求值 | 「公式语法有误：请检查运算符与括号是否成对匹配」 |
| 行级 | warning | 缺 `[当前行.活动数据]` 或 `[当前行.排放因子]` | 「建议包含变量 …，否则行碳排可能无法计算」 |
| 行级 | warning | 缺 `[当前行.单位换算系数]` | 「推荐包含变量 [当前行.单位换算系数] 以统一量纲…」 |
| 行级 | success | 通过 | 「行级公式校验通过，将逐行套用计算每行碳排」 |
| 阶段 | warning | 既无 `SUM()` 也无 `[当前阶段.总碳排]` | 「建议包含 SUM() 或 [当前阶段.总碳排] 以汇总当前阶段各行碳排」 |
| 阶段 | success | 通过 | 「阶段汇总公式校验通过，将累加当前阶段所有行的碳排」 |
| 全局 | warning | 既无 `SUM()` 也无 `[当前阶段.总碳排]` | 「建议包含 SUM() 或 [当前阶段.总碳排] 以汇总各阶段碳排」 |
| 全局 | success | 通过 | 「全局公式校验通过，将按全局公式汇总各阶段碳排得出核算结果」 |

> 提示级别为 `success` / `warning` / `error`；**warning 不阻断发布**。

## 3. 变量库（系统内置，非用户维护）

变量由系统内置、随作用域切换展示，**不可增删改**；取值由**核算引擎运行时注入**。

| 变量占位 | 变量类型 | 可用作用域 | 引擎取值 |
| :--- | :--- | :--- | :--- |
| `[当前行.活动数据]` | 行级 | 行级 | 该行填报的活动量（`quantity`） |
| `[当前行.单位换算系数]` | 全局 | 行级 | 活动数据单位 → 因子分母单位的换算系数（引擎按计量单位库「**基准中转**」计算：`f_from ÷ f_to`；无法换算时为 `1`） |
| `[当前行.排放因子]` | 因子 | 行级 | 该行匹配因子的因子值（`factorValue` 快照） |
| `[当前阶段.总碳排]` | 阶段 | 阶段 / 全局 | **集合变量**：阶段汇总时 = 该阶段各行碳排数组；全局汇总时 = 各阶段碳排数组（经 `SUM()` 展开求和） |
| `SUM()` | 函数 | 阶段 / 全局 | 对上述集合变量求和 |

**变量类型配色（界面圆点）**

| 变量类型 | 编码 | 说明 |
| :--- | :--- | :--- |
| 行级 | `row` | 取当前行数据 |
| 全局 | `global` | 引擎注入的全局/环境量（含单位换算系数） |
| 因子 | `factor` | 取当前行匹配因子 |
| 阶段 | `stage` | 集合型（分行 / 分阶段两种语义） |
| 函数 | `func` | `SUM()` 等受控函数 |

> **不存在的变量**：`[全局.产品总产量]`、`[全局.单位转换系数]` 已于 V1.0 移除 —— 单位产品碳足迹不固定除以产量（口径为「清单 = 单位产品用量」），单位换算系数改为**行级**（每行单位可能不同）。

## 4. 运算符与表达式语法

| 类别 | 取值 | 界面写法 | 引擎归一化 |
| :--- | :--- | :--- | :--- |
| 加 | `+` | ` + ` | `+` |
| 减 | `−` | ` − ` | `-` |
| 乘 | `×` | ` × ` | `*` |
| 除 | `÷` | ` ÷ ` | `/` |
| 括号 | `( )` | 直接插入 | 全角 `（）` 归一化为半角 |
| 函数 | `SUM()` | 插入后光标置于括号内 | `SUM(` → `(`（集合变量已展开为 `(v1+v2+…)`） |
| 数字 | `0–9 .` | 直接输入 | 字面量 |
| 变量占位 | `[作用域.字段]` | **点选左侧变量**插入 | 替换为数值字面量 |

## 6. 关键约束与联动规则

| 编号 | 约束 | 触发环节 | 处理 |
| :--- | :--- | :--- | :--- |
| D01 | 公式配置名称非空 | 新增 / 编辑 | 空值拒绝并提示「公式配置名称不能为空」 |
| D02 | 新增公式配置须输入名称 | 新增 | 弹窗输入；取消则终止新增 |
| D03 | 一个公式配置固定 3 条层公式（行级 / 阶段汇总 / 全局） | 新增 | 按默认表达式预置，**不可增删层** |
| D04 | 表达式变量须在当前作用域变量库内 | 编辑 / 试算 | 未定义变量 → `error` |
| D05 | 表达式语法合法（运算符 / 括号 / `SUM()` 可求值） | 编辑 / 试算 | 不合法 → `error`，界面给出定位提示 |
| D06 | 表达式为空 | 编辑 | `error`（原型允许暂存空值，但发布前应修正） |
| D07 | **已发布**公式配置不可编辑 | 编辑 | 列表「编辑」置灰；点击提示「已发布状态不可编辑，请先取消发布」 |
| D08 | **仅草稿**可删除 | 删除 | 已发布拦截并提示「已发布状态不可删除，请先取消发布」 |
| D09 | 复制公式配置 | 复制 | 生成**草稿副本**（名称加「（副本）」、版本重置 `v1.0`），公式内容整体复制 |
| D10 | 发布 / 取消发布双向可达 | 发布 | 发布后配置可被前台项目引用；取消发布后恢复可编辑 |
| D11 | 编辑实时保存 | 编辑 | 无「保存」按钮；改动立即写入（原型为内存态） |
| D12 | 公式变更不追溯已核算结果 | 编辑 | 项目需「重新计算」才生效（E13） |
| D13 | 项目按「名称 + 版本文本」快照引用 | 项目步骤① | 项目存 `formulaId` / `formulaName`；公式后续改名**不回溯**项目已存名称 |
| D14 | 前台候选仅返回**已发布**公式配置 | 项目步骤① | 未发布 / 未配置不出现在下拉候选 |
| D15 | 公式配置被项目引用后仍可取消发布 / 删除 | 编辑 / 删除 | 原型**不拦截**；核算时按 `formulaId` 取配置，**取不到则回退默认口径**（不阻断核算） |

## 7. 原型实现边界

| 项 | 状态 | 说明 |
| :--- | :--- | :--- |
| 公式配置列表（卡片网格 / 搜索） | 已实现 | `/model/formula` |
| 新增 / 复制 / 发布·取消发布 / 删除 | 已实现 | 新增走 `prompt` 输入名称；删除走 `confirm` |
| 编辑页（三作用域 Tab + 变量库 + 运算符 + 表达式编辑器） | 已实现 | `/model/formula/:id` |
| 实时校验（三级提示） | 已实现 | 编辑器内即时展示 |
| 试算弹窗（阶段 / 行自行新增，即时重算） | 已实现 | 与核算引擎同一变量绑定口径 |
| 基本信息（名称 / 描述）维护 | 已实现 | 实时保存；已发布只读 |
| 版本号自动递增 | **未实现** | `version` 为展示文本，需人工维护 |
| 公式配置独立「详情页」 | **未实现** | 列表卡片直接进入编辑页 |
| 独立「审核流程」 | **不适用** | 有意取舍：轻量配置，不做审核 |
| 「被项目引用」反查 | **未实现** | 删除 / 取消发布时不校验项目引用 |
| 公式配置使用状态（启用 / 禁用） | **不适用** | 用「草稿 / 已发布」两态替代 |
