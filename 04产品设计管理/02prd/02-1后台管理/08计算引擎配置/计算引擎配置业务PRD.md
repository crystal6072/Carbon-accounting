## 1. 功能定位

计算引擎配置负责核算模型域的两件事：

1. **计算公式**（公式配置）：定义「**一类计算项怎么算**」，只关心算法本身（数据因素 + 运算符），跨生命周期阶段、跨模型复用。
2. **核算模型**（模型管理）：定义「**公式算在哪**」，通过公式绑定把公式落到整模型、生命周期阶段、核算工序、投入项或产出项。

**核心业务表达**

```text
产品总碳排放量
  = Σ 模型下各绑定对象命中的公式结果
  = Σ（活动数据/自定义变量/业务库取值/常量 的运算组合）

公式结果 = 公式表达式(数据因素集合)
```

**计入方向**

| 方向 | 实现方式 | 示例 |
| :--- | :--- | :--- |
| 正排放 | 公式结果为正，加到总量 | 材料生产、电力消耗、燃料燃烧、运输、废弃物处理 |
| 扣减 / 负排放 | 公式勾选「允许负值结果」+ 数据因素含方向系数（如 `-1`） | 回收碳信用、替代法扣减、生物碳吸收 |

## 2. 设计原则

| 原则 | 说明 |
| :--- | :--- |
| 公式负责“怎么算” | 公式只定义一类计算项的算法，**不记录适用模型 / 适用阶段**，保证跨阶段、跨模型复用。 |
| 模型负责“算在哪” | 核算模型用「公式绑定」表达阶段 / 工序 / 投入项归属，公式本体保持干净。 |
| 不设阶段计算方案中间层 | 阶段归属由绑定对象直接表达，不引入额外配置层，降低配置复杂度。 |
| 公式轻量、不做版本化 | 公式不做审核流程、不做版本化，可直接编辑；变更不追溯已核算的历史结果。 |
| 公式类型按“输入口径”分类 | 因子公式 / 能耗公式 / 碳排公式 / 其他四类；材料、运输、热力、制冷剂、末期处理、回收信用等方法学差异由绑定对象与数据因素体现。 |
| 受控表达式 | 只允许「已定义的数据因素名称 + 数字 + `+ - * / ( ) [ ] %`」，不支持任意脚本。 |
| 数据因素即运算项 | 因素名称直接作为表达式中的运算项，不再单独维护变量编码与变量类型。 |
| 支持 Σ 循环计算 | 活动数据 / 自定义变量支持多值入参，按 `SUM()` 语义逐值求和。 |
| 模型发布冻结绑定 | 草稿模型可编辑与配置绑定；发布后绑定冻结，可被项目引用；如需调整须先停用。 |
| 结果可解释 | 结果可追溯到公式、结果单位、数据因素取值与命中的绑定对象。 |

## 3. 目标用户

| 角色 | 主要诉求 | 典型操作 |
| :--- | :--- | :--- |
| 平台运营人员 | 维护平台预置通用公式 | 新建因子公式、能耗公式、碳排公式 |
| 专业配置人员 | 维护公式并为模型配置绑定 | 新建 / 编辑公式、试算校验、新增公式绑定、设为默认 |
| 组织管理员 | 管理组织自建公式与模型 | 启用 / 禁用 / 删除、发布 / 停用模型 |
| 核算人员 | 在项目中引用已发布的核算模型 | 选择模型并执行核算（核算侧，不在本模块） |

> 本期公式**不做审核流程**，因此不涉及「审核人员」角色动作；模型侧为「发布 / 停用」两态动作，无独立审核环节。

## 4. 使用场景

| 场景编号 | 场景 | 说明 |
| :--- | :--- | :--- |
| S01 | 新建因子公式 | 数据因素 = 活动数据 + 排放因子（业务库取值）；表达式 `活动数据*排放因子`。 |
| S02 | 新建化石燃料燃烧公式 | 表达式 `燃料消耗量*低位发热量*含碳量*氧化率*分子量比值`；后四项为常量，可直接维护数值。 |
| S03 | 新建净外购热力公式 | 表达式 `净外购热力*热力排放因子`；活动数据单位 GJ，因子单位 `tCO₂e/GJ`。 |
| S04 | 新建制冷剂泄漏公式 | 表达式 `制冷剂泄漏量*GWP`；GWP 为常量（如 1430 `kgCO₂e/kg`）。 |
| S05 | 新建运输 t·km 公式 | 表达式 `运输重量*运输距离*运输因子`；周转量由重量 × 距离直接相乘得到。 |
| S06 | 新建回收信用公式（减碳） | 勾选「允许负值结果」；数据因素含方向系数常量 `-1`，结果以负值扣减。 |
| S07 | 公式试算与校验 | 打开试算弹窗：3 项完整性校验 + 手填样例入参 → 得到试算结果。 |
| S08 | 新建核算模型 | 维护模型名称、核算边界、版本号、适用行业、模型说明。 |
| S09 | 为模型配置公式绑定 | 整模型绑定兜底公式，再为关键生命周期阶段 / 核算工序 / 投入项绑定精确公式。 |
| S10 | 同对象多公式时设置默认 | 同一对象绑定了多条公式，指定其中一条为默认（命中优先）。 |
| S11 | 发布模型 | 发布后绑定冻结、模型可被项目引用；需要调整时先停用。 |

## 8. 核心对象关系

```text
计算公式（跨阶段、跨模型复用）
  ├── 数据因素 1..N
  │     ├── 活动数据
  │     ├── 自定义变量
  │     ├── 业务库取值（排放因子库 / 能源库 / 物料库）
  │     └── 常量
  └── 结果（结果名称 = 碳排放量，结果单位 = kgCO₂e）
        ↑ 被引用（仅「启用」公式可被引用）
核算模型
  └── 公式绑定 1..N
        ├── 绑定对象 = 整模型（默认兜底）
        ├── 绑定对象 = 生命周期阶段
        ├── 绑定对象 = 核算工序
        ├── 绑定对象 = 投入项（工序编码::物料编码）
        └── 绑定对象 = 产出项（工序编码::物料编码）
```

## 9. 核心流程

### 9.1 配置计算公式

1. 在「计算公式」列表点「新增公式」。
2. 填写公式名称、选择适用行业（至少 1 项）、选择公式类型。
3. 按需选择「是否允许负值结果」（减碳类公式选「是」）。
4. 配置数据因素：默认含 1 行「活动数据」，按需添加数据因素（业务库取值）/ 自定义变量 / 常量，并维护因素名称、数值、单位。
5. 点「配置」打开表达式弹窗，用键盘与数据因素标签拼接计算公式。
6. 保存后系统生成公式编码 `FM-{序号}`，默认状态「启用」。

### 9.2 试算与校验

1. 在公式详情点「试算」。
2. 系统执行 3 项完整性校验（表达式合法性、数据因素完整性、结果单位为碳排放量单位）。
3. 活动数据 / 自定义变量手填样例入参（多值用英文逗号分隔，按求和处理）。
4. 点「执行试算」，得到试算结果（4 位小数）与结果单位。

### 9.3 配置核算模型与公式绑定

1. 在「模型管理」新建模型（弹窗），填写模型名称、核算边界、版本号、适用行业、模型说明。
2. 进入模型详情，点「新增公式绑定」。
3. 选择引用公式（仅「启用」公式可选）、绑定对象类型、绑定对象，选择是否默认，填写备注。
4. 整模型绑定建议作为兜底默认；生命周期阶段 / 核算工序 / 投入项 / 产出项用于精确命中。
5. 同一对象绑定多条公式时，指定其中一条为「默认」。

### 9.4 发布模型与项目引用

1. 草稿状态下可反复调整绑定。
2. 点「发布」后公式绑定冻结，模型可被项目引用；发布模型不可再编辑基本信息或新增绑定。
3. 需要调整时先「停用」（软停用，历史快照保留），停用后可重新发布。
4. 仅「草稿」模型可删除，删除时连带清理其全部绑定行。

### 9.5 运行时匹配（口径）

```text
投入项 → 投入项类型 → 核算工序 → 生命周期阶段 → 整模型默认
（同对象多条命中时以「是否默认」行优先）
```

## 10. 典型公式支撑说明

> 公式与生命周期阶段无关；下表的「阶段」仅为使用场景示意，阶段归属一律在建模时通过绑定配置。

| 使用场景 | 公式示例 | 公式类型 | 数据因素配置 |
| :--- | :--- | :--- | :--- |
| 材料生产 | `活动数据*排放因子` | 因子公式 | 活动数据（kg）+ 排放因子（排放因子库取值） |
| 运输（周转量） | `运输重量*运输距离*运输因子` | 因子公式 | 运输重量（t）+ 运输距离（km）+ 运输因子（排放因子库取值） |
| 化石燃料燃烧 | `燃料消耗量*低位发热量*含碳量*氧化率*分子量比值` | 能耗公式 | 燃料消耗量（活动数据）+ 低位发热量 / 含碳量 / 氧化率 / 分子量比值（常量，如 42.7、0.0204、0.99、44/12） |
| 净外购热力 | `净外购热力*热力排放因子` | 能耗公式 | 净外购热力（GJ）+ 热力排放因子（常量，`tCO₂e/GJ`） |
| 制冷剂泄漏 | `制冷剂泄漏量*GWP` | 碳排公式 | 制冷剂泄漏量（kg）+ GWP（常量，`kgCO₂e/kg`） |
| 生命周期末期 | `废弃处理量*处理方式排放因子` | 因子公式 | 废弃处理量（kg）+ 处理方式排放因子（排放因子库取值） |
| 回收信用（减碳） | `回收量*替代因子*方向系数` | 因子公式 | 回收量 + 替代因子（排放因子库取值）+ 方向系数（常量 `-1`）；勾选「允许负值结果」 |
| 使用阶段能耗 | `使用年限*年能耗量*能源因子` | 能耗公式 | 使用年限、年能耗量（自定义变量，运行时取值）+ 能源因子（排放因子库取值） |

| 二次确认 | 启用 / 禁用 / 删除均走确认弹窗；删除提示「仅「已禁用」的公式可删除；建模侧若仍有绑定，请先在建模中解除」。 |

### 11.2 计算公式新增 / 编辑

| 功能 | 说明 |
| :--- | :--- |
| 公式名称 | 必填，如「因子法」。 |
| 适用行业 | 必填，多选引用行业库（A1-4），至少 1 项。 |
| 公式类型 | 必填，因子公式 / 能耗公式 / 碳排公式 / 其他。 |
| 是否允许负值结果 | 选填，默认「否」；减碳类公式（回收信用、生物碳）选「是」；不再由公式类型自动判定。 |
| 描述 | 选填，≤1000 字符，带字数统计。 |
| 计算公式 | 必填，只读输入框 + 「配置」按钮打开表达式弹窗。 |
| 数据因素 | 至少 1 项；支持添加数据因素 / 自定义变量 / 常量，支持删除。 |
| 系统自动项 | 结果名称（碳排放量）、结果单位（kgCO₂e）、是否支持循环求和（是）、数据归属（组织自建）由系统按口径生成，表单不暴露。 |
| 保存 | 保存后跳转公式详情；编辑为直接覆盖（无版本化）。 |

### 11.3 数据因素配置

| 因素来源 | 行内可维护 | 取值说明 |
| :--- | :--- | :--- |
| 活动数据 | 因素名称、单位 | 系统标准取数项，运行时由填报侧提供；默认首行。 |
| 自定义变量 | 因素名称、单位 | 自命名、运行时取值，如「使用年限」「年能耗量」。 |
| 业务库取值 | 来源库、引用对象 | 引用排放因子库 / 能源库 / 物料库；数值与单位由库带出（可为复合单位，如 `kgCO₂e/kWh`）。 |
| 常量 | 常量名称、常量值、单位 | 公式固定参数，如 `44/12`、`-1`、氧化率。 |

**约束**：至少 1 项；因素名称同一公式内唯一；业务库取值必须选择引用对象；常量必须填写常量值；活动数据 / 自定义变量 / 常量必须填写单位。

### 11.5 计算公式详情

| 分组 | 内容 |
| :--- | :--- |
| 基本信息 | 公式编码、公式类型、适用行业、使用状态、结果名称、结果单位、关联生命周期阶段（固定「不关联（公式通用、可跨阶段复用）」）、计算公式、描述。 |
| 数据因素 | 只读表格：因素名称、因素来源、来源库、引用对象、因素数值、单位。 |
| 制单信息 | 创建人、创建时间、更新人、更新时间。 |
| 顶部操作 | 返回列表、试算、编辑、禁用 / 启用、删除。 |
| 口径提示 | 计算公式由数据因素与运算符点选生成，不使用脚本；公式不做审核流程、不做版本化，变更不追溯历史结果。 |

### 11.6 试算与校验

| 功能 | 说明 |
| :--- | :--- |
| 完整性校验 | ① 计算公式只使用已定义的数据因素与运算符；② 数据因素完整（业务库取值已选对象、常量已填值）；③ 结果单位为碳排放量单位。 |
| 样例入参 | 活动数据 / 自定义变量手填；支持多值（英文逗号分隔，Σ 求和）；业务库取值与常量自动带出、只读。 |
| 试算结果 | 输出数值 + 结果单位，按 4 位小数展示。 |
| 持久化 | 无（不记录试算记录）。 |

### 11.7 核算模型

| 功能 | 说明 |
| :--- | :--- |
| 列表查询 | 模型名称 / 编码、核算边界、状态。 |
| 列表列 | 模型编码、模型名称、适用行业（空 = 全行业通用）、核算边界、版本、公式绑定数（N 条 / 未配置）、状态、更新时间、操作。 |
| 行操作 | 查看、编辑（仅草稿）、发布 / 停用、删除（仅草稿）。 |
| 表单字段 | 模型名称（必填）、核算边界（必填，默认摇篮到大门）、版本号（必填，默认 V1.0）、适用行业（选填，空 = 全行业通用）、模型说明（≤500 字符）。 |
| 详情分组 | 基本信息（编码 / 边界 / 版本 / 适用行业 / 状态 / 公式绑定数 / 说明）、公式绑定、制单信息。 |
| 状态动作 | 发布（绑定冻结、可被项目引用）、停用（软停用，历史快照保留，可重新发布）、删除（仅草稿，连带清理绑定）。 |

### 11.8 模型公式绑定

| 功能 | 说明 |
| :--- | :--- |
| 新增绑定 | 弹窗：引用公式（仅启用公式可选）、绑定对象类型、绑定对象、是否默认（默认「是」）、备注。 |
| 绑定对象候选 | 整模型（特判，固定模型编码）；启用中的生命周期阶段；启用中的核算工序；启用工序的投入项 / 产出项（编码 `工序编码::物料编码`）。 |
| 绑定表格列 | 绑定对象（默认行前置「默认 ·」）、对象类型、对象编码、引用公式（禁用标注「已禁用」、删除显示「公式已删除」）、是否默认、备注、操作。 |
| 行操作 | 设为默认（非默认行）、解除绑定（二次确认，说明不影响公式本体与历史核算结果）。 |
| 维护权限 | 仅「草稿」模型可新增绑定、设为默认、解除绑定；已发布 / 已停用只读。 |
| 默认唯一 | 同一「模型 + 对象类型 + 对象编码」下仅一条默认；保存默认时其余自动置否。 |
| 重复拦截 | 同一对象不可重复绑定同一公式。 |

## 12. 规则与校验

| 规则编号 | 规则 | 触发环节 | 处理 |
| :--- | :--- | :--- | :--- |
| R01 | 公式名称、适用行业、公式类型必填 | 保存 | 缺失阻断保存 |
| R02 | 适用行业至少 1 项 | 保存 | 为空阻断 |
| R03 | 至少 1 项数据因素 | 保存 | 为空阻断 |
| R04 | 数据因素名称同一公式内唯一且非空 | 保存 | 重复 / 为空阻断 |
| R05 | 业务库取值必须选择引用对象 | 保存 | 未选阻断并指名因素 |
| R06 | 常量必须填写常量值 | 保存 | 未填阻断并指名因素 |
| R07 | 活动数据 / 自定义变量 / 常量必须填写单位 | 保存 | 未填阻断并指名因素 |
| R08 | 计算公式只能使用已定义数据因素与 `+ - * / ( ) [ ] %` | 保存 / 试算 | 含非法内容阻断并回显非法片段 |
| R09 | 计算公式括号必须闭合 | 保存 / 试算 | 不闭合阻断 |
| R10 | 公式说明 ≤1000 字符 | 保存 | 超长阻断 |
| R11 | 公式不做审核与版本化，编辑为直接覆盖 | 编辑 | 允许；变更不追溯历史结果 |
| R12 | 仅「启用」公式可作为绑定候选 | 绑定 | 候选过滤 + 保存校验双重拦截 |
| R13 | 仅「禁用」公式可删除 | 删除 | 启用中阻断并提示先禁用 |
| R14 | 模型名称、核算边界、版本号必填；模型说明 ≤500 字符 | 保存 | 缺失 / 超长阻断 |
| R15 | 仅「草稿」模型可编辑基本信息 | 编辑 | 已发布阻断并提示先停用 |
| R16 | 仅「草稿」模型可新增绑定 / 设为默认 / 解除绑定 | 绑定 | 已发布阻断（绑定冻结）；已停用只读 |
| R17 | 仅「草稿」模型可删除 | 删除 | 非草稿阻断；删除时清理该模型全部绑定行 |
| R18 | 同一「模型 + 对象类型 + 对象编码」下默认行唯一 | 绑定 / 设为默认 | 自动将其余行「是否默认」置否 |
| R19 | 同一对象不可重复绑定同一公式 | 绑定 | 重复阻断 |
| R20 | 绑定对象必填 | 绑定 | 未选阻断 |
| R21 | 公式禁用 / 删除后历史绑定保留 | 展示 | 详情标注「已禁用」或显示「公式已删除」 |
| R22 | 结果单位须为碳排放量单位 | 试算校验 | 非 `CO₂e` 结尾显示校验不通过 |

## 13. 异常场景

| 异常编号 | 场景 | 影响 | 处理建议 |
| :--- | :--- | :--- | :--- |
| CE-E01 | 保存公式时数据因素校验不通过 | 阻断保存 | 在「算法配置」区顶部展示具体错误（未命名 / 重名 / 未选引用对象 / 常量未填值 / 缺单位 / 表达式非法）。 |
| CE-E02 | 表达式含未定义内容 | 阻断保存 / 试算 | 提示非法片段，并列出允许的运算符。 |
| CE-E03 | 表达式括号不匹配 | 阻断保存 / 试算 | 提示「计算公式的括号不匹配」。 |
| CE-E04 | 试算样例入参为空或非数值 | 阻断试算 | 提示「「{因素名称}」样例入参不能为空 / 须为数值」。 |
| CE-E05 | 试算结果非有限数 | 阻断试算 | 提示「试算结果无效，请检查样例入参」。 |
| CE-E06 | 绑定候选为空（无启用公式 / 无启用对象） | 无法绑定 | 公式下拉提示仅启用公式可选；对象下拉提示先选类型或先维护启用对象。 |
| CE-E07 | 引用公式被禁用 | 不影响历史核算 | 绑定详情标注「已禁用」，运行时需重新选择启用公式。 |
| CE-E08 | 引用公式被删除 | 绑定行留空 | 详情显示「公式已删除」，需重新绑定。 |
| CE-E09 | 已发布模型尝试编辑 / 绑定 | 阻断 | 提示「请先停用后再修改」。 |
| CE-E10 | 非草稿模型尝试删除 | 阻断 | 提示「仅「草稿」状态的模型可删除」。 |
| CE-E11 | 同一对象重复绑定同一公式 | 阻断 | 提示「该对象已绑定同一公式，请勿重复绑定」。 |
| CE-E12 | 模型不存在 / 已删除 | 详情空态 | 显示「模型不存在或已被删除」。 |

## 15. 数据流转说明

```text
行业库 / 排放因子库 / 能源库 / 物料库 / 工序库 / 生命周期阶段
        ↓
计算公式（数据因素 + 受控表达式）—— 跨阶段、跨模型复用
        ↓
核算模型（公式绑定：整模型 / 阶段 / 工序 / 投入项 / 产出项）
        ↓
项目引用已发布模型（后续迭代：生成配置快照）
        ↓
按绑定对象命中公式 → 逐条计算 → 按阶段 / 工序 / 产品总量汇总
        ↓
核算结果与报告
```

**追溯要求**

| 追溯对象 | 追溯内容 |
| :--- | :--- |
| 公式 | 公式编码、名称、类型、表达式、结果单位、是否允许负值结果。 |
| 数据因素 | 因素名称、来源、来源库、引用对象、数值、单位。 |
| 模型 | 模型编码、名称、核算边界、版本、状态、适用行业。 |
| 绑定 | 引用公式、绑定对象类型 / 编码 / 名称、是否默认、备注。 |
