## 1. 功能定位

公式管理负责一件事：**定义「产品碳足迹怎么算」**。

一个**公式配置**内含**三层受控表达式**，由前台核算项目在步骤①引用「已发布」版本，**核算引擎据此执行全部计算**：

```text
① 行级公式     逐条「阶段数据项（行）」求值      → 行碳排
② 阶段汇总公式  汇总该阶段各行碳排               → 阶段碳排
③ 全局公式     汇总各阶段碳排                    → 核算结果（单位产品碳足迹）
```

**核心业务表达**

```text
行碳排   = 行级公式([当前行.活动数据], [当前行.单位换算系数], [当前行.排放因子])
阶段碳排 = 阶段汇总公式(该阶段各行碳排)
核算结果 = 全局公式(各阶段碳排)
```

> **改公式即改算法**：更换 / 调整公式配置即可承载标准差异（ISO 14067 / PAS 2050 / GB/T 24067 / PEF）与产品特有折算，**无需修改引擎**。

**与「计算公式」的边界（重要）**

| | 本模块 · 公式管理 | 后台 · 计算公式 |
| :--- | :--- | :--- |
| 菜单 | `/model/formula` | `/model/calc-engine` |
| 编码 | `FC-{编号}` | `FM-{序号}` |
| 对象 | 公式配置（三层表达式） | 计算公式（数据因素 + 表达式） |
| 服务对象 | **前台 PCF 核算项目**（步骤① 引用 → 步骤④ 执行） | **工艺库 / 产品工艺的投入产出流** |
| 用途 | 决定核算结果 | 决定工序投入产出项的算法 |
| 关系 | **两者不可混用**；前台核算只认本模块 | — |

## 2. 设计原则

| 原则 | 说明 |
| :--- | :--- |
| 三层分工 | 行级管「一条数据怎么算」、阶段汇总管「一个阶段怎么合」、全局管「一个项目怎么出结果」，层次与核算引擎一一对应 |
| 变量内置 | 变量由系统内置、不可增删改；用户只写表达式，避免变量体系失控 |
| 受控表达式 | 只允许「当前作用域变量占位 + 数字 + `+ − × ÷ ( )` 与 `SUM()`」，不支持任意脚本 |
| 轻量配置 | **不做审核流程、不做版本化流转**；编辑实时保存；`version` 仅演示性文本 |
| 状态两态 | 草稿 / 已发布：**已发布只读、不可删除**，须先「取消发布」 |
| 引用即快照 | 项目引用时快照 `formulaId` + `formulaName`；公式后续改名不回溯项目 |
| 兜底不阻断 | 公式缺失 / 表达式非法时，核算引擎**回退默认口径**，不让整个核算挂掉 |
| 可解释 | 核算结果可标注所引用的公式名称（`PcfCalcResult.formulaName`） |

## 4. 使用场景

| 场景编号 | 场景 | 说明 |
| :--- | :--- | :--- |
| S01 | 新建公式配置 | 列表点「+ 新增公式配置」→ 输入名称 → 系统按默认表达式预置三层公式 |

| S04 | 扣减项（负排放） | 把某行数据项填为负值，或在公式中引入减项（如 `− [当前行.活动数据] × …`） |

| S08 | 取消发布后修改 | 已发布 → 点「取消发布」→ 恢复可编辑 → 调整 → 重新发布 |
| S09 | 项目引用并核算 | 前台步骤① 选择「核算公式」→ 步骤④「开始核算」→ 结果按该公式产出，结果卡标注公式名称 |

## 8. 核心对象关系

```text
公式配置（FormulaConfig，FC-{编号}）
  ├── 基本信息（名称 / 描述 / 状态 / 版本 / 更新人 / 更新时间）
  ├── 层公式 × 3（固定）
  │     ├── ① 行级公式      row-formula      scope=row
  │     ├── ② 阶段汇总公式   stage-sum        scope=stage
  │     └── ③ 全局公式      global-footprint scope=global
  └── 变量库（系统内置，随作用域切换；不可维护）

前台核算项目（PcfProject）
  └── formulaId + formulaName（步骤① 引用「已发布」配置的快照）
        ↓ 步骤④ 执行
核算引擎（runPcfCalc）：行级 → 阶段汇总 → 全局 → PcfCalcResult
```

## 9. 核心流程

### 9.1 新建与配置公式

1. 列表点「+ 新增公式配置」，输入名称（空值拒绝）。
2. 进入编辑页，三层公式已按默认表达式预置。
3. 在「① 行级公式」Tab：点选左侧变量、点运算符，拼接表达式。
4. 切到「② 阶段汇总公式」「③ 全局公式」分别编写（通常保持 `SUM([当前阶段.总碳排])`）。
5. 表达式实时校验：`error` 须修正，`warning` 建议修正但不阻断。
6. 名称 / 描述随时可改，**实时保存**。

### 9.2 试算验证

1. 点顶部「试算」。
2. 「+ 新增阶段」→ 阶段内「+ 新增行」，录入名称、活动数据、单位换算系数、排放因子。
3. 系统即时重算并展示：各阶段碳排、模型总碳排、核算结果（按全局公式）。
4. 试算口径与步骤④ 核算**完全一致**（同一变量绑定与表达式求值）。

### 9.3 发布与项目引用

1. 点「发布」→ 状态置「已发布」（只读）。
2. 前台新建核算项目 → 步骤①「核算公式」下拉出现该配置（**仅返回已发布**）。
3. 保存步骤① 时快照 `formulaId` / `formulaName` 到项目。

### 9.4 核算执行（消费侧口径，详见前台 PRD）

```text
行级：逐条阶段数据项 → 行级公式求值（单位换算系数由引擎按「基准中转」计算）
阶段：按阶段汇总公式汇总该阶段各行
全局：按全局公式汇总各阶段 → unitEmission（核算结果）
兜底：未引用 / 配置不存在 / 表达式非法 → 回退默认口径，不阻断核算
```

### 9.5 变更与重算

```text
公式编辑（实时保存） → 已核算项目结果不变（不追溯）
                     → 在项目中点「重新计算」→ 产出新结果版本（V+1）
```

## 10. 变量与默认公式（口径）

### 10.1 变量（系统内置）

| 变量占位 | 作用域 | 取值来源 |
| :--- | :--- | :--- |
| `[当前行.活动数据]` | 行级 | 该行填报的活动量 |
| `[当前行.单位换算系数]` | 行级 | 活动数据单位 → 因子分母单位的换算系数（引擎按计量单位库「**基准中转**」计算；无法换算时为 `1`） |
| `[当前行.排放因子]` | 行级 | 该行匹配因子的因子值（快照） |
| `[当前阶段.总碳排]` | 阶段 / 全局 | 集合变量：阶段汇总时 = 该阶段各行碳排；全局汇总时 = 各阶段碳排 |

### 10.2 默认公式

| 层 | 默认表达式 |
| :--- | :--- |
| ① 行级 | `[当前行.活动数据] × [当前行.单位换算系数] × [当前行.排放因子]` |
| ② 阶段汇总 | `SUM([当前阶段.总碳排])` |
| ③ 全局 | `SUM([当前阶段.总碳排])` |

### 10.3 典型改造示例

| 目标 | 改哪层 | 示例表达式 |
| :--- | :--- | :--- |
| 统一按固定折减 | 行级 | `[当前行.活动数据] × [当前行.单位换算系数] × [当前行.排放因子] × 0.98` |
| 不做单位换算（强约定同口径） | 行级 | `[当前行.活动数据] × [当前行.排放因子]` |
| 阶段碳排取平均（特殊口径） | 阶段汇总 | `SUM([当前阶段.总碳排]) ÷ 3` |
| 结果按批次规模折算 | 全局 | `SUM([当前阶段.总碳排]) ÷ 1000` |

> **注意**：`[全局.产品总产量]` / `[全局.单位转换系数]` 两个旧变量已移除；如需归一化请在公式内以常数表达，或后续按需恢复「产出量」字段并作为变量取值源。

## 12. 规则与校验

| 规则编号 | 规则 | 触发环节 | 处理 |
| :--- | :--- | :--- | :--- |
| R01 | 公式配置名称必填（trim 后非空） | 新增 / 编辑 | 空值阻断并提示 |
| R02 | 一个公式配置固定 3 条层公式 | 新建 | 按默认表达式预置，不可增删层 |
| R03 | 表达式变量须在当前作用域变量库内 | 编辑 / 试算 | 未定义变量 → `error` 并列出变量名 |
| R04 | 表达式语法合法（运算符 / 括号 / `SUM()` 可求值） | 编辑 / 试算 | 不合法 → `error` |
| R05 | 行级公式建议含活动数据与排放因子 | 编辑 | 缺失 → `warning`（不阻断发布） |
| R06 | 行级公式建议含单位换算系数 | 编辑 | 缺失 → `warning`（提示「以统一量纲」） |
| R07 | 阶段 / 全局公式建议含 `SUM()` 或 `[当前阶段.总碳排]` | 编辑 | 缺失 → `warning` |
| R08 | **已发布**配置不可编辑 | 编辑 | 列表「编辑」置灰 + 提示先取消发布 |
| R09 | **仅草稿**可删除 | 删除 | 已发布拦截并提示先取消发布 |
| R10 | 复制生成**草稿副本**，名称加「（副本）」、版本重置 `v1.0` | 复制 | 直接执行 |
| R11 | 编辑实时保存，无「保存」按钮 | 编辑 | 改动立即写入 |
| R12 | 公式变更不追溯已核算结果 | 编辑 | 项目需「重新计算」生效（E13） |
| R13 | 前台步骤① 仅返回**已发布**配置 | 项目步骤① | 未发布 / 未配置不出现在候选 |
| R14 | 配置被引用后取消发布 / 删除不阻断 | 编辑 / 删除 | 原型不校验；核算时取不到配置 → **回退默认口径，不阻断核算** |
| R15 | 试算数据不落库 | 试算 | 关闭弹窗即丢弃 |

## 13. 异常场景

| 编号 | 场景 | 影响 | 处理建议 |
| :--- | :--- | :--- | :--- |
| FE-E01 | 新增时名称为空 | 不创建 | 提示「公式配置名称不能为空」 |
| FE-E02 | 表达式含未定义变量 | 校验 `error` | 提示含未定义变量名，指引从左侧变量库点选 |
| FE-E03 | 表达式括号 / 运算符不匹配 | 校验 `error` | 提示「公式语法有误：请检查运算符与括号是否成对匹配」 |
| FE-E04 | 表达式为空 | 校验 `error` | 提示「公式为空，请点击左侧变量或使用上方运算符编写公式」 |
| FE-E05 | 已发布配置点「编辑」 | 阻断 | 提示「已发布状态不可编辑，请先取消发布」 |
| FE-E06 | 已发布配置点「删除」 | 阻断 | 提示「已发布状态不可删除，请先取消发布」 |
| FE-E07 | 试算结果非有限数 | 阻断展示 | 提示「试算结果无效，请检查全局公式」 |
| FE-E08 | 公式配置不存在（URL 直访） | 空态 | 编辑页展示空态并可返回列表 |
| FE-E09 | 项目引用的公式被取消发布 / 删除 | 核算仍可执行 | 引擎按 `formulaId` 取配置，取不到则**回退默认口径**（不阻断），结果 `formulaName` 为空 |

## 15. 数据流转说明

```text
管理员配置公式
      ↓
公式配置（三层受控表达式）—— 无审核、无版本化流转
      ↓ 发布（草稿 → 已发布）
前台新建核算项目 · 步骤① 选择「核算公式」（仅已发布）
      ↓ 保存时快照 formulaId / formulaName
步骤② 填报阶段数据项（单位产品用量 + 匹配因子）
      ↓ 检测通过
步骤④ 核算（runPcfCalc）：行级公式 → 阶段汇总公式 → 全局公式
      ↓
核算结果（unitEmission = 全局公式结果）+ 阶段 / 数据项 / 排放源汇总
      ↓
步骤⑤ 报告（标注核算公式名称）
```

**追溯要求**

| 追溯对象 | 追溯内容 |
| :--- | :--- |
| 公式配置 | 编码、名称、状态、版本文本、三层表达式、更新人、更新时间 |
| 项目引用 | `formulaId`、`formulaName`（快照） |
| 核算结果 | `formulaName`（本次引用的公式名称）、`unitEmission`、`totalEmission`、`unitEmissionBreakdown` |
| 结果明细 | 每行的活动量、单位、因子名 / 因子值、排放量 |
