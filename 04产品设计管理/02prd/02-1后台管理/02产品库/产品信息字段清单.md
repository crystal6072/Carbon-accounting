## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 产品信息库 |
| 业务归属 | 后台管理 → 基础库 → 产品库 → 产品信息库（方案 §2.3 A1-6、§八 P08） |
| 模块类型 | 完整主数据（带可维护子表、版本化） |
| 核心对象 | 产品（含产品版本） |
| 核心职责 | 以「基本信息 + 工艺 + 工序」的组合方式定义被核算产品，并通过版本化向核算项目提供稳定的版本快照 |

### 1.2 对象结构

**推荐结构（方案 A，待确认 Q01）**

| 结构 | 对象 | 与主对象关系 | 主键/唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 产品 | 主对象 | 产品编码 + 版本号 | 版本化主数据，一个产品下可有多个版本 |
| 子表 | 产品工艺 | 1:N | 产品版本 + 工艺流程 | 引用「工艺流程库」的工艺流程（A1-7） |
| 子表（孙表） | 产品工序 | 1:N（挂在产品工艺下） | 产品版本 + 工艺 + 工序 | 引用「工序管理」的工序（A1-8），随工艺流程带出 |
| 只读明细 | 投入产出流 | 1:N（挂在产品工序下，只读） | 工序 | **维护归属为「工序管理」，本模块只读引用**（见 Q07） |

**备选结构（方案 B，待确认 Q01）**

| 结构 | 对象 | 说明 |
| :--- | :--- | :--- |
| 主表 | 产品 | 同上 |
| 子表 | 产品工序 | 工序直接挂产品（2 层结构），工序上带「所属工艺流程」字段 |

> A/B 取舍见 §9 Q01。**在确认前，下游 Demo PRD 不得按某一方案画页面。**

### 1.3 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | 人工维护（专业配置人员维护平台级、组织管理员维护组织自建，方案 §7.2） |
| ERP是否数据源 | 否 |
| 新增编辑 | 支持（按状态支持：草稿版本可编辑，已发布版本不可编辑，只能新建版本） |
| 子表 | 可维护（产品工艺、产品工序）；投入产出流为只读引用 |
| 导入导出 | 导出：支持（【待确认】范围）；导入：V0.1 不支持（【待确认 Q09】） |
| 状态与执行 | 版本化（V1.0/V1.1/V2.0）+ 使用状态（上架/下架）；无审核流、无外部系统推送、无单据下推 |
| 关键唯一键 | 产品编码（唯一）；产品 + 版本号为版本维唯一键 |
| 历史兼容 | 历史版本只读，不可删除、不可原地修改（对齐方案 §4.9 不可变对象） |

### 1.4 关键数据约束

| 约束ID | 约束 | 影响对象 |
| :--- | :--- | :--- |
| D01 | 产品编码唯一（【待确认】全租户唯一） | 主表 |
| D02 | 「产品 + 版本号」组合唯一，产品下版本号不得重复 | 主表 |
| D03 | 产品分类只能引用「启用」状态的分类 | 主表 |
| D04 | 「单位」引用计量单位库，须为可用于产品计量的单位（数量类 / 重量类 / 体积类，对齐计量单位库 B6）；**合并承载原「计量单位」与「功能单位」口径**，本期不单列功能单位 / 声明单位 | 主表 |
| D05 | 组合完整性：至少 1 个工艺流程、至少 1 个工序 | 子表 |
| D06 | 工序顺序在同一工艺流程内不得重复且必须连续 | 子表 |
| D07 | 末道工序的产出必须为「成品」 | 子表 |
| D08 | 已被核算项目引用的版本不可编辑、不可删除（对齐 §4.9） | 主表 + 子表 |
| D09 | 存在子表明细的版本不可删除 | 主表 |
| D10 | 产品的当前版本唯一（`是否当前版本` 为一个产品下唯一为真的记录） | 主表 |
| D12 | 本期不单列「声明单位」字段：由「单位」统一承载标准中的功能单位 / 声明单位口径；以声明单位口径出具报告时，报告须附「非完整功能单位评价」的局限性声明 | 主表 |
| D13 | 「所属行业」引用行业库（A1-4），用于匹配行业阶段基线与核算模型；产品必须归属一个行业 | 主表 |

> 编号说明：原 D11「产品净重不得为空或 0」随字段移出本模块一并删除，**编号不再复用**。

### 1.5 已移出 / 已删除 / 已合并的字段（2026-09-20 决策）

| 字段 | 原设计 | 现状 | 理由 |
| :--- | :--- | :--- | :--- |
| 产品净重 / 净重单位 | 主对象必填；缺失触发核算异常 E01（原 D11） | **移出本模块**：改由核算项目 · 产品与边界配置（P19）/ 数据填报（P22）按批次录入实测值 | 净重随批次与含水率波动，属**核算参数**而非产品固有属性；E01 的责任角色本就是「项目负责人」、处理动作为「补**实测**净重并核验」，落在核算侧 |
| 功能单位数量 | 主对象选填（原 Q05） | **删除字段** | 功能单位本身即含数量语义（如「1 双」）；数量恒为 1 时该字段无信息量 |
| 声明单位 | 标准要求「功能单位或声明单位」二者取一 | **本期不单列**，由「单位」统一承载（D12） | 避免与功能单位并列造成「两个字段填一样」的歧义 |
| 「计量单位」+「功能单位」两个字段 | 两个并列字段：计量单位（产品固有）+ 功能单位（选填，留空取计量单位） | **合并为单一「单位」字段**（D04） | 两者长期填同一个值（6 条原型种子数据 100% 相同），并列会形成「两个框填一样」的重复；功能单位口径由「单位」统一承载，无需再拆 |
| 生效日期 | 版本信息字段，选填，默认保存日期（原 Q10） | **删除字段** | 版本化字段已足够精简，生效时点由「版本状态 + 上架 / 下架」表达；单列日期字段缺乏下游消费方 |
