## 1. 拟添加的批注清单

### 1.1 整体流程

#### B02-01 产品建档与维护整体流程
**拟标注位置**：功能标题「产品信息库」附近（全局说明）
**标记**：已确认（无版本化，K-01）

**批注内容**

- **适用场景**：后台维护产品主数据（基本信息 + 工艺 + 工序组合），作为核算项目引用与核算的对象。
- **流程**：进入产品信息库 → 列表（仅核心字段）→ 页头「新增」建档，或点编码 / 名称进入详情 → 在详情 / 列表做编辑、上架、下架 → 保存即生效并刷新列表。
- **分支**：新增走独立新增页（`/basic/product/new`）；编辑走独立编辑页（`/basic/product/:id/edit`）；查看走独立详情页（`/basic/product/:id`）；列表行上 / 下架走二次确认弹窗。
- **衔接**：列表 ↔ 表单 ↔ 详情均为独立页跳转，不在本页弹窗内完成。
- **结束 / 特殊**：原型**不做版本化**——新增保存后产品为「下架」态，编辑保存为**直接覆盖**（无新版本生成），全程无提交 / 审核 / 驳回，也无「新建版本」「删除」入口。

### 1.2 全局规则说明

#### B02-02 全局规则
**拟标注位置**：功能标题「产品信息库」附近（与整体流程同一全局说明入口）
**标记**：已确认（列表范围 / 组合关系 / 版本化按 K-01）＋ 原型已表现·待核对（组合校验口径）

**批注内容**

1. **列表仅展示核心字段**：产品编码 / 产品名称 / 产品分类 / 单位 / 使用状态 / 创建时间 / 更新时间 / 操作；其余字段（规格、批次号、生产地点、生产功能、所属行业、图片、描述、归属组织、工艺工序、版本等）一律进详情页查看，避免列过多横向滚动。
2. **组合关系**：产品 = 基本信息 + 工艺 + 工序的组合；工艺与工序引用「工艺流程库（已发布）」「工序管理」并复制为产品内副本。
3. **组合规则**：① 工艺流程为**选填**（可不关联）；② 已关联时**同一生命周期阶段仅允许一个工艺流程**（C9，原型已实现校验）；③ 末道工序产出须为「成品」、工序链须首尾相接（C5 / C6）——原型仅在提示文案中声明，**提交时未实际阻断**（见 B02-11）。
4. **引用关系（上游）**：产品分类引用启用中的分类（R-003）；单位引用计量单位库（D04，合并承载原「计量单位 + 功能单位」）；所属行业引用行业库（D13）；工艺 / 工序引用已发布工艺流程与工序副本（C3 / C3b）。
5. **不做版本化（K-01 已确认）**：PRD 原本将版本化作为核心（版本号 V1.0/V1.1/V2.0、版本状态、新建版本、引用锁定、删除草稿、快照引用 R-002/R-007~R-015）；经裁决，**以原型为准——产品级、不做版本化**：无版本号、无版本状态、无「新建版本」、无引用锁定、无删除草稿；新增保存为下架态、编辑保存直接覆盖。B02-16（新建版本）、B02-27/28（版本信息块 / 引用数）相应不再保留。
6. **无流程节点**：没有提交、审核、驳回；编辑直接覆盖（原型口径）或仅草稿可编辑（PRD 口径，待裁决）；不提供操作日志外的版本化历史。

### 1.3 业务状态说明

#### B02-03 使用状态（上架 / 下架，产品级）
**拟标注位置**：清单「使用状态」列旁（确认弹窗内相应引用）
**标记**：已确认（K-01：产品级上架 / 下架，不做版本化）

**批注内容**

- **含义**：上架 = 可被新的核算项目选择；下架 = 不可被新项目选择。原型仅此两态（产品级），**不展示版本状态、不展示引用状态**。
- **进入条件**：新增保存后默认「下架」；「上架」由下架态经行操作「上架」进入；「下架」由上架态经行操作「下架」进入。
- **可进行的操作**：无论上架还是下架，都可读、可编辑（原型允许，不受状态阻断）；上架态多出「下架」、下架态多出「上架」；原型任何状态都不提供删除。
- **状态变化**：上架与下架双向可达、可反复切换；变更只刷新使用状态与最后修改时间。
- **对下游的影响**：下架后新项目不可选该版本 / 产品；已引用该产品的项目、核算结果与报告不受影响，历史引用数据保留。
- **（K-01 已确认）**：上 / 下架为产品级两态，不作用于版本；无「版本状态（草稿 / 已发布 / 已停用）+ 引用状态」维度。

### 1.4 操作功能及对应业务规则

#### B02-04 查询与重置
**拟标注位置**：清单上方查询区
**标记**：已确认（查询项 / 叠加入口）；搜索为模拟

**批注内容**

- **查询项**：① 产品编码——包含关系模糊匹配、忽略大小写；② 产品名称——包含关系模糊匹配；③ 产品分类——级联选择（一级 / 二级 / 三级），选中父级时命中其下**所有子级分类**（allowParent）；④ 使用状态——下拉「上架 / 下架」，不选即为全部。**无「版本」筛选**（原型无版本）。
- **规则**：四个条件同时生效（叠加过滤）；只过滤当前已展示数据；任一条件变化后清单回到第 1 页；「重置」清空全部条件并恢复完整清单。
- **搜索按钮**：点「搜索」仅 `toast('查询完成')`，真实过滤为输入即时生效（与产品分类页同口径，原型模拟行为）。

#### B02-05 列表与操作列
**拟标注位置**：清单表格区域与上方工具条
**标记**：已确认（核心字段口径）；无删除入口见 B02-15

**批注内容**

- **展示内容**：产品编码（链接）、产品名称、产品分类、单位、使用状态、创建时间、更新时间、操作。
- **工具条**：左侧「产品列表」+「共 N 条 · 列表仅展示核心字段，其余字段请进入详情页查看」提示；右侧「导出」按钮（见 B02-09 导出口径）。
- **操作列**：「查看」「编辑」恒显示；「上架」「下架」按当前状态二者只出现其一（下架态显示上架、上架态显示下架）；**不提供删除**。
- **分类禁用标识**：当产品所属分类为「已禁用」时，列表分类列显示「分类名 + 已禁用 Tag」；详情页同口径。
- **分页**：每页 20 条；无「版本号」列（无版本）。

#### B02-06 新增产品
**拟标注位置**：页头「新增」按钮旁、新增页
**标记**：已确认（以原型为准，K-04）

**批注内容**

- **操作目的**：建立一个新产品主数据。
- **入口**：列表页头「新增」→ 独立新增页。
- **过程**：填写基本信息（产品编码* / 产品名称* / 产品分类* / 单位* / 所属行业* + 规格 / 产品批次号 / 生产地点 / 生产功能 / 产品图片 / 产品描述，选填）+ 维护工艺与工序组合（选填）。
- **结果**：保存成功后产品为**下架**态，提示「保存成功」，跳转到详情页；分类树与清单刷新。
- **校验**：编码 / 名称 / 分类 / 单位 / 行业必填；同一生命周期阶段仅允许一个工艺流程（见 B02-11）。
- **取消或失败**：点「取消」返回列表，不保存；校验不通过保留已填内容并给出提示。

#### B02-07 编辑产品
**拟标注位置**：清单操作列「编辑」、详情页头「编辑」
**标记**：已确认（K-01：无版本，编辑直接覆盖）

**批注内容**

- **操作目的**：修改产品信息。
- **可操作条件**：原型允许任何状态编辑（不受使用状态或引用状态阻断）。
- **过程**：打开独立编辑页，带出全部字段，与新增共用同一表单。
- **结果**：保存后**直接覆盖**原记录（编辑页注释明示「产品不版本化，保存后直接覆盖」），提示「保存成功」，跳详情页。
- **（K-01 已确认）**：无版本概念，编辑一律直接覆盖，不生成新版本；PRD「仅草稿可编辑 / 已发布须新建版本 / 被引用不可编辑」均不再适用。

#### B02-08 上架 / 下架 + 确认弹窗
**拟标注位置**：清单操作列「上架 / 下架」、详情页头「上架 / 下架」、确认弹窗
**标记**：已确认（产品级，K-01）

**批注内容**

- **操作目的**：控制产品能否被新核算项目选择。
- **入口**：列表行「上架 / 下架」或详情页头对应按钮。
- **确认弹窗**：标题「确认上架」/「确认下架」；正文「确认将产品『产品名称』（产品编码）上架 / 下架？」；提示——上架：「上架后该产品可被新的核算项目选择。」；下架：「下架后新项目不可选择该产品；已引用该产品的项目、核算结果与报告不受影响。」；底栏「取消」+「确认上架」/「确认下架」（不使用「确定」字样）。
- **结果**：确认后状态变更，提示「上架成功 / 下架成功」，列表与详情刷新。
- **层级**：**产品级**（弹窗代码注释明示「不再作用于版本」）。与 PRD 推荐版本级（R-009）冲突，待 K-01 裁决。

#### B02-09 查看产品详情
**拟标注位置**：清单编码 / 名称链接、详情页
**标记**：已确认（详情结构）；无版本信息块 / 无引用数见 B02-27、B02-28

**批注内容**

- **操作目的**：只读核对产品完整定义与历史变更。
- **入口**：列表编码 / 名称链接，或详情页头。
- **展示**：基本信息（约 16 项）+ 产品工艺与工序（画布 / 列表切换）+ 操作日志（可折叠，5/页）。
- **工艺工序列表**：列 = 工序 / 工序类型 / 投入项 / 产出项 / 计算公式，**不含数量**；但「查看工序」弹窗**含数量列**——原型的列表与弹窗口径不一致（见 §4.2 D-04）。
- **结果**：页头 / 底栏有「返回列表」「上架 / 下架」「编辑」；只读，不能直接修改。
- **缺失**：详情**无版本信息块**（版本号 / 版本状态 / 是否当前版本 / 变更说明）、**无「引用核算项目数 / 版本数量」**（见 B02-27、B02-28）。

#### B02-10 工艺与工序组合维护（画布 / 列表 / 全屏 / 查看工序）
**拟标注位置**：新增 / 编辑页「工艺与工序组合」区块、详情页「产品工艺与工序」区块
**标记**：已确认

**批注内容**

- **操作目的**：把工艺流程与工序关联到产品，形成核算用的工艺 / 工序组合。
- **入口**：新增 / 编辑页「+ 添加工艺流程」；选中工艺流程后自动带出工序。
- **画布模式**：工艺流程块内工序节点按序连接；节点可点选（选中）/ 双击（查看工序详情）；可「+ 添加工序」「删除工艺」「删除工序」；支持「全屏」。
- **列表模式**：列 = 工序 / 工序类型 / 投入项 / 产出项 / 计算公式（不展示数量）；行内「删除」。
- **查看工序**：选中节点后「查看工序」打开弹窗，展示投入 / 产出与计算公式（含数量列）。
- **规则**：工艺流程为选填；同阶段仅一工艺流程；工序顺序连续（见 B02-11）。

#### B02-11 组合校验
**拟标注位置**：新增 / 编辑页「工艺与工序组合」区块提示与保存逻辑
**标记**：原型已表现·待核对（校验口径与 PRD 不一致，需裁决）

**批注内容**

- **已实现**：同一生命周期阶段仅允许一个工艺流程——选第二份同阶段工艺时阻断并 `toast` 提示（含阶段名与已绑定工艺名）。
- **声明但未实现**：表单提示文案声明「每个工艺流程至少 1 道工序、末道工序产出必须为『成品』、首尾相接、同一生命周期阶段只允许一个工艺流程」，但**提交时未实际校验**「末道产出为成品」「首尾相接」；其余必填通过即保存成功。
- **与 PRD 冲突**：原型允许「工艺流程为选填，可不关联」，而 PRD C1 要求「至少 1 个工艺流程、每个至少 1 道工序」。
- **跨模块不一致**：本模块「末道产出须为成品」提示为阻断级，而工艺流程库（B03-07）同类校验为提示级不阻断——需统一口径（见 §4.2 D-02）。
- **结论**：组合校验的「实际执行口径」需你裁决（提示级 or 阻断级、工艺是否必填）。

#### B02-12 工序副本机制（复制 / 来源模板标识 / 产品自建 / 公式清空）
**拟标注位置**：新增 / 编辑页工序节点、详情工序列表
**标记**：原型已表现·待核对（公式清空与 PRD 冲突；产品自建标注口径待确认）

**批注内容**

- **复制为副本**：选择工艺流程后，工序随带出并**复制为产品版本自己的副本**，保留来源模板标识（`sourceCode` + `sourceCopiedAt` 写死 `'2026-09-20 10:00'`）、`sourceUpdated=false`、`origin='template'`（C3 / C3b）。
- **产品自建**：通过「+ 添加工序」新增的行可标注「产品自建」（`origin='custom'`，节点显示「产品自建」Tag），用于区分模板副本行（Q18 待确认）。
- **公式随副本**：复制时**清空公式字段**（`formulaId/Code/Name/Expression=''`，仅保留 `disposal='formula'`），与 PRD V0.4「公式随工序默认带出、可手工覆盖」冲突（见 §4.2 D-05）。
- **投入产出流**：副本可在产品版本内修改；基础库模板变更不回写副本，仅展示「来源模板已更新」标记（C3b / C7）。
- **增删**：允许删除工序；新增行允许（须标注「产品自建」），与模板行区分（Q18 待确认）。

#### B02-13 保存与取消
**拟标注位置**：新增 / 编辑页底栏「保存」「取消」
**标记**：已确认（交互）

**批注内容**
