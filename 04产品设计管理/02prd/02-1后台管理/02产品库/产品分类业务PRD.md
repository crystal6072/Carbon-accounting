## 1. 需求概述

### 1.1 需求背景

产品分类是产品信息库建档时的分类依据，也是核算项目选择产品、按分类检索与统计的维度。分类树在产品分类、产品信息库之间形成「分类 → 产品」的引用关系，是后台基础库中产品库主体数据的前置基础。

本模块为轻量配置模块：以**左树 + 右表 + 弹窗**维护多级分类，不涉及审核流、外部系统同步与单据下推。

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :--- | :--- | :--- |
| G1 | 支持多级产品分类树的维护 | 可新增、编辑一/二/三级分类，层级由上级自动带出 |
| G2 | 分类编码唯一且稳定 | 编码在约束范围内不可重复；被产品引用后编码只读 |
| G3 | 分类可停用但不破坏历史数据 | 禁用后不可被新产品选用，已引用产品的分类关系与核算不受影响 |
| G4 | 提供按分类的产品检索维度 | 产品信息库可按分类筛选产品 |
| G5 | 数据可导出留存 | 支持按当前查询结果导出分类数据 |

### 1.3 In Scope / Out of Scope

**In Scope**

| 能力 | 说明 |
| :--- | :--- |
| 分类树浏览 | 左树展示多级分类，支持展开/折叠与选中联动 |
| 分类列表 | 右表展示当前树节点范围内的分类记录 |
| 查询 | 按分类编码、名称、使用状态筛选 |
| 新增 / 编辑 | 弹窗维护分类基本信息 |
| 查看 | 弹窗查看分类详情 |
| 启用 / 禁用 | 行操作 + 二次确认 |
| 排序 | 维护同级展示顺序 |
| 导出 | 导出当前查询结果 |

**Out of Scope**

| 不做项 | 说明 |
| :--- | :--- |
| 审核流 | 无提交、审核、驳回，无单据状态机 |
| 操作日志 | 轻量配置不提供操作日志入口 |
| 物理删除 | V0.1 不开放删除，统一用「禁用」替代（【待确认 Q10】） |
| 导入 | V0.1 不支持 Excel 导入（【待确认】） |
| 移动分类（改上级） | V0.1 不支持（【待确认 Q11】） |
| 分类层级配置页 | 层级上限为系统配置，不提供用户配置界面 |
| 跨组织分类共享 / 多级继承 | 见方案 §3.5 本期不做 |

### 1.4 涉及角色

| 角色 | 数据域 | 在本模块的职责 |
| :--- | :--- | :--- |
| 平台运营管理员 | 平台域 | 维护平台级产品分类 |

| 核算人员 / 填报人 / 审核员 | `CURRENT` / `SELF` / `SUB_TREE` | 只读引用 |

> 权限判定的具体落地以方案 §3.3 与 §7.2 为准，本文不重复定义。

## 2. 用户与使用场景

### S01 维护一级分类

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要新增一个顶级分类 |
| 操作流程 | 进入产品分类 → 点击页头「新增」或树顶「新增一级分类」 → 在弹窗填写分类名称、编码等 → 保存 |
| 预期结果 | 一级分类创建成功，上级分类为空、分类层级为一级、使用状态默认启用；左树与右表刷新 |

### S02 在选中上级节点下维护下级分类

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要在某分类下建立子分类 |
| 操作流程 | 在左树选中目标节点 → 点「新增下级」 → 弹窗中上级分类默认带出且只读 → 填写其余字段 → 保存 |
| 预期结果 | 子分类创建成功，层级 = 上级层级 + 1；若已达层级上限则**不展示**「新增下级」入口 |

### S03 启用 / 禁用分类

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 某分类不再适用于新业务，但历史数据仍需保留 |
| 操作流程 | 在列表行操作点「禁用」 → 二次确认 → 确认 |
| 预期结果 | 分类变为禁用；产品信息库新建产品时不再可选；已引用该分类的产品展示与核算不受影响 |
| 例外 | 该分类存在启用中的下级分类时，是否允许禁用见 R-008（【待确认】） |

### S04 调整同级排序

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要调整同级分类的展示顺序 |
| 操作流程 | 编辑分类 → 修改排序号 → 保存 |
| 预期结果 | 左树与右表按排序号升序展示（R-009） |

### S05 导出分类数据

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要将分类清单用于线下核对或迁移 |
| 操作流程 | 设置查询条件 → 点列表工具条「导出」 |
| 预期结果 | 按当前查询结果导出（【待确认 Q13】） |

### S06 被产品引用后的编辑与禁用限制

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 某分类已被产品信息库的产品引用 |
| 操作流程 | 尝试编辑或禁用该分类 |
| 预期结果 | 分类编码只读（R-006）；禁用被阻止并给出提示（R-007）；无「删除」入口（V0.1 不开放） |

## 4. 分类树结构规则

| # | 规则 |
| :--- | :--- |
| T1 | 分类为树形结构，一级分类的「上级分类」为空 |
| T2 | **层级上限【待确认 Q01，建议 3 级】**；达到上限的分类不再提供「新增下级」入口 |
| T3 | **不允许跳级创建**：任意分类的层级恒等于「上级分类层级 + 1」（【待确认 Q01】） |
| T4 | 「上级分类」只能从**已存在且未禁用**的分类中选择；不得选择自身或自身的下级，禁止形成环（D02） |
| T5 | 同级下分类名称不得重复（【待确认 Q06】） |
| T6 | 存在下级分类的分类**不可删除**（D06）；V0.1 不开放删除 |
| T7 | 分类编码在约束范围内唯一（【待确认 Q03】） |
| T8 | 左树选中节点后，右表范围口径：选中「全部」→ 展示全部分类；选中某节点 → 展示范围【待确认 Q14，见 §8】 |

## 5. 业务规则

| 规则编号 | 规则名称 | 触发条件 | 处理逻辑 | 例外策略 |
| :--- | :--- | :--- | :--- | :--- |
| R-001 | 分类编码生成 | 新增分类保存时 | 编码按既定方式生成或校验唯一性（【待确认 Q02】）；保存后进行唯一性校验（【待确认 Q03：全租户 / 同级】） | 编码重复时阻断保存并提示 |
| R-002 | 同级名称唯一 | 新增或编辑分类保存时 | 同一上级分类下名称不得与已有分类重复（【待确认 Q06】） | 重复时阻断保存并提示 |
| R-003 | 层级自动带出 | 选择/带出上级分类时 | 分类层级 = 上级分类层级 + 1；未选择上级时层级 = 1 | 层级超上限时阻断（T2） |
| R-004 | 禁止跳级 | 新增分类时 | 只能从选中节点向下创建，不允许跨级指定上级 | 无例外 |
| R-005 | 环校验 | 编辑分类的上级分类时 | 上级分类不得为自身或其下级 | 命中时阻断保存 |
| R-006 | 被引用后编码锁定 | 分类已被产品引用 | 分类编码转为只读；分类名称与描述是否可改见【待确认 Q08】 | 前端不提供编辑入口，接口兜底拦截 |
| R-007 | 被引用后不可禁用 | 分类已被产品引用 | 禁用操作被阻断；已引用产品的分类关系与核算结果不受影响 | 命中时提示引用产品数量 |
| R-008 | 父分类禁用的级联处理 | 禁用存在启用下级的分类 | 【待确认 Q09，建议阻止禁用】 | 命中时提示先处理下级分类 |
| R-009 | 同级排序 | 列表与左树渲染时 | 同级内按「排序号升序 → 创建时间升序」展示 | 排序号为空时按 0 处理 |
| R-010 | 默认启用 | 新增分类保存时 | 使用状态默认「启用」 | 无例外 |
| R-011 | 不提供物理删除 | 全生命周期 | V0.1 不展示删除入口，停用统一用「禁用」（【待确认 Q10】） | 无例外 |
| R-012 | 禁用后的引用影响 | 分类被禁用后 | 产品信息库新建产品时该分类不可选；已引用产品不受影响，历史引用保留 | 无例外 |

> 说明：状态枚举（启用/禁用 或 上架/下架）以字段清单为准，本文统一按「启用 / 禁用」表述，最终命名见字段清单【待确认 Q04】。

## 6. 状态与操作矩阵

> 状态枚举最终以字段清单为准（【待确认 Q04】）。本表按「启用 / 禁用」表述。

| 当前状态 | 编辑 | 启用 | 禁用 | 删除 | 新增下级 | 被新业务选用 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| 启用 | 是（分类编码按引用情况锁定，见 R-006） | — | 是（被产品引用时阻断，见 R-007） | 否（V0.1 不开放） | 是（未达层级上限时） | 是 |
| 禁用 | 是（同上） | 是 | — | 否 | 【待确认 Q09】 | 否（R-012） |

**闭环校验**

- 无终态死状态：启用 ↔ 禁用双向可达；
- 无删除态：V0.1 不存在删除分支（R-011）；
- 无审核分支：本模块不涉及提交 / 审核 / 驳回。

## 7. 上下游与引用关系

| 方向 | 关联模块 | 引用字段 | 联动规则 |
| :--- | :--- | :--- | :--- |
| 上游 | 组织架构 | 归属组织 | 分类数据归属组织，参与数据可见范围过滤（方案 §3.4） |

| 下游 | 核算项目 · 产品与边界配置（P19） | 产品（间接引用分类） | 项目选产品时可按分类筛选；分类变更不影响已生成的项目快照 |
