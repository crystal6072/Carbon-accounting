## 1. 需求概述

### 1.1 需求背景

产品分类是产品信息库建档时的分类依据，也是核算项目选择产品、按分类检索与统计的维度。分类树在产品分类、产品信息库之间形成「分类 → 产品」的引用关系，是后台基础库中产品库主体数据的前置基础。

本模块为轻量配置模块：以**左树 + 右表 + 弹窗**维护多级分类，不涉及审核流、外部系统同步与单据下推。V0.1 首次进入内置**国家统计局《统计用产品分类目录》**的 1~3 级分类作为初始数据。

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :--- | :--- | :--- |
| G1 | 支持多级产品分类树的维护 | 可新增、编辑一/二/三级分类，层级由上级自动带出、最高 3 级 |
| G2 | 分类编码唯一且稳定 | 编码全库唯一，新增 / 编辑保存时校验，重复即阻断 |
| G3 | 分类可停用但不破坏历史数据 | 禁用后不可被新产品选用，已引用产品的分类关系与核算不受影响 |
| G4 | 提供按分类的产品检索维度 | 产品信息库可按分类筛选产品 |
| G5 | 数据可导出留存 | 支持按当前查询结果导出分类数据 |

### 1.3 In Scope / Out of Scope

**In Scope**

| 能力 | 说明 |
| :--- | :--- |
| 分类树浏览 | 左树展示多级分类（默认全部展开），节点展示直接下级数量，支持展开/折叠与选中联动 |
| 分类列表 | 右表展示**当前树选中节点的直接子级** |
| 查询 | 按分类编码（模糊）、分类名称（模糊）、使用状态（精确）筛选 |
| 新增 / 编辑 | 弹窗维护分类基本信息（含修改上级 = 移动分类） |
| 查看 | 弹窗查看分类详情 |
| 启用 / 禁用 | 列表行操作 + 二次确认弹窗 |
| 排序 | 同级按「排序号升序」展示（空值排末尾） |
| 导出 | 导出当前查询结果 |

**Out of Scope**

| 不做项 | 说明 |
| :--- | :--- |
| 审核流 | 无提交、审核、驳回，无单据状态机 |
| 操作日志 | 轻量配置不提供操作日志入口 |
| 物理删除 | V0.1 不开放删除，统一用「禁用」替代 |
| 导入 | V0.1 不支持 Excel 导入 |
| 分类层级配置页 | 层级上限固定 3 级，不提供用户配置界面 |
| 跨组织分类共享 / 多级继承 | 见方案 §3.5 本期不做 |
| 归属组织 / 可见性维护 | V0.1 原型未纳入该两字段（见 §8 Q07） |

## 2. 用户与使用场景

### S01 维护一级分类

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要新增一个顶级分类 |
| 操作流程 | 进入产品分类 → 点击页头「新增」或左树底部「新增一级分类」 → 弹窗中「上级分类」锁定为「无上级（一级分类）」 → 填写编码、名称等 → 保存 |
| 预期结果 | 一级分类创建成功，上级为空、层级为一级、使用状态默认启用；左树与右表刷新 |

### S02 在选中上级节点下维护下级分类

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要在某分类下建立子分类 |
| 操作流程 | 在左树选中目标节点 → 点「新增下级分类」 → 弹窗中上级分类默认带出且只读 → 填写其余字段 → 保存 |
| 预期结果 | 子分类创建成功，层级 = 上级层级 + 1；若已达 3 级上限则**不展示**「新增下级分类」入口 |

### S03 启用 / 禁用分类

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 某分类不再适用于新业务，但历史数据仍需保留 |
| 操作流程 | 在列表「操作」列点「禁用」 → 二次确认弹窗 → 「确认禁用」 |
| 预期结果 | 分类变为禁用；产品信息库新建产品时不再可选；已引用该分类的产品展示与核算不受影响 |
| 例外 | 该分类存在启用中的下级分类时，是否允许禁用见 R-008 / §8 Q09（原型暂未拦截） |

### S04 调整同级排序

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要调整同级分类的展示顺序 |
| 操作流程 | 编辑分类 → 修改排序号 → 保存 |
| 预期结果 | 左树与右表按排序号升序展示，空值排末尾（R-009） |

### S05 导出分类数据

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要将分类清单用于线下核对或迁移 |
| 操作流程 | 设置查询条件 → 点列表工具条「导出」 |
| 预期结果 | 按当前查询结果导出（R-013） |

### S06 移动分类（修改上级）

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要把某分类调整到另一上级之下 |
| 操作流程 | 编辑分类 → 在「上级分类」下拉中选择目标上级 → 保存 |
| 预期结果 | 分类层级随之重算为「新上级层级 + 1」；下拉中不出现自身与其全部下级（禁止成环） |

### S07 被产品引用后的编辑与禁用限制（业务约定，待落地）

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 某分类已被产品信息库的产品引用 |
| 操作流程 | 尝试编辑或禁用该分类 |
| 预期结果 | 按业务约定：编码只读（R-006）、禁用被阻止（R-007）、无「删除」入口（V0.1 不开放） |
| 现状 | **原型 V0.1 尚未实现引用锁定与禁用拦截**，仅约定；确认前不作为既定事实（见 §8 Q08 / Q09） |

## 4. 分类树结构规则

| # | 规则 |
| :--- | :--- |
| T1 | 分类为树形结构，一级分类的「上级分类」为空 |
| T2 | **层级上限为 3 级**；达到上限的分类不再提供「新增下级分类」入口 |
| T3 | **不允许跳级创建**：任意分类的层级恒等于「上级分类层级 + 1」（无上级则为 1） |
| T4 | 「上级分类」只能从**已存在且未禁用**的分类中选择；不得选择自身或自身的下级，禁止形成环（D02） |
| T5 | 同级下分类名称是否唯一**原型未校验**（见 §8 Q06） |
| T6 | 存在下级分类的分类**不可删除**（D06）；V0.1 不开放删除 |
| T7 | 分类编码**全库唯一**（新增 / 编辑保存时校验） |
| T8 | 左树选中节点后，右表范围口径：选中「全部分类」→ 展示全部分类（一级）；选中某节点 → 展示其**直接子级** |
| T9 | 左树默认全部展开；节点右侧展示**直接下级数量** |

## 5. 业务规则

| 规则编号 | 规则名称 | 触发条件 | 处理逻辑 | 例外策略 |
| :--- | :--- | :--- | :--- | :--- |
| R-001 | 分类编码唯一性 | 新增 / 编辑分类保存时 | 全库范围校验编码唯一（D01） | 重复时阻断保存并提示「分类编码已存在，请修改后重试」 |
| R-002 | 编码必填 | 新增 / 编辑分类保存时 | 分类编码非空 | 为空时字段级提示「请输入分类编码」 |
| R-003 | 名称必填 | 新增 / 编辑分类保存时 | 分类名称非空 | 为空时字段级提示「请输入分类名称」 |
| R-004 | 层级自动带出 | 选择 / 带出上级分类时 | 分类层级 = 上级分类层级 + 1；未选择上级时层级 = 1 | 层级上限 3，超限不可新增下级（T2） |
| R-005 | 禁止跳级 | 新增分类时 | 只能从选中节点向下创建，不允许跨级指定上级 | 无例外 |
| R-006 | 环校验 | 编辑分类的上级分类时 | 上级可选范围排除自身及其全部下级 | 命中范围外的分类不出现在下拉中 |
| R-007 | 被引用后编码锁定 | 分类已被产品引用 | 编码转只读（业务约定） | **原型 V0.1 未实现**，见 §8 Q08 |
| R-008 | 被引用 / 有下级时不可禁用 | 分类已被产品引用或存在启用下级 | 禁用操作被阻断（业务约定） | **原型 V0.1 未实现**，见 §8 Q09 |
| R-009 | 同级排序 | 列表与左树渲染时 | 同级内按「排序号升序」展示，`null` 视为最大值排末尾 | 排序号为空时排到同级最后 |
| R-010 | 默认启用 | 新增分类保存时 | 使用状态默认「启用」 | 无例外 |
| R-011 | 不提供物理删除 | 全生命周期 | V0.1 不展示删除入口，停用统一用「禁用」 | 无例外 |
| R-012 | 禁用后的引用影响 | 分类被禁用后 | 产品信息库新建产品时该分类不可选；已引用产品不受影响，历史引用保留 | 无例外 |
| R-013 | 导出范围 | 点「导出」时 | 导出当前查询结果 | 无例外 |
| R-014 | 树表联动 | 左树选中节点时 | 右表展示该节点的直接子级 | 无例外 |

> 说明：状态枚举以字段清单为准（启用 / 禁用）。R-007 / R-008 为业务约定，**原型尚未落地**，确认前不得作为既定事实进入 Demo PRD。

## 6. 状态与操作矩阵

> 状态枚举以字段清单为准：「启用 / 禁用」。使用状态**不在表单内维护**，通过列表行操作变更。

| 当前状态 | 查看 | 编辑 | 启用 | 禁用 | 删除 | 新增下级 | 修改上级 | 被新业务选用 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 启用 | 是 | 是 | — | 是 | 否（V0.1 不开放） | 是（未达 3 级上限时） | 是 | 是 |
| 禁用 | 是 | 是 | 是 | — | 否 | 是（未达 3 级上限时） | 是 | 否（R-012） |

**闭环校验**

- 无终态死状态：启用 ↔ 禁用双向可达；
- 无删除态：V0.1 不存在删除分支（R-011）；
- 无审核分支：本模块不涉及提交 / 审核 / 驳回。

## 7. 上下游与引用关系
