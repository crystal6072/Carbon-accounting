# 产品分类字段清单

> **文档定位**：产品分类字段定义的唯一真相源（SST）。业务 PRD 和 Demo PRD 只引用字段名称，不重复维护枚举、必填性和字段口径。
> **适用类型**：轻量配置模块（多级分类树 + 列表 + 弹窗）
> **维护形态**：轻量配置（工作台 + 弹窗）；查看 = 查看弹窗，新增/编辑 = 弹窗可编辑。**无独立详情页、无独立新增/编辑页、无操作日志**
> **成熟度**：粗纲
> **版本**：V0.1
> **更新时间**：2026-09-20

## 1. 模块与数据边界

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 产品分类 |
| 业务归属 | 后台管理 → 基础库 → 产品库 → 产品分类（方案 §2.3 A1-5、§八 P07） |
| 模块类型 | 轻量配置 |
| 维护形态 | 工作台 + 弹窗（左树右表；查看 = 弹窗，`查看=弹窗`） |
| 核心用途 | 维护多级产品分类树，作为产品信息库建档时的分类依据，并提供按分类检索产品的维度 |

### 1.2 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | 人工维护 |
| ERP是否数据源 | 否 |
| 外部系统 | `-` |
| 同步方式 | 不适用 |
| 新增编辑 | 支持（弹窗） |
| 启用禁用 | 支持 |
| 导入导出 | 导出：支持（【待确认】导出范围与字段）；导入：V0.1 不支持（【待确认】） |
| 子表/明细 | 无 |
| 唯一键 | 分类编码（【待确认】全租户唯一 or 同级唯一） |

### 1.3 关键约束

| 约束ID | 约束 | 影响字段/记录 |
| :--- | :--- | :--- |
| D01 | 分类编码唯一（【待确认】全租户唯一 or 同级唯一） | 分类编码 |
| D02 | 上级分类必须为已存在的分类，且不得构成环（不能把自己或自己的下级设为上级） | 上级分类 |
| D03 | 分类层级深度上限【待确认，建议 3 级】 | 上级分类 / 分类层级 |
| D04 | 同级下分类名称不得重复【待确认】 | 分类名称 |
| D05 | 已被产品引用的分类：编码只读、不可禁用、不可删除 | 分类编码 / 使用状态 |
| D06 | 存在下级分类时不可删除（V0.1 是否开放物理删除【待确认】） | 上级分类 |
| D07 | 已禁用的分类不可被产品信息库新选用，历史引用保留 | 使用状态 |
| D08 | 归属组织在新增保存后不可修改【待确认】 | 归属组织 |

## 7. 待确认事项

| 编号 | 问题 | 影响字段/记录 | 当前建议 | 状态 |
| :--- | :--- | :--- | :--- | :--- |
| Q01 | 分类层级上限是几级？是否允许跳级创建（如直接在根下建三级）？ | 上级分类、分类层级 | 建议 3 级，禁止跳级，层级由上级自动带出 | 待确认 |
| Q02 | 分类编码的生成方式：手工填写 / 系统按「前缀+序号」生成？是否可修改？ | 分类编码 | 建议系统生成、不可改，避免引用后编码漂移 | 待确认 |
| Q03 | 编码唯一范围：全租户唯一 还是 同级唯一？ | 分类编码 | 建议全租户唯一，便于下游按编码引用 | 待确认 |
| Q04 | 使用状态的枚举用「启用/禁用」还是「上架/下架」？ | 使用状态 | 方案 §2.3 A1-6 对产品用「上架」，分类建议沿用「启用/禁用」 | 待确认 |
| Q05 | 排序号：取值范围、默认值、同级是否允许重复？ | 排序号 | 建议 1～999 整数，默认同级最大值 +10，允许重复（重复时按创建时间兜底） | 待确认 |
| Q06 | 分类名称是否要求同级唯一？ | 分类名称 | 建议同级唯一，避免下游选择器歧义 | 待确认 |
| Q07 | 是否需要「归属组织」与「可见性（`ORG` / `PUBLIC`）」字段？ | 归属组织、可见性 | 方案 §3.3.3 将分类归为「组织自建（`ORG`）」，建议保留归属组织，可见性本期可不开放编辑 | 待确认 |
| Q08 | 被产品引用后，除编码外还有哪些字段转为只读？分类名称可否继续修改？ | 分类编码 / 分类名称 | 建议仅「分类编码」锁定，名称与描述可改 | 待确认 |
| Q09 | 父分类被禁用时，其下级分类如何处理？ | 使用状态 | 建议阻止禁用（须先处理下级），避免出现「子可用、父不可用」的悬空状态 | 待确认 |
| Q10 | V0.1 是否开放物理删除？ | 上级分类 | 建议不开放，统一用「禁用」替代 | 待确认 |
| Q11 | 是否支持移动分类（修改上级分类）？ | 上级分类 | 建议 V0.1 不支持，减少环校验与下游快照失效风险 | 待确认 |
| Q12 | 是否需要在列表/查看弹窗展示「引用产品数」「下级分类数」？ | 只读明细字段 | 建议至少展示引用产品数，用于演示引用锁定 | 待确认 |
| Q13 | 导出范围：当前查询结果 / 当前树节点及其下级 / 全部分类？ | 可导出 | 建议导出当前查询结果 | 待确认 |
