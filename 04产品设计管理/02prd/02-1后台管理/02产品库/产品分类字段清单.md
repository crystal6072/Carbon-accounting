## 1. 模块与数据边界

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 产品分类 |
| 业务归属 | 后台管理 → 基础库 → 产品库 → 产品分类（方案 §2.3 A1-5、§八 P07） |
| 模块类型 | 轻量配置 |
| 维护形态 | 工作台（左树 + 右表）+ 弹窗；查看 = 弹窗（`查看=弹窗`） |
| 核心用途 | 维护多级产品分类树，作为产品信息库建档时的分类依据，并提供按分类检索产品的维度 |
| 核心对象 | 产品分类（自引用树，最多三级） |

### 1.2 数据来源与维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | 人工维护；**首次进入内置国家统计局《统计用产品分类目录》1~3 级分类**作为初始数据 |
| ERP是否数据源 | 否 |
| 外部系统 | `-` |
| 同步方式 | 不适用 |
| 新增编辑 | 支持（弹窗） |
| 启用禁用 | 支持（列表行操作 + 二次确认弹窗） |
| 排序 | 支持（同级按「排序号」升序，空值排末尾） |
| 导入导出 | 导出：支持（当前查询结果）；导入：V0.1 不支持 |
| 移动分类 | 支持（编辑时可修改「上级分类」，见 §3.1 / Q11） |
| 子表/明细 | 无 |
| 唯一键 | 分类编码（**全库唯一**，见 D01） |

### 1.3 关键约束

| 约束ID | 约束 | 影响字段/记录 |
| :--- | :--- | :--- |
| D01 | **分类编码全库唯一**：新增与编辑保存时均校验，重复则阻断并提示「分类编码已存在，请修改后重试」 | 分类编码 |
| D02 | 上级分类必须为已存在的分类，且不得构成环（不能把自己或自己的下级设为上级） | 上级分类 |
| D03 | 分类层级深度上限 **3 级**；层级由上级自动带出，不允许跳级创建 | 上级分类 / 分类层级 |
| D04 | 分类名称、分类编码非空必填 | 分类编码 / 分类名称 |
| D05 | 上级分类只能从**「启用」且层级 < 3** 的分类中选择（禁止选择自身或后代） | 上级分类 |
| D06 | 存在下级分类的分类不可删除；V0.1 不开放物理删除 | 上级分类 |
| D07 | 已禁用的分类不可被产品信息库新选用，历史引用保留 | 使用状态 |
| D08 | （未纳入）归属组织、可见性字段 V0.1 原型未维护，见 §7 Q07 | 归属组织 / 可见性 |

> **原型未实现的约束**（仅业务约定、原型无拦截，见 §7）：被产品引用后编码锁定（Q08）、父分类禁用级联（Q09）、同级名称唯一（Q06）。**在确认前不得作为既定事实**。

## 3. 字段明细

### 3.1 主对象字段

**分类编码 `code`**

| 项 | 说明 |
| :--- | :--- |
| 类型 / 长度 | 字符串；原型未限制长度（建议 ≤32） |
| 必填 | 是 |
| 默认值 | 无（手工填写，占位提示「如 BAM-01」） |
| 取值来源 | 人工输入 |
| 唯一性 | **全库唯一**（D01）：新增 / 编辑保存均做唯一性校验 |
| 校验与提示 | 为空 → 「请输入分类编码」；重复 → 「分类编码已存在，请修改后重试」 |
| 编辑性 | 编辑弹窗内可修改（**原型未实现「被产品引用后锁定」**，见 Q08） |

**分类名称 `name`**

| 项 | 说明 |
| :--- | :--- |
| 类型 / 长度 | 字符串；原型未限制长度 |
| 必填 | 是 |
| 默认值 | 无（占位提示「请输入分类名称」） |
| 校验与提示 | 为空 → 「请输入分类名称」 |
| 查询 | 模糊匹配（包含） |
| 唯一性 | 同级下是否唯一**原型未校验**（Q06） |

**上级分类 `parentId`**

| 项 | 说明 |
| :--- | :--- |
| 类型 | 引用产品分类自身；`null` 表示一级分类 |
| 必填 | 否（一级分类为空） |
| 取值方式 | 新增一级分类 / 新增下级分类时**由入口带出并锁定**（只读展示）；编辑时可在下拉中选择 |
| 可选范围 | 仅「**启用**」且「**层级 < 3**」的分类；排除自身及其全部下级（禁止成环） |
| 展示口径 | 表单下拉选项文案为「缩进 + 名称（编码）」；一级分类的显式选项文案为「无上级（一级分类）」；锁定时一级分类显示「无上级（一级分类）」，否则显示所选上级名称 |
| 联动 | 变更上级会重算「分类层级」= 上级层级 + 1（上限 3） |

**分类层级 `level`**

| 项 | 说明 |
| :--- | :--- |
| 类型 | 枚举 `1` / `2` / `3` |
| 取值 | 系统带出，只读展示；无上级 = 1，否则 = 上级层级 + 1 |
| 展示文案 | `1` → 一级分类，`2` → 二级分类，`3` → 三级分类 |
| 上限 | 3 级（D03）；达上限的分类不提供「新增下级分类」入口 |

**排序号 `sortNo`**

| 项 | 说明 |
| :--- | :--- |
| 类型 | 整数（非负），可空 |
| 必填 | 否 |
| 默认值 | 空 |
| 输入约束 | 仅允许数字字符（输入时过滤非数字）；占位提示「越小越靠前，可留空」 |
| 排序口径 | 同级按「排序号升序」展示，`null` 视为最大值（排在同级末尾） |

**使用状态 `status`**

| 项 | 说明 |
| :--- | :--- |
| 类型 | 枚举 `enabled`（启用）/ `disabled`（禁用） |
| 默认值 | 新增保存时默认「启用」 |
| 维护方式 | **不在新增/编辑表单内**，通过列表「操作」列的启用 / 禁用链接 + 二次确认弹窗变更 |
| 展示 | 列表与查看弹窗以 Tag 展示（启用 = 成功色，禁用 = 默认色） |
| 联动 | 禁用后不可被产品信息库新产品选用，历史引用保留（D07） |

**备注 `remark`**

| 项 | 说明 |
| :--- | :--- |
| 类型 / 长度 | 长文本（多行）；原型未限制长度 |
| 必填 | 否（占位提示「选填」） |
| 展示 | 查看弹窗展示，空值显示 `-` |

### 3.2 制单信息字段

| 字段名称 | 字段编码 | 生成方式 | 展示位置 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 创建人 | `createdBy` | 系统生成 | 查看弹窗 | 原型固定为「当前用户」 |
| 创建时间 | `createdAt` | 系统生成 | 查看弹窗 | 页面展示置底 |
| 最后修改时间 | `updatedAt` | 系统生成 | 列表 + 查看弹窗 | 列表列名「最后修改时间」 |

> 原型未展示「更新人」；如需可后续补充（见 §7 Q12 关联项）。

## 5. 列表 / 查询 / 表单 / 弹窗口径

### 5.1 左树（分类树）

- 根节点：`全部分类`（虚拟节点，选中表示不限分类）。
- 子节点：按「排序号升序」渲染；有下级的节点右侧展示**直接下级数量**。
- 选中节点驱动右表范围。
- 底部操作：`+ 新增一级分类`（常驻）；选中非根节点时追加 `+ 新增下级分类`（选中层级 = 3 的节点不展示）。

### 5.2 列表列（右表）

按当前树选中节点展示其**直接子级**，列顺序如下：

| 序 | 列名 | 对应字段 | 说明 |
| :---: | :--- | :--- | :--- |
| 1 | 分类编码 | `code` | 可点击链接，点击打开查看弹窗 |
| 2 | 分类名称 | `name` | — |
| 3 | 分类层级 | `level` | 文案展示 |
| 4 | 排序号 | `sortNo` | 空值显示 `-` |
| 5 | 使用状态 | `status` | Tag 展示 |
| 6 | 最后修改时间 | `updatedAt` | — |
| 7 | 操作 | — | 「查看」「编辑」「启用 / 禁用」 |

> 分页：每页 20 条；列表上方展示「当前节点名称 + 共 N 条」，右侧提供「导出」。

### 5.3 查询项

| 查询项 | 对应字段 | 匹配方式 |
| :--- | :--- | :--- |
| 分类编码 | `code` | 模糊匹配（包含，忽略大小写） |
| 分类名称 | `name` | 模糊匹配（包含） |
| 使用状态 | `status` | 精确匹配（下拉：启用 / 禁用 / 全部） |

> 查询项「重置」清空全部条件；「搜索」触发查询（原型为即时过滤）。

### 5.4 新增 / 编辑表单字段

| 字段 | 控件 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| 上级分类 | 下拉选择 / 只读文本 | 否 | 新增下级 / 一级时锁定只读；编辑时可改 |
| 分类编码 | 输入框 | 是 | 占位「如 BAM-01」；全库唯一 |
| 分类名称 | 输入框 | 是 | — |
| 分类层级 | 只读文本 | — | 随上级自动带出 |
| 排序号 | 输入框（数字） | 否 | 占位「越小越靠前，可留空」 |
| 备注 | 多行文本 | 否 `（full 宽）` | 占位「选填」 |

- 弹窗标题：编辑 → 「编辑分类」；新增下级 → 「新增下级分类」；新增一级 → 「新增一级分类」；其余 → 「新增分类」。
- 底栏：`取消` + `保存`。
- **使用状态不在表单内编辑**，统一走行操作。

### 5.5 查看弹窗字段

分类编码、分类名称、上级分类、分类层级、排序号、使用状态、创建人、创建时间、最后修改时间、备注。

- 底栏：`关闭` + `编辑`。

### 5.6 启用 / 禁用二次确认弹窗

- 标题：`确认启用` / `确认禁用`；正文「确认将分类『{名称}』（{编码}）启用/禁用？」。
- 禁用时补充提示：「禁用后，新产品建档时不可再选择该分类；历史引用数据保留不变。」
- 底栏按钮语义化：`确认启用` / `确认禁用`（不使用「确定」）。

## 6. 字段级校验与联动

| 编号 | 触发时机 | 校验 / 联动 | 异常处理 |
| :--- | :--- | :--- | :--- |
| V-01 | 保存新增 / 编辑 | 分类编码非空 | 阻断，字段级提示「请输入分类编码」 |
| V-02 | 保存新增 / 编辑 | 分类名称非空 | 阻断，字段级提示「请输入分类名称」 |
| V-03 | 保存新增 / 编辑 | 分类编码全库唯一 | 阻断，顶部提示「分类编码已存在，请修改后重试」 |
| V-04 | 选择 / 带出上级 | 分类层级 = 上级层级 + 1，上限 3 | 层级达 3 的分类不提供「新增下级」入口 |
| V-05 | 表单渲染 | 上级可选范围 = 启用 且 层级 < 3，且非自身 / 后代 | 不在范围内不出现于下拉 |
| V-06 | 保存新增 | 使用状态默认「启用」 | 无 |
| V-07 | 排序号输入 | 仅允许数字字符 | 非数字字符自动过滤 |
| V-08 | 启用 / 禁用 | 二次确认后变更状态并刷新 | 无 |
