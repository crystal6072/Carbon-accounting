## 1. 拟添加的批注清单

### 1.1 整体流程

#### B15-01 平台账号维护整体流程
**拟标注位置**：功能标题「平台账号」附近（全局说明）
**标记**：已确认

**批注内容**

- **适用场景**：平台管理员在后台维护平台自有账号（平台团队人员），作为平台后台的登录身份与权限载体。
- **流程**：进入平台账号 → 列表展示持有平台角色的账号 → 按需查询、查看核对 → 新建 / 编辑 / 分配平台角色 / 停用 / 启用 / 重置密码 / 注销。
- **入口分布**：列表页可发起全部操作（页头「新建」+ 行内操作列）；详情页同样可发起全部操作（页头按钮区），操作后留在详情或返回列表。
- **交互形态**：新建 / 编辑为**独立表单页**；分配平台角色、停用 / 启用 / 注销为**弹窗 + 二次确认**；重置密码为**弹窗 + 一次性密码展示**；查看为**独立详情页**（列表点姓名进入）。
- **衔接**：列表点「姓名」进入该账号详情；「账号查询」页点「姓名」可下钻对应账号详情（平台账号进可操作详情，租户成员进只读详情）。
- **结束**：全流程没有提交、审核、驳回；账号状态在「启用 / 停用」之间可逆流转，「注销」为终态（执行后账号记录删除，见 B15-12）。
- **超管兜底说明**：全部超管均无法登录时，产品内不设自助找回入口，统一转运维恢复（双人复核 + 复盘 + 审计），本页无可画分支。

### 1.2 全局规则说明

#### B15-02 全局规则
**拟标注位置**：功能标题「平台账号」附近（与整体流程同一全局说明入口）
**标记**：已确认

**批注内容**

1. **账号只有一份**：全系统账号表全局唯一，平台账号与租户成员共用同一账号表，不按域拆表；账号本身不设归属标签。
2. **平台账号的识别口径**：持有**至少 1 个生效平台角色**的账号即为平台账号，出现在本菜单；不持平台角色的账号不在本菜单出现（仅在「账号查询」可见）。识别按角色关联动态判定，不设账号归属字段。
3. **准入口径**：识别为平台账号**且**账号状态为「启用」，才能进入平台后台。
4. **权限来源**：平台账号的权限取自所持平台角色的功能码（多角色取并集）；角色定义与维护在「平台角色管理」，本模块只指派、不定义。
5. **登录凭证唯一**：登录名、手机号各自**全局唯一**；登录名不区分大小写、去空格、转半角后判重；登录名不得为 11 位纯数字；登录名仅支持字母、数字与下划线。
6. **密码口径**：密码只在生成时**一次性展示**，弹窗关闭后任何入口不可再查；列表与详情只呈现掩码；遗失只能由超管再次重置，不提供自助找回。
7. **手机号脱敏**：列表与详情脱敏展示（前 3 后 4），编辑表单内展示明文，不设明文查看入口。
8. **超管保护**：系统始终保留至少 1 个启用状态的超管 —— 不可停用 / 注销最后一个启用超管，不可移除最后一个超管的超级管理员角色；任一超管不可停用 / 注销 / 重置本人账号。
9. **数量不设上限**：平台账号总数不限制。
10. **不占租户名额**：平台账号不计入租户成员数，不因分配平台角色而创建或修改租户成员关系。
11. **角色隔离**：本模块只分配平台角色（候选只出现平台角色），不展示、不下发、不回收租户角色；租户角色由租户管理员在租户端分配。
12. **租户主管理员例外**：账号被指定为租户主管理员时，本模块不为其分配平台角色，其租户权限来自租户侧自动授予的「租户管理员」角色。
13. **审计留痕**：所有写操作记录审计；详情页「操作记录」展示账号级轨迹（创建 / 编辑 / 分配角色 / 停用 / 启用 / 注销 / 重置密码），含操作人与客户端 IP；明文密码不在任何记录中留存。
14. **权限呈现**：页面按钮按账号状态矩阵（B15-03）与「非本人」规则呈现；角色级权限可见性由功能码控制，正式实现按 PRD §4 / E13 执行（无「平台账号」功能码时菜单不渲染、接口拒绝）。

### 1.3 业务状态说明

#### B15-03 账号状态
**拟标注位置**：清单「账号状态」列旁、详情页「账号状态」行旁
**标记**：已确认

**批注内容**

- **三态含义**：
  - **启用**：放行登录（平台侧还需至少持有 1 个平台角色）；
  - **停用**：拦截登录，会话即时失效 —— 账号级停用，平台端与租户端登录同时失效；
  - **注销**：终态，不可登录、不可任何操作；执行后账号记录删除（口径见 B15-12）。
- **进入条件**：新建保存后默认「启用」；「停用」由启用态经行操作进入；「启用」由停用态经行操作进入；「注销」由启用或停用态经行操作进入。
- **可进行的操作（状态矩阵）**：

| 状态 | 可编辑 | 可分配角色 | 可重置密码 | 可停用 | 可启用 | 可注销 | 可登录平台后台 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 启用 | 是 | 是 | 是 | 是 | 否 | 是 | 是 |
| 停用 | 是 | 是 | 是 | 否 | 是 | 是 | 否 |
| 注销 | 否 | 否 | 否 | 否 | 否 | 否 | 否 |

- **查看的例外**：任何状态（含演示数据中的注销态账号）均可「查看」详情，注销态为只读。
- **状态变化的影响**：停用不收回平台角色关联、不改租户成员关系记录，仅关闭登录闸门；重新启用后恢复登录能力（启用前校验至少持有 1 个平台角色）。
- **交互表现不算状态**：页面加载、按钮置灰属于交互表现，不视为业务状态。

### 1.4 操作功能及对应业务规则

#### B15-04 平台账号列表（清单、查询与排序）
**拟标注位置**：清单表格区域、清单上方工具条与查询区
**标记**：已确认

**批注内容**

- **操作目的**：查看并维护平台账号（持平台角色的账号）。
- **展示内容**：姓名、登录名、手机号（脱敏）、邮箱、平台角色、账号状态、最近登录时间、创建人、创建时间、操作。**不展示头像列与密码列**。
  - 姓名列中，当前登录账号带「本人」标签；
  - 手机号脱敏为前 3 后 4（如 `138****0001`）；
  - 平台角色以标签展示，「超级管理员」红色高亮；
  - 邮箱为空显示「—」；最近登录时间为空显示「未登录」。
- **查询条件**：① 姓名 / 登录名 —— 关键字包含匹配（登录名忽略大小写）；② 平台角色 —— 下拉单选，不选即全部；③ 账号状态 —— 下拉单选「启用 / 停用」，不选即全部。三条件叠加生效；「重置」清空全部条件；任一条件变化后清单回到第 1 页。
- **排序**：启用状态在前，其余按更新时间倒序。
- **分页**：每页 20 条。
- **工具条**：显示「平台账号列表」与「共 N 条 · 启用 N 条」，并常驻保护提示「不可停用或注销最后一个启用状态的超管，也不可重置自己的密码」。
- **操作列**：「查看」「编辑」「分配角色」常驻；超过 3 个操作时收起进「更多 ▾」下拉；「停用 / 启用 / 重置密码 / 注销」按账号状态出现其一，危险操作（停用 / 重置密码 / 注销）红色展示；注销态账号操作列仅「查看」。
- **本人账号的特殊处理**：列表中本人账号不显示「重置密码」；「停用」「注销」对本人显示但点击后阻断（提示不可对自己执行该操作）。

#### B15-05 查看账号详情
**拟标注位置**：详情页各信息区、页头按钮区
**标记**：已确认

**批注内容**

- **操作目的**：只读核对某个账号的完整信息与操作轨迹。
- **入口**：列表「姓名」链接或操作列「查看」；「账号查询」页点「姓名」下钻。
- **账号信息区**：头像、登录名、手机号（脱敏）、邮箱、姓名、平台角色、密码（掩码）、首次登录强制修改密码、账号状态、创建人、创建时间、最近更新（更新人 · 更新时间）。
- **名下租户身份区**：仅对**不持平台角色**的账号展示（列出有效租户身份，主管理员标注「（主管理员）」；空时显示「该账号暂无有效租户身份」）；持平台角色且有租户身份的账号不在详情页展示该区，其影响提示在停用 / 注销弹窗给出（见 B15-09 / B15-12）。
- **操作记录区**：账号级审计轨迹表 —— 时间、操作、操作人、变更摘要、客户端 IP；只记录账号级操作（创建 / 编辑 / 分配角色 / 停用 / 启用 / 注销 / 重置密码），不含密码重置专项明细，明文密码不在任何记录中留存。
- **页头操作**：按状态矩阵与「非本人」规则呈现（返回列表、分配平台角色、停用、启用、重置密码、编辑、注销）。
- **无平台角色账号（租户成员视角）**：从账号查询下钻进入时以只读形态展示 —— 面包屑归「账号查询」、标签「只读 · 租户成员」、平台角色显示「无（租户成员，不在此维护平台角色）」、展示「所属组织」与「名下租户身份」、仅提供「返回账号查询」。

#### B15-06 新建平台账号
**拟标注位置**：页头「新建」按钮、新建表单页各字段
**标记**：已确认

**批注内容**

- **操作目的**：建立一个新的平台账号并授予平台角色。
- **入口**：列表页头「新建」。
- **可操作条件**：恒可操作，不限制账号总数。
- **表单内容**：头像、登录名、手机号、邮箱、姓名、平台角色、初始密码设置、首次登录强制修改密码（字段说明见 B15-14～B15-21）。
- **校验规则（任一不通过即阻断保存，已填内容保留）**：
  1. 登录名必填；仅支持字母、数字与下划线；不得为 11 位纯数字；与已有账号不重复（不区分大小写、去空格、转半角后判重）；
  2. 手机号必填；须为有效手机号格式；全局唯一；
  3. 姓名必填，不超过 50 字符；
  4. 平台角色须选 1 至 5 个，至少 1 个；
  5. 选择自定义初始密码时，须 8-20 位且同时包含字母和数字，两次输入一致。
- **结果**：保存成功后弹出强提示「账号创建成功！」，**一次性展示登录名与初始密码**（含「复制密码」按钮），提示「请立即复制并线下告知用户。关闭后将无法再次查看密码。」；账号状态为启用、置首登改密标记、记录创建人、写审计；返回列表后可见新账号。
- **取消**：点「取消」返回列表，不保存任何内容。

#### B15-07 编辑平台账号
**拟标注位置**：操作列「编辑」、详情页「编辑」、编辑表单页各字段
**标记**：已确认

**批注内容**

- **操作目的**：修改账号资料（改档）。
- **入口**：列表操作列「编辑」；详情页「编辑」。
- **可操作条件**：启用与停用状态均可编辑；注销态不可编辑（状态矩阵见 B15-03）。
- **可修改内容**：姓名、手机号、邮箱、头像、平台角色；**登录名只读**（创建后不可改）。
- **平台角色的维护口径**：编辑表单包含「平台角色」多选（带出现有角色），可增减（增减后 1-5 个、至少 1 个），**保存时角色变更一并生效**；也可通过「分配平台角色」弹窗维护（见 B15-08），两个入口口径一致。
- **校验规则**：手机号须为有效格式且全局唯一（与已有账号重复即阻断）；姓名必填且不超过 50 字符；登录名不可改。
- **结果**：保存成功提示「保存成功」，跳转回该账号详情；审计记录手机号前后值；记录更新人与更新时间。
- **取消**：点「取消」返回来源页（详情或列表），不保存。

#### B15-08 分配平台角色
**拟标注位置**：操作列「分配角色」、详情页「分配平台角色」、分配角色弹窗
**标记**：已确认

**批注内容**

- **操作目的**：为目标账号增减平台角色，权限随之实时变化。
- **入口**：列表操作列「分配角色」；详情页「分配平台角色」。
- **可操作条件**：启用与停用状态均可分配；注销态不可分配。
- **操作过程**：打开弹窗，标题「分配平台角色 · 姓名」；以复选框勾选角色（「超级管理员」标注「保护角色」，其他内置角色标注「内置」）；底部「已选角色」只读汇总所选角色名。
- **规则**：
  1. 增减后角色总数须在 1 至 5 个之间，至少保留 1 个；
  2. 候选只出现平台角色，不出现任何租户角色；
  3. 不可移除最后一个启用超管的超级管理员角色（阻断并提示系统至少保留 1 个启用超管）；
  4. 不把平台角色写入该账号的租户成员关系，也不因其持有成员关系而改动平台角色。
- **结果**：保存后提示「平台角色已更新」，**实时生效并踢目标账号下线重新取权限**；列表与详情的角色标签刷新；审计记前后值。
- **取消**：点「取消」或关闭弹窗，不变更。

#### B15-09 停用账号
**拟标注位置**：操作列「停用」、详情页「停用」、确认弹窗
**标记**：已确认

**批注内容**

- **操作目的**：临时冻结账号登录能力，保留档案与角色。
- **可操作条件**：仅启用态显示「停用」。
- **操作过程**：点击后弹出二次确认，标题「确认停用」，正文「确认停用账号「姓名」（登录名）？」，并提示「停用后该账号无法登录平台后台，会话立即失效；平台角色保留，可重新启用。」；底栏「取消」与「确认停用」。
- **名下租户身份影响**：目标账号名下有有效租户身份时，弹窗列出「该账号名下有 N 个租户身份将同时失效」与各租户名称（主管理员标注），并需**勾选「已知悉：停用后该账号在以上租户的登录同时失效，成员关系记录保留」**方可确认。
- **规则**：不可停用本人（点击后阻断，提示不可对自己执行该操作）；不可停用最后一个启用超管（阻断）；账号级停用 —— 平台端与租户端登录同时失效，目标会话立即失效；不收回平台角色关联、不改成员关系记录；审计记受影响租户身份数。
- **结果**：确认后提示「停用成功」，状态标签变更为「停用」，操作列出现「启用」。
- **取消**：点「取消」或关闭弹窗，状态不变。

#### B15-10 启用账号
**拟标注位置**：操作列「启用」、详情页「启用」、确认弹窗
**标记**：已确认

**批注内容**

- **操作目的**：恢复已停用账号的登录能力。
- **可操作条件**：仅停用态显示「启用」。
- **操作过程**：点击后弹出二次确认，标题「确认启用」，正文「确认启用账号「姓名」（登录名）？」，并提示「启用后该账号恢复登录能力，需已持有平台角色。」；底栏「取消」与「确认启用」。
- **规则**：目标账号须至少持有 1 个平台角色；角色数为 0 时阻断，提示先分配平台角色。
- **结果**：确认后提示「启用成功」，状态标签变更为「启用」；该账号在租户端的登录能力同步恢复。
- **取消**：点「取消」或关闭弹窗，状态不变。

#### B15-11 重置密码
**拟标注位置**：操作列「重置密码」、详情页「重置密码」、重置密码弹窗
**标记**：已确认

**批注内容**

- **操作目的**：为遗忘密码的账号重新生成登录密码。
- **入口**：列表操作列「重置密码」；详情页「重置密码」。**本人账号不显示该入口**。
- **权限**：重置密码执行权限限超级管理员（PRD D04 / E14）；原型固定以超管身份演示，非超管视角的入口可见性由功能码控制。
- **操作过程**：打开弹窗，标题「重置密码 · 姓名」；选择重置方式（单选）：
  - **随机生成**（默认）：系统生成 12 位随机密码，含大写、小写、数字、特殊字符；
  - **自定义密码**：录入新密码与确认新密码，须不少于 8 位，且包含大写、小写、数字、特殊字符中的三类，两次输入一致。
- **结果**：确认重置后**一次性展示新密码**（提示「请抄录并线下交付给账号持有人。关闭本弹窗后不可再次查看，遗失只能重新重置。」）；旧密码立即失效、目标账号全部会话失效、置首登改密标记；写密码重置记录（记重置方式：随机生成 / 自定义）与审计；密码重置记录按字段清单落库，**不在详情页展示**（详情页只呈现操作记录）。
- **取消**：关闭弹窗不产生变更；已生成的一次性密码关闭后不可再查。

#### B15-12 注销账号
**拟标注位置**：操作列「注销」、详情页「注销」、确认弹窗
**标记**：已确认（按裁决以原型为准；PRD / 字段清单需同步修订，见 §3）

**批注内容**

- **操作目的**：对离职 / 废弃账号做终态处理。
- **可操作条件**：启用或停用态显示「注销」；注销态不再出现。
- **操作过程**：点击后弹出二次确认，标题「确认注销」，正文「确认注销账号「姓名」（登录名）？」，并提示「注销为不可逆操作：账号数据将被删除，平台角色关联同步回收，登录名与手机号一并释放（可重新注册）。」；名下有有效租户身份时，列出「该账号名下有 N 个租户身份将同时失效」与各租户名称，并需勾选「已知悉」方可确认；底栏「取消」与「确认注销」，**不设双人复核，仅二次确认**。
- **落库口径（原型为准）**：注销为**物理删除** —— 从账号表删除该账号记录，同步回收其平台角色关联，**登录名与手机号一并释放**（之后可被重新注册使用）；执行后该账号从平台账号列表与账号查询中消失。
- **与停用的区别**：停用是保留记录的临时冻结，可重新启用；注销是删除记录的终态处理，不可恢复。
- **规则**：不可注销本人（阻断）；不可注销最后一个启用超管（阻断）；注销后踢下线、不可登录。
- **提示口径差异说明**：PRD §5.7 / D05 与字段清单原为「记录保留、登录名与手机号不释放」口径，本轮裁决以原型为准，两份文档需同步修订（见 §3 L-01）。

### 1.5 账号查询（平台全局只读视图）

#### B15-13 账号查询
**拟标注位置**：功能标题「账号查询」附近、清单区域
**标记**：已确认

**批注内容**

- **定位**：平台管理员的全局账号视图，跨域查看全部账号（平台账号 + 租户成员），**只读，不提供任何写入口**。
- **入口与权限**：平台后台 → 系统管理 → 组织与权限 → 账号查询（功能编码 `M221`，由平台角色勾选控制；无功能码时菜单不渲染、调接口返回无权限并写审计）。
- **数据范围**：账号表全局唯一一份，既含持平台角色的平台账号，也含不持平台角色的租户成员；账号类型按「是否存在生效平台角色关联」动态判定，同一账号不出现两行。
- **展示内容**：姓名、登录名、手机号（脱敏）、邮箱、账号类型（平台账号 / 租户成员）、账号状态、最近登录时间、所属组织（生效成员关系对应的租户名，无则「—」）、创建人、创建时间。**不展示密码与头像**。
- **查询条件**：① 姓名 / 登录名 / 手机号 —— 关键字包含匹配；② 账号类型 —— 「平台账号 / 租户成员」；③ 账号状态 —— 「启用 / 停用」。三条件叠加，变化后回第 1 页；「重置」清空条件。
- **注销账号的可见性**：列表展示注销态账号（演示数据）；账号状态筛选只有「启用 / 停用」两个选项，**不提供「注销」单独筛选**。
- **排序**：平台账号在前、租户成员在后；同类内启用状态在前，其余按更新时间倒序。
- **分页**：每页 20 条。
- **工具条**：显示「全部账号列表」与「共 N 条 · 平台账号 N 条 · 租户成员 N 条（账号表全局唯一一份，两域共享）」。
- **下钻**：所有账号的姓名均可下钻 —— 平台账号进入平台账号详情（可操作）；租户成员进入只读详情（见 B15-05）。
- **与平台账号菜单的分界**：本页只读；所有写操作仍走平台账号列表 / 详情等既有入口。

#### B15-19 平台角色
**拟标注位置**：表单「平台角色」内容旁、列表 / 详情「平台角色」列旁、分配角色弹窗
**标记**：已确认

**批注内容**

- **业务含义**：账号在平台侧的身份与权限来源；多角色权限按功能码取并集。
- **选择方式**：新建 / 编辑表单中多选；分配角色弹窗中复选框勾选；候选**只出现平台角色**，不出现租户角色。
- **必填与数量**：必选；至少 1 个、最多 5 个；0 个阻断保存。
- **特殊角色**：「超级管理员」为保护角色（不可删除、不可停用、不可取消内置；最后一个启用超管的该角色不可移除）。
- **可否修改**：可随时通过编辑表单或「分配平台角色」增减，保存 / 授权后实时生效并踢目标账号下线。
- **联动**：账号是否出现在「平台账号」菜单、是否算平台账号，均由是否持有生效平台角色动态判定。

#### B15-20 密码（初始密码设置与一次性展示）
**拟标注位置**：新建表单「初始密码设置」、重置密码弹窗「重置方式」、详情页「密码」行旁
**标记**：已确认

**批注内容**

- **展示口径**：列表与详情只呈现掩码（`••••••••`），不回显明文；密码只在**生成时一次性展示**，关闭后任何入口不可再查；系统日志与接口响应不含明文。
- **建号初始密码**（新建表单「初始密码设置」，二选一）：
  - **系统随机生成**（默认）：8 位大小写字母 + 数字，至少含大写、小写、数字各一；
  - **自定义密码**：8-20 位且同时包含字母和数字，两次输入一致。
- **重置密码**（重置弹窗「重置方式」，二选一）：随机生成 12 位（含大写、小写、数字、特殊字符）或自定义（不少于 8 位且含四类字符中的三类）。
- **生效规则**：新密码生成后旧密码立即失效、目标账号全部会话失效、置首登改密标记。
- **遗失处理**：只能由超管再次重置，不提供明文找回、不提供自助找回入口。

#### B15-21 首次登录强制修改密码
**拟标注位置**：新建表单「首次登录强制修改密码」、详情页该行旁
**标记**：已确认

**批注内容**

- **业务含义**：首登改密标记，置位时账号首次登录后被强制进入改密页，改密后方可进入系统。
- **置位时机**：新建账号时置 1（新建表单中默认开启、不可关闭）；重置密码后再次置 1；改密成功后清零。
- **详情展示**：详情页展示「是（待改密）/ 否（已改密）」，用于核查该账号是否已完成首次改密。

#### B15-22 制单信息与操作记录
**拟标注位置**：详情页「创建人 / 创建时间 / 最近更新」行旁、「操作记录」区、列表「创建人 / 创建时间」列旁
**标记**：已确认（均为演示数据）

**批注内容**

- **创建人、创建时间**：新建保存时由系统记录，不可维护；列表与详情均展示。
- **最近更新**：每次保存与状态变更刷新（更新人 · 更新时间）；只在详情展示。
- **操作记录表**：时间、操作、操作人、变更摘要、客户端 IP；按时间倒序；只记录账号级操作（创建 / 编辑 / 分配角色 / 停用 / 启用 / 注销 / 重置密码 / 改密），**不含密码重置专项明细**（密码重置记录按字段清单独立落库，仅不在前端详情页呈现）。
- **数据性质**：原型中的账号数据与操作记录为演示数据，正式实现需由系统按真实操作记录生成；明文密码不在任何记录中留存。
