## 1. 拟添加的批注清单

### 1.1 整体流程

#### B06-01 能源维护整体流程
**拟标注位置**：功能标题「能源库」附近（全局说明）｜**标记**：已确认

- **适用场景**：在后台维护一本统一的能源字典，作为工序「能源投入」选择能源时的依据。
- **流程**：进入能源库 → 右侧清单展示全部能源 → 按需查询、查看核对 → 新增或编辑能源 → 用「启用 / 禁用」控制该能源能否被工序选用。
- **分支**：新增只有页头「新增」一个入口；编辑可来自清单操作列「编辑」或查看弹窗底栏「编辑」。
- **衔接**：查看、编辑均以弹窗完成，不离开本页；批量启停作用于勾选项。
- **结束**：保存后立即生效并刷新清单。全程没有提交、审核、驳回；能源可在启用与禁用之间反复切换。

### 1.2 全局规则说明

#### B06-02 全局规则
**拟标注位置**：功能标题「能源库」附近（与整体流程同一全局说明入口）｜**标记**：已确认（权限为待确认，见 §3）

1. **适用范围**：能源由**能源库独立承载**，**不在物料库**；物料与能源分属两本字典。
2. **极简字典口径**：能源**不设「数据来源」「引用状态」「默认单位」「数量」**等字段；**本期不落「热值 / 热值单位」**（《能源字段清单》D06 / H1，热值折算需求待定）。所有能源对有权进入本模块的用户同等可编辑，不区分系统预置 / 组织自建。
3. **能源类型口径**：能源类型只取粗粒度三类 —— **燃料 / 电力 / 热力**；**具体品名填在「能源名称」**（如「柴油」「外购电力」），不用类型表达具体品名。
4. **适用行业**：引用行业库、多选；**为空 = 全行业通用**（候选为启用状态的行业，见行业库）。
5. **删除限制**：本页**仅「已禁用」的能源可删除**，启用态不展示删除入口。
6. **变更不追溯**：编辑为直接覆盖，不保留历史版本，也不改变已生成的工序引用与核算结果。
7. **无流程节点**：没有提交、审核、驳回，也没有操作日志入口。
8. **统一限制**：能源编码、能源名称、能源类型必填；使用状态不在新增 / 编辑表单中出现，只能通过清单操作变更。
9. **权限**：谁可维护、谁只能查看，原型未做任何限制 → **待确认**（见 §3）。

### 1.3 业务状态说明

#### B06-03 使用状态
**拟标注位置**：清单「使用状态」列旁｜**标记**：已确认

- **含义**：能源只有「启用」「禁用」两个状态。启用 = 可被工序的「能源投入」选用；禁用 = 不再出现在新的工序投入项选择中。
- **进入条件**：新增保存后默认为「启用」；「启用」由禁用态经行操作「启用」进入；「禁用」由启用态经行操作「禁用」进入。
- **可进行的操作**：无论启用还是禁用，都可以「查看」「编辑」；禁用态多出「启用」与「删除」，启用态多出「禁用」。
- **状态变化**：启用与禁用双向可达、可反复切换；变更状态只刷新使用状态与更新时间，不改动能源编码、名称、类型、适用行业、描述等任何内容。
- **对下游的影响**：能源一旦禁用，新的工序「能源投入」不能再选它；**已引用该能源的工序与已生成的核算结果不受影响，历史引用数据保留**。
- **删除前提**：删除仅对「已禁用」能源开放，删除后不可恢复。

### 1.4 操作功能及对应业务规则

#### B06-04 清单
**拟标注位置**：清单表格区域与清单上方工具条｜**标记**：已确认

- **展示内容**：能源编码、能源名称、能源类型、适用行业、使用状态、更新时间、操作。
- **展示规则**：每页 **20 条**。
- **工具条**：左侧显示「能源列表」与「共 N 条 · 已选 N 条」；右侧为「批量启用」「批量停用」。
- **操作列**：「查看」「编辑」恒显示；「启用」「禁用」按当前状态二者只出现其一；「删除」仅对已禁用能源显示。
- **勾选**：行首复选框 + 表头「全选当前页」；勾选按当前列表求交集，已删除 / 被筛掉的条目自动移出选择集。

#### B06-05 查询与重置
**拟标注位置**：清单上方查询区｜**标记**：已确认（搜索按钮行为为原型已表现·待核对）

- **查询项**：① 能源编码 —— 包含关系模糊匹配、忽略大小写；② 能源名称 —— 包含关系模糊匹配；③ 能源类型 —— 下拉（燃料 / 电力 / 热力）；④ 适用行业 —— 级联选择，支持按行业名称 / 编码搜索；⑤ 使用状态 —— 下拉「启用 / 禁用」，不选即为全部。
- **规则**：多个条件同时生效（叠加过滤）；任一条件变化后清单回到第 1 页；「重置」清空全部条件并恢复完整清单。
- **搜索按钮**：点「搜索」执行一次当前条件的筛选。
- **原型表现（待核对）**：原型中点「搜索」仅出现一次「查询完成」提示、不产生额外动作（条件输入后清单已即时收敛）。需确认正式需求是「点击后查询」还是保留「即时筛选 + 按钮共存」。

#### B06-06 新增能源
**拟标注位置**：页头「新增」按钮旁｜**标记**：已确认

- **操作目的**：建立一个新的能源字典记录。
- **入口**：页头「新增」；恒可操作，不限制已有能源数量。
- **操作过程**：打开弹窗，标题「新增能源」；填写能源编码、能源名称，选择能源类型，按需选适用行业、填能源描述。
- **结果**：保存成功后弹窗关闭，页面提示「保存成功」，新能源出现在清单中，使用状态为「启用」。
- **取消或失败**：点「取消」或关闭弹窗不保存任何内容；校验不通过时保留已填内容并给出提示（见 B06-14）。

#### B06-07 查看能源
**拟标注位置**：清单操作列「查看」、清单「能源编码」链接、查看弹窗｜**标记**：已确认（制单信息为原型已表现·待核对）

- **操作目的**：只读核对某个能源的完整信息。
- **入口**：清单操作列的「查看」，或直接点击清单中的能源编码；任何状态均可查看。
- **展示内容**：基本信息（能源编码、能源名称、能源类型、使用状态、适用行业、能源描述）+ 制单信息（创建人 / 创建时间 / 更新人 / 更新时间）。
- **规则**：只读弹窗，不能在其中直接修改内容；能源描述为空显示「-」。
- **结果**：底栏为「关闭」与「编辑」；点「关闭」不产生任何变更，点「编辑」切换到编辑弹窗并带出该能源内容。

#### B06-08 编辑能源
**拟标注位置**：清单操作列「编辑」、查看弹窗底栏「编辑」｜**标记**：已确认

- **操作目的**：修改能源信息；任何状态均可编辑，不区分启用与禁用。
- **操作过程**：打开弹窗，标题「编辑能源」，带出该能源现有内容；**能源编码为只读，不可修改**；可修改能源名称、能源类型、适用行业、能源描述。
- **结果**：保存成功后弹窗关闭，提示「保存成功」，清单刷新。

#### B06-09 启用能源
**拟标注位置**：清单操作列「启用」、确认弹窗｜**标记**：已确认

- **显示条件**：只在该能源当前为「禁用」时，操作列才显示「启用」。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认启用」，正文「确认将能源『能源名称』（能源编码）启用？」，并提示「启用后该能源可被工序的『能源投入』选用。」；底栏为「取消」与「确认启用」，不使用「确定」字样。
- **结果**：确认后该能源变为「启用」，提示「启用成功」，清单刷新；此时起可被工序的「能源投入」选用。
- **取消**：点「取消」或关闭弹窗，状态不变。

#### B06-10 禁用能源
**拟标注位置**：清单操作列「禁用」、确认弹窗｜**标记**：已确认

- **显示条件**：只在该能源当前为「启用」时，操作列才显示「禁用」。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认禁用」，正文「确认将能源『能源名称』（能源编码）禁用？」，并提示「禁用后该能源不可被新的工序投入项选用；已有引用不受影响。禁用后可执行删除。」；底栏为「取消」与「确认禁用」。
- **结果**：确认后该能源变为「禁用」，提示「禁用成功」，清单刷新；禁用后才出现「删除」入口。
- **待确认**：原型对启用态能源一律允许直接禁用，未按「是否被工序引用」拦截（见 §3）。

#### B06-11 删除能源
**拟标注位置**：清单操作列「删除」、确认弹窗｜**标记**：已确认

- **显示条件**：**仅对该能源当前为「禁用」时显示**；启用态不出现删除入口。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认删除」（危险态按钮），正文「确认将能源『能源名称』（能源编码）删除？」，并提示「删除后不可恢复。仅『已禁用』的能源可删除；当前能源使用状态为『禁用 / 启用』。」
- **结果**：确认后该能源被删除，提示「删除成功」，清单刷新；删除不可恢复。
- **取消**：点「取消」或关闭弹窗，不删除。

#### B06-12 批量启用 / 停用
**拟标注位置**：清单工具条「批量启用」「批量停用」、批量确认弹窗、批量结果弹窗｜**标记**：已确认

- **操作目的**：对勾选的多条能源一次性变更使用状态。
- **可操作条件**：需先勾选至少一条；未勾选时按钮不可点。
- **操作过程**：点击「批量启用」或「批量停用」→ 二次确认弹窗，标题「确认批量启用 / 停用」，正文「将对已勾选的 N 条能源执行批量启用 / 停用？」，并提示「逐条执行，完成后返回『成功条数 + 跳过清单与原因』」；底栏「取消」与「确认批量启用 / 停用」（处理中显示「处理中…」）。
- **结果**：完成后弹出「批量操作结果」，显示「成功 N 条，跳过 N 条。跳过条目未做任何改动。」，并以表格列出被跳过条目的「能源编码 / 能源名称 / 跳过原因」；无跳过时表格显示「没有被跳过的能源」。底栏「知道了」。
- **规则**：逐条执行、不整体回滚；命中不可变更的条目跳过并在失败清单中返回原因。

#### B06-14 弹窗的保存与取消
**拟标注位置**：新增 / 编辑弹窗底栏「保存」「取消」｜**标记**：已确认

- **保存**：点击后先校验填写内容，通过后保存并关闭弹窗，提示「保存成功」，清单刷新；保存过程中按钮显示「保存中…」并暂时不可点击，避免重复提交。
- **校验规则（任一不通过即阻断保存，弹窗不关闭，已填内容全部保留）**：
  1. 能源编码未填写 → 「请输入能源编码」；
  2. 能源名称未填写 → 「请输入能源名称」；
  3. 能源类型未选择 → 「请选择能源类型」；
  4. 能源描述超过 500 字符 → 「描述最长 500 字符」。
- **保存失败**：给出失败原因提示，弹窗保持打开、内容保留。
- **取消**：点「取消」或关闭弹窗不保存任何内容；再次打开时不保留上次填写的内容。

### 1.5 字段说明

#### B06-15 字段：能源编码
**拟标注位置**：表单「能源编码」内容旁，及清单该列表头｜**标记**：已确认

- **业务含义**：能源的唯一业务标识，用于清单展示与核对。
- **填写方式**：手工填写，输入框提示「如 E-011」。
- **必填**：必填；为空提示「请输入能源编码」并阻断保存。
- **可否修改**：**编辑时只读，不可修改**（仅在新增时确定）。
- **重复限制**：能源编码应保持唯一；与已有能源重复时保存被拦截（以接口校验为准）。

#### B06-16 字段：能源名称
**拟标注位置**：表单「能源名称」内容旁，及清单该列表头｜**标记**：已确认

- **业务含义**：能源的具体品名（如「柴油」「外购电力」）。
- **填写方式**：手工填写，输入框提示「请输入具体品名，如『柴油』『外购电力』」。
- **必填**：必填；为空提示「请输入能源名称」并阻断保存。
- **重复限制**：名称不要求唯一，允许重名。

#### B06-17 字段：能源类型
**拟标注位置**：表单「能源类型」内容旁，及清单「能源类型」列｜**标记**：已确认

- **业务含义**：能源的粗粒度类别，仅三类：**燃料 / 电力 / 热力**；具体品名填在「能源名称」。
- **填写方式**：下拉单选；控件下方按所选类型显示口径说明（未选时显示「类型只取『燃料 / 电力 / 热力』，具体品名填在『能源名称』」）。
- **必填**：必填；未选提示「请选择能源类型」并阻断保存。
- **候选口径**：燃料 = 来自燃料燃烧的能源，如煤炭、天然气、柴油等；电力 = 外购输入电力，如电网供电；热力 = 蒸汽、热水等热力（来源：外购或自产）。

#### B06-18 字段：适用行业
**拟标注位置**：表单「适用行业」内容旁，及清单「适用行业」列｜**标记**：已确认

- **业务含义**：该能源适用的行业范围，引用行业库。
- **填写方式**：多选级联选择，支持按行业名称 / 编码搜索。
- **必填**：选填；**为空 = 全行业通用**。
- **候选范围**：来自行业库（原型为行业库四级结构的启用节点）。

#### B06-19 字段：能源描述
**拟标注位置**：表单「能源描述」内容旁，及查看弹窗该行｜**标记**：已确认

- **业务含义**：补充说明该能源的口径或用途。
- **填写方式**：多行文本，提示「选填」，带字符计数「当前长度 / 500」。
- **必填**：选填。
- **长度上限**：最长 **500 字符**；超出时保存被阻断并提示「描述最长 500 字符」。
- **展示**：查看弹窗中展示，为空显示「-」；清单中不展示。

#### B06-20 使用状态（表单口径）
**拟标注位置**：清单「使用状态」列旁（引用 B06-03，不重复展开）｜**标记**：已确认

- 新增 / 编辑表单中**不出现**使用状态，用户不能在表单内改动它。
- 新增保存后默认「启用」；之后只能通过清单操作列的「启用」「禁用」变更。

#### B06-21 查看弹窗中的制单信息
**拟标注位置**：查看弹窗「创建人 / 创建时间 / 更新人 / 更新时间」｜**标记**：原型已表现·待核对

- **创建人、创建时间**：新增保存时由系统记录，不可维护。
- **更新人、更新时间**：每次保存、每次启用 / 禁用都会刷新，用于追溯最近变更；清单中也有「更新时间」列。
- **展示位置**：四者均只在查看弹窗中查看（清单仅展示更新时间）。
- **数据性质**：原型中为演示数据（内置演示值），正式实现需由系统按真实操作记录生成。
