> **文档定位**：物料字段定义的唯一真相源（SST）。业务 PRD 和 Demo PRD 只引用字段名称，不重复维护枚举、必填性和字段口径。
> **适用类型**：基础数据维护（轻量）—— 无审核流、无版本化
> **维护形态**：列表（支持批量启用 / 停用）+ 查看 / 新增 / 编辑弹窗
> **成熟度**：粗纲
> **版本**：V0.4
> **更新时间**：2026-09-21

**六条「不设字段」的设计约定**

| 约定 | 说明 |
| :--- | :--- |
| **不设「默认单位」字段** | 物料就是「一个物料对象 + 类型 + 适用行业」，**不绑定单位**。单位在**工序的投入项 / 产出项**中逐行选择（那本来就有单位字段），避免在物料上预设默认值造成同一物料在不同工序口径不一致。**方案 §4.2.1 已同步回改**（方案 v1.2 r4，见方案「附录二 · 基础库落地偏离清单」第 1 项）（**已确认，2026-09-20**） |
| **不设「数据来源」字段** | 不区分「系统预置 / 组织自建」，**不设记录归属字段**，因此也不推导可见性、不设「仅平台运营可维护」的只读档（**已确认，2026-09-21**）。这是相对方案 §3.3.3 的**有意偏离**，已在附录二登记 |
| **不设「引用状态 / 引用清单」字段** | 物料主数据上**不维护引用状态**：编辑与启用 / 禁用对所有物料开放，不受工序引用约束（**已确认，2026-09-21**）；删除仅由「使用状态」决定（见 D05） |
| **不设「数据获取方式」字段**（实测 / 统计 / 估算 / 供应商 / 数据库） | 该属性属于**活动数据**，不属于物料主数据 —— 方案 §4.6 把它列在「活动数据」章节。同一种物料（如原竹）在不同批次可能是实测、也可能是估算。**改为在数据填报（P22）时按填报记录填写**，物料侧不预设默认值（**已确认，2026-09-20**） |
| **不设「引用资源」字段** | 竞品的资源文件选择器不采纳 —— 不参与计算，且会引入对标准文件库（A1-3，P1 优先级）的依赖，与「物料库保持轻量」的定位不符（**已确认，2026-09-20**） |
| **不设「可见性」字段** | 不单独设字段（原「由数据来源推导」的口径随「数据来源」移除而失效）（**已确认，2026-09-21**） |

> **物料与单位的关系（说明）**：物料**不持有单位**；单位由**工序的投入项 / 产出项**在引用物料时逐行选择。因此 E04（因子单位不匹配）与 E09（质量平衡）的校验仍以**工序行的单位**为准，链路不受影响。与竞品（南平铝业）的做法一致。

> **物料与能源的边界（说明）**：物料承载「原辅料 / 自然资源输入 / 中间品 / 产品 / 副产品 / 排放物」；**能源（燃料 / 电力 / 热力）由能源库（A1-2）承载**，不在本清单。

## 1. 模块与数据结构

### 1.1 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块名称 | 物料 |
| 业务归属 | 后台管理 → 基础库 → 物料库 → 物料管理（方案 §2.3 A1-1、§4.2.1、§八 P04） |
| 模块类型 | 基础数据维护（轻量），非业务单据、无审核流、无版本化 |
| 核心对象 | 物料 |
| 核心职责 | 维护可用于工序投入项 / 产出项的物料字典，为活动数据填报与排放计算提供挂载对象。**物料只回答"是什么"，不回答"多少、用什么单位"** —— 数量与单位在工序的投入项 / 产出项中填写 |

### 1.2 对象结构

| 结构 | 对象 | 与主对象关系 | 主键/唯一标识 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 主表 | 物料 | 主对象 | 物料编码 | **单一对象，无子表**；轻量基础数据 |
| 字典 | 物料类型（一级 = 投入产出流） | — | 类型编码 | 系统内置枚举（§5.1，6 类），不开放维护 |
| 字典 | 物料子类（二级） | — | 子类编码 | 系统内置枚举（§5.2，3 类），**仅一级 = 原辅料时使用** |
| 字典 | 适用行业 | — | 行业编码 | 引用行业库（A1-4）；主表存多选值 |

### 1.3 维护边界

| 维度 | 说明 |
| :--- | :--- |
| 数据来源 | **不设**（V0.4 起）：物料不分「系统预置 / 组织自建」，统一由后台维护，**对所有有权进入本模块的用户同等可编辑** |
| ERP是否数据源 | 否 |
| 新增编辑 | 支持（**查看 / 新增 / 编辑均走弹窗**） |
| 子表 | 无 |
| 导入导出 | 导出：**不支持**（已下线，V0.5）；导入：V0.1 不支持（【待确认 Q09】） |
| 状态与执行 | 使用状态（启用 / 禁用）+ **支持批量启用 / 停用**；无版本化、无审核流、无外部系统推送 |
| 关键唯一键 | 物料编码唯一（全租户） |
| 删除 | **仅「已禁用」的物料可删除**（不检查引用状态） |
| 历史兼容 | 物料主数据变更（类型、适用行业等）不影响已核算结果；需按新口径重算时走 **E13** |

| 约束ID | 约束 | 影响对象 |

## 5. 枚举值

### 5.1 物料类型（一级 = **工序的投入产出流**）

> **与工序的 `流类型` 严格同源**，保证「物料类型 ↔ 投入产出流」可一一对应挂接；**能源不在本库**（由能源库 A1-2 承载）。

| 枚举值 | 含义 | 工序侧挂接位置 |
| :--- | :--- | :--- |
| 原辅料 | 进入工序的原材料 / 辅助材料 / 包装材料 | 工序**投入项** · 流类型 = 原辅料 |
| 自然资源输入 | 直接取自自然环境的资源（如自来水 / 地表水） | 工序**投入项** · 流类型 = 自然资源输入 |
| 中间品 | 工序间流转的中间产物 | 工序**产出项** · 流类型 = 中间品 |
| 产品 | 工序产出的最终产品 | 工序**产出项** · 流类型 = 产品 |
| 副产品 | 工序产出的非主产品 | 工序**产出项** · 流类型 = 副产品 |
| 排放物 | 生产过程中产生的废气 / 废水 / 废渣 | 工序**产出项** · 流类型 = 排放物（行上再选**排放物类别**：废气 / 废水 / 废渣） |

> 原「物料分类」7 类扁平枚举（原料 / 辅料 / 包装材料 / 中间品 / 成品 / 副产品 / 废弃物）**已由本口径替代**（V0.4）：原「原料 / 辅料 / 包装材料」降为「原辅料」下的二级子类（§5.2）；原「成品」改称「**产品**」、原「废弃物」并入「**排放物**」；**新增「自然资源输入」**。

### 5.2 物料子类（二级，**仅一级 = 原辅料时维护**）

| 枚举值 | 含义 | 备注 |
| :--- | :--- | :--- |
| 原料 | 进入工序的原材料 | 对标原「原料」分类 |
| 辅料 | 用量较小的辅助材料 | 对标原「辅料」分类 |
| 包装材料 | 用于包装的材料 | 对标原「包装材料」分类 |

### 5.3 使用状态

| 枚举值 | 含义 | 是否默认 | 备注 |
| :--- | :--- | :---: | :--- |
| 启用 | 可被业务选用 | 是 | 新增默认启用 |
| 禁用 | 不可被新业务选用 | 否 | 启用 ↔ 禁用双向可达；**仅「已禁用」可删除**（D05） |

> 原「数据来源」枚举（系统预置 / 组织自建）随字段移除而废止（V0.4 起）。
