## 1. 拟添加的批注清单

### 1.1 整体流程

#### B05-01 物料维护整体流程
**拟标注位置**：功能标题「物料库」附近（全局说明）｜**标记**：已确认

- **适用场景**：在后台维护一本统一的物料字典，作为工序投入项 / 产出项选择物料时的依据。
- **流程**：进入物料库 → 右侧清单展示全部物料 → 按需查询、查看核对 → 新增或编辑物料 → 用「启用 / 禁用」控制该物料能否被工序选用。
- **分支**：新增只有页头「新增」一个入口，建立物料；编辑可来自清单操作列「编辑」或查看弹窗底栏「编辑」。
- **衔接**：查看、编辑均以弹窗完成，不离开本页；批量启停作用于勾选项。
- **结束**：保存后立即生效并刷新清单。全程没有提交、审核、驳回；物料可在启用与禁用之间反复切换。

### 1.2 全局规则说明

#### B05-02 全局规则
**拟标注位置**：功能标题「物料库」附近（与整体流程同一全局说明入口）｜**标记**：已确认（权限为待确认，见 §3）

1. **适用范围**：本页维护统一的物料字典；**能源不由本页承载**（燃料 / 电力 / 热力等归「能源库」），物料与能源分属两本字典。
2. **极简字典口径**：物料**不设「数据来源」「引用状态」「默认单位」「数量」**等字段（《物料字段清单》D07）；所有物料对有权进入本模块的用户同等可编辑，不区分系统预置 / 组织自建。
3. **物料类型口径**：物料类型 = 工序投入产出流，一级 6 类（原辅料 / 自然资源输入 / 中间品 / 产品 / 副产品 / 排放物）；其中**仅「原辅料」需要维护二级子类**（原料 / 辅料 / 包装材料），其余一级类型不涉及二级。
4. **适用行业**：引用行业库、多选；**为空 = 全行业通用**（候选为启用状态的行业，见行业库）。
5. **删除限制**：本页**仅「已禁用」的物料可删除**，启用态不展示删除入口。
6. **变更不追溯**：编辑为直接覆盖，不保留历史版本，也不改变已生成的工序引用与核算结果。
7. **无流程节点**：没有提交、审核、驳回，也没有操作日志入口。
8. **统一限制**：物料编码与物料名称必填，物料类型必填；使用状态不在新增 / 编辑表单中出现，只能通过清单操作变更。
9. **权限**：谁可维护、谁只能查看，原型未做任何限制 → **待确认**（见 §3）。

### 1.3 业务状态说明

#### B05-03 使用状态
**拟标注位置**：清单「使用状态」列旁｜**标记**：已确认

- **含义**：物料只有「启用」「禁用」两个状态。启用 = 可被工序按对应流类型选用；禁用 = 不再出现在新的工序投入项 / 产出项选择中。
- **进入条件**：新增保存后默认为「启用」；「启用」由禁用态经行操作「启用」进入；「禁用」由启用态经行操作「禁用」进入。
- **可进行的操作**：无论启用还是禁用，都可以「查看」「编辑」；禁用态多出「启用」与「删除」，启用态多出「禁用」。
- **状态变化**：启用与禁用双向可达、可反复切换；变更状态只刷新使用状态与更新时间，不改动物料编码、名称、类型、适用行业、描述等任何内容。
- **对下游的影响**：物料一旦禁用，新的工序投入项 / 产出项不能再选它；**已引用该物料的工序与已生成的核算结果不受影响，历史引用数据保留**。
- **删除前提**：删除仅对「已禁用」物料开放，删除后不可恢复。

### 1.4 操作功能及对应业务规则

#### B05-04 清单
**拟标注位置**：清单表格区域与清单上方工具条｜**标记**：已确认

- **展示内容**：物料编码、物料名称、物料类型（含二级子类）、适用行业、使用状态、更新时间、操作。
- **展示规则**：① 每页 **20 条**；② 「物料类型」列同时展示一级类型（标签）与原辅料的二级子类（弱化文字）。
- **工具条**：左侧显示「物料列表」与「共 N 条 · 已选 N 条」；右侧为「批量启用」「批量停用」。
- **操作列**：「查看」「编辑」恒显示；「启用」「禁用」按当前状态二者只出现其一；「删除」仅对已禁用物料显示。
- **勾选**：行首复选框 + 表头「全选当前页」；勾选按当前列表求交集，已删除 / 被筛掉的条目自动移出选择集。

#### B05-05 查询与重置
**拟标注位置**：清单上方查询区｜**标记**：已确认（搜索按钮行为为原型已表现·待核对）

- **查询项**：① 物料编码 —— 包含关系模糊匹配、忽略大小写；② 物料名称 —— 包含关系模糊匹配；③ 物料类型 —— 下拉（一级 6 类）；④ 物料子类 —— 下拉（原料 / 辅料 / 包装材料）；⑤ 适用行业 —— 级联选择，支持按行业名称 / 编码搜索；⑥ 使用状态 —— 下拉「启用 / 禁用」，不选即为全部。
- **规则**：多个条件同时生效（叠加过滤）；任一条件变化后清单回到第 1 页；「重置」清空全部条件并恢复完整清单。
- **搜索按钮**：点「搜索」执行一次当前条件的筛选。
- **原型表现（待核对）**：原型中点「搜索」仅出现一次「查询完成」提示、不产生额外动作（条件输入后清单已即时收敛）。需确认正式需求是「点击后查询」还是保留「即时筛选 + 按钮共存」。

#### B05-06 新增物料
**拟标注位置**：页头「新增」按钮旁｜**标记**：已确认

- **操作目的**：建立一个新的物料字典记录。
- **入口**：页头「新增」；恒可操作，不限制已有物料数量。
- **操作过程**：打开弹窗，标题「新增物料」；填写物料编码、物料名称、物料类型（一级），选择「原辅料」时再选二级子类，按需选适用行业、填物料描述。
- **结果**：保存成功后弹窗关闭，页面提示「保存成功」，新物料出现在清单中，使用状态为「启用」。
- **取消或失败**：点「取消」或关闭弹窗不保存任何内容；校验不通过时保留已填内容并给出提示（见 B05-14）。

#### B05-07 查看物料
**拟标注位置**：清单操作列「查看」、清单「物料编码」链接、查看弹窗｜**标记**：已确认（制单信息为原型已表现·待核对）

- **操作目的**：只读核对某个物料的完整信息。
- **入口**：清单操作列的「查看」，或直接点击清单中的物料编码；任何状态均可查看。
- **展示内容**：基本信息（物料编码、物料名称、物料类型、适用行业、使用状态、物料描述）+ 制单信息（创建人 / 创建时间 / 更新人 / 更新时间）。
- **规则**：只读弹窗，不能在其中直接修改内容；物料描述为空显示「-」。
- **结果**：底栏为「关闭」与「编辑」；点「关闭」不产生任何变更，点「编辑」切换到编辑弹窗并带出该物料内容。

#### B05-08 编辑物料
**拟标注位置**：清单操作列「编辑」、查看弹窗底栏「编辑」｜**标记**：已确认

- **操作目的**：修改物料信息；任何状态均可编辑，不区分启用与禁用。
- **操作过程**：打开弹窗，标题「编辑物料」，带出该物料现有内容；**物料编码为只读，不可修改**；可修改物料名称、物料类型、二级子类、适用行业、物料描述。
- **联动**：切换一级类型时，若新类型不是「原辅料」，**已选的二级子类被清空**（二级仅原辅料需要维护）。
- **结果**：保存成功后弹窗关闭，提示「保存成功」，清单刷新。

#### B05-09 启用物料
**拟标注位置**：清单操作列「启用」、确认弹窗｜**标记**：已确认

- **显示条件**：只在该物料当前为「禁用」时，操作列才显示「启用」。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认启用」，正文「确认将物料『物料名称』（物料编码）启用？」，并提示「启用后该物料可被工序按对应流类型选用。」；底栏为「取消」与「确认启用」，不使用「确定」字样。
- **结果**：确认后该物料变为「启用」，提示「启用成功」，清单刷新；此时起可被工序按对应流类型选用。
- **取消**：点「取消」或关闭弹窗，状态不变。

#### B05-10 禁用物料
**拟标注位置**：清单操作列「禁用」、确认弹窗｜**标记**：已确认

- **显示条件**：只在该物料当前为「启用」时，操作列才显示「禁用」。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认禁用」，正文「确认将物料『物料名称』（物料编码）禁用？」，并提示「禁用后该物料不可被新的工序投入项 / 产出项选用；已有引用不受影响。禁用后可执行删除。」；底栏为「取消」与「确认禁用」。
- **结果**：确认后该物料变为「禁用」，提示「禁用成功」，清单刷新；禁用后才出现「删除」入口。
- **待确认**：原型对启用态物料一律允许直接禁用，未按「是否被工序引用」拦截（见 §3）。

#### B05-11 删除物料
**拟标注位置**：清单操作列「删除」、确认弹窗｜**标记**：已确认

- **显示条件**：**仅对该物料当前为「禁用」时显示**；启用态不出现删除入口。
- **操作过程**：点击后弹出二次确认弹窗，标题「确认删除」（危险态按钮），正文「确认将物料『物料名称』（物料编码）删除？」，并提示「删除后不可恢复。仅『已禁用』的物料可删除；当前物料使用状态为『禁用 / 启用』。」
- **结果**：确认后该物料被删除，提示「删除成功」，清单刷新；删除不可恢复。
- **取消**：点「取消」或关闭弹窗，不删除。

#### B05-12 批量启用 / 停用
**拟标注位置**：清单工具条「批量启用」「批量停用」、批量确认弹窗、批量结果弹窗｜**标记**：已确认

- **操作目的**：对勾选的多条物料一次性变更使用状态。
- **可操作条件**：需先勾选至少一条；未勾选时按钮不可点。
- **操作过程**：点击「批量启用」或「批量停用」→ 二次确认弹窗，标题「确认批量启用 / 停用」，正文「将对已勾选的 N 条物料执行批量启用 / 停用？」，并提示「逐条执行，完成后返回『成功条数 + 跳过清单与原因』」；底栏「取消」与「确认批量启用 / 停用」（处理中显示「处理中…」）。
- **结果**：完成后弹出「批量操作结果」，显示「成功 N 条，跳过 N 条。跳过条目未做任何改动。」，并以表格列出被跳过条目的「物料编码 / 物料名称 / 跳过原因」；无跳过时表格显示「没有被跳过的物料」。底栏「知道了」。
- **规则**：逐条执行、不整体回滚；命中不可变更的条目跳过并在失败清单中返回原因。

#### B05-14 弹窗的保存与取消
**拟标注位置**：新增 / 编辑弹窗底栏「保存」「取消」｜**标记**：已确认

- **保存**：点击后先校验填写内容，通过后保存并关闭弹窗，提示「保存成功」，清单刷新；保存过程中按钮显示「保存中…」并暂时不可点击，避免重复提交。
- **校验规则（任一不通过即阻断保存，弹窗不关闭，已填内容全部保留）**：
  1. 物料编码未填写 → 「请输入物料编码」；
  2. 物料名称未填写 → 「请输入物料名称」；
  3. 物料类型未选择 → 「请选择物料类型」；
  4. 一级类型为「原辅料」但未选二级子类 → 「请选择物料子类」；
  5. 物料描述超过 500 字符 → 「描述最长 500 字符」。
- **保存失败**：给出失败原因提示，弹窗保持打开、内容保留。
- **取消**：点「取消」或关闭弹窗不保存任何内容；再次打开时不保留上次填写的内容。

### 1.5 字段说明

#### B05-15 字段：物料编码
**拟标注位置**：表单「物料编码」内容旁，及清单该列表头｜**标记**：已确认

- **业务含义**：物料的唯一业务标识，用于清单展示与核对。
- **填写方式**：手工填写，输入框提示「如 M-801」。
- **必填**：必填；为空提示「请输入物料编码」并阻断保存。
- **可否修改**：**编辑时只读，不可修改**（仅在新增时确定）。
- **重复限制**：物料编码应保持唯一；与已有物料重复时保存被拦截（以接口校验为准）。

#### B05-16 字段：物料名称
**拟标注位置**：表单「物料名称」内容旁，及清单该列表头｜**标记**：已确认

- **业务含义**：物料的展示名称。
- **填写方式**：手工填写。
- **必填**：必填；为空提示「请输入物料名称」并阻断保存。
- **重复限制**：名称不要求唯一，允许重名。

#### B05-17 字段：物料类型（一级）
**拟标注位置**：表单「物料类型（一级）」内容旁，及清单「物料类型」列｜**标记**：已确认

- **业务含义**：物料在工序中的投入 / 产出流归类，一级 6 类：原辅料 / 自然资源输入 / 中间品 / 产品 / 副产品 / 排放物。
- **填写方式**：下拉单选，占位提示「请选择投入产出流」。
- **必填**：必填；未选提示「请选择物料类型」并阻断保存。
- **联动**：切换到非「原辅料」时，二级子类被清空且不再展示二级字段。

#### B05-18 字段：物料子类（二级）
**拟标注位置**：表单「物料子类（二级）」内容旁｜**标记**：已确认

- **业务含义**：仅「原辅料」下的细分：原料 / 辅料 / 包装材料。
- **显示条件**：**仅当一级类型选择「原辅料」时出现**，其余一级类型不展示该字段。
- **填写方式**：下拉单选，占位提示「请选择子类」。
- **必填**：一级为「原辅料」时必填；未选提示「请选择物料子类」并阻断保存。

#### B05-19 字段：适用行业
**拟标注位置**：表单「适用行业」内容旁，及清单「适用行业」列｜**标记**：已确认

- **业务含义**：该物料适用的行业范围，引用行业库。
- **填写方式**：多选级联选择，支持按行业名称 / 编码搜索。
- **必填**：选填；**为空 = 全行业通用**。
- **候选范围**：来自行业库（原型为行业库四级结构的启用节点）。

#### B05-20 字段：物料描述
**拟标注位置**：表单「物料描述」内容旁，及查看弹窗该行｜**标记**：已确认

- **业务含义**：补充说明该物料的口径或用途。
- **填写方式**：多行文本，提示「选填」，带字符计数「当前长度 / 500」。
- **必填**：选填。
- **长度上限**：最长 **500 字符**；超出时保存被阻断并提示「描述最长 500 字符」。
- **展示**：查看弹窗中展示，为空显示「-」；清单中不展示。

#### B05-21 使用状态（表单口径）
**拟标注位置**：清单「使用状态」列旁（引用 B05-03，不重复展开）｜**标记**：已确认

- 新增 / 编辑表单中**不出现**使用状态，用户不能在表单内改动它。
