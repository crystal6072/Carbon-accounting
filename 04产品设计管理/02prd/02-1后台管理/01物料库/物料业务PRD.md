## 1. 需求概述

### 1.1 需求背景

物料是**工序投入项 / 产出项的引用对象**，是活动数据填报与排放计算的挂载点。方案 §4.2.2 原将工序的投入产出流分为原料投入、能源投入、中间品、成品、副产品五类，其中**除能源投入外的四类都指向物料**。

**本模块口径（已确认 2026-09-21）**：**物料类型 = 工序的投入产出流类型**，与工序的流类型**严格同源**，保证「物料类型 ↔ 投入产出流」一一对应挂接：

```text
物料类型（一级）              工序侧挂接位置
├── 原辅料          →  工序投入项 · 流类型 = 原辅料
├── 自然资源输入     →  工序投入项 · 流类型 = 自然资源输入
├── 中间品          →  工序产出项 · 流类型 = 中间品
├── 产品            →  工序产出项 · 流类型 = 产品
├── 副产品          →  工序产出项 · 流类型 = 副产品
└── 排放物          →  工序产出项 · 流类型 = 排放物（行上再选「排放物类别」）
```

> **相对方案 §4.2.2 的偏离（已在附录二登记）**：① 原「5 类流」扩展为 **7 类流**（新增「**自然资源输入**」与「**排放物**」，原「原料投入」细化并改称「**原辅料**」，原「成品」改称「**产品**」）；② 原「物料分类」7 类扁平枚举由「物料类型（一级）+ 原辅料二级子类」替代。

物料的**定位是"是什么"**：一个物料对象 + 类型 + 适用行业。它**不绑定单位、不绑定数量** —— 数量与单位在**工序的投入项 / 产出项**中逐行填写（那里本来就有单位字段）。

> 关于单位：碳核算确实强依赖单位（方案 §4.2.3 指出，单位不可换算则 `活动数据 × 排放因子` 无法计算，触发 **E04**；质量平衡 **E09** 也依赖单位统一），但**承载点在工序行**，不在物料主数据。本模块不设默认单位字段（**已确认 2026-09-20**，与竞品做法一致）。

本模块为轻量基础数据，不做审核流与版本化。

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :--- | :--- | :--- |
| G1 | 提供可覆盖工序投入产出的物料字典 | 物料类型（一级 6 类）与工序的投入产出流可一一对应挂接 |
| G2 | 物料字典保持极简 | 主对象字段 **7 项**（编码 / 名称 / 类型 / 子类 / 适用行业 / 使用状态 / 描述），不承载单位、数量、数据来源等非物料属性 |
| G3 | 类型口径与工序同源 | 物料类型取自工序流类型枚举，不允许自由填写；原辅料再分子类 |
| G4 | 支持批量维护 | 列表可按勾选项批量启用 / 停用 |
| G5 | 物料变更不污染历史结果 | 物料主数据变更后已核算结果不变；需重算时走 **E13** |

### 1.3 In Scope / Out of Scope

**In Scope**

| 能力 | 说明 |
| :--- | :--- |
| 物料列表与查询 | 按编码、名称、物料类型、物料子类、适用行业、状态筛选 |
| 新增 / 编辑物料（弹窗） | 名称、类型（一级 + 原辅料子类）、适用行业、描述 |
| 查看物料（弹窗） | 基本信息 + 制单信息 |
| 启用 / 禁用（单个 + 批量） | 行操作 / 勾选批量 + 二次确认 |
| 删除 | **仅「已禁用」的物料可删除**，二次确认 |

**Out of Scope**

| 不做项 | 说明 |
| :--- | :--- |
| 审核流 / 版本化 | 基础数据，均不涉及 |
| 外部系统推送 / 单据下推 | 不涉及 |
| **数据来源** | 不区分「系统预置 / 组织自建」，不设归属与可见性档位（**已确认 2026-09-21**） |
| **引用状态 / 引用清单** | 编辑与启停不受工序引用约束；删除仅由使用状态决定（**已确认 2026-09-21**） |
| 物料规格、型号、材质等扩展属性 | 本期不做 |
| 是否生物质 / 可再生标记 | 建议不做；生物碳处理在排放因子库侧用负因子表达（方案 §6.5） |
| Excel 导入 | V0.1 不支持（【待确认 Q09】） |
| 物料的碳排放因子 | 归**排放因子库**（方案 §4.4），本模块不存因子 |
| **数据获取方式 / 引用资源 / 可见性** | 「数据是怎么来的」（实测 / 统计 / 估算 / 供应商 / 数据库）属**活动数据**属性，在数据填报 P22 时记录（方案 §4.6）；竞品的「引用资源」选择器不采纳（**已确认 2026-09-20**） |
| 独立详情页 / 独立新增编辑页 | **不设**：查看 / 新增 / 编辑均走弹窗 |
| 能源类物料 | 能源由**能源库（A1-2）**承载，不在本模块 |

## 2. 用户与使用场景

### S01 维护物料

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要补充物料字典（如某类原料） |
| 操作流程 | 列表页点「新增」→ 弹窗填写编码、名称、物料类型、适用行业、描述（一级选「原辅料」时再选子类）→ 保存 |
| 预期结果 | 保存成功提示；列表刷新出现该物料，使用状态默认「启用」 |

### S02 批量启用 / 停用物料

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 一批物料同时需要停用（如某类原料不再使用） |
| 操作流程 | 勾选多条物料 → 点击「批量停用」→ 二次确认 → 确认 |
| 预期结果 | 逐条执行并置为禁用，返回「成功条数」；失败条目跳过并返回清单与原因 |

### S03 删除物料

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 某条物料不再需要 |
| 操作流程 | 先禁用该物料 → 行操作「删除」→ 二次确认 → 确认 |
| 预期结果 | **仅「已禁用」的物料可删除**；启用态不展示删除入口。删除不检查工序引用状态 |

### S04 查看物料

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要确认物料口径 |
| 操作流程 | 列表点编码或「查看」→ 弹窗查看基本信息与制单信息；底栏可切「编辑」 |
| 预期结果 | 展示完整字段与制单信息 |

### S05 物料主数据变更的影响

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 物料的名称、类型、子类、适用行业或描述需要修改 |
| 操作流程 | 编辑物料 → 修改内容 → 保存 |
| 预期结果 | 可直接保存（不受引用状态限制）；**不影响工序行已填的数量与单位**；**已核算项目的既有结果不变**；如需按新口径重算，须走 **E13**（重新检测 → 重新核算 → 生成新结果版本） |

## 4. 物料类型与单位规则

### 4.1 物料类型（= 工序的投入产出流）

| # | 规则 |
| :--- | :--- |
| C1 | 物料类型（一级）取值来自字段清单 §5.1 的 6 类枚举，**不允许自由填写**；枚举与工序的 `流类型` **同源**（D02） |
| C2 | 物料类型与工序侧挂接位置**一一对应**：原辅料 / 自然资源输入 → 投入项；中间品 / 产品 / 副产品 / 排放物 → 产出项（见 §1.1 图示） |
| C3 | **物料子类（二级）仅当一级 = 原辅料时维护**（原料 / 辅料 / 包装材料，必填）；其余类型不展示该字段、存空值（D03） |
| C4 | 物料类型变更不影响已建立的工序引用（工序只引用物料本身，不引用类型）；**本模块不校验「物料类型是否等于工序行的流类型」**，该一致性由工序侧自行把握 |
| C5 | 排放物类物料在工序侧还需选择**排放物类别**（废气 / 废水 / 废渣），该属性在工序行上维护，不在物料主数据 |

### 4.2 物料与单位的关系

> **结论：物料不持有单位。** 方案 §4.2.1 原在物料字段中列有「默认单位」，本 PRD 有意偏离，**方案已同步回改**（方案 v1.2 r4，见方案「附录二 · 基础库落地偏离清单」第 1 项）（**已确认 2026-09-20**，与行业平台做法一致）。

| # | 规则 |
| :--- | :--- |
| U1 | 物料只回答「是什么」；单位在**工序的投入项 / 产出项**中逐行选择（那里本来就有单位字段） |
| U2 | 因此 **E04**（因子单位不匹配）与 **E09**（质量平衡）的校验以**工序行的单位**为准，物料侧不参与 |
| U3 | 同一物料在不同工序可以选不同单位（只要同类型且可换算），由填报人按实际情况决定 —— 这正是「不在物料上预设默认单位」的理由 |
| U4 | 若后续需要「按物料推荐单位」的填报便利，应作为**填报页（P22）的辅助推荐**实现，**不得把单位写回物料主数据** |

## 5. 「数据来源」的移除（V0.4）

> **本章锁定结论：物料主数据上不设「数据来源」字段。**

| 被移除的内容 | 理由 |
| :--- | :--- |
| **数据来源**（系统预置 / 组织自建） | 该字段原仅用于判定可编辑性与可见范围。原型落地后不再区分平台域与组织域，**统一由后台维护**（**已确认 2026-09-21**，相对方案 §3.3.3 为**有意偏离**，已在附录二登记） |
| **引用状态 / 引用清单** | 编辑与启用 / 禁用不受工序引用约束；删除仅由使用状态决定（仅「已禁用」可删除）（**已确认 2026-09-21**） |
| **可见性** | 原由「数据来源」推导，随「数据来源」移除而不再设 |

| # | 规则 |
| :--- | :--- |
| S1 | 所有物料对有权进入本模块的用户**同等可编辑**；不设只读档 |
| S2 | **数据质量等级（DQR）不在本模块维护**：方案 §4.6 规定 DQR 默认随活动数据的「数据获取方式（实测 / 统计 / …）」生成，因此 DQR 的承载点在**活动数据**（P22），不在物料主数据 |
| S3 | 本模块**不承载任何"数据是怎么来的"信息**；若后续需要按物料追溯原始依据，应通过活动数据的凭证字段实现 |

## 6. 业务规则

| 规则编号 | 规则名称 | 触发条件 | 处理逻辑 | 例外策略 |
| :--- | :--- | :--- | :--- | :--- |
| R-001 | 物料编码唯一 | 新增 / 编辑保存时 | 编码**全租户唯一**；新增时手工填写，编辑时**只读**（【待确认 Q04】生成方式）；名称不唯一 | 重复时阻断保存 |
| R-002 | 物料类型必填且受控 | 保存时 | 一级必须来自 §4.1 / 字段清单 §5.1 枚举（6 类）；**一级 = 原辅料时必须选二级子类**（原料 / 辅料 / 包装材料）；均不允许自由填写（C1 / C3 / D02 / D03） | 命中时阻断 |
| ~~R-003~~ | ~~默认单位必填~~ | — | **已废止（2026-09-20）**：物料不设默认单位字段 | 已废止 |
| R-004 | 描述长度约束 | 保存时 | 最长 500 字符（D04） | 超长时阻断并提示字符数 |
| R-005 | 编辑不受归属与引用限制 | 编辑物料时 | **所有物料均可编辑**名称 / 类型 / 子类 / 适用行业 / 描述；不设数据来源与引用状态（已确认 2026-09-21） | 无例外 |
| R-006 | 启用 / 禁用双向可达 | 启用 / 禁用物料时 | 启用 ↔ 禁用双向可达，**不检查工序引用**；禁用后不可被新工序选用，历史引用保留 | 无例外 |
| R-007 | 删除仅限「已禁用」 | 删除物料时 | **仅「已禁用」的物料可删除**；启用中的物料不可删除（D05） | 命中时阻断，提示「请先禁用后再删除」 |
| R-008 | 批量启停逐条执行 | 批量启用 / 停用时 | 逐条执行；被筛选 / 已删除的条目跳过，返回「成功 N 条、失败 M 条 + 失败原因」 | 无例外 |
| R-009 | 主数据变更不追溯历史 | 修改物料名称 / 类型 / 子类 / 适用行业 / 描述时 | 可直接保存，不影响工序行已填的数量与单位；**不追溯**已核算结果；需按新口径重算走 **E13** | 无例外 |
| R-010 | 不设数据来源 / 引用状态 / 默认单位 | 全生命周期 | 本模块不含上述字段（D07 / §5） | 无例外 |

> R-005～R-010 为 V0.4 重排后的编号，分别替代原 R-006～R-010；原 R-011（引用资源约束）随「引用资源」字段移除而废止，编号保留空号以维持交叉引用稳定。

## 7. 状态与操作矩阵

### 7.1 状态维度说明

| 状态维度 | 取值 | 来源 |
| :--- | :--- | :--- |
| 使用状态 | 启用 / 禁用 | 字段清单（用户操作） |

> 本模块**无数据来源维度、无引用状态维度、无版本维度、无审核维度**。

### 7.2 操作矩阵

| 使用状态 | 编辑 | 启用 | 禁用 | 删除 | 被新工序选用 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 启用 | 是 | — | 是 | 否（R-007） | 是 |
| 禁用 | 是 | 是 | — | 是 | 否 |

**闭环校验**

- 启用 ↔ 禁用双向可达，无前置约束（不检查引用状态）；
- 「已被引用」**不构成**编辑、禁用或删除限制；
- 删除仅由使用状态决定（仅「已禁用」可删除），入口在启用态隐藏；
- 批量启停遵循 R-008 的逐条执行规则，不会出现部分失败导致状态不一致；
- 无版本维度、无审核分支。

## 8. 上下游与引用关系
