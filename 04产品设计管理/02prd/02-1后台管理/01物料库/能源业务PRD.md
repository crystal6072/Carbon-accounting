## 1. 需求概述

### 1.1 需求背景

能源是工序「**能源投入**」的引用对象，也是排放计算中最敏感的数据源（电力、燃料）。方案 §6.1.1 的计算链路为：

```text
碳排放量 = 活动数据 × 排放因子 × 单位换算系数 × 分配系数
             ↑ 能源实物量    ↑ 因子库     ↑ 单位库
```

能源可能多一层转换：**实物量 → 能量 → 排放量**。其中「实物量 → 能量」由**热值**承担，「能量 / 活动数据 → 排放量」由**排放因子库**负责（方案 §4.4）。

**本期边界（已确认 2026-09-21）**：**本模块不落「热值 / 热值单位」字段**。原因是热值是否必需取决于排放因子库的因子表达口径（物理量 vs 能量，见 Q12）——若因子按物理量给出（如 `kgCO₂e/L 柴油`），活动数据 × 因子即可直接计算，热值冗余。故本期**能源库只回答「是什么」**：能源名称 + 能源类型 + 适用行业；数量与单位在**工序的投入项 / 产出项**逐行填写。

**单位归属（已确认 2026-09-20）**：能源**不绑定默认单位**，与物料一致 —— 「这次填了多少、用什么单位」由**工序的投入项 / 产出项**逐行决定。若 Q12 后续落地热值，其「热值单位」只是**热值的分母**（`44.8 MJ/kg` 中的 `kg`），是定义域信息，不是填报单位。

本模块为轻量基础数据，不做审核流与版本化。

### 1.2 需求目标

| # | 目标 | 可验证口径 |
| :--- | :--- | :--- |
| G1 | 提供可覆盖工序能源投入的能源字典 | 燃料 / 电力 / 热力三类齐备，具体品名可扩展 |
| G2 | 能源字典保持极简 | 主对象字段 **6 项**（编码 / 名称 / 类型 / 适用行业 / 使用状态 / 描述），不承载单位、数量、热值、数据来源等其余属性 |
| G3 | 与排放因子库职责不重叠 | 本模块不含排放因子、不含区域 / 年度、不含热值 |
| G4 | 支持批量维护 | 列表可按勾选项批量启用 / 停用 |
| G5 | 主数据变更不污染历史结果 | 变更后已核算结果不变；需重算时走 **E13** |

**In Scope**

| 能力 | 说明 |
| :--- | :--- |

**Out of Scope**

| 不做项 | 说明 |
| :--- | :--- |
| 审核流 / 版本化 | 基础数据，均不涉及 |
| **数据来源** | 不区分「系统预置 / 组织自建」，不设归属与可见性档位（**已确认 2026-09-21**，与物料库原型一致） |
| **引用状态 / 引用清单** | 编辑与启停不受工序引用约束；删除仅由使用状态决定（**已确认 2026-09-21**） |
| **热值 / 热值单位** | **本期不落字段**；待排放因子库因子表达口径确认（Q12）后再定 |
| **默认单位** | 能源不绑定填报单位；单位由工序投入项 / 产出项逐行选择（**已确认 2026-09-20**） |
| **排放因子** | 「活动数据 → 排放量」归**排放因子库**（方案 §4.4） |
| **适用区域 / 年度** | 电网类因子的区域 + 年度管理归**排放因子库**（方案 §4.4） |
| **数据获取方式 / 引用资源 / 可见性** | 「数据是怎么来的」属**活动数据**（方案 §4.6），在 P22 记录；竞品的资源选择器不采纳 |
| 热值随批次变化的历史版本 | 本期无热值字段，暂不涉及 |
| 是否可再生 / 是否生物质标记 | 建议不做；生物碳在排放因子库用负因子表达（方案 §6.5） |
| Excel 导入 | V0.1 不支持（【待确认 Q07】） |
| 独立详情页 / 独立新增编辑页 | **不设**：查看 / 新增 / 编辑均走弹窗（与物料库一致） |

## 2. 用户与使用场景

### S01 维护能源

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要补充能源字典（如「生物质颗粒」） |
| 操作流程 | 列表页点「新增」→ 弹窗填写编码、名称、能源类型、适用行业、描述 → 保存 |
| 预期结果 | 保存成功提示；列表刷新出现该能源，使用状态默认「启用」 |

### S02 批量启用 / 停用能源

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 一批能源同时需要停用（如某类燃料不再使用） |
| 操作流程 | 勾选多条 → 点击「批量停用」→ 二次确认 → 确认 |
| 预期结果 | 逐条执行并置为禁用，返回「成功条数」；失败条目跳过并返回清单与原因 |

### S03 删除能源

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 某条能源不再需要 |
| 操作流程 | 先禁用该能源 → 行操作「删除」→ 二次确认 → 确认 |
| 预期结果 | **仅「已禁用」的能源可删除**；启用态不展示删除入口。删除不检查工序引用状态 |

### S04 查看能源

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 需要确认能源口径 |
| 操作流程 | 列表点编码或「查看」→ 弹窗查看基本信息与制单信息；底栏可切「编辑」 |
| 预期结果 | 展示完整字段与制单信息 |

### S05 能源主数据变更的影响

| 项 | 内容 |
| :--- | :--- |
| 触发条件 | 能源的名称、类型、适用行业或描述需要修改 |
| 操作流程 | 编辑能源 → 修改内容 → 保存 |
| 预期结果 | 可直接保存（不受引用状态限制）；**不影响工序行已填的数量与单位**；**已核算项目的既有结果不变**；如需按新口径重算，须走 **E13** |

## 4. 能源类型与单位规则

### 4.1 能源类型分层（**方案冲突，按推荐口径处理**）

| 出处 | 口径 |
| :--- | :--- |
| 方案 §2.3 A1-2 | 能源类型 = 电、柴油、天然气、蒸汽、热力（类型与品名混用） |
| 竞品界面 | 能源类型 = 燃料 / 电力 / 热力，品名放在「能源名称」 |

**本模块按竞品分层口径撰写**：

```text
能源类型（粗粒度，枚举）      能源名称（具体品名，用户填写）
├── 燃料          →  柴油、天然气、汽油、煤炭、生物质燃料
├── 电力          →  外购电力、自发电
└── 热力          →  蒸汽、热水、外购热力
```

| # | 规则 |
| :--- | :--- |
| T1 | 能源类型只取「燃料 / 电力 / 热力」三类，**不再把具体品名放进枚举** |
| T2 | 能源名称填写具体品名；名称**不唯一**（可用括号补充用途） |
| T3 | 能源类型必须来自字段清单 §5.1 枚举，不允许自由填写 |

### 4.2 热值（**本期不落字段**）

| # | 规则 |
| :--- | :--- |
| H1 | **本期不设「热值 / 热值单位」字段**（已确认 2026-09-21） |
| H2 | 是否必需取决于排放因子库的因子表达口径：因子按**能量**给出（如 `kgCO₂e/GJ`）则必需；按**物理量**给出（如 `kgCO₂e/L 柴油`）则冗余（**Q12**） |
| H3 | 若 Q12 结论为「需要」，再补「热值（正数，必填）」+「热值单位（引用计量单位库能量类单位）」两字段，并同步恢复热值口径（统一采用**低位热值 LHV**，不设高位热值）与「可按实际批次覆盖」的填报口径 |
| H4 | 若 Q12 落地热值，热值变更**不追溯**已核算结果；需按新口径重算须走 **E13** |

### 4.3 单位归属（**已确认，不得推翻**）

> 方案 §4.2.1 原在能源字段中列有「默认单位」，本 PRD 有意偏离，**方案已同步回改**（方案 v1.2 r4，见方案「附录二 · 基础库落地偏离清单」第 2 项）（**已确认 2026-09-20**，与物料做法一致）。

| # | 规则 |
| :--- | :--- |
| N1 | 能源**不持有默认单位**；「这次填了多少、用什么单位」由**工序的投入项 / 产出项**逐行选择 |
| N2 | 因此 **E04**（因子单位不匹配）与 **E09**（质量平衡）的校验以**工序行的单位**为准 |
| N3 | 若 Q12 后续落地热值，其「**热值单位**」与「默认单位」性质不同：它是**热值的分母**（定义域信息），**只服务于热值字段本身**，不与填报行为耦合；「默认单位」是填报语义，已移除 |
| N4 | 若后续需要「按能源推荐填报单位」的便利，应作为**填报页（P22）的辅助推荐**实现，**不得把填报单位写回能源主数据** |

### 4.4 与排放因子库的边界

| # | 规则 |
| :--- | :--- |
| X1 | 本模块**不存排放因子**；「活动数据 → 排放量」由排放因子库负责（方案 §4.4） |
| X2 | 本模块**不设「适用区域 / 适用年度」字段**；电网类因子的区域 + 年度管理归排放因子库（方案 §4.4） |
| X3 | 两层不得混算：本模块只提供**能源字典**（「是什么」），因子库负责**折算**（「排多少」） |

## 5. 校验口径与异常

| # | 规则 |
| :--- | :--- |
| U1 | 能源默认单位的缺失**不影响** E04 校验 —— 校验对象是工序行上填写的单位与因子单位的可换算性（方案 §5.4） |
| U2 | 年度能源未分配时触发 **E08**（原始数据不得直接参与核算，方案 §4.5 / §5.4） |
| U3 | 能量平衡异常触发 **E15（提示级）**：核对投入能源与单位产品能耗的合理性；**E15 的折算基础本期不在本模块**（无热值字段），**校验本身由检测引擎执行** |
| U4 | 热值单位不可换算的问题**本期不适用**（无热值字段）；若 Q12 落地热值，则在核算阶段按 **E04** 处理 |

| R-005 | 编辑不受归属与引用限制 | 编辑能源时 | **所有能源均可编辑**名称 / 类型 / 适用行业 / 描述；不设数据来源与引用状态（已确认 2026-09-21） | 无例外 |
| R-006 | 启用 / 禁用双向可达 | 启用 / 禁用能源时 | 启用 ↔ 禁用双向可达，**不检查工序引用**；禁用后不可被新工序选用，历史引用保留 | 无例外 |
| R-007 | 删除仅限「已禁用」 | 删除能源时 | **仅「已禁用」的能源可删除**；启用中的能源不可删除（D04） | 命中时阻断，提示「请先禁用后再删除」 |
| R-008 | 批量启停逐条执行 | 批量启用 / 停用时 | 逐条执行；被筛选 / 已删除的条目跳过，返回「成功 N 条、失败 M 条 + 失败原因」 | 无例外 |
| R-009 | 主数据变更不追溯历史 | 修改能源名称 / 类型 / 适用行业 / 描述时 | 可直接保存，不影响工序行已填的数量与单位；**不追溯**已核算结果；需按新口径重算走 **E13** | 无例外 |
| R-010 | 不设热值 / 因子 / 区域年度 / 数据来源 / 引用状态 | 全生命周期 | 本模块不含上述字段（D06 / H1 / X1 / X2） | 无例外 |

> R-005～R-010 为 V0.4 重排后的编号，分别替代原 R-006～R-012；原 R-011（热值变更连锁）随热值字段移除而废止，原 R-012（不存因子与区域年度）并入 R-010。

## 7. 状态与操作矩阵

### 7.1 状态维度说明

| 状态维度 | 取值 | 来源 |
| :--- | :--- | :--- |
| 使用状态 | 启用 / 禁用 | 字段清单（用户操作） |

> 本模块**无数据来源维度、无引用状态维度、无版本维度、无审核维度**。

### 7.2 操作矩阵

| 使用状态 | 编辑 | 启用 | 禁用 | 删除 | 被新工序选用 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 启用 | 是 | — | 是 | 否（R-007） | 是 |
| 禁用 | 是 | 是 | — | 是 | 否 |

**闭环校验**

- 启用 ↔ 禁用双向可达，无前置约束（不检查引用状态）；
- 「已被引用」**不构成**编辑、禁用或删除限制；
- 删除仅由使用状态决定（仅「已禁用」可删除），入口在启用态隐藏；
- 批量启停遵循 R-008 的逐条执行规则，不会出现部分失败导致状态不一致；
- 无版本维度、无审核分支。
