## 1. 拟添加的批注清单

### 1.1 整体流程

#### D01-01 平台驾驶舱使用流程
**拟标注位置**：页头标题「竹木产品碳足迹运行驾驶舱」附近（全局说明入口）
**标记**：原型已表现·待核对

**批注内容**

- **适用场景**：平台运营 / 管理者在对外汇报或日常巡检时，用一屏回答「平台现在有多少企业真正在用、产出了多少碳足迹、覆盖哪些行业和区域、最近是在升还是在降」。
- **流程**：从菜单「数据驾驶舱」进入（新页签、全屏、无业务侧栏与顶栏）→ 默认落在平台视角 → 自上而下读 6 项指标 → 看全国产业分布与三块结构分布（行业 / 边界 / 阶段）→ 看两条趋势（核算量与碳足迹、活跃企业率）→ 需要现场口述结论时按 `C` 呼出结论卡 → 按 `Esc` 关卡片或退出全屏。
- **分支**：① 趋势筛选组合没有数据时，图内给出明确空态文案，**不做降级替换**；② 地图可在「企业分布 / 碳足迹记录」两个图层间切换；③ 页内切到企业视角时整屏重新汇总，主图口径清空；④ 装载失败时无提示、无重试（见 D01-03）。
- **衔接**：本页**没有任何下钻、跳转、导出**；所有指标与图形不可点，信息需在本屏读完。
- **结束**：关闭页签或切到企业视角即离开；本页无保存、提交、审核动作，也没有流程终点。

### 1.2 全局规则说明

#### D01-02 全局规则
**拟标注位置**：页头标题附近（与整体流程同一全局说明入口）
**标记**：原型已表现·待核对（权限、口径一致性为待确认）

**批注内容**

1. **只读大屏**：无新增 / 编辑 / 删除 / 导入 / 导出入口，无表格、无分页、无「查询」按钮；打开即汇总呈现，全部内容一次到位。
2. **入口与形态**：从系统菜单「数据驾驶舱」进入，**整屏独立打开**（不显示业务侧栏与顶栏），不占用业务菜单页签；从该入口进入后默认展示平台视角。
3. **视角切换＝整屏重新汇总**：页头「平台驾驶舱 / 企业驾驶舱」是两个按钮，点击后**整屏重新汇总并重绘**，不是局部替换数据；切换后主图口径回到默认分组。
4. **适配方式**：按 **1920×1080** 设计稿等比缩放，缩放比取「屏幕宽 / 1920」与「屏幕高 / 1080」的较小值，保证整屏完整、**永不出现滚动条**；代价是实际字号随屏幕缩放，小屏或投影现场的可读性需现场核对。
5. **核算口径（页脚常显）**：`GB/T 24067-2024 · IPCC AR6 GWP100 · 同品类同边界同单位样本`。该口径要求**跨声明单位不加总**；原型在趋势的「汇总碳足迹」中存在例外（见 D01-10 / §4）。
6. **时间口径**：页头「数据截止 {时间}」取**打开页面时的系统时刻**，不是数据实际截止时间；页面无刷新按钮、无自动轮询。
7. **演示标识**：页脚固定显示「演示数据 · 外部验收」，正式交付前必须移除（见 D01-24）。
8. **键盘快捷键**：`C` 呼出 / 关闭汇报结论卡，`Esc` 关闭结论卡或退出全屏；在大屏任意位置按键均生效，**下拉框获得焦点时同样触发**（见 §4）。
9. **权限与数据范围**：原型**无任何权限控制**，任何可登录账号都能直接打开该大屏；平台视角展示**全平台跨租户**数据，企业账号也能看到（见 D01-23 / §4）。
10. **概念不外露**：不出现计算式、因子、异常编号；但保留 `tCO₂e`、`GWP`、`功能单位` 等核算专业词，属汇报场景可接受的口径用语。

### 1.3 进入与数据装载

#### D01-03 进入与数据装载（含加载态）
**拟标注位置**：页头标题附近（全局说明入口）
**标记**：原型已表现·待核对（失败处理为待确认）

**批注内容**

- **触发**：从菜单进入大屏；每次进入都重新汇总，**不缓存上次结果**。
- **装载方式**：打开时一次性汇总多类数据（核算台账、行业基线、碳足迹报告、数据上报、租户、因子库、模型、标准、核算项目、产品、工艺、当前组织、账号），**全部到位后一次性呈现**，避免出现「半空屏」。
- **加载中表现**：主区显示环形动画 +「正在汇总平台数据…」；页头、页脚、动态条仍在，指标区不显示占位数字。
- **统计年份**：页面**没有年份筛选**；默认统计 **2022–2026 年**，并自动收窄到台账实际有数据的年份区间。**超出该范围的记录不会计入本页任何统计**（见 §4 X-01）。
- **失败表现**：汇总失败时仅把内容置空，**没有错误文案、没有重试入口**，页面会一直停在加载态（见 §4 X-12）。
- **刷新**：无刷新按钮、无轮询；要更新数据只能刷新浏览器或重新进入。
- **待确认**：失败提示与重试策略、平台视角是否需要年份区间筛选。

### 1.4 数据来源与统计范围

#### D01-04 数据来源与统计范围（替代「业务状态说明」）
**拟标注位置**：顶部指标轨标题或页头附近（全局说明入口）
**标记**：原型已表现·待核对

**批注内容**

本页自身**没有业务状态**；这里说明每个区块的取数范围，因为它决定指标之间能不能互相对上。

**区块 → 数据来源**

| 区块 | 数据来源 | 过滤条件 | 备注 |
| :--- | :--- | :--- | :--- |
| 顶部 6 项指标 | 租户管理 + 核算台账 + 账号 | 见下表（**6 项口径并不一致**） | 同一行内混用不同范围 |
| 全国产业分布 | 租户属地 + 台账「区域」 | 记录层＝有效台账 + 年份区间；企业层＝全部租户 | 企业层与记录层是两份数据 |
| 行业分布 Top 5 | 核算台账 | 有效台账 + 年份区间 | 按记录数降序 |
| 核算边界分布 | 核算台账 | 有效台账 + 年份区间 | 仅记录数，不做碳足迹加总 |
| 生命周期阶段构成 | 核算台账的阶段构成（一级阶段） | 有效台账 + 年份区间 | 全部样本，不区分品类 |
| 核算量与单位碳足迹趋势 | 核算台账 | 有效台账 + 年份区间 + 三维筛选 | 组合预生成 |
| 活跃企业率趋势 | 账号最近登录时间 + 台账创建时间 + 租户 | 近 30 天窗口 | 前 11 周为回推演示序列 |
| 最新动态 | 台账 + 报告 + 数据上报 | 各取最近若干条 | 跨租户 |

**6 项指标的统计范围**

| 指标 | 统计对象 | 状态过滤 | 年份过滤 | 组织范围 |
| :--- | :--- | :--- | :--- | :--- |
| 企业总数 | 租户 | 不限（启用数单列在注释） | 不限 | 全平台 |
| 活跃率 | 租户（去重） | 近 30 天有登录或数据更新 | 相对最新数据时间回推 | 全平台 |
| 碳足迹记录 | 核算台账 | **仅有效记录** | **区间内** | 全平台 |
| 核算产品数 | 核算台账按产品去重 | 仅有效 | 区间内 | 全平台 |
| 核算记录 | 核算台账 | **不筛状态** | **全年份** | 全平台 |
| 覆盖行业 | 核算台账按行业去重 | 仅有效 | 区间内 | 全平台 |

- **有效版本（地图用）**：同组织 + 同产品取最新结果版本，历史版本不计入「有效版本」；判定范围仅限区间内记录（若最新版本落在区间外，会被误判为历史版本，见 §4）。
- **活跃口径**：近 30 天内「账号最近登录时间」或「台账创建时间」有更新的租户去重 ÷ 租户总数；30 天窗口以**数据中最新的时间点**为基准回推，**不是当天**（演示数据不会随时间失效，真实环境应改为当天）。
- **不估算、不造数**：取不到的维度显示「—」或明确空态，不用 0 冒充分母。
- **已汇总但本页未展示**：阶段×品类矩阵、行业对标、单位碳足迹分布、基线覆盖率、上报漏斗、数据资产、标准分布等已在后台汇总，平台视角不展示 —— 属预留，**不作为本期需求**。

### 1.5 区块说明、操作功能及对应业务规则

#### D01-05 顶部指标轨（6 项）
**拟标注位置**：指标轨整体（从「企业总数」起）
**标记**：原型已表现·待核对

**批注内容**

- **展示内容**：编号 `01–06` + 指标名 + 大数字 + 单位 + 一行注释；只有「活跃率」带环比箭头与「较上周」。
- **组成顺序**：企业总数 → 活跃率 → 碳足迹记录 → 核算产品数 → 核算记录 → 覆盖行业（字段口径见 D01-16、D01-17）。
- **数字表现**：进入与切视角时从 0 滚到目标值（1.2 秒，缓出），千分位 + 固定小数位（活跃率 1 位，其余 0 位）；系统开启「减少动效」时直接显示终值，不做滚动。
- **无数据表现**：指标被标记为「数据不足」时显示「—」，且不显示单位与环比；**原型未把任何指标置为不足**，即使台账为空也显示 0。
- **口径提示**：「碳足迹记录」（有效 + 区间内）与「核算记录」（不筛状态 + 全年份）相邻展示，两个数字天然不等，现场容易被读成「数据不一致」（见 §4 X-04）。
- **不具备**：指标不可点、无下钻、无趋势小图、无自定义指标、无日期对比。

#### D01-06 全国产业分布（地图 + 区域排行）
**拟标注位置**：中部地图面板标题「全国产业分布」及图层按钮
**标记**：原型已表现·待核对

**批注内容**

- **图层切换**：「企业分布 / 碳足迹记录」二选一，默认「碳足迹记录」；切换只改指标和配色，**不重新汇总数据**。
- **企业层**：省份色块深浅＝该省企业数；点位大小＝企业数；点位标签＝企业数。
- **记录层**：色块深浅＝该省碳足迹记录数；点位大小＝**有效版本数**；点位标签＝有效版本数。
- **地图上方三枚数字**：覆盖区域数（有企业或有记录的区域数）/ 企业数 / 碳足迹记录数。
- **右栏区域排行**：按当前图层指标降序取**前 6**，展示数值与占比；**占比分母是前 6 之和，不是全量**（见 §4 X-05）。
- **悬浮提示**：企业层显示「企业 x 家 + 碳足迹记录 y 条」；记录层显示「碳足迹记录 x 条 + 有效版本 y 个」。
- **区域归属口径**：企业取租户「所在地区 / 地理位置 / 行政归属区划」的**第一个省级值**；记录取台账「区域」字段；未填写统一记为「未填写」，**不参与地图定位但计入覆盖区域数**。
- **覆盖限制**：内置坐标只覆盖 18 个重点省份，其余省份**只参与色块填充、不显示点位**；面板右上「n 个区域」取的是有数据的区域总数，与地图上能看见的点位数不等（见 §4 X-08）。
- **无数据**：底图仍显示，点位 / 排行 / 色块为空，**无空态文案**。

#### D01-07 行业分布 Top 5
**拟标注位置**：左侧上方面板标题「行业分布 Top 5」
**标记**：原型已表现·待核对

**批注内容**

- **排序依据**：按**已完成核算记录数**降序取前 5，**不是按碳足迹量**（副标题已写明）。
- **每行内容**：排名、行业名（超长省略 + 悬停看全称）、记录条数、占比、细进度条。
- **条形与占比**：条形长度相对**第一名**（最大值）填充；百分比分母是**前 5 之和**，不是全部行业记录数（见 §4 X-05）。
- **无数据**：列表为空，**无空态文案**。

#### D01-08 核算边界分布
**拟标注位置**：左侧下方面板标题「核算边界分布」
**标记**：已确认（按裁决去掉碳足迹合计，只保留边界记录数）

**批注内容**

- **展示内容**：摇篮到大门 / 摇篮到坟墓两个边界的记录数、占比；**不展示碳足迹合计**（已按裁决去掉面板右上「合计 x tCO₂e」）。
- **取值规则**：记录数按边界计数；占比分母为**两个边界记录数之和**（即当前区间内全部有效记录数）；两种边界互斥。
- **口径说明**：本区块只统计记录数，不做碳足迹加总，避免把不同声明单位的碳足迹值混算，与页脚「同单位样本」口径保持一致。
- **数据来源**：核算台账的有效记录（与行业 Top 5 同源），区间内计数。
- **无数据**：两个边界都为 0 时**整块不显示任何行**，面板只剩标题。

#### D01-09 生命周期阶段构成占比
**拟标注位置**：右侧面板标题「生命周期阶段构成占比」
**标记**：原型已表现·待核对

**批注内容**

- **展示形式**：环形图 + 右侧图例；环心显示占比最高的阶段名称与占比。
- **统计口径**：**区间内全部有效台账记录**的一级生命周期阶段占比取**算术平均**（每条记录等权，**不按排放量加权**），与副标题「全部有效样本 · 阶段占比」一致。
- **图例**：阶段名 + 占比（1 位小数），颜色按阶段出现顺序分配，最多取配色序列前 6 色循环。
- **解读限制**：不同产品的阶段配置不同，平均后各阶段占比合计**可能不等于 100%**（见 §4 X-06）；本图**不区分系统边界、不区分品类**，只作结构总览。
- **无数据**：显示「暂无阶段数据」，环形图为空。

#### D01-10 核算量与单位碳足迹趋势
**拟标注位置**：底部左面板标题「核算量与单位碳足迹趋势」及三个筛选下拉
**标记**：原型已表现·待确认（汇总口径）

**批注内容**

- **双轴**：左轴核算量（条，柱），右轴汇总碳足迹（tCO₂e，折线 + 面积）；悬浮提示补「单位碳足迹中位数」。
- **筛选**：边界 / 行业 / 单位三个下拉，任一可取「全部」；**选择即生效，没有「查询」按钮**；切换后取对应的年度序列。
- **序列生成**：预生成「全部 + 具体值」的三维组合（共 `(1+边界数) × (1+行业数) × (1+单位数)` 组年度序列），取**精确匹配**；组合不存在时图内显示「该筛选组合暂无已完成核算记录」，**不做降级替换或近似**。
- **年份轴**：区间内**实际有记录**的年份，缺年不补 0，不显示空年份。
- **汇总碳足迹**＝组合内全部记录的单位碳足迹值求和后换算为吨；选「全部」单位时**跨声明单位加总**（见 §4 X-02）。
- **单位碳足迹中位数**＝组合内各记录单位碳足迹值的中位数，仅用于悬浮对照，不单独成线。
- **不具备**：无导出、无数据表、无同比 / 环比、无点击联动其他区块。
