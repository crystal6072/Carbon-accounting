## 1. 拟添加的批注清单

### 1.1 整体流程

#### D02-01 企业驾驶舱使用流程
**拟标注位置**：页头标题「企业碳足迹驾驶舱」附近（全局说明入口）
**标记**：原型已表现·待核对

**批注内容**

- **适用场景**：企业管理者 / 核算负责人在对外汇报或内部复盘时，用一屏回答「我核算了多少产品、排放集中在哪里、碳足迹在变好还是变坏、和行业基线差多少、哪几个产品最高」。
- **流程**：从菜单「数据驾驶舱」进入（新页签、全屏）→ 页内切到「企业驾驶舱」→ 先确认页头组织名，按需调整**统计区间**（或点「近 3 年」）→ 读 4 项基础指标 → 看「年度排放总量」了解按品类的规模结构 → 看「碳足迹趋势」并切换同口径分组、对照行业基线 → 看「碳足迹 Top 10」定位高排放产品 → 看「生命周期阶段构成」定位排放阶段 → 按 `C` 呼出结论卡。
- **分支**：① 统计区间内无核算记录时，各图给空态文案；② 趋势分组无同口径基线时，明确提示「暂无同口径行业基线」且不画基线、不算占比；③ 切换产品 / 边界 / 类别页签时，相关下拉与列表联动重置；④ 装载失败时无提示、无重试（见 D02-03）。
- **衔接**：本页**没有任何下钻、跳转、导出**；Top 10 的行、阶段饼图、地图类元素均不可点，需到「碳足迹核算」「报告管理」等模块查看明细。
- **结束**：关闭页签或切到平台视角即离开；本页无保存、提交、审核动作，也没有流程终点。

### 1.2 全局规则说明

#### D02-02 全局规则
**拟标注位置**：页头标题附近（与整体流程同一全局说明入口）
**标记**：原型已表现·待核对（权限、报告范围、加总口径为待确认）

**批注内容**

1. **只读大屏**：无新增 / 编辑 / 删除 / 导入 / 导出入口，无表格、无分页、无「查询」按钮；筛选即生效。
2. **企业范围**：展示对象为**当前登录用户所属组织**（组织名显示在指标区首块），**本页不提供组织切换**；本期单组织口径。
3. **入口与形态**：从系统菜单「数据驾驶舱」进入，**整屏独立打开**（不显示业务侧栏与顶栏）；入口默认是平台视角，页内可切到企业视角。
4. **视角切换＝整屏重新汇总**：页头「平台驾驶舱 / 企业驾驶舱」为两个按钮，点击后整屏重新汇总并重绘，不是局部切换；切换后数字重新滚动、主图口径清空。
5. **统计区间的影响面（关键）**：区间只影响「已核算记录 + 年度排放总量 + 碳足迹趋势 + Top 10 + 阶段构成 + 结论卡」；**不影响**「我的产品 / 我的工艺」，而「报告」**既不受区间也不受组织过滤**（见 D02-15、§4 X-05 / X-06）。
6. **核算口径（页脚常显）**：`GB/T 24067-2024 · IPCC AR6 GWP100 · 同品类同边界同单位样本`；要求**跨声明单位不加总、不比较**，但「年度排放总量」与「Top 10」存在跨单位混排（见 §4 X-03 / X-04）。
7. **适配方式**：按 **1920×1080** 设计稿等比缩放，取「屏幕宽 / 1920」与「屏幕高 / 1080」较小值，整屏完整、**永不出现滚动条**；字号随屏幕缩放，需现场核对可读性。
8. **时间口径**：页头「数据截止 {时间}」取**打开页面时的系统时刻**，不是数据实际截止时间；无刷新按钮、无自动轮询。
9. **演示标识**：页脚固定显示「演示数据 · 外部验收」，正式交付前必须移除（见 D02-23）。
10. **键盘快捷键**：`C` 呼出 / 关闭结论卡，`Esc` 关闭结论卡或退出全屏；在大屏任意位置按键均生效，**下拉框聚焦时同样触发**（见 §4 X-13）。
11. **权限与数据范围**：原型无权限控制；企业视角按当前账号所属组织过滤台账，但**报告、数据上报动态未按组织过滤**，且可一键切到平台视角看全平台数据（见 §4 X-10）。
12. **概念不外露**：不出现计算式、因子、异常编号；保留 `tCO₂e`、`GWP`、`功能单位`、`声明单位` 等核算专业词。

### 1.3 进入与数据装载

#### D02-03 进入与数据装载（含加载态）
**拟标注位置**：页头标题附近（全局说明入口）
**标记**：原型已表现·待核对（失败处理为待确认）

**批注内容**

- **触发**：从平台视角切过来，或在大屏内刷新；每次进入 / 每次改筛选都重新汇总，**不缓存**。
- **装载方式**：一次性汇总多类数据（核算台账、行业基线、报告、数据上报、产品、工艺、账号等），全部到位后一次性呈现，避免「半空屏」。
- **加载中表现**：主区显示环形动画 +「正在汇总企业数据…」；页头、页脚仍在，指标区不显示占位数字。
- **区间回写**：选择器里的年份区间会自动**收窄到台账实际年份**，并把收窄后的区间回写到选择器，避免下拉出现不存在的年份。
- **失败表现**：汇总失败时仅把内容置空，**无错误文案、无重试**，页面停在加载态（见 §4 X-12）。
- **刷新**：无刷新按钮、无轮询；只能刷新浏览器或重新进入。
- **待确认**：失败提示与重试、是否需要自动刷新。

### 1.4 同口径分组与行业基线匹配

#### D02-04 同口径分组与行业基线匹配（替代「业务状态说明」）
**拟标注位置**：碳足迹趋势面板「切换口径」下拉与基线提示条
**标记**：原型已表现·待核对

**批注内容**

本页自身**没有业务状态**；核心是「同口径」这件事——不同口径的数据不能放在一条线上比，所以先分组、再对标。

**分组规则**

| 项 | 规则 |
| :--- | :--- |
| 分组键 | **产品分类 + 系统边界 + 功能单位**（三者全同才算同一口径） |
| 组内样本 | 区间内该组合的全部有效台账记录 |
| 产品范围 | 组内按产品编码去重计数（编码为空按产品名称） |
| 默认分组 | 优先「**年度覆盖最全**」的组（有记录的年数最多），其次样本量最大；**不为了有基线而牺牲趋势可读性** |
| 切换分组 | 下拉显示「分类 · 边界 · 单位（样本数）」，选择即重算；分组不存在时回落到默认组 |

**行业基线匹配**

| 项 | 规则 |
| :--- | :--- |
| 匹配条件 | **行业 + 系统边界 + 功能单位 + GWP 版本**四项全同 |
| 多命中取舍 | 先取**基准年最新**；同年多条时，企业视角**优先本组织基线**，其次平台基线 |
| 命中展示 | 提示条显示「行业基线：{基线名称}（{基准年}）」，下方补「行业 · 边界 · 单位 · 来源类型 · 发布机构」 |
| 未命中展示 | 「暂无同口径行业基线」，并明示「未绘制基线，不计算占比」——**不降级替换、不用其他口径基线顶替** |
| 使用方式 | 趋势图画一条**常数虚线**（基线值不随年份变化），不参与「优于基线占比」以外的计算 |

- **待确认**：基线为常数线是否符合基线库「按基准年一条值」的定义；是否支持分年度基线。

### 1.5 统计区间筛选

#### D02-05 统计区间筛选
**拟标注位置**：指标区首块「统计区间」两个下拉与「近 3 年」
**标记**：原型已表现·待核对

**批注内容**

- **控件**：起始年下拉 `—` 结束年下拉 +「近 3 年」按钮；年份选项来自**本组织台账实际出现的年份**（升序）。
- **联动**：改起始年时，若新起始年大于结束年，**结束年自动抬到起始年**；改结束年时，若新结束年小于起始年，**起始年自动降到结束年**。
- **近 3 年**：取「台账最后一年往前 2 年 ~ 最后一年」；台账年份不足 3 年时按实际夹紧。
- **生效方式**：选择即重新汇总，**没有「查询」按钮**；区间只在本屏内生效，不改变其他页面的筛选。
- **影响面**：见 D02-02 第 5 条；区间变化后各区块同步刷新，已选的产品 / 边界 / 类别页签**保持不变**（若该产品在新区间无数据，阶段面板自动回落到第一个产品）。
- **不具备**：无「本月 / 本季 / 本年」快捷项、无自定义起止日期、无同比区间对比。

### 1.6 区块说明、操作功能及对应业务规则

#### D02-06 顶部指标区（企业名 + 4 项指标）
**拟标注位置**：指标区整体（从左到右：企业名 → 我的产品 → 我的工艺 → 已核算记录 → 报告）
**标记**：原型已表现·待核对

**批注内容**

- **首块**：英文小标 `ENTERPRISE COCKPIT` + 企业名称 + 统计区间控件（见 D02-05）。
- **4 项指标**：我的产品 / 我的工艺 / 已核算记录 / 报告（字段口径见 D02-14、D02-15）。
- **数字表现**：进入与切视角时从 0 滚到目标值（1.2 秒，缓出），千分位整数；系统开启「减少动效」时直接显示终值。
- **口径差异（重要）**：同一行内「我的产品 / 我的工艺」取**库口径**（全部，不受区间影响），「已核算记录」取**台账口径**（区间内有效记录），「报告」取**全部报告**（不限年份、不限组织、不限状态）——四者不是同一范围，注释行已分别写明。
- **无数据**：数值为 0 时照常显示 0，不走「—」；原型未启用「数据不足」表达。
- **不具备**：不可点、无下钻、无环比 / 同比。

#### D02-07 年度排放总量
**拟标注位置**：第二行左侧面板标题「年度排放总量」
**标记**：原型已表现·待确认（命名与口径）

**批注内容**

- **展示形式**：柱状图，横轴为「产品分类（同分类存在多个功能单位时，第二行补单位）」，纵轴为汇总值，柱顶显示数值；面板右上「n 个分类口径」。
- **汇总规则**：按「**产品分类 + 功能单位（排放量单位 / 声明单位）**」分组，**同一分组内**把区间内全部记录的单位碳足迹值求和；**跨单位不合并**（轴标签用两行区分）。
- **悬浮提示**：分类名 + 汇总排放量 + 功能单位 + 核算记录条数。
- **命名问题（重要）**：记录上的碳足迹值是「按声明单位的碳足迹」，把多条记录求和后称「排放总量」，**物理含义是『每声明单位碳足迹的多条记录合计』，不是该品类的实际排放总量**（见 §4 X-01）。
- **跨边界风险**：分组键**不含系统边界**，摇篮到大门与摇篮到坟墓的记录会被加在同一根柱子里（见 §4 X-02）。
- **排序风险**：按数值降序排列，但数值分属不同功能单位，**混排顺序没有可比性**（见 §4 X-03）。
- **无数据**：图内文案「当前筛选条件下暂无核算记录」；但本图**只受统计区间影响**，不受边界 / 类别筛选影响，文案与实际不符（见 §4 X-11）。

#### D02-08 碳足迹趋势（口径切换 + 行业基线）
**拟标注位置**：第二行右侧面板标题「碳足迹趋势」及口径切换下拉、口径条、基线条
**标记**：原型已表现·待核对

**批注内容**

- **切换口径**：下拉「分类 · 边界 · 单位（样本数）」切换同口径分组（见 D02-04）。
- **口径条（三枚标签）**：产品范围（分类 + `n 个产品`）/ 系统边界 / 功能单位——**固定展示在图上，避免脱离口径看图**。
- **基线提示条**：命中显示「行业基线：{名称}（{基准年}）」+ 行业 · 边界 · 单位 · 来源类型 · 发布机构；未命中显示「暂无同口径行业基线」+「未绘制基线，不计算占比」。
- **图形**：柱＝核算次数（右轴，整数），虚线＝行业基线（常数），实线 + 面积＝本企业单位碳足迹（左轴）；**末点标注最新值**。
- **纵轴范围**：以「本企业各年值 + 基线值」的极值为基础外扩（35% 差值或 8% 极值或 0.05 兜底），保证曲线与基线都可见。
- **悬浮提示**：默认按轴展示各系列数值与轴名，无自定义文案。
- **无数据**：图内文案「当前区间暂无同口径核算记录」。
- **待确认**：用中位数而非均值、样本量下限（少于 n 条是否照样出图）、基线不随年份变化是否合理。

#### D02-09 碳足迹 Top 10
**拟标注位置**：第三行左侧面板标题「碳足迹 Top 10」及边界页签、类别下拉
**标记**：原型已表现·待确认（跨单位排序）

**批注内容**

- **筛选一：边界页签**「摇篮到大门 / 摇篮到坟墓」，页签后带**记录条数**；切换后类别下拉**重置为「全部产品类别」**，可选项重新从当前边界的记录中提取。
- **筛选二：产品类别下拉**，选项随边界页签联动。
- **排序与取数**：全部记录先按碳足迹值**全局降序**，再做边界 / 类别过滤，取前 10；**排序是跨单位混排**（见 §4 X-04）。
- **每行内容**：排名（前 3 高亮）、产品名称（超长省略 + 悬停看全称）、`类别 · 年度`、碳足迹数值 + 单位。
- **页脚说明**：「数值口径随记录声明单位，不同功能单位之间不做比较」——该说明与排序行为**存在冲突**（排序本身就在跨单位比较）。
- **无数据**：图内文案「当前筛选条件下暂无核算记录」（文案与实际筛选维度一致）。
- **不具备**：不可点、无导出、无「查看全部」、无排序方式切换、同产品多条记录**不去重**。

#### D02-10 生命周期阶段构成占比
**拟标注位置**：第三行右侧面板标题「生命周期阶段构成占比」及「按产品切换」下拉
**标记**：原型已表现·待核对

**批注内容**

- **切换产品**：下拉「{产品} · {边界}」，选项为区间内有阶段数据的「产品 + 边界」组合，默认第一个（年度覆盖最多的）。
- **展示内容**：**只展示该产品最新年度**的环形图 + 右侧明细；副标题给出「分类 · 单位 · 边界 · {年份} 年各阶段占比」。
- **环心**：占比最高的阶段名称与占比（1 位小数）；无数据显示「— / 暂无阶段数据」。
- **右侧明细**：首行为「年份 + 该年单位碳足迹总值 + 单位」，下方逐阶段列出「占比 + 阶段排放量」；阶段按**占比降序**。
- **统计口径**：该年该产品全部记录的一级阶段占比取**算术平均**；阶段排放量取该阶段排放量的**中位数**；该年总值取各条记录单位碳足迹的**中位数**。
- **限制**：**不提供年度切换**，历史年份看不到；不区分同一年内的多个结果版本。
- **无数据**：面板副标题「暂无阶段构成数据」，图内「当前产品暂无阶段构成数据」。
- **待确认**：只展示最新年度是否满足复盘需求；多记录平均 / 中位数的统计方式是否固定为口径。

#### D02-11 底部最新动态
**拟标注位置**：底部滚动条「最新动态」
**标记**：原型已表现·待确认（跨组织内容）

**批注内容**

- **内容来源**：最近 3 条核算（**本组织台账**）+ 2 份已定稿报告（**全部报告，未按组织过滤**）+ 2 条数据上报（**全部上报，未按组织过滤**），合计最多 7 条；整条轨道复制一份循环滚动，悬停暂停。
- **时间取值**：核算取台账创建时间、报告取生成时间、上报取更新时间；缺失显示「—」。
- **风险**：企业视角会出现其他组织的报告与上报动态（见 §4 X-10）。

#### D02-12 汇报结论卡
**拟标注位置**：页脚提示「C 汇报结论」附近；卡片本身作为独立浮层
**标记**：原型已表现·待核对

**批注内容**

- **触发**：按 `C`；关闭：`C` / `Esc` / 点遮罩 / 右上角关闭按钮。标题为「{企业名} · 汇报结论」。
- **三条结构固定、文字由当前数据生成**：
  1. 规模与产出：`{起}–{止} 年，本企业产品库 X 个产品、工艺库 Y 个工艺，已完成 Z 条核算记录、生成 R 份报告`；
  2. 排放结构：占比最高的生命周期阶段 + 记录最多的产品品类；
  3. 主图口径与对标：主图口径 + 基线名称 / 基准年 / 来源 + 「当前口径 x% 的记录优于基线」；无基线时明示未计算占比。
- **口径风险**：第 1 条的「R 份报告」取全部报告（不限组织 / 年份 / 状态），与企业口径不一致（见 §4 X-05）。

- **不具备**：不可编辑、不可导出、不可翻页。

#### D02-13 视角切换与全屏
