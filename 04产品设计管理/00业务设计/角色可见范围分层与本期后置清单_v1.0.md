## 0. 结论

> **能力不减，暴露面减。**

| 判断 | 结论 |
| :--- | :--- |
| 功能范围重不重 | **不重** —— 均为 PCF 核算必需件，且方案已砍掉版本化、审核流、分析域、多气体、公式自定义 |
| 用户用不用得明白 | **目前偏重** —— 40+ 个概念（公式绑定/命中优先级、阶段三态、因子匹配规则、分配三层级、17 个异常编号……）被平铺给所有人 |
| 解法 | **三段分层 + 默认兜底 + 默认路径最短 + 高级折叠** |

**三条原则**

1. **角色分层**：配置者的复杂度关进"专业配置"门里；
2. **默认兜底**：预置模型 / 预置阶段 / 自动因子推荐，让"重的东西变成默认"；
3. **默认路径最短**：新用户走 `选产品 → 选模型 → 填数据 → 出结果`，不经过任何配置页。

**验收标准（唯一一把尺）**

> 一个**没培训的填报人**，能否在 **30 分钟内、不看文档**，跑完一个竹筷项目？

## 1. 三段式路径定义

按"谁在什么阶段做什么"把系统切成三段，**每段只暴露本段所需概念**。

| 段 | 使用者 | 面对的对象 | 需要的概念量 |
| :--- | :--- | :--- | :--- |
| **配置段**（后台管理） | 平台运营 / 专业配置人员 | 基础库、核算模型、计算公式、因子、分配规则 | 多（他们必须懂） |
| **项目段**（前台·核算） | 项目负责人 / 核算人员 | 核算项目、产品、边界、快照、检测、核算、报告 | 中（只懂"选、填、算、出"） |
| **填报段**（前台·填报） | 数据填报人 | 阶段 → 工序 → 活动数据 → 凭证 | **极少**（只看"填什么") |

> **关键约束**：项目段与填报段**不得出现**配置段的概念（公式、绑定、优先级、检测规则、异常编号、版本/快照术语）。

## 3. 关键"重概念"暴露策略（**本节是修订核心**）

> 目标：**概念不消失，但不出现在不该出现的人眼前。**

| # | 重概念 | 谁可见 | 用户侧呈现方式 | 默认折叠 |
| :-: | :--- | :--- | :--- | :---: |
| 1 | 公式绑定 / 命中优先级 | **仅专业配置** | 项目侧仅显示「**本工序使用：材料因子法**（只读）」 | ✅ |
| 2 | 「默认公式（未精确匹配时使用）」 | **仅专业配置** | 结果中标注「命中默认公式」，供审核判断口径粗细 | — |
| 3 | 生命周期阶段**三态**（必须/可选/不纳入） | **仅专业配置** | 用户侧只看「**阶段名 + 启用 / 排除**」（排除须填原因） | ✅ |
| 4 | 行业**阶段基线** | 系统自动 | **完全不出现**，按「行业 + 边界」自动加载 | — |
| 5 | **因子匹配规则**（活动类型+阶段+区域+年度） | 系统自动 | 「**推荐因子** + 采纳 / 替换」两步，不解释规则 | — |
| 6 | **计量单位基准中转 / 单位类型不可换算** | 不可见 | 仅在选择不匹配时报错（**E04** 人话提示） | — |
| 7 | **分配层级**（ISO 14044 三层级 + 留痕） | **仅专业配置** | 用户侧「**选方法 + 填比例（合计 100%）**」；层级合规**降级为提示** | ✅ |
| 8 | **异常编号 E01–E17** | 内部 / 审计 | **用户侧只显示人话问题 + 修改入口**（映射见下表） | — |
| 9 | **DQR 数据质量等级** | 不可见 | 随数据来源**自动生成**，可人工调整但**不强制填** | — |
| 10 | **项目快照 / 引用即复制** | 不可见 | 系统行为；用户仅感知"模型改了不影响已建项目" | — |
| 11 | **覆盖度检查** | 核算人员（结果级） | 呈现为「**待补充清单**」，**不暴露"覆盖度"这个词** | — |
| 12 | 受控表达式语法 | **仅专业配置** | 点选生成，用户不写表达式 | ✅ |

## 5. 各角色最短路径（**作为默认路径验收依据**）

| 角色 | 最短路径 | 经过的页面数 | 不经过 |
| :--- | :--- | :---: | :--- |
| **填报人** | 登录 → 我的待填 → 填数（含 Excel 导入）→ 提交 | **3** | 产品/模型/因子/公式/报告 |
| **核算人员** | 新建项目（选产品 + 选边界）→ 选预置模型（**默认已选**）→ 数据填报 / Excel 导入 → 检测 → 核算 → 结果 → 报告 | **7** | 模型配置、公式绑定、因子规则、分配层级 |
| **专业配置人员** | 模型管理 → 新建 → 绑「默认公式」→ 设因子开关 → 启用 | **5** | 项目数据填报 |
| **平台运营** | 租户开通 → 预置数据维护（因子 / 模型） | — | 租户业务数据（默认不可见） |

> **木竹开箱包**：`预置模型（通用·GB/T 24067-2024）+ 预置阶段（按行业自动加载）+ 预置因子 + 预置工序` → 核算人员**无需任何配置**即可跑通样板项目。
