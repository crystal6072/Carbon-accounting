# 竹木产品碳政策背景

> 依据来源：公开政策、标准与监管信息，包括国家发展改革委、市场监管总局/国家标准委、生态环境部、国家认监委、国家林业和草原局、国家数字标准馆、欧盟公开法规资料等。  
> 说明：本文仅做政策业务背景分析，供后续产品设计前的需求分析使用；不定义产品边界、功能模块、字段、流程或实施分期。所有判断按【事实/归纳/推断/待核实】标注。

## 0 背景摘要

【事实】我国正在从企业层面的碳排放管理，逐步延伸到产品层面的全生命周期碳足迹管理。国家层面已发布产品碳足迹管理体系建设意见、产品碳足迹核算通则、产品碳足迹标识认证试点规则，并推动重点产品核算标准和背景数据库建设。  
来源：`发改环资〔2023〕1529号`、`GB/T 24067-2024`、国家认监委 2025 年第 8 号公告等。

【事实】木竹产品已开始进入产品碳足迹标准和认证试点体系。`LY/T 3436-2025《木竹产品碳足迹评价指南》`、`T/CBIAS 2108-2025《温室气体 产品碳足迹量化方法与要求 竹木产品》` 等专项标准陆续发布；第一批产品碳足迹标识认证试点目录中，木制品对应认证目录包括“人造板和木质地板”。  
来源：国家林业和草原局、国家数字标准馆、产品碳足迹标识认证试点认证目录公开信息。

【归纳】竹木产品碳足迹政策背景的核心不是“是否需要算碳”，而是“如何在统一标准、可追溯数据、认证认可、供应链披露和国际互认语境下形成可信碳足迹结果”。这决定后续需求分析需要重点关注标准适用性、数据来源、核算口径、结果解释、认证证据和对外披露责任。

【推断】竹木行业的政策价值来自两端叠加：一端是木竹材料具有生物碳储量和长期固碳贡献，具备低碳产品叙事基础；另一端是企业在核算、认证、绿色采购、出口贸易和客户审查中需要提供可验证的产品碳足迹数据。

## 1 政策背景

### 1.1 双碳目标推动碳管理从组织走向产品

【事实】“碳达峰、碳中和”目标提出后，国家政策从总量控制、企业减排、行业转型，逐步扩展到产品全生命周期碳足迹核算。`《2030年前碳达峰行动方案》`提出探索建立重点产品全生命周期碳足迹标准。

【归纳】产品碳足迹成为连接企业减排、绿色消费、绿色采购、绿色金融和国际贸易的重要数据载体。相比企业年度碳盘查，产品碳足迹更关注某一类产品从原料获取、生产、运输、使用到废弃处置全过程的温室气体排放。

【推断】竹木企业若只掌握企业总能耗、总排放数据，难以满足客户对单个产品、单个批次、单个供应链环节的碳足迹披露要求。

### 1.2 产品碳足迹管理体系成为国家级制度方向

【事实】`《关于加快建立产品碳足迹管理体系的意见》（发改环资〔2023〕1529号）`提出五项重点任务：

| 任务 | 政策含义 | 对竹木行业的业务影响 |
| :--- | :--- | :--- |
| 制定产品碳足迹核算规则标准 | 形成统一、规范、可采信的核算规则 | 竹木产品需要从通用核算转向行业专项核算 |
| 加强碳足迹背景数据库建设 | 建设重点行业背景数据库，支撑企业核算 | 竹木行业需要积累原料、能源、辅料、运输、处置等因子和背景数据 |
| 建立产品碳标识认证制度 | 鼓励企业自愿开展产品碳足迹认证和标识 | 竹木产品碳足迹结果需要满足认证和标识使用要求 |
| 丰富产品碳足迹应用场景 | 推动生产、消费、贸易、金融等场景应用 | 碳足迹结果可能进入采购、销售、招投标、融资和客户审查 |
| 推动国际衔接与互认 | 加强与主要贸易伙伴方法学和认证互认 | 出口型竹木企业需要关注 ISO、EPD、欧盟规则等口径差异 |

【事实】该意见提出，到 2025 年国家层面出台 50 个左右重点产品碳足迹核算规则和标准，到 2030 年出台 200 个左右重点产品碳足迹核算规则和标准，并推动重点行业背景数据库、碳标识认证制度和国际互认。

【归纳】政策方向表明，产品碳足迹不会长期停留在企业自愿探索阶段，而会逐步形成“标准规则 + 因子数据库 + 标识认证 + 应用场景 + 国际互认”的制度体系。

### 1.3 产品碳足迹核算通则补齐国内基础标准

【事实】`GB/T 24067-2024《温室气体 产品碳足迹 量化要求和指南》`于 2024 年发布并实施，是我国产品碳足迹核算通用国家标准。该标准修改采用 `ISO 14067`，与生命周期评价标准 `GB/T 24040`、`GB/T 24044` 形成方法衔接。

【归纳】该通则解决的是“所有产品都应如何开展产品碳足迹量化”的共性问题，包括目的和范围、功能或声明单位、生命周期清单、影响评价、结果解释、报告、鉴定性评审和声明等。

【推断】对竹木行业而言，`GB/T 24067-2024`是底层通用依据，但不能完全解决竹木产品特有的生物碳、碳储量、含水率、产品寿命和废弃处置情景问题，因此需要叠加行业专项标准。

### 1.4 碳标识认证试点开始影响木制品市场

【事实】国家认监委发布`《产品碳足迹标识认证通用实施规则（试行）》`，用于规范产品碳足迹标识认证试点工作。第一批产品碳足迹标识认证试点认证目录中，木制品对应认证目录包括“人造板和木质地板”。

【归纳】这意味着木制品已进入国家产品碳足迹标识认证试点范围。竹木企业若产品形态接近人造板、地板、板材、家居建材等领域，后续可能面临客户要求、认证要求或市场竞争压力。

【推断】碳标识认证会改变企业对碳足迹数据的要求：从内部测算或宣传材料，转向需要第三方可核查、证据可追溯、结果可解释、标识使用合规的业务材料。

## 2 标准体系

### 2.1 国内通用标准

| 标准 | 定位 | 与竹木产品的关系 |
| :--- | :--- | :--- |
| `GB/T 24067-2024《温室气体 产品碳足迹 量化要求和指南》` | 产品碳足迹核算通则 | 作为竹木产品碳足迹量化的国内通用底座 |
| `GB/T 24040`、`GB/T 24044` | 生命周期评价基础标准 | 支撑 LCA 的目标范围、清单分析、影响评价和结果解释 |
| `GB/T 32150`、`GB/T 32151` 系列 | 组织/行业温室气体核算相关标准 | 更偏企业或行业层面，可作为企业数据背景参考，但不替代产品碳足迹核算 |

【归纳】国内通用标准提供方法框架，但产品级核算仍需结合具体产品类别规则、行业标准和认证要求。

### 2.2 竹木专项标准

| 标准 | 状态 | 业务意义 |
| :--- | :--- | :--- |
| `LY/T 3436-2025《木竹产品碳足迹评价指南》` | 2025 年发布，2025-11-01 实施 | 木竹领域首部聚焦产品碳足迹评价的行业标准，明确基本要求、量化方法、结果解释和报告等内容 |
| `T/CBIAS 2108-2025《温室气体 产品碳足迹量化方法与要求 竹木产品》` | 2025 年发布实施 | 规定竹木产品核算步骤、数据质量、碳足迹核算方法、生物碳储量计算与报告等 |
| 国家标准计划《温室气体 产品碳足迹量化方法与要求 木竹产品》 | 公开信息显示处于制定计划阶段 | 若后续发布，将可能成为木竹产品核算更高层级的国家标准依据 |

【事实】木竹产品专项标准强调竹木产品的材料属性和碳储贡献，弥补通用标准对天然生物质复合材料适用性不足的问题。

【归纳】竹木专项标准的出现，说明木竹产品碳足迹核算正在从“套用通用方法”转向“行业专用方法学”。

### 2.3 国际标准与方法学

| 标准/方法 | 定位 | 适用语境 |
| :--- | :--- | :--- |
| `ISO 14067:2018` | 国际产品碳足迹量化标准 | 面向国际客户、认证机构、跨境披露时常用 |
| `ISO 14040`、`ISO 14044` | LCA 基础标准 | 支撑生命周期评价方法 |
| `GHG Protocol Product Life Cycle Accounting and Reporting Standard` | 产品生命周期温室气体核算与报告标准 | 常用于供应链 Scope 3、客户披露和跨企业数据交换 |
| `PAS 2050` | 产品与服务生命周期温室气体排放评价规范 | 部分国际客户或历史项目仍可能引用 |
| `ISO 14025` | III 型环境声明标准 | EPD 环境产品声明的基础 |
| `EN 15804+A2`、`ISO 21930` | 建筑产品 EPD 核心规则 | 竹地板、竹板材、木竹建材进入建筑材料市场时需要关注 |
| `EN 15978` | 建筑全生命周期评价 | 当竹木产品作为建筑材料进入建筑整体碳评价时相关 |

【归纳】国际标准之间不是简单替代关系，而是按应用场景叠加：`ISO 14067`偏产品碳足迹量化，`GHG Protocol Product Standard`偏供应链温室气体披露，`ISO 14025/EN 15804`偏 EPD 和建筑产品环境声明。

【推断】竹木产品若服务国内认证，可优先关注国内通用标准和木竹专项标准；若服务出口客户或建筑材料市场，则需要关注国际口径差异。

## 3 竹木行业特殊性

### 3.1 生物碳与碳储量是竹木产品区别于一般工业品的核心特征

【事实】竹木材料在生长过程中吸收并储存生物碳，产品加工成地板、板材、家具、包装等后，部分碳会在产品寿命周期内继续储存在产品中。

【归纳】竹木产品碳足迹核算不能只看加工过程中的能源、燃料和辅料排放，还必须解释原料中的生物碳储量、产品使用期碳储存、废弃处置后的碳释放路径。

【推断】政策和标准对竹木产品的关注点，既包括“生产环节减排”，也包括“木竹材料固碳贡献如何科学表达”。如果表达不规范，容易出现低碳宣传争议或认证结果不可比。

### 3.2 碳储贡献不等于可以直接抵扣全部排放

【事实】公开标准信息显示，竹木专项标准会关注生物碳储量计算与报告。国际 EPD 规则通常要求区分化石碳、生物碳、土地利用变化相关排放等指标，并对边界外收益单独列示。

【归纳】竹木产品可以强调生物碳和长期碳储存，但是否纳入最终碳足迹总量、是否允许抵扣、如何列示负排放或延迟排放，需要按采用标准和认证规则确定。

【推断】后续需求分析不能预设“竹木产品天然为负碳”或“碳储量直接抵扣制造排放”。更稳妥的业务表述是：碳储量需要单独计算、单独解释、按标准规则列示。

### 3.3 竹木加工过程存在明显行业排放热点

【归纳】竹木产品的排放热点通常集中在以下环节：

| 环节 | 可能影响碳足迹的因素 |
| :--- | :--- |
| 原料获取 | 采伐方式、出材率、林地/竹林管理、集材距离、原料损耗 |
| 初加工 | 破竹、刨切、干燥、炭化、防腐、防霉等工艺 |
| 深加工 | 热压、胶合、砂光、涂装、成型、包装 |
| 辅料投入 | 胶黏剂、涂料、防腐剂、包装材料等 |
| 能源使用 | 电力、蒸汽、天然气、生物质燃料、柴油等 |
| 物流运输 | 原料运输、半成品调拨、成品配送、出口运输 |
| 使用阶段 | 产品寿命、维护频次、翻新、更换、重复使用 |
| 废弃处置 | 回收、再利用、焚烧、填埋、堆肥、能源回收 |

【推断】同为竹木产品，不同工艺路线、能源结构、辅料用量和产品寿命会导致碳足迹差异显著。因此政策背景下的“低碳竹木产品”不能只按材料类别判断，还要结合生命周期数据判断。

### 3.4 数据真实性和可追溯性会成为认证与披露的关键

【归纳】产品碳足迹政策体系强调核算边界、数据质量、溯源性、报告和认证。竹木企业如果缺少生产、能耗、辅料、物流、供应商和废弃处置数据，难以支撑可信核算。

【推断】未来行业竞争中，碳足迹能力可能从“能否计算”转向“数据是否可信、结果是否可认证、是否能被客户和监管采信”。

## 4 政策对行业经营的影响

### 4.1 对企业经营的影响

| 影响方向 | 业务含义 | 判断类型 |
| :--- | :--- | :--- |
| 产品低碳证明需求增加 | 客户、采购方、认证机构可能要求提供产品碳足迹报告或碳标识 | 【归纳】 |
| 碳数据成为产品竞争要素 | 低碳材料、低碳工艺、低碳能源和长期碳储存可能影响产品议价和市场准入 | 【推断】 |
| 绿色采购和招投标权重提升 | 政府、央国企、建筑、家居品牌可能把碳足迹纳入采购评价 | 【推断】 |
| 核算成本前置 | 企业需要提前整理原料、工艺、能耗、辅料、运输等数据 | 【归纳】 |
| 认证与审核压力增加 | 一旦使用碳标识或低碳声明，企业需要准备证据链并接受核查 | 【归纳】 |

### 4.2 对供应链协同的影响

【归纳】产品碳足迹不是单一企业内部数据，竹木产品涉及原竹/原木、胶黏剂、涂料、包装、物流、加工外协等多个供应链环节。政策推动后，供应商数据将影响最终产品碳足迹结果。

【推断】品牌商、出口商或大型制造企业可能向上游供应商提出碳数据填报、材料来源证明、因子来源说明和第三方认证要求。

【待核实】目前竹木行业内不同细分品类的供应商碳数据成熟度、第三方报告覆盖率和认证接受度仍需通过企业访谈或行业调研确认。

### 4.3 对外贸和国际客户的影响

【事实】欧盟及国际市场持续推进绿色贸易、环境声明、供应链尽责管理和产品环境信息披露。`EUDR`关注无毁林合规，`ESPR`和数字产品护照关注产品可持续信息，`EPD`体系关注建筑产品环境声明，`GHG Protocol`常用于企业供应链碳披露。

【事实/待核实】公开资料显示，欧盟关于无毁林产品规则的后续说明中，对竹、藤等非木材性质材料与木材范围的关系作出澄清；但具体产品是否适用仍需结合最终法规文本、海关编码、材料构成和目标市场要求判断。

【归纳】即便竹木产品不直接落入某一项欧盟碳或森林法规范围，国际客户仍可能基于自身 ESG、Scope 3、绿色采购或 EPD 需求，要求中国供应商提供产品碳足迹或环境声明数据。

【推断】出口型竹木企业的合规压力不只来自政府强制监管，也来自客户链条向供应商传导的披露要求。

### 4.4 对行业公共数据和方法学建设的影响

【归纳】产品碳足迹管理体系建设强调背景数据库和重点产品核算规则。竹木行业若缺少权威、透明、可更新的行业数据，企业核算会出现因子选择不一致、结果不可比、认证解释成本高等问题。

【推断】行业协会、科研机构、龙头企业和认证机构会在竹木产品因子、典型工艺、碳储量参数、产品寿命和废弃情景方面承担更重要角色。

## 5 需求分析关注点

> 本节仅列后续需求分析应关注的业务问题，不代表产品功能设计或建设边界。

| 关注问题 | 为什么重要 | 判断类型 |
| :--- | :--- | :--- |
| 目标产品是否属于人造板、木质地板、竹地板、竹板材、家具部件或包装制品 | 不同品类适用的标准、认证目录和生命周期边界可能不同 | 【归纳】 |
| 企业是为了内部管理、客户披露、认证标识、绿色采购还是出口合规 | 不同目标决定采用标准、报告深度和证据要求 | 【归纳】 |
| 采用国内标准还是需要兼容国际标准 | 国内认证和国际客户披露可能使用不同口径 | 【归纳】 |
| 生物碳储量如何列示 | 关系到竹木产品低碳价值表达和结果可比性 | 【归纳】 |
| 是否存在第三方认证或碳标识目标 | 影响材料准备、数据质量和审核证据要求 | 【归纳】 |
| 供应商能否提供可采信数据 | 上游材料、辅料和物流数据会影响产品结果可信度 | 【推断】 |
| 是否面向欧盟、北美、日本等目标市场 | 不同市场的环境声明、绿色采购和客户要求不同 | 【推断】 |
| 企业历史数据是否足以支撑全生命周期核算 | 缺失数据会影响核算范围、数据质量评级和报告解释 | 【推断】 |

## 8 衔接摘要

【归纳】政策业务背景可概括为：国家正在建立产品碳足迹核算、数据库、标识认证和国际互认体系；木竹产品已出现专项标准和认证试点入口；竹木行业因生物碳储量、长期固碳和全生命周期数据复杂性，具备行业化分析必要性。

【归纳】后续需求分析应围绕“政策适用范围、目标产品类别、采用标准优先级、碳储量列示口径、认证/披露目标、数据可采信程度、目标市场要求”继续展开。

【待核实】本文基于公开资料整理，正式用于项目立项、认证申请或对外合规声明前，应以标准正式文本、认证机构要求、目标市场法规和企业实际产品信息为准。
